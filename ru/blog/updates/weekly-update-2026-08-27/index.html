Еженедельный дайджест Qwen Code: Goal — автоматическая передача дел при превышении бюджета, переключатель Thinking для моделей Qwen, больше команд «/» прямо во время генерации

Qwen Team
2026-08-27

На этой неделе Qwen Code выпустил три официальных релиза — v0.21.15, v0.22.0 и v0.22.2 — и принял более 300 pull-реквестов.

Goal научился завершаться самостоятельно. Автономный режим Goal теперь работает с токеновым бюджетом: когда лимит исчерпан, Goal пишет отчёт о проделанном и останавливается. Если цель изначально недостижима — Goal прекращает работу заранее.

Переключатель Thinking для моделей Qwen. Гибридные модели вроде qwen3.5-plus получили простой переключатель Thinking: выключил — модель отвечает без размышления, включил — вернулся к поведению по умолчанию.

Больше команд «/» прямо во время генерации. Пока AI генерирует ответ, 10 команд вроде /theme и /tools теперь работают без ожидания — результат появляется мгновенно.

✨ Новые возможности

Goal: автономная работа с бюджетом и отчёт перед остановкой

Автономный режим Goal на этой неделе обзавёлся «самоконтролем»: он считает расходы, знает, когда пора остановиться, и перед остановкой оставляет отчёт.

Расходы на виду. Для каждого Goal ведётся отдельный учёт потраченных токенов — всё видно в get_goal рядом с количеством раундов.

Бюджет по умолчанию. Новые Goal создаются с токеновым бюджетом: когда он исчерпан, Goal переходит в режим ожидания. Чтобы продолжить, восстановите или отредактируйте Goal — бюджет автоматически продлится на ещё одно окно.

Отчётный раунд перед остановкой. При достижении лимита включается дополнительный «раунд передачи»: Goal не начинает новую работу, а описывает, что сделано, что осталось и что делать дальше. Новый участник прочитает этот отчёт и сразу включится в работу.

Остановка при зависании. Три подряд зависших чекпоинта — Goal останавливается автоматически. Если есть доказательства, что цель невыполнима, он прекращает работу в том же раунде.

/goal-draft превращает смутную идею в исполняемый Goal. Сначала он задаёт несколько вопросов, чтобы прояснить смутную идею, затем составляет проверяемую цель и прикладывает готовую команду /goal set, которую можно сразу запустить. Он только черновит и не берётся за работу; использовать ли его — решать вам.

Подробнее: PR #9583 , #9891 , #10132 , #9975 , #10125 , #10002 

Переключатель Thinking для моделей Qwen

В web shell для моделей qwen3.5-plus, qwen3.6-plus, qwen3.6-flash, qwen3.7-plus и qwen3.7-max появился переключатель Thinking: выключите — модель ответит без размышления; включите — сначала подумает, потом ответит.

Для qwen3.8-max сохраняется трёхступенчатая настройка глубины размышления: low / medium / extra high.

Подробнее: PR #9574 

Рабочие процессы: официальный переключатель и пре-аппрув

Рабочие процессы позволяют разбить большую задачу на части и распределить их между несколькими AI-ассистентами. На этой неделе добавлены три уровня контроля:

  • Официальный переключатель: включите tools.workflowsEnabled в настройках — и только вы можете это сделать, конфигурация проекта остаётся нетронутой
  • Пре-аппрув: перед запуском окно подтверждения полностью показывает скрипт рабочего процесса, который AI только что написал — что он исследует, как делит работу, как сводит результаты. Вы читаете, подтверждаете — и только тогда он запускается
  • Запуск по запросу: рабочий процесс стартует только по вашей команде — скажите «используй рабочий процесс», укажите конкретный процесс или попросите продолжить предыдущий; если AI считает, что нужен рабочий процесс, а вы не предложили, он сначала опишет план распределения и количество ассистентов и дождётся вашего решения

Подробнее: PR #9098 , #9837 , #9806 

PR на GitHub привязан к создавшей его сессии

Раньше, чтобы найти, из какой сессии был создан PR, приходилось листать историю. Теперь PR, созданный через Git-панель Web Shell, привязывается к сессии-создателю: рядом с названием сессии в боковой панели появляется значок PR, а поиск по номеру PR сразу находит нужную сессию. Одна сессия хранит до 10 PR; при повторном пуше того же PR запись обновляется.

Подробнее: PR #9543 

Больше команд «/» прямо во время генерации

Раньше большинство slash-команд приходилось ждать окончания текущего раунда генерации. Теперь 10 команд работают без очереди: /theme, /editor, /vim, /voice, /terminal-setup — настройки интерфейса, а также /tools, /tasks, /hooks, /docs, /bug — команды только для чтения. Пока AI говорит, вы пользуетесь — результат появляется мгновенно.

Подробнее: PR #9495 

📊 Прочие новинки

qwen3.8-max стал стабильным. Модель qwen3.8-max вышла из превью — пользователи Token Plan теперь выбирают стабильную версию прямо в /model. Подробнее: PR #9383 

Файлы можно прикрепить на ходу. На прошлой неделе файлы можно было перетаскивать в поле ввода Web Shell, а теперь — прикреплять даже в разгар диалога: поддерживаются и вложения из поля ввода, и @-ссылки на файлы рабочей области. Загруженные файлы сохраняются надёжно. Подробнее: PR #9570 , #9477 

Диалоговая модель теперь умеет и генерировать изображения. Одна и та же модель одновременно поддерживает диалог и встроенную генерацию изображений — отдельная модель для картинок больше не нужна; генерация изображений также поддерживает API MiniMax. Подробнее: PR #9650 , #8322 

Управление Goal прямо в Web Shell. Goal больше не теряется среди сообщений — в Web Shell для него выделена компактная строка управления. Подробнее: PR #9393 

Запланированные задачи можно запускать в текущей сессии. При создании запланированной задачи можно выбрать, чтобы она выполнялась в текущей сессии. Подробнее: PR #9838 , #9361 

Код десктоп-приложения перенесён в OpenWork. Electron-код десктопной версии переехал в отдельный open-source проект OpenWork ; в репозитории Qwen Code остался мост миграции на новую десктопную версию. Подробнее: PR #9085 

Computer Use переведён на драйвер навыков. Управление компьютером через AI теперь работает через встроенные навыки: при первом использовании автоматически устанавливаются зависимости, после перезапуска всё работает как прежде; Node REPL из встроенного инструмента превратился в отдельный MCP-пакет @qwen-code/node-repl-mcp — по умолчанию отключён, активируется через конфигурацию mcpServers. Подробнее: PR #9856 , #9587 , #9499 

Kimi — встроенный провайдер. В /auth выберите сторонний провайдер Kimi, вставьте API key — и всё готово; доступны как международные, так и внутренние эндпоинты. В списке моделей уже прописаны флагманская K3, K2.6 и две специализированные модели для кода, список можно редактировать. K3 работает с размышлением по умолчанию, остальные три — свободным переключателем. Подробнее: PR #9814 

👏 Улучшения UX

Панель расхода токенов в Web Shell. Откройте панель на уровне сессии: суммарный расход, разбивка по моделям, вызовы суб-агентов, статистика использования инструментов — всё на одной странице. Подробнее: PR #9988 

Компактный режим — единственный режим Web Shell. Блоки размышлений и активности инструментов по умолчанию свёрнуты в строку-сводку, переключатель Ctrl+O убран; основной диалог, разделение экрана и панель деталей суб-агентов теперь используют единый компактный рендер. Подробнее: PR #9993 , #9657 

Карточки аппрува — прямо в потоке сообщений. Окна аппрува и вопросов больше не перекрывают весь список сообщений, а отображаются как карточка внизу, по ширине совпадающая с областью чата. Подробнее: PR #9351 

Фоновый shell — раунд остаётся раскрытым. Если в раунде запущен фоновый shell, раунд остаётся развёрнутым до завершения — удобно следить за прогрессом. Подробнее: PR #9632 

Единый рендер в плагине VS Code. Таймлайн сессии в плагине VS Code теперь использует тот же рендерер, что и Web Shell — опыт работы выровнен. Подробнее: PR #9719 

60 FPS в большом терминале. Частота рендеринга виртуальной прокрутки терминала поднята с 30 до 60 кадров в секунду — прокрутка истории в большом окне заметно плавнее. Подробнее: PR #9681 

Видны загруженные контекстные файлы. Если вы подключили пользовательские контекстные файлы через настройки, над первым сообщением сессии теперь появляется их список — раньше этот шаг был полностью скрыт. Подробнее: PR #8855 

Сессия запоминает выбранную модель. После перезапуска или переподключения daemon-сессии восстанавливается модель, выбранная вами в прошлый раз; новые сессии по-прежнему используют модель по умолчанию из настроек. Подробнее: PR #9687 

DingTalk-канал понимает цитаты. Раньше при цитировании картинки или файла в DingTalk AI видел лишь заглушку; теперь цитируемые изображения, файлы, аудио и видео реально скачиваются и передаются AI, а пересланные сообщения из чатов парсятся с извлечением заголовка и краткого содержания. Подробнее: PR #9347 , #9339 

Установка расширений из приватных репозиториев. Установка расширений через HTTPS Git теперь поддерживает аутентификацию — можно клонировать из приватного репозитория, а сохранять учётные данные или нет — на ваш выбор. Подробнее: PR #9458 

Публичные расширения на старых версиях Git. На системах с Git ниже 2.37 установка публичных расширений с GitHub идёт через загрузку архива. Подробнее: PR #9680 , #9690 

Web Shell с авторизацией одной командой. qwen serve --open-with-auth открывает локальный Web Shell с токен-аутентификацией; если токен не настроен, он автоматически генерируется и передаётся браузеру. Подробнее: PR #9738
