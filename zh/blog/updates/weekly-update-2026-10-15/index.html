Qwen Code 周报：@ Claude Code、Codex 当队友，一个页面连几个 Qwen Code 项目，启动时点名去掉 MCP 服务

Qwen Team
2026-10-15

Qwen Code 本周发布 v0.25.1、v0.25.2 两个正式版本，371 个 PR 合入。

Agent Collaboration：把 Claude Code、Codex @ 进对话里当队友。 它的回答直接出现在你当前这段对话里，还能放到另一台电脑上去跑。

你开的几个 Qwen Code，一个页面同时连着。 侧栏一个 Qwen Code 占一组，各组下面列的是它当下真实的会话和工作区，来回切换都在页面里完成。

不想用某个 MCP 服务，启动时点名去掉就行。 qwen --disable-mcp-server <名字> 只管这一次，不动你的设置文件。

✨ 新增特性

Agent Collaboration：把 Claude Code、Codex @ 进对话里当队友

一件事想拆开同时办——比如让它改代码，同时叫另一个程序来复核。以前你 @ 一个 Agent，它另开一条话题、把你最近说的几句话复制过去、再把你带到那个新页面上，主对话里收不到它的回复。

现在 @ 它，它就在你当前这段对话里回答：带名字、走到哪一步、用了哪些工具、花了多少 token，要跑命令照样弹给你批。这个 Agent 不必是 Qwen Code——你装了 Claude Code 或者 Codex，也能 @ 进来使唤。详见 PR #13467 

它也可以在另一台电脑上干活：那边开着 Qwen Code 的服务，把它加进来当帮手，重活就派到那台机器上跑，那台机器重启之后自己接回来。还能 @ 一个组：组长负责把活拆开派给组员，组员干完回它。详见 PR #13583 

它和派子代理的分工是：子代理是它自己派出去办一件小事、只向它汇报；@ 进来的这个在你眼前说话，可以是别的厂商的程序，也可以在另一台机器上。

这项还在实验阶段，默认关着：在设置里打开「启用 Agent 协作」，重启后生效。队友要先建：在左侧「智能体」页新建一个。之后在任何对话里 @ 它的名字，就能叫它来。

你能用它做什么：

  • 一边让它改代码，一边 @ 另一个 Agent 复核，两条线在同一段对话里看得清
  • 把编译、跑测试这类重活派给另一台机器，自己这边继续干活
  • 让不同厂商的程序搭同一个组，各干各擅长的那一段

你开的几个 Qwen Code，一个页面同时连着

有人手边一台笔记本、一台专门跑编译的电脑、还有一台挂着长活儿；也有人就一台电脑，给每个项目单开一个 Qwen Code Web Shell，不想几个活儿搅在一处。以前一个浏览器页面只认其中一个，要看另一个得让页面整个重新加载，中间闪一下，你在这边写到一半的东西也丢了。

现在保存过的几个同时连着。侧栏一个 Qwen Code 占一组，每组下面列的是它当下的会话和工作区；输入框里挑工作区时，各组的目录也按组分着放；切到另一组在页面里就完成了。详见 PR #13739 、#13677 

要用它，被连的那台得先允许你这个页面连进来：起 qwen serve 时带上 --allow-origin，填你在浏览器地址栏看到的页面地址。

你能用它做什么：

  • 编译那台在跑长活儿，你在自己电脑上盯着它到哪一步
  • 一台电脑上给几个项目各开一个，几个活儿不搅在一处，一个页面看全
  • 从笔记本换到台式机，接着派活

不想用某个 MCP 服务，启动时点名去掉

接了 MCP 服务的人大概都碰过：某一个服务今天出问题，工具报错、或者拖慢启动，你想的只是「这一次先别带上它」。以前只有一刀切的做法，把设置里来的服务连同本地配置一起关掉。

现在可以在启动时点名：

qwen --disable-mcp-server github

要一次关掉几个，这个参数可以重复写，也可以写成 --disable-mcp-server github,postgres。它只管这一次启动，你的配置文件不动。详见 PR #14003 

你能用它做什么：

  • 怀疑某个服务出问题，先关掉它试一次，看是不是它
  • 启动被某个服务拖慢，这一次先不带上它
  • 同一份代码，一轮专跑数据库、一轮专跑网页，各带各的服务

Web Shell：项目里的文件点开就能看，补的话当场送到，等你点头时会提醒你

项目里的文件在右侧就能翻。 整棵工作区的目录树摆在这里，点开一个文件，内容就在旁边：Markdown、网页、图片、Excel 都直接看得了，也能复制路径、下载、引用。详见 PR #13878 、#13664 

本地的文件拖进去就上传。 拖进哪个文件夹就传到哪个文件夹，在桌面版里也一样。详见 PR #14145 、#14053 

排队的消息立刻插入，取消后退回输入框。 它正在回答时发送的内容先排队，急着让它收到可以点「立即发送」立刻插入；AI 还没输出时按停止，那句话退回输入框，改好再发。详见 PR #13681 、#13488 

它停下来等你的时候会发通知。 要你放行一个操作、或者要你回答它反问的那道题，这两种时候以前没有任何动静；现在只要页面切到后台，就会弹一条通知，点一下回到那条会话。详见 PR #13832 

有子代理或者后台任务在跑时，聊天区顶部的列表样式的图标会亮一个闪点。 不用打开面板也看得见。详见 PR #14048 

📊 更多新功能

连着查了很多次还没给你结果，会被提醒交结论。 读文件、搜代码这类只读动作跑到一定次数，下一轮它会收到一句提醒：把手上查到的用起来、把你要的东西往前推一步，或者讲清卡在哪；本来就是让你摸清情况的，就把结论和还没弄明白的问题说出来。详见 PR #13601 

MCP 服务带来的界面想往对话里发内容，得先经你确认。 有些 MCP 服务不只给工具，还会在对话里给你一块能点的界面。这块界面要替你发一段话时，Qwen Code 先把完整内容、它从哪儿来、要发进哪段对话摊给你，你点确认才真的发出去。详见 PR #13958 

工作流里每个 agent 干了什么，点它的节点就能看到。 对话里的工作流卡片、Tasks 页或者工作流页上点一个 agent，右侧面板打开它这一次的经过：给它下的提示、跑过哪些工具、正在输出什么、走到哪一步。详见 PR #14175 

动手之前的那道检查，能改它这一次要执行的参数。 你在设置里配的 hook 就是这种检查：它要用某个工具之前先跑一遍。这一遍交回来的新参数会先重新校验、再走一遍权限和确认，然后才真的动手。详见 PR #13442 

顺带的一问，能开到另一份工作区。 主任务正在回答时，/btw side 可以在它所属的另一份工作区里单独建一条对话，不跟主任务混在同一段。详见 PR #13468 

Claude 格式插件自带的命令，现在真能跑了。 这类命令是一段代码，不是给模型的提示词：以前敲它等于跟模型说了句话，现在插件在本地跑完直接返回结果，不花 token。要在设置里打开 experimental.mods、工作区受信任，且只在 qwen -p '…' 这种跑一次出结果的用法里生效，交互界面和 Web Shell 暂不支持。只实现了 Mod 接口的一部分，现成的不保证个个能跑。详见 PR #13843 、#13890 、#13915 、#13950 

👏 体验优化

新建任务那一页，还没开口就能用右侧的文件、终端和网页预览。 顶部换成一条精简的工具栏；每个工作区这套布局各自记住，刷新、切会话都不丢。你发出第一句话时，连标签页、排列顺序、面板宽窄和全屏一起交给新建的那条会话。详见 PR #14159 

轨迹页签能搜、能筛、能往前翻。 搜工具名、模型名或者一段记录文本都能跳过去，也可以只看某一类记录、只看失败或成功的。更早的记录能一段段翻过去，翻完回到最新那份——搜索和统计只算你当前翻到的这一段。中途断线重连，你停在哪儿、选了哪条、筛着什么、滚到哪儿，都不丢。详见 PR #13264 、#13716 、#13952 

回答里选中一段，能挑怎么复制。 鼠标划一段，菜单里给你两个选择：纯文本，或者带原本写法的 Markdown——标题、列表、代码、表格都跟着走。详见 PR #13833 

上下文用了多少，点一下开在右侧，不再往对话里堆卡片。 以前点输入框上那个圆环，对话里会落一张 Context Usage 卡片，卡片上的明细又落一张；现在两个都开在右侧面板，每条会话各留一份。想让它留在对话里，敲 /context。详见 PR #14086 

又宽又长的表格能全屏看。 点表格上的 Fullscreen 铺满整个窗口，按 Esc 或者退出按钮出来；你排的序、筛的条件、列设置、读到第几行都还在。详见 PR #13589 

排在队里的话，还没发出去就能就地删掉。 带着附件传到一半的那句也能删，中间那份文件跟着清干净。详见 PR #13594 

把这一轮收起来，后台跑完的结果跟着一起藏。 后台任务的产出卡片和完成通知一起收进折叠里。详见 PR #13825 

语音输入的提示有中文，出了错能关掉。 报错和「没听到声音」这类提示跟着界面语言显示；点提示右上角的关闭，麦克风回到待用，可以直接再试一次。详见 PR #13938 

要一份独立副本，选中 Worktree 就定了。 在 Git 对话框里点它，直接选定、菜单收起；等你发出第一句话，它才按建会话的流程起名字、建出那份副本，之前随时能改回去。详见 PR #13607 

图标统一到现行的品牌标。 换的地方包括 Web Shell 的浏览器标签小图、侧栏标志、浏览器通知图标，以及桌面版的启动图和应用图标。详见 PR #14052
