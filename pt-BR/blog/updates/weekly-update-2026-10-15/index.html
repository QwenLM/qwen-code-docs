Qwen Code Semanal: chame o Claude Code e o Codex para a conversa com um @, vários projetos Qwen Code ligados numa página só, um servidor MCP de fora ao iniciar

Qwen Team
2026-10-15

O Qwen Code lançou duas versões oficiais nesta semana, v0.25.1 e v0.25.2, com 371 PRs integrados.

Agent Collaboration: @ o Claude Code e o Codex na conversa como colegas. A resposta dele aparece direto na conversa em que você está, e dá para mandar o trabalho rodar em outro computador.

Vários Qwen Code abertos, todos conectados numa página só. Cada Qwen Code ocupa um grupo na barra lateral, e dentro de cada grupo estão as sessões e os workspaces reais dele naquele momento; você alterna entre eles sem sair da página.

Não quer um servidor MCP? Exclua ele ao iniciar. qwen --disable-mcp-server <nome> vale só para aquela execução e não mexe no seu arquivo de configuração.

✨ Novidades

Agent Collaboration: @ o Claude Code e o Codex na conversa como colegas

Dá para dividir uma tarefa em partes e tocar todas ao mesmo tempo — por exemplo, deixar ele mexer no código e chamar outro programa para revisar. Antes, quando você @ um Agent, ele abria uma conversa à parte, copiava as suas últimas frases para lá e ainda te levava para aquela página nova, e a conversa principal nunca recebia a resposta dele.

Agora, quando você @ ele, ele responde na própria conversa em que você está: com nome, em que passo está, quais ferramentas usou e quantos tokens gastou; se precisar rodar um comando, a aprovação continua aparecendo para você. Esse Agent não precisa ser o Qwen Code — se você tem o Claude Code ou o Codex instalado, também pode @ ele. Veja o PR #13467 

Ele também pode trabalhar em outro computador: deixe o serviço do Qwen Code rodando lá, adicione ele como colega e o trabalho pesado vai para aquela máquina; se ela reiniciar, a tarefa volta sozinha. Dá para @ um grupo inteiro: o líder divide o trabalho e distribui entre os membros, e cada membro devolve a ele quando termina. Veja o PR #13583 

A divisão em relação ao subagente é esta: o subagente ele mesmo despacha para resolver algo pequeno, e o subagente só presta conta a ele; quem entra pelo @ fala na sua frente, pode ser um programa de outro fornecedor e pode rodar em outra máquina.

Isso ainda está em fase experimental e desligado por padrão: ative Enable Agent Collaboration nas configurações e reinicie. O colega precisa ser criado antes: crie um na página Agents, à esquerda. Depois é só @ o nome dele em qualquer conversa para chamá-lo.

Na prática:

  • Enquanto ele mexe no código, você @ outro Agent para revisar — as duas linhas ficam claras na mesma conversa
  • Mande o trabalho pesado, como compilar e rodar testes, para outra máquina e continue do seu lado
  • Monte um grupo com programas de fornecedores diferentes, cada um na parte em que é bom

Vários Qwen Code abertos, todos conectados numa página só

Tem gente com um notebook à mão, uma máquina só para compilar e outra segurando uma tarefa longa. Tem também quem use uma máquina só e abra um Qwen Code Web Shell por projeto, sem querer misturar as coisas. Antes, uma página do navegador reconhecia apenas um deles. Para ver outro, era recarregar a página inteira: um flash no meio e o que você estava escrevendo ali se perdia.

Agora todos os que você salvou ficam conectados ao mesmo tempo. Cada Qwen Code ocupa um grupo na barra lateral, e dentro do grupo aparecem as sessões e os workspaces dele naquele momento; quando você escolhe o workspace na caixa de entrada, as pastas também ficam separadas por grupo; trocar de grupo acontece dentro da própria página. Veja os PRs #13739 , #13677 

Para usar, a máquina conectada precisa liberar a sua página: inicie o qwen serve com --allow-origin e informe o endereço da página que aparece na barra do navegador.

Na prática:

  • A máquina de compilação está com uma tarefa longa: acompanhe do seu computador até onde ela chegou
  • Abra um por projeto na mesma máquina: nada se mistura e você vê tudo numa página só
  • Troque do notebook para o desktop e continue distribuindo o trabalho

Não quer um servidor MCP? Exclua ele ao iniciar

Quem usa servidor MCP já passou por isso: um deles dá problema no dia, as ferramentas dão erro ou a inicialização fica lenta, e você só queria não carregar ele desta vez. Antes existia só o tudo-ou-nada: desligar os servidores vindos das configurações junto com a configuração local.

Agora você chama pelo nome na hora de iniciar:

qwen --disable-mcp-server github

Para excluir vários de uma vez, repita o parâmetro ou escreva --disable-mcp-server github,postgres. Vale só para aquela inicialização; o seu arquivo de configuração fica intacto. Veja o PR #14003 

Na prática:

  • Suspeita de um servidor: exclua ele e rode uma vez para ver se é ele mesmo
  • A inicialização está lenta por causa de um servidor: não carregue ele desta vez
  • No mesmo código, uma rodada só de banco de dados e outra só de web, cada uma com os seus servidores

Web Shell: os arquivos do projeto abrem com um clique, a mensagem extra entra na hora e ele avisa quando precisa do seu OK

Os arquivos do projeto ficam no painel direito. A árvore de diretórios do workspace inteiro aparece ali; clique em um arquivo e o conteúdo abre ao lado: Markdown, página web, imagem e Excel abrem direto. Dá também para copiar o caminho, baixar e referenciar. Veja os PRs #13878 , #13664 

Arraste um arquivo local para fazer o upload. Ele vai para a pasta onde você soltou, e no desktop funciona igual. Veja os PRs #14145 , #14053 

Mensagem na fila pode entrar na hora, e cancelar devolve ela para a caixa de entrada. O que você envia enquanto ele está respondendo fica na fila. Clique em Send now para ela entrar imediatamente. Se você parar antes de a IA produzir saída, a frase volta para a caixa de entrada: edite e reenvie. Veja os PRs #13681 , #13488 

Ele manda notificação quando para esperando você. São dois casos: liberar uma operação ou responder à pergunta que ele fez. Antes, nenhum dos dois dava sinal; agora, se a página estiver em segundo plano, aparece uma notificação e um clique te leva de volta àquela sessão. Veja o PR #13832 

Quando há um subagente ou uma tarefa em segundo plano rodando, o ícone de lista no topo do chat ganha um ponto piscando. Você vê sem abrir o painel. Veja o PR #14048 

📊 Mais funcionalidades

Muitas buscas seguidas sem te dar resultado viram um lembrete para concluir. Quando as ações somente leitura — ler arquivo, buscar código — chegam a certa quantidade, ele recebe um aviso na rodada seguinte: use o que já encontrou, avance no que você pediu ou diga onde travou; se o objetivo era mesmo entender a situação, entregue a conclusão e as perguntas que ainda não têm resposta. Veja o PR #13601 

Interface de servidor MCP precisa do seu OK antes de enviar mensagem. Alguns servidores MCP não trazem só ferramentas: mostram uma interface clicável dentro da conversa. Quando essa interface quer enviar uma frase por você, o Qwen Code apresenta primeiro o conteúdo inteiro, de onde ele vem e em qual conversa vai cair. Só sai depois do seu clique em confirmar. Veja o PR #13958 

Clique no nó de um agent do workflow e veja o que ele fez. Na conversa, na página Tasks ou na página do workflow, clicar em um agent abre no painel direito o histórico daquela execução: o prompt que ele recebeu, quais ferramentas rodou, o que está saindo agora e em que passo está. Veja o PR #14175 

A checagem antes da ação pode trocar os parâmetros daquela execução. O hook que você definiu nas configurações é esse tipo de checagem: roda antes de ele usar determinada ferramenta. Os parâmetros novos que ela devolve são revalidados e passam de novo por permissão e confirmação antes de qualquer execução de fato. Veja o PR #13442 

A pergunta lateral pode ir para outro workspace. Com a tarefa principal respondendo, /btw side cria uma conversa à parte em outro workspace ao qual ela pertence, sem misturar com a tarefa principal. Veja o PR #13468 

Comando embutido em plugin no formato Claude agora roda de verdade. Esse tipo de comando é código, não prompt para o modelo: antes, digitá-lo era o mesmo que falar uma frase com o modelo; agora o plugin executa localmente e devolve o resultado direto, sem gastar token. Exige experimental.mods ligado nas configurações e um workspace confiável, e só funciona no uso de execução única qwen -p '…' — a interface interativa e o Web Shell ainda não suportam. Só parte da interface Mod foi implementada, então não dá para garantir que todo comando pronto funcione. Veja os PRs #13843 , #13890 , #13915 , #13950 

👏 Melhorias de experiência

Na página de nova tarefa, arquivos, terminal e prévia web do painel direito já funcionam antes de você enviar qualquer coisa. O topo virou uma barra de ferramentas enxuta; cada workspace guarda o próprio layout, que sobrevive a recarregar a página e a trocar de sessão. Quando você envia a primeira frase, abas, ordem, largura dos painéis e tela cheia vão junto para a sessão que acabou de nascer. Veja o PR #14159 

A aba Trajectory busca, filtra e carrega registros mais antigos. Busque pelo nome de uma ferramenta, pelo nome de um modelo ou por um trecho do histórico e ela salta para lá; dá para ver só um tipo de registro, ou só os que falharam e os que deram certo. O histórico anterior vem em lotes, e ao terminá-los você volta para a parte mais recente — busca e estatísticas contam só o lote carregado. Se a conexão cair e voltar no meio, você mantém onde estava, a entrada selecionada, o filtro e a posição de rolagem. Veja os PRs #13264 , #13716 , #13952 

Selecione um trecho da resposta e escolha como copiar. Passe o mouse sobre um trecho e o menu oferece duas opções: texto puro ou Markdown com a formatação original — títulos, listas, código e tabelas vêm junto. Veja o PR #13833 

O uso de contexto abre no painel direito em vez de empilhar cartão na conversa. Antes, clicar no anel da caixa de entrada deixava um cartão Context Usage na conversa, e os detalhes dele deixavam outro; agora os dois abrem no painel direito, um por sessão. Se quiser o cartão dentro da conversa, digite /context. Veja o PR #14086 

Tabela grande pode ocupar a tela inteira. Clique em Fullscreen na tabela para ela cobrir a janela toda; saia com Esc ou pelo botão de sair. A ordenação, o filtro, as colunas e a linha em que você estava ficam como estavam. Veja o PR #13589 

Dá para apagar uma mensagem da fila antes dela sair. Vale também para a que está no meio do upload de um anexo: o arquivo temporário é limpo junto. Veja o PR #13594 

Dobrar a rodada esconde também o que terminou em segundo plano. Os cartões de resultado e os avisos de conclusão das tarefas em segundo plano entram na dobra junto. Veja o PR #13825 

Os avisos da entrada de voz agora saem em chinês, e o erro pode ser fechado. Avisos de erro e de “não ouvi voz nenhuma” seguem o idioma da interface; clique em fechar no canto superior direito e o microfone volta a ficar pronto — é só tentar de novo. Veja o PR #13938 

Quer uma cópia de trabalho independente: basta escolher Worktree. Clique nele no diálogo do Git e a escolha é confirmada na hora, com o menu fechando. A cópia só é nomeada e criada no fluxo de abertura de sessão quando você envia a primeira frase; antes disso, dá para voltar atrás a qualquer momento. Veja o PR #13607 

Todos os ícones foram unificados na marca atual. Entram nessa troca o ícone da aba do navegador no Web Shell, o logotipo da barra lateral, o ícone das notificações do navegador, a tela de inicialização e os ícones do aplicativo no desktop. Veja o PR #14052

Agora voltou a navegar o histórico, e quem quiser que as setas rolem a tela encontra essa opção nas configurações#14016

Agora a busca para cima para na raiz do Git, e as instruções aninhadas dentro do repositório continuam carregando#13381

No Windows, o hook não minimiza mais o seu terminalComandos escritos no estilo de gestão corporativa encolhiam a janela do terminal inteira, uma vez a cada chamada de ferramenta, e em máquina gerenciada não dava para desfazer. Agora o hook roda na sua própria janela invisível#13670 
Com modelo local, estourar o contexto comprime antes de continuarQuando o prompt passava do limite real de contexto do serviço llama.cpp local, a sessão ficava presa no mesmo erro sem saída. Agora ele reconhece essa mensagem e calcula quanto comprimir usando o limite que o serviço devolve#13421 , #13788
