# Visual Studio Code

> VS Code 확장 프로그램(Beta)을 사용하면 IDE에 직접 통합된 네이티브 그래픽 인터페이스를 통해 Qwen의 변경 사항을 실시간으로 확인할 수 있어 Qwen Code에 더 쉽게 접근하고 상호작용할 수 있습니다.

### 기능

- **네이티브 IDE 경험**: Qwen 아이콘을 통해 접근하는 전용 Qwen Code 사이드바 패널
- **자동 편집 수락 모드**: Qwen의 변경 사항이 만들어지는 대로 자동으로 적용
- **파일 관리**: 파일을 @로 언급하거나 시스템 파일 선택기를 사용해 파일과 이미지 첨부
- **대화 기록**: 과거 대화 접근
- **다중 세션**: 여러 Qwen Code 세션을 동시에 실행

### 요구 사항

- VS Code 1.96.0 이상

### 설치

[Visual Studio Code Extension Marketplace](https://marketplace.visualstudio.com/items?itemName=qwenlm.qwen-code-vscode-ide-companion)에서 확장 프로그램을 다운로드하고 설치하세요.

## 문제 해결

### 확장 프로그램이 설치되지 않음

- VS Code 1.96.0 이상이 있는지 확인하세요
- VS Code에 확장 프로그램 설치 권한이 있는지 확인하세요
- Marketplace 웹사이트에서 직접 설치를 시도해 보세요

### Qwen Code가 응답하지 않음

- 인터넷 연결을 확인하세요
- 새 대화를 시작하여 문제가 지속되는지 확인하세요
- 문제가 계속되면 [GitHub에 이슈를 등록하세요](https://github.com/qwenlm/qwen-code/issues)
