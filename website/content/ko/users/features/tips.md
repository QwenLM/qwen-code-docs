# 상황별 팁

Qwen Code는 기능을 발견하고 세션 상태를 인지할 수 있도록 돕는 상황별 팁 시스템을 포함합니다.

## 시작 팁

Qwen Code를 실행할 때마다 헤터 영역에 팁이 표시됩니다. 팁은 우선순위별로 선택된 후, 같은 우선순위의 팁 사이에서 LRU(최소 최근 사용) 스케줄링을 통해 세션 간에 순환되므로 매번 다른 팁을 보게 됩니다.

신규 사용자는 처음 세션 동안 온보킹 중심 팁을 보게 됩니다:

| 세션 수 | 예시 팁                                              |
| ------- | ---------------------------------------------------- |
| < 5     | 슬래시 명령어 (`/`), Tab 자동 완성                   |
| < 10    | `QWEN.md` 프로젝트 컨텍스트, `--continue` / `--resume` |
| < 15    | `!` 접두사가 있는 셸 명령어                          |

그 후에는 `/compress`, `/approval-mode`, `/insight`, `/btw` 등의 일반 기능을 순환합니다.

## 응답 후 팁

대화 중에 Qwen Code는 컨텍스트 창 사용량을 모니터링하고 조치가 필요할 수 있을 때 팁을 표시합니다:

| 컨텍스트 사용량 | 조건                         | 팁                                                     |
| --------------- | ---------------------------- | ------------------------------------------------------ |
| 50-80%          | 세션 중 몇 번의 프롬프트 후  | 컨텍스트를 확보하기 위해 `/compress`를 제안            |
| 80-95%          | —                            | 컨텍스트가 가득 차고 있다는 경고                       |
| >= 95%          | —                            | 긴급: 지금 `/compress`를 실행하거나 `/new`로 계속      |

응답 후 팁은 반복을 피하기 위해 팁별 쿨다운이 있습니다.

## 팁 기록

팁 표시 기록은 `~/.qwen/tip_history.json`에 저장됩니다. 이 파일은 다음을 추적합니다:

- 세션 수 (신규 사용자 팁 선택에 사용)
- 어떤 팁이 언제 표시되었는지 (LRU 순환 및 쿨다운에 사용)

이 파일을 안전하게 삭제하여 팁 기록을 초기화할 수 있습니다.

## 팁 비활성화

모든 팁(시작 및 응답 후 모두)을 숨기려면 `~/.qwen/settings.json`에서 `ui.hideTips`를 `true`로 설정하세요:

```json
{
  "ui": {
    "hideTips": true
  }
}
```

`/settings` 명령어를 통해 설정 대화상자에서 토글할 수도 있습니다.

팁은 화면 읽기 모드가 활성화될 때도 자동으로 숨겨집니다.
