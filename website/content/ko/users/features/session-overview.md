# 세션 개요

Web Shell의 세션 개요를 사용하여 세션을 탐색하고, 대화로 돌아가고,
세션 제목과 아카이브를 관리하세요.

## 세션 찾기 및 열기

**더보기 → 세션 개요**를 엽니다. 세션 제목, 세션 ID, Git 브랜치,
또는 `#123`과 같은 연결된 풀 리퀘스트 번호로 검색합니다. 상태 필터를 사용하여
목록을 좁힙니다. 여러 워크스페이스를 사용할 수 있는 경우, 워크스페이스 필터를 통해
포함할 워크스페이스를 선택할 수 있습니다. **새로고침**을 선택하여 카탈로그를 다시 로드합니다.

세션 행을 클릭하여 해당 대화를 엽니다. 행 체크박스를 사용하여
푸터 작업을 위해 세션을 선택합니다. 페이지네이션 컨트롤은 표시되는 페이지와
행 수를 변경합니다.

## 세션 이름 변경

사용 가능한 경우 행의 연필 작업을 선택한 다음 제목을 편집합니다.
**Enter**를 눌러 저장하거나 **Escape**를 눌러 취소합니다. 편집기가 포커스를 잃으면,
완료되지 않은 이름 변경은 저장되지 않고 취소됩니다.

## 세션 아카이브

행 체크박스로 세션을 선택한 다음 푸터에서 **아카이브**를 선택합니다.
이 작업은 선택한 모든 세션이 유휴 상태이고 아카이브를 지원하는 경우에만 활성화됩니다.
대화상자에서 아카이브를 확인하거나, **취소**를 선택하여 세션을 활성 상태로 유지합니다.

이름 변경 편집기가 여전히 포커스를 가진 상태에서 **아카이브**를 클릭하면, 완료되지 않은
초안이 취소되고 아카이브 확인이 열립니다. 이름 변경을 입력하거나 취소해도
푸터 컨트롤이 제자리에 유지되므로, 버튼 가장자리 근처의 클릭도
해당 버튼에 도달합니다.
