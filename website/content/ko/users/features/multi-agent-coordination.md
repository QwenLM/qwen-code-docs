# 멀티 에이전트 조율

Qwen Code는 실험적인 Agent Team 런타임으로 여러 팀원을 조율할 수 있습니다. 팀원은 별도의 작업을 할당받고, 작업 목록을 공유하며, 메시지를 교환하고, 기존 Agent View 탭에 표시됩니다. `/coordinate`는 조사 워커를 읽기 전용 도구 집합으로 제한하며, 리더 소유의 Git worktree에 한 명의 작성자를 배치할 수 있습니다.

## Agent Team 활성화

Qwen Code 설정에서 `experimental.agentTeam`을 `true`로 설정하고 재시작하거나, `QWEN_CODE_ENABLE_AGENT_TEAM=1`로 Qwen Code를 시작하세요.

## 조율된 작업 실행

목표와 함께 번들 skill을 사용하세요:

```text
/coordinate investigate the authentication regression and propose the smallest fix
```

리더가 팀을 생성하고, 최대 3개의 독립적인 작업 스트림을 할당하며, 기존 팀 도구를 사용하여 메시지와 작업 상태를 관리합니다. 팀원의 대화와 승인은 기존 Agent View UI를 통해 계속 표시됩니다. 읽기 전용 팀원은 shell 명령어를 실행하거나 파일을 작성할 수 없습니다. 구현이 필요한 경우, 리더는 하나의 Git worktree를 생성하고 한 명의 작성자 팀원을 그곳에 고정할 수 있습니다. 리더가 현재 브랜치의 유일한 병합 권한을 유지합니다.

Agent Team이 비활성화된 경우에도 `/coordinate`는 일반 포그라운드 에이전트를 사용하여 읽기 전용 병렬 조사를 수행할 수 있습니다. 이 폴백은 위임이며, 협업 팀이 아닙니다. 워커는 리더에게만 보고합니다.

## 올바른 멀티 에이전트 모드 선택

| 모드                          | 사용 목적                                                     | 통신                               | 작업 공간 동작                                            |
| ----------------------------- | ------------------------------------------------------------- | ---------------------------------- | --------------------------------------------------------- |
| `/coordinate` + Agent Team    | 하나의 결과에 기여하는 서로 다른 작업 스트림                  | 공유 작업 및 팀원 메시지           | 읽기 전용 워커 제한; 선택적 단일 worktree 작성자          |
| 서브에이전트                  | 소규모 위임 작업                                              | 워커가 부모에게 보고               | 선택된 에이전트에 따라 다름                               |
| Arena                         | 동일한 작업에서 경쟁하는 여러 모델                            | 에이전트가 협업하지 않음           | 격리된 worktree; 하나의 승자가 선택됨                     |
| Herdr                         | 서로 다른 CLI 제품 또는 원격 터미널 세션 조율                 | 외부 터미널 수준 제어              | Qwen Code 외부에서 관리                                   |

현재 워크플로는 인메모리 Agent Team 런타임과 Agent View UI를 의도적으로 재사용합니다. 팀원은 일반적으로 세션 모델을 상속하지만, 에이전트 정의에서 재정의할 수 있습니다. 영구적인 독립 PTY 세션, 크로스 벤더 워커, 원격 연결은 별도의 제품 관심사이며 `/coordinate`에서 구현되지 않습니다.
