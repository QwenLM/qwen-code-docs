# Qwen Code 키보드 단축키

이 문서는 Qwen Code에서 사용 가능한 키보드 단축키를 나열합니다.

## 일반

| 단축키                         | 설명                                                                                                                                                                                                                                          |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                          | 대화 상자와 제안을 닫습니다. 빈 프롬프트에서 진행 중인 요청을 취소합니다. IDE 모드 외부에서 유휴 상태일 때 두 번 누르면 되감기 선택기가 열립니다.                                                                                              |
| `Ctrl+C`                       | 진행 중인 요청을 취소하고 입력을 지웁니다. 두 번 누르면 애플리케이션이 종료됩니다.                                                                                                                                                            |
| `Ctrl+D`                       | 입력이 비어 있을 때 애플리케이션을 종료합니다. 두 번 눌러 확인합니다.                                                                                                                                                                          |
| `Ctrl+L`                       | 화면을 지웁니다.                                                                                                                                                                                                                              |
| `Ctrl+O` / `Alt/Option+T`      | 확장 세부 모드 전환: 모든 사고 블록과 도구 출력을 인라인으로 확장하거나 접습니다. 다시 누르면 접힙니다. `ui.useTerminalBuffer`가 꺼져 있으면, 토글 시 전체 대화를 자르지 않은 출력으로 다시 그려 터미널 스크롤백에 표시합니다.              |
| `Ctrl+S`                       | 현재 프로젝트의 비어 있지 않은 입력을 저장하고 다음 시작 시 복원합니다. 빈 입력에서는 긴 응답이 완전히 인쇄되도록 하여 잘라내기를 비활성화합니다. 터미널의 스크롤백을 사용하여 전체 출력을 확인하세요.                                         |
| `Ctrl+T`                       | 도구 설명 표시를 토글합니다.                                                                                                                                                                                                                  |
| `Alt/Option+M`                 | Markdown 출력을 렌더링된 미리보기와 원본/소스 모드 간에 전환합니다. macOS에서는 터미널이 Option을 Meta로 전송해야 합니다.                                                                                                                      |
| `Shift+Tab` (Windows: `Tab`)   | 승인 모드를 순환합니다 (`plan` → `default` → `auto-edit` → `auto` → `yolo`)                                                                                                                                                                   |

## 포그라운드 셸

이 단축키는 대화형 포그라운드 셸 명령이 실행 중인 동안 적용됩니다.

| 단축키                              | 설명                                                                                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl+F`                            | 셸과 프롬프트 간에 키보드 포커스를 토글합니다. 셸이 실행 중이 아닐 때 `Ctrl+F`는 프롬프트 커서를 오른쪽으로 이동합니다.                                    |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | 포커스된 셸을 위 또는 아래로 스크롤합니다.                                                                                                               |
| `Ctrl+B`                            | 셸을 백그라운드 작업으로 승격합니다. 자식 프로세스는 계속 실행되고, 에이전트의 턴이 차단 해제되며, 셸이 `/tasks` 및 백그라운드 작업 대화 상자에 표시됩니다. |

## 제안

| 단축키                               | 설명                                                   |
| ------------------------------------ | ------------------------------------------------------ |
| `Down Arrow` / `Ctrl+N`              | 제안 목록을 아래로 탐색합니다.                          |
| `Tab` / `Enter`                      | 선택된 제안을 수락합니다.                               |
| `Up Arrow` / `Ctrl+P`                | 제안 목록을 위로 탐색합니다.                            |
| `Right Arrow`                        | 프롬프트가 비어 있을 때 고스트 텍스트 제안을 수락합니다. |
| `Ctrl+Tab` / `Ctrl+Right Arrow`      | 카테고리 탭이 표시될 때 다음 완성 카테고리로 전환합니다. |
| `Ctrl+Shift+Tab` / `Ctrl+Left Arrow` | 카테고리 탭이 표시될 때 이전 완성 카테고리로 전환합니다. |

## 기록 검색

`Ctrl+R`을 눌러 프롬프트 기록을 검색하거나, 셸 모드가 활성화된 동안 셸 기록을 검색합니다.

| 단축키                     | 설명                                                |
| -------------------------- | --------------------------------------------------- |
| `Up Arrow` / `Down Arrow`  | 일치하는 기록 항목을 탐색합니다.                     |
| `Left Arrow` / `Right Arrow` | 긴 선택 항목을 접거나 확장합니다.                  |
| `Tab`                      | 선택된 항목을 제출 없이 프롬프트에 수락합니다.        |
| `Enter`                    | 선택된 항목을 제출합니다.                            |
| `Esc`                      | 기록 검색을 닫습니다.                                |

| ----------------------------- | ------------------------------------------------------------------------------------------------------- |

## 기록 스크롤백

`ui.useTerminalBuffer`가 활성화되어 있고(Settings → UI → Virtualized History), 스크린 리더 모드가 꺼져 있으며, Qwen Code가 호환되는 대화형 터미널에서 실행 중일 때 활성 상태입니다(`stdout`이 TTY이고, CI가 비활성 상태이며, `TERM`이 `dumb`이 아닌 경우). 이는 일반적인 비스크린 리더 세션의 기본값입니다. 이 모드에서 대화 기록은 호스트 터미널 스크롤백 대신 앱 내 뷰포트 내에 렌더링되므로 아래 키가 터미널의 네이티브 스크롤을 대체합니다.

| 단축키            | 설명                                                                     |
| ----------------- | ------------------------------------------------------------------------ |
| `Shift+Up`        | 기록을 한 줄 위로 스크롤합니다.                                          |
| `Shift+Down`      | 기록을 한 줄 아래로 스크롤합니다.                                        |
| `PgUp`            | 기록을 한 페이지(뷰포트 높이) 위로 스크롤합니다.                          |
| `PgDn`            | 기록을 한 페이지(뷰포트 높이) 아래로 스크롤합니다.                        |
| `Ctrl+Home`       | 대화의 맨 위로 이동합니다.                                               |
| `Ctrl+End`        | 맨 아래로 이동합니다(실시간 자동 따라가기 재활성화).                       |
| **마우스 휠**     | 기록을 스크롤합니다(틱당 3줄). `ui.mouseTracking` 필요(기본적으로 활성화). |

`ui.useTerminalBuffer`가 켜져 있고 `ui.mouseTracking`이 활성화되어 있을 때(기본값), 터미널은 마우스 이벤트를 qwen-code로 전달하여 휠이 앱 내 뷰포트를 구동할 수 있습니다. 부수적 효과로 네이티브 클릭-and-드래그 텍스트 선택이 프로그램에 의해 소비되므로 qwen-code는 자체 선택을 제공합니다: **기록 뷰포트에서 드래그하여 텍스트 선택, 더블클릭하여 단어 선택, 트리플클릭하여 줄 선택.** 선택 영역이 강조 표시되고 마우스를 놓을 때 클립보드에 복사됩니다(로컬, SSH를 통한 OSC 52, tmux 내부에서 작동). 단일 클릭은 선택을 지웁니다. 스크롤이나 새 출력도 선택을 지웁니다. 선택은 현재 보이는 뷰포트로 제한됩니다. `Shift`(또는 macOS Terminal / iTerm에서 `Option`)를 누른 채 드래그하면 터미널 자체의 선택으로 돌아갈 수 있습니다. `ui.mouseTracking`을 `false`로 설정하면 qwen-code가 마우스를 완전히 캡처하지 않습니다. 터미널의 네이티브 오른쪽 클릭 메뉴, OSC 8 하이퍼링크 클릭 및 클릭-and-드래그 선택이 복원되지만 앱 내 뷰포트는 더 이상 마우스에 응답하지 않으므로 위 키보드 단축키를 사용하여 스크롤하세요.

### tmux 트랙패드 스크롤링

tmux 내부에서 일부 터미널은 트랙패드나 휠 제스처를 qwen-code가 받기 전에 단순한 `Up Arrow` 및 `Down Arrow` 시퀀스로 변환합니다. 이러한 바이트는 실제 방향키 누름과 구별할 수 없으므로 qwen-code는 뷰포트를 스크롤하려 했는지 프롬프트 기록을 탐색하려 했는지 알 수 없습니다.

tmux에서 트랙패드 스크롤링이 프롬프트 기록을 변경하면 `ui.useTerminalBuffer`가 활성화되어 있는지 확인한 후 `Shift+Up` / `Shift+Down`을 사용하거나 tmux가 휠 이벤트를 앱으로 전달할 때 마우스 휠을 사용하세요(`ui.mouseTracking` 필요). 호스트 스크롤백을 선호하는 경우 휠 이벤트에 대한 tmux 마우스 바인딩을 조정하세요.
