# Qwen Code 문서

Qwen Code 문서에 오신 것을 환영합니다. Qwen Code는 터미널에서 작동하는 에이전트 기반 코딩 도구로, 아이디어를 코드보다 빠르게 구현할 수 있도록 도와줍니다.

## 문서 섹션

### [사용자 가이드](./users/overview)

Qwen Code를 최종 사용자로 사용하는 방법을 배웁니다. 이 섹션에서는 다음을 다룹니다:

- 기본 설치 및 설정
- 일반적인 사용 패턴
- 기능 및 역량
- 구성 옵션
- 문제 해결

### [개발자 가이드](./developers/architecture)

Qwen Code에 기여하고 개발하는 방법을 배웁니다. 이 섹션에서는 다음을 다룹니다:

- 아키텍처 개요
- 기여 가이드라인
- 핵심 개념 및 구현 세부 정보
- 도구 및 개발 워크플로우
- 확장 및 플러그인 개발
