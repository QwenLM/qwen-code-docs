기말 과제는 프로젝트 시연이 필수인데, CSS 만지다 머리 빠질 지경이신가요? 수업 프로젝트 시연 영상을 새벽 3시까지 편집하고 계신가요? 오픈소스에 참여하고 싶은데 첫 PR은 어떻게 내는지 모르겠나요?

얼마 전 Qwen Code를 써 봤습니다. 솔직히 큰 기대는 없었어요 — 'AI 프로그래밍'이라는 말은 이미 닳았으니까요. 그런데 직접 쓰 보니 'AI가 세상을 바꾼다'는 헛말이 아니라, 시간을 실제로 벌어 주고 더 값어치 있는 일에 힘을 쓰게 해 주는 도구였습니다.

가장 간단한 예부터 시작해 볼게요.

## 5분 만에 개인 포트폴리오 사이트

취업할 때 포트폴리오 보여 줄 이력서 페이지가 필요한데, 템플릿 사이트에서 이리저리 고치고 계신가요? 그냥 AI에게 만들게 하세요.

저는 Qwen Code에서 `@` 명령으로 제 이력서를 참조시키고, 애니메이션 깔끔하게 들어간 개인 사이트를 만들게 했습니다(시연용으로 만든 것이고, 진짜 꽤 예쁩니다). prompt는 한 문장입니다:

```
/skills react-native-design build a personal resume website based on @resume-website/resume.md
```

과정은 간단합니다:

1. Qwen Code에서 `/extensions`로 웹 디자인 플러그인을 설치합니다(마켓에 있는 확장 저장소는 대부분 지원합니다)
2. 마음에 드는 웹 페이지 스크린샷을 로컬에 저장합니다
3. prompt를 입력해 레이아웃, 스타일, 컴포넌트를 인식시키고 실행 가능한 코드로 복원하게 합니다

prompt는 여전히 한 문장입니다:

```

```

## 첫 PR부터 시작하는 오픈소스 참여

오픈소스에 참여하고 싶은데 어디서 시작할지 모르겠다면? Qwen Code가 전체 과정을 자동화해 줍니다.

Issue 링크 하나 던져 주세요. 그러면:

1. 문제 설명을 알아서 이해하고
2. 저장소 구조를 탐색하고
3. 버그 위치를 짚고
4. 수정 코드를 내고
5. PR까지 자율적으로 올립니다

<video class="mt-5" src="https://cloud.video.taobao.com/vod/JV-7WNvq-GF9ZRHhrr1igplZDtHaFeNNoJ412hgkKYI.mp4" controls></video>

사람 손이 하나도 안 갑니다. 물론 처음에는 코드를 직접 review해 보시는 걸 권합니다. 과정을 익힌 뒤 맡기셔도 늦지 않아요. (어떻게 아냐고요? 묻지 마세요)

오픈소스 경력을 쌓고 싶은 분들께 특히 유용합니다. 간단한 bug fix부터 시작해 점점 복잡한 기능 개발로 옮겨 가시면 돼요.

(컴퓨터공학 전공자들은 정말 한 번 해 보세요. 오픈소스 경력은 취업할 때 실제로 도움 됩니다)

## 코드로 시연 영상 만들기, 편집 프로그램은 그만

수업 발표, 프로젝트 심사, 대회 피칭 — 전에 참여했던 오픈소스 프로젝트까지 — 시연 영상은 늘 따라붙습니다. 그런데 Premiere 배우고 영상 편집하는 데 시간이 너무 오래 걸리죠. (편집해 본 사람만 압니다)

Qwen Code는 Remotion(React로 영상을 만드는 라이브러리) 위에 있어서, 코드로 전문적인 시연 영상을 만들 수 있습니다.

제품 소개 영상을 만들어 볼까요:

1. Remotion 관련 스킬 설치
2. 대본과 스토리보드 설명 작성
3. 영상 코드 생성
4. 렌더링해 출력

<video class="mt-5" src="https://cloud.video.taobao.com/vod/ZgaPle1nAI5-130zVv4yObnskE3ByRJYnlWABtfZwH4.mp4" controls></video>

**맞는 상황:**

- 수업 프로젝트 발표 영상
- 창업 대회 피칭
- 동아리 행사 홍보
- 개인 Vlog 자동 생성

Remotion의 강점은 React 컴포넌트 방식으로 영상을 만든다는 점입니다. 애니메이션, 전환, 자막, 오디오 편집을 지원하고 버전 관리까지 됩니다(맞습니다, 영상도 Git으로 관리할 수 있습니다. 이거 진짜 멋져요).

## 어떻게 시작하나요?

1. Model Studio 콘솔에서 API Key 발급
2. Qwen Code를 다운로드하고 `qwen`으로 실행

```bash
# Linux/macOS
curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh | bash

# Windows
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat
```

3. `/auth`를 입력하고 'Alibaba Cloud Coding Plan'을 선택한 뒤 API Key를 붙여넣기
4. `/model`로 모델을 고르고, 시작!

Qwen Code에는 스킬 마켓이 있습니다(VS Code 플러그인 마켓과 비슷해요). 바로 쓸 수 있는 스킬 팩이 잔뜩 있고, `/extensions` 명령으로 설치할 확장을 고를 수 있습니다. 더 많은 플러그인과 스킬을 둘러보셔도 좋아요.

처음부터 큰 프로젝트를 노리지 마세요. 간단한 상황에서 시작하시면 됩니다:

- AI에게 Hello World 웹 페이지 하나 쓰게 하기
- 이해 안 되는 코드 설명해 달리기
- 수업 노트 템플릿 만들어 달리기

익숙해지면 점점 복잡한 과제로 옮겨 가세요. (저도 그렇게 시작했습니다ㅎㅎ)

## 대학생을 위한 스킬 팩 추천

제 사용 경험상, 아래 스킬 팩은 대학생에게 특히 유용합니다:

| 스킬 팩                       | 용도                | 맞는 전공       |
| ------------------------- | ----------------- | ---------- |
| `skill-creator`           | 표준에 맞춰 스킬을 만들고, 나만의 스킬 만들기 | 전체 전공       |
| `find-skills`             | 새로운 스킬 찾고 설치하기          | 전체 전공       |
| `react-native-design`     | React 웹 페이지 빠르게 생성     | 컴퓨터공학, 디자인, 뉴미디어 |
| `web-component-design`    | 스크린샷으로 웹 페이지 복제          | 전체 전공       |
| `remotion-best-practices` | 코드로 영상 생성           | 언론, 커뮤니케이션, 컴퓨터공학  |

설치 방법:

```bash
npx skills add <스킬 팩 이름> -g
```

## 사용 제안 몇 가지

1. **AI에만 맡기지 마세요.** 도구이지 대체재가 아닙니다. 코드는 직접 이해하고, 과제는 직접 이해해야 합니다.
2. **흉내에서 시작하세요.** 누가 특정 스킬로 좋은 결과물을 만드는 걸 보면, 그 prompt를 먼저 흉내 내고 차츰 자기 스타일로 바꾸세요.
3. **스킬 마켓을 잘 쓰세요.** 떠오르는 요구의 상당수는 이미 누군가 스킬 팩으로 만들어 뒀습니다. 먼저 검색하고 쓰세요. 바퀴를 다시 발명할 필요 없습니다.
4. **prompt를 기록하세요.** 잘 먹히는 prompt는 적어 두면 다음에 그대로 쓰거나 살짝 고쳐 쓸 수 있습니다.
5. **작품을 나누세요.** 좋은 게 나왔다면 GitHub, 즈후, 샤오홍슈에 올려 보세요. 작품도 쌓이고 같은 관심사의 사람도 만날 수 있습니다.

## 마치며

AI 코딩 도구는 당신을 대체하려는 게 아니라, 더 값어치 있는 일에 시간을 쓰게 도와주는 것입니다.

CSS 만지다 머리 빠질 시간은 논문 몇 편 더 읽는 데 쓰면 됩니다. 새벽까지 영상 편집하는 시간은 면접 준비에 쓰고, 환경 설정에 하루를 쏟는 시간은 핵심 알고리즘 공부에 쓸 수 있어요.

도구는 거기 있습니다. 쓸지는 본인이 정할 일입니다. 적어도 지금은, 선택지가 하나 더 늘었습니다.
