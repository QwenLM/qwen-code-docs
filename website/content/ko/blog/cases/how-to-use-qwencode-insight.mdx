> Qwen Code 새 기능 Insight 사용기. 데이터로 보여주는 '나는 AI를 이렇게 쓰고 있었다', 그리고 AI가 알려 주는 '더 잘 쓰는 법'.

![](https://gw.alicdn.com/imgextra/i1/O1CN01ztrQcd1aEzkPLMKqf_!!6000000003299-2-tps-2400-1374.png)

최근 Qwen Code에 새 기능이 하나 붙었습니다 — **Insight**입니다.

며칠 써 보고 나서 든 생각은 하나였습니다. **AI가 나보다 나를 더 아는 것 같습니다.**

저는 AI와 꽤 잘 맞춘다고 생각했어요. 그런데 Insight가 제가 '그래 왔던 불편'을 전부 표면 위로 끌어냈습니다. 더 놀라운 건—**AI가 AI를 더 잘 쓰는 법을 가르쳐 줬다**는 점입니다. "당신이 뭘 했다"는 것만 알려 주는 게 아니라, "어떻게 하면 더 나아진다"는 것까지 말해 줍니다.

이건 딱 **제때 복기해 주는 맞춤 과외 선생님** 아닌가요?

## 왜 'AI 사용 복기'가 필요할까요?

복기의 가치는 다 압니다. 되돌아보고, 반성하고, 고치는 것요. 그런데 솔직히, **자기가 'AI를 어떻게 쓰는지'까지 복기하는 사람이 몇이나 될까요?**

대부분(저 포함)은 이렇습니다: **문제 생기면 AI에게 묻고, 답 나오면 쓰고, 버그 나면 한 번 더 묻기**. 하루하루 그러다 보니 잘 쓰고 있다고 착각하는데, 사실은 같은 비효율을 반복하고 같은 함정에 계속 빠져 있습니다.

**Insight가 하는 일은 이 복기를 자동화해 준다는 것입니다.**

Qwen Code와 나눈 대화를 전부 분석해서 개인 사용 리포트를 만들어 줍니다. 스마트폰의 '스크린 타임'과 비슷하지만, "오늘 짧은 영상을 몇 시간 봤다"는 얘기가 아니라 "오늘 AI에게 시킨 일이 이만큼이고, 더 시키려면 이렇게 하라"는 얘기를 해 줍니다.

![](https://gw.alicdn.com/imgextra/i3/O1CN01TbTAPo1gEtLwqodNV_!!6000000004111-2-tps-1573-904.png)

## 거울 같습니다: 'AI 사용 습관'을 비춰 주니까

Insight에서 저를 가장 흔든 부분은, **저 스스로도 몰랐던 패턴**을 보여 줬다는 점입니다.

![](https://gw.alicdn.com/imgextra/i4/O1CN01VJBusI1uz3trvVkRt_!!6000000006107-2-tps-1437-505.png)

예를 들어 제 리포트에는 4일 동안 shell 명령을 246번 쓴 것으로 나왔습니다. 다른 모든 도구보다 압도적으로 많았습니다. Insight는 여기서 이렇게 분석했습니다:

> **미리 자세히 계획하는 편이 아니라, 해 보면서 조절합니다.**
>
> **조언만 받는 것보다 Qwen Code가 실행하고 검증까지 하게 하는 것을 선호합니다.**

이 부분을 읽고 잠깐 멈췄습니다. 너무 정확했거든요. 저도 '우선 해 보는' 쪽 사람이긴 한데, 이 습관이 AI와의 협업 효율까지 좌우한다는 건 전혀 인지하지 못했습니다.

![](https://gw.alicdn.com/imgextra/i2/O1CN01vuQnjd1QAHVvKHOPT_!!6000000001935-2-tps-1460-580.png)

복기의 가치는 바로 여기에 있습니다: **뭘 잘못했는지 가르쳐 주는 게 아니라, 자기 행동 패턴을 보이게 해 주는 것**이고, 그러면 어디를 고칠지는 본인이 알게 됩니다.

Insight는 업무 내용 분포, 활동 시간대, 요구 유형까지 분석해 줍니다. 내가 AI로 실제로 뭘 하고 있는지 큰 그림에서 이해할 수 있게 되는 거죠. 저는 그 며칠 동안 코드를 쓰기보다 문서와 스킬 개발에 시간을 썼다는 걸 처음 알았습니다(세션 19개). 저, 완전 '문서하는 사람'이었네요(웃음).

![](https://gw.alicdn.com/imgextra/i4/O1CN01F77QIP1DLBwYv4e5Q_!!6000000000199-2-tps-1506-969.png)

## 진단가 같습니다: '걸리는 지점'을 찾아 주니까

복기는 데이터만 봐서 될 일이 아니고, **발목 잡는 지점을 찾는 것**이 더 중요합니다.

Insight는 AI와의 협업에서 마찰이 생기는 지점을 자동으로 골라내 유형별로 분석해 줍니다. 제 리포트에서 상위 세 가지가 이랬습니다:

![](https://gw.alicdn.com/imgextra/i3/O1CN01kkz3VJ1xoTarHMdRr_!!6000000006490-2-tps-1446-1022.png)

- **빌드와 의존성 문제**: npm 충돌, ffmpeg 누락, 권한 오류 — 그때마다 몇 바퀴를 헤맸습니다
- **파일 쓰기 실패**: heredoc 문법, YAML frontmatter 손상 — 스킬 파일을 만들 때마다 반복해서 틀렸습니다
- **Git 워크플로 끊김**: PR 생성 실패, 따옴표 이스케이프 — 한 번에 끝났을 작업이 여러 바퀴 디버깅으로 변했습니다

이걸 보고 확 깨졌습니다 — **문제가 가끔 생긴 게 아니라 구조적이었습니다.** 빌드 문제만 만나면 늘 몇 바퀴를 헤맸는데, AI 문제가 아니라 제 환경 설정이 덜 되어 있었던 겁니다. Insight가 이 데이터를 테이블에 올려 주지 않았으면 계속 모르고 지나갔을 거예요.

병원 가는 것과 비슷합니다. '가끔 머리 아픈 정도는 괜찮지' 하고 넘기는데, 건강검진 결과는 혈압이 높다고 말해 주죠 — **문제는 증상 하나하나가 아니라, 그 뒤에 있는 패턴을 못 보고 있다는 점입니다.**

## 코치 같습니다: 구체적인 개선안까지 내어 주니까

문제를 찾은 다음은요? 여기가 Insight의 진짜 값어치입니다 — **진단만 하는 게 아니라 처방전까지 내어 줍니다.**

Insight는 당신을 막는 지점에 맞춰, QWEN.md(Qwen Code의 개인 설정 파일)에 그대로 붙여 넣을 수 있는 규칙 제안을 만들어 줍니다. 저의 경우 이런 제안이 나왔습니다:

- PR을 만들 때마다 반드시 검증하고 URL까지 제시할 것(실제로 PR이 만들어지지 않은 일이 여러 번 있었습니다)
- 스킬 파일은 heredoc 대신 직접 쓰기 방식으로 작성할 것(heredoc이 반복해서 YAML을 망가뜨렸습니다)
- 빌드를 시작하기 전에 의존성이 설치됐는지 확인할 것(누락된 의존성이 제 최대의 시간 도둑이었습니다)

![](https://gw.alicdn.com/imgextra/i2/O1CN01DLriav1kIKnEsI5Bb_!!6000000004660-2-tps-1453-638.png)

**이건 두루뭉술한 '모범 사례'가 아니라, 당신의 실제 사용 데이터에서 뽑아 낸 개인 맞춤 제안입니다.** 코치가 경기 영상을 보고 나서 "세 번째 동작이 항상 박자 반박자 늦어요, 이렇게 고쳐 보세요"라고 말하는 것과 같고, 두루뭉술한 훈련 매뉴얼을 던져 주는 것과 다릅니다.

![](https://gw.alicdn.com/imgextra/i2/O1CN01qmzio71yXonubltON_!!6000000006589-2-tps-1474-1088.png)

필요한데 아직 안 써 본 기능도 추천해 줍니다. 저는 shell 명령으로 PR을 우회 생성하는 일이 많았는데, Insight는 **MCP Servers**를 제안했습니다. Qwen Code가 GitHub와 직접 대화하니 커맨드 라인에서 발 동동 구를 일이 줄어드는 거죠.

![](https://gw.alicdn.com/imgextra/i1/O1CN01ssrTMy1DalPTJKmIf_!!6000000000233-2-tps-1466-824.png)

## 응원도 해 줍니다: 잘한 부분도 보이게

좋은 복기는 문제만 찾지 않아요. 진보와 하이라이트도 함께 봐야 합니다.

Insight는 어디를 잘했는지, AI가 어떤 면에서 가장 도움이 됐는지도 알려 줍니다. 제 리포트에는 만족도 97%, 완전히 또는 대체로 끝낸 일이 80%라고 나왔습니다. Qwen Code가 가장 크게 도와준 능력은 '선제적 도움'이었습니다. 제가 하나하나 지시하지 않아도 스스로 문제를 찾고 해결안을 먼저 내왔습니다.

리포트 마지막에는 미래 전망 모듈도 있습니다. AI 보조 개발이 어디로 가고 있는지를 그려 주는데, '주어진 일 끝내는 것'에서 '여러 에이전트가 스스로 굴러가는 것'으로 바뀌고 있습니다. 읽고 나면 이런 기분이에요: **지금 우리가 AI와 협업하는 방식은 아직 출발점 정도일 수도 있겠다.**

![](https://gw.alicdn.com/imgextra/i4/O1CN01zK0pOT1ll1DL4Nd0A_!!6000000004858-2-tps-1481-1389.png)

## 재미있던 구석

![](https://gw.alicdn.com/imgextra/i4/O1CN01YNjMMT1I9LmZt55ll_!!6000000000850-2-tps-1455-247.png)

리포트에 이런 일화가 남아 있습니다. 로컬 IP 주소를 물어보면서 오타를 내서 입력이 전혀 알아볼 수 없는 문자열이 됐는데, Qwen Code가 제 뜻을 맞히고 IP 주소까지 제대로 주었습니다. 이런 '마음이 통하는' 느낌, 은근 귀엽더군요ㅎㅎ

## Insight는 어떻게 쓰나요?

Qwen Code에서 `/insights` 명령을 입력하면 사용 리포트가 만들어집니다.

<video class="mt-5" src="https://cloud.video.taobao.com/vod/KECE0t_PB_P9P2Djf22fMZ97mRNPrqroKO5cf4V71XM.mp4" controls></video>

리포트는 일곱 개 모듈로 구성됩니다:

| 모듈 | 설명 |
|------|------|
| At a Glance | 사용 개요, 전체 사용량을 한눈에 |
| What You Work On | 업무 내용 분석, 시간 배분 확인 |
| How You Use Qwen Code | 사용 패턴, 행동 습관 발견 |
| Impressive Things | 하이라이트와 성과, 내 진보 보기 |
| Where Things Go Wrong | 문제 진단, 발목 잡는 지점 찾기 |
| Features to Try | 기능 추천, 새로운 가능성 발견 |
| On the Horizon | 미래 전망, 진화 방향 읽기 |

**사람마다 리포트가 다릅니다.** 전부 본인 사용 데이터만으로 만들기 때문이죠. 당신의 발목 잡는 지점, 당신의 습관, 당신의 개선 제안이 전부 맞춤으로 나옵니다.

<Callout>
    **요령**:
    `/insights` 명령을 주기적으로 돌려 리포트를 보면서, AI와의 협업 방식을 계속 다듬어 주세요.
</Callout>

Qwen Code를 쓰고 있다면 한 번 꼭 돌려 보세요. 데이터를 보려는 게 아닙니다. **평소 못 보던 나를 보려는 것**이고, 그러면 다음 협업이 이번보다 조금 더 매끄러워지니까요.

## 마치며

Insight는 기능 하나 이상입니다. 시선 하나를 새로 열어 주거든요 — **AI를 통해, 내가 AI를 어떻게 쓰는지 이해하게 해 주는** 시선입니다.

AI 보조 코딩이 점점 흔해지는 시대에, 매끄럽게 쓰고 협업하는 법은 특정 프로그래밍 언어를 하나 더 익히는 것보다 중요할 수 있습니다. 그리고 Insight는 그 거울이자, 진단가이자, 코치입니다.
