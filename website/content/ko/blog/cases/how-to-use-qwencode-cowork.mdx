파일 하나 찾으려면 쓰레기 더미에서 보물찾기 하는 것 같습니다. 분명 저장하긴 했는데 도무지 안 보여요. 더 억울한 건 몇 달에 한 번씩 뜨는 시스템 알림입니다: **디스크 공간 부족**.

정리해야 하는 건 아는데—

> 파일 정리는 TODO 목록에만 누워 있는, 영원히 실행되지 않는 일입니다.

그러다 **Qwen Code Cowork**를 만났습니다. 말 그대로 일을 해 주는 AI 어시스턴트입니다.

## Qwen Code Cowork가 뭐냐면

짧게 말하면 **무료 오픈소스** 데스크톱 AI 어시스턴트이고, Qwen Code SDK 위에 만들어졌습니다.

그렇다고 채팅창만 붙은 도구는 아닙니다. 실제로 **손을 움직여 일을 해 주는** AI입니다:

| 하는 일 | 설명 |
|------|------|
| 📝 코드 작성·수정 | 모든 프로그래밍 언어 지원 |
| 📁 파일 관리 | 생성, 이동, 이름 바꾸기, 정리 |
| ⚡ 명령 실행 | 빌드, 테스트, 배포 |
| 💬 질문에 답하기 | 코드 관련이든 다른 것이든 |
| 🔧 작업 자동화 | 자연어로 설명할 수 있으면 됩니다 |

가장 중요한 부분은 이겁니다: **완전히 무료, 오픈소스라 통제 가능, 데이터는 로컬 저장**.

비슷한 역할의 Claude Code는 Max 구독자만 쓸 수 있고 월 100~200달러입니다. Qwen Code Cowork는 같은 능력을 비용 없이 씁니다.

## 활용 총정리

아래는 직접 쓰면서 건진 아주 실용적인 상황들입니다. 하나씩 시연도 붙여 뒀습니다.

### 상황 1: 엉망진창인 데스크톱 / 다운로드 폴더 정리

데스크톱과 다운로드 폴더는 그야말로 디지털 쓰레기장입니다. 스크린샷, 문서, 설치 파일, 임시 파일이 한데 뒤섞여 있어서 뭘 찾으려면 한참을 헤매야 하죠. 보기만 해도 짜증나는데 손으로 정리하자니 시간이 아깝습니다.

**Cowork가 해 주는 일**:

그냥 이렇게 말해 보세요. "데스크톱을 파일 종류별로 정리해 줘. 스크린샷은 스크린샷 폴더, 문서는 문서 폴더, 설치 파일은 설치 파일 폴더로"

그러면 이렇게 동작합니다:

1. 먼저 데스크톱을 스캔해서 모든 파일을 목록으로 보여 줍니다
2. 정리 방안 미리보기를 제시합니다
3. 당신이 승인하면 분류와 이동을 자동으로 실행합니다

</Callout>

### 상황 2: 파일 이름 일괄 바꾸기 (사진을 촬영 날짜 기준으로)

휴대폰에서 내보낸 사진 이름은 IMG_0001, IMG_0002… 언제 찍었는지 전혀 알 수 없습니다. "2024-01-15_바다 일몰" 같은 형식으로 바꾸고 싶은데, 몇 백 장을 손으로 고치다 보면 새벽이 됩니다.

**Cowork가 해 주는 일**:

이렇게 말해 보세요. "이 폴더의 사진을 촬영 날짜 기준으로 이름 바꿔 줘. 형식은 YYYY-MM-DD_일련번호"

그러면 이렇게 동작합니다:

1. 사진마다 EXIF 정보(촬영 날짜)를 읽습니다
2. 지정한 형식으로 새 파일 이름을 만듭니다
3. 이름 바꾸기 전체 작업을 미리보기로 보여 줍니다
4. 확인 후 일괄 실행합니다

### 상황 3: 저장 공간 점검해서 큰 파일 찾기

디스크 공간이 부족하다는 알림이 또 떴지만, 무엇을 위해 쓰이는지는 모릅니다. 정리하고 싶은데 중요한 파일을 지울까 무섭고, 청소 프로그램은 개인정보가 걱정되죠.

**Cowork가 해 주는 일**:

이렇게 말해 보세요. "저장 공간 사용량을 점검해서 공간을 가장 많이 먹는 폴더·파일 10개를 찾아 줘. 내용도 간단히 설명하고, 지워도 되는지, 지우면 어떤 일이 생기는지도 알려 줘"

그러면 이렇게 동작합니다:

1. 디스크 사용량을 스캔합니다
2. 공간을 가장 많이 차지하는 파일과 폴더를 목록으로 보여 줍니다
3. 안전하게 지워도 되는 것(캐시, 임시 파일 등)을 가려 냅니다
4. 정리 방법을 제안합니다

### 상황 4: 메모 통합 및 서식 정리

메모는 여기저기 흩어져 있습니다: WeChat 즐겨찾기, 메모 앱, Notion, Obsidian… 하나로 모으고 싶은데 서식은 제각각입니다. 손으로 복붙하면서 서식까지 맞추자니 일이 너무 커지죠.

**Cowork가 해 주는 일**:

이렇게 말해 보세요. "이 폴더의 docx 파일을 모두 합쳐 하나의 Markdown 파일로 만들어 줘. 생성 시간 순으로 정렬하고 서식은 통일하며, 파일 이름은 두 번째 제목으로 표시해 줘"

그러면 이렇게 동작합니다:

1. 모든 파일 내용을 읽습니다
2. 서식을 인식해 통일합니다
3. 지정한 규칙대로 정렬하고 합칩니다
4. 서식 갖춰진 Markdown 파일을 만들어 줍니다

### 상황 5: 문서 일괄 처리 (PDF 내용 추출)

PDF 자료를 잔뜩 받아와서 메모로 정리하고 싶은데, 하나씩 열어 복붙하기엔 너무 느립니다. 스캔본은 복붙해도 글자가 깨져 나오죠.

**Cowork가 해 주는 일**:

이렇게 말해 보세요. "이 폴더의 모든 PDF 내용을 추출해서 파일마다 대응하는 markdown 파일로 저장해 줘"

그러면 이렇게 동작합니다:

1. 폴더 안의 PDF를 전부 훑습니다
2. 텍스트 내용을 추출합니다
3. PDF마다 대응하는 txt 파일을 만듭니다
4. 처리 결과를 보고합니다

```
cowork 프로젝트를 설치하고 시작해 줘. 저장소 주소는 https://github.com/QwenLM/qwen-code-examples
```

### 소스로 설치 (고급)

소스로 빌드하려면 Bun을 먼저 설치해야 합니다:

```bash
# Bun 설치
curl -fsSL https://bun.sh/install | bash
exec /bin/zsh

# 저장소 클론
git clone https://github.com/QwenLM/qwen-code-examples

# 디렉터리로 이동해 설치
cd qwen-code-examples/apps/qwen-cowork
bun install

# 시작
bun run dev
```

## 사용 요령

### 1. Plan 모드를 잘 쓰기

파일 정리처럼 되돌리기 어려운 작업은 AI에게 먼저 계획을 세우게 하는 편이 좋습니다:

```
"먼저 이 폴더 상황을 분석해서 정리 방안만 보여 줘. 아직 직접 실행하지는 말고"
```

방안이 맞는다고 확인된 뒤에 실행하게 하세요.

### 2. 작업 디렉터리 지정하기

세션을 만들 때 작업 디렉터리를 지정할 수 있습니다. 그러면 AI는 그 아래에서만 동작하니 더 안전합니다.

### 3. 민감한 작업은 확인 거치기

Cowork는 삭제, 이동 같은 민감한 작업 전에 반드시 확인을 묻습니다. 실수로 지어버릴 걱정은 없어요.

## 더 넓은 활용

위 상황뿐 아니라 Qwen Code Cowork는 이런 일도 합니다:

- 🔄 일상 작업 자동화 (정기 백업, 파일 동기화)
- 💻 코드 프로젝트 관리 (프로젝트 초기화, 의존성 설치, 테스트 실행)
- 📊 데이터 처리 (CSV 변환, 데이터 정제, 형식 변환)
- 📝 문서 생성 (코드에서 문서 만들기, README 작성)
- 🔍 코드 리뷰 (품질 분석, 잠재 문제 색출)

자연어로 설명할 수 있는 일은 거의 다 시킬 수 있습니다.
