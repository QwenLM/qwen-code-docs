신제품 낼 때마다 밤을 새워 소재를 만들고 있나요? 아마 이런 경험이 있을 겁니다.

신제품 등록이 코앞인데 운영팀에서 모바일 스플래시 화면 하나, 배너 광고 세 장, 상품 상세페이지 컷세트, 15초 상품 소개 영상에, 샤오홍슈 후기 글과 위챗 공식 계정 포스트까지 달라고 합니다. **마감은 모레**예요.

포토샵을 켜고 30초를 기다리는데 디자이너가 오늘 휴가라는 걸 뒤늦게 압니다. 편집 앱을 켜서 반 시간 동안 클립을 끌어다 놓면 내보내기 해상도가 틀려요. 문서에 카피를 두 줄 쓰다 멈춰서 화면만 바라봅니다.

**새벽 두 시, 겨우 소재를 맞췄습니다. 다음 신제품에도 똑같은 일이 반복되고요.**

그런데 이게 이렇게 된다면 어떨까요?

- 터미널에 한 문장 치면, **10초 만에 모바일 스플래시 화면**이 나옵니다
- 폰으로 상품 사진을 찍어 Feishu 그룹에 올리고 봇을 @하면, **1분 뒤에 보정된 상품컷**이 돌아옵니다
- AI에게 "이 보조배터리 샤오홍슈 후기 글 하나 써 줘"라고 하면, **30초 만에 초안**이 나옵니다

2026년에 일하는 방식은 이런 거 아닌가요?

이 글에서는 실제 세 가지 장면으로 **Qwen Code + Model Studio CLI**를 써서 이미지 생성부터 사진 보정, 카피 작성까지 전 과정을 보여 드립니다. 각 장면마다 절차를 적어 두었으니 보고 그대로 따라 하면 됩니다.

## 먼저 도구부터: Qwen Code와 Model Studio CLI가 뭔가요?

쉽게 말하면 이렇습니다.

- **Qwen Code**는 AI 코딩 어시스턴트입니다. 그런데 코드만 쓰는 도구가 아니에요. 자연어 지시를 이해하고 여러 도구를 불러와 일을 끝내는 범용 AI Agent입니다
- **Model Studio CLI**(`bl` 명령)는 알리바바클라우드 Model Studio 플랫폼의 커맨드라인 도구입니다. 텍스트→이미지, 이미지→이미지, 텍스트→영상, 이미지→영상 같은 AI 능력을 한곳에 모아 뒀어요

이 둘을 붙이면 **사람 말 알아듣는 마케팅 소재 생산 라인**이 됩니다.

## 장면 1: 한 문장으로 마케팅 이미지 생성 🎨

큰 행사가 있을 때마다, 신제품이 올라갈 때마다 디자이너에게 메인 컷과 상세페이지 이미지, 프로모션 포스터를 부탁해야 합니다. 디자이너 일정은 늘 차 있고 사소한 수정도 반 하루를 기다려야 하죠. **급할 때는 정말 기다릴 수가 없습니다.**

이제는 원하는 그림을 한 문장으로 설명하면 AI가 바로 만들어 냅니다. 흰 배경 메인 컷, 장면 사진, 행사 분위기 이미지, 기술 느낌 이미지가 전부 가능해요.

상품이 있으니 먼저 상품컷부터 만들어 봅니다.

```
帮我生成 3 张充电宝的电商白底主图，要求：淡米色背景、专业棚拍风格、柔和灯光、底部轻微阴影、构图居中干净，3:4 尺寸
```

상품컷이 마음에 들었으니 이번엔 판매 포인트 문구를 얹어 봅니다. 한 문장만 더하면 됩니다.

```
已经生成了商品图，现在给这些图片加上宣传语，以及卖点内容。
```

<video class="mt-5" src="https://cloud.video.taobao.com/vod/jepzY16ry-ep9h6Arp_iKjY1_zqMGQR8Pp_xNSJhXMc.mp4" controls></video>

아직 마음에 안 들면? 조금만 고쳐 보세요

어떤 이미지가 80점쯤 되니 손보고 싶다 싶으면 Qwen Code에게 그냥 말하면 됩니다.

```
把第一张图的背景换成紫红渐变，加金色点缀，更适合双 11 氛围
```

문구를 고칠 때도 처음부터 다시 갈 필요가 없습니다. 기존 이미지에서 계속 고쳐 가면 갈수록 정확해져요. 텍스트는 HTML 레이어에서 다루기 때문에 문구를 바꾼다고 이미지를 다시 그리지 않아도 됩니다. 토큰도 절약되죠. Qwen Code에게 이렇게 말하면 끝입니다.

```
把 20000mAh，修改为10000mAh
```

### 지원하는 이미지 종류

| 종류 | 크기 | 용도 |
| ------ | ------------------ | -------------- |
| 이커머스 메인 컷 | 1024×1024 (정사각 1:1) | 타오바오/징둥 상품 첫 이미지, 프로모션 메인 |
| 상품 상세페이지 컷 | 1024×1366 (세로 3:4) | 상세페이지 한 화면 |
| 모바일 스플래시 화면 | 1080×1920 (세로 9:16) | 앱 오픈 광고 |
| 배너 광고 | 1344×756 (가로 16:9) | PC 배너 |

모든 크기에 **마케팅 문구가 들어간 상품 이미지**가 가능합니다. AI가 먼저 비주얼만 있는 상품 배경 컷을 만들고, HTML로 판매 포인트와 슬로건, 가격 같은 텍스트를 정확히 얹어서 최종 PNG 한 장으로 내보내는 방식이에요. 글자는 선명하고 찌그러지지 않습니다. 문구를 고치면 2초 만에 다시 렌더링하면 되지, 이미지를 다시 그리지 않아도 돼요.

## 장면 2: Feishu에 사진 한 장, 상품컷과 영상이 자동으로 📸

이커머스 상품 촬영은 비쌉니다. 스튜디오 빌리고, 포토그래퍼 부르고, 후보정까지 하면 최소 몇 천 위안부터, 기간도 1~2주예요. 작은 팀은 감당하기 어렵습니다. 게다가 요새는 모든 플랫폼이 숏폼을 미는 통에 상품 영상은 또 별도 지출이죠.

지금 가장 시원한 방법은 이겁니다. **폰으로 사진 한 장 찍어서 Feishu 그룹에 올리고 봇을 @하면, AI가 알아서 어떤 상품인지 파악한 뒤 흰 배경 상품컷, 문구가 들어간 마케팅 이미지, 5초 소개 영상을 한 번에 만들어 줍니다.**

과정 내내 컴퓨터를 켜지 않아도 됩니다.

**1단계: 찍어서 그룹에 올리기**

폰으로 상품 사진을 대충 한 장 찍습니다. 배경은 책상이나 소파, 아무 데나 괜찮아요. Feishu 그룹에 올리고 @Qwen Code에게 이렇게 말합니다.

```
使用 open1v-product-visual 技能帮我生成2张商品图
```

봇이 자동으로 세 가지를 합니다.

1. **상품 인식** — 무엇을 찍었는지 알아맞춥니다
2. **표준 상품컷 생성** — 인식한 상품에 맞춰 이미지를 만들어 프로젝트 폴더에 저장합니다
3. **결과 반환** — 클라우드 저장소 이미지 링크로 바로 돌려줍니다

**2단계: 이미지 고르고 마케팅 문구 얹기**

흰 배경 컷에서 마음에 드는 것을 하나 고른 뒤, 이어서 말합니다.

```
现在我需要加上营销文字，小红书3:4尺寸，布局你可以自选，我要白底的。
```

봇은 인식한 상품 정보를 바탕으로 마케팅 문구를 뽑아 이미지에 얹습니다. 메인 타이틀, 서브 타이틀, 판매 포인트 태그, 스펙 수치까지 — 조판까지 끝난 완성컷이라 그대로 상품 등록을 해도 됩니다.

문구나 레이아웃을 바꾸고 싶으면 그냥 말하면 됩니다.

```
把图片整体向右侧移动一点，产品主体居中，文字和排版不变
```

문구 수정에 이미지 재생성은 필요 없습니다. **2초**면 다시 렌더링돼서 나옵니다.

**3단계: 완성본 링크 받기**

```
现在我需要你生成图片的链接，上传到云空间并返回给我链接，只需要终稿版本
```

### 최종 산출물은 프로젝트 폴더 하나

```
product-charger-0610/
├── raw/          ← 직접 찍은 원본 사진
├── product/      ← 생성된 표준 상품컷 (흰 배경 컷, 장면 컷)
├── index.html    ← 텍스트 조판 소스 파일 (직접 글자 고치고 2초 만에 다시 내보내기)
├── final/        ← 문구가 들어간 완성 이미지 (그대로 상품 등록 가능)
└── video/        ← 5초 소개 영상
```

사진을 찍는 순간부터 전 소재를 손에 쥐기까지 **10분이 안 걸립니다**. 예전엔 포토그래퍼와 디자이너가 붙어서 일주일이었어요.

> Feishu를 안 써도 됩니다 — Qwen Code 터미널에서 해도 똑같아요. 사진 경로를 넘기면 끝납니다.

## 장면 3: AI가 홍보 카피를 써 드립니다 ✍️

카피 쓰기가 가장 시간을 많이 잡아먹는 구간입니다. 위챗 공식 계정은 깊이 있는 긴 글, 샤오홍슈는 짧은 후기조, 상세페이지는 판매 포인트 — **같은 상품에 채널이 세 개면 쓰는 방식도 세 개**입니다. 매번 백지에서 시작하다 보면 결국 표현이 고갈되어 그 말이 그 말만 반복돼요.

이제는 상품 정보와 올릴 채널만 알려 주세요. 위챗에는 스토리를, 샤오홍슈에는 후기를, 상세페이지에는 포인트를 — 한 번 넣고 여러 채널로 뽑습니다.

**예시: 휴대용 보조배터리 카피를 세 채널로 만들기**

Qwen Code에 이렇게 입력합니다.

```
帮我写一篇充电宝的推广文案。
产品名：PowerMax 迷你充电宝
卖点：1. 仅重 120g，比一颗鸡蛋还轻  2. 10000mAh 大容量  3. 支持 65W 快充，30 分钟充满 iPhone
目标人群：经常出差的商务人士
渠道：公众号、小红书、详情页
```

AI가 세 버전을 따로 뽑아 줍니다. 데모 영상을 한번 보세요.

### 여전히 부족하다면? 계속 말하기 — 위챗 발행까지 한 번에

내용이 마음에 안 들면 Qwen Code에게 어떻게 고칠지 말해 주면 됩니다. 예를 들어:

```
公众号版本内容再轻松一些，直接帮我发不到公众号后台
```

위챗 공식 계정의 AppID와 AppSecret을 Qwen Code에게 알려 주고, 위챗 개발자 플랫폼에서 본인 IP를 화이트리스트에 등록해 두면 설정은 한 번으로 끝납니다. 이후엔 초안함에 바로 게시할 수 있어서 조판 고민이 사라져요.

## 세 장면을 이으면 신제품 출시 라인 하나가 됩니다

처음 그 장면으로 돌아가 보죠. 신제품이 올라가는데 마케팅 소재가 통째로 필요합니다.

이제 작업 흐름이 이렇게 바뀝니다.

```
상품 사진을 대충 한 장 찍는다
    ↓
장면 1: 스플래시 화면·배너·포스터 생성 → 10분에 마케팅 이미지 전부
    ↓
장면 2: 상품컷 보정 + 소개 영상 생성   → 20분에 상품컷과 영상
    ↓
장면 3: 위챗/샤오홍슈/상세페이지 카피  → 10분에 전 채널 카피
```

**40분, 사람 한 명, 전 소재 완성.** 예전엔 디자이너와 포토그래퍼, 카피라이터가 일주일 붙어야 나오던 양입니다.

## 시작하는 법

### 환경 준비

1. **Qwen Code 설치**: [공식 문서](https://qwenlm.github.io/qwen-code-docs/ko/users/overview/)를 보고 설치
2. **Model Studio CLI 설치**: [Model Studio CLI 문서](https://bailian.console.aliyun.com/cli)를 보고 설치
3. **Qwen Code 실행**: Qwen Code에게 API Key와 원하는 작업을 그대로 말하면 됩니다

### 스킬 팩 설치

Qwen Code를 열고 이렇게 말하면 됩니다.

```
帮我安装 open1v-skills 技能包：git clone https://github.com/joeytoday/open1v-skills.git ~/.agents/skills/open1v-skills，然后安装依赖
```

설치가 끝나면 한 문장으로 전 과정이 돌아갑니다.

- **상품컷 생성**: `帮我生成一张充电宝的白底主图`
- **홍보 카피 작성**: `帮我写一篇充电宝的推广文案，渠道：公众号、小红书、详情页`
- **위챗 발행**: `把公众号文案发布到草稿箱`

이 스킬들을 바탕으로 우리 제품에 맞는 버전으로 고쳐 쓸 수도 있습니다.

### Feishu 연결 (선택)

## 마무리

AI가 디자이너와 카피라이터를 대신하겠다는 게 아닙니다. **누구나 '일단 한 번 뽑아 보는' 능력을 갖게 하는 거죠.**

AI 초안이 있으면 디자이너는 0에서 시작하는 대신 80점에서 95점으로 다듬으면 됩니다. 카피라이터는 기본 골격과 씨름하지 않고, 한 줄의 훅과 공감 만드는 데 힘을 쓸 수 있고요.

이게 AI 도구를 쓰는 올바른 방식입니다 — **대체가 아니라 가속**이죠.
