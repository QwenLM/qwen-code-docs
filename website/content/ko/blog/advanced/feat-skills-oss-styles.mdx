혹시 이런 적 있으신가요?

반 년 넘게 밤을 새워서 꽤 마음에 드는 오픈소스 프로젝트를 만들었습니다. GitHub 코드도 말끔히 정리했고, README도 몇 번을 고쳐 썼죠. 그런데 막상 소셜미디어에 알리려고 하면 늘 **뭔가 하나가 비어 있습니다**.

정적 스크린샷 한 장? 너무 심심합니다. 글로만 소개하면? 끝까지 읽는 사람이 없어요. 데모 영상을 만들자면? 편집 앱을 켰다 그냥 닫고, 결국 "다음에 꼭" 하는 탄식만 남습니다.

제가 아는 대학생 개발자 친구는 작년에 꽤 재미있는 프론트엔드 컴포넌트 라이브러리를 만들었습니다. 그런데 스타 수가 이삼십 개에서 멈추지 않더군요. 그 친구가 이렇게 하소연했습니다. "제 프로젝트가 나쁘지 않다는 건 제가 아는데, 그걸 남에게 어떻게 알려야 할지는 모르겠어요."

아픈 말이지만, 많은 개발자의 현실입니다.

## 한 문장이면 영상이 나옵니다

요즘 Qwen Code를 쓰다가 꽤 흥미로운 스킬을 하나 발견했습니다 — **[oss-styles](https://github.com/heimanba/oss-video-skill)**.

쉽게 말하면 Qwen Code에게 한 문장만 던지면 됩니다:

```
이 스킬 https://github.com/QwenLM/qwen-code-examples/blob/main/skills/oss-styles/SKILL.md 기준으로
https://github.com/QwenLM/qwen-code 저장소의 데모 영상을 만들어 주세요
```

그러면 알아서 GitHub에서 프로젝트 정보를 가져오고, 기술 스택과 통계, 컨트리뷰터 내역을 분석해서 마지막엔 **영화 같은 홍보 영상**을 뽑아 냅니다.

과정 전체에서 당신이 안 해도 되는 것들:

- ❌ 캡컷이나 Premiere를 켜는 것
- ❌ 대본 쓰고 콘티 짜는 것
- ❌ 소재 찾고 음악 고르는 것
- ❌ 애니메이션 만지고 타임라인 맞추는 것

AI가 다 해 줍니다.

## 완성 영상은 어떤 모습인가요?

Qwen Code 프로젝트로 직접 만들어 봤습니다. 영상 길이는 30~40초 정도, 템포가 짜임새 있고 비주얼도 통일감이 있어서 그대로 트위터나 샤오홍슈, 지커에 올리거나 프로젝트 GitHub README 맨 앞에 붙일 수 있습니다.

## 누가 쓰면 좋을까요?

따져 보니 이 스킬이 특히 쓸모 있는 경우는 최소한 다섯 가지였습니다.

### 1. 개인 개발자의 콜드스타트

사이드 프로젝트를 방금 세상에 냈고 Product Hunt나 V2EX에 올려 볼 생각이죠. 번듯한 제품 영상 하나가 글과 그림으로만 된 소개보다 훨씬 오래 남습니다.

### 2. 대학생의 오픈소스 과제 / 졸업 프로젝트

컴퓨터 관련 학과에는 오픈소스 프로젝트 과제가 자주 나옵니다. 예전엔 GitHub 링크만 제출했다면, 이제는 영상을 같이 내서 발표나 심사 때 틀 수 있어요. 교수님이나 다른 학생들 눈에 훨씬 잘 띕니다 (정말 효과가 큽니다).

### 3. 기술 블로거의 콘텐츠 소재

블로그나 기술 영상에서 어떤 오픈소스든 소개하고 싶다면, oss-video로 프로젝트 소개 클립을 뽑아 자기 콘텐츠에 끼워 넣으면 됩니다. 화면 녹화도 편집도 필요 없어집니다.

### 4. 회사 오픈소스의 외부 홍보

사내 도구를 오픈소스로 여는 회사는 많지만 운영이 따라가지 못하는 일이 많습니다. 이 스킬이면 개발팀이 직접 홍보 자산을 빠르게 뽑을 수 있어요. 디자이너 일정을 기다릴 필요가 없습니다.

### 5. 해커톤 / 기술 대회 프로젝트 시연

시간은 없고 할 일은 많은데 데모 영상은 꼭 필요합니다. 영상은 한 문장으로 만들어 버리고, 남은 시간은 코드와 데모 다듬는 데 쓰면 됩니다.

## 어떻게 쓰나요?

Qwen Code가 이미 있다면 설치는 간단합니다:

```bash
# 프로젝트 디렉터리로 이동
cd your-project

# Qwen Code 실행
qwen

# 그 다음 Qwen Code에게 그대로 말하면 됩니다
이 스킬 https://github.com/QwenLM/qwen-code-examples/blob/main/skills/oss-styles/SKILL.md 기준으로
<당신 저장소 주소> 데모 영상을 만들어 주세요"
```

AI는 자동으로 다음을 합니다:

1. GitHub API에서 프로젝트 정보를 가져옵니다
2. 프로젝트 공식 사이트에서 로고와 브랜드 컬러를 가져옵니다
3. 프로젝트 포지셔닝과 기술 스택을 분석합니다
4. 다섯 장면의 영상 클립을 만듭니다
5. 최종 영상으로 합성합니다

스타일을 바꾸고 싶을 수도 있습니다. 색을 바꿔 달라고 해도 되고, 문구를 고치거나 애니메이션 템포를 조절해도 돼요. 코드는 전부 오픈소스이니 생성된 Remotion 프로젝트도 마음대로 만질 수 있습니다.

<Callout>
**오픈소스의 힘**: 모든 코드가 오픈소스입니다. 생성된 Remotion 프로젝트를 자유롭게 수정하고 확장해서 나만의 영상 스타일을 만들 수 있습니다.
</Callout>

## 잠깐의 소회

솔직히 이 스킬을 봤을 때 첫 반응은 이랬습니다. **오픈소스 프로젝트 '간판'의 문턱이 드디어 낮아졌구나.**

전에는 대기업 오픈소스만 멋진 홍보 영상에 예산을 쓸 수 있었습니다. 개인 개발자나 학생 프로젝트는 코드가 알아서 말해 주기를 바라는 수밖에요. 그런데 코드는 스스로 말을 하지 않습니다. 정보가 넘치는 시대에는 더 그렇고요.

이제 한 문장이면 전문가급 홍보 영상이 나옵니다. 이게 무슨 뜻일까요?

**좋은 프로젝트가 눈에 띄기 쉬워진다**는 뜻입니다.

**기술력이 제대로 전달된다**는 뜻이고요.

**오픈소스 커뮤니티가 더 활발하고 다채로워진다**는 뜻입니다.

저는 이거, 꽤 좋다고 생각합니다.
