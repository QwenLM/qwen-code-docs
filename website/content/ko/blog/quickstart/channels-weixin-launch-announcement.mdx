> **개발자분들, 좋은 소식입니다!** 오늘부터 Qwen Code는 위챗 채널을 정식 지원합니다. 터미널도 IDE도 열 필요 없습니다. 위챗에 메시지 하나만 보내면 AI 어시스턴트가 코드를 쓰고, 문서를 찾고, 기술 문제를 해결해 줍니다. 알려드립니다, 이건 가재가 아닙니다. Qwen Code의 Channel 기능입니다! 방금 갓 만들어 낸 따끈따끈한 기능입니다: https://github.com/QwenLM/qwen-code/pull/2628

## 💡 먼저 이렇게 써 봤습니다

점심 먹으러 식당에 가는 길에 GitHub에서 새 issue 알림을 받았습니다. channel 기능이 생긴 뒤로는 스크린샷을 그냥 위챗에 던지면 됩니다. 위챗이 로컬의 Qwen Code를 깨우고, 기분 좋게 커뮤니티 문의 응대가 시작됩니다.

## 🎯 왜 위챗 채널이 필요할까요?

![위챗 채널 핵심 개념도](https://img.alicdn.com/imgextra/i4/O1CN01p9WUdg27Z2P6L8UTB_!!6000000007810-0-tps-1376-768.jpg)

개발자라면 이런 장면이 익숙하실 겁니다:

- **출근길**에 갑자기 버그 해결책이 떠올라서, AI에게 바로 검증해 보라고 시키고 싶을 때
- **회의 사이**에 API 쓰는 법을 빨리 확인해야 하는데, 노트북은 열고 싶지 않을 때
- **늦은 밤** 침대에 누운 채 아이디어가 쏟아져, AI에게 코드 골격을 맡기고 싶을 때
- **여행 중**에 온라인 급 문제가 생겨, 동료 원격 점검을 도와줘야 할 때

예전에는 노트북을 열고 터미널을 켜야만 Qwen Code를 쓸 수 있었습니다. 이제는 **위챗이 개발 환경**입니다.

## 🚀 빨리 시작하는 법

### 준비물

다음이 갖춰져 있어야 합니다:

- ✅ 미리보기 버전 Qwen Code 설치 `npm i @qwen-code/qwen-code@0.14.0-preview.0 -g`
- ✅ 메시지를 받을 수 있는 위챗 계정

> AI 시대에 누가 아직도 파라미터를 손으로 찍어 설정할까요? `npx skills add https://github.com/QwenLM/qwen-code-examples --skill weixin-channel-setup` 으로 weixin-channel-setup Skill을 설치하고, qwen을 연 다음 `{'/'}skills weixin-channel-setup 설정을 도와줘` 라고 물어보세요.

직접 설정해 보고 싶으시다면 아래 세 단계를 따라해 주세요.

![세 단계 설정 흐름도](https://img.alicdn.com/imgextra/i4/O1CN01aWJWAF1YwqRJ6ryra_!!6000000003124-0-tps-1376-768.jpg)

### 1단계: QR 코드로 연결

터미널에서 실행합니다:

```bash
qwen channel configure-weixin
```

터미널에 "QR code URL"이 출력됩니다. 링크를 복사해 브라우저에서 열고, 위챗으로 스캔하면 됩니다.

- 위챗 설치를 안내받을 수 있습니다
  스캔에 성공하면 이렇게 보입니다:

```
Connected to WeChat successfully!
Credentials saved. You can now start a weixin channel with:
  qwen channel start <name>
```

이제 위챗 자격 증명이 로컬에 안전하게 저장됐습니다.

### 2단계: 채널 설정

`~/.qwen/settings.json`을 열어 아래 설정을 추가합니다:

```json
"channels": {
    "my-weixin": {
      "type": "weixin",
      "senderPolicy": "open",
      "sessionScope": "user",
      "model": "qwen3.5-plus",
      "instructions": "You are a concise coding assistant responding via WeChat. Keep responses under 500 characters. Use plain text only."
    }
  }
```

### 3단계: 시작하고 테스트

```bash
qwen channel start my-weixin
```

`[Channel] "my-weixin" is running.` 문구가 보이면 위챗을 엽니다:

1. 봇 어시스턴트를 찾습니다 (아까 스캔한 바로 그 계정)
2. 메시지를 보냅니다: "안녕, Python으로 Hello World 하나 작성해 줘"
3. 답장을 기다립니다...

🎉 **축하합니다! 지금부터 위챗으로 코드를 쓸 수 있습니다!**

## 🔧 더 활용하기

### 1. AI 페르소나 직접 만들기

`instructions` 필드를 고치면 나만의 AI 어시스턴트를 만들 수 있습니다:

```json
{
  "instructions": "당신은 베테랑 TypeScript 엔지니어입니다. 답할 때:\n1. 바로 실행 가능한 코드 예시를 우선 제시합니다\n2. 핵심 설계 결정을 설명합니다\n3. 생길 수 있는 엣지 케이스를 짚어 줍니다\n4. 전문적이되 친절한 어조를 유지합니다"
}
```

### 2. 부팅 시 자동 시작

솔직히 이 부분은 Qwen Code에게 직접 물어보는 편이 더 나을 수 있습니다. 대신 설정해 달라고 하세요~

더 많은 활용법은 여러분이 더해 주세요~
