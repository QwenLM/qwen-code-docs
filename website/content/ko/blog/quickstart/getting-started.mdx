Qwen Code가 처음이라면 이 글에서 설치, 설정, 대화, 확장 네 단계로 전체 흐름을 따라가 보세요. 각 단계마다 영상 시연이 있으니 그대로 따라하시면 됩니다.

## Qwen Code 설치

Qwen Code는 스크립트 하나로 설치할 수 있습니다. Windows, macOS, Linux 모두 지원합니다.

**macOS / Linux:**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows (PowerShell):**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

설치가 끝나면 `qwen --version`을 실행해 정상적으로 들어갔는지 확인합니다. npm으로 설치해도 됩니다:

```bash
npm i @qwen-code/qwen-code@latest -g
```

다운로드부터 확인까지 전 과정을 영상에 담았습니다. 옆에서 따라 해 보세요:

## 모델 서비스 제공자 연결

설치를 마지면 Qwen Code가 모델 서비스 제공자 연결을 안내합니다. 알리바바클라우드 Model Studio를 추천합니다.

1. [Alibaba Cloud Model Studio](https://modelstudio.console.alibabacloud.com/) 에서 API Key를 발급받습니다
2. 터미널에 `qwen`을 입력해 시작하고 Alibaba ModelStudio를 선택합니다
3. API Key를 붙여넣고 모델을 고릅니다

직접 설정하고 싶다면 `~/.qwen/settings.json`을 고치면 됩니다:

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "여기에 API Key 붙여넣기"
  }
}
```

설정을 마쳤다면 `/model` 명령으로 모델을 확인하고 바꿀 수 있습니다:

## 첫 대화 시작

프로젝트 디렉터리로 이동해 Qwen Code를 켭니다:

```bash
cd your-project && qwen
```

하고 싶은 일을 자연어로 그대로 말씀하세요. 예를 들어:

```
피보나치 수열을 계산하는 Python 함수를 작성해 줘
```

이런 부탁도 됩니다:

```
이 폴더의 파일들을 종류별로 다른 폴더에 나눠 담아 줘
```

Qwen Code는 과제를 스스로 짜르고, 작업을 실행하고, 결과까지 돌려줍니다. 하나씩 가르쳐 줄 필요가 없습니다. 목표만 말씀하시면 됩니다.

## Skill 확장 설치

Skill은 Qwen Code의 기능 확장 시스템입니다. 커뮤니티가 만든 Skill을 필요한 만큼 설치하면 AI에게 전문 능력을 더할 수 있습니다.

설치는 한마디면 끝납니다:

```
find-skills 설치해 줘
```

명령어로 직접 넣어도 됩니다:

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

설치가 끝나면 `/skills`로 설치된 Skill 목록을 확인하세요.
