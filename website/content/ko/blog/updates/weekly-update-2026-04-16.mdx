이번 주에 기능 버전 **v0.14.3**, **v0.14.4**, **v0.14.5** 세 개를 릴리스했습니다.

v0.14.3이 나온 뒤 커뮤니티 피드백이 꽤 들어와서, 이번 주에는 입력 경험과 서브 Agent 관련 문제를 집중적으로 다뤘습니다. 새 기능으로는 v0.14.4의 도구 지능형 병렬 실행이 눈에 띕니다 — 읽기 전용 도구는 자동으로 묶어서 병렬로 돌리고, 여러 도구가 얽힌 상황에서 응답 속도가 눈에 띄게 빨라졌습니다. CJK 형태소 인식 덕분에 중·일·한 사용자의 커서 이동이 드디어 정상 동작합니다. v0.14.5에는 Fork 서브 Agent가 추가돼 하위 작업이 부모 Agent의 컨텍스트를 그대로 물려받습니다. 참고로 Qwen OAuth 무료 쿼터는 4월 15일자로 제공이 종료됐으니 OpenRouter나 Fireworks로 옮겨 가시는 걸 권합니다.

## ✨ 새로운 기능

### 도구 지능형 병렬 실행

Qwen Code가 이제 도구 종류를 보고 병렬 가능 여부를 자동으로 판단합니다. 검색이나 파일 읽기 같은 읽기 전용 작업은 자동으로 묶어 병렬 실행하고, shell 쓰기는 순차로 남겨 안전을 지킵니다. 여러 도구를 쓰는 상황에서 대기 시간이 뚜렷하게 줄어듭니다. 관련 PR [#2864](https://github.com/QwenLM/qwen-code/pull/2864)

**이렇게 쓸 수 있습니다:**
- 여러 파일을 동시에 검색하고 코드 여러 구간을 한꺼번에 읽습니다 — 하나씩 줄 서서 기다릴 필요가 없습니다
- Agent가 어떤 도구 호출을 병렬로 돌릴 수 있는지 스스로 알아내니 설정은 아무것도 필요 없습니다
- 쓰기 작업은 여전히 순차 실행이라 파일 충돌 걱정이 없습니다

### Fork 서브 Agent의 컨텍스트 공유

Fork 서브 Agent 방식이 새로 추가됐습니다. 작업을 쪼개면 서브 Agent가 부모 Agent의 컨텍스트를 자동으로 물려받아, 배경 정보를 반복해서 넘길 필요가 없습니다. 큰 작업 여러 작은 작업으로 나눠 각각 돌리는 상황에 알맞습니다. 관련 PR [#2936](https://github.com/QwenLM/qwen-code/pull/2936)

**이렇게 쓸 수 있습니다:**
- '모듈 전체 리팩터링'을 여러 서브 Agent로 나눠 파일별로 처리시키되, 각 서브 Agent가 전체 맥락을 알고 있습니다
- 컨텍스트를 반복 전달할 일이 줄어 Token을 아낍니다
- 서브 Agent끼리 서로 간섭하지 않고 결과는 부모 Agent로 모읍니다

### Skill에서 모델 지정

Skill 파일의 frontmatter에서 모델을 덮어쓰는 설정을 할 수 있습니다. Skill마다 다른 모델로 실행하는 식입니다. 코드 검토에는 추론이 강한 모델, 간단한 작업에는 빠른 모델 — 필요한 만큼씩만 씁니다. 관련 PR [#2949](https://github.com/QwenLM/qwen-code/pull/2949)

**이렇게 쓸 수 있습니다:**
- 코드 검토 Skill에는 추론이 더 강한 모델을 지정해 검토 품질을 올림
- 간단한 작업 Skill에는 더 빠른 모델을 지정해 비용과 시간을 절약
- Skill마다 독립 설정이라 서로 영향을 주지 않음

### CJK 형태소 인식과 Ctrl+방향키 이동

터미널 입력에서 중·일·한 문자의 형태소 경계를 인식합니다. Ctrl+좌우 방향키를 누르면 커서가 단어 단위로 뛰고, 한 글자씩 밀려 다니지 않습니다. 아시아 문자와 영문을 섞어 입력할 때 체감 개선이 큽니다. 관련 PR [#2942](https://github.com/QwenLM/qwen-code/pull/2942)

**이렇게 쓸 수 있습니다:**
- 한국어·중국어 prompt를 입력할 때 Ctrl+방향키로 단어 단위로 이동해 고칠 위치를 바로 찾음
- 한글·영문 혼합 입력에서 커서 이동이 직관에 맞음
- 일본어·한국어 사용자도 똑같이 혜택을 받습니다

### LLM 메시지 재작성 미들웨어

ACP 프로토콜에 LLM 기반 메시지 재작성 미들웨어가 추가됐습니다. 커스텀 prompt로 사용자 메시지를 사전 처리할 수 있습니다. 예를 들어 컨텍스트 자동 보강, 형식 통일, 번역 같은 용도입니다. 관련 PR [#3191](https://github.com/QwenLM/qwen-code/pull/3191)

**이렇게 쓸 수 있습니다:**
- 짧은 사용자 메시지에 프로젝트 컨텍스트를 자동으로 채워 넣음
- 팀 환경에서 메시지 형식과 규약을 통일
- 재작성 규칙을 커스터마이즈해 각자 업무 요구에 맞춤

### 컨텍스트 인지형 힌트

대화가 끝난 뒤 현재 컨텍스트를 보고 다음에 할 작업을 추천해 줍니다. 코드를 고치면 "테스트 돌려 볼까요" 하고 알려 주는 식으로, 아직 안 써 본 기능을 발견하는 데도 도움이 됩니다. 관련 PR [#2904](https://github.com/QwenLM/qwen-code/pull/2904)

**이렇게 쓸 수 있습니다:**
- 코드 수정을 끝내면 관련 후속 작업을 자동 안내
- 새 사용자에게 기능을 발견하고 배우기 쉬운 입구
- 대화 내용을 보고 관련 슬래시 명령어 추천

### /review 강화: 결정적 분석과 자동 수정 제안

`/review` 코드 검토에 결정적 분석(LLM에 의존하지 않는 정적 검사), 자동 수정 제안, 보안 강화 체크가 추가됐습니다. 검토 결과가 더 신뢰할 만해지고 수정 방안까지 바로 제시합니다. 관련 PR [#2932](https://github.com/QwenLM/qwen-code/pull/2932)

**이렇게 쓸 수 있습니다:**
- 검토 결과가 안정적입니다 — 같은 코드는 매번 같은 결론
- 문제를 찾으면 수정 제안이 바로 나오니 어떻게 고칠지 직접 고민하지 않음
- 흔한 보안 취약점을 자동으로 점검

<video class="mt-5" poster="https://img.alicdn.com/imgextra/i4/6000000008055/O1CN015vMexX29NFRbpMTA7_!!6000000008055-0-tbvideo.jpg" src="https://cloud.video.taobao.com/vod/K3xtn5O3mNeSt9Sqb5UVBAQIrKT5iYFHHHQWAP3Rv60.mp4" controls></video>

### 유휴 컨텍스트 미세 압축

대화가 유휴 상태일 때 불필요한 컨텍스트를 자동 정리해 Token 소비를 줄입니다. 긴 대화에서 효과가 크고, 컨텍스트 창을 손으로 관리하지 않아도 됩니다. 관련 PR [#3006](https://github.com/QwenLM/qwen-code/pull/3006)

**이렇게 쓸 수 있습니다:**
- 긴 대화에서 컨텍스트 창 한도에 그리 빨리 부딪히지 않음
- 필요 없어진 중간 결과를 자동 정리해 Token 절약
- 손대지 않아도 백그라운드에서 알아서 처리
