Qwen Code는 이번 주 v0.27.3부터 v0.28.0까지 세 개의 정식 버전을 출시했습니다.

**새 플래그십 Qwen4-Max를 씁니다.** Qwen의 차세대 플래그십 모델이며, 최신 Qwen Code에 연동됐습니다.

**새 세션은 기본으로 독립 사본에서 작업합니다.** 같은 프로젝트에서 여러 세션을 병렬로 열어도 각자 자기 워크트리를 수정합니다. 내 브랜치와 파일은 그대로입니다.

**작업 결과를 Feishu, WeCom, DingTalk 그룹으로 바로 보냅니다.** 그룹에 커스텀 봇을 추가하고 webhook 주소를 Web Shell에 넣으면, 알림과 예약 작업 결과가 그룹으로 전송됩니다.

## ✨ 새로운 기능

### 새 플래그십 Qwen4-Max 지원

Qwen4-Max는 Qwen의 차세대 플래그십 모델입니다. 11월 16일 정식 버전이 출시됐고, 텍스트, 이미지, 영상을 처리하며 복잡한 추론, 코딩, Agent 작업을 위해 만들어졌습니다.

Qwen Code는 이번 주 연동을 마쳤습니다. Bailian, Qianwen AI Platform, Qwen 구독 등 어느 경로로 접속하든 Qwen4-Max를 씁니다. 사고 깊이는 low, high, xhigh 세 단계이고 기본값은 high입니다. 사고는 끌 수도 있습니다.

이미지와 영상은 대화에 바로 보내 이해시킬 수 있습니다. Bailian과 Qianwen AI Platform 경로에는 token을 아끼는 설정 두 가지가 더 있습니다. 캐시 유지 시간을 기본 5분에서 1시간까지 늘리고, 이미지 정밀도를 낮출 수 있습니다.

이렇게 활용할 수 있습니다:

- 디자인 시안 스크린샷을 첨부해 페이지를 만들게 합니다
- 화면 녹화 영상을 보내 Bug 재현 단계를 정리하게 합니다
- 원인을 찾기 어려운 테스트 실패를 조사할 때 사고 강도를 높입니다

관련 PR: [#17513](https://github.com/QwenLM/qwen-code/pull/17513)

### 새 세션은 독립 워크트리에서 실행, 병렬 작업 간섭 없음

같은 프로젝트에서 여러 Web Shell 세션을 열면 각 세션이 독립 워크트리에서 작업합니다. 신뢰된 Git 워크스페이스에서 만드는 새 세션에 기본 적용됩니다. 워크트리는 같은 저장소의 별도 작업 사본입니다. 커밋 히스토리는 서로 통하고, 파일은 각자 수정합니다.

작업이 끝나면 결과를 두 가지 방식으로 거둡니다. 브랜치 메뉴에서 「여기에 브랜치 만들기」를 누르면 바로 정식 브랜치가 됩니다. 「로컬로 인계」를 누르면 변경을 원래 디렉터리로 가져옵니다.

워크트리 모드가 필요 없다면 `worktree.defaultForNewSessions`를 false로 두세요. 현재 브랜치에서 바로 작업합니다.

이렇게 활용할 수 있습니다:

- 여러 요구사항을 여러 세션에서 동시에 수정해도 서로 덮어쓰지 않습니다
- 나는 로컬에서 코드를 계속 쓰고 AI는 사본에서 수정해, 양쪽이 충돌하지 않습니다
- 두 세션에서 리팩터링 방안 두 가지를 각각 시도해 비교합니다

관련 PR: [#17228](https://github.com/QwenLM/qwen-code/pull/17228)

### 작업 결과를 Feishu, WeCom, DingTalk 그룹으로 바로 전송

Feishu, WeCom, DingTalk에 「Webhook(전송 전용)」 연결 방식이 하나씩 추가됐습니다. 그룹에 커스텀 봇을 추가하고 webhook 주소를 Web Shell 채널 관리에 넣으면, 알림, 작업 실행 결과, 예약 작업 결과가 Markdown 메시지로 그룹에 전송됩니다.

이 방식은 전송만 하고 그룹 메시지는 수신하지 않습니다. 그룹에서 AI와 대화하려면 각 플랫폼의 기존 봇 연결 방식을 씁니다.

이렇게 활용할 수 있습니다:

- 「매일 아침 9시 어제 병합된 PR 요약」 예약 작업을 만들면 결과가 Feishu 프로젝트 그룹으로 자동 전송됩니다
- AI가 매일 밤 회귀 테스트를 돌리고 결과를 WeCom 그룹으로 보내, 출근해서 바로 확인합니다
- 긴 작업에 완료 알림을 설정하면 작업이 끝날 때 DingTalk 그룹으로 자동 전송되어 동료도 진행 상황을 함께 봅니다

관련 PR: [#16804](https://github.com/QwenLM/qwen-code/pull/16804), [#17013](https://github.com/QwenLM/qwen-code/pull/17013), [#17224](https://github.com/QwenLM/qwen-code/pull/17224)

### Web Shell: 변경 규모 한눈에, 백그라운드 진행 추적

**세션 변경 규모를 개요로 봅니다.** 세션 작업을 전달하기 전, 몇 개 파일을 고쳤고 몇 줄을 추가·삭제했는지 확인하고 싶을 때가 있습니다. 오른쪽 패널에 「변경 개요」가 생겼습니다. 커밋하지 않은 변경, 묶인 PR별 변경, 나머지 커밋을 파일 목록과 줄 수로 나눠 표시합니다. 관련 PR: [#17378](https://github.com/QwenLM/qwen-code/pull/17378)

**백그라운드 작업은 배지를 눌러 확인합니다.** 입력창 위에 작은 배지가 생겼습니다. 실행 중인 워크플로, shell, 모니터, 백그라운드 Agent가 하나씩 차지하고, 누르면 해당 실행 화면으로 이동합니다. 관련 PR: [#16813](https://github.com/QwenLM/qwen-code/pull/16813)

**사이드바 세션을 워크스페이스와 날짜로 거릅니다.** 워크스페이스가 많아지면 사이드바에서 워크스페이스별로 필터링합니다. 세션은 활동 날짜별로 그룹화해, 범위를 좁힌 뒤 세션을 찾습니다. 관련 PR: [#17244](https://github.com/QwenLM/qwen-code/pull/17244), [#17447](https://github.com/QwenLM/qwen-code/pull/17447)

**그 외 개선.** 답변마다 훅이 몇 번 실행됐고 몇 번 막혔으며 얼마나 걸렸는지 봅니다 ([#17015](https://github.com/QwenLM/qwen-code/pull/17015), [#17327](https://github.com/QwenLM/qwen-code/pull/17327)). 러시아어 인터페이스 번역을 채웠습니다 ([#17414](https://github.com/QwenLM/qwen-code/pull/17414)). 세션 검색 결과가 더 명확해지고, 키보드 위아래 키로 선택합니다 ([#16779](https://github.com/QwenLM/qwen-code/pull/16779)).

## 📊 그 외 새로운 기능

**세션이 다른 워크스페이스로 작업을 넘깁니다.** Web Shell이 여러 워크스페이스를 관리할 때, 한 세션이 다른 워크스페이스에 작업을 맡깁니다. 그쪽 지시와 설정으로 작업하고, 결과를 돌려받으며, 이어서 추가 질문도 합니다. 처음 넘길 때는 사용자 확인이 필요합니다. 관련 PR: [#17454](https://github.com/QwenLM/qwen-code/pull/17454), [#17484](https://github.com/QwenLM/qwen-code/pull/17484)

**PR 묶기는 수동으로 추가하고, 밀린 댓글은 요약으로 받습니다.** 자동 묶기가 빠졌다면 `/pr <PR 번호 또는 링크>`를 입력해 직접 묶습니다. Web Shell 세션 개요와 사이드바 메뉴에도 「PR 묶기」 버튼이 있습니다. 서비스가 멈춰 있던 동안 묶인 PR에 쌓인 댓글은, 다시 시작할 때 요약 한 건으로 합쳐져 세션에 전달됩니다. 관련 PR: [#16877](https://github.com/QwenLM/qwen-code/pull/16877), [#17199](https://github.com/QwenLM/qwen-code/pull/17199)

**/memory 패널에서 설정을 바꿉니다.** 터미널 `/memory` 패널에서 자동 저장과 주기적 정리를 바로 켜고 끕니다. 사용자 수준과 프로젝트 수준 메모리 파일도 열어 편집합니다. 관련 PR: [#17213](https://github.com/QwenLM/qwen-code/pull/17213)

**Goals 페이지에서 모든 워크스페이스의 목표를 봅니다.** 여러 워크스페이스를 등록했다면 신뢰된 워크스페이스의 목표가 한 페이지에 모입니다. 시간순으로 정렬되고, 카드마다 소속 워크스페이스가 표시됩니다. 새 목표를 만들 때 어느 워크스페이스에 둘지 고릅니다. 관련 PR: [#17230](https://github.com/QwenLM/qwen-code/pull/17230)

**Mods 플러그인이 사고 내용도 바꿉니다.** 펼친 thinking 블록도 플러그인이 바꿉니다. 예를 들어 플러그인으로 thinking을 중국어로 번역합니다. 두 가지 터미널 인터페이스 모두 지원합니다. 관련 PR: [#16873](https://github.com/QwenLM/qwen-code/pull/16873), [#17443](https://github.com/QwenLM/qwen-code/pull/17443)

**Web Shell이 일반 HTTP에서도 정상 동작합니다.** 다른 PC에서 `http://<PC IP>:<포트>`로 Web Shell에 접속하면 터미널 탭, 웹페이지 미리보기, 로컬 명령을 모두 씁니다. 관련 PR: [#17196](https://github.com/QwenLM/qwen-code/pull/17196)

**GitLab 채널을 Web Shell에서 설정합니다.** 저장소 화이트리스트가 group/subgroup/project 같은 다단계 프로젝트 경로를 지원합니다. 관련 PR: [#16845](https://github.com/QwenLM/qwen-code/pull/16845)

## 👏 사용성 개선

**컨텍스트 압축 후에도 최근 전체 작업은 그대로 남습니다.** 대화가 길어져 압축이 일어나면 가장 최근 작업과 결과는 원형 그대로 유지하고, 그 이전 기록만 요약합니다. 관련 PR: [#17141](https://github.com/QwenLM/qwen-code/pull/17141)

**브랜치 전환이 커밋하지 않은 변경에 막히면 페이지에서 바로 처리합니다.** stash 또는 폐기를 골라 바로 전환합니다. 관련 PR: [#17364](https://github.com/QwenLM/qwen-code/pull/17364)

**Goals 카드 상태를 한눈에 구분합니다.** 실행 중은 파란색, 처리 대기는 호박색입니다. 상한을 설정한 목표는 라운드, token, 시간 진행 막대를 표시합니다. 세션 안의 목표 긴 텍스트는 한 줄로 접힙니다. 관련 PR: [#17349](https://github.com/QwenLM/qwen-code/pull/17349), [#17133](https://github.com/QwenLM/qwen-code/pull/17133)

**사용량 대시보드가 더 빨리 열립니다.** Web Shell 상태 페이지의 사용량 대시보드입니다. 관련 PR: [#17239](https://github.com/QwenLM/qwen-code/pull/17239)

**선택 팝업에서 현재 단계를 강조 표시합니다.** 사고 깊이 팝업에서 현재 선택된 단계를 바로 알아봅니다. 모델 목록과 실행 모드 선택도 같습니다. 관련 PR: [#16622](https://github.com/QwenLM/qwen-code/pull/16622)

**세션 이름 변경이 즉시 반영됩니다.** 확인하면 새 제목이 바로 표시됩니다. 관련 PR: [#17006](https://github.com/QwenLM/qwen-code/pull/17006)
