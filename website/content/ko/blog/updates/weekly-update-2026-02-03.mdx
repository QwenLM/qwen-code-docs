이번 주에 v0.8.1, v0.8.2 정식 버전과 v0.9.0 프리뷰 버전을 출시했습니다. LSP 지원, batch-runner 배치 평가 도구, 통합 UI 아키텍처, 일본어와 포르투갈어가 새로 추가됐습니다.

- 정식 버전 2개(v0.8.1, v0.8.2)와 프리뷰 버전 1개(v0.9.0)를 출시했습니다. 핵심 이슈 5개 이상을 고치고 새 기능 여럿을 담았습니다
- TypeScript SDK v0.1.4를 출시했습니다. SDK의 포지션은 CodeAgent as a Service입니다
- 전체 Star 수가 17,984에 도달했고, 지난 금요일 GitHub Trending Ranking 10위에 올랐습니다

## ✨ 새로운 기능

### Extension 확장 시스템 도입

Qwen Code에 새로운 Extension 확장 시스템이 들어왔습니다. prompts, MCP servers, subagents, skills, 커스텀 명령어를 한 덩어리로 묶어 관리할 수 있습니다. 특히 Gemini CLI Extensions Gallery와 Claude Code Marketplace의 플러그인을 Qwen Code에 바로 설치해 쓸 수 있습니다!

Git 저장소, 로컬 경로, Claude Code Marketplace, Gemini CLI Extensions Gallery 등 여러 소스에서 설치할 수 있습니다.

**사용 가능한 Extension 관리 명령어:**

| 명령어 | 설명 |
|------|------|
| `/extensions` 또는 `/extensions list` | 설치된 확장 전체 목록 |
| `/extensions install <source>` | 확장 설치 (git URL, 로컬 경로, 앱 마켓 지원) |
| `/extensions uninstall <name>` | 지정한 확장 제거 |
| `/extensions enable <name>` | 확장 활성화 |
| `/extensions disable <name>` | 확장 비활성화 |
| `/extensions update <name>` | 지정한 확장 업데이트 |
| `/extensions update --all` | 모든 확장 업데이트 |
| `/extensions detail <name>` | 확장 상세 정보 확인 |
| `/extensions explore [source]` | 확장 마켓 페이지 열기 |

### LSP 지원 추가

Language Server Protocol(LSP)을 기본적으로 지원하게 되어, 한 단계 높은 코드 이해 능력을 갖추게 됐습니다. AI agent가 텍스트 검색에 머무르지 않고 코드의 의미를 읽고 작업합니다.

`qwen --experimental-lsp`로 시작할 수 있습니다. 관련 PR: [#1401](https://github.com/QwenLM/qwen-code/pull/1401)

![](https://gw.alicdn.com/imgextra/i1/O1CN01kxCAnu1c0SPDCZsUt_!!6000000003538-2-tps-1694-948.png)

### batch-runner 배치 평가 도구 추가

Python 기반 동시 실행 도구를 추가했습니다. 격리된 git worktree를 써서 Qwen Code 작업을 여러 개 나란히 돌립니다. 여러 모델을 대상으로 여러 작업을 한 번에 시험하고 벤치마크를 돌릴 수 있어 효율적입니다. 함께 돌린 결과물과 trajectory를 모두 로컬에 저장하고 온라인으로 볼 수 있습니다.

관련 PR: [#1640](https://github.com/QwenLM/qwen-code/pull/1640)

![](https://gw.alicdn.com/imgextra/i1/O1CN01u4j9r41kwde3UBP5X_!!6000000004748-2-tps-3372-1026.png)

### 통합 UI 아키텍처, `@qwen-code/webui`

VSCode IDE Companion의 UI를 공용 패키지 `@qwen-code/webui`로 뽑아내 통합 UI 아키텍처를 도입했습니다. 이제 VSCode, Chrome 플러그인, 웹 인터페이스, Share 기능 등 여러 플랫폼에서 같은 UI 컴포넌트를 재사용할 수 있습니다.

관련 PR: [#1543](https://github.com/QwenLM/qwen-code/pull/1543)

![](https://gw.alicdn.com/imgextra/i3/O1CN01TCL20a1z4KvCdwzf4_!!6000000006660-2-tps-2002-1222.png)

커뮤니티의 힘으로 일본어와 포르투갈어가 추가됐습니다. 두 지역 사용자가 qwen을 처음 설치하면 그 언어가 UI 표시 언어와 LLM 출력 언어로 자동으로 설정됩니다.
