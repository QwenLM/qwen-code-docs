Qwen Code는 이번 주 v0.26.4부터 v0.26.7까지 네 개의 정식 버전을 출시했습니다.

**원격 연결에 독립 스위치가 생겼습니다.** 이제 **설정 → 연결**에서 **원격 연결 허용**을 켜면, 같은 네트워크 안에 있는 다른 PC에서 이쪽으로 붙을 수 있습니다.

**GitHub 이벤트가 세션을 자동으로 진행합니다.** 채널에 저장소를 연결해 두면 새 커밋, 새 리뷰, CI 실패 같은 이벤트가 그 PR에 묶인 세션으로 바로 흘러 들어갑니다.

**Web Shell 세션 상태가 더 선명해졌습니다.** 채널 이벤트를 한곳에서 모아 보고, 사이드바에서 어떤 세션이 돌고 있고 어떤 세션이 기다리고 있는지 한눈에 알 수 있습니다.

## ✨ 새로운 기능

### 원격 연결: 같은 네트워크에서 다른 기기로 이어서 작업하기

여러 대의 Qwen Code를 한 페이지로 연결할 때, 지금까지는 연결 대상 쪽을 `--hostname 0.0.0.0` 플래그로 시작해야 했습니다. 이제 PC들이 같은 네트워크에 있을 때 **설정 → 연결**에 주소와 Bearer token만 넣으면 다른 PC로 연결됩니다.

이번 주 **설정 → 연결**에 **원격 연결 허용** 스위치가 생겼습니다. 켜면 연결 주소와 Bearer token이 생성되고, 다른 PC에서 입력하면 재시작 없이 바로 붙습니다. 필요 없을 땐 언제든 끄면 됩니다. 관련 PR: [#15887](https://github.com/QwenLM/qwen-code/pull/15887), [#16199](https://github.com/QwenLM/qwen-code/pull/16199)

이렇게 활용할 수 있습니다:

- PC를 바꿔서 기존 대화를 그대로 이어갑니다
- 자리를 비운 뒤 원격으로 후속 질문에 답하거나 승인을 처리합니다
- 임시로 원격 접근을 열고, 끝나면 설정에서 닫습니다

### GitHub 저장소 이벤트가 세션으로 자동 흘러 들어옵니다

채널에 GitHub 저장소를 연결한 뒤, 새 커밋, 새 리뷰, CI 실패 같은 이벤트가 생기면 그 PR에 묶인 세션으로 자동 전달됩니다. Qwen Code는 이를 받아서 이어서 처리합니다 — 빌드가 깨졌으면 로그를 읽고 고치러 가는 식입니다. 답변은 기본적으로 비공개이고, 확인해야 PR 아래에 달립니다. 관련 PR: [#16117](https://github.com/QwenLM/qwen-code/pull/16117), [#16258](https://github.com/QwenLM/qwen-code/pull/16258)

채널 편집기에서 GitHub 저장소 접근 권한, @ 동작, 알림 빈도를 바로 설정할 수 있어서 설정 파일을 직접 편집할 필요가 없어졌습니다. 이벤트에 언급된 PR과 Issue 번호는 자동으로 클릭 가능한 링크로 바뀝니다. 관련 PR: [#16149](https://github.com/QwenLM/qwen-code/pull/16149), [#16096](https://github.com/QwenLM/qwen-code/pull/16096), [#16226](https://github.com/QwenLM/qwen-code/pull/16226)

이렇게 활용할 수 있습니다:

- PR의 CI가 깨지면 실패 로그가 바로 세션으로 들어오니 직접 찾아보지 않아도 됩니다
- 동료가 PR에 리뷰를 남기면 그 의견이 채팅 화면에 나타납니다
- 새 저장소를 추적하려면 편집기에 주소만 넣으면 됩니다

### Web Shell: 채널 이벤트와 세션 상태를 화면에서 더 선명하게

**채널 이벤트를 한곳에서 모아 봅니다.** 채널에서는 매일 여러 일이 일어납니다 — GitHub에 새 커밋, 예약 작업 완료, 세션의 새 응답 등. 이제 채널 페이지에 '이벤트' 칸이 생겨 모든 활동을 시간순으로 정렬해 보여 줍니다. 채널별로 필터할 수 있고, 타임라인은 스스로 갱신됩니다. 관련 PR: [#16106](https://github.com/QwenLM/qwen-code/pull/16106)

**Token 사용량 패널에서 요청별로 분리해 봅니다.** 전에는 유형별 총량만 표시됐지만, 이제 요청마다 따로 뜯어서 봅니다 — 출력 속도, 첫 응답까지 걸린 시간, 성공/실패 여부. 모델마다 다른 색으로 구분되고, 항목을 펼치면 실패 원인도 나옵니다. 관련 PR: [#16108](https://github.com/QwenLM/qwen-code/pull/16108), [#16111](https://github.com/QwenLM/qwen-code/pull/16111)

**사이드바 세션에 상태 표식이 생겼습니다.** 전에는 사이드바의 세션 목록이 이름만 나열돼서 안에서 무슨 일이 일어나는지 알 수 없었습니다. 이제 각 세션 옆에 상태 표식이 붙습니다 — 돌고 있으면 회전 아이콘, 승인을 기다리면 주황색 알림, 오류가 나면 빨간 줄. 표식을 펼치면 누가 기다리는지, 어떤 프롬프트에 방금 답했는지 보입니다. 읽지 않은 메시지 수도 표시되고, 한 번에 모두 읽음 처리하거나 보관할 수 있습니다. 관련 PR: [#16022](https://github.com/QwenLM/qwen-code/pull/16022)

**세션을 나란히 띄웁니다.** 세션 오른쪽 클릭 메뉴에 '분할 화면에 추가'가 생겨서, 세션 두 개를 좌우로 펼쳐 놓고 비교하며 볼 수 있습니다. 관련 PR: [#15956](https://github.com/QwenLM/qwen-code/pull/15956)

**그 외 개선.** Workflow 모드 스위치가 입력창 옆 '+' 메뉴로 들어갔고, 켜면 탭이 생겨서 끌 수 있습니다 ([#16107](https://github.com/QwenLM/qwen-code/pull/16107), [#15779](https://github.com/QwenLM/qwen-code/pull/15779)). 이미지 주소를 입력창에 붙이면 자동으로 첨부 파일이 되고, 스크린샷도 바로 붙여 넣을 수 있습니다 ([#16179](https://github.com/QwenLM/qwen-code/pull/16179)).

## 📊 그 외 새로운 기능

**인터랙티브 카드가 기본 켜짐입니다.** 전에는 설정에서 직접 켜야 했지만, 이제 설치하면 바로 쓸 수 있습니다 — 대출 계산이나 대안 비교를 시키면 대화 중에 

슬라이더를 움직여 결과를 바로 봅니다. 값을 맞추고 '유지'를 누르면 그대로 대화로 돌려보내 이어서 물어볼 수 있습니다. 관련 PR: [#15856](https://github.com/QwenLM/qwen-code/pull/15856)

**웹에서 받은 프로젝트는 신뢰 확인 후에만 hooks를 실행합니다.** 낯선 프로젝트에 포함된 hooks, 권한 규칙, 언어 서버는 확인 대화상자가 뜨고 '신뢰'를 눌러야 적용됩니다. PC에서 직접 만든 로컬 프로젝트는 영향받지 않습니다. 관련 PR: [#16182](https://github.com/QwenLM/qwen-code/pull/16182), [#16196](https://github.com/QwenLM/qwen-code/pull/16196)

**/verify-pr이 Docker 안에서 신뢰하지 않는 코드를 검증합니다.** 명령 한 줄로 로컬 컨테이너를 띄워 PR 코드를 넣고 검증을 돌립니다. 모델 키는 사용자 PC에 남고 컨테이너로 넘어가지 않습니다. 관련 PR: [#16077](https://github.com/QwenLM/qwen-code/pull/16077)

**데스크톱 앱이 Fedora 44와 RHEL 10을 지원합니다.** 해당 시스템 사용자는 GitHub Releases에서 rpm 패키지를 바로 받아 설치하면 됩니다. 관련 PR: [#16060](https://github.com/QwenLM/qwen-code/pull/16060)

**QQ 그룹 관리도 AI에 맡깁니다.** 채널이 자신의 관리 도구를 세션에 노출해서, 메시지 철회, 멤버 추방, 가입 승인 같은 그룹 관리를 AI가 대신 수행합니다. 어떤 도구를 쓸지는 채널 설정에서 `moderationTools`로 제어합니다. 관련 PR: [#14348](https://github.com/QwenLM/qwen-code/pull/14348)

**Managed Agent를 Helm 명령 한 줄로 처음부터 배포합니다.** Helm chart를 설정하면 MySQL과 게이트웨이가 함께 준비됩니다. 관련 PR: [#15492](https://github.com/QwenLM/qwen-code/pull/15492)

**보관한 대화를 설정에서 바로 복원합니다.** 설정 → 보관으로 들어가면 각 항목 옆에 '복원'과 '내보내기' 버튼이 생겼습니다. 세션으로 이동하지 않고 바로 복원할 수 있습니다. 관련 PR: [#15872](https://github.com/QwenLM/qwen-code/pull/15872)

**스킬 타이핑 중에 남은 인자 힌트가 뜹니다.** `/qwencode-weekly`까지 치면 그 뒤에 넣을 인자가 무엇인지 계속 떠 있고, 하나를 채우면 다음 인자로 힌트가 줄어듭니다. 관련 PR: [#15930](https://github.com/QwenLM/qwen-code/pull/15930)

**업데이트 명령에 버전 지정을 지원합니다.** `qwen update --target-version <버전 번호>`로 특정 버전을 바로 설치합니다. npm registry에서 새 버전을 먼저 확인할 필요 없고, 다운그레이드나 같은 버전 재설치도 됩니다. 관련 PR: [#11486](https://github.com/QwenLM/qwen-code/pull/11486)

## 👏 사용성 개선

**/autofix-pr이 더 안정적으로: main에 뒤처지면 스스로 병합하고, 현재 checkout에서 함께 작업하며, 관리할 라운드 수를 명시합니다.** 브랜치가 main보다 뒤처져 CI가 빨간불이면 먼저 main을 병합한 뒤 검사를 다시 돌려서 수동 rebase를 생략합니다. `--in-place`를 붙이면 현재 checkout 안에서 작업하므로 옆에서 함께 보고 고칠 수 있습니다. PR에 `@qwen-code /takeover for N`이라고 쓰면 몇 라운드까지 관리할지 정하고, 끝나면 스스로 손을 뗍니다. 관련 PR: [#15922](https://github.com/QwenLM/qwen-code/pull/15922), [#15929](https://github.com/QwenLM/qwen-code/pull/15929), [#15388](https://github.com/QwenLM/qwen-code/pull/15388)

**긴 답변을 스크롤로 봅니다.** `/btw` 답변이 길어지면 이제 스크롤 막대가 있는 고정된 영역에 표시됩니다. 마우스 휠, 키보드 위아래 키, PageUp/PageDown으로 넘길 수 있습니다. 관련 PR: [#15982](https://github.com/QwenLM/qwen-code/pull/15982)

**DeepSeek V4, qwen4, latest-series 계열 모델도 사고 깊이를 설정할 수 있습니다.** 이 세대 모델에는 선택 가능한 사고 깊이가 없었고, Alibaba 프록시를 거치는 DeepSeek V4.1 Flash에는 기본값도 없었습니다. 이제 모델별로 각 단계가 지정되며, 사고를 끄는 것은 기존 스위치를 그대로 사용합니다. 자세한 내용은 PR [#15987](https://github.com/QwenLM/qwen-code/pull/15987), [#15828](https://github.com/QwenLM/qwen-code/pull/15828)

**Web Shell 한 번 업데이트가 pnpm, yarn, bun도 지원합니다.** 전에는 npm만 한 번에 업데이트할 수 있었지만, 이제 여러 패키지 관리자 모두 한 번에 올릴 수 있습니다. 지원하지 않는 환경이면 수동 단계를 안내합니다. 관련 PR: [#15849](https://github.com/QwenLM/qwen-code/pull/15849)

**상태 표시줄에서 백그라운드 agent 개수를 봅니다.** 데스크톱과 Web Shell 하단의 작업 표식에 현재 실행 중인 agent 수가 실시간으로 표시됩니다. 관련 PR: [#14002](https://github.com/QwenLM/qwen-code/pull/14002)

**코드 점프 실패 시 분명한 이유를 알려 줍니다.** 사용 가능한 언어 서버가 없을 때, 전에는 빈 결과만 조용히 반환했지만 이제 현재 사용 가능한 언어 서버가 없다고 알려 줍니다. 관련 PR: [#15946](https://github.com/QwenLM/qwen-code/pull/15946)

**컨텍스트 메모리 파일을 패널에서 펼쳐 봅니다.** AGENTS.md 같은 파일을 클릭하면 내용을 바로 볼 수 있습니다. 관련 PR: [#15932](https://github.com/QwenLM/qwen-code/pull/15932)

**워크스페이스가 없는 세션 목록은 비었을 때 칸 전체를 숨깁니다.** 전에는 빈 칸이 공간만 차지했지만, 이제는 고정된 칸처럼 비어 있으면 칸 전체가 표시되지 않습니다. 관련 PR: [#15916](https://github.com/QwenLM/qwen-code/pull/15916)
