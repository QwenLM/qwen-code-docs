Qwen Code는 이번 주에 v0.22.3, v0.23.0 두 개의 정식 버전을 출시하고 PR 320개 이상을 병합했습니다.

**AI의 말투를 고를 수 있게 됐습니다.** Concise(간결), Proactive(능동), Explanatory(설명), Learning(학습) 네 가지 내장 출력 스타일 중에서 선택할 수 있고, 대화 중에도 언제든 전환할 수 있습니다.

**DingTalk 봇이 파일을 보냅니다.** AI가 작성한 보고서나 문서를 첨부 파일로 대화에 바로 보내 줘서, 스마트폰에서 바로 열어볼 수 있습니다.

**Web Shell에 내장 터미널이 생겼습니다.** 대화 옆에서 바로 명령을 실행할 수 있고, 탭마다 독립 터미널이라 서로 방해하지 않습니다.

## ✨ 새로운 기능

### 출력 스타일: AI의 말투를 고른다

사람마다 AI 응답에 바라는 게 다릅니다. 군말 없이 결과만 바로 보고 싶은 사람도 있고, 작업하면서 설명도 곁들여 배우길 원하는 사람도 있습니다. 이번 주부터 출력 스타일을 고를 수 있게 됐습니다. 네 가지 스타일이 내장되어 있습니다:

- **Concise(간결)**: 결론부터 말하고, 서두나 과정 설명은 붙이지 않습니다
- **Proactive(능동)**: 바로 작업을 시작하고, 확신이 서지 않으면 가정을 밝힌 채 계속 진행하며 거듭 묻지 않습니다
- **Explanatory(설명)**: 코드를 수정하면서 관련 코드도 함께 설명해 줍니다
- **Learning(학습)**: 작업하면서 가르쳐 주고, 작은 결정은 직접 내리도록 남겨 둡니다

선택 방법은 세 가지입니다. `settings.json`에서 `general.outputStyle`을 설정하면 계속 적용되고, 실행할 때 `--output-style`을 지정하면 한 번만 적용되며, 대화 중에는 `/output-style`로 언제든 전환할 수 있습니다. 다음 응답부터 바로 새 스타일이 적용됩니다.

이렇게 활용할 수 있습니다:

- 결과만 보고 싶을 때는 Concise로 전환하면 AI가 결론만 바로 말합니다
- 코드를 배우고 싶을 때는 Explanatory나 Learning으로 전환하면 AI가 수정하면서 설명해 줍니다
- 대화 중간에 출력 스타일을 바꾸고 싶다면 `/output-style`로 언제든 전환할 수 있습니다

### Goal: AI가 목표 작성, 확인만 하면 시작

지난주에는 `/goal-draft`로 AI가 목표를 대신 작성해 줬는데, 이번 주에는 초안 작성 후 AI가 완성된 목표를 확인 대화상자로 보여 주고, 확인하면 바로 Goal 실행을 시작합니다.

여러 라운드가 걸리고 완료 기준이 명확한 작업은, AI가 끝까지 챙길 가치가 있다고 스스로 판단해 목표를 작성한 뒤 물어봅니다. 이 동작이 필요 없다면 설정에서 통째로 끌 수 있습니다. 현재는 터미널 대화 세션에서 사용할 수 있으며, Web Shell 지원은 준비 중입니다.

지난주에는 Goal에 token 예산이 생겼고, 이번 주에는 예산 크기를 직접 정할 수 있습니다. 설정에서 `model.goalTokenBudget`을 수정하면 되며, 늘리거나 줄이는 것 모두 가능하고, -1로 설정하면 상한이 없습니다.

이렇게 활용할 수 있습니다:

- AI가 목표를 작성해 주고, 확인만 누르면 바로 시작합니다
- 완료 기준이 명확한 긴 작업은 AI가 먼저 끝까지 챙기자고 제안합니다
- 예산을 늘리고 줄이며 더 세밀하게 제어할 수 있습니다

관련 PR: [#10171](https://github.com/QwenLM/qwen-code/pull/10171), [#10543](https://github.com/QwenLM/qwen-code/pull/10543)

### 코드 리뷰: 수정 라운드는 변경 사항만, 리뷰 깊이는 기억

**수정 라운드는 변경된 파일만 리뷰합니다.** AI가 리뷰하고 수정하고, 수정한 것을 다시 리뷰하는 반복 과정에서 이후 라운드는 변경된 파일만 리뷰합니다. 이미 리뷰했고 변경되지 않은 파일은 이전 라운드의 결론을 그대로 사용해, token도 시간도 절약됩니다.

**리뷰 깊이를 기억합니다.** `--effort`로 리뷰 깊이를 명시적으로 지정하면, 같은 프로젝트에서 다음에 `/review`를 그냥 실행해도 그 깊이가 유지됩니다.

**오래 걸리는 작업도 진행 상황을 알려줍니다.** 자동 수정 라운드가 오래 걸릴 때, PR 페이지의 상태 댓글이 약 10분마다 한 번씩 업데이트되어 실행 시간과 최근 활동 시각을 알려줍니다. 실제로 동작 중인지 한눈에 알 수 있습니다.

**반복되는 문제는 알려줍니다.** 같은 파일의 심각한 문제가 수정했다가 다시 나타나면, 리뷰 결론에서 해당 문제의 이력을 명확히 표시해 다른 접근을 고려하라고 알려줍니다.

이렇게 활용할 수 있습니다:

- 로컬에서 한 판 고치고 한 판 리뷰해도, 매 라운드 변경된 파일만 다시 리뷰하므로 몇 라운드를 연속으로 돌려도 token이 많이 들지 않습니다
- 같은 프로젝트에서 `/review --effort high`을 한 번 실행해 두면, 이후에는 `/review`만 입력해도 같은 깊이가 적용됩니다
- PR에 걸어 둔 자동 수정이 몇 시간 동안 돌아가도, 상태 댓글이 10분마다 업데이트되어 제대로 동작 중인지 한눈에 알 수 있습니다

관련 PR: [#9659](https://github.com/QwenLM/qwen-code/pull/9659), [#9883](https://github.com/QwenLM/qwen-code/pull/9883), [#9771](https://github.com/QwenLM/qwen-code/pull/9771), [#10010](https://github.com/QwenLM/qwen-code/pull/10010)

### DingTalk 봇이 파일을 보냅니다

DingTalk의 Channel 봇은 그동안 텍스트와 이미지만 보낼 수 있었습니다. AI가 작성한 보고서나 정리한 문서는 내용을 메시지에 붙여 넣을 수밖에 없어서, 파일 자체가 필요하면 컴퓨터로 돌아가야 했습니다. 이제 봇이 파일을 첨부로 보낼 수 있습니다. AI가 보고서를 작성하면 파일을 DingTalk 대화로 바로 보내 줘서, 스마트폰에서 바로 열어보고 다운로드할 수 있습니다. 봇이 먼저 메시지를 보낼 때도 파일을 함께 보낼 수 있습니다.

이렇게 활용할 수 있습니다:

- AI가 작성한 보고서와 문서를 첨부 파일로 DingTalk에 바로 전송
- 스마트폰에서 바로 열어보고 다운로드
- 봇이 먼저 보고할 때도 파일 첨부 가능

관련 PR: [#10893](https://github.com/QwenLM/qwen-code/pull/10893)

### Web Shell: 내장 터미널, 더 꼼꼼해진 세션과 워크스페이스 관리

**대화 옆에서 바로 터미널을 엽니다.** Web Shell로 작업하다 보면 직접 명령 몇 개를 실행하고 싶을 때가 많습니다. 서버를 띄워 결과를 확인하거나 빌드 결과를 점검하는 식으로요. 이제 오른쪽 패널에서 터미널을 열어 대화 옆에서 바로 실행할 수 있습니다. 각 탭은 독립된 터미널이며, 열면 현재 워크스페이스 디렉터리로 시작합니다. 한 탭에서 오래 실행되는 서비스를 띄워 두고 다른 탭에서 평소처럼 명령을 입력해도 서로 영향을 주지 않습니다.

![Web Shell 내장 터미널](https://img.alicdn.com/imgextra/i2/O1CN01gLcBvJPyiWE7nW9B_!!6000000004154-2-tps-3841-2160.png)

**프로젝트 없이도 작업을 만들 수 있습니다.** 새 작업을 만들 때 어떤 워크스페이스에도 속하지 않는 세션을 만들 수 있습니다. 가벼운 질문이나 특정 프로젝트와 무관한 일을 처리할 때 유용합니다. 이런 세션은 별도의 목록으로 관리되며, 이름 변경, 내보내기, 아카이브를 모두 지원합니다.

**대화 내용으로 세션을 찾습니다.** 세션 제목이 기억나지 않으면 당시 나눈 대화 내용을 바로 검색해 찾을 수 있습니다. 일치하는 세션 아래에는 검색에 걸린 메시지의 발췌도 함께 표시됩니다.

**예약 작업에 깨끗한 컨텍스트를 제공합니다.** 예약 작업이 반복 실행될 때 매번 새 세션을 만들도록 선택할 수 있어, 실행마다 컨텍스트가 독립적으로 유지됩니다. 같은 작업에서 생긴 세션은 자동으로 하나의 그룹으로 묶여 목록이 어지러워지지 않습니다.

**워크스페이스 상태를 한눈에 파악합니다.** 새로 추가된 워크스페이스 개요 패널이 모든 워크스페이스를 한 페이지에 나열합니다. 실행 중인 세션 수, MCP 연결 상태, 현재 브랜치, 커밋되지 않은 변경 사항 여부까지 알 수 있고, 각 행에서 바로 새 작업을 만들 수 있습니다.

![워크스페이스 현황 패널](https://img.alicdn.com/imgextra/i3/O1CN01bu5Xi34eXdD7nW9B_!!6000000001080-2-tps-3841-2160.png)

**세션 개요가 더 쓰기 편해졌습니다.** 세션 개요 페이지가 정렬, 필터, 페이지네이션을 지원하는 표로 바뀌었고, 창이 좁을 때는 가로 스크롤을 지원하며 주요 열은 고정됩니다. 진입은 사이드바 하단의 작은 아이콘 중 그리드 아이콘이며, 마우스를 올리면 '세션 개요'로 표시됩니다.

**스마트폰 페어링이 오른쪽 상단으로 이동했습니다.** 대화 오른쪽 상단에 QR 코드 아이콘이 있는데, 누르면 페어링 코드가 표시되고 스마트폰으로 스캔하면 컴퓨터의 이 세션에 연결되어 스마트폰에서 AI에게 작업을 지시할 수 있습니다(이 기능은 Local Control이라고 합니다). 기능이 꺼져 있으면 눌러도 바로 설정 페이지로 이동해 켤 수 있습니다.

**작업 전에 Git 상태를 먼저 확인합니다.** Update Project, Commit, Push 옆에 이제 상태 안내가 표시됩니다. 커밋이 몇 개 뒤처지거나 앞서 있는지, 커밋되지 않은 변경 사항이 몇 개인지 알 수 있습니다. 커밋되지 않은 변경 사항이 있을 때 프로젝트를 업데이트하려면, 먼저 스태시한 뒤 업데이트하거나 변경 사항을 포기하고 업데이트하는 것 중 고를 수 있습니다.

이렇게 활용할 수 있습니다:

- 대화 옆에서 바로 명령 실행
- 나눴던 대화 내용을 검색해 지난 세션 찾기
- 모든 워크스페이스의 상태를 한눈에 파악

## 📊 그 외 새로운 기능

**워크플로를 실행 중에도 관리할 수 있습니다.** 실행 중인 워크플로의 진행 상황 확인, 일시 중지, 재개, 취소, 재실행을 지원하며, 취소는 즉시 적용됩니다. 관련 PR: [#10411](https://github.com/QwenLM/qwen-code/pull/10411), [#10468](https://github.com/QwenLM/qwen-code/pull/10468)

**메모리가 프로젝트와 개인으로 나뉩니다.** AI에게 무언가를 기억하라고 할 때 현재 프로젝트에 저장할지 개인 전역에 저장할지 지정할 수 있으며, 양쪽은 엄격하게 분리되어 서로 섞이지 않습니다. 관련 PR: [#9895](https://github.com/QwenLM/qwen-code/pull/9895)

**세션과 PR 연결이 더 꼼꼼해졌습니다.** 지난주에는 Web Shell Git 패널에서 만든 PR이 세션에 기록되도록 했는데, 이번 주에는 몇 가지가 더 보완됐습니다. PR 상태에 컬러 아이콘이 붙어 초록색은 진행 중, 보라색은 병합됨, 빨간색은 닫힘을 나타냅니다. issue 번호로도 해당 세션을 검색할 수 있고, 대화에서 AI에게 `gh pr create`를 실행해 만든 PR도 동일하게 기록됩니다. 관련 PR: [#9729](https://github.com/QwenLM/qwen-code/pull/9729), [#10258](https://github.com/QwenLM/qwen-code/pull/10258), [#10425](https://github.com/QwenLM/qwen-code/pull/10425), [#9739](https://github.com/QwenLM/qwen-code/pull/9739)

**Mem0 외부 메모리를 정식으로 사용할 수 있습니다.** Qwen Code를 Mem0 메모리 서비스에 연결하려면, 이제 공식 확장 패키지를 설치하고 설정만 하면 됩니다. 관련 PR: [#10653](https://github.com/QwenLM/qwen-code/pull/10653), [#10634](https://github.com/QwenLM/qwen-code/pull/10634)
