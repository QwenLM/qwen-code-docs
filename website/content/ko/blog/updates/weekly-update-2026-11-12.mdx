Qwen Code는 이번 주 v0.26.8부터 v0.27.2까지 다섯 개의 정식 버전을 출시했습니다.

**Qwen 구독 계정으로 로그인하면 바로 씁니다.** CLI, VS Code, 데스크톱 모두 Plus/Pro 구독으로 로그인해 구독에 포함된 모델로 대화하고 웹 검색을 씁니다.

**WeChat, QQ, Email Channel 모두 Web Shell에서 설정합니다.** WeChat과 QQ는 페이지에서 QR 코드를 스캔해 로그인하고, Email Channel은 서버 주소와 계정 정보만 넣으면 연결됩니다.

**GitHub 채널이 저장소 단위로 이벤트를 거릅니다.** 화이트리스트는 목록에 있는 저장소만 받고, 블랙리스트는 목록에 있는 저장소를 제외합니다.

## ✨ 새로운 기능

### Qwen Code, Qwen 구독 계정 로그인 지원

Qwen 계정에 Plus나 Pro 구독이 있다면 터미널, VS Code, 데스크톱에서 그 계정으로 로그인합니다. 터미널에서 `/auth`를 실행하고 Qwen 멤버십 계정을 선택한 뒤 브라우저에서 인증을 마치면 됩니다. 로그인하면 클라이언트가 구독으로 쓸 수 있는 모델을 불러오고, 내장 웹 검색도 그대로 씁니다.

이렇게 활용할 수 있습니다:

- 구독 모델을 바로 일에 쓰고, 사용량은 구독으로 청구됩니다
- 터미널, VS Code, 데스크톱에서 같은 계정으로 로그인하면 모델도 같습니다
- API를 따로 연결할 필요 없이 Qwen을 구독하면 Qwen Code에서 바로 씁니다

관련 PR: [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Qwen 구독 로그인 후 계정과 모델 목록](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### Web Shell에서 WeChat, QQ, Email Channel 설정

Web Shell 채널 관리에 WeChat, QQ, Email Channel 세 플랫폼이 추가됐습니다. WeChat과 QQ는 페이지에 QR 코드가 바로 뜨고, 휴대폰으로 스캔하면 로그인됩니다. Email Channel은 서버 주소와 계정 정보만 넣으면 됩니다. 이전에는 개인 WeChat을 터미널 명령으로, QQ와 Email Channel은 설정 파일을 직접 고쳐 연결했습니다. 이제 Telegram을 제외한 주요 채팅 플랫폼을 모두 Web Shell에서 설정합니다.

이렇게 활용할 수 있습니다:

- 휴대폰으로 Web Shell의 QR 코드를 스캔해 개인 WeChat 1:1 채팅에 연결하거나 QQ를 연동합니다
- 채널 관리에서 Email Channel을 추가하거나 편집하고, 어떤 발신자가 메일로 세션을 시작할지 정합니다
- 채널 페어링 취소까지 Web Shell에서 한 번에 관리합니다

관련 PR: [#16736](https://github.com/QwenLM/qwen-code/pull/16736), [#16724](https://github.com/QwenLM/qwen-code/pull/16724), [#16746](https://github.com/QwenLM/qwen-code/pull/16746)

### GitHub 채널, 저장소별 이벤트 필터

GitHub 채널은 저장소 이벤트를 세션으로 자동 전달합니다. 누군가 PR을 열거나 댓글을 달고 CI가 끝나면 Agent가 이어서 처리합니다. 연결만 하면 전부 받던 방식이라, 저장소가 많은 조직에서는 관련 없는 저장소까지 끼어들었습니다. 이제 범위를 고릅니다. 화이트리스트는 목록에 있는 저장소만 받고, 블랙리스트는 목록 밖의 모든 저장소를 받습니다. 제외된 이벤트는 건너뛰어서 세션에 들어가지 않고 처리도 차지하지 않습니다.

이렇게 활용할 수 있습니다:

- 조직에 저장소가 수백 개 있어도 내가 맡은 두 개만 목록에 넣으면 그 이벤트만 받습니다
- 요즘 안 보는 저장소는 블랙리스트에 넣고, 다시 맡을 때 목록에서 빼면 됩니다
- 관련 없는 저장소의 PR이 Agent 대기열을 차지하지 않아, 관심 있는 저장소가 더 빨리 처리됩니다

관련 PR: [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

### Web Shell: 문답과 사용량을 한눈에, 세션은 한꺼번에 정리

**문답 히트맵.** 며칠씩 돌아가는 긴 작업에서 특정 날의 문답을 다시 보려면 대화를 한참 올려야 했습니다. 이제 히트맵 버튼이 생겼습니다. 누르면 날짜별 달력이 뜨고, 색이 진할수록 그날 문답이 많았습니다. 날짜를 누르면 그날 첫 문답으로 바로 이동합니다. 관련 PR: [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**입력창 아래 사용량 막대.** 사용량을 보려면 Token 사용량 패널을 열어야 했습니다. 이제 입력창 아래에 숫자 한 줄이 표시됩니다 — 라운드 수, 출력 속도, 총 token, 캐시 적중률. 관련 PR: [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**세션 일괄 고정과 보관.** 사이드바 정리는 하나씩 누르거나 세션 개요로 가서 해야 했습니다. 이제 사이드바에 다중 선택 스위치가 생겼습니다. 세션을 고르고 한 번에 고정하거나 보관합니다. 관련 PR: [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**모르는 선택지는 「상세 질문」으로 묻습니다.** AI가 선택형 질문을 띄웠을 때 선택지가 어려우면 질문 패널의 「상세 질문」 버튼을 누릅니다. 별도 작업이 열려 각 선택지의 뜻과 차이, 영향, 추천을 설명합니다. 관련 PR: [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**그 외 개선.** 워크스페이스를 한 번에 전부 접거나 펼치고, 제목을 잡고 끌어 순서를 바꿉니다 ([#16197](https://github.com/QwenLM/qwen-code/pull/16197)). 백그라운드 작업이 승인을 기다리면 데스크톱 알림이 뜨거나 터미널이 울려서, 다른 창으로 옮겨 가도 놓치지 않습니다 ([#16800](https://github.com/QwenLM/qwen-code/pull/16800)). MCP 호출 같은 도구 카드는 펼치면 매개변수와 전체 결과가 바로 보입니다 ([#15435](https://github.com/QwenLM/qwen-code/pull/15435)). 스킬 페이지에서 ZIP 압축 파일을 바로 올려 스킬을 설치합니다 ([#16424](https://github.com/QwenLM/qwen-code/pull/16424)).

![Web Shell 사이드바 다중 선택과 입력창 아래 사용량 막대](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 그 외 새로운 기능

**예약 작업이 결과를 보낼 채널을 고릅니다.** Web Shell에서 예약 작업을 만들 때 결과를 어느 채널로 보낼지 지정합니다. 관련 PR: [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**QQ 그룹에 먼저 메시지를 보냅니다.** 예약 작업, webhook, 백그라운드 작업의 결과를 QQ 그룹에 먼저 보냅니다. 이전에는 QQ가 답장 창 안에서만 응답했습니다. 선택 스위치 `forwardBotMessages`를 켜면 그룹 안 다른 봇이 보낸 메시지도 세션으로 전달됩니다. 관련 PR: [#15635](https://github.com/QwenLM/qwen-code/pull/15635), [#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**파일 변경 hooks.** 로컬 세션에 `FileChanged` hook이 생겼습니다. 지켜보는 파일이나 디렉터리에서 생성, 수정, 삭제가 일어나면 설정한 hook이 실행됩니다. 다른 프로그램이 바꾼 파일도 알려 줍니다. 관련 PR: [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Mods 플러그인에 세 가지 능력 추가.** `$.store`는 플러그인 데이터를 세션 간에 저장합니다. `ui.render`는 터미널에 표시되는 답변 텍스트만 바꾸고, 저장되거나 복사되는 텍스트는 그대로입니다. `$.model.complete`는 일회성 텍스트 완성을 실행합니다. 관련 PR: [#16791](https://github.com/QwenLM/qwen-code/pull/16791), [#16794](https://github.com/QwenLM/qwen-code/pull/16794), [#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**PR에 묶인 세션은 새 댓글을 자동으로 받습니다.** 세션을 PR에 묶으면 PR의 새 댓글이 그 세션으로 자동 전달됩니다. 일반 댓글과 인라인 리뷰 댓글 모두 포함되고, @ 없이도 받습니다. 관련 PR: [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 사용성 개선

**/btw 곁질문은 이어 묻고, 여러 개를 동시에 던집니다.** 새 곁질문을 던지면 이전에 답한 곁질문이 함께 따라가서, 이전 답변에 이어 물을 수 있습니다. 여러 곁질문을 연달아 던져도 각자 답하고 서로 끊지 않습니다. 관련 PR: [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**시작할 때 AI에게 현재 Shell을 알려 줍니다.** 세션 시작 부분에 명령이 어떤 Shell에서 실행되는지(bash, cmd.exe 등) 명시합니다. AI가 시스템만 보고 문법을 추측하지 않아 Windows에서 명령 오류가 줄어듭니다. 관련 PR: [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**세션 자동 제목이 대화 언어를 따릅니다.** 중국어 대화에는 중국어 제목이 붙는 식으로, 언어별로 각자 생성됩니다. 관련 PR: [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Goal 검사 결과의 사유가 세션 언어를 따릅니다.** 통과나 반려 이유가 세션의 출력 언어로 표시됩니다. 관련 PR: [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**태국어, 라오스어, 크메르어, 버마어 후속 질문 제안은 해당 언어로 유지됩니다.** 이 언어로 대화하면 후속 질문 제안도 같은 언어로 생성됩니다. 관련 PR: [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**실험적 코드 인텔리전스(LSP)를 설정에서 켭니다.** 사용자 수준 설정에서 `tools.lspEnabled`를 true로 두면 켜집니다. 명령줄 플래그가 필요 없어서 데스크톱처럼 인자를 넘길 수 없는 클라이언트도 정의로 이동, 참조 찾기, 진단을 씁니다. 기본값은 꺼짐입니다. 관련 PR: [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**서브 Agent의 기본 실행 위치를 전역으로 정합니다.** `agents.defaultBackground`를 false로 두면 서브 Agent가 포그라운드에서 끝나기를 기다렸다가 결과를 현재 라운드에 바로 돌려줍니다. 채널이나 봇처럼 한 라운드 안에서 결과가 필요한 상황에 알맞습니다. 재시작해야 적용됩니다. 관련 PR: [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**Managed 세션은 여러 질문을 동시에 걸어 둡니다.** Managed 세션이 낸 여러 질문이 동시에 떠 있고, 순서에 상관없이 답할 수 있습니다. 관련 PR: [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**채널 이벤트에서 세션으로 바로 들어갑니다.** 채널 이벤트 타임라인의 항목을 누르면 해당 세션으로 바로 이동합니다. 관련 PR: [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
