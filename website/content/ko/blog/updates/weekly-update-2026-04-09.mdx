이번 주에 기능 버전 **v0.14.0**, **v0.14.2** 두 개와 버그 수정 버전 **v0.13.2**, **v0.14.1** 두 개를 릴리스했습니다.

v0.14.0은 규모가 큰 업데이트입니다:

- **Channels 시스템으로 Qwen Code가 터미널 밖으로 나갔습니다**. Telegram, WeChat, DingTalk 같은 플랫폼으로 원격 제어할 수 있습니다;
- Cron 예약 작업으로 AI가 시간표에 따라 반복 업무를 자동으로 처리합니다;
- Qwen 3.6 Plus 모델이 정식 출시됐습니다. v0.14.1에는 후속 제안, 상세/간결 모드 전환 같은 경험 개선이 들어왔습니다.
- v0.14.2에는 `/plan` 계획 모드 명령어, thinking block 라운드 간 유지, 적응형 출력 Token 업그레이드(기본 8K + 자동으로 64K까지 상향), 내장 bugfix 워크플로와 디버깅 스킬이 추가됐습니다.

## ✨ 새로운 기능

### Channels: DingTalk, Telegram, WeChat으로 Qwen Code 원격 제어

Qwen Code를 더 이상 터미널에서만 쓸 필요가 없습니다. Channels 시스템은 플러그인 방식으로 여러 플랫폼을 붙이며, 현재 Telegram, WeChat, DingTalk을 지원합니다. 모바일에서 Bot에게 메시지 한 통을 보내 서버에서 작업을 돌리게 할 수 있습니다.

**이렇게 쓸 수 있습니다:**

- 외출 중에는 Telegram으로 Qwen Code에 메시지를 보내 스크립트를 돌리거나 로그를 확인
- DingTalk 그룹에서 @봇을 호출해 팀의 코드 관련 작업을 처리
- WeChat에서 편하게 한 줄 보내 개발 환경을 원격으로 조작

### Cron 예약 작업: AI가 시간표대로 알아서 일합니다

Cron 도구가 새로 추가돼, 현재 세션에서 예약 반복 작업을 설정할 수 있습니다. AI가 지정한 시간표에 따라 자동으로 실행하니 지켜보고 있을 필요가 없습니다.

**이렇게 쓸 수 있습니다:**

- 30분마다 테스트 통과 여부를 자동으로 확인
- 매일 아침 최신 코드를 가져와 빌드를 한 번 돌림
- 로그 파일을 주기적으로 감시해 이상을 찾으면 알림

관련 PR [#2731](https://github.com/QwenLM/qwen-code/pull/2731)

<video class="mt-5" poster="https://img.alicdn.com/imgextra/i2/6000000002950/O1CN018Sepbk1Xf9Wjb2uR5_!!6000000002950-0-tbvideo.jpg" src="https://cloud.video.taobao.com/vod/VN0xFz-zPV1vvFzIuT6S3HUTFUX36x_JtySMTzAJYpE.mp4" controls></video>

**어떻게 켜나요**?

`~/.qwen/settings.json`에 다음을 추가합니다:

```json
{
	"experimental":{
		"cron": true
	}
}
```

### Qwen 3.6 Plus 모델 출시

Qwen 3.6 Plus가 Qwen Code에 정식 탑재됐고 무료로 쓸 수 있습니다. 코딩 작업에서 GPT-5, Claude 3.7 Sonnet에 맞먹는 성능을 내고, 특히 중문 이해와 긴 컨텍스트 처리에서 뚜렷하게 앞섭니다. 알리바바 클라우드 Bailian Coding Plan도 함께 출시됐습니다.

**이렇게 쓸 수 있습니다:**

- Qwen Code에서 최신 Qwen 3.6 Plus 모델을 바로 사용
- 하루 1000회 무료 호출, 100만 token 컨텍스트
- 중문 코딩 환경에서의 사용 경험이 더 좋음

### 후속 제안: AI가 일을 마치고 다음에 할 일을 알려 줍니다

AI가 작업을 끝내면 후속 제안 2~3개가 자동으로 나옵니다. '다음에 뭘 하지' 직접 고민하지 않아도, 클릭하면 바로 이어집니다.

**이렇게 쓸 수 있습니다:**

- 컴포넌트를 다 쓰면 AI가 '단위 테스트 추가할까요?'라고 제안 — 클릭하면 시작
- 버그를 고치면 AI가 '비슷한 부분도 확인할까요?'라고 제안 — 직접 떠올릴 필요 없음
- 다음 단계를 모르는 초보에게 제안이 곧 내비게이션

관련 PR [#2525](https://github.com/QwenLM/qwen-code/pull/2525)

![](https://gw.alicdn.com/imgextra/i3/O1CN01bduOSo1HBoIgKUkbq_!!6000000000720-2-tps-2208-1202.png)

**어떻게 켜나요**?

`~/.qwen/settings.json`에 다음을 추가합니다:

```json
{
	"ui":{
		"enableFollowupSuggestions": true
	}
}
```

제안 응답을 더 빠르게 받으려면 `/model --fast`로 경량 모델을 지정해 백그라운드 제안에만 쓰면 됩니다.

![](https://gw.alicdn.com/imgextra/i3/O1CN01RGAS8t22o5LA9v4OK_!!6000000007166-2-tps-1694-948.png)

### 서브 Agent 모델 분리: 작업마다 다른 모델로

이제 서브 Agent는 메인 Agent와 다른 모델을 쓸 수 있습니다. 메인 작업은 강력한 모델로 품질을 지키고, 하위 작업은 경량 모델로 속도를 내는 식입니다. 자유롭게 조합하면서 Token은 줄이고 품질은 떨어뜨리지 않습니다.

**이렇게 쓸 수 있습니다:**

- 메인 작업은 Qwen 3.6 Plus, 하위 작업은 경량 모델 — Token 소비는 줄이고 중요한 작업 품질은 유지
- 종류가 다른 하위 작업에 자동으로 가장 알맞은 모델을 배정

관련 PR [#2698](https://github.com/QwenLM/qwen-code/pull/2698)

<video class="mt-5" poster="https://img.alicdn.com/imgextra/i4/6000000000621/O1CN01uFmNW81GST5dMLGJA_!!6000000000621-0-tbvideo.jpg" src="https://cloud.video.taobao.com/vod/gWur3ruz89gz8-LdUper69IQkHXcQNSgFs1HgKpllNs.mp4" controls></video>

**어떻게 시작하나요**?

서브 Agent Skill 파일을 만들고 서로 다른 모델을 지정합니다:

```markdown
---
name: test-cross-provider
description: 서로 다른 Provider의 Agent 테스트
model: openai:gpt-4o
---

당신은 테스트 도우미입니다. 자신이 사용하는 모델 이름을 포함해 간단히 자기소개를 해 주세요.
```

이후 대화에서 Qwen Code에게 이 서브 Agent를 호출하라고 하면 됩니다.
### Ctrl+O 상세/간결 모드 전환: 출력 수준을 원터치로

Ctrl+O를 누르면 verbose(상세) 모드와 compact(간결) 모드가 번갈아 전환됩니다. 디버깅할 때는 상세 출력, 평소에는 간결판을 씁니다. 설정을 건드릴 필요도 없습니다.

**이렇게 쓸 수 있습니다:**

- 문제 디버깅 때는 verbose 모드로 전환해 실행 과정을 전부 확인
- 평소 사용에서는 compact 모드로 전환해 화면을 깔끔하게
- 언제든 전환 가능 — 재시작이나 설정 파일 수정 불필요

관련 PR [#2770](https://github.com/QwenLM/qwen-code/pull/2770)

### /plan 명령어: 계획 먼저, 실행은 그 다음

`/plan` 명령어가 새로 추가돼 계획 모드로 바로 들어갑니다. AI가 전체 실행 방안을 먼저 제시하고, 확인한 뒤에 실행을 시작합니다. 전체 그림을 보고 단계별로 밀고 나가야 하는 복잡한 작업에 알맞습니다.

**이렇게 쓸 수 있습니다:**

- 대형 모듈 리팩터링 전에 AI에게 수정할 파일과 절차를 전부 목록으로 만들게 함
- 여러 단계 작업은 방안부터 확인해서, AI가 딴길로 새고 전부 다시 하는 일을 방지
- 팀 협업에서는 방안을 먼저 만들어 동료 확인을 받고 실행

관련 PR [#2921](https://github.com/QwenLM/qwen-code/pull/2921)

![](https://gw.alicdn.com/imgextra/i4/O1CN01wm82SI1tw1fL4l7DE_!!6000000005965-2-tps-2840-1310.png)

### 적응형 출력 Token: 답변이 더 이상 잘리지 않습니다

출력 Token 기본값은 8K입니다. AI가 답변이 잘렸다고 판단하면 자동으로 64K까지 올려 다시 시도합니다. 파라미터를 손으로 조절하지 않아도 AI가 답변 길이를 스스로 판단합니다.

**이렇게 쓸 수 있습니다:**

- 긴 파일 생성이 잘리지 않고 한 번에 전체 내용이 나옴
- 복잡한 코드 생성을 나눠서 이어 붙이지 않아도 됨
- max_tokens를 직접 설정할 필요 없이 AI가 알아서 맞춤

관련 PR [#2898](https://github.com/QwenLM/qwen-code/pull/2898)

### Thinking Block 라운드 간 유지

AI의 사고 과정(thinking block)을 이제 대화 라운드를 넘어 유지하며, 유휴 상태일 때 자동으로 정리합니다. 여러 라운드 대화에서 AI가 앞선 추론 흐름을 이어가므로 답변이 훨씬 자연스럽습니다.

관련 PR [#2897](https://github.com/QwenLM/qwen-code/pull/2897)
