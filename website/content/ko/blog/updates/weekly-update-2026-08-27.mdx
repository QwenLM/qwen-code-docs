Qwen Code는 이번 주에 v0.21.15, v0.22.0, v0.22.2 세 개의 정식 버전을 출시하고 PR 300개 이상을 병합했습니다.

**Goal이 스스로 마무리합니다.** Goal의 자율 실행에 기본 토큰 예산이 붙었습니다. 예산을 다 쓰면 인수인계를 남기고 멈추고, 목표에 도달하기 어렵다고 판단되면 미리 스스로 멈춥니다.

**Qwen 모델에 Thinking 스위치가 생겼습니다.** qwen3.5-plus 같은 혼합 사고 모델에 간단한 Thinking 스위치가 추가됐습니다. 끄면 현재 세션에서 생각하지 않고, 켜면 모델 기본값으로 돌아갑니다.

**AI가 응답하는 중에도 더 많은 '/명령어'를 바로 쓸 수 있습니다.** AI가 응답을 생성하는 동안에도 `/theme`, `/tools` 등 10개 명령어를 바로 사용할 수 있고 결과가 즉시 표시됩니다.

## ✨ 새로운 기능

### Goal: 자율 실행에 예산 관리, 멈추기 전 인수인계

Goal의 자율 실행에 이번 주 '자기 인식' 기능이 몇 가지 보강됐습니다. 얼마나 썼는지 알고, 멈출 때 멈추며, 멈추기 전에 상황을 정리해 알려줍니다.

**소비 내역을 따로 기록합니다.** 각 Goal이 토큰을 얼마나 썼는지 따로 집계하며, `get_goal`에서 라운드 수와 나란히 확인할 수 있습니다.

**자율 실행에 예산이 붙습니다.** 새로 만든 Goal에는 기본 토큰 예산이 설정되며, 자율 실행이 예산을 모두 쓰면 멈추고 Goal은 대기 상태로 들어갑니다. 계속 실행하려면 Goal을 복구하거나 편집하면 되고, 예산은 자동으로 새 창만큼 연장됩니다.

**멈추기 전 인수인계 한 번 더.** 예산을 모두 소진하면 '인수인계 라운드'가 한 번 더 주어집니다. 새 작업을 시작하지 않고, 어디까지 했는지, 무엇이 남았는지, 다음 단계가 무엇인지만 정리한 뒤 멈춥니다. 중간에 다른 사람이 이어받을 때 이 부분만 보면 바로 계속할 수 있습니다.

**막히면 스스로 멈춥니다.** 체크포인트에서 연속 세 번 막히면 자동으로 멈추고, 목표 자체가 달성 불가능하다는 증거가 나오면 해당 라운드에서 바로 멈춥니다.

**`/goal-draft`는 막연한 아이디어를 실행 가능한 Goal로 바꿔 줍니다.** 먼저 몇 가지 질문으로 막연한 아이디어를 명확히 한 뒤, 검증 가능한 Goal 초안을 만들고 바로 실행할 수 있는 `/goal set` 명령을 첨부합니다. 초안만 작성할 뿐 실제로 작업을 시작하지는 않으며, 사용할지는 본인이 결정합니다.

관련 PR: [#9583](https://github.com/QwenLM/qwen-code/pull/9583), [#9891](https://github.com/QwenLM/qwen-code/pull/9891), [#10132](https://github.com/QwenLM/qwen-code/pull/10132), [#9975](https://github.com/QwenLM/qwen-code/pull/9975), [#10125](https://github.com/QwenLM/qwen-code/pull/10125), [#10002](https://github.com/QwenLM/qwen-code/pull/10002)

### Qwen 모델에 Thinking 스위치 추가

웹 셸에서 qwen3.5-plus, qwen3.6-plus, qwen3.6-flash, qwen3.7-plus, qwen3.7-max 모델에 Thinking 스위치가 추가됐습니다. 끄면 현재 응답에서 생각하지 않고, 켜면 생각한 뒤 답변합니다.

qwen3.8-max의 사고 강도는 기존과 같이 low / medium / extra high 세 단계로 유지됩니다.

관련 PR: [#9574](https://github.com/QwenLM/qwen-code/pull/9574)

### 워크플로에 정식 스위치와 실행 전 승인 추가

워크플로는 큰 작업을 여러 단계로 나누고 여러 AI 어시스턴트에 동시에 분배하는 기능입니다. 이번 주에 세 가지 관문이 추가됐습니다.

- **정식 스위치**: 설정에서 `tools.workflowsEnabled`를 켜면 바로 사용할 수 있으며, 본인만 설정을 변경할 수 있고 프로젝트 구성으로는 건드릴 수 없습니다.
- **실행 전 승인**: 실행 전에 승인 창이 AI가 방금 작성한 워크플로 스크립트를 통째로 보여줍니다 — 무엇을 조사하고, 어떻게 나누고, 어떻게 종합하는지 전부 안에 적혀 있어 확인 후 승인해야 실행됩니다.
- **필요할 때만 시작**: 명확하게 작업을 분배해야 할 때만 시작합니다. 예를 들어 "워크플로 사용해"라고 말하거나 특정 워크플로를 지명하거나, 이전 이어서 실행하도록 합니다. AI가 필요하다고 판단해도 사용자가 언급하지 않으면 어떻게 분배할지, 몇 명을 배치할지 먼저 제안하고 승인을 기다립니다.

관련 PR: [#9098](https://github.com/QwenLM/qwen-code/pull/9098), [#9837](https://github.com/QwenLM/qwen-code/pull/9837), [#9806](https://github.com/QwenLM/qwen-code/pull/9806)

### GitHub PR이 생성된 세션에 다시 연결

웹 셸에서 PR을 언급한 뒤 "이 PR이 어느 세션에서 만들어졌지?" 하고 찾으려면 기록을 뒤져야 했습니다. 이제 웹 셸의 Git 패널에서 만든 PR은 해당 세션에 기록됩니다. 사이드바 세션 이름 옆에 PR 배지가 나타나고, PR 번호로 검색해도 해당 세션을 찾을 수 있습니다. 한 세션에 최대 10개까지 기록되며, 같은 PR을 다시 푸시하면 최신 상태로 갱신됩니다.

관련 PR: [#9543](https://github.com/QwenLM/qwen-code/pull/9543)

### AI 응답 중에도 더 많은 '/명령어'를 바로 쓸 수 있습니다

이전에는 AI가 응답하는 동안 슬래시 명령어를 사용하려면 대부분 해당 라운드가 끝날 때까지 기다려야 했습니다. 이번 주에 10개 명령어가 '기다리지 않아도 되는' 목록에 추가됐습니다. `/theme`, `/editor`, `/vim`, `/voice`, `/terminal-setup` 같은 인터페이스 설정 명령어와 `/tools`, `/tasks`, `/hooks`, `/docs`, `/bug` 같은 읽기 전용 명령어입니다. AI가 응답하는 중에도 바로 사용할 수 있고 결과가 즉시 표시됩니다.

관련 PR: [#9495](https://github.com/QwenLM/qwen-code/pull/9495)

## 📊 그 외 새로운 기능

**qwen3.8-max이 정식 버전으로 전환.** qwen3.8-max이 프리뷰에서 정식 버전으로 전환됐습니다. Token Plan 사용자는 `/model`에서 안정적인 버전을 바로 선택할 수 있습니다. 관련 PR: [#9383](https://github.com/QwenLM/qwen-code/pull/9383)

**대화 중에도 파일을 나중에 추가할 수 있습니다.** 지난주에 파일을 웹 셸 입력창에 드래그할 수 있게 된 데 이어, 이번 주에는 대화가 진행 중에도 첨부 파일을 추가할 수 있습니다. 입력창 첨부 파일과 @로 워크스페이스 파일을 참조하는 방식 모두 지원되며, AI가 즉시 받을 수 있습니다. 업로드 경로도 통합됐습니다. 워크스페이스 파일 참조와 직접 업로드 중 하나를 선택하면 되고, 업로드한 첨부 파일은 영구적으로 보존됩니다. 관련 PR: [#9570](https://github.com/QwenLM/qwen-code/pull/9570), [#9477](https://github.com/QwenLM/qwen-code/pull/9477)

**대화 모델이 이미지 생성도 함께 담당할 수 있습니다.** 이제 하나의 모델이 대화와 내장 이미지 생성을 동시에 담당할 수 있어, 이미지 생성을 위해 별도 모델을 설정할 필요가 없습니다. 이미지 생성은 MiniMax 인터페이스도 지원하게 됐습니다. 관련 PR: [#9650](https://github.com/QwenLM/qwen-code/pull/9650), [#8322](https://github.com/QwenLM/qwen-code/pull/8322)

**웹 셸에서 Goal을 직접 관리합니다.** Goal이 더 이상 채팅 메시지에 섞여 관리되지 않고, 웹 셸 화면에 별도의 컴팩트 관리 영역이 마련됐습니다. 관련 PR: [#9393](https://github.com/QwenLM/qwen-code/pull/9393)

**예약 작업을 기존 세션에서 실행할 수 있습니다.** 예약 작업을 만들 때 현재 세션에서 실행되도록 선택할 수 있습니다. 관련 PR: [#9838](https://github.com/QwenLM/qwen-code/pull/9838), [#9361](https://github.com/QwenLM/qwen-code/pull/9361)

**데스크톱 코드가 OpenWork로 이전.** Electron 데스크톱 코드가 독립 오픈소스 프로젝트 [OpenWork](https://github.com/modelstudioai/openwork)로 옮겨 계속 개발되며, Qwen Code 저장소에는 새 데스크톱 버전으로의 마이그레이션 브리지만 남겨둡니다. 관련 PR: [#9085](https://github.com/QwenLM/qwen-code/pull/9085)

**Computer Use가 스킬 기반으로 변경.** AI가 PC를 조작하는 방식이 내장 스킬로 바뀌었습니다. 처음 사용하면 자동으로 의존성이 설치되고, 안내에 따라 한 번 재부팅하면 정상 사용할 수 있습니다. Node REPL은 내장 도구에서 독립 MCP 서비스 `@qwen-code/node-repl-mcp`로 변경됐으며, 기본적으로 비활성화되고 `mcpServers`에서 설정해야 적용됩니다. 관련 PR: [#9856](https://github.com/QwenLM/qwen-code/pull/9856), [#9587](https://github.com/QwenLM/qwen-code/pull/9587), [#9499](https://github.com/QwenLM/qwen-code/pull/9499)

**Kimi가 내장 서비스 제공자로 추가.** `/auth`에서 서드파티 서비스 제공자로 Kimi를 선택하고 API key를 입력하면 연결됩니다. 국제 또는 국내 엔드포인트 중 선택할 수 있으며, 모델 목록에는 플래그십 K3, K2.6과 코드 전용 모델 2개가 기본 제공됩니다. 목록은 직접 편집할 수도 있습니다. K3는 기본적으로 사고가 켜져 있고, 나머지 3개는 자유롭게 켜고 끌 수 있습니다. 관련 PR: [#9814](https://github.com/QwenLM/qwen-code/pull/9814)

## 👏 사용성 개선

**웹 셸에 사용량 패널이 생겼습니다.** 웹 셸에서 세션 수준의 토큰 사용량 패널을 열 수 있습니다. 총 소비, 모델별 분류, 서브 에이전트 호출, 도구 사용 통계를 한 페이지에서 모두 확인할 수 있습니다. 관련 PR: [#9988](https://github.com/QwenLM/qwen-code/pull/9988)

**컴팩트 모드가 웹 셸의 유일한 모드가 됐습니다.** 사고 블록과 도구 활동이 기본적으로 요약 행으로 접히며, 이전의 Ctrl+O 스위치는 제거됐습니다. 메인 대화, 분할 화면, 서브 에이전트 상세 패널 모두 컴팩트 렌더링으로 통일됐습니다. 관련 PR: [#9993](https://github.com/QwenLM/qwen-code/pull/9993), [#9657](https://github.com/QwenLM/qwen-code/pull/9657)

**승인 카드가 메시지 흐름 안에 들어왔습니다.** 도구 승인 및 질문이 더 이상 메시지 목록 전체를 덮지 않고, 메시지 흐름에 밀착되어 표시되는 하단 카드로 변경됐습니다. 너비도 채팅 영역과 맞춰 정렬됩니다. 관련 PR: [#9351](https://github.com/QwenLM/qwen-code/pull/9351)

**백그라운드 shell이 실행 중이면 라운드가 펼쳐진 상태로 유지됩니다.** 라운드 내에서 백그라운드 shell이 시작되면, 해당 라운드는 완료될 때까지 펼쳐진 상태로 유지되어 진행 상황을 파악하기 쉽습니다. 관련 PR: [#9632](https://github.com/QwenLM/qwen-code/pull/9632)

**VS Code 플러그인이 통일된 렌더링을 사용합니다.** VS Code 플러그인의 세션 타임라인이 웹 셸과 동일한 렌더러로 바뀌어 양쪽의 표시 경험이 맞춰졌습니다. 관련 PR: [#9719](https://github.com/QwenLM/qwen-code/pull/9719)

**대형 터미널에서 스크롤이 더 부드럽습니다.** 터미널 가상 스크롤의 렌더링이 초당 30프레임에서 60프레임으로 향상되어, 대형 창에서 기록을 볼 때 확실히 더 부드럽습니다. 관련 PR: [#9681](https://github.com/QwenLM/qwen-code/pull/9681)

**어떤 컨텍스트 파일이 로드되었는지 확인할 수 있습니다.** 설정으로 커스텀 컨텍스트 파일을 추가한 경우, 세션의 첫 메시지 위에 어떤 파일이 로드되었는지 표시됩니다. 이전에는 이 단계가 완전히 보이지 않았습니다. 관련 PR: [#8855](https://github.com/QwenLM/qwen-code/pull/8855)

**세션이 마지막으로 선택한 모델을 기억합니다.** daemon 세션이 재시작되거나 연결이 끊겼다 다시 연결되면, 해당 세션에서 마지막으로 선택한 모델로 복구됩니다. 새 세션은 여전히 설정의 기본 모델을 사용합니다. 관련 PR: [#9687](https://github.com/QwenLM/qwen-code/pull/9687)

**딩딩 채널이 참조를 이해합니다.** 이전에는 딩딩에서 이미지나 파일을 참조하면 AI가 자리 표시자만 보았지만, 이제 참조된 이미지, 파일, 오디오, 비디오가 실제로 다운로드되어 AI에 전달됩니다. 전달된 채팅 기록도 제목과 요약이 추출되어 함께 포함됩니다. 관련 PR: [#9347](https://github.com/QwenLM/qwen-code/pull/9347), [#9339](https://github.com/QwenLM/qwen-code/pull/9339)

**비공개 저장소의 확장 기능을 설치할 수 있습니다.** HTTPS Git을 통한 확장 기능 설치에 인증이 지원되어, 비공개 저장소에서도 클론할 수 있으며, 자격 증명 지속 저장 여부를 선택할 수 있습니다. 관련 PR: [#9458](https://github.com/QwenLM/qwen-code/pull/9458)

**구버전 Git에서도 공개 확장 기능을 설치할 수 있습니다.** Git 버전이 2.37 미만인 시스템에서는 공개 GitHub 확장 기능 설치가 아카이브 다운로드 경로로 진행됩니다. 관련 PR: [#9680](https://github.com/QwenLM/qwen-code/pull/9680), [#9690](https://github.com/QwenLM/qwen-code/pull/9690)

**명령어 하나로 잠긴 웹 셸 열기.** `qwen serve --open-with-auth`는 토큰 인증이 있는 로컬 웹 셸을 엽니다. 토큰이 설정되지 않으면 자동으로 생성해 브라우저에 전달합니다. 관련 PR: [#9738](https://github.com/QwenLM/qwen-code/pull/9738)

**Homebrew가 업데이트를 잘못 알리지 않습니다.** 로컬 메타데이터에서 새 버전이 없는 것을 확인하면 업데이트 알림이 더 이상 표시되지 않습니다. 관련 PR: [#9502](https://github.com/QwenLM/qwen-code/pull/9502)
