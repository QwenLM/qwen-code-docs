이번 주에 v0.11.1 정식 버전을 출시했습니다. 안정성 수정과 기능 개선이 여럿 담겼습니다. 한편 v0.12.0 개발 브랜치도 계속 진행되고 있는데, 눈여겨볼 만한 새 기능이 몇 개 있습니다.

- 정식 버전 출시: v0.11.1
- v0.12.0 개발 중, 새 기능 PR 여러 개가 이미 병합됐습니다

## ✨ 새로운 기능

### HTML 내보내기: 도구 호출 내용 뷰어

세션을 HTML 파일로 내보낸 뒤 **Shell 도구 호출의 IN / OUT 태그를 클릭하면 이제 모달 창에 전체 내용이 뜹니다**. 이전에는 두 태그를 눌러도 반응이 없었습니다. 관련 PR: [#2085](https://github.com/QwenLM/qwen-code/pull/2085)

![](https://gw.alicdn.com/imgextra/i4/O1CN01jLoKVP29zihmemlWK_!!6000000008139-2-tps-1610-858.png)

### 터미널 스트리밍 스크린샷과 GIF 생성

terminal-capture 도구에 스트리밍 캡처 모드가 추가됐습니다. 명령어가 실행되는 동안 일정한 간격으로 화면을 찍는데, 진행률 표시줄이나 spinner 애니메이션처럼 계속 바뀌는 터미널 출력에 어울립니다. 찍기가 끝나면 ffmpeg을 불러 반복 재생되는 GIF로 합칩니다. 관련 PR: [#2116](https://github.com/QwenLM/qwen-code/pull/2116)

스크린샷 간격, 시작 지연 시간, 출력이 안정되면 자동으로 멈추는 설정을 지원합니다. ffmpeg이 설치돼 있지 않으면 GIF 생성만 건너뛰고 그대로 진행하니 스크린샷에는 영향이 없습니다.

이전에는 정지 화면만 찍을 수 있었지만, **이제는 명령어 실행 과정 전체를 녹화할 수 있습니다**. 기능 시연이나 튜토리얼 자료로 좋습니다.

![](https://gw.alicdn.com/imgextra/i4/O1CN01VFg7mt1YGFbKnhOII_!!6000000003031-1-tps-860-584.gif)

### GitHub 워크플로 내장 명령어

흔한 GitHub 작업을 다루는 내장 커스텀 명령어 4개가 추가됐습니다. `/qc:<명령어 이름>` 형태로 호출합니다. 관련 PR: [#2117](https://github.com/QwenLM/qwen-code/pull/2117)

- **`/qc:code-review`**: PR 상세와 diff를 가져와 정확성, 스타일, 성능, 보안을 아우르는 코드 리뷰 보고서를 만듭니다
- **`/qc:commit`**: 스테이징된 변경을 분석해 Conventional Commits 규격에 맞는 커밋 메시지를 만들고, 브랜치를 자동으로 처리합니다 (main에 바로 커밋하는 일을 막습니다)
- **`/qc:create-issue`**: 코드베이스 맥락에 맞춰 GitHub Issue 초안을 쓰고, feature request와 bug report 템플릿 중 알맞은 것을 고릅니다
- **`/qc:create-pr`**: Pull Request를 프로젝트 PR 템플릿을 따라 짜임새 있게 만듭니다

![](https://gw.alicdn.com/imgextra/i1/O1CN01yjkkmf1PU94inB5NU_!!6000000001843-1-tps-860-584.gif)

### AGENTS.md를 기본 컨텍스트 파일로

프로젝트 루트의 `AGENTS.md`가 이제 컨텍스트 파일로 자동 로드됩니다. `GEMINI.md`, `CLAUDE.md`와 똑같이 동작합니다. 여러 Agent 프레임워크에서 작업할 때 별도 설정이 필요 없습니다. 관련 PR: [#2018](https://github.com/QwenLM/qwen-code/pull/2018)

![](https://gw.alicdn.com/imgextra/i1/O1CN018tD4ZB1HuEiAze39i_!!6000000000817-2-tps-1902-1144.png)

### Ctrl+Y로 실패한 요청 재시도

요청이 실패한 뒤 `Ctrl+Y`만 누르면 바로 다시 시도합니다. 내용을 처음부터 다시 입력할 필요가 없습니다. 관련 PR: [#2011](https://github.com/QwenLM/qwen-code/pull/2011)

![](https://gw.alicdn.com/imgextra/i1/O1CN01YtZAzm1ShNMbf8YTt_!!6000000002278-2-tps-1694-956.png)

### 인증 대화창 레이아웃 개선

로그인 대화창을 선택지 3개 레이아웃으로 다시 만들어 항목별 구분이 명확해졌습니다. 관련 PR: [#2030](https://github.com/QwenLM/qwen-code/pull/2030)

![](https://gw.alicdn.com/imgextra/i2/O1CN011eGoRs1Pf8a4hXQ0K_!!6000000001867-2-tps-1700-952.png)

### 코드 하이라이팅의 Tab 폭 지원

코드 하이라이팅 컴포넌트에 `tabWidth` 설정이 추가됐습니다. Tab 문자가 지정한 개수의 공백으로 바뀌어, 코드 블록에서 Tab 표시 폭이 제각각이던 문제가 해결됩니다. 관련 PR: [#2077](https://github.com/QwenLM/qwen-code/pull/2077)

![](https://gw.alicdn.com/imgextra/i4/O1CN016C78pF1aCFN1nJhiI_!!6000000003293-2-tps-2868-1346.png)
