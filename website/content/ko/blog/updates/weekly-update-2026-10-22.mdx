Qwen Code는 이번 주 v0.25.3과 v0.26.0 두 개의 정식 버전을 출시하고 PR 436개를 병합했습니다.

**결과를 인터랙티브 카드로 만듭니다.** 숫자를 몇 개 바꿔 보며 결과가 어떻게 달라지는지 비교하고 싶으면 카드의 숫자를 고치면 됩니다 — 총합도 함께 다시 계산됩니다.

**저장소에 둔 워크플로, 하위 디렉터리에서도 씁니다.** 프로젝트를 프런트엔드·백엔드·컴포넌트 디렉터리로 나눠 두고 루트에 코드 검사나 테스트 워크플로를 저장해 뒀다면, 하위 디렉터리에서 Qwen Code를 시작해도 그대로 찾고 돌릴 수 있습니다.

**Web Shell은 `qwen daemon` 한 그룹으로 관리합니다.** 시작, 상태 확인, 로그, 종료, 재시작이 전부 이 명령 안에 모였습니다.

## ✨ 새로운 기능

### 인터랙티브 카드: 조절하면서 비교, 맞는 답을 고릅니다

숫자를 몇 개 바꿔 가며 결과를 보고 싶은 질문이 있습니다. 이제는 Qwen Code가 그런 요청을 곧바로 인터랙티브 카드로 만들어 줍니다 — 숫자와 비율을 움직이면 결과가 그 자리로 반영됩니다. 관련 PR: [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

팀 점심을 계획할 때를 예로 들어 보겠습니다. 비용 계산 카드를 만들어 달라고 하고 인원수, 1인 식사비, 장소비를 채워 넣으세요. 인원이 바뀌면 인원수를 고치고, 식당을 바꾸면 식사비를 고치면 됩니다. 총비용이 따라 다시 계산되니 그때마다 AI에게 메시지를 보낼 필요가 없습니다.

기본은 꺼져 있습니다. 실험 설정에서 Generated UI를 켜고 재시작하면 적용됩니다. 관리형·원격·샌드박스 세션은 내장 버전을 아직 지원하지 않습니다. 관련 PR: [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

이렇게 활용할 수 있습니다:

- 월세, 통근 시간, 교통비를 함께 놓고 집 구하기 조건 비교
- 프로젝트 인원과 작업 배치를 바꿔 가며 공기와 비용 추정
- 서버 구성을 비교해 방문자 수마다 용량과 비용 추정

### 워크플로: 하위 디렉터리에서 시작해도 같은 워크플로

프로젝트를 프런트엔드·백엔드·여러 컴포넌트 디렉터리로 나눠 두는 경우가 많습니다. 이미 프로젝트 루트에 코드 검사나 테스트 워크플로를 저장해 뒀다면, 이제 그 아래 디렉터리에서 Qwen Code를 시작해도 찾아서 돌릴 수 있습니다.

프런트엔드 디렉터리에서 페이지를 고치다가 프로젝트에 저장해 둔 검사를 돌리고 싶으면, 지금 세션의 워크플로 목록에서 바로 찾으면 됩니다. 이번 업데이트는 현재 디렉터리에서 위로 올라가 같은 Git 저장소 안의 신뢰된 디렉터리에 있는 워크플로를 찾습니다. 로컬 터미널 세션과 일반 Web Shell 세션에서 모두 동작합니다. 관련 PR: [#14369](https://github.com/QwenLM/qwen-code/pull/14369), [#14646](https://github.com/QwenLM/qwen-code/pull/14646)

이렇게 활용할 수 있습니다:

- 각기 다른 컴포넌트 디렉터리에서 프로젝트 공통 코드 검사를 재사용
- 백엔드를 고친 뒤 저장소에 둔 테스트 워크플로 실행
- 문서를 쓸 때 윗 디렉터리에 저장된 문서 검사를 사용

### qwen daemon: Web Shell 관리, 명령 한 그룹으로

지난주에 Web Shell이 한 페이지에서 여러 Qwen Code를 연결하게 됐고, 이번 주에는 이 로컬 서비스의 관리가 더해졌습니다.

Web Shell을 시작하고 상태를 보고 다시 띄우는 동작이 전부 `qwen daemon` 명령에 모였습니다.

`qwen daemon start`를 실행하면 서비스가 백그라운드로 뜨면서 접근 주소가 반환됩니다. `qwen daemon status`로 떠 있는 서비스를 확인하고, `qwen daemon logs`로 로그를 읽고, `qwen daemon stop`으로 지정한 서비스를 내립니다. 관련 PR: [#14739](https://github.com/QwenLM/qwen-code/pull/14739), [#14869](https://github.com/QwenLM/qwen-code/pull/14869)

문제를 찾을 때는 `qwen daemon status --detail`이 버전, 가동 시간, 세션 수, 오류 수까지 보여 줍니다. 스크립트에서 서비스를 띄운 뒤 곧바로 붙어야 한다면 `qwen daemon start --wait`을 쓰면 실행 환경이 준비될 때까지 기다려 줍니다. 관련 PR: [#14902](https://github.com/QwenLM/qwen-code/pull/14902), [#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <포트>`는 지정한 로컬 HTTP 서비스를 다시 띄우면서 기록에 남아 있던 시작 워크스페이스와 Web Shell 설정까지 되돌립니다. 관련 PR: [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

이렇게 활용할 수 있습니다:

- 로컬 서비스를 띄운 뒤 같은 터미널에서 다른 일을 계속하기
- 여러 로컬 서비스의 상태를 보고 손댈 것을 고르기
- 기록된 시작 설정대로 지정한 서비스를 재시작하기

### Web Shell: 파일과 실행 기록, 화면에서 더 분명하게

**PDF와 Word 파일을 화면에서 바로 봅니다.** `@` 참조, 오른쪽 `Files`, 산출물 카드 중 어디서 열든 PDF는 브라우저 기본 뷰어로 나오고, Word 파일도 같은 진입점에서 미리보기 됩니다. 관련 PR: [#14825](https://github.com/QwenLM/qwen-code/pull/14825), [#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**오른쪽 파일에서 만들고 지웁니다.** 대화 제목 옆의 디렉터리 이름을 누르면 오른쪽에 워크스페이스 파일 트리가 열립니다. 여기서 파일과 폴더를 새로 만들 수 있습니다. 파일은 확인을 한 번 거쳐 지우고, 폴더는 확인을 한 번 더 거칩니다 — 안에 든 파일까지 함께 사라지기 때문입니다. 관련 PR: [#14344](https://github.com/QwenLM/qwen-code/pull/14344), [#14169](https://github.com/QwenLM/qwen-code/pull/14169), [#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**Trajectory 탭은 멈출 수 있습니다.** 지난 기록을 넘기면 자동으로 멈춰 화면이 지금 보는 구간에 그대로 뜹니다. 최신으로 돌아가려면 `Jump to latest`를 누르세요. 목록에서 아무 항목이나 누르면 그 기록의 상세가 열립니다. 관련 PR: [#14723](https://github.com/QwenLM/qwen-code/pull/14723), [#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**그 외 개선.** 대화에서 특정 발화와 그 답을 골라 함께 지울 수 있고, 몇 군데만 골라 지울 수도 있습니다 ([#14297](https://github.com/QwenLM/qwen-code/pull/14297)); 지금 하는 일과 방금 끝낸 일이 각 단계 소요 시간과 함께 접히는 '최근 실행' 영역에 모입니다 ([#14071](https://github.com/QwenLM/qwen-code/pull/14071)); '세션 token 사용량' 패널의 개요에는 입력·출력·캐시 항목만 남고, 아래에서 모델별과 메인 Agent, 서브 Agent가 각각 쓴 양을 나뉘어 볼 수 있습니다; 모델 이름 옆의 Info 아이콘에 마우스를 올리면 첫 글자가 나올 때까지 걸린 시간과 초당 출력량도 보입니다 ([#14728](https://github.com/QwenLM/qwen-code/pull/14728), [#14648](https://github.com/QwenLM/qwen-code/pull/14648)).

![Web Shell 오른쪽 패널에서 프로젝트 파일을 열고, Trajectory 탭으로 바꿔 각 단계에 시간이 얼마나 걸렸는지 본다](https://img.alicdn.com/imgextra/i4/O1CN011HVsNLd8EyF7nW9B_!!6000000005070-2-tps-3841-2160.png)

## 📊 그 외 새로운 기능

**`/auth` 첫 화면에 QwenCloud 진입점이 생겼습니다.** 종량제 key와 Token Plan key를 나눠 고르고, 그 다음 단계에서 China 또는 International을 선택합니다. 관련 PR: [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**자체 Managed Agent 서비스를 쓰면 프로젝트와 작업을 더 편하게 다룰 수 있습니다.** 이 세션들이 내 컴퓨터의 세션과 나란히 Web Shell 첫 화면에 뜨고, 같은 입력창과 승인 카드를 씁니다. 이번 주에는 이미 있는 프로젝트 디렉터리를 바로 고를 수 있고, 새 세션을 만들 때 켜 둔 스킬을 함께 실으며, 도중에 실행 권한을 바꿀 수 있고, 세션 이름도 직접 바꿀 수 있습니다. 일반 관리형 세션도 같은 프로젝트 디렉터리를 함께 쓰며 파일을 공유합니다. 각각 해당 배포의 뒷받침이 필요합니다. 관련 PR: [#14316](https://github.com/QwenLM/qwen-code/pull/14316), [#14970](https://github.com/QwenLM/qwen-code/pull/14970), [#14930](https://github.com/QwenLM/qwen-code/pull/14930), [#14920](https://github.com/QwenLM/qwen-code/pull/14920), [#14987](https://github.com/QwenLM/qwen-code/pull/14987), [#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**QQ 봇이 파일을 받습니다.** 개별 채팅이나 그룹에서 @로 부르며 Word, PDF, 표 파일을 보내면 받아 두고 그 내용을 읽고 답합니다. 관련 PR: [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**WeCom 자체 구축 앱도 붙일 수 있습니다.** 동료가 사내에서 직접 만든 앱으로 한 마디에 일을 시키면 Qwen Code가 받아 처리하고, 끝난 뒤 그 앱 자격으로 답을 보냅니다. 관련 PR: [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Claude 형식 플러그인의 자체 명령, 터미널에서도 치면 돌아갑니다.** 지난주에는 한 번 돌려서 결과를 받는 용도에만 적용됐는데, 이제는 터미널에서 바로 쓸 수 있고 모델 요청도 나가지 않습니다. 모델이 도구를 쓰기 전에 플러그인이 끼어드는 계층도 인터랙티브 세션에 열렸습니다 — 이번 호출을 고쳐 쓰거나 막아 세울 수 있습니다. 기본은 꺼져 있고 설정의 Mods 토글을 켜면 재시작 뒤에 적용됩니다. 관련 PR: [#14268](https://github.com/QwenLM/qwen-code/pull/14268), [#14565](https://github.com/QwenLM/qwen-code/pull/14565), [#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**백그라운드 명령이 어디까지 출력했는지 바로 보입니다.** 작업 상세에 출력의 마지막 부분과 전체 크기, 마지막으로 쓴 시각이 뜨고, 점유 메모리와 시작·종료 시각까지 함께 볼 수 있습니다. 출력 내용은 그대로 복사됩니다. 관련 PR: [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 사용성 개선

**첫 화면에서 접힌 내용은 마우스를 올리면 미리 볼 수 있습니다.** 관련 PR: [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**표의 정렬·필터·복사가 매끄러워졌습니다.** 넓은 표의 고급 컨트롤과 복사 경로를 이번 주에 함께 손봤습니다. 관련 PR: [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**같은 일을 반복하면 그 라운드를 끊지 않고 먼저 경고합니다.** 명령이나 파일 읽기가 일정 횟수를 넘으면 기본은 다른 방법을 쓰라는 경고와 함께 계속 진행합니다. 자동으로 멈추게 하려면 설정에서 고르세요. 관련 PR: [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**모바일 입력창에서 방향키 두 개가 사라졌습니다.** 입력창 위쪽에 있던 기록 넘김 방향키를 치웠고, 기록 검색은 그 자리에서 그대로 됩니다. 관련 PR: [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**브라우저 탭 아이콘이 어두운 탭에서도 잘 보입니다.** 탭 배경이 어두우면 아이콘이 거의 묻혀 있었습니다. 관련 PR: [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**모델 목록은 선택기에서 새로 고침됩니다.** 모델 선택기를 누르면 목록을 다시 불러오고, 새로 고침은 검색 옆 작은 아이콘으로 뜹니다. 관련 PR: [#14685](https://github.com/QwenLM/qwen-code/pull/14685), [#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**Linux 터미널에서 `Ctrl+V`로 텍스트를 붙여 넣습니다.** 클립보드 내용이 텍스트나 링크면 입력창에 그대로 들어가고, 이미지는 전처럼 첨부로 처리됩니다. 관련 PR: [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
