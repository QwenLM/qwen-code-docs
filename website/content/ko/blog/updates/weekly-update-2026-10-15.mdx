Qwen Code는 이번 주 v0.25.1과 v0.25.2 두 개의 정식 버전을 출시하고 PR 371개를 병합했습니다.

**Agent Collaboration: Claude Code와 Codex를 @로 불러 팀원으로 씁니다.** 답은 지금 이 대화에 그대로 떨어지고, 다른 컴퓨터로 보내 돌릴 수도 있습니다.

**열어 둔 여러 Qwen Code, 한 페이지에서 함께 연결합니다.** 사이드바에서 Qwen Code 하나가 그룹 하나를 잡고, 각 그룹 아래에는 그 순간의 실제 세션과 워크스페이스가 뜹니다. 오가는 전환도 전부 페이지 안에서 끝납니다.

**안 쓸 MCP 서비스는 시작할 때 지목해서 빼면 됩니다.** `qwen --disable-mcp-server <이름>`은 이번 실행에만 적용되고 설정 파일은 건드리지 않습니다.

## ✨ 새로운 기능

### Agent Collaboration: Claude Code와 Codex를 @로 대화에 불러 팀원으로

한 가지 일을 쪼개서 동시에 하고 싶을 때가 있습니다 — 코드는 이쪽에서 고치면서, 같은 시간에 다른 프로그램에게 검토받는다든지. 전에 Agent를 @로 부르면 새 스레드가 하나 열리고, 방금 한 말이 거기로 복사되고, 새 페이지까지 따라갑니다. 원본 대화에는 그 답이 떨어지지 않습니다.

이제는 @로 부르면 지금 이 대화에서 답합니다. 이름이 붙고, 어디까지 진행했는지, 어떤 도구를 썼는지, token을 얼마나 썼는지까지 보입니다. 명령을 실행해야 하면 평소처럼 승인 팝업이 뜹니다. 이 Agent는 Qwen Code일 필요가 없습니다 — Claude Code나 Codex를 설치했다면 @로 불러 부릴 수 있습니다. 관련 PR: [#13467](https://github.com/QwenLM/qwen-code/pull/13467)

다른 컴퓨터에서 일하게 해도 됩니다. 그쪽에 Qwen Code 서비스를 띄워 두고 팀원으로 추가하면, 무거운 일은 그 기계로 보내고, 그 기계가 재시작하면 스스로 다시 이어 붙습니다. 그룹 통째로 @로 부르기도 가능합니다. 리더가 일을 나눠 팀원에게 시키고, 팀원은 끝난 것을 리더에게 알립니다. 관련 PR: [#13583](https://github.com/QwenLM/qwen-code/pull/13583)

서브 Agent를 파견하는 일과의 차이는 이렇습니다. 서브 Agent는 스스로 작은 일 하나를 맡겨 오직 자기에게만 보고합니다. @로 부른 팀원은 눈앞에서 말하고, 다른 업체의 프로그램이어도 되고 다른 기계에서 돌아도 됩니다.

아직 실험 단계라 기본으로 꺼져 있습니다. 설정에서 `Enable Agent Collaboration`을 켜고 재시작하면 적용됩니다. 팀원은 먼저 만들어야 합니다 — 왼쪽의 `Agents` 페이지에서 새로 만듭니다. 이후 아무 대화에서나 그 이름을 @로 부르면 옵니다.

이렇게 활용할 수 있습니다:

- 한쪽에서 코드를 고치는 사이에 다른 Agent를 @로 불러 검토시키고, 두 흐름을 같은 대화에서 한눈에 보기
- 컴파일이나 테스트 실행 같은 무거운 일은 다른 기계로 보내고, 이쪽은 계속 일하기
- 다른 업체의 프로그램으로 한 그룹을 만들어 각자 잘하는 부분만 맡기기

![`Agents` 페이지에서 reviewer라는 팀원을 만들고 대화로 돌아와 @로 부르니, 이름과 ReadFile 단계를 달아 그대로 지금 이 대화에 답한다](https://img.alicdn.com/imgextra/i3/O1CN01nZHvJWBQd2I5qXns_!!6000000004221-1-tps-2880-1800.gif)

### 열어 둔 여러 Qwen Code를 한 페이지에서 동시 연결

손에 노트북 하나, 컴파일 전용 컴퓨터 하나, 긴 작업을 올려둔 기계 하나가 있는 사람이 있습니다. 컴퓨터 한 대만 쓰면서 프로젝트마다 Qwen Code Web Shell을 따로 열어, 일이 뒤섞이지 않게 하려는 사람도 있습니다. 예전에는 브라우저 페이지가 그중 하나만 알아봤습니다. 다른 것을 보려면 페이지를 통째로 새로고침해야 하고, 중간에 화면이 한 번 깜빡이는 동안 이쪽에서 아직 다 못 쓴 입력도 사라졌습니다.

이제는 저장해 둔 여러 개를 동시에 연결합니다. 사이드바에서 Qwen Code 하나가 그룹 하나를 차지하고, 각 그룹 아래에는 그 순간의 세션과 워크스페이스가 나열됩니다. 입력창에서 워크스페이스를 고를 때도 디렉터리가 그룹별로 나뉘어 나오고, 다른 그룹으로 옮기는 것도 페이지 안에서 끝납니다. 관련 PR: [#13739](https://github.com/QwenLM/qwen-code/pull/13739), [#13677](https://github.com/QwenLM/qwen-code/pull/13677)

쓰려면 연결되는 쪽에서 이 페이지의 접근을 먼저 허용해야 합니다. `qwen serve`를 띄울 때 `--allow-origin`을 붙이고, 브라우저 주소창에 보이는 페이지 주소를 적어 주세요.

이렇게 활용할 수 있습니다:

- 컴파일용 기계에 긴 작업이 도는 동안, 내 컴퓨터에서 어디까지 진행됐는지 지켜보기
- 컴퓨터 한 대에서 프로젝트마다 하나씩 열어 일이 섞이지 않게 하고, 한 페이지에서 전부 보기
- 노트북에서 데스크톱으로 옮겨 가며 이어서 일 맡기기

![Web Shell 사이드바에 Qwen Code 두 그룹이 나란히 보이고, 두 번째 그룹 127.0.0.1:4171에는 connected가 표시되며 그 아래 지금의 세션과 워크스페이스가 나온다](https://img.alicdn.com/imgextra/i1/O1CN013gKPf9c85bL5qXns_!!6000000000032-0-tps-2880-1800.jpg)

### 안 쓸 MCP 서비스, 시작할 때 지목해서 빼기

MCP 서비스를 붙여 본 사람이면 대개 겪어 봤을 겁니다. 서비스 하나가 그날 문제를 일으켜 도구가 오류를 내거나 시작을 느리게 만들고, 바라는 건 '이번 실행에는 그 서비스 없이'뿐입니다. 예전에는 한 번에 끄는 방법뿐이었습니다. 설정에서 가져오는 서비스를 로컬 설정까지 통째로 꺼야 했습니다.

이제는 시작할 때 지목할 수 있습니다:

```text
qwen --disable-mcp-server github
```

여럿을 한 번에 빼려면 이 인수를 반복해서 적거나 `--disable-mcp-server github,postgres`처럼 쉼표로 묶으면 됩니다. 이번 시작에만 적용되고 설정 파일은 그대로 둡니다. 관련 PR: [#14003](https://github.com/QwenLM/qwen-code/pull/14003)

이렇게 활용할 수 있습니다:

- 어떤 서비스가 의심되면 일단 빼고 한 번 돌려서 범인인지 확인하기
- 시작이 어떤 서비스에 끌려 느려진다면 이번 실행에서는 그것 없이 출발하기
- 같은 코드에서 한 라운드는 데이터베이스만, 다른 라운드는 웹만 다루도록 서비스씩 나눠 가기

![시작할 때 `--disable-mcp-server`로 MCP 서비스 하나를 제외한 모습](https://img.alicdn.com/imgextra/i3/O1CN01eTCrgCnavhE3thAe_!!6000000000173-1-tps-1920-1080.gif)

### Web Shell: 프로젝트 파일은 클릭 바로 열람, 덧넣은 말은 그 자리 전달, 승인을 기다리면 알림

**워크스페이스 파일을 오른쪽에서 그대로 넘깁니다.** 워크스페이스 전체 디렉터리 트리가 이쪽에 서고, 파일 하나를 누르면 옆에 내용이 뜹니다 — Markdown, 웹페이지, 이미지, Excel은 바로 보입니다. 경로를 복사하거나 다운로드하거나 참조로 넣을 수도 있습니다. 관련 PR: [#13878](https://github.com/QwenLM/qwen-code/pull/13878), [#13664](https://github.com/QwenLM/qwen-code/pull/13664)

**로컬 파일은 끌어 넣으면 업로드됩니다.** 넣는 폴더에 그대로 올라가고, 데스크톱 버전에서도 같습니다. 관련 PR: [#14145](https://github.com/QwenLM/qwen-code/pull/14145), [#14053](https://github.com/QwenLM/qwen-code/pull/14053)

**대기열의 메시지를 곧바로 끼워 넣고, 취소하면 입력창으로 돌아갑니다.** Qwen Code가 답하는 중에 보낸 말은 먼저 줄을 섭니다. 어서 닿게 하려면 `Send now`를 눌러 바로 끼워 넣고, AI가 아직 출력을 시작하기 전에 중지를 누르면 그 문장이 입력창으로 되돌아가니 고쳐서 다시 보내면 됩니다. 관련 PR: [#13681](https://github.com/QwenLM/qwen-code/pull/13681), [#13488](https://github.com/QwenLM/qwen-code/pull/13488)

**멈춰 나를 기다리면 알림을 보냅니다.** 작업 하나를 통과시켜 달라는 때, 아니면 되물은 질문에 답할 때까지 — 예전에는 이 두 상황에서 아무 소식이 없었습니다. 이제는 페이지가 백그라운드로 밀려나면 알림이 하나 뜨고, 누르면 그 세션으로 돌아갑니다. 관련 PR: [#13832](https://github.com/QwenLM/qwen-code/pull/13832)

**서브 Agent나 백그라운드 작업이 도는 중이면 채팅 위쪽의 목록 모양 아이콘에 점이 켜집니다.** 패널을 열지 않아도 보입니다. 관련 PR: [#14048](https://github.com/QwenLM/qwen-code/pull/14048)

![Web Shell 오른쪽의 `Files` 패널이 워크스페이스 전체 파일 트리를 펼친 모습. `Filter files` 검색창과 data/tests 디렉터리, 여러 종류의 파일이 보이고, 아래쪽 대기열 메시지 옆에 `Send now` 버튼이 표시된다](https://img.alicdn.com/imgextra/i1/O1CN01e27zKWHeHTH4s7X6_!!6000000007916-0-tps-2400-1616.jpg)

## 📊 그 외 새로운 기능

**계속 찾기만 하고 끝내 답을 안 주면 결론을 내라는 주의를 받습니다.** 파일 읽기나 코드 검색 같은 읽기 전용 동작이 몇 번을 넘으면, 다음 라운드에 Qwen Code가 한 마디를 받습니다 — 손에 쥔 조사 결과를 쓰라, 시킨 일을 한 걸음 진전시키라, 아니면 어디서 막혔는지 설명하라는 것입니다. 애초에 상황을 파악하게 하려는 조사였다면, 결론과 아직 못 푼 의문을 함께 말하면 됩니다. 관련 PR: [#13601](https://github.com/QwenLM/qwen-code/pull/13601)

**MCP 서비스가 준 화면이 대화에 내용을 보내려면 내가 먼저 확인해야 합니다.** 일부 MCP 서비스는 도구만 주지 않고 대화 안에 클릭하는 화면을 하나 걸어 넣습니다. 이 화면이 내 말을 대신 보내려 할 때, Qwen Code는 보내질 내용 전체와 어디서 왔는지, 어떤 대화에 들어가는지 먼저 펼쳐 보여 주고, 확인 단추를 누르어야 실제로 나갑니다. 관련 PR: [#13958](https://github.com/QwenLM/qwen-code/pull/13958)

**워크플로에서 각 agent가 무엇을 했는지, 노드를 누르면 보입니다.** 대화의 워크플로 카드, `Tasks` 페이지, 워크플로 페이지에서 agent 하나를 누르면 오른쪽 패널에 그 라운드의 경과가 열립니다 — 무엇을 시켰는지, 어떤 도구를 돌렸는지, 지금 무엇을 출력하는지, 어디까지 왔는지. 관련 PR: [#14175](https://github.com/QwenLM/qwen-code/pull/14175)

**실행 직전에 통과하는 검사가 이번 호출의 인수를 바꿀 수 있습니다.** 설정에서 두는 hook가 바로 이 검사입니다 — 도구를 쓰기 전에 한 번 훑고 지나갑니다. 이 검사가 새 인수를 돌려주면 Qwen Code가 그것을 다시 검증하고, 권한과 승인을 한 번 더 거쳐, 그다음에 실제로 실행합니다. 관련 PR: [#13442](https://github.com/QwenLM/qwen-code/pull/13442)

**덧붙이는 짧은 질문은 다른 워크스페이스로 열 수 있습니다.** 본 작업이 답하는 중에 `/btw side`를 치면 다른 워크스페이스에 독립적인 대화 하나를 새로 만들어, 본 작업과 같은 대화에 섞이지 않습니다. 관련 PR: [#13468](https://github.com/QwenLM/qwen-code/pull/13468)

**Claude 형식 플러그인의 자체 명령, 이제 실제로 돌아갑니다.** 이 명령은 프롬프트가 아니라 코드 한 덩어리입니다. 예전에는 치면 모델에게 한마디 거는 것과 같았지만, 이제는 플러그인이 로컬에서 실행하고 결과를 바로 돌려주니 token을 쓰지 않습니다. 설정에서 `experimental.mods`를 켜야 하고, 워크스페이스가 신뢰된 상태여야 하며, 한 번 돌려서 결과를 받는 `qwen -p '…'` 같은 용도로만 동작합니다. 인터랙티브 화면과 Web Shell에서는 아직 지원되지 않습니다. Mod 인터페이스의 일부만 구현했으니 기존 플러그인이 모두 될 것이라고는 장담하지 못합니다. 관련 PR: [#13843](https://github.com/QwenLM/qwen-code/pull/13843), [#13890](https://github.com/QwenLM/qwen-code/pull/13890), [#13915](https://github.com/QwenLM/qwen-code/pull/13915), [#13950](https://github.com/QwenLM/qwen-code/pull/13950)

## 👏 사용성 개선

**새 작업 화면은 말을 꺼내기 전에도 오른쪽의 파일·터미널·웹 미리보기를 쓸 수 있습니다.** 윗줄은 간결한 툴바로 바뀌었고, 이 배치는 워크스페이스마다 따로 기억해서 새로고침이나 세션 전환으로도 사라지지 않습니다. 첫 문장을 보내면 탭과 배치 순서, 패널 너비와 전체 화면까지 통째로 새 세션에 넘깁니다. 관련 PR: [#14159](https://github.com/QwenLM/qwen-code/pull/14159)

**Trajectory 탭은 검색하고, 필터링하고, 과거로 넘길 수 있습니다.** 도구 이름, 모델 이름, 기록된 문구를 검색하면 해당 항목으로 이동하고, 특정 종류만 보거나 실패·성공만 볼 수도 있습니다. 오래된 기록도 구간씩 넘겨 볼 수 있고, 끝까지 보면 최신으로 돌아옵니다 — 검색과 통계는 지금 열어 본 구간만 계산합니다. 도중에 연결이 끊겼다 돌아와도 서 있던 위치, 골랐던 항목, 필터, 스크롤 위치가 그대로 남습니다. 관련 PR: [#13264](https://github.com/QwenLM/qwen-code/pull/13264), [#13716](https://github.com/QwenLM/qwen-code/pull/13716), [#13952](https://github.com/QwenLM/qwen-code/pull/13952)

**답에서 일부를 선택하면 복사 방식을 고를 수 있습니다.** 마우스로 문지르면 메뉴에 두 가지가 나옵니다 — 평문, 또는 원본 서식을 살린 Markdown. 제목, 목록, 코드, 표까지 함께 따라갑니다. 관련 PR: [#13833](https://github.com/QwenLM/qwen-code/pull/13833)

**컨텍스트 사용량은 누르면 오른쪽에 열리고, 대화에 카드를 쌓지 않습니다.** 전에 입력창의 링을 누르면 대화에 `Context Usage` 카드가 하나 떨어지고, 그 카드의 상세를 열면 또 하나 떨어졌습니다. 이제는 둘 다 오른쪽 패널에 열리고 세션마다 하나씩 남습니다. 대화에 두고 싶으면 `/context`를 치세요. 관련 PR: [#14086](https://github.com/QwenLM/qwen-code/pull/14086)

**넓고 긴 표는 전체 화면으로 봅니다.** 표의 `Fullscreen`을 누르면 창 전체로 펼치고, Esc나 종료 버튼으로 나옵니다. 정렬과 필터, 컬럼 설정, 몇 번째 줄까지 읽었는지가 그대로 남아 있습니다. 관련 PR: [#13589](https://github.com/QwenLM/qwen-code/pull/13589)

**대기열에 줄 선 말은 보내기 전에 그 자리에서 지웁니다.** 첨부 파일을 올리던 도중이던 문장도 지워지고, 중간에 만들어진 파일까지 함께 정리됩니다. 관련 PR: [#13594](https://github.com/QwenLM/qwen-code/pull/13594)

**이 라운드를 접으면 백그라운드 결과까지 함께 숨습니다.** 백그라운드 작업의 산출물 카드와 완료 알림이 접힘 안으로 들어갑니다. 관련 PR: [#13825](https://github.com/QwenLM/qwen-code/pull/13825)

**음성 입력 안내에 중국어가 생기고, 오류는 닫을 수 있습니다.** 오류나 '소리를 듣지 못했다' 같은 안내가 화면 언어를 따릅니다. 안내 오른쪽 위의 닫기를 누르면 마이크가 대기 상태로 돌아가 바로 다시 시도할 수 있습니다. 관련 PR: [#13938](https://github.com/QwenLM/qwen-code/pull/13938)

**독립된 사본이 필요하면 Worktree를 고르면 끝납니다.** Git 대화상자에서 Worktree를 고르면 그대로 선택되고 메뉴가 닫힙니다. 첫 문장을 보낼 때 비로소 세션 생성 절차에 따라 이름이 지어지고 사본이 만들어지니, 그 전에는 언제든 되돌릴 수 있습니다. 관련 PR: [#13607](https://github.com/QwenLM/qwen-code/pull/13607)

**아이콘을 현재 브랜드 마크로 통일했습니다.** Web Shell의 브라우저 탭 아이콘, 사이드바 로고, 브라우저 알림 아이콘, 데스크톱 버전의 시작 화면과 앱 아이콘까지 바뀝니다. 관련 PR: [#14052](https://github.com/QwenLM/qwen-code/pull/14052)
