Qwen Code는 이번 주에 v0.21.12부터 v0.21.14까지 세 개의 정식 버전을 출시하고 PR 140개 이상을 병합했습니다.

**독립적인 세컨드 오피니언.** `/advisor`가 현재 대화를 독립적으로 검토해 결론, 리스크, 부족한 근거, 제안 네 가지를 알려줍니다. 전 과정 읽기 전용이라 메인 대화는 건드리지 않습니다.

**명령어 하나로 실행 중인 세션 확인.** 새로 추가된 `qwen sessions ps` 명령어가 이 PC에서 어떤 세션이 실행 중인지 보여줍니다. 어느 디렉터리에서, 얼마나 실행됐는지, 프로세스 번호까지.

**중단된 Review, 처음부터 다시 하지 않아도 됩니다.** 중단된 PR 검토는 `--resume`으로 이어받을 수 있습니다. 상태가 그대로인지 확인한 뒤, 일치하면 중단된 지점부터 계속합니다.

## ✨ 새로운 기능

### /advisor: 독립적인 모델이 현재 대화를 검토합니다

대화가 길어지면 한 가지 흐름에 갇히기 쉽고, 내 컨텍스트 안의 사각지대는 알아채기 어렵습니다. `/advisor`가 현재 대화에 독립적인 세컨드 오피니언을 붙여줍니다. 읽기 전용 보조 세션 하나가 전체 컨텍스트를 처음부터 끝까지 읽고, 결론, 리스크, 부족한 근거, 제안 네 가지를 내놓습니다. 세컨드 오피니언은 철저히 읽기 전용입니다. 메인 대화를 바꾸지도, 어떤 작업도 실행하지 않으며, 검토가 끝난 뒤에도 이어지는 대화에 영향을 주지 않습니다.

관심 있는 부분을 함께 물어볼 수도 있습니다. 예를 들어 `/advisor 이 방안 안전한가요`처럼요. `advisorModel` 설정으로 검토 전용 모델을 지정할 수 있고, 지정하지 않으면 현재 모델을 사용합니다.

관련 PR: [#7567](https://github.com/QwenLM/qwen-code/pull/7567)

### qwen sessions ps: 명령어 하나로 실행 중인 세션 확인

Qwen Code 세션을 여러 개 동시에 열어 두면 어떤 게 어떤 것인지 헷갈리기 쉽습니다. 새로 추가된 `qwen sessions ps` 명령어는 이 PC에서 지금 실행 중인 모든 대화형 세션을 한 줄에 하나씩 보여줍니다. 세션 이름, 프로세스 번호, 실행 시간, 위치한 디렉터리. 스크립트와 연결하려면 `--json`을 붙여 JSON으로 출력하면 됩니다.

목록에 보이는 세션은 전부 실제로 실행 중인 것들입니다. 세션을 하나 닫으면 목록에서도 바로 사라집니다.

관련 PR: [#8969](https://github.com/QwenLM/qwen-code/pull/8969)

![qwen sessions ps가 실행 중인 세션을 보여줍니다](https://img.alicdn.com/imgextra/i1/O1CN01edM2ef0oKxI7nOLI_!!6000000005536-2-tps-3840-2160.png)

### Review: 중단된 PR 검토 이어받기, 댓글은 알기 쉽게

이번 주 `/review`에 실용적인 개선이 몇 가지 추가됐습니다.

**중단된 검토를 이어서.** 큰 PR을 검토하다 중단되면 이전에는 처음부터 다시 해야 했습니다. 이제 `qwen review fetch-pr`에 `--resume`이 추가됐습니다. 먼저 디스크의 상태를 대조합니다. 지난번 검토 보고서, worktree, diff 내용이 모두 그대로이고 PR도 갱신되지 않았다면 이어서 실행하고, 하나라도 맞지 않으면 자동으로 처음부터 다시 시작합니다.

**검토 댓글이 알기 쉬워졌습니다.** `/review`로 PR을 검토하고 댓글을 달 때, 이전 댓글은 템플릿 특유의 딱딱한 말투가 강했습니다. 이제는 문제가 어디인지, 언제 문제가 생기는지, 어떻게 고치는지를 자연스러운 검토 문장으로 정리합니다. PR에 남기는 댓글은 심각도 표시와 서명을 넣을지, 얼마나 깊이 검토할지, 실제로 게시할지까지 설정에서 조정할 수 있습니다.

**스크립트 검토는 실행 환경을 봅니다.** shell 스크립트나 CI 설정 같은 파일은 '이 기계에서는 멀쩡한데 환경이 바뀌면 죽는' 문제를 찾아내기 어렵습니다. 이제는 검토할 때 이 파일들이 실제로 어떤 환경에서 실행되는지 먼저 파악하고, 그 환경의 특성에 맞춰 검토합니다.

관련 PR: [#9092](https://github.com/QwenLM/qwen-code/pull/9092), [#9027](https://github.com/QwenLM/qwen-code/pull/9027), [#8994](https://github.com/QwenLM/qwen-code/pull/8994), [#9263](https://github.com/QwenLM/qwen-code/pull/9263)

### Web Shell 파일 전송: 로컬 파일을 대화에 바로 드래그

원격 연결 토큰(`QWEN_SERVER_TOKEN` 또는 `--token`)을 설정해 두면, 파일을 Web Shell 대화 입력창에 끌어다 놓거나 복사해서 붙여넣는 것만으로 Qwen Code에 전달됩니다. 어떤 파일이든 워크스페이스에 저장되고 대화에는 자동으로 참조가 붙어 AI가 바로 사용할 수 있습니다. 텍스트 파일은 내용을 대화에 그대로 첨부할 수도 있어, AI가 파일을 열지 않고 그 자리에서 읽습니다.

파일이 저장될 폴더를 지정할 수도 있고, 폴더가 없으면 자동으로 만들어집니다. 토큰을 설정하지 않은 상태에서는 파일 드래그나 붙여넣기를 아직 지원하지 않습니다.

관련 PR: [#8874](https://github.com/QwenLM/qwen-code/pull/8874), [#9180](https://github.com/QwenLM/qwen-code/pull/9180), [#9382](https://github.com/QwenLM/qwen-code/pull/9382)

## 📊 그 외 새로운 기능

**워크플로 agent를 특정 디렉터리에 고정할 수 있습니다.** 워크플로에서 `agent({workingDir})`로 agent를 특정 디렉터리에 고정해 작업시킬 수 있습니다. 기본 디렉터리 범위에 얽매이지 않습니다. 관련 PR: [#8972](https://github.com/QwenLM/qwen-code/pull/8972)

**릴리스 노트에 이중 언어 요약이 생겼습니다.** 릴리스 노트가 더 이상 PR 목록을 그대로 나열하지 않습니다. 기능 주제별로 묶고 각 그룹마다 알기 쉬운 요약을 한 단락씩 붙이며, 중국어 버전도 함께 제공합니다. PR에 포함된 변경 전후 비교 스크린샷도 함께 가져옵니다. 관련 PR: [#9216](https://github.com/QwenLM/qwen-code/pull/9216)

**외부 지식 베이스 연동에 통합 규격이 생겼습니다.** 검색 서비스를 만드는 업체는 이 규격에 맞춰 Qwen Code 플러그인을 개발할 수 있고, 플러그인을 설치하면 AI가 해당 업체의 코퍼스를 검색할 수 있습니다. 무엇을 검색할 수 있는지는 설치한 플러그인이 결정하며, AI는 그 범위 안에서만 검색합니다. 관련 PR: [#9068](https://github.com/QwenLM/qwen-code/pull/9068)

## 👏 사용성 개선

**Channel 관리가 완전한 관리 페이지로 새로워졌습니다.** Web Shell의 Channel 관리가 예약 작업과 같은 전체 페이지 레이아웃으로 바뀌었습니다. 채널별로 누구에게 허용할지, 승인제인지 화이트리스트인지, 세션을 어떻게 나눌지, 어느 워크스페이스에 연결할지 한 페이지에서 모두 설정합니다. 관련 PR: [#8848](https://github.com/QwenLM/qwen-code/pull/8848)

**WeChat '입력 중' 표시가 긴 작업 도중에도 끊기지 않습니다.** WeChat의 '상대방이 입력 중입니다' 상태는 만료 시간이 있어, 이전에는 긴 작업을 실행하면 도중에 표시가 사라져 연결이 끊긴 것처럼 보였습니다. 이제는 작업 실행 중 4초마다 갱신되고, 작업이 끝나야 사라집니다. 관련 PR: [#9358](https://github.com/QwenLM/qwen-code/pull/9358)

**컴팩트 모드에서도 AI의 사고를 볼 수 있습니다.** Web Shell 컴팩트 모드(Ctrl+O)는 이전에는 thinking 내용을 통째로 숨겼습니다. 이제는 모델이 사고하는 동안 요약에 'thinking 중'으로 표시되고, 사고가 끝나면 도구 요약 안으로 접혀 들어가며, 클릭해서 볼 수 있습니다. 관련 PR: [#9148](https://github.com/QwenLM/qwen-code/pull/9148)

**사이드바를 접어도 세션을 전환할 수 있습니다.** Web Shell 사이드바를 접은 상태에서 프로젝트 아이콘에 마우스를 올리면 전체 세션 브라우저가 열립니다. 승인 대기, 질문, 완료 대기 같은 상태는 아이콘에 색상으로 표시됩니다. 관련 PR: [#9311](https://github.com/QwenLM/qwen-code/pull/9311)

**이미지 미리보기가 새로고침 후에도 사라지지 않습니다.** Web Shell에서 보낸 이미지는 대기열에 있든 이미 작업에 주입됐든, 페이지를 새로고침해도 미리보기가 그대로 유지됩니다. 여러 장의 이미지도 합쳐지거나 사라지지 않습니다. 관련 PR: [#9310](https://github.com/QwenLM/qwen-code/pull/9310)

**연결이 끊겨도 질문을 보낼 수 있습니다.** Web Shell 입력창이 연결 상태와 분리됐습니다. 스트림이 끊겨도 질문을 정상적으로 보낼 수 있고, 입력창이 잠기지 않습니다. 관련 PR: [#9323](https://github.com/QwenLM/qwen-code/pull/9323)

**내보낸 HTML을 한 번에 펼치고 접습니다.** `/export`로 내보낸 대화 HTML 페이지 상단에 '모두 펼치기 / 모두 접기' 버튼이 생겼습니다. thinking 블록과 도구 출력을 한 번에 전환합니다. 관련 PR: [#9367](https://github.com/QwenLM/qwen-code/pull/9367)

**큰 세션의 복원이 빨라졌습니다.** daemon의 세션 복원이 필요할 때만 읽는 방식으로 바뀌어, 상태 재구성에 필요한 기록만 읽습니다. 큰 세션일수록 효과가 뚜렷합니다. 관련 PR: [#9055](https://github.com/QwenLM/qwen-code/pull/9055)

**백그라운드 shell이 실수로 정리되지 않습니다.** 백그라운드에서 실행 중인 shell이 활성 작업으로 집계되어, 활동 중에는 자동으로 정리되지 않습니다. 관련 PR: [#9042](https://github.com/QwenLM/qwen-code/pull/9042)
