Qwen Code는 이번 주 v0.28.3, v0.28.4, v0.28.6 세 개의 정식 버전을 출시했습니다.

**다른 세션에 작업을 맡깁니다.** Web Shell에서 `/send`로 다른 세션에 작업을 넘기면, 그쪽이 이어서 처리하고 결과를 가져와 보고합니다.

**예약 작업 결과를 지정 주소로 보냅니다.** 채널 관리에 Generic Webhook을 추가하고 수신 주소를 넣으면, 예약 작업이 끝날 때 결과가 자동으로 전송됩니다.

**생성 파일은 한곳에서 봅니다.** 모든 세션이 만든 보고서와 내보내기 파일이 Artifacts 페이지에 모입니다. 세션을 일일이 열지 않고 바로 미리보거나 다운로드합니다.

## ✨ 새로운 기능

### /send로 다른 세션에 작업 넘기기

Web Shell에서 `/send 방금 실패한 테스트 확인해 줘`를 입력하면 같은 워크스페이스에 새 세션이 열려 작업을 이어받습니다. `--workspace`로 워크스페이스를 고르거나 `--session-id`로 기존 세션을 지정합니다. 작업이 끝나면 현재 세션이 결과를 전해 줍니다.

AI도 이 방식으로 작업을 넘깁니다. 사용자가 직접 연 세션에도 작업을 맡길 수 있고, YOLO 모드에서는 다른 프로젝트 폴더로 작업을 넘길 때도 확인 없이 바로 진행됩니다.

이렇게 활용할 수 있습니다:

- A 세션에서 자료를 조사한 뒤 B 세션으로 넘겨 방안 작성을 이어갑니다
- 메인 세션에서는 코드를 계속 쓰고, 테스트 문제 조사는 다른 세션에 맡깁니다
- 오른쪽 패널에서 진행 상황을 보고, 상대 세션의 확인 요청과 질문을 그 자리에서 처리합니다

관련 PR: [#17539](https://github.com/QwenLM/qwen-code/pull/17539), [#17818](https://github.com/QwenLM/qwen-code/pull/17818)

### 채널: 예약 작업 결과를 지정 주소로 전송, 진행 중 방향 수정

**예약 작업 결과를 지정 주소로 보냅니다.** Feishu, WeCom, DingTalk 그룹 전송에 이어, 플랫폼을 가리지 않는 Generic Webhook이 추가됐습니다. 채널 관리에 HTTPS 수신 주소를 넣으면 알림과 예약 작업 결과가 그리로 전송됩니다. 관련 PR: [#17405](https://github.com/QwenLM/qwen-code/pull/17405)

**진행 중인 작업의 방향을 바로잡습니다.** 터미널에서 독립 실행한 채널은 inject 전달 모드를 지원합니다. AI가 작업하는 중에 도착한 메시지가 현재 턴에 바로 전달되어, 도중에도 내용을 읽고 방향을 조정합니다. 작업이 어긋나면 한마디만 보태면 됩니다. 관련 PR: [#15634](https://github.com/QwenLM/qwen-code/pull/15634)

**QQ 봇이 파일을 채팅으로 보냅니다.** QQ 채널 설정에서 `fileTools`를 `true`로 바꾸고(기본값은 꺼짐) 채널을 재시작하면, AI가 워크스페이스에서 만든 파일, 이미지, 영상, 음성을 채팅으로 바로 보냅니다. 관련 PR: [#15450](https://github.com/QwenLM/qwen-code/pull/15450)

이렇게 활용할 수 있습니다:

- 예약 작업이 끝나면 결과가 내 시스템으로 자동 전송됩니다
- 작업이 어긋나면 그룹에 한마디 보태 AI가 그 자리에서 방향을 바꾸게 합니다
- QQ에서 바로 작업을 맡기고, 만든 파일은 그 채팅으로 돌려받습니다

[📸 데모 스크린샷 추가 예정: Generic Webhook 설정 페이지와 QQ에서 받은 파일]

### Web Shell: 산출물은 한 페이지에, 입력 기록은 기기 간 공유

**세션 산출물을 한 페이지에서 보고 다운로드합니다.** 로컬 배포 Web Shell에 Artifacts 페이지가 생겼습니다. 워크스페이스 전체 세션이 만든 보고서, 내보내기 파일, 웹페이지 미리보기 스냅샷이 한 페이지에 모입니다. 바로 미리보거나 다운로드합니다. 관련 PR: [#18071](https://github.com/QwenLM/qwen-code/pull/18071), [#17689](https://github.com/QwenLM/qwen-code/pull/17689)

**입력 기록이 기기 간 공유됩니다.** PC에서 입력한 프롬프트와 명령을 휴대폰에서 같은 워크스페이스를 열면 입력 기록에서 찾습니다. 반대 방향도 같습니다. 관련 PR: [#18120](https://github.com/QwenLM/qwen-code/pull/18120)

**사이드바에서 세션 상태를 알아봅니다.** 목표가 있는 세션에는 목표 표식이 붙고, 색은 Goals 페이지와 같습니다. 실행 중은 파란색, 처리 대기는 호박색입니다. 지난 턴이 중단된 세션에는 Continue 배지가 붙어, 다시 시작했을 때 이어갈 세션을 한눈에 고릅니다. 관련 PR: [#17515](https://github.com/QwenLM/qwen-code/pull/17515), [#18044](https://github.com/QwenLM/qwen-code/pull/18044)

**휴대폰 Follow-up 제안은 눌러서 고릅니다.** 제안이 입력창 위의 누를 수 있는 버튼으로 바뀌었습니다. 누르면 입력창에 채워지고, 고친 뒤 보내면 됩니다. 관련 PR: [#17918](https://github.com/QwenLM/qwen-code/pull/17918)

**그 외 개선.** Generated UI 카드의 버튼으로 텍스트를 바로 복사하거나 작은 파일을 다운로드합니다([#18158](https://github.com/QwenLM/qwen-code/pull/18158)). 터치 편집 바는 휴대폰과 iPad에서 한 줄을 유지합니다([#18126](https://github.com/QwenLM/qwen-code/pull/18126)).

## 📊 그 외 새로운 기능

**번체 중국어 인터페이스.** Web Shell과 VS Code Companion 인터페이스에 번체 중국어가 추가됐습니다. 언어 선택에서 「繁體中文 [zh-TW]」를 고르면 됩니다. 관련 PR: [#17421](https://github.com/QwenLM/qwen-code/pull/17421)

**표시 번역.** 설정에서 `general.displayLanguage`로 간체 중국어를 고르면, 모델이 영어로 쓴 답변과 펼친 사고 내용이 터미널과 Web Shell에서 중국어로 표시됩니다. 저장, 복사, 후속 대화에는 원문이 그대로 남습니다. 기본값은 꺼짐이며, 터미널 `/settings`나 Web Shell 설정 페이지에서 켭니다. 관련 PR: [#18175](https://github.com/QwenLM/qwen-code/pull/18175)

**Microsoft Teams 채널 확장.** `@qwen-code/channel-msteams` 확장을 따로 설치하고 Azure 봇을 설정하면, Teams 개인 대화와 그룹에서 봇을 @로 불러 작업을 맡깁니다. 주제별 대화는 각자 독립적으로 진행됩니다. 관련 PR: [#15620](https://github.com/QwenLM/qwen-code/pull/15620)

**CLI 스크린 리더 모드.** 터미널에 스크린 리더 모드(실험적)가 생겼습니다. 시작할 때 `--screen-reader`를 붙이면 답변 완료 후 한 번 읽어 주고, 기록은 키보드로 넘깁니다. 현재 선택된 항목과 승인 대기 중인 작업도 읽어 줍니다. 기본 그래픽 인터페이스는 그대로입니다. 관련 PR: [#17500](https://github.com/QwenLM/qwen-code/pull/17500)

## 👏 사용성 개선

**Web Shell이 더 빨리 열립니다.** 터미널은 쓸 때만 로드하고, 큰 세션 기록은 압축해서 전송합니다. 과거 세션을 눌러 내용을 보기까지 실측 시간이 약 1.3초에서 0.8초로 줄었습니다. 관련 PR: [#17840](https://github.com/QwenLM/qwen-code/pull/17840), [#11220](https://github.com/QwenLM/qwen-code/pull/11220), [#18223](https://github.com/QwenLM/qwen-code/pull/18223)

**백그라운드 작업 배지에 물음표가 생겼습니다.** 입력창 위 배지마다 물음표가 하나씩 붙었습니다. 누르면 AI가 그 작업이 무엇을 하는지, 왜 시작됐는지 쉬운 말로 설명합니다. 답은 옆 문답 패널에 표시되고, 현재 대화와 작업은 그대로 진행됩니다. 관련 PR: [#17398](https://github.com/QwenLM/qwen-code/pull/17398)

**명령 실행 중에도 보탠 말에 바로 답합니다.** AI가 명령을 실행하는 중에 말을 보태면, 명령은 백그라운드로 옮겨 계속 실행되고 보탠 말에는 그 자리에서 답이 옵니다. 관련 PR: [#17926](https://github.com/QwenLM/qwen-code/pull/17926)

**MCP 설정 변경이 즉시 반영됩니다.** 설정에서 MCP 서버를 추가하거나 삭제하면 실행 중인 세션에 재시작 없이 바로 적용됩니다. 관련 PR: [#17743](https://github.com/QwenLM/qwen-code/pull/17743)

**Follow-up 제안이 더 빨리 나옵니다.** 제안을 만들 때 대화의 짧은 구간만 참고합니다. 관련 PR: [#17532](https://github.com/QwenLM/qwen-code/pull/17532)

**Mods 플러그인이 바꾼 텍스트가 Web Shell에도 표시됩니다.** 답변과 펼친 사고 내용이 플러그인이 바꾼 모습 그대로 표시됩니다. 기록, 복사, 검색, 분기에는 원문이 쓰입니다. `experimental.mods`를 켜야 합니다. 관련 PR: [#17718](https://github.com/QwenLM/qwen-code/pull/17718), [#17920](https://github.com/QwenLM/qwen-code/pull/17920)

**워크플로 단계를 처음부터 미리 봅니다.** 워크플로가 거칠 단계를 시작 시점에 전부 나열합니다. 아직 실행되지 않은 단계는 미리 표시하고, 실행되면 실제 진행 상황을 보여 줍니다. 전체가 어디까지 왔는지 한눈에 봅니다. 먼저 환경 변수 `QWEN_CODE_ENABLE_WORKFLOWS=1`로 워크플로를 켜야 합니다. 관련 PR: [#17782](https://github.com/QwenLM/qwen-code/pull/17782)

**Gemini 4, Kimi K3 사고 깊이 단계 자동 적용.** 두 모델을 연결하면 사고 깊이 단계를 바로 쓸 수 있습니다. 관련 PR: [#18039](https://github.com/QwenLM/qwen-code/pull/18039), [#18095](https://github.com/QwenLM/qwen-code/pull/18095)

**대체 모델 전환이 더 빨라집니다.** `experimental.modelAvailabilityTracking`을 켜면 이번 턴에서 용량 부족으로 실패한 모델은 건너뛰고 다음 대체 모델을 바로 씁니다. 실패한 모델은 다음 턴에 다시 시도합니다. 기본값은 꺼짐입니다. 관련 PR: [#17377](https://github.com/QwenLM/qwen-code/pull/17377)
