# 설정 참조

## 개요

이 페이지는 `qwen serve` daemon과 adapter에 영향을 미치는 모든 설정을 수집합니다: 환경 변수, CLI 플래그, `settings.json` 키, 프로그래밍 옵션. 기능별 페이지는 교차 설정 정보가 필요할 때 여기로 링크합니다.

[`qwen-serve.md` — 에이전트 텍스트 쓰기의 새 파일 모드](../../users/qwen-serve.md#new-file-mode-for-agent-text-writes) 참조. |

### `BridgeOptions.childEnvOverrides`를 통해 ACP 자식으로 전달

`runQwenServe`는 핸들별로 이를 구성하므로, 한 프로세스의 두 daemon이 `process.env`에서 경주하지 않습니다. 예산 변수는 `qwen serve`의 부모 프로세스 env 폴백이 아닙니다. CLI 경로는 `--mcp-client-budget` / `--mcp-budget-mode`에서 이를 생성해야 합니다.

| 환경 변수                              | 효과                                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `QWEN_SERVE_MCP_CLIENT_BUDGET`   | ACP 자식의 `readBudgetFromEnv()`에서 소비하는 양의 정수 문자열.                                               |
| `QWEN_SERVE_MCP_BUDGET_MODE`     | `off` / `warn` / `enforce`.                                                                                              |
| `QWEN_SERVE_MCP_POOL_TRANSPORTS` | 쉼표로 구분된 전송 허용 목록. 기본 풀 전송은 `stdio,websocket`. `http,sse`를 명시적으로 포함 가능. |
| `QWEN_SERVE_MCP_POOL_DRAIN_MS`   | 풀 엔트리 유휴 드레인 지연. 기본값 `30000`, `1000..600000`ms 범위로 제한.                                              |

| `QWEN_DAEMON_WORKSPACE` | `POST /session`에 전송되는 `cwd`를 오버라이드.                      |

## `settings.json` 키

daemon은 각 워크스페이스의 병합된 설정과 환경 오버레이에서 각 워크스페이스 런타임을 구성합니다. 프로세스 전역 리스너/인증 옵션은 한 번 해석되며, 런타임별 서비스와 ACP 자식은 소유 런타임 스냅샷을 받습니다. 잘못된 설정은 영향을 받는 런타임에 대해 문서화된 시작 폴백 또는 실패 동작을 따릅니다. 다른 워크스페이스의 설정이 재사용되게 해서는 안 됩니다.

| 키                         | 타입                                                               | 효과                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `policy.permissionStrategy` | `'first-responder' \| 'designated' \| 'consensus' \| 'local-only'` | `BridgeOptions.permissionPolicy` 설정. 활성 값은 `/capabilities`에 `policy.permission`으로 표시. **부팅 시** `SERVE_CAPABILITY_REGISTRY.permission_mediation.modes`에 대해 `validatePolicyConfig()`를 통해 검증. 알 수 없는 리터럴은 `InvalidPolicyConfigError`를 발생시키고 부팅을 명시적으로 실패.                                                                                                                                                                                                                               |
| `policy.consensusQuorum`    | 양의 정수                                                   | `consensus` 정책의 N. **기본값**은 `votersAtIssue.size`에 대해 `floor(M/2) + 1`(M=2는 만장일치; 더 큰 짝수 M은 과반 이상). consensus가 아닌 정책에서 설정하면 무시되며 부팅 시 stderr 경고를 출력. 양이 아닌 정수는 `InvalidPolicyConfigError`를 발생. [`04-permission-mediation.md`](./04-permission-mediation.md) 참조.                                                                                                                                                                        |
| `context.fileName`          | string                                                             | `BridgeOptions.contextFilename`을 통해 `getCurrentGeminiMdFilename()` 오버라이드.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `tools.disabled`            | string[]                                                           | 다음 ACP 자식 spawn에 대해 비활성화되는 도구. `normalizeDisabledToolList()`를 통해 정규화(`packages/cli/src/config/normalizeDisabledTools.ts`): 비배열은 `[]`가 되고, 비문자열 항목은 건너뛰며, 공백이 트리밍되고, 빈 항목은 삭제되며, 첫 번째 항목을 유지하면서 중복이 제거. 부팅과 `restartMcpServer` 설정 새로고침 모두 이 함수를 통과. `ToolRegistry.has(name)`은 정확하고 대소문자를 구분. `POST /workspace/tools/:name/enable` 및 `tool_toggled`가 이 키를 업데이트. |
| `tools.approvalMode`        | `'default' \| 'auto' \| ...`                                       | 기본 세션 승인 모드. `persist: true`일 때 `POST /session/:id/approval-mode`가 여기에 기록.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `telemetry`                 | object                                                             | OTel 설정. 키는 `enabled`, `otlpEndpoint`, `otlpProtocol`, `otlpTracesEndpoint`, `otlpLogsEndpoint`, `otlpMetricsEndpoint`, `target`, `outfile`, `userId`, `includeSensitiveSpanAttributes`, `sensitiveSpanAttributeMaxLength`, `resourceAttributes`, `metrics.includeSessionId`를 포함. `resolveTelemetrySettings()`가 부팅 시 읽고 `initializeTelemetry()`를 초기화. `userId`는 프로세스 전체이며 daemon이 여러 사용자에게 서비스할 때 최종 사용자 정체성으로 설정하면 안 됨.                                   |

## `ServeOptions` (프로그래밍 임베딩)

`packages/cli/src/serve/types.ts`는 공개 serve API를 통해 전달되는 타입화된 옵션을 정의합니다. 위의 CLI 플래그를 미러링하며 다음을 추가합니다:

| 필드                         | 효과                                                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `eventRingSize`               | 기본 세션당 링 크기를 오버라이드.                                                                                                      |
| `memoryProjectScope`          | `runQwenServe` 전용. 우선순위: 옵션, 런치 env, 그다음 `workspace`. 직접 `createServeApp` 호출자는 `deps.daemonEnv`를 사용.              |
| `maxPendingPromptsPerSession` | 세션당 대기 프롬프트 상한. `0` / `Infinity`는 무제한.                                                                                 |
| `mcpPoolActive`               | 프로그래밍 스위치. `QWEN_SERVE_NO_MCP_POOL`에서 기본값 결정.                                                                                    |
| `externalToolGuard`           | 선택적 `{mode:'required', endpoint, token, timeoutMs?}`. 생략하면 완전히 비활성화. required 모드는 수신 전에 프로바이더 핸드셰이크 수행. |
| `allowOrigins`                | 교차 origin 허용 목록(`string[]`). `--allow-origin`에 해당.                                                                           |
| `allowPrivateAuthBaseUrl`     | 사설 / localhost 인증 프로바이더 `baseUrl` 설치를 허용.                                                                                  |
| `serveWebShell`               | 데몬 루트에서 빌드된 Web Shell SPA를 제공(기본 `true`). `false`(CLI의 `--no-web`)는 데몬을 API 전용으로 남깁니다. 빌드에 셸 애셋이 없으면 효과 없음. |
| `enableSessionShell`          | 세션 셸 실행 활성화. Bearer 토큰과 세션 바인딩 클라이언트 id는 여전히 필요.                                                     |
| `promptDeadlineMs`            | 프롬프트 월클럭 제한.                                                                                                                           |
| `writerIdleTimeoutMs`         | SSE 라이터 유휴 타임아웃.                                                                                                                          |
| `channelIdleTimeoutMs`        | 마지막 세션이 닫힌 후 ACP 자식을 웜 상태로 유지하는 시간.                                                                                |
| `initializeTimeoutMs`         | initialize 핸드셰이크를 포함한 ACP 자식 요청 타임아웃.                                                                                    |
| `sessionRestoreTimeoutMs`     | ACP 세션 로드/재개 타임아웃. 우선순위: 명시적 복원 값. 그렇지 않으면 명시적 initialize 값이 60000 기본값을 높이되 낮추지는 않음. 그렇지 않으면 60000.     |
| `sessionReapIntervalMs`       | 세션 리퍼 스캔 간격.                                                                                                                     |
| `sessionIdleTimeoutMs`        | 연결 해제된 세션의 유휴 회수 시간.                                                                                                           |
| `rateLimit*`                  | 티어별 HTTP 속도 제한 스위치, 임계값 및 윈도우.                                                                                          |
