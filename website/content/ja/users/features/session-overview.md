# セッション概要

Web Shell の Session Overview を使って、セッションの閲覧、会話への復帰、セッションタイトルとアーカイブの管理を行います。

## セッションの検索とオープン

**More → Session Overview** を開きます。セッションタイトル、セッション ID、Git ブランチ、`#123` のような関連付けられたプルリクエスト番号で検索できます。ステータスフィルターでリストを絞り込みます。複数のワークスペースが利用可能な場合、ワークスペースフィルターで含めるものを選択できます。**Refresh** を選択してカタログを再読み込みします。

セッション行をクリックすると、その会話を開きます。行のチェックボックスでセッションを選択し、フッターのアクションを実行します。ページネーションコントロールで、表示ページと行数を変更します。

## セッションの名前変更

利用可能な場合、行の鉛筆アクションを選択し、タイトルを編集します。**Enter** で保存、**Escape** でキャンセルします。エディタがフォーカスを失った場合、未完了の名前変更は保存されずにキャンセルされます。

## セッションのアーカイブ

行のチェックボックスでセッションを選択し、フッターの **Archive** を選択します。このアクションは、選択したすべてのセッションがアイドル状態でアーカイブをサポートしている場合にのみ有効です。ダイアログでアーカイブを確認するか、**Cancel** を選択してセッションをアクティブなままにします。

**Archive** をクリックした時点で名前変更エディタにまだフォーカスがある場合、未完了のドラフトはキャンセルされ、アーカイブ確認ダイアログが開きます。名前変更の入力やキャンセルを行ってもフッターコントロールはそのまま維持されるため、ボタンの端付近をクリックしても確実にそのボタンに到達します。
