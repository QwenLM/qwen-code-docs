# Qwen Code キーボードショートカット

本文書では、Qwen Code で利用可能なキーボードショートカットの一覧を紹介します。

## 一般

| ショートカット                       | 説明                                                                                                                                                                                                                                                                                               |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                          | ダイアログと提案を閉じます。                                                                                                                                                                                                                                                                            |
| `Ctrl+C`                       | 進行中のリクエストをキャンセルし、入力をクリアします。2回押すとアプリケーションを終了します。                                                                                                                                                                                                                      |
| `Ctrl+D`                       | 入力が空の場合にアプリケーションを終了します。2回押すと確定します。                                                                                                                                                                                                                                       |
| `Ctrl+L`                       | 画面をクリアします。                                                                                                                                                                                                                                                                                         |
| `Ctrl+O`                       | コンパクトモードを切り替えます（ツール出力と思考の表示/非表示）。                                                                                                                                                                                                                                                 |
| `Ctrl+S`                       | 長いレスポンスの切り捨てを無効にして、完全に出力できるようにします。ターミナルのスクロールバックを使用して、出力全体を表示します。                                                                                                                                                                                     |
| `Ctrl+T`                       | ツール説明の表示を切り替えます。                                                                                                                                                                                                                                                                  |
| `Ctrl+B`                       | フォアグラウンドのシェルコマンドの実行中: バックグラウンドタスクに昇格させます。子プロセスは実行を継続し、エージェントのターンがブロック解除され、シェルは `/tasks` とバックグラウンドタスクダイアログに表示されます。シェルが実行されていない場合はノーオペレーションとなり、Ctrl+B はプロンプト領域のバインディング（カーソル左）にフォールスルーします。 |
| `Alt/Option+M`                 | Markdown 出力をリッチレンダリングプレビューと生/ソースモードの間で切り替えます。macOS では、ターミナルが Option を Meta として送信する必要があります。                                                                                                                                                                               |
| `Shift+Tab`（Windows では `Tab`） | 承認モードを循環させます（`plan` → `default` → `auto-edit` → `auto` → `yolo`）                                                                                                                                                                                                                                 |

| `Meta+Delete` / `Ctrl+Delete`                         | カーソルの右側の単語を削除します。                                                                                         |
| `Tab`                                                 | 提案が存在する場合は、現在の提案をオートコンプリートします。                                                                                  |
| `Up Arrow`                                            | 上に移動し、次に先頭にスナップし、次に履歴の前へ移動します。                                                                                      |
| `Ctrl+A` / `Home`                                     | カーソルを行の先頭に移動します。                                                                                       |
| `Ctrl+B` / `Left Arrow`                               | カーソルを1文字左に移動します。                                                                                          |
| `Ctrl+C`                                              | 入力プロンプトをクリアします。                                                                                                              |
| `Esc`（2回押し）                                  | 入力プロンプトをクリアします。                                                                                                             |
| `Ctrl+D` / `Delete`                                   | カーソルの右側の文字を削除します。                                                                                    |
| `Ctrl+E` / `End`                                      | カーソルを行の末尾に移動します。                                                                                             |
| `Ctrl+F` / `Right Arrow`                              | カーソルを1文字右に移動します。                                                                                         |
| `Ctrl+H` / `Backspace`                                | カーソルの左側の文字を削除します。                                                                                     |
| `Ctrl+K`                                              | カーソルから行の末尾までを削除します。                                                                                      |
| `Ctrl+Left Arrow` / `Meta+Left Arrow` / `Meta+B`      | カーソルを1単語左に移動します。                                                                                               |
| `Ctrl+N`                                              | 下に移動し、次に末尾にスナップし、次に履歴の次へ移動します。                                                                                      |
| `Ctrl+P`                                              | 上に移動し、次に先頭にスナップし、次に履歴の前へ移動します。                                                                                      |
| `Ctrl+R`                                              | 入力/シェル履歴を逆方向に検索します。                                                                                         |
| `Ctrl+Y`                                              | 最後に失敗したリクエストを再試行します。                                                                                                      |
| `Ctrl+Right Arrow` / `Meta+Right Arrow` / `Meta+F`    | カーソルを1単語右に移動します。                                                                                              |
| `Ctrl+U`                                              | カーソルから行の先頭までを削除します。                                                                                |
| `Ctrl+V`（Windows: `Alt+V`）                           | クリップボードの内容を貼り付けます。クリップボードに画像が含まれている場合は、その画像が保存され、プロンプトにその参照が挿入されます。 |
| `Ctrl+W` / `Meta+Backspace` / `Ctrl+Backspace`        | カーソルの左側の単語を削除します。                                                                                          |
| `Ctrl+X`                                              | 現在の入力を外部エディタで開きます。                                                                                       |

## 提案

| ショートカット                | 説明                            |
| ----------------------- | -------------------------------------- |
| `Down Arrow` / `Ctrl+N` | 提案を下方にナビゲートします。 |
| `Tab` / `Enter`         | 選択した提案を受け入れます。        |
| `Up Arrow` / `Ctrl+P`   | 提案を上方にナビゲートします。   |

## ラジオボタン選択

| ショートカット                      | 説明                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `Down Arrow` / `j` / `Ctrl+N` | 選択を下に移動します。                                                                                          |
| `Enter`                       | 選択を確定します。                                                                                            |
| `Up Arrow` / `k` / `Ctrl+P`   | 選択を上に移動します。                                                                                            |
| `1-9`                         | 番号で項目を選択します。                                                                                 |
| （複数桁）                 | 9より大きい番号の項目の場合、数字を素早く連続して押すことで、対応する項目を選択します。 |

## 履歴スクロールバック

`ui.useTerminalBuffer` が有効な場合のみアクティブになります（Settings → UI → Virtualized History）。このモードでは、会話履歴はホストターミナルのスクロールバックではなく、アプリ内のビューポート内にレンダリングされるため、以下のキーがターミナルのネイティブスクロールに取って代わります。

| ショートカット        | 説明                                          |
| --------------- | ---------------------------------------------------- |
| `Shift+Up`      | 履歴を1行上にスクロールします。                          |
| `Shift+Down`    | 履歴を1行下にスクロールします。                        |
| `PgUp`          | 履歴を1ページ（ビューポートの高さ）上にスクロールします。        |
| `PgDn`          | 履歴を1ページ（ビューポートの高さ）下にスクロールします。      |
| `Ctrl+Home`     | 会話の先頭にジャンプします。                 |
| `Ctrl+End`      | 末尾にジャンプします（およびライブ自動追従を再有効化します）。 |
| **Mouse wheel** | 履歴をスクロールします（1クリックあたり3行）。                   |
`ui.useTerminalBuffer` がオンの場合、ターミナルはマウスイベントを qwen-code に転送し、ホイールでアプリ内ビューポートを操作できるようにします。副作用として、**ネイティブのクリック＆ドラッグによるテキスト選択がプログラムに消費されます** — ドラッグ中に `Shift`（macOS Terminal / iTerm の場合は `Option`）を押し続けると、マウスキャプチャを回避して通常通りテキストを選択できます。

### tmux トラックパッドスクロール

tmux 内では、一部のターミナルがトラックパッドやホイールのジェスチャを、qwen-code が受信する前に単純な `Up Arrow` および `Down Arrow` シーケンスに変換します。これらのバイトは実際の矢印キーの押下と同一であるため、qwen-code はビューポートをスクロールしようとしたのか、プロンプト履歴を操作しようとしたのかを区別できません。

tmux 内でトラックパッドスクロールがプロンプト履歴を変更してしまう場合は、`ui.useTerminalBuffer` を有効にしてください。その後、`Shift+Up` / `Shift+Down` を使用するか、tmux がホイールイベントをアプリに転送する場合はマウスホイールを使用します。ホストのスクロールバックを優先する場合は、ホイールイベントに対する tmux のマウスバインディングを調整してください。
