# Qwen Code キーボードショートカット

本文書では、Qwen Code で利用可能なキーボードショートカットの一覧を紹介します。

## 一般

| ショートカット                       | 説明                                                                                                                                                                                                                                        |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                          | ダイアログと提案を閉じます。空のプロンプトでは、進行中のリクエストをキャンセルします。IDE モード外でアイドル状態のときは、2 回押すと巻き戻しセレクターを開きます。                                                                                               |
| `Ctrl+C`                       | 進行中のリクエストをキャンセルし、入力をクリアします。2 回押すとアプリケーションを終了します。                                                                                                                                                               |
| `Ctrl+D`                       | 入力が空の場合にアプリケーションを終了します。2 回押すと確定します。                                                                                                                                                                                |
| `Ctrl+L`                       | 画面をクリアします。                                                                                                                                                                                                                                  |
| `Ctrl+O` / `Alt/Option+T`      | 展開詳細モードを切り替えます: すべての思考ブロックとツール出力をインラインで展開または折りたたみます。再度押すと折りたたみます。`ui.useTerminalBuffer` がオフの場合、切り替えると切り捨てられていない出力で会話全体を再描画し、ターミナルのスクロールバックに書き込みます。 |
| `Ctrl+S`                       | 現在のプロジェクトの空でない入力を一時保存し、次回の起動時に復元します。入力が空の場合、長いレスポンスが完全に出力されるようにし、切り捨てを無効にします。ターミナルのスクロールバックを使用して出力全体を表示します。                        |
| `Ctrl+T`                       | ツール説明の表示を切り替えます。                                                                                                                                                                                                           |
| `Alt/Option+M`                 | Markdown 出力をリッチレンダリングプレビューと生/ソースモードの間で切り替えます。macOS では、ターミナルが Option を Meta として送信する必要があります。                                                                                                                                                                        |
| `Shift+Tab`（Windows では `Tab`） | 承認モードを循環させます（`plan` → `default` → `auto-edit` → `auto` → `yolo`）                                                                                                                                                                          |

| `Ctrl+P`                                              | 上に移動し、次に先頭にスナップし、次に履歴の前へ移動します。                                                                                      |

## フォアグラウンドシェル

これらのショートカットは、インタラクティブなフォアグラウンドシェルコマンドが実行中に適用されます。

| ショートカット                            | 説明                                                                                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl+F`                            | シェルとプロンプト間のキーボードフォーカスを切り替えます。シェルが実行されていない場合、`Ctrl+F` はプロンプトカーソルを右に移動します。                                      |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | フォーカスされたシェルを上下にスクロールします。                                                                                                                           |
| `Ctrl+B`                            | シェルをバックグラウンドタスクに昇格させます。子プロセスは実行を継続し、エージェントのターンがブロック解除され、シェルは `/tasks` とバックグラウンドタスクダイアログに表示されます。 |

## 提案

| ショートカット                             | 説明                                                              |
| ------------------------------------ | ------------------------------------------------------------------------ |
| `Down Arrow` / `Ctrl+N`              | 提案を下方にナビゲートします。                                   |
| `Tab` / `Enter`                      | 選択した提案を受け入れます。                                          |
| `Up Arrow` / `Ctrl+P`                | 提案を上方にナビゲートします。                                     |
| `Right Arrow`                        | プロンプトが空のときにゴーストテキストの提案を受け入れます。                 |
| `Ctrl+Tab` / `Ctrl+Right Arrow`      | カテゴリタブが表示されているときに、次の補完カテゴリに切り替えます。     |
| `Ctrl+Shift+Tab` / `Ctrl+Left Arrow` | カテゴリタブが表示されているときに、前の補完カテゴリに切り替えます。 |

## 履歴検索

`Ctrl+R` を押してプロンプト履歴を検索します。シェルモードがアクティブな間はシェル履歴を検索します。

| ショートカット                     | 説明                                                |
| ---------------------------- | ---------------------------------------------------------- |
| `Up Arrow` / `Down Arrow`    | 一致する履歴エントリをナビゲートします。                 |
| `Left Arrow` / `Right Arrow` | 選択された長いエントリを折りたたむか展開します。                  |
| `Tab`                        | 選択されたエントリを送信せずにプロンプトに受け入れます。 |
| `Enter`                      | 選択されたエントリを送信します。                                 |
| `Esc`                        | 履歴検索を閉じます。                                      |

| ショートカット                      | 説明                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `Down Arrow` / `j` / `Ctrl+N` | 選択を下に移動します。                                                                                          |
| `Enter`                       | 選択を確定します。                                                                                            |
| `Up Arrow` / `k` / `Ctrl+P`   | 選択を上に移動します。                                                                                            |
| `1-9`                         | 番号で項目を選択します。                                                                                 |
| （複数桁）                 | 9より大きい番号の項目の場合、数字を素早く連続して押すことで、対応する項目を選択します。 |

## 履歴スクロールバック

`ui.useTerminalBuffer` が有効（Settings → UI → Virtualized History）で、スクリーンリーダーモードがオフで、Qwen Code が互換性のあるインタラクティブターミナルで実行されている場合（`stdout` が TTY で、CI が非アクティブで、`TERM` が `dumb` でない）にアクティブになります。これが通常の非スクリーンリーダーセッションのデフォルトです。このモードでは、会話履歴はホストターミナルのスクロールバックではなくアプリ内のビューポート内にレンダリングされるため、以下のキーがターミナルのネイティブスクロールに取って代わります。

| ショートカット        | 説明                                                                     |
| --------------- | ------------------------------------------------------------------------------- |
| `Shift+Up`      | 履歴を1行上にスクロールします。                                                     |
| `Shift+Down`    | 履歴を1行下にスクロールします。                                                   |
| `PgUp`          | 履歴を1ページ（ビューポートの高さ）上にスクロールします。                                   |
| `PgDn`          | 履歴を1ページ（ビューポートの高さ）下にスクロールします。                                 |
| `Ctrl+Home`     | 会話の先頭にジャンプします。                                            |
| `Ctrl+End`      | 末尾にジャンプします（およびライブ自動追従を再有効化します）。                            |
| **マウスホイール** | 履歴をスクロールします（1クリックあたり3行）。`ui.mouseTracking` が必要です（デフォルトでオン）。 |

`ui.useTerminalBuffer` がオンで `ui.mouseTracking` が有効な場合（デフォルト）、ターミナルはマウスイベントを qwen-code に転送し、ホイールでアプリ内ビューポートを操作できるようにします。副作用として、ネイティブのクリック＆ドラッグによるテキスト選択はプログラムに消費されます。qwen-code は独自の方法を提供します: **履歴ビューポートでドラッグしてテキストを選択、ダブルクリックで単語を選択、トリプルクリックで行を選択します。** マウスを離すと選択範囲がハイライトされ、クリップボードにコピーされます（ローカル、SSH 経由の OSC 52、tmux 内で機能します）。シングルクリックで選択がクリアされます。スクロールや新しい出力でも選択はクリアされます。選択は現在の表示ビューポートに限定されます。ドラッグ中に `Shift`（macOS Terminal / iTerm の場合は `Option`）を押し続けることで、ターミナル独自の選択にフォールバックできます。`ui.mouseTracking` を `false` に設定すると、qwen-code によるマウスのキャプチャを完全に停止します。これにより、ターミナルのネイティブな右クリックメニュー、OSC 8 ハイパーリンククリック、クリック＆ドラッグ選択が復元されますが、アプリ内ビューポートはマウスに応答しなくなるため、上記のキーボードショートカットを使用してスクロールしてください。

### tmux トラックパッドスクロール

tmux 内では、一部のターミナルがトラックパッドやホイールのジェスチャを、qwen-code が受信する前に単純な `Up Arrow` および `Down Arrow` シーケンスに変換します。これらのバイトは実際の矢印キーの押下と同一であるため、qwen-code はビューポートをスクロールしようとしたのか、プロンプト履歴を操作しようとしたのかを区別できません。

tmux 内でトラックパッドスクロールがプロンプト履歴を変更してしまう場合は、`ui.useTerminalBuffer` が有効であることを確認してください。次に、`Shift+Up` / `Shift+Down` を使用するか、tmux がホイールイベントをアプリに転送する場合（`ui.mouseTracking` が必要）はマウスホイールを使用します。ホストのスクロールバックを優先する場合は、ホイールイベントに対する tmux のマウスバインディングを調整してください。
