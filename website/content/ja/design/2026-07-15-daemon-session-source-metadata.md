# デーモンセッションのソース metadata

## 動機

デーモンのクライアントは、デーモンの再起動後に、どの統合がセッションを作成したかを識別する必要があります。ライブ専用のブリッジ metadata では不十分です。ライブのエントリは、load や resume 時に永続化されたトランスクリプトから再構築されるためです。

## API

`POST /session` は 2 つのオプションの不変フィールドを受け付けます:

- `sourceType`: 小文字のソーストークン（`[a-z][a-z0-9_-]{0,63}`）。
- `sourceId`: 最大 256 文字の非空の識別子。`sourceType` が存在する場合にのみ有効。

これらのフィールドは、セッション作成、ステータス、ワークスペースのセッションリストのレスポンスで返されます。既存のセッションは両方のフィールドを省略します。`sessionScope: single` の場合、attach は既存セッションのソースを返し、アタッチするリクエストのソースを引き継ぐことは決してありません。

ワークスペースのセッションリストは、`sourceType` とオプションの `sourceId` のクエリパラメータを受け付けます。`sourceId` は `sourceType` を必要とし、両方が存在する場合は一緒にマッチングされます。ソースフィルターは整理されたビューとは組み合わせられません。

デーモンのスケジュールタスクは、専用セッションに `sourceType: "scheduled_task"` と、`sourceId` としての永続的なタスク ID をタグ付けします。

デーモンのチャネルワーカーは、自身が作成するセッションに `sourceType: "channel"` と、設定されたチャネルインスタンス名（例: `feishu-main`）を `sourceId` としてタグ付けします。これにより、チャネルインスタンス — そしてチャネル設定を介してチャネルの種類（dingtalk/feishu/...）— がデーモンのデータプレーンで帰属可能になります。既存セッションの読み込みやアタッチが、その作成時のソースを再スタンプすることは決してありません。

## 永続化

新しいセッションは、JSONL トランスクリプトの先頭付近に 1 つの `session_source` システムレコードを保存します:

```json
{
  "type": "system",
  "subtype": "session_source",
  "systemPayload": {
    "sourceType": "web_shell",
    "sourceId": "window-1"
  }
}
```

ブリッジは、既存の `parent_session` の永続化境界に合わせ、await された ACP の制御メソッドを通じて、セッションの子プロセスにこのレコードを追記するよう要求します。作成レスポンスは `sourcePersisted` を公開し、記録が失敗した場合に呼び出し元が degraded なライブ専用のソースを検出できるようにします。

`SessionService` は、リストレスポンスのためにトランスクリプトの先頭をスキャンする際、および load/resume の前にこのレコードを読み取り、復元されたライブサマリーがソースを保持するようにします。

## ブランチ

フォークされたトランスクリプトは `session_source` をコピーしてはなりません。さもなければ、新しいブランチが元のセッションの作成者を主張することになります。ブランチは、その作成パスが明示的に割り当てない限り、ソースを持ちません。

## 互換性

両フィールドともオプションです。古いトランスクリプトとクライアントは引き続き有効です。REST、ACP-over-HTTP、TypeScript SDK は、作成とリストフィルターのフィールドを転送します。フィールドを実装するデーモンは `session_source_metadata` を通知します。SDK は、ソース metadata やソースフィルターを送信する前にこのケーパビリティを確認するため、古いデーモンがそれらを暗黙に無視してフィルタリングされていない結果を返すことはできません。値は帰属のためだけのものであり、クライアントが指定できるため、認可のシグナルとして使用してはなりません。

クライアントが新しく作成されたセッションを受信する前に切断した場合、デーモンはライブセッションと新しく書き込まれたトランスクリプトの両方を削除します。並行する attach は両方の操作を防ぎ、アタッチしたクライアントのためにセッションを保持します。
