# 信頼されていないワークスペースの読み取り専用セッションカタログ

## Summary

マルチワークスペースのデーモンは、起動時の信頼状態が `false` である登録済みの
非プライマリワークスペースに対して、狭い読み取り専用のカタログを公開する。
カタログには、永続化されたセッションサマリとセッション organization のサイドカー
が含まれる。セッションへのアタッチ、ACP 子プロセスの起動、ライブランタイム状態
のマージ、ワークスペースが制御するケイパビリティ定義の解釈は行わない。

これはルートの許可リストであり、ワークスペースの ACL ではない。デーモンの
Bearer トークンを持つクライアントは、すべての登録済みワークスペースに対して
許可されたデータを読み取れる。信頼は引き続き実行とミューテーションをゲート
する。別の認証プリンシパルを作ることはない。

## Security Invariants

新しく許可される信頼されていないワークスペースの各読み取りパスは、以下の条件
をすべて満たさなければならない:

- `loadSettings()` や設定のマイグレーション/修復パスを呼び出さない。
- ストレージの作成、修復、書き換え、その他の変更を行わない。
- カタログリーダーがアクティブな間はファイルベースのデバッグログを抑制し、
  不正なレコードが読み取りの副作用としてデバッグログを作成・追記できないように
  する。
- `ensureChannel()` やその他の ACP 子プロセス起動パスを呼び出さない。
- 信頼されていないランタイムのライブブリッジ状態を照会・マージしない。
- 外部コマンドを実行しない。
- ワークスペースのエージェント、スキル、フック、MCP 設定、その他のプロジェク
  トが制御するケイパビリティ定義の検出や解析を行わない。

実装は、すべてのセッションリスト形式（デフォルト、organized、
`parentSessionId` フィルター）で内部の `mergeLive: false` 読み取りポリシーに
よりライブ状態の境界を強制する。同じ非同期読み取り境界は、信頼されていない
カタログ読み取りについてのみファイルベースのデバッグログを抑制する。信頼され
たリクエストと、その境界の外側のログは変更されない。ストレージが存在しない
場合は空のカタログを生成し、不正なエントリはファイルを修復せずに既存のベスト
エフォート読み取り挙動に従う。

## Route Matrix

この表は、特に記載のない限り、信頼されていないセカンダリワークスペースを
説明する。

| サーフェス                                   | 結果              | データソースと制約                                                                     |
| ------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------- |
| `GET /workspace/:id/sessions`               | 200               | 永続化されたセッションファイルのみ。id またはエンコードされた正規の cwd セレクター      |
| `GET /workspaces/:workspace/sessions`       | 200               | 同じ永続化専用のカタログ                                                                 |
| `GET /workspace/:id/session-groups`         | 200               | organization サイドカーのみ。任意の登録済み id またはエンコードされた cwd               |
| `GET /workspaces/:workspace/session-groups` | 200               | organization サイドカーのみ                                                             |
| ファイル読み取り、バイト、stat、一覧、glob     | 既存の挙動         | 既存のファイルシステム読み取りポリシーは変更されない                                        |
| ワークスペース信頼の GET/リクエスト            | 既存の挙動         | 既存の信頼設定のセマンティクスは変更されない                                              |
| `/capabilities`、`/daemon/status`           | 既存の挙動         | 既存のデーモン診断は変更されない                                                          |
| 複数形のセッション/グループのミューテーション    | 403               | ミューテーションの信頼ゲートは変更されない                                                |
| 単数形のグループのミューテーション              | 既存の挙動         | プライマリ専用のまま。セカンダリのセレクターは fail closed（失敗時は拒否）となる            |
| 設定、権限、プロバイダー                       | 403               | 設定の読み込みはファイルのマイグレーション、バックアップ、修復を行う場合がある               |
| メモリ                                        | 403               | 現在のレスポンスは、ワークスペース専用の投影ではなくグローバルメモリのパスを含む             |
| 環境変数                                      | 403               | 認証情報の存在とプロキシ/ホストの診断を公開する                                            |
| プリフライト                                   | 403               | git、npm、ripgrep、その他のプローブを実行する場合がある                                    |
| MCP、ツール、フック                            | 403               | ライブのブリッジ状態またはプロジェクト設定に結合している                                     |
| スキル、エージェント                            | 403               | プロジェクトが制御する定義を検出・解析する                                                 |
| トランスクリプト                               | 403               | 現在のパスは ACP を開始する場合があり、カーソルの初期化が HMAC キーを書き込む場合がある      |
| エクスポート、セッション status/context/tasks  | 403               | ワークスペース修飾の永続化専用実装が存在しない                                              |
| ACP HTTP/WebSocket、ボイス、チャネル           | 拒否              | 実行、プロセス、または長時間存続するランタイムのケイパビリティ                               |

不明な絶対パス、ネストされた、または未登録のワークスペースセレクターは、引き続き
既存の `400 workspace_mismatch` レスポンスで fail closed（失敗時は拒否）となる。
不正なレガシーの単数形セレクターは、既存の `400` 検証メッセージを保持する。
いずれの場合もプライマリワークスペースへフォールバックしない。複数形ルートは、
信頼されていないプライマリワークスペースに対して `403 untrusted_workspace` を
返し続ける。単数形のプライマリルートは既存の互換性挙動を保持する。

## Session Catalog Semantics

永続化専用モードは、既存の `archiveState`、`view=organized`、`group`、
`parentSessionId`、カーソル、ページサイズの挙動を保持する。ライブランタイムから
保留中のインタラクション、ターンエラー、クライアント状態を設定することは決して
ない。`clientCount: 0` や `hasActivePrompt: false` などの既存の永続化サマリの
デフォルトは、引き続きワイヤー互換である。`bridge.listWorkspaceSessions()` を
呼び出すことは決してない。

信頼されたセカンダリおよびプライマリのワークスペースは、既存の永続化/ライブの
マージを維持する。ルート、ワイヤーフィールド、スキーマ、ケイパビリティタグは追加
されない。古いクライアントは引き続き `403` を処理し、バンドルされた Web Shell
はデーモンとともに提供される場合に新しい `200` レスポンスを消費する。

## Web Shell Behavior

信頼されていないセカンダリのワークスペースは引き続き展開可能であり、`untrusted`
と `read-only` の両方のラベルが付く。展開すると 1 回のカタログ読み取りが行われる。
`reloadToken` の変更は別の読み取りを行うが、このデーモンはそのワークスペースで
セッションを作成できないため、通常の 10 秒のポーリングは無効になる。

展開してもワークスペースは選択もアクティベーションもされない。永続化された
セッションは、`role="note"` と、セッション名、日付、およびセッションを開く前に
ワークスペースを信頼する必要があるという説明を含むアクセシブルな名前を持つ、
非インタラクティブな行として描画される。この行はマウスやキーボードによるアク
ティベーションをバインドせず、アクティブなセッションのスタイルも受けない。
信頼されたワークスペースの挙動は変更されない。信頼されていないプライマリは、
別のプライマリセーフモード設計を待って引き続き無効である。

## Failure and Compatibility Behavior

- セッションまたは organization のストレージが存在しない場合は、空のカタログを
  返す。
- 解析不能な JSONL レコードやオブジェクトでない JSONL レコードは、既存の
  セッションリーダーによってスキップされる。この変更は、構造的に無効なオブジェ
  クトレコードに対するスキーマ検証を追加しない。
- 読み取り不能な organization サイドカーは、既存の空の読み取りビューと警告を
  返す。読み取りはそれを修復しない。
- Web Shell のリクエスト失敗は、既存の空の状態とコンソール警告を保持する。
- 信頼の GET は、引き続きディスク上の現在の信頼設定を観測し、ランタイムの変更
  には再起動が必要であることを呼び出し元に伝える。この変更では起動時スナップ
  ショットへの変換は行わない。

## Deferred Work

- 副作用のない設定と信頼のスナップショットローダー。
- ワークスペース専用のメモリの投影。
- 秘匿化した環境変数と設定の検査。
- プロジェクト定義を解析しないスキルとエージェントのインベントリ。
- ACP の開始もカーソル HMAC キーの初期化も行わないデーモンローカルのトランス
  クリップトリーダーと、真に読み取り専用のセッションビューアー。
- 動的な信頼の適用、ランタイムの再構築、ワークスペースの削除/drain。
