# ワークスペースのスキルインストールパス

日付: 2026-07-13

## 契約

`GET /workspace/skills` と `GET /workspaces/:workspace/skills` が返す各スキルには `installedPath` が含まれます。これはその `SKILL.md` ファイルを指す、既存の絶対パスの `SkillConfig.filePath` です。値は保存されたままコピーされます。ステータス層はシンボリックリンクの解決や再正規化を行いません。

## 互換性

これは追加的な v1 フィールドです。現在のデーモンは常にこれを出力しますが、ACP ブリッジと TypeScript SDK のパブリックなステータス型はオプションのままにするため、クライアントは古いデーモンとの互換性を維持します。プロトコルバージョンとケーパビリティリストは変更されません。

## データフロー

`SkillManager.listSkills()` が `SkillConfig` レコードを提供します。共用の `mapSkillConfigToStatus()` 関数が `filePath` を `installedPath` にコピーします。ライブの ACP スナップショットとデーモンローカルのフォールバックの両方がそのマッパーを使用するため、プロジェクト、ユーザー、バンドル、拡張機能、無効化された拡張機能、および無効化されたスキルはすべて同じ形状になります。ワークスペースのステータスサービスは、その共用の結果を両方のルート形式に転送します。

## マスキングの境界

ステータスマッパーは明示的な metadata の allowlist のままです。インストールのファイルパスは公開しますが、スキルの本体、フック、`skillRoot`、その他のスキル設定は公開しません。本変更による UI の動作追加はありません。
