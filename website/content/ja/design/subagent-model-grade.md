# サブエージェントのモデルグレード選択

## 目標

Agent ツールのスキーマでプロバイダー固有のモデル ID を公開することなく、通常のサブエージェントを起動する際にユーザー定義のモデルグレードをモデルが選択できるようにする。

```json
{
  "agents": {
    "modelGrades": {
      "small": "fast",
      "high": "qwen-max"
    },
    "allowedGrades": ["small", "high"]
  }
}
```

Agent ツールは `model: "small" | "high"` を提示し、サブエージェントの設定を読み込んだ直後に選択されたグレードを解決する。

## 解決

実効モデルセレクターは、次の優先順位を使用する:

1. ビルトインでないエージェントの明示的な非 `inherit` モデル
2. `agents.modelGrades` によってマップされた許可済みグレード
3. ビルトインの Explore モデル設定
4. 継承された親モデル

不明または許可されていないグレードは拒否される。フォークは親のモデルとプロンプトキャッシュを継承する必要があるため、このパラメーターを拒否する。名前付きチームのチームメイトも、バックエンドのモデルオーバーライドがグレードセレクターではなく具体的なモデル ID を受け付けるため、これを拒否する。

設定された許可済みのグレード名のみが、動的なツールスキーマに含まれる。具体的なモデルセレクターはユーザー設定の非公開のままとなる。

## 検証

- 設定スキーマと CLI から core への設定転送
- グレード解決、許可リストフィルタリング、カスタムエージェントの優先順位
- 具体的なモデル ID を含まない動的な Agent ツールスキーマ
- 解決されたモデルを使用した通常のフォアグラウンドおよびバックグラウンドのディスパッチ
- フォークのバリデーション
