# バックグラウンドエージェントのステータスと詳細

## 問題

Agent ツール呼び出しは、バックグラウンドエージェントが起動されるとすぐに戻る。そのため、そのトランスクリプトブロックには、ペイロードが `status: background` である終端のツールイベントが存在する。Web Shell は意図的にその起動結果を保留中のツールカードへマップし直すのだが、その後、カードをライブなバックグラウンドタスクのレジストリと reconciliation（突合）するものが何もない。フッターのタスクリストが終端状態に達しても、元の Agent カードは実行中のままになる。

フォアグラウンドのエージェントはすでに共有のサブエージェント詳細パネルで開く。バックグラウンドエージェントも同じ `toolUseId`、タスクレジストリエントリ、JSONL トランスクリプト、バーチャルセッションリゾルバーを持つが、このパスには明示的なカバレッジがない。

## 設計

起動のプロジェクションは変更しない: `status: background` の起動結果は、権威あるタスク状態が届くまで保留のままとなる。デーモンはすでに、セッションの SSE ストリーム上で、タスクの `status` と `toolUseId` を含む終端のバックグラウンドエージェント通知を発行している。Web Shell はその非表示の通知メタデータを消費し、プロジェクションされた Agent ツールカードへ突合して戻す。

- `completed` と `cancelled` はカードを完了させる。
- `failed` はカードを失敗させる。
- 通知のタイムスタンプがカードの終了時刻となる。
- `toolUseId` のない通知、エージェント以外の通知、無関係なツール呼び出しは、メッセージを直接変更しない。

既存のサブエージェント詳細プロバイダーが唯一の UI パスのままとなる。バックグラウンド Agent カードは、保留中および終端の突合後もクリック可能なままとなる。バーチャルセッションリゾルバーは、フォアグラウンド／バックグラウンドモードによるフィルタリングなしで、引き続きタスクの JSONL をストリーミングし、タスクレジストリからライブステータスを取得する。`toolUseId` のないレガシーなタスクについては、起動記録を永続化されたサイドカーと照合し、元のバックグラウンド起動結果がまだ `running` となっている場合でも、終端のサイドカーステータスを保持する。

デタッチされた作業がアクティブな間、そのメインリストのカードは、フォアグラウンドの `running` ラベルの代わりに、専用の静的な `background task` ラベルを使用する。カードは実行中の shimmer や刻々と進む経過タイマーを使用しない。終端通知は、そのラベルを通常の完了、失敗、キャンセルの表示に置き換える。

バックグラウンドエージェントは、その進捗がクリック可能なカードと詳細パネルから得られるため、下部のステータスバーからは省略される。完全な Tasks パネルには引き続き表示される。シェルコマンドを含む他の種類のバックグラウンドタスクは、下部のステータスバーにとどまり、既存のポーリングを維持する。バックグラウンド Agent だけでは、下部バーのタスクポーリングは起動しない。

永続化された通知レコードは、常に `toolUseId` を保持しているとは限らない。そのため、読み込まれたトランスクリプトにアクティブなバックグラウンド Agent カードが含まれる場合、Web Shell はトランスクリプトの catch-up の後に、既存のサブエージェントエンドポイントを通じて各保留カードを解決する。このワンショットチェックは、再接続後も、終端の Agent 通知が届いたときも、その通知がカードを直接特定できない場合であっても、繰り返される。インターバルを開始することは決してない。入力フォーカスや通常のストリーミングは、保留中の Agent 呼び出し ID や終端通知のキーを変更しないため、別のリクエストをトリガーすることはない。

ドッキングされた詳細パネルは右端から展開し、別のパネルの動きの前にリサイズされるのではなく、チャットが連続的に左へ押される。Reduced-motion の設定は、ドッキング時のアニメーションを無効にする。パネルのタブは固定幅を保ち、長いタイトルは切り詰められ、タブのリストが利用可能なスペースを超えると水平方向にスクロールする。

## スコープ

この変更は、Web Shell のプロジェクションと、デーモンのバーチャルサブエージェントのステータスリゾルバーを更新する。永続化された親のトランスクリプトの書き換え、タスクのライフサイクルの変更、バックグラウンドエージェントのタスクポーリングの追加、完全な Tasks パネルからのエージェントの削除、2 つ目のサブエージェントビューアーの追加は行わない。
