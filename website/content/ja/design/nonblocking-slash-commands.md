# ストリーミング中のノンブロッキングなスラッシュコマンド

## Problem

インタラクティブ入力ルーターは現在、モデルレスポンスのストリーミング中、`/btw` 以外のすべてのスラッシュコマンドをキューに入れる。これにより、結果がそのターンに依存しない場合でも、ローカルの UI コントロールがアクティブな会話ターンを待つことになる。

## Design

`SlashCommand` にオプトインの `canRunDuringStreaming` capability を追加する。デフォルトは false のまま。メインモデルが応答中、入力ルーターは送信されたコマンドを既存のスラッシュコマンドツリーで解決する。オプトインしたコマンドはスラッシュコマンドプロセッサへ直接送られ、その他のすべてのスラッシュコマンドは既存の直列化メッセージキューを使い続ける。

直接パスは `submitQuery` を通過しない。この関数はモデルターンのライフサイクルを所有し、並行するトップレベルターンを意図的に拒否する。ローカルコマンドをその外に置くことで、アクティブなレスポンスとの中断コントローラー、送信フラグ、モデルストリームカウンターの共有を回避する。

スラッシュコマンドプロセッサとコマンド結果は、すでに React ステートを通じて Ink を更新している。そのため初期のコマンドは、Ink のレンダリング中にターミナルの stdout へ直接書き込まない。

## Initial Command Set

- `/status`、`/about`、`/status paths`: ローカルのランタイム情報を読み取り、Ink の履歴項目を追加する。
- `/settings`: 設定ダイアログを開く。保存された変更は、アクティブな会話ターンを置き換えずに既存の設定フックを通じて適用される。
- `/help`: 静的なヘルプダイアログを開く。

以下のカテゴリは直列化のままである:

- スキル、`/summary`、`/compress`、`/model <model> <prompt>`、`/goal` など、モデルターンを送信または変換するコマンド。
- 会話状態を置換、クリア、rewind、再開、ブランチ、その他ミューテートするコマンド。
- ツールをスケジュールしたり、長時間の外部作業を実行したりするコマンド。
- `/context`、`/stats`、`/copy`、`/diff`、`/recap` など、アクティブターンによってミューテートされている状態を読み取るコマンド。

`/btw` は専用の並行モデルリクエストパスを維持する。`/quit` は既存の即時キャンセルパスを維持する。Ctrl+Q は引き続き、オプトイン済みのコマンドを含め、あらゆる送信をアイドルまでの待機に強制する。

## Verification

ユニットカバレッジは、レスポンス中にオプトインしたコマンドが `submitQuery` とメッセージキューの両方をバイパスすること、およびマークのないスラッシュコマンドがキューに残ることを検証する。コマンドテストは初期の capability 宣言を固定する。インタラクティブ E2E チェックでは、明らかにストリーミング中のレスポンスを開始し、各オプトインコマンドを開き、ダイアログを閉じ、元のレスポンスが継続して完了することを確認する。
