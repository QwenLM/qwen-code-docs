# フォークサブエージェントの `fork_turns`

## サマリー

Agent ツールの既存のデタッチド `subagent_type: "fork"` ランタイムに、オプションの `fork_turns` パラメーターを追加する。このパラメーターが省略された場合、フォークは引き続き親の会話全体を継承する。呼び出し元は明示的に次を使用できる:

- 親の会話全体を示す `all`、または
- 直近の 3 つの実際のユーザーターンを示す `"3"` のような正の整数文字列。

通常のサブエージェントと名前付きチームメイトは `fork_turns` を受け付けず、引き続き親の会話履歴なしで開始する。

## 目標

- パラメーターを省略したフォーク呼び出しについて、既存の全履歴の動作を維持する。
- システムプロンプト、ツール、モデル、承認モード、作業ディレクトリ、デタッチドライフサイクルを変更せずに、呼び出し元がフォークの継承履歴を制限できるようにする。
- 生の API メッセージではなく実際のユーザーターンを数える。ツール応答や純粋なシステムリマインダーは、リクエストされたターン数を消費しない。
- 選択されたフォーク履歴を、親の可変なメッセージパーツから隔離したままにする。

## 非目標

- 通常の特殊化サブエージェントやエージェントチームのチームメイトへのコンテキスト継承の追加。
- 履歴なしフォークモードの追加。親のコンテキストを望まない呼び出し元は、通常のサブエージェントを起動すべきである。
- フォークの可用性、ネストのルール、バックグラウンド実行、トランスクリプトの復旧、親のシステムプロンプトとツール宣言の再利用の変更。

## 設計

### パラメーターとバリデーション

`AgentParams.fork_turns` は任意である。JSON スキーマは `all` または `^[1-9][0-9]*$` にマッチする文字列を受け付ける。省略時は `all` に正規化され、既存のフォークの動作が保たれる。

`fork_turns` をフォーク以外のサブエージェント種別とともに指定した場合、サブエージェント種別を明示せずに指定した場合、または名前付きチームメイトを起動する際に指定した場合は拒否される。`none`、ゼロ、負数、小数、空白でパディングされた値、文字列以外の値は拒否される。

### 履歴の選択

`all` は、既存のフォークランタイムと同じキュレートされた親の履歴を使用する。

数値の場合、親のチャットは会話履歴をキュレートする前に先頭の起動コンテキストを削除する。これにより、キュレーションで起動時のリマインダーと最初の実際のユーザープロンプトが統合されてしまうことを防ぐ。その後、元の起動プレフィックスが選択されたウィンドウの前に追加され、フォークは親の環境コンテキストを保持する。

実際のユーザーターンとは、function response、空のテキスト、純粋なシステムリマインダー以外のコンテンツを含む user ロールのメッセージである。選択されたスライスは直近 N 番目の実際のユーザーターンから始まり、後続のモデルメッセージ、ツール呼び出し、ツール応答、リマインダーを含む。実際のターンが N 未満しか存在しない場合は、利用可能なすべての実際のターンが選択される。

コンパクションされた履歴のサマリーは合成プレフィックスであり、数値ウィンドウには含まれない。フォークにコンパクションされたサマリーが必要な場合は、呼び出し元は `all` を使用すべきである。最終的に選択された履歴はディープクローンされるため、フォークと親が可変のネストされたメッセージパーツを共有することはない。

既存のフォーク構築は、ディレクティブを送信する前に引き続き最終境界を修復する。応答のない末尾のユーザーメッセージを削除し、必要に応じて開いたままのモデルの function call をプレースホルダー応答でクローズする。

### バックグラウンドでの復帰

選択された初期メッセージは、引き続き既存のフォークのブートストラップレコードを使用する。したがってトランスクリプトの復旧は、履歴を制限されたフォークを、元の起動時と同じ選択された履歴、起動時のシステム指示、ツール、タスクプロンプトで復帰させる。

## 互換性とリスク

省略時のデフォルトが `all` であるため、既存のフォーク呼び出しは全履歴のフォークのままである。既存の通常のサブエージェントおよびチームメイトの呼び出しは隔離されたままである。数値ウィンドウは古い事実やコンパクションされたサマリーを省略し得るため、ディレクティブはフォークが依然として必要とする古いコンテキストを繰り返さなければならない。また、親のシステムプロンプト、ツール、起動コンテキストは共有されたままとなる一方で、再利用可能な会話履歴キャッシュのプレフィックスは短くなる。
