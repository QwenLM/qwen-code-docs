# デーモンの extension インストールにおけるやり取り

## Context

デーモンは extension を非同期のワークスペース操作としてインストールする。
一部の extension では、インストールの進行中にユーザーが Claude マーケットプレイスの
プラグインを選択したり、設定値を提供したりする必要がある。

## Design

extension 操作は `waiting_for_input` に入ることがある。そのステータスは
一度に 1 つの機密でないやり取りを公開する：

- `marketplace_plugin` はマーケットプレイス名と選択可能なプラグインを含む。
- `setting` は設定の名前、説明、環境変数、値が機密かどうかを含む。

クライアントは既存の操作ステータスエンドポイントをポーリングし、その後
`POST /workspace/extensions/operations/:operationId/interactions/:interactionId`
に回答を送信する。回答が検証された後、操作のメモリ内コールバックが再開する。

設定値は操作のステータス、結果、ログには決して含めない。
それらの保存については、既存の extension 設定の仕組みが引き続き責任を持つ。

## Lifetime

インストール操作と更新操作は 20 分の共有ライフタイムを持つ。
各やり取りは、操作の残りライフタイムのうち最大 10 分を使用できる。
その他の extension 変更操作は既存のタイムアウトを維持する。待機中の操作は
既存の直列化された変更キューに残るため、他の extension 変更操作が
部分的にインストールされた状態を観測することはない。
