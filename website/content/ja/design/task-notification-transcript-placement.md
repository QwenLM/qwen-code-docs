# タスク通知のトランスクリプト配置

バックグラウンドタスクの完了はモデル入力であり、ユーザーが作成したプロンプトではない。ライブのデーモンパスはすでに `_meta.source = "background_notification"` でそれらを識別しているが、履歴のリプレイは以前、永続化された通知レコードをマークのないユーザーメッセージとして投影していた。

履歴のリプレイは、永続化されたモデル入力のロールを保持しつつ、ライブ通知と同じ source マーカーを追加する。Web Shell のトランスクリプトアダプターは、ユーザーまたはアシスタントのいずれのチャンクからでも、その source を情報系のシステムメッセージにマップする。新しいレコードは既存の構造化タスクステータスも永続化し、ライブとリプレイのメッセージが同じ completed、failed、cancelled のラベルを使用する。古いレコードは汎用の通知ラベルにフォールバックする。通知の内容は、セマンティックなステータスアイコンの横に変更なくレンダリングされる。これにより、他のコンシューマー向けの共有リプレイセマンティクスを変更することなく、ライブとリプレイの両方の通知が左側に表示され続ける。
