# `/stats` における生成タイミングメトリクス

> 後続の GenAI アラインメントにより、既存のプライベートな `ttft_ms` と並んで、独立した
> `gen_ai.response.time_to_first_chunk` Span 属性が追加されます。本文書の
> `ApiResponseEvent.ttft_ms` データフローと最初のユーザー可視出力のセマンティクスは変更されません。
> `/stats` は標準のファーストチャンク属性を消費しません。

## コンテキスト

Issue #4252 は、`/stats` にセッションの実時間（wall time）やエンドツーエンドの API レイテンシとは
別に生成タイミングを表示することを求めています。低レベルのタイミングはすでに存在します:

- `LoggingContentGenerator` は、リクエスト送出から最初のユーザー可視のストリームチャンクまでの
  `ttftMs` を計測します。
- `endLLMRequestSpan` は `sampling_ms` と `output_tokens_per_second` を導出します。
- `ApiResponseEvent` はすでにリクエスト時間、モデル、プロンプト ID、出力トークン数を
  `UiTelemetryService` に伝搬しています。

欠けているつながりは、既存の TTFT 値を、`/stats` が使用するコンテンツ非依存のセッション
メトリクスで利用可能にすることです。

## スコープ

この変更は、ライブかつセッションスコープの生成メトリクスを次のものに追加します:

- インタラクティブな `/stats` のセッションタブ;
- 非インタラクティブな `/stats` のテキストレスポンス。

2 つ目のタイマーの追加、日次/月次のトークン使用量ファイルへのタイミングの永続化、
エクスポートの変更、デーモン/Web Shell の統計スキーマの変更は行いません。

## データフロー

```text
LoggingContentGenerator.loggingStreamWrapper
  -> ApiResponseEvent(ttft_ms)
  -> logApiResponse
  -> UiTelemetryService
  -> SessionMetrics.generation
  -> SessionContext
  -> /stats
```

`ttft_ms` はオプションです。非ストリーミングレスポンスおよびユーザー可視コンテンツなしで終了する
ストリームは現在の動作を維持し、生成サンプルを作成しません。

## メトリクスとセマンティクス

TTFT を持つ各成功したストリーミングレスポンスについて:

- **TTFT** は既存の `ttftMs` 計測値です。
- **生成時間** は `max(0, duration_ms - ttft_ms)` で、最初のユーザー可視のストリームコンテンツから
  完了までを計測します。
- **TPS** は `output_token_count / generation_time_seconds` です。生成時間がゼロの場合は利用できません。

`SessionMetrics.generation` は遅延して作成され、以下を含みます:

- 最後に完了したリクエストのモデル、TTFT、生成時間、出力トークン数;
- スループット対象リクエストの生成時間と出力トークンに加えて、計測されたリクエストの総数と TTFT の合計。

セッションの平均 TTFT は、計測されたリクエスト全体の算術平均です。セッションの TPS は
加重スループットで、出力トークンの合計を生成時間の合計で割ったものです。生成時間がゼロの
リクエストは TTFT の統計には寄与しますが、セッション TPS 計算のどちらの側にも寄与しません。
これによりゼロ除算と短いリクエストの過大評価を回避します。

内部ヘルパープロンプトは生成メトリクスから除外されます。これらは再開可能なトランスクリプトに
記録されず、含めるとユーザーを驚かせるだけでなく、ライブセッションと再開セッションの値が
一致しなくなります。メインの会話とサブエージェントのリクエストは引き続き含まれ、既存の
セッションレベルのモデル統計と一致します。

## 互換性

- `ApiResponseEvent.ttft_ms` と `SessionMetrics.generation` は加法的かつオプションです。
- 既存の記録イベントと呼び出し元は引き続き有効です。
- 既存の日次/月次レコードは引き続きトークンと API 時間のデータのみを含み、
  `issue-4479-token-usage-stats-coordination.md` に記載された所有権の境界を維持します。
- Session コンテキストのクローン/等価性ロジックは、オプションの generation オブジェクトを
  コピーおよび比較するため、インタラクティブダッシュボードは計測されたリクエストが完了するたびに
  更新されます。

## 検証

- コアテストは、集計、内部プロンプトの除外、ゼロ生成の処理、セッションの分離、リセットの動作を
  証明します。
- LoggingContentGenerator テストは、キャプチャされた TTFT が `ApiResponseEvent` に到達し、
  非可視ストリームでは不在のままであることを証明します。
- CLI テストは、非インタラクティブな出力とインタラクティブなセッションタブのレンダリングを証明します。
- i18n テストは、新しく注目を集めるラベルについてすべての組み込みロケールをカバーします。
