# MCP 管理ランタイムモデル

MCP 設定が永続的な信頼できるソースである。各 CLI または Web セッションは、引き続き独立した MCP ランタイムを所有し、CLI がワークスペースの管理プロセスに依存しないようにする。

Web 管理ページは、ステータスと管理操作のためにオプションの管理ランタイムを作成できる。設定を変更する操作は、まず永続化し、その後同じ ACP プロセス内のすべてのライブランタイムを reconciliation する。後続のセッションは、永続化された設定を通常どおり読み込む。

管理ステータスは、プロセス全体の互換性ステータスマップではなく、管理ランタイムのクライアントマネージャーから読み取る。互換性マップは既存の CLI コンシューマー向けに変更しないままとする。共有プールの再接続はプールエントリを再起動し、非プールの再接続は各ライブランタイム内でサーバーを再検出する。

サーバーの出どころは区別されたまま: ユーザー設定、ワークスペース設定、プロジェクトの `.mcp.json`、拡張機能。プロジェクトまたはワークスペースのサーバーを無効化する場合、除外は共有のプロジェクトファイルを変更せず、ワークスペースローカルな設定へ書き込まれる。
