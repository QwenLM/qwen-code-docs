# デーモンのステートレス generation SSE

## Goal

`POST /session/:id/generate` を追加する。短くステートレスなテキスト生成のための、
リクエストスコープの SSE エンドポイントである。呼び出し元は 1 つのプレーンテキストの
`prompt` を指定する。ACP 子プロセスはまず設定された fast モデルを解決し、
fast モデルが存在しないか解決できない場合はセッションのメインモデルに
フォールバックする。

## Contract

リクエストボディは `{ "prompt": string }` である。プロンプトは空であってはならず、
UTF-8 で 32 KiB 以下でなければならない。このエンドポイントは
`started`、任意の `thinking`、`delta`、`done`、`error` の SSE イベントを出力する。
ネイティブの `EventSource` は POST ボディを送信できないため、
`fetch` で消費される。

生成はメインの会話から分離されている：チャット履歴の読み取りや変更をせず、
メインのシステムプロンプトやメモリを使用せず、常に `tools: []` を送信する。
クライアントはモデルや生成設定を選択できない。
契約はタスクに依存しない：翻訳は最初の Web Shell コンシューマであり、
エンドポイントスキーマの一部ではない。

## Architecture

このルートは `AcpSessionBridge` に generation ストリームを要求する。ブリッジは
リクエスト ID を作成し、リクエストスコープの制限付きキューを登録してから、
`qwen/control/session/generation/start` を ACP 子プロセスにディスパッチする。
子プロセスはまず `config.getFastModel()` を試し、解決中は
`config.getModel()` にフォールバックし、
`BaseLlmClient.resolveForModel` を通して対応するコンテンツジェネレーターを作成し、
`generateContentStream` を消費する。チャンクは
`qwen/notify/session/generation/event` を通して返され、登録された
リクエストキューにのみルーティングされる。セッションの EventBus や
リプレイリングには公開されない。

クライアントの切断は `qwen/control/session/generation/cancel` を送り、
子プロセスは対応するコントローラーを中断する。制限付きのブリッジキューが
デーモンを遅い HTTP リーダーから保護する。HTTP ライターは
`res.write()` のバックプレッシャーを尊重する。

## Model fallback

フォールバックは選択時のみである。fast モデルが存在しないか無効な場合は
メインモデルを選択する。生成が開始されると、プロバイダーの失敗は
ストリームを終了させる。デルタが出力された後にモデルを切り替えると、
出力が重複または混在する。

## Web Shell の思考翻訳

完了した思考ブロックは、ホバー時に翻訳アクションを表示する。
思考ブロックが展開されている間、アクションは表示されたままとなる。
Web Shell はこのエンドポイントを通して翻訳プロンプトを送信し、
デルタをポップオーバーにレンダリングする。最終的な入力および出力の
トークン数は翻訳の下に表示される。ポップオーバーは実行中のリクエストを
キャンセルしたり、キャッシュされた結果を破棄して再翻訳したりできる。
内容のない `thinking` イベントは、推論を公開せずに進捗を報告する。
アクティブな思考ブロックはアクションを公開しない。
完了した翻訳は、言語、メッセージ、コンテンツごとにページメモリに
キャッシュされるため、ポップオーバーを再度開いても別のモデルリクエストは
行われない。ページのリフレッシュでキャッシュはクリアされる。

## Non-goals

- 会話のコンテキストや履歴
- ツール呼び出し
- 任意のモデルやサンプリングの上書き
- SSE リプレイや再接続時の再開
- タスクレジストリやタスク固有のスキーマ
- `packages/core` の変更
