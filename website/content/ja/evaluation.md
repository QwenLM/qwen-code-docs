# Qwen Code 評価


この評価では、同じ Qwen 3.7 Max モデルと設定を使用して、7つの Qwen Code バージョンを SWE-bench Verified で比較しています。平均スコアは **76.40% から 77.80%** の範囲で、**1.40 パーセントポイント**の差です。

## Qwen Code バージョン別のスコア

| 0.22.0     |    77.33%  |   84.4% |  84.4% |  68.0% |

折れ線グラフはリリース順にバージョンを接続し、70%〜80% のスケールを明示的にラベル付けしています。テーブルは報告されたすべてのメトリクスを保持しています。パス率と pass @3 はこれらの結果で同じ値になっています。

## 評価設定

| 設定項目                 | 値                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| データセット             | `princeton-nlp/SWE-bench_Verified`、500 ケース                                                       |
| 実行回数                 | 各バージョン 3 試行、各バージョン 1,500 ジョブ、7 つの Qwen Code バージョン                          |
| モデル                   | `Qwen 3.7 Max`                                                                                      |
| サンプリング             | `temperature=1`、`top_p=0.95`                                                                       |
| 思考 / 推論              | `interleaved_thinking=true`、`thinking_type=adaptive`、`reasoning_effort=high`                      |
| コンテキスト / 出力制限  | `context_1m=true`、`model_context_length=1,000,000`、`max_tokens=64,000`、`model_max_tokens=65,535` |
| ハーネス制限             | `max_iterations=500`、`runtime_timeout_sec=7,200`、`agent_timeout_multiplier=3.0`                   |
