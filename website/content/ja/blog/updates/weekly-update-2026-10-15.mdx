Qwen Code は今週、v0.25.1 と v0.25.2 の 2 つの正式版をリリースし、371 件の PR がマージされました。

**Agent Collaboration：Claude Code や Codex を @ で会話に招き入れ、チームメイトにできます。** 回答は現在の会話にそのまま現れます。別のパソコンで走らせることもできます。

**開いている複数の Qwen Code を、1 ページにしたまま同時に接続できます。** サイドバーでは Qwen Code 1 つにつき 1 グループ。グループの下に、その時点の実際のセッションとワークスペースが並び、切り替えはすべてページ内で完結します。

**特定の MCP サービスを外したいときは、起動時に名指しで構いません。** `qwen --disable-mcp-server <名前>` はその 1 回だけ効き、設定ファイルには手をつけません。

## ✨ 新機能

### Agent Collaboration：Claude Code や Codex を @ で会話のチームメイトに

1 つの仕事を分けて同時にこなしたくなることがあります。一方でコードを直させ、もう一方で別のプログラムにレビューさせる、という具合です。以前 Agent を @ すると、別のスレッドが開き、直前に話した数文がコピーされ、その新しいページへ連れていかれました。メインの会話には、その返信は届きません。

今は @ すれば、現在の会話にそのまま回答が返ってきます。名前付きで、どこまで進んだか、どのツールを使ったか、Token をどれだけ使ったかまで表示され、コマンド実行はこれまでどおり承認のためにポップアップします。この Agent は Qwen Code である必要はありません。Claude Code や Codex を入れていれば、@ で呼び出して使えます。詳しくは PR [#13467](https://github.com/QwenLM/qwen-code/pull/13467)

別のパソコンで働かせることもできます。向こうで Qwen Code のサービスを立てて仲間に加えれば、重い作業はそのマシンに投げられ、マシンが再起動したあとは自分で拾いに戻ってきます。グループまるごと @ もできます——リーダー役が仕事を分解してメンバーに割り振り、メンバーは終えるとリーダーに返します。詳しくは PR [#13583](https://github.com/QwenLM/qwen-code/pull/13583)

サブ Agent との使い分けはこうです。サブ Agent は自身が小さな用を 1 つ任せて、自分だけに報告する存在。@ で呼んだこちらは目の前で話します。ほかのベンダーのプログラムでも構いませんし、別のマシン上で動かすこともできます。

まだ実験段階で、デフォルトはオフです。設定で `Enable Agent Collaboration` をオンにし、再起動すると有効になります。チームメイトは先に作っておきます。左側の `Agents` ページで 1 つ新規作成してください。以後はどの会話でも名前を @ すれば呼び出せます。

こんなことに使えます：

- 一方でコードを直させ、もう一方で別の Agent を @ してレビューさせる——2 本の作業が同じ会話に並んで見える
- ビルドやテスト実行のような重い作業は別のマシンに投げ、手元は普通に続ける
- 別のベンダーのプログラムを同じグループに組み、それぞれ得意な区間だけ担当させる

### 開いている複数の Qwen Code を、1 ページで同時接続

ノート PC が 1 台、ビルド専用が 1 台、長時間ジョブを乗せたのがもう 1 台という人もいます。PC は 1 台でも、プロジェクトごとに Qwen Code Web Shell を立てて、作業を混ぜたくないという人もいます。以前は 1 つのブラウザページに 1 つの Qwen Code しか繋がれませんでした。別を見たいとページを丸ごと読み直す必要があり、そのあいだ画面がちらつき、書きかけていた内容は失われました。

今は、保存した複数の Qwen Code を同時に接続できます。サイドバーでは Qwen Code 1 つにつき 1 グループで、グループの下にその時点のセッションとワークスペースが並びます。入力欄でワークスペースを選ぶときも、ディレクトリはグループごとに分かれて表示され、別のグループへの切り替えはページ内で完結します。詳しくは PR [#13739](https://github.com/QwenLM/qwen-code/pull/13739)、[#13677](https://github.com/QwenLM/qwen-code/pull/13677)

使うには、接続される側のパソコンが、このページからの接続を許可している必要があります。`qwen serve` を起動するとき `--allow-origin` を付け、ブラウザのアドレスバーに見えるページアドレスを入力してください。

こんなことに使えます：

- ビルド専用のマシンで長いジョブが走っていても、自分の PC からどこまで進んだか見続けられる
- 1 台の PC でプロジェクトごとに 1 つずつ立てれば、作業が混ざらず、1 ページで全部見渡せる
- ノート PC からデスクトップ PC に移っても、作業をそのまま継げる

### 使いたくない MCP サービスは、起動時に名指しで外す

MCP サービスを繋いでいる人なら、一度は当たったことがあるはずです。あるサービスがその日だけ調子がおかしい、ツールがエラーを返す、起動を引っ張る——やりたいのは今回だけ外しておくこと、それだけです。以前は一律の手段しかなく、設定由来のサービスをローカル設定ごと切るしかありませんでした。

今は、起動時に名前を指定して外せます。

```text
qwen --disable-mcp-server github
```

複数まとめて外すなら、この引数は繰り返し書けます。`--disable-mcp-server github,postgres` の書き方にも対応します。効くのはその回の起動だけで、設定ファイルはそのままです。詳しくは PR [#14003](https://github.com/QwenLM/qwen-code/pull/14003)

こんなことに使えます：

- 怪しいサービスをまず外して 1 回試せば、原因がそれかどうか切り分けられる
- 起動が 1 つのサービスに引っ張られているなら、その回だけ外して起動する
- 同じコードで、1 ラウンドはデータベース専用、もう 1 ラウンドは Web 専用と、それぞれ必要なサービスだけ持たせられる

### Web Shell：プロジェクトのファイルは開くだけで見え、追加入力はそのまま届き、待っているときは通知が来る

**プロジェクトのファイルは右側でたどれます。** ワークスペース全体のディレクトリツリーがそこに並び、ファイルを開くと中身が隣に出ます。Markdown、Web ページ、画像、Excel がそのまま見え、パスのコピー、ダウンロード、参照もできます。詳しくは PR [#13878](https://github.com/QwenLM/qwen-code/pull/13878)、[#13664](https://github.com/QwenLM/qwen-code/pull/13664)

**ローカルファイルはドラッグすればアップロードされます。** ドロップしたフォルダにそのまま保存され、デスクトップ版でも同じです。詳しくは PR [#14145](https://github.com/QwenLM/qwen-code/pull/14145)、[#14053](https://github.com/QwenLM/qwen-code/pull/14053)

**キューに入ったメッセージはその場に差し込め、取り消すと入力欄に戻ります。** 回答中に出した一文はまずキューに入ります。早く届けたければ `Send now` を押して即座に挿入できます。AI がまだ何も出力していないところで停止を押すと、その一文は入力欄に戻るため、直してから出せます。詳しくは PR [#13681](https://github.com/QwenLM/qwen-code/pull/13681)、[#13488](https://github.com/QwenLM/qwen-code/pull/13488)

**止まってあなたを待っているときは通知が出ます。** ある操作を通過させてほしいとき、こちらの返事を待っているとき——この 2 つの場面では、以前は何の音沙汰もありませんでした。今はページをバックグラウンドに回しておけば通知が 1 件飛び、押すとそのセッションに戻れます。詳しくは PR [#13832](https://github.com/QwenLM/qwen-code/pull/13832)

**サブ Agent やバックグラウンドタスクが動いているあいだ、チャット欄の上部にあるリスト型のアイコンに点滅が付きます。** パネルを開かなくても分かります。詳しくは PR [#14048](https://github.com/QwenLM/qwen-code/pull/14048)

![Web Shell 右側の Files パネルにワークスペース全体のファイルツリーが開いている（Filter files 検索ボックス、data/tests ディレクトリと各種ファイル）。下部のキューに入ったメッセージの隣に Send now ボタンが表示されている](https://img.alicdn.com/imgextra/i1/O1CN01e27zKWHeHTH4s7X6_!!6000000007916-0-tps-2400-1616.jpg)

## 📊 その他の新機能

**読み取りの調べが続いても結論が出なければ、結果を出すよう促します。** ファイルを読む、コードを検索するといった読み取り専用の操作が一定回数に達すると、次のラウンドで 1 文の促しが入ります。今分かっているものを使い、依頼を 1 歩前に進めるか、どこで行き詰まっているかをはっきりさせる——もともと状況把握を頼まれていたなら、結論と、まだ分かっていない論点を述べます。詳しくは PR [#13601](https://github.com/QwenLM/qwen-code/pull/13601)

**MCP サービスの UI が会話に内容を投稿したいときは、あなたの確認が要ります。** MCP サービスには、ツールだけでなく、会話の中で操作できる UI を付けてくるものもあります。その UI が代わりに 1 文送りたいとなったとき、Qwen Code はまず内容全体と出どころ、どの会話に送るかを提示します。あなたが確認を押してはじめて送信されます。詳しくは PR [#13958](https://github.com/QwenLM/qwen-code/pull/13958)

**ワークフローの各 agent が何をしたかは、そのノードを押せば分かります。** 会話の中のワークフローカード、Tasks ページ、ワークフローページのいずれかで agent を 1 つ押すと、右側パネルに今回の経過が開きます。渡したプロンプト、実行したツール、出力中の内容、どこまで進んだかが並びます。詳しくは PR [#14175](https://github.com/QwenLM/qwen-code/pull/14175)

**手を動かす前のチェックで、今回の引数を書き換えられます。** 設定に書いた hook がこの種のチェックです。あるツールを使う前に 1 回走ります。そこで返された新しい引数は、もう 1 度検証され、権限と承認の確認を通ってから、実際に手を動かしに行きます。詳しくは PR [#13442](https://github.com/QwenLM/qwen-code/pull/13442)

**ついで質問を、別のワークスペースに開けます。** メインのタスクが回答中のとき、`/btw side` は別のワークスペースに会話を 1 本作り、メインのタスクと同じ会話に混ぜません。詳しくは PR [#13468](https://github.com/QwenLM/qwen-code/pull/13468)

**Claude 形式プラグイン同梱のコマンドが、実際に動くようになりました。** この種のコマンドはモデルへのプロンプトではなく、コードです。以前は叩いてもモデルに 1 文言っただけでしたが、今はプラグインがローカルで実行し切って結果をそのまま返し、Token を使いません。設定で `experimental.mods` をオンにし、ワークスペースが信頼済みで、かつ `qwen -p '…'` のように 1 回実行して結果が出る使い方でのみ効きます。インタラクティブ UI と Web Shell ではまだ使えません。実装したのは Mod インターフェースの一部で、既にあるコマンドがすべて動くとまでは言い切れません。詳しくは PR [#13843](https://github.com/QwenLM/qwen-code/pull/13843)、[#13890](https://github.com/QwenLM/qwen-code/pull/13890)、[#13915](https://github.com/QwenLM/qwen-code/pull/13915)、[#13950](https://github.com/QwenLM/qwen-code/pull/13950)

## 👏 体験改善

**新規タスクのページは、まだ何も言わないうちから右側のファイル・ターミナル・Web ページプレビューを使えます。** 上部はすっきりしたツールバー 1 本になりました。このレイアウトはワークスペースごとに別々で覚えられ、更新してもセッションを切り替えても消えません。最初の 1 文を出したとき、タブも並びもパネルの幅も Fullscreen もまとめて、新しく作ったセッションに引き継がれます。詳しくは PR [#14159](https://github.com/QwenLM/qwen-code/pull/14159)

**Trajectory タブは検索でき、絞り込めて、過去へ遡れます。** ツール名、モデル名、記録の中の 1 文で飛びに行けます。ある種類の記録だけ、失敗だけ、成功だけと絞ることもできます。より古い記録は 1 区間ずつたどれ、たどり終えれば最新に戻ります——検索と統計は、いまたどっている区間だけを数えます。途中で切れて再接続しても、どこにいて、どれを選び、何を絞り込み、どこまでスクロールしていたかは失われません。詳しくは PR [#13264](https://github.com/QwenLM/qwen-code/pull/13264)、[#13716](https://github.com/QwenLM/qwen-code/pull/13716)、[#13952](https://github.com/QwenLM/qwen-code/pull/13952)

**回答のある範囲を選ぶと、コピーの仕方を決められます。** マウスでなぞるとメニューに 2 つの選択肢が出ます。プレーンテキストか、書き方を残した Markdown か——見出し、リスト、コード、表もついてきます。詳しくは PR [#13833](https://github.com/QwenLM/qwen-code/pull/13833)

**コンテキストの使用量は、押すと右側に開き、会話にカードを積まなくなりました。** 以前は入力欄のリングを押すと Context Usage のカードが会話に 1 枚落ち、その明細がもう 1 枚落ちていました。今は両方とも右側パネルに開き、セッションごとに 1 枚ずつ残ります。会話に残したいときは `/context` を叩してください。詳しくは PR [#14086](https://github.com/QwenLM/qwen-code/pull/14086)

**横幅も高さもある表は全画面で見られます。** 表の Fullscreen を押すとウィンドウいっぱいに広がり、Esc か終了ボタンで出ます。並べた順、絞り込み条件、列の設定、何行目まで読んだかはそのまま残ります。詳しくは PR [#13589](https://github.com/QwenLM/qwen-code/pull/13589)

**キュー待ちの一文は、出す前にその場で消せます。** 添付をアップロードしている途中の一文も消せ、途中でできたファイルまで一緒に片付きます。詳しくは PR [#13594](https://github.com/QwenLM/qwen-code/pull/13594)

**このラウンドを畳むと、バックグラウンドで出た結果もいっしょに隠れます。** バックグラウンドタスクの成果物カードと完了通知が、まとめて折りたたみの中に入ります。詳しくは PR [#13825](https://github.com/QwenLM/qwen-code/pull/13825)

**音声入力のメッセージに中国語が加わり、エラーは閉じられます。** エラー表示や「音声が聞こえなかった」といったメッセージが言語に追従します。メッセージの右上の閉じるを押すとマイクは待機に戻り、そのままもう 1 回試せます。詳しくは PR [#13938](https://github.com/QwenLM/qwen-code/pull/13938)

**独立したコピーが欲しいなら、Worktree を選ぶだけになりました。** Git のダイアログで押すと即確定し、メニューは閉じます。実際のコピー作成と名前付けは、あなたが最初の 1 文を出すとき、セッション作成の手順に沿って行われ、そのあいだはいつでも元に戻せます。詳しくは PR [#13607](https://github.com/QwenLM/qwen-code/pull/13607)

**アイコンを今のブランドロゴに揃えました。** Web Shell のブラウザタブのアイコン、サイドバーのロゴ、ブラウザ通知のアイコンに加え、デスクトップ版の起動画面とアプリアイコンも差し替えです。詳しくは PR [#14052](https://github.com/QwenLM/qwen-code/pull/14052)
