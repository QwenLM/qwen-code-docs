Qwen Code は今週、v0.26.8〜v0.27.2 の 5 つの正式版をリリースしました。

**Qwen サブスクリプションのアカウントでログインしてすぐ使えます。** CLI、VS Code、デスクトップ版のいずれにも Plus/Pro サブスクリプションでログインでき、サブスクリプション内のモデルでチャットや Web 検索をそのまま使えます。

**WeChat、QQ、メールは Web Shell で設定できます。** WeChat と QQ はページ上の QR コードをスマホでスキャンしてログイン。メールはサーバーとアカウント情報を入力するだけで接続できます。

**GitHub チャンネルはリポジトリ単位で動きを絞り込めます。** ホワイトリストは記載したリポジトリだけを受け取り、ブラックリストは記載したリポジトリを除外します。

## ✨ 新機能

### Qwen サブスクリプションのアカウントで Qwen Code にログイン

Qwen アカウントに Plus または Pro サブスクリプションがあれば、そのアカウントでターミナル、VS Code、デスクトップ版にログインできます。ターミナルで `/auth` を実行し、「Qwen Account with Subscription」を選んで、ブラウザで認証を完了します。ログイン後はサブスクリプションで使えるモデルが読み込まれ、組み込みの Web 検索も使えます。

こんなことに使えます：

- サブスクリプションのモデルでそのまま作業でき、使用量はサブスクリプションに計上されます
- ターミナル、VS Code、デスクトップ版に同じアカウントでログインすれば、モデルも同じです
- API の設定なしで、Qwen のサブスクリプション契約後すぐに Qwen Code で使えます

詳しくは PR [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Qwen サブスクリプションでログインした後のアカウントとモデル一覧](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### Web Shell で WeChat、QQ、メールのチャンネルを設定

Web Shell のチャンネル管理に WeChat、QQ、メールの 3 プラットフォームが加わりました。WeChat と QQ はページに QR コードが表示され、スマホでスキャンするだけでログインできます。メールはサーバーアドレスとアカウント情報を入力すれば接続できます。これで Telegram 以外の主要チャットプラットフォームはすべて Web Shell で設定できます。

こんなことに使えます：

- Web Shell の QR コードをスマホでスキャンして、個人 WeChat のチャットや QQ を接続
- チャンネル管理でメールチャンネルを追加・編集し、メールで会話を開始できる送信者を指定
- チャンネルのペアリング解除も Web Shell でワンクリック管理

詳しくは PR [#16736](https://github.com/QwenLM/qwen-code/pull/16736)、[#16724](https://github.com/QwenLM/qwen-code/pull/16724)、[#16746](https://github.com/QwenLM/qwen-code/pull/16746)

![Web Shell の WeChat チャンネルの QR コードログイン画面](https://img.alicdn.com/imgextra/i1/O1CN01ldag0pIAw9J4s7XG_!!6000000004740-2-tps-2400-1626.png)

### GitHub チャンネルの動きをリポジトリ単位で絞り込む

GitHub チャンネルはリポジトリの動きを自動で会話に届けます。PR の作成、コメント、CI の完了を Agent が引き継いで処理します。受け取る範囲はリポジトリ単位で選べます。ホワイトリストは記載したリポジトリだけを受け取り、ブラックリストは記載したリポジトリ以外をすべて受け取ります。除外された動きはそのままスキップ。会話に入るのは受け取り対象のリポジトリの動きだけで、処理もその分だけです。

こんなことに使えます：

- 組織に数百のリポジトリがあっても、自分が担当する 2 つだけを記載すれば、その動きだけ届きます
- しばらく追わないリポジトリはブラックリストに入れておき、担当になったら戻せます
- 無関係なリポジトリの PR が Agent の行列に並ばなくなり、気になるリポジトリの処理が速くなります

詳しくは PR [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

![チャンネルエディターのリポジトリフィルター設定](https://img.alicdn.com/imgextra/i4/O1CN01NAru06FwyBE7o1Mj_!!6000000003227-2-tps-3845-2160.png)

### Web Shell：質問と使用量を画面で把握、会話はまとめて整理

**質問と回答のヒートマップ。** 数日かかる長いタスクでも、ヒートマップボタンから日付別のカレンダーを開けます。色の濃さがその日の質問と回答の回数に対応し、日付をクリックするとその日の最初の質問と回答へ直接ジャンプします。詳しくは PR [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**入力欄の下に使用量バー。** ターン数、出力速度、合計トークン、キャッシュヒット率が入力欄の下に 1 行で表示されます。詳しくは PR [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**会話をまとめてピン留め・アーカイブ。** サイドバーに複数選択スイッチが増え、会話を選んでワンクリックでピン留めやアーカイブができます。詳しくは PR [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**わからない選択肢は詳細を質問。** AI が選択式の質問を出したとき、問題パネルの「Ask for details」ボタンから枝分かれのタスクを開き、各選択肢の意味、違い、影響、推奨を確認できます。詳しくは PR [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**その他の改善。** ワークスペースはワンクリックで全部折りたたみ・展開でき、タイトルをつかんでドラッグで並べ替えられます（[#16197](https://github.com/QwenLM/qwen-code/pull/16197)）。バックグラウンドタスクが承認を待っているときは、デスクトップ通知やターミナルのベルで知らせ、別のウィンドウで作業中でも気づけます（[#16800](https://github.com/QwenLM/qwen-code/pull/16800)）。MCP 呼び出しなどのツールカードは、展開するとパラメータと完全な結果がそのまま表示されます（[#15435](https://github.com/QwenLM/qwen-code/pull/15435)）。スキルページから ZIP 圧縮パッケージを直接アップロードしてスキルをインストールできます（[#16424](https://github.com/QwenLM/qwen-code/pull/16424)）。

![Web Shell のサイドバー複数選択と入力欄下の使用量バー](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 その他の新機能

**定期ジョブの配信先チャンネルを選べます。** Web Shell で定期ジョブを作成するとき、結果を送るチャンネルを指定できます。詳しくは PR [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**QQ グループへ自分からメッセージを送れます。** 定期ジョブ、webhook、バックグラウンドタスクの結果を、QQ グループへの自発的なグループメッセージとして送れます。オプションの `forwardBotMessages` スイッチをオンにすると、グループ内の他のボットのメッセージも会話に転送されます。詳しくは PR [#15635](https://github.com/QwenLM/qwen-code/pull/15635)、[#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**ファイル変更フック。** ローカル会話に `FileChanged` フックが増えました。監視しているファイルやディレクトリの作成・変更・削除で、設定したフックが発火します。他のプログラムによる変更も通知されます。詳しくは PR [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Mods プラグインに 3 つの機能。** `$.store` でプラグインのデータをセッションをまたいで保存。`ui.render` はターミナルに表示される返信テキストだけを書き換え、保存・コピーされるテキストは元のまま。`$.model.complete` は 1 回限りのテキスト補完を実行します。詳しくは PR [#16791](https://github.com/QwenLM/qwen-code/pull/16791)、[#16794](https://github.com/QwenLM/qwen-code/pull/16794)、[#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**PR に紐づいた会話は新しいコメントを自動で受け取ります。** 会話を PR に紐づけると、その PR の新しいコメントが自動で会話に届きます。通常のコメントもインラインレビューコメントも対象で、@ メンションなしで受け取れます。詳しくは PR [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 体験改善

**/btw のついで質問：フォローアップと同時質問に対応。** 新しいついで質問を始めると、回答済みのついで質問も一緒に渡され、前の回答の続きを聞けます。同時にいくつも聞いても、それぞれ独立して回答されます。詳しくは PR [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**起動時に使用中の Shell を AI に伝えます。** 会話の冒頭に、コマンドを実行する Shell（bash、cmd.exe など）が明記されます。AI はシステムから構文を推測する必要がなく、Windows でもコマンドの書き間違いが減ります。詳しくは PR [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**会話の自動タイトルは会話の言語に合わせます。** 中国語の会話には中国語のタイトルを生成し、言語ごとに揃えます。詳しくは PR [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Goal のチェック結果の理由は会話の言語で表示。** 合格・却下の理由を、会話の出力言語で表示します。詳しくは PR [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**タイ語、ラオ語、クメール語、ビルマ語のフォローアップ提案はその言語のまま。** これらの言語でチャットすると、フォローアップ提案も同じ言語で生成されます。詳しくは PR [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**実験的なコードインテリジェンス（LSP）を設定で有効化。** ユーザーレベルの設定で `tools.lspEnabled` を true にするだけで有効になります。コマンドライン引数は不要で、引数を渡せないデスクトップ版などのクライアントでも、定義ジャンプ、参照検索、診断を使えます。デフォルトはオフです。詳しくは PR [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**サブ Agent のフォアグラウンド／バックグラウンド既定を全体で設定。** `agents.defaultBackground` を false にすると、サブ Agent はフォアグラウンドで実行され、完了を待って結果を現在のターンに直接返します。チャンネルやボットなど、1 ターン内で結果が必要な場面に向いています。再起動後に有効になります。詳しくは PR [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**マネージドセッションは複数の質問を同時に保持。** マネージドセッションが出した複数の質問は同時に並べられ、どの順序でも回答できます。詳しくは PR [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**チャンネルイベントから会話へ直接ジャンプ。** チャンネルイベントのタイムラインの項目をクリックすると、対応する会話に直接移動します。詳しくは PR [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
