Qwen Code は今週、v0.21.12 から v0.21.14 までの 3 つの正式版をリリースし、140 以上の PR をマージしました。

**独立したセカンドオピニオン。** `/advisor` は現在の会話を独立した立場でレビューし、結論・リスク・不足している証拠・提案の 4 項目を返します。終始読み取り専用で、メインの会話には触れません。

**実行中のセッションを 1 つのコマンドで把握。** 新しい `qwen sessions ps` コマンドが、このマシンで実行中のセッションを一覧表示します：どのディレクトリで動いているか、どれくらい動いているか、プロセス ID。

**Review は中断しても最初からやり直さない。** 中断した PR レビューは `--resume` で再開でき、状態が一致すれば中断したところから続行します。

## ✨ 新機能

### /advisor：独立したモデルが現在の会話をレビュー

会話が長くなると 1 つの考え方にとらわれやすく、自分のコンテキスト内の盲点には気づきにくいものです。`/advisor` は現在の会話に独立したセカンドオピニオンを用意します：読み取り専用の別セッションがコンテキスト全体を読み通し、結論・リスク・不足している証拠・提案の 4 項目を返します。セカンドオピニオンは厳密に読み取り専用で、メインの会話を変更せず、何も実行しません。レビュー後の会話にも影響しません。

気になる点を添えて質問できます（例：`/advisor この案は安全ですか`）。`advisorModel` 設定でレビュー専用モデルを指定でき、未設定なら現在のモデルが使われます。

詳細は PR [#7567](https://github.com/QwenLM/qwen-code/pull/7567) を参照

![/advisor が返す 4 項目のレビュー](https://img.alicdn.com/imgextra/i4/O1CN01x6UkJeTG4kD7nOLI_!!6000000004249-2-tps-3840-2160.png)

### qwen sessions ps：実行中のセッションを 1 つのコマンドで把握

Qwen Code のセッションを同時に複数開いていると、どれがどれか分からなくなりがちです。新しい `qwen sessions ps` コマンドは、このマシンで現在実行中のインタラクティブセッションをすべて、1 行 1 件で一覧表示します：セッション名、プロセス ID、実行時間、ディレクトリ。スクリプトと連携したい場合は `--json` を付けると JSON で出力できます。

一覧に出るのは実際に動いているセッションだけです：セッションを閉じれば、すぐにリストから消えます。

詳細は PR [#8969](https://github.com/QwenLM/qwen-code/pull/8969) を参照

![qwen sessions ps が実行中のセッションを一覧表示](https://img.alicdn.com/imgextra/i1/O1CN01edM2ef0oKxI7nOLI_!!6000000005536-2-tps-3840-2160.png)

### Review シリーズ：中断した PR レビューを再開、コメントは分かりやすい言葉に

`/review` に今週、実用的な改善がいくつか入りました。

**中断したレビューを途中から再開。** 大きな PR のレビュー中に中断すると、これまでは最初からやり直すしかありませんでした。今は `qwen review fetch-pr` に `--resume` が追加されました：まずディスク上の状態を確認し、前回のレビューレポート、worktree、diff の内容がいずれも変わらず、PR も更新されていなければ、そのまま続きを実行します。どれか 1 つでも一致しなければ、自動的に最初からやり直します。

**レビューコメントを分かりやすい言葉に。** `/review` で PR をレビューしてコメントを投稿する際、これまではテンプレート調の強いコメントでしたが、今は自然なレビュー表現に書き換えられます：問題はどこか、いつ問題になるか、どう直すか。PR に投稿するコメントについては、重要度マークと署名を付けるか、どこまで深く調べるか、そもそも投稿するかまで、設定で変えられます。

**スクリプトのレビューは実行環境を見てチェック。** shell スクリプトや CI 設定といったファイルは、「このマシンでは動くのに、環境が変わると壊れる」問題が見つかりにくいものです。レビュー時はまず、これらのファイルが実際にどの環境で動くかを特定し、その環境の特徴に合わせてチェックします。

詳細は PR [#9092](https://github.com/QwenLM/qwen-code/pull/9092)、[#9027](https://github.com/QwenLM/qwen-code/pull/9027)、[#8994](https://github.com/QwenLM/qwen-code/pull/8994)、[#9263](https://github.com/QwenLM/qwen-code/pull/9263) を参照

### Web Shell ファイル転送：ローカルファイルを会話に直接ドラッグ

リモート接続トークン（`QWEN_SERVER_TOKEN` または `--token`）を設定すれば、ファイルを Web Shell の入力欄にドラッグ、またはコピー＆ペーストするだけで Qwen Code に渡せます：任意のファイルはワークスペースに保存され、会話には自動的に参照が付き、AI はそのまま使えます。テキストファイルなら内容を直接会話に添付でき、AI はファイルを開かずにその場で読めます。

アップロード先のフォルダも指定でき、フォルダが存在しなければ自動作成されます。トークン未設定の場合、入力欄へのファイルのドラッグやペーストにはまだ対応していません。

詳細は PR [#8874](https://github.com/QwenLM/qwen-code/pull/8874)、[#9180](https://github.com/QwenLM/qwen-code/pull/9180)、[#9382](https://github.com/QwenLM/qwen-code/pull/9382) を参照

## 📊 その他の新機能

**ワークフローの agent を指定ディレクトリに固定。** ワークフロー内で `agent({workingDir})` を使うと、agent を指定ディレクトリに固定して作業させられます。デフォルトのディレクトリ範囲に縛られません。詳細は PR [#8972](https://github.com/QwenLM/qwen-code/pull/8972) を参照

**リリースノートにバイリンガルサマリー。** リリースノートは PR リストの羅列ではなくなりました：機能テーマごとにグループ化し、各グループに分かりやすいサマリーを付け、中国語版も付きます。PR に含まれていた前後比較のスクリーンショットも一緒に載ります。詳細は PR [#9216](https://github.com/QwenLM/qwen-code/pull/9216) を参照

**外部知識ベース統合の統一仕様。** 検索サービスを提供するベンダーは、仕様に沿って Qwen Code プラグインを開発でき、プラグインを入れれば AI がそのベンダーのコーパスを検索できます。何を検索できるかはインストールしたプラグインで決まり、AI はその範囲内でのみ検索します。詳細は PR [#9068](https://github.com/QwenLM/qwen-code/pull/9068) を参照

## 👏 体験最適化

**Channel 管理を完全な管理ページに刷新。** Web Shell の Channel 管理は、スケジュールタスクと同じ全ページレイアウトになりました：各 Channel を誰が使えるか、承認制かホワイトリスト制か、セッションをどう分割するか、どのワークスペースに紐付けるかを、すべて 1 ページで設定できます。詳細は PR [#8848](https://github.com/QwenLM/qwen-code/pull/8848) を参照

**WeChat の「入力中」表示が長時間タスクでも途切れない。** WeChat の「相手が入力中」ステータスは期限切れになるため、これまでは長時間タスクの実行中に表示が消え、接続が切れたようになっていました。今はタスク実行中、4 秒ごとに更新され、完了後に初めて消えます。詳細は PR [#9358](https://github.com/QwenLM/qwen-code/pull/9358) を参照

**コンパクトモードでも AI の思考が見えるように。** Web Shell のコンパクトモード（Ctrl+O）は、これまで思考内容を完全に隠していました。今はモデルの思考中、サマリーに「思考中」と表示され、思考が終わるとツールサマリー内に折りたたまれ、クリックで開けます。詳細は PR [#9148](https://github.com/QwenLM/qwen-code/pull/9148) を参照

**サイドバーをたたんでもセッションを切り替え。** Web Shell のサイドバーをたたんだ後は、プロジェクトアイコンにホバーするとセッションブラウザ全体を開けます。承認待ち、質問、完了待ちなどの状態はアイコンに色で示されます。詳細は PR [#9311](https://github.com/QwenLM/qwen-code/pull/9311) を参照

**画像プレビューがリフレッシュ後も消えない。** Web Shell で送信した画像は、キュー待ちでもタスク実行中に投入済みでも、ページをリフレッシュした後にプレビューが残ります。複数画像がまとめられたり消えたりしません。詳細は PR [#9310](https://github.com/QwenLM/qwen-code/pull/9310) を参照

**切断中でも質問を送信可能。** Web Shell の入力欄は接続状態から切り離されました：ストリームが切断していても質問を通常どおり送信でき、入力欄がロックされることもありません。詳細は PR [#9323](https://github.com/QwenLM/qwen-code/pull/9323) を参照

**エクスポートした HTML をワンクリックで展開・折りたたみ。** `/export` でエクスポートした会話の HTML ページ上部に「すべて展開／すべて折りたたむ」ボタンが追加され、思考ブロックとツール出力をワンクリックで一括切り替えできます。詳細は PR [#9367](https://github.com/QwenLM/qwen-code/pull/9367) を参照

**大きなセッションの復元が高速化。** daemon のセッション復元はオンデマンド読み取りに変わり、状態の再構築に必要なレコードだけを読むようになりました。大きなセッションで効果が顕著です。詳細は PR [#9055](https://github.com/QwenLM/qwen-code/pull/9055) を参照

**バックグラウンド shell の誤クリーンアップを防止。** バックグラウンドで実行中の shell はアクティブタスクとしてカウントされるようになり、稼働中に自動クリーンアップされません。詳細は PR [#9042](https://github.com/QwenLM/qwen-code/pull/9042) を参照
