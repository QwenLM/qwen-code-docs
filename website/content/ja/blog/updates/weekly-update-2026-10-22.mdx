Qwen Code は今週、v0.25.3 と v0.26.0 の 2 つの正式版をリリースし、436 件の PR がマージされました。

**結果は、その場で数字を直せるインタラクティブカードにできます。** 数字をいくつか変えたり条件をいくつか試したりして結果の違いを見たくなったら、カード上の数字を直接変更します。合計は追って再計算されます。

**サブディレクトリでも、リポジトリに保存済みのワークフローが使えます。** プロジェクトがフロントエンド、バックエンド、複数のコンポーネントディレクトリに分かれているとき、ルートでコード検査やテスト実行のフローを保存済みなら、サブディレクトリで Qwen Code を起動しても同じフローが見つかり、実行できます。

**Web Shell の管理は `qwen daemon` の 1 組のコマンドにまとまりました。** 起動、状態確認、ログ閲覧、停止、再起動まで、この 1 組で済みます。

## ✨ 新機能

### インタラクティブカード：調整しながら比較して、しっくりくる案を見つける

数字をいくつか変えて、条件いくつで結果がどう違うか見たくなることがあります。Qwen Code はこの種の要望に、そのままインタラクティブカードで答えます。数字も割合もその場で変更でき、結果はすぐに出ます。詳しくは PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

たとえばチームの会食の段取りなら、費用計算のカードを作らせて、人数、1 人あたりの食事代、会場費を入力します。人数が変われば人数を、会場を変えるなら食事代を書き換えます。合計費用は追って再計算されるので、その都度メッセージで計算し直させる必要はありません。

この機能はデフォルトではオフで、実験設定で Generated UI をオンにし、再起動すると有効になります。マネージド、リモート、サンドボックスのセッションではビルトイン版がまだ使えません。詳しくは PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

こんなことに使えます：

- 引っ越し先の比較——家賃、通勤時間、交通費を合わせて見比べる
- プロジェクトの人員とタスクの割り当てを調整しながら、工期とコストを見積もる
- サーバー構成を比べ、アクセス量ごとに容量と費用を見積もる

### ワークフロー：プロジェクトのサブディレクトリに入っても、同じ流れが使える

プロジェクトをフロントエンド、バックエンド、複数のコンポーネントディレクトリに分けていることがあります。ルートでコード検査やテスト実行のワークフローを保存済みなら、このほどサブディレクトリで Qwen Code を起動しても、それらが見つかり、実行できるようになりました。

たとえばフロントエンドディレクトリでページを直しているとき、プロジェクトに保存済みの検査フローを走らせたくなることがあります。今の会話のワークフロー一覧から見つけてそのまま実行できます。今回の更新は、現在のディレクトリから上位へ、同じ Git リポジトリ内の信頼済みディレクトリにあるワークフローを辿るようになり、ローカルのターミナル会話でも通常の Web Shell 会話でも使えます。詳しくは PR [#14369](https://github.com/QwenLM/qwen-code/pull/14369)、[#14646](https://github.com/QwenLM/qwen-code/pull/14646)

こんなことに使えます：

- いろいろなコンポーネントディレクトリから、プロジェクト共通のコード検査フローを使い回す
- バックエンドのコードを変えたあと、リポジトリに保存済みのテストフローを走らせる
- プロジェクトのドキュメントを書くとき、上位ディレクトリに保存済みのドキュメント検査フローを使う

### qwen daemon：Web Shell の管理は 1 組のコマンドで

先週 Web Shell が 1 ページで複数の Qwen Code に接続できるようになり、今週はこれらのローカルサービスを管理するコマンドが加わりました。

Web Shell の起動、状態確認、再起動といった操作は、すべて `qwen daemon` コマンドに集約されています。

`qwen daemon start` を実行するとサービスはバックグラウンドで起動し、アクセスアドレスを返します。`qwen daemon status` で起動済みのサービスを確認し、`qwen daemon logs` でログを読み、`qwen daemon stop` で指定したサービスを止めます。詳しくは PR [#14739](https://github.com/QwenLM/qwen-code/pull/14739)、[#14869](https://github.com/QwenLM/qwen-code/pull/14869)

トラブル調査では、`qwen daemon status --detail` がバージョン、稼働時間、セッション数、問題数まで出します。スクリプトの中で起動した直後に接続したいときは `qwen daemon start --wait` を使い、実行環境の用意ができてから次に進めます。詳しくは PR [#14902](https://github.com/QwenLM/qwen-code/pull/14902)、[#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <ポート>` は指定したローカルの HTTP サービスを再起動し、記録されている起動時のワークスペースと Web Shell の設定も復元します。詳しくは PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

こんなことに使えます：

- ローカルサービスを起動したあと、同じターミナルで他の作業を続けられる
- 複数のローカルサービスの状態を見比べて、対処が必要な 1 つを特定できる
- 記録された起動設定どおりに、指定したサービスを再起動できる

### Web Shell：ファイルと実行記録が、界面でもっと見やすく

**PDF と Word ファイルは界面で直接開けます。** `@` からの参照、右側の Files、成果物カード——どの入口からでも開けます。PDF はブラウザ内蔵のビューアを使い、Word ファイルも同じ入口でプレビューできます。詳しくは PR [#14825](https://github.com/QwenLM/qwen-code/pull/14825)、[#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**右側のファイルは作成も削除もできます。** チャットタイトルの横にあるディレクトリ名を押すと、右側にワークスペースのファイルツリーが開きます。ここでファイルもフォルダも新規作成できます。ファイルは 1 回確認してから削除、フォルダはもう 1 回確認が挟まります——中身まで一緒に消えるためです。詳しくは PR [#14344](https://github.com/QwenLM/qwen-code/pull/14344)、[#14169](https://github.com/QwenLM/qwen-code/pull/14169)、[#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**Trajectory は、過去を遡ると自動で止まります。** 記録をさかのぼって見ているあいだ、画面は見ている数行で止まります。最新の続きまで見たければ `Jump to latest` を押します。一覧の任意の行を選ぶと、その記録の詳細が開きます。詳しくは PR [#14723](https://github.com/QwenLM/qwen-code/pull/14723)、[#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**その他の改善。** 会話で 1 組の質問と回答だけを選んで一緒に削除でき、いくつか選んでまとめて消すこともできます（[#14297](https://github.com/QwenLM/qwen-code/pull/14297)）。作業中と作業終わりの項目は、各ステップの所要時間とともに、折りたためる `Recent activity` にまとめられました（[#14071](https://github.com/QwenLM/qwen-code/pull/14071)）。セッションの Token 消費量パネルでは、概要に入力・出力・キャッシュを残し、下段でモデルごと、メイン Agent とサブ Agent がそれぞれいくら使ったかを分けて確認できます。モデル名横の Info アイコンにマウスを乗せると、最初の文字が出るまでの時間と 1 秒あたりの出力量も出ます（[#14728](https://github.com/QwenLM/qwen-code/pull/14728)、[#14648](https://github.com/QwenLM/qwen-code/pull/14648)）。

![Web Shell の右側パネルでプロジェクトのファイルを開き、Trajectory に切り替えて各ステップの所要時間を見る](https://img.alicdn.com/imgextra/i4/O1CN011HVsNLd8EyF7nW9B_!!6000000005070-2-tps-3841-2160.png)

## 📊 その他の新機能

**`/auth` の最初の画面に QwenCloud の入口が加わりました。** 従量課金のキーと Token Plan のキーを分けて選び、その次のステップで China か International を選びます。詳しくは PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**自ら構築した Managed Agent サービスなら、プロジェクトとタスクの管理がもっと簡単に。** これらのセッションは、あなたのパソコン上のセッションと同じ Web Shell のホームに並び、同じ入力欄と同じ承認カードを使います。今期は既存のプロジェクトディレクトリを直接選べ、新規セッション作成時に有効済みのスキルを付けられ、実行中に実行権限を調整でき、セッション名も手で変えられます。通常のマネージドセッションも同じプロジェクトディレクトリを同時に使え、ファイルはこれらのセッションで共有されます。いずれも対応するデプロイ側のサポートが必要です。詳しくは PR [#14316](https://github.com/QwenLM/qwen-code/pull/14316)、[#14970](https://github.com/QwenLM/qwen-code/pull/14970)、[#14930](https://github.com/QwenLM/qwen-code/pull/14930)、[#14920](https://github.com/QwenLM/qwen-code/pull/14920)、[#14987](https://github.com/QwenLM/qwen-code/pull/14987)、[#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**QQ ボットがファイルを受け取れるようになりました。** プライベートチャットでもグループで @ しても、Word、PDF、スプレッドシートを渡せば、受け取って読み、そのとおりに回答します。詳しくは PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**WeCom の自社アプリを接続できるようになりました。** 同僚が自社で構築したアプリのなかで一言用件を伝えれば、Qwen Code が受け取って作業し、終わったらそのアプリの名前で返信します。詳しくは PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Claude 形式プラグイン同梱のコマンドが、ターミナルでも叩けるようになりました。** 先週は 1 回実行して結果が出る使い方でのみ効いていましたが、今はターミナルで直接叩け、モデルへリクエストしません。モデルがツールを使う前に挟まるプラグインのフック層もインタラクティブ会話で開通し、その 1 回の呼び出しを書き換えたり、止めたりできます。これはデフォルトオフで、設定に Mods のスイッチがあり、変更すると再起動で有効になります。詳しくは PR [#14268](https://github.com/QwenLM/qwen-code/pull/14268)、[#14565](https://github.com/QwenLM/qwen-code/pull/14565)、[#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**バックグラウンドで走っているコマンドは、どこまで出力したかその場で分かります。** タスクの詳細に出力の末尾、出力サイズ、最後の書き込み時刻が並び、さらに確保したメモリ量、開始と終了の時刻も出ます。内容もワンクリックでコピーできます。詳しくは PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 体験改善

**ホームの折りたたまれた内容は、マウスを乗せると先にプレビューできます。** 詳しくは PR [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**表の並び替え・絞り込み・コピーが使いやすくなりました。** 横幅のある表の詳細コントロールとコピーの経路は、今回まとめて使いやすい形に直されました。詳しくは PR [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**同じ作業を繰り返したら、そのラウンドを打ち切らずにまず促します。** コマンド実行やファイル読み取りが一定回数に達すると、デフォルトでは別のやり方を促して続けます。自動で止めたければ設定で選べます。詳しくは PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**スマホの入力欄から矢印キー 2 つが減りました。** 入力欄の上にあった、履歴を辿る上下キーはなくなりました。履歴の検索はこれまでどおりその場で使えます。詳しくは PR [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**ブラウザタブのアイコンが暗い配色でも見えるようになりました。** タブの背景が暗いとき、アイコンがほぼ背景に溶け込んでいました。詳しくは PR [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**モデル一覧はセレクターの中でリフレッシュできます。** モデルセレクターを押すとモデル一覧を再取得でき、リフレッシュは検索欄の横の小さなアイコンとして出ます。詳しくは PR [#14685](https://github.com/QwenLM/qwen-code/pull/14685)、[#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**Linux のターミナルで `Ctrl+V` が文字の貼り付けに使えます。** クリップボードの中身が文字やリンクならそのまま入力欄へ貼り、画像はこれまでどおり添付として扱います。詳しくは PR [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
