Qwen Code はこの 2 週間で v0.24.5 ～ v0.25.0 の 4 つの正式版をリリースし、467 件の PR がマージされました。

**Qwen Live が使えるようになりました。** 声で話しかけると、音声で返ってきます。会話中は画面共有もでき、いま画面で起きていることを見せられます。

**Qwen Code がログイン済みのウェブページを操作できます。** いつも使っている Chrome に入ってページ移動・入力・送信をこなし、すべてバックグラウンドで完結するので、パソコンを使うじゃまになりません。

**メール 1 通で仕事が出せます。** 手元にそのパソコンがないとき、スマホのメールアプリで一言伝えれば、そこで動いている Qwen Code が片付けて、結果を返信で知らせてくれます。

**まとめ作業は /batch-api で半額バックグラウンドに。** やりたいことを伝えると、まず課金されない計画を出し、うなずいてはじめて預かります。数時間後、結果はファイルとして手元に届きます。

**1 ラウンドが遅い・高いと感じたら Trajectory タブ。** Model requests、Tool calls、Subagent requests を 3 本に広げるので、異常に長い区間が一目で見えます。

## ✨ 新機能

### Qwen Live が登場

Qwen Live が使えるようになりました。Web Shell とデスクトップ版の両方です。左のサイドバーで Live アイコンを選ぶと、右側に Qwen Live のカードが開きます——スイッチをオンにし、百炼の DashScope Realtime API キーを貼り付けて Save を押すだけ。詳しくは PR [#12529](https://github.com/QwenLM/qwen-code/pull/12529)

有効にしたら、Live ページで「Open Live Voice」を押すか、入力欄の右下にあるリアルタイム音声ボタンを押すと、話し始められます。返答は音声で届きます。詳しくは PR [#12189](https://github.com/QwenLM/qwen-code/pull/12189)

会話の最中は「画面共有」も使えます。画面で起きていることを Qwen Code 自身が見たうえで、映っているエラーメッセージの意味をそのまま質問できます。詳しくは PR [#12378](https://github.com/QwenLM/qwen-code/pull/12378)、[#12623](https://github.com/QwenLM/qwen-code/pull/12623)

こんなことに使えます：

- キーボードがふさがっているとき、次の手順を声で伝える
- 画面に読めないエラーが出たら、画面共有して相手にも見てもらったうえで意見をもらう
- 1 ラウンドで何文も往復するやり取りを、話し終えるだけで済ませる

### Qwen Code がログイン済みのウェブページを操作できる

Qwen Code は、いつも使っている Chrome に入って仕事ができます。開いているタブもログイン済みのアカウントもそのまま使い、ページ移動・入力・送信を済ませ、結果のページは手元に残します。「開いているレポートを読んで、今日の注文をまとめて」と一言頼むだけでかまいません。詳しくは PR [#11242](https://github.com/QwenLM/qwen-code/pull/11242)

使う前に Chrome ウェブストアから [Qwen Code 拡張機能](https://chromewebstore.google.com/detail/qwen-code/hdhmmjclhibojdddmancfgbkleahfaph) を追加しておいてください。以後は会話で用件を言うだけです。Mac と Linux で使えますが、Windows はまだ未対応です。詳しくは PR [#12510](https://github.com/QwenLM/qwen-code/pull/12510)

作業はすべてバックグラウンドで完結し、Chrome が前面に出てこないのでパソコンの利用をじゃましません。複数のセッションで同時に使っても、それぞれ別のタブグループで、互いに干渉しません。詳しくは PR [#12229](https://github.com/QwenLM/qwen-code/pull/12229)

こんなことに使えます：

- ログイン済みの管理画面を読ませ、今日の数字を取り出して手元の表と突き合わせる
- 経費精算やチケットがいくつかのページに散っているとき、一言で一つずつ入力して送信させる
- ページでしか見えないフロー（承認待ちキューや ToDo 一覧）を見張らせて、対応が必要なものを絞り込む

### メール 1 通で仕事を頼める

用が思い浮かんでも、Qwen Code が動いているパソコンに届かないことがある——手が届かないのです。そこで Email Channel が加わりました。メール 1 通送るだけでいいです。

スマホの好きなメールアプリで一言伝えれば、そのパソコンの Qwen Code が作業し、終わった結果を返信 1 通で知らせてくれます。どこか気になるなら、その返信に一言足すだけで、これまでどこまで進んだかを踏まえて続けます。ユーザーから届いた障害報告メールやシステムのアラートも、そのままこのアドレスに転送して引き受けさせられます。

使うには、Qwen Code にメールアカウントを 1 つ割り当て、さらに自分のメールアドレスを許可リストに書きます。あなたからのメールだけが作業を起動します。

こんなことに使えます：

- 通勤中に 1 通送っておけば、作業を前もって進めてくれ、席に着いたら結果を見るだけ
- 障害報告メールをそのまま転送すると、添付のログを読んで最初の判断を返す
- アラートメールが出た直後に Qwen Code が先に調べ始め、原因を返信してくる

詳しくは PR [#12939](https://github.com/QwenLM/qwen-code/pull/12939)

### /batch-api：まとめ作業を半額でバックグラウンドに

手がつけられていない小さな作業が数百個溜まることがあります。ディレクトリまるごとのドキュメント翻訳、数十枚のチケットからの項目抽出、1 本ごとの要約作成。1 通ずつ出すと、待ち時間だけで会話を埋め、コストも膨らみます。

`/batch-api` の後に用件を 1 文書くと、まず数件を見本で確認し、計画を 1 枚出します——合計何件か、どこに書き出すか、Token はだいたい幾らか。この段階では課金されません。うなずいてはじめて実際に預けます。以後はバックグラウンドで通常価格の半額の課金で走り、数十分から数時間後、結果は指定した場所にファイルとして落ちていきます。そのあいだ、今の会話は普通に働けます。

```text
/batch-api docs/zh の Markdown ドキュメントを英語に翻訳し、同じファイル名で docs/en に書き出して
```

1 ラウンドで終わり、内容が互いに無関係なまとめ作業に向いています。何往復も議論が必要な仕事は、従来どおり会話で進めてください。

こんなことに使えます：

- ドキュメントディレクトリまるごと英語訳し、一度預けて数時間後に受け取る
- ログやチケットから項目抽出をまとめ、1 回のジョブにして走らせる
- 数百件のユーザーフィードバックを一つずつ分類してタグ付けし、一度預ける

詳しくは PR [#12492](https://github.com/QwenLM/qwen-code/pull/12492)

### Trajectory タブ：1 ラウンドが遅いのか高いのか、時間がどこへ消えたか見える

1 ラウンド走らせて「長い」と感じても、分かるのは長いことだけです。モデルがなかなか応答しなかったのか、出力が多すぎたのか、途中でどのツールが詰まったのかは分かりませんでした。

右側パネルの Trajectory タブは、時間を 3 本に広げます——Model requests、Tool calls、Subagent requests がそれぞれ 1 本です。異常に長い区間は一目で見え、詰め込みすぎた時間帯は区間を広げて見られます。詳しくは PR [#12524](https://github.com/QwenLM/qwen-code/pull/12524)、[#12557](https://github.com/QwenLM/qwen-code/pull/12557)

怪しい区間は軸上で選択すると、その時間帯に起きたことだけが残ります。1 件を選ぶと、何を読み、何を返し、Token をいくらか費やしたかが下に展開され、そのままコピーできます。詳しくは PR [#12543](https://github.com/QwenLM/qwen-code/pull/12543)、[#12971](https://github.com/QwenLM/qwen-code/pull/12971)

軸には Real time という表示もあり、ただ待っていた時間まで数え入れたうえで、「経過時間と実際に走っていた時間」の 2 つの数を示します——1 ラウンドが手元の時間をどれだけ奪ったかはここで確認します。詳しくは PR [#12607](https://github.com/QwenLM/qwen-code/pull/12607)

終わったラウンドは折りたためるので、長い会話を先頭から追い直さなくて済みます。詳しくは PR [#13081](https://github.com/QwenLM/qwen-code/pull/13081)

こんなことに使えます：

- 遅いと感じたら軸を見て決める——モデルを替えるのか、あのツールを調べるのか
- 長い会話で特定の区間に戻りたいとき、選択してそこだけ表示し、終わったラウンドは畳む
- ある操作が誤った疑いが出たら、入出力と消費 Token をその場で確認する

### Channel：1 つのボットを使い分け、個別とグループの許可を分離、長い会話は自動で新しいものへ

**1 つのボットのまま、受け口を使い分けられます。** メッセージの先頭に別のプレフィックスを付けると、通る会話も依頼条件も分かれます。一方ではコードレビューを、もう一方ではリポジトリの質問応答を——2 本は混ざらず、接続をもう 1 本開く必要もありません。グループで @ したあとにプレフィックスを付けても大丈夫です。詳しくは PR [#12595](https://github.com/QwenLM/qwen-code/pull/12595)

**個別で話せる人とグループで使える人を、別々に決められます。** グループは全面開放したまま、個別は許可リストの数人だけに限る——両方は互いに影響しません。詳しくは PR [#12547](https://github.com/QwenLM/qwen-code/pull/12547)、[#12475](https://github.com/QwenLM/qwen-code/pull/12475)

**グループの長い会話は自動で切り替わります。** スレッドが延び続け、最終的に 1 通も出せなくなると、壊れるのはその会話だけです。DingTalk であるスレッドは 8,577 件まで溜まったことがあります。いま上限を設定でき、到達したら新しい会話に自動で切り替わり、グループ内にも一言知らせます。詳しくは PR [#12616](https://github.com/QwenLM/qwen-code/pull/12616)

### Web Shell：サイドバー再配置、長い会話の履歴検索、1 リポジトリの複数作業コピーなど

**サイドバーを作り直しました。** 左に細いナビゲーションが増え、Channel や音声はそれぞれの入口を持ち、バージョン番号と使わない操作は「その他」に収納しました。詳しくは PR [#12943](https://github.com/QwenLM/qwen-code/pull/12943)

**長い会話でも検索できます。** 前に言った 1 文や貼ったコードを探すとき、キーワードで検索すると該当メッセージに飛びます。それより前のメッセージをスクロールで遡る必要はなく、検索すれば見つかります。詳しくは PR [#12234](https://github.com/QwenLM/qwen-code/pull/12234)

**「ついでに一言」が表面に出ました。** メインの作業が動いている最中に小さな質問を挟みたいとき、入力欄の「+」メニューに項目があり、押すと書き上げてくれます。回答は隣のパネルに出るので、メインの作業は邪魔されません。詳しくは PR [#12775](https://github.com/QwenLM/qwen-code/pull/12775)

**1 つのリポジトリで複数の作業コピーを開けます。** 前回のブランチツリーに続けて、Git のダイアログに Worktree タブが増えました。セッションが自分専用のコピーを使い、編集が互いに影響しません。どれがセッションで動き中か、どれに未コミットの変更があるかが一目で見え、押せば切り替わります。詳しくは PR [#12154](https://github.com/QwenLM/qwen-code/pull/12154)、[#11816](https://github.com/QwenLM/qwen-code/pull/11816)

![Web Shell のサイドバー新ナビゲーション、左下の検索入口、入力欄の「+」メニューにある「ついでに一言」](https://img.alicdn.com/imgextra/i4/O1CN01AoFuuHb4MgI7nW9B_!!6000000005620-2-tps-3841-2160.png)

## 📊 その他の新機能

**コミットも任せられます。** `/commit` と打つと、どのファイルを変えたかを見て、リポジトリの履歴の書き方に倣ったコミットメッセージを作り、今回に入れるべきファイルだけ加えます。`.env` のように秘密情報を置いているファイルは直接拒否します。コミットを作るだけで、push は自分の手で。範囲を絞りたいときは後ろに一文足してください。たとえば `/commit only stage the parser changes` のように。詳しくは PR [#10586](https://github.com/QwenLM/qwen-code/pull/10586)

**1 文が何をしたか見られます。** Web Shell で自分が送ったメッセージにマウスを乗せると、コピーボタンの隣にレンチのアイコンが出て、押すと「ツール呼び出し」タブが開きます。そのラウンドで読んだファイル、実行したコマンド、変更した場所が 1 件ずつ並び、展開すると結果と差分が見えます。前のラウンドも照会できます。詳しくは PR [#12466](https://github.com/QwenLM/qwen-code/pull/12466)

**`/advisor` が手動レビューから自発的な相談に変わりました。** オンにすると、作業するモデルが手を動かす前と成果を出す準備の 2 つの場面で、自分でアドバイザーに問いに行きます。意見は会話に戻ってきてから作業を継続します。派遣したサブ Agent も相談できます。1 回の相談ごとに Token を追加で費やし、その会話はアドバイザーのモデルに見せるので、信頼できるものを選んでください。詳しくは PR [#9636](https://github.com/QwenLM/qwen-code/pull/9636)、[#12688](https://github.com/QwenLM/qwen-code/pull/12688)

**新しいモデルの接続で、入力がずいぶん減ります。** コンテキストウィンドウの大きさ、一度に出せる量、画像を受け付けるか——これらを Qwen Code が自分で判断します。モデル一覧を組み込んであり、毎日バックグラウンドで更新し、オフラインでも使えます。自分で入力した値は引き続き優先されます。詳しくは PR [#11959](https://github.com/QwenLM/qwen-code/pull/11959)

**外部メモリへの接続が簡単になりました。** セッションをまたいで覚えてさせたいとき、アドレスとキーを 1 つ渡すだけで、拡張機能のインストールもサービス登録も不要です。検索はデフォルトで使えます。外に書き込むにはスイッチを 1 つ追加でオンにする必要があり、オンにすると何が保存されるか毎回確認できます。詳しくは PR [#12891](https://github.com/QwenLM/qwen-code/pull/12891)

**メモリが増えても全部は広げません。** オンにすると、今の質問に関係する数件だけをコンテキストに拾い、全文が見たくなったら取りに行きます。メモリが数十〜百個のファイルになったとき、節約が大きいです。詳しくは PR [#10183](https://github.com/QwenLM/qwen-code/pull/10183)

**QQ ボットが画像と動画を受け取れるようになりました。** グループで送られた画像や短い動画をそのまま読めるので、文章に書き直す必要はありません。詳しくは PR [#12850](https://github.com/QwenLM/qwen-code/pull/12850)

## 👏 体験改善

**起動してから入力できるまでが倍速になりました。** 何もないパソコンで `qwen` を叩いてから入力できるまでの待ち時間が約 2.5 秒——うち最初の 2 秒はターミナルが真っ白でした。この待ち時間が半分になり、メモリ使用量も 575 MB から約 6 割減りました。詳しくは PR [#12622](https://github.com/QwenLM/qwen-code/pull/12622)、[#12602](https://github.com/QwenLM/qwen-code/pull/12602)、[#12603](https://github.com/QwenLM/qwen-code/pull/12603)

**設定パネルの中国語表記を埋めました。** 表示言語に中国語を選ぶと、画面全体が中国語になります。詳しくは PR [#12783](https://github.com/QwenLM/qwen-code/pull/12783)

**Channel のグループ発言者とセッション管理者をポップアップで変更できます。** 設定ファイルを開いて手で打ち込む必要がなくなりました。詳しくは PR [#12535](https://github.com/QwenLM/qwen-code/pull/12535)

**画面がすっきりしました。** 空のパラメータ行を消し、統計ページの先頭を整え、生のデータは詳細に収納しました。詳しくは PR [#12601](https://github.com/QwenLM/qwen-code/pull/12601)、[#13091](https://github.com/QwenLM/qwen-code/pull/13091)

**スキルの中身を変えたら、リロードで反映されます。** 詳しくは PR [#12182](https://github.com/QwenLM/qwen-code/pull/12182)
