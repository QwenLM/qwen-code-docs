Qwen Code は今週、v0.26.4〜v0.26.7 の 4 つの正式版をリリースしました。

**リモート接続に独立したスイッチが付きました。** 「設定 → 接続」で「リモート接続を許可」をオンにすると、同じネットワーク内の別のパソコンから接続できます。

**GitHub のイベントが会話を自動で進めます。** チャンネルにリポジトリを紐づけておくと、新しいコミット、レビュー、CI の失敗といった動きが、その PR に紐づいた会話へ直接届きます。

**Web Shell の状態もより明確になりました。** チャンネルのイベントをまとめて確認でき、サイドバーではどの会話が動いていて、どれが承認待ちかが一目でわかります。

## ✨ 新機能

### リモート接続：同じネットワーク内の別の端末から作業を続ける

複数の Qwen Code をひとつの画面にまとめるには、これまで接続先の起動時に `--hostname 0.0.0.0` が必要でした。今回から、同じネットワーク内であれば「設定 → 接続」にアドレスと Bearer トークンを入力するだけで、別のパソコンに接続できます。

今週、「設定」→「接続」に「リモート接続を許可」スイッチを追加しました。オンにすると接続アドレスと Bearer トークンが生成され、別のパソコンから入力すれば再起動なしで接続でき、いつでもオフにできます。詳しくは PR [#15887](https://github.com/QwenLM/qwen-code/pull/15887)、[#16199](https://github.com/QwenLM/qwen-code/pull/16199)

こんなことに使えます：

- パソコンを替えて、それまでの会話を続ける
- 席を離れたあとも、リモートでフォローアップに返事したり、承認を処理したり
- 一時的にリモートアクセスを開放し、用が済んだら設定で閉じる




![リモート接続](https://img.alicdn.com/imgextra/i4/O1CN01WL5kej9I8kI4s7XG_!!6000000004481-2-tps-2400-1626.png)

### GitHub リポジトリの動きを、会話へ自動で届ける

チャンネルに GitHub リポジトリを紐づけると、新しいコミット、レビュー、CI の失敗が、その PR に紐づいた会話へ自動で届きます。Qwen Code はそれを受け取って続きを処理します——ビルドが落ちればログを読んで修正する、といった具合です。返信はデフォルトでは非公開で、あなたが確認してから PR に投稿されます。詳しくは PR [#16117](https://github.com/QwenLM/qwen-code/pull/16117)、[#16258](https://github.com/QwenLM/qwen-code/pull/16258)

チャンネルエディターでは、GitHub リポジトリのアクセス権、@ メンションの挙動、通知の頻度を直接設定できます。設定ファイルを手で書く必要はありません。イベント内の PR 番号や Issue 番号は自動でクリック可能なリンクになります。詳しくは PR [#16149](https://github.com/QwenLM/qwen-code/pull/16149)、[#16096](https://github.com/QwenLM/qwen-code/pull/16096)、[#16226](https://github.com/QwenLM/qwen-code/pull/16226)

こんなことに使えます：

- PR の CI が落ちたら、失敗ログがそのまま会話に入る——自分で探しに行かなくていい
- 同僚が PR をレビューしたら、そのコメントがチャット画面に現れる
- 新しいリポジトリを追跡したければ、エディターに URL を入れるだけ

### Web Shell：チャンネルの動きとセッションの状態を画面で把握

**チャンネルのイベントをまとめて確認できるようになりました。** チャンネルでは日々さまざまなことが起きています——GitHub のコミット、定期ジョブの完了、会話からの返信。チャンネルページに「イベント」欄が増え、すべてのアクティビティが時系列で並び、チャンネルごとに絞り込め、タイムラインは自動更新されます。詳しくは PR [#16106](https://github.com/QwenLM/qwen-code/pull/16106)

**トークン使用量パネルがリクエスト単位で見られます。** これまでは種類ごとの合計だけでしたが、リクエスト 1 件ずつに分解——出力速度、初回応答までの時間、成功か失敗か、モデルごとに異なる色で表示されます。クリックすれば失敗の具体的な理由も確認できます。詳しくは PR [#16108](https://github.com/QwenLM/qwen-code/pull/16108)、[#16111](https://github.com/QwenLM/qwen-code/pull/16111)

**サイドバーの会話に状態マークが付きました。** これまでのサイドバーは会話の名前が並ぶだけで、中で何が起きているかわかりませんでした。各会話の横に状態表示が付き、実行中はスピナー、承認待ちはオレンジの表示、エラーは赤いライン——マークを開けば、誰が待っているか、どのプロンプトに答え終わったかがわかります。未読メッセージ数も表示され、ワンクリックで全件既読やアーカイブもできます。詳しくは PR [#16022](https://github.com/QwenLM/qwen-code/pull/16022)

**会話を左右に並べて表示。** 会話の右クリックメニューに「分割表示に追加」が増え、2 つの会話を左右に並べて見比べられます。詳しくは PR [#15956](https://github.com/QwenLM/qwen-code/pull/15956)

**その他の改善。** Workflow モードのスイッチは入力欄横の「+」メニューに収まり、オンにするとタブが現れてクリックでオフにできます（[#16107](https://github.com/QwenLM/qwen-code/pull/16107)、[#15779](https://github.com/QwenLM/qwen-code/pull/15779)）。画像の URL を入力欄にコピーすると自動で添付ファイルになり、スクリーンショットの貼り付けにも対応します（[#16179](https://github.com/QwenLM/qwen-code/pull/16179)）。

## 📊 その他の新機能

**インタラクティブカードがデフォルトで有効に。** これまでは設定でオンにする必要がありましたが、インストール直後から使えます——ローン計算やプラン比較も、会話の中でスライダーを動かして

結果を見られます。パラメータを調整して「保持」を押せば、その値を会話に戻して続けて質問できます。詳しくは PR [#15856](https://github.com/QwenLM/qwen-code/pull/15856)

**ダウンロードしたプロジェクトは、信頼してから hooks が動きます。** 見知らぬプロジェクトに含まれる hooks、権限ルール、言語サーバーは、確認ダイアログであなたが「信頼」を押してから有効になります。自分のパソコンで新規作成したローカルプロジェクトは影響を受けません。詳しくは PR [#16182](https://github.com/QwenLM/qwen-code/pull/16182)、[#16196](https://github.com/QwenLM/qwen-code/pull/16196)

**/verify-pr が Docker 内で信頼できないコードを実行。** コマンド 1 つでローカルにコンテナを起動し、PR のコードを中に入れて検証——モデルの API キーはあなたのマシンに残り、コンテナには渡りません。詳しくは PR [#16077](https://github.com/QwenLM/qwen-code/pull/16077)

**デスクトップ版が Fedora 44 と RHEL 10 に対応。** これらのシステムをお使いなら、GitHub Releases から rpm パッケージを直接ダウンロードしてインストールできます。詳しくは PR [#16060](https://github.com/QwenLM/qwen-code/pull/16060)

**QQ グループの管理操作も AI に任せられます。** チャンネルが自分の管理ツールを内部の会話に公開——メッセージの取り消し、メンバーのキック、参加申請の承認といった操作を、AI が代行できます。どのツールを使えるかは、チャンネル設定の `moderationTools` で制御します。詳しくは PR [#14348](https://github.com/QwenLM/qwen-code/pull/14348)

**Managed Agent を Helm コマンド 1 本でデプロイ。** Helm chart を設定すれば、MySQL もゲートウェイも自動で付いてきます。詳しくは PR [#15492](https://github.com/QwenLM/qwen-code/pull/15492)

**アーカイブした会話を設定から直接復元。** 「設定 → アーカイブ」を開くと、各アイテムの横に「復元」と「エクスポート」ボタンが表示されます。その会話を開かなくても操作できます。詳しくは PR [#15872](https://github.com/QwenLM/qwen-code/pull/15872)

**スキル入力中に残りのパラメータ候補が表示されます。** `/qwencode-weekly` まで打つと、続けて入力すべきパラメータが常に浮かんで表示され、ひとつ埋めると次の候補に縮みます。詳しくは PR [#15930](https://github.com/QwenLM/qwen-code/pull/15930)

**アップグレードコマンドでバージョン指定が可能に。** `qwen update --target-version <バージョン番号>` を実行すると、指定したバージョンを直接インストールします。npm registry に新版があるか確認する手間が省け、ダウングレードや同じバージョンの再インストールもできます。詳しくは PR [#11486](https://github.com/QwenLM/qwen-code/pull/11486)

## 👏 体験改善

**/autofix-pr がより安定：main から遅れていれば自動マージ、現在のチェックアウト内で修正、担当ラウンド数を明示。** ブランチが main に遅れて CI が落ちているときは、まず main を取り込んでからチェックを走らせるため、手動 rebase が不要です。`--in-place` を付けるとあなたの現在のチェックアウト内で作業し、隣で一緒に修正を進められます。PR に `@qwen-code /takeover for N` と書けば担当ラウンド数を指定でき、修復が終われば自動で手放します。詳しくは PR [#15922](https://github.com/QwenLM/qwen-code/pull/15922)、[#15929](https://github.com/QwenLM/qwen-code/pull/15929)、[#15388](https://github.com/QwenLM/qwen-code/pull/15388)

**長い回答をスクロールで読めます。** `/btw` の回答が長くなったとき、スクロールバー付きの固定領域に表示——マウスホイール、キーボードの上下キー、PageUp/PageDown で移動できます。詳しくは PR [#15982](https://github.com/QwenLM/qwen-code/pull/15982)

**DeepSeek V4、qwen4、latest-series 系のモデルでも思考の深さを設定できるようになりました。** これら世代のモデルには選択できる思考深度がなく、Alibaba のプロキシ経由の DeepSeek V4.1 Flash には既定値もありませんでした。現在はモデルごとに各段階が用意され、思考をオフにするのは従来のスイッチのままです。詳しくは PR [#15987](https://github.com/QwenLM/qwen-code/pull/15987)、[#15828](https://github.com/QwenLM/qwen-code/pull/15828)

**Web Shell のワンクリック更新が pnpm、yarn、bun に対応。** これまでは npm のみでしたが、これらのパッケージマネージャーでもワンクリック更新が可能に。未対応が検出された場合は手動の手順を表示します。詳しくは PR [#15849](https://github.com/QwenLM/qwen-code/pull/15849)

**ステータスバーでバックグラウンド Agent の実行数がわかります。** デスクトップ版と Web Shell の下部にあるタスク表示に、実行中の Agent 数がリアルタイムで表示されます。詳しくは PR [#14002](https://github.com/QwenLM/qwen-code/pull/14002)

**コードジャンプの失敗時に理由を明示。** 利用可能な言語サーバーがないとき、これまでは空の結果が返るだけでしたが、現在は「利用可能な言語サーバーがありません」と伝えます。詳しくは PR [#15946](https://github.com/QwenLM/qwen-code/pull/15946)

**コンテキストメモリファイルをパネル内でプレビュー。** AGENTS.md などのファイルをクリックすると内容を確認できます。詳しくは PR [#15932](https://github.com/QwenLM/qwen-code/pull/15932)

**ワークスペースのない会話一覧が空のとき、その欄全体を非表示に。** これまでは空欄が場所を取っていましたが、ピン留めと同じ扱いで、空なら欄ごと表示しません。詳しくは PR [#15916](https://github.com/QwenLM/qwen-code/pull/15916)
