## Qwen Code のインストール

Qwen Code はスクリプトによるワンクリックインストールに対応し、Windows、macOS、Linux を網羅しています。

**macOS / Linux：**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows（PowerShell）：**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

インストール完了後、`qwen --version` を実行してインストール成功を確認します。npm でインストールすることも可能です：

```bash
npm i @qwen-code/qwen-code@latest -g
```

## モデルプロバイダーの設定

インストール完了後、Qwen Code がモデルプロバイダーへの接続をガイドします。Alibaba Cloud Bailian プラットフォームの使用を推奨します。

1. [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key)で API Key を取得
2. ターミナルで `qwen` を起動し、Alibaba ModelStudio を選択
3. API Key を貼り付け、モデルを選択

手動設定を希望する場合は、`~/.qwen/settings.json` を編集します：

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "あなたのAPI-KEY"
  }
}
```

設定完了後、`/model` コマンドでモデルの確認と切り替えができます：

## 最初の対話を始める

プロジェクトディレクトリに移動し、Qwen Code を起動します：

```bash
cd your-project && qwen
```

自然言語でやりたいことをそのまま記述します。例えば：

```
Python でフィボナッチ数列を計算する関数を書いて
```

または AI にファイル整理を頼むこともできます：

```
このフォルダ内のファイルをタイプ別に分類して別のフォルダに整理して
```

Qwen Code がタスクを自動的に分解、操作を実行、結果を返します。やり方を一歩ずつ教える必要はなく、ゴールを記述すれば OK です。

## Skills 拡張のインストール

Skills は Qwen Code の機能拡張システムです。コミュニティが開発した Skill を必要に応じてインストールし、AI にさらに多くの専門能力を持たせることができます。

Skill のインストールは簡単で、一言で完了します：

```
find-skills をインストールして
```

または直接コマンドを使います：

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

インストール完了後は `/skills` でインストール済みの Skills を確認できます。
