プログラミング開発はコードを書くだけではありません。何をするかを明確にすることから、コード品質の確保まで、各ステップに時間がかかります。以下の 3 つのシナリオで、Qwen Code が全工程に参加します — 要件の整理、コードレビュー、テストケースの補充をサポートします。

## 曖昧な要件からインタラクティブなプロトタイプへ

頭の中にアイデアはあるけれど、詳細までは固まっていない？ Qwen Code にやりたいことを伝えれば、すぐにコードを書き始めるのではなく、プロダクトマネージャーのように相談してくれます — コア機能は何か、インタラクション方式はどうするか、技術的実現方法など。あなたと AI の両方が要件に満足したら、ツール全体を開発します。一文から動くプロトタイプまで、自分で一行もコードを書く必要はありません。

### 操作手順

1. **要件のブラッシュアップ** — アイデアを Qwen Code に伝えます。曖昧な一文だけでも構いません。AI が詳細を補完するための一連の質問を投げかけます — コア機能、インタラクション方式、技術的実現など — 最終的に完全な要件ドキュメントを生成します。
2. **要件案の確認** — AI が要件案を生成した後、項目ごとに確認できます。変更や追加があれば修正します。問題がなければ次のステップに進みます。
3. **開発へ移行** — 要件案が確定したら、そのまま Qwen Code に開発を開始させます。要件ドキュメントに沿ってツール全体を順番に構築します。全工程が自動的に完了します。

<Callout>
    **ヒント**：要件段階が具体的であるほど、開発段階での手戻りが減ります。急いで AI にコードを書かせず、まず要件を話し合いましょう。
</Callout>

## 9 つの AI レビューアーが同時にコードを確認

コードを書き終えて提出前に `/review` を実行すると、9 つのレビュー Agent が同時に作業を開始し、セキュリティ、パフォーマンス、コード品質の観点から並行スキャンし、問題を発見したら直接修正します。同僚が PR を提出したら、一条コマンドでレビューし、意見が自動的に GitHub のコード行に書き込まれます。人間の review と同じように。

### 操作手順

1. **プロジェクトコードレビュー** — `/review` を実行してプロジェクトコードをレビュー。9 つの Agent が並行スキャンし、ハードコードされたシークレットキーや SQL インジェクションなどのセキュリティ・パフォーマンス問題を自動検出します。
2. **ワンクリックで問題を修正** — 自動修復を選択すると、Qwen Code が直接コードを修正し、linter を実行して検証し、修復が新たな問題を持ち込まないことを確認します。
3. **PR レビューとコメント** — `/review <PR number> --comment` を実行してリモート PR をレビュー。GitHub に切り替えてインライン注釈を確認。レビュー意見が直接コード行に書き込まれます。

```bash
/review <PR number> --comment
```

## プロジェクトにユニットテストを追加

Qwen Code にプロジェクトルールを読み込ませ、正常シナリオ、境界シナリオ、異常入力をカバーするユニットテストを自動生成し、実行・検証、問題修正、テストカバレッジの補充を行います。

### 操作手順

1. **プロジェクトとテスト目標の理解** — Qwen Code がプロジェクトファイルを通読し、ビジネスルール、コア関数、テスト目標を理解し、優先的にカバーすべきテストシナリオを計画します。
2. **テスト生成と実行検証** — ビジネスルールに基づき、コア関数のユニットテストを生成し、正常シナリオ、境界シナリオ、異常入力をカバーします。例えばクーポンの閾値、送料無料の境界値、空のカート、無効な入力など。テストを自動実行します。
3. **問題修正とテスト通過** — テスト失敗結果から問題の原因を判断します。ソースコードの実装とビジネスルールが一致しない場合、Qwen Code がコードを修正し、テストを再実行して、テストが通過するまで繰り返します。
4. **テストカバレッジの補充** — テストカバレッジレポートを確認し、未カバーのファイルとブランチを分析し、価値のあるテストケースを継続的に補充し、重要なロジックのテストカバレッジを向上させます。

<Callout type="error">
    **注意**：AI が生成したテストケースは、ビジネスロジックが正しいかあなたが確認する必要があります。AI はテストの作成を助けますが、何が正しいかを判断するのはあなたの役割です。
</Callout>
