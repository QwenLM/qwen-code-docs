## Qwen Code installieren

Qwen Code unterstützt die Ein-Klick-Installation per Skript und deckt Windows, macOS und Linux ab.

**macOS / Linux:**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows (PowerShell):**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

Führen Sie nach der Installation `qwen --version` aus, um die erfolgreiche Installation zu bestätigen. Wenn Sie lieber mit npm installieren, geht das auch:

```bash
npm i @qwen-code/qwen-code@latest -g
```

## Modellanbieter konfigurieren

Nach der Installation führt Sie Qwen Code durch die Verbindung mit einem Modellanbieter. Empfohlen wird die Alibaba Cloud Bailian-Plattform.

1. Gehen Sie zu [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key), um Ihren API Key zu erhalten
2. Starten Sie im Terminal mit `qwen`, wählen Sie Alibaba ModelStudio
3. Fügen Sie Ihren API Key ein und wählen Sie das Modell

Wenn Sie lieber manuell konfigurieren, bearbeiten Sie `~/.qwen/settings.json`:

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "Ihr-API-KEY"
  }
}
```

Verwenden Sie nach der Konfiguration den Befehl `/model`, um Modelle anzuzeigen und zu wechseln:

## Erste Konversation starten

Wechseln Sie in Ihr Projektverzeichnis und starten Sie Qwen Code:

```bash
cd your-project && qwen
```

Beschreiben Sie in natürlicher Sprache, was Sie tun möchten. Zum Beispiel:

```
Schreibe mir eine Python-Funktion, die die Fibonacci-Folge berechnet
```

Oder lassen Sie AI beim Organisieren von Dateien helfen:

```
Sortiere die Dateien in diesem Ordner nach Typ in verschiedene Unterordner
```

Qwen Code zerlegt die Aufgabe automatisch, führt Operationen aus und liefert Ergebnisse. Sie müssen nicht Schritt für Schritt anleiten – beschreiben Sie einfach das Ziel.

## Skills-Erweiterungen installieren

Skills ist das Erweiterungssystem von Qwen Code. Sie können nach Bedarf von der Community entwickelte Skills installieren, um der AI zusätzliche Fachkompetenzen zu verleihen.

Ein Skill zu installieren ist ganz einfach – ein Satz reicht:

```
Installiere find-skills
```

Oder direkt mit dem Befehl:

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

Verwenden Sie nach der Installation `/skills`, um die installierten Skills anzuzeigen.

## VS Code Integration

Wenn Sie lieber im Editor arbeiten, bietet Qwen Code eine VS Code Erweiterung. Suchen Sie im Extension Marketplace nach „Qwen Code" und installieren Sie sie. Nach der Installation können Sie direkt in der Seitenleiste mit der AI chatten und ein nahtloses Programmiererlebnis genießen.
