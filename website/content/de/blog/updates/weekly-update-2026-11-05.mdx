Qwen Code liefert diese Woche vier Stable-Releases aus — v0.26.4 bis v0.26.7.

**Die Remote-Verbindung hat jetzt einen eigenen Schalter, kein Neustart mehr nötig.** Geh in **Settings → Connections**, schalte **Allow remote connections** ein — schon erreichst du Qwen Code von einem anderen Rechner im selben Netzwerk.

**GitHub-Events schieben deine Session automatisch weiter.** Bindest du ein Repository an einen Channel, kommen neue Commits, Reviews und fehlgeschlagene CI-Läufe direkt in die Session, die an den PR gebunden ist.

**Der Session-Status im Web Shell ist jetzt auf einen Blick sichtbar.** Channel-Events laufen zentral zusammen, und in der Sidebar siehst du sofort, welche Session gerade arbeitet und welche auf dich wartet.

## ✨ Neue Features

### Remote-Verbindung: Am anderen Rechner weitermachen, ohne Neustart

Früher musstest du Qwen Code mit `--hostname 0.0.0.0` starten, um von einem anderen Gerät darauf zuzugreifen. Jetzt reicht ein Schalter: In **Settings → Connections** schaltest du **Allow remote connections** ein. Qwen Code zeigt dir eine Verbindungsadresse und ein Bearer-Token an — beides gibst du auf dem anderen Rechner ein, und die Verbindung steht. Schaltest du den Schalter wieder aus, ist der Zugang sofort dicht. Kein Neustart. Siehe PR [#15887](https://github.com/QwenLM/qwen-code/pull/15887), [#16199](https://github.com/QwenLM/qwen-code/pull/16199)

Was du damit machen kannst:

- Arbeitsrechner verlassen und vom Laptop aus dieselbe Session weiternutzen
- Unterwegs eine Rückfrage beantworten oder eine Freigabe erteilen
- Remote-Zugang für einen Abend aufmachen und danach in den Settings wieder schließen




![Remote-Verbindungen](https://img.alicdn.com/imgextra/i4/O1CN01WL5kej9I8kI4s7XG_!!6000000004481-2-tps-2400-1626.png)

### GitHub-Events: Dein Repository meldet sich selbst in der Session

Bindest du ein GitHub-Repository an einen Channel, laufen neue Commits, Reviews und fehlgeschlagene CI-Jobs automatisch in die Session ein, die mit dem PR verknüpft ist. Qwen Code reagiert darauf: Build rot? Er liest das Log und repariert. Die Antwort bleibt erstmal privat — erst wenn du sie freigibst, erscheint sie im PR. Siehe PR [#16117](https://github.com/QwenLM/qwen-code/pull/16117), [#16258](https://github.com/QwenLM/qwen-code/pull/16258)

Im Channel-Editor richtest du Zugriffsrechte, @-Verhalten und Benachrichtigungsfrequenz für das Repository direkt ein — kein Griff mehr in die Konfigurationsdatei. PR- und Issue-Nummern in Events werden automatisch zu klickbaren Links. Siehe PR [#16149](https://github.com/QwenLM/qwen-code/pull/16149), [#16096](https://github.com/QwenLM/qwen-code/pull/16096), [#16226](https://github.com/QwenLM/qwen-code/pull/16226)

Was du damit machen kannst:

- CI deines PRs schlägt fehl — das Fehlerlog erscheint in der Session, du musst nicht selbst danach suchen
- Ein Kollege reviewed deinen PR — seine Anmerkungen landen im Chat
- Neues Repository zum Verfolgen? Adresse in den Channel-Editor eintippen, fertig

### Web Shell: Channel-Events und Session-Status auf einen Blick

**Channel-Events laufen zentral zusammen.** In einem Channel passiert ständig etwas: GitHub hat einen Commit, ein geplanter Job ist durch, eine Session hat geantwortet. Jetzt hat jede Channel-Seite eine „Events“-Spalte — alle Aktivitäten als Zeitstrahl, filterbar nach Channel, mit automatischer Aktualisierung. Siehe PR [#16106](https://github.com/QwenLM/qwen-code/pull/16106)

**Token-Nutzung bis auf die einzelne Anfrage aufgeschlüsselt.** Bisher stand da nur eine Summe pro Kategorie. Jetzt siehst du jede Anfrage einzeln: Ausgabegeschwindigkeit, Wartezeit bis zur ersten Antwort, Erfolg oder Fehler — verschiedene Modelle in verschiedenen Farben. Ein Klick auf einen Eintrag zeigt die genaue Fehlerursache. Siehe PR [#16108](https://github.com/QwenLM/qwen-code/pull/16108), [#16111](https://github.com/QwenLM/qwen-code/pull/16111)

**Session-Status in der Sidebar.** Früher war die Session-Liste nur eine Namensliste — was drin passiert, hast du nicht gesehen. Jetzt trägt jede Session ein Statussymbol: ein drehender Kreis, wenn sie läuft, ein oranger Punkt, wenn sie auf deine Freigabe wartet, ein roter Strich bei einem Fehler. Klickst du das Symbol an, siehst du, wer wartet und welche Antwort gerade fertig wurde. Ungelesene Nachrichten zählt ein Badge mit, und du markierst alle auf einmal als gelesen oder archivierst sie. Siehe PR [#16022](https://github.com/QwenLM/qwen-code/pull/16022)

**Sessions nebeneinander.** Rechtsklick auf eine Session, „Add to split view“ — schon liegen zwei Gespräche Seite an Seite zum Vergleichen. Siehe PR [#15956](https://github.com/QwenLM/qwen-code/pull/15956)

**Weitere Verbesserungen.** Der Workflow-Modus-Schalter ist ins „+“-Menü neben dem Eingabefeld gewandert; ein Label zeigt den aktiven Modus, du klickst es zum Ausschalten ([#16107](https://github.com/QwenLM/qwen-code/pull/16107), [#15779](https://github.com/QwenLM/qwen-code/pull/15779)). Kopierst du eine Bild-URL ins Eingabefeld, wird sie automatisch zum Anhang; Screenshots fügst du direkt per Paste ein ([#16179](https://github.com/QwenLM/qwen-code/pull/16179)).

## 📊 Weitere neue Features

**Interaktive Karten sind ab sofort Standard.** Bisher musstest du sie erst in den Settings aktivieren. Jetzt sind sie direkt nach der Installation da — lass dir einen Kredit ausrechnen, vergleiche Optionen und zieh im Gespräch die Regler. Stehen die Werte, klickst du „Keep“ und sie fließen zurück in die Unterhaltung. Siehe PR [#15856](https://github.com/QwenLM/qwen-code/pull/15856)

**Heruntergeladene Projekte fragen vor Hooks, Permission-Regeln und Language-Servern.** Kommt ein Projekt aus dem Netz, zeigt Qwen Code einen Bestätigungsdialog. Erst nach deinem Klick auf „Trust“ laufen die mitgebrachten Hooks, Permission-Regeln und Language-Server. Lokal von dir angelegte Projekte sind davon nicht betroffen. Siehe PR [#16182](https://github.com/QwenLM/qwen-code/pull/16182), [#16196](https://github.com/QwenLM/qwen-code/pull/16196)

**`/verify-pr` führt nicht vertrauenswürdigen Code im Docker-Container aus.** Ein Befehl, ein lokaler Container, der PR-Code rein, die Prüfung läuft — deine Modell-Keys bleiben auf deinem Rechner. Siehe PR [#16077](https://github.com/QwenLM/qwen-code/pull/16077)

**Desktop-App jetzt für Fedora 44 und RHEL 10.** Auf diesen Systemen lädst du das rpm-Paket direkt von GitHub Releases. Siehe PR [#16060](https://github.com/QwenLM/qwen-code/pull/16060)

**QQ-Gruppen-Moderation übernimmt die KI.** Ein Channel stellt seine Moderationswerkzeuge den darin laufenden Sessions zur Verfügung: Nachrichten zurückziehen, Mitglieder entfernen, Beitrittsanfragen bearbeiten — die KI führt es aus. Welche Werkzeuge freigegeben sind, steuerst du mit `moderationTools` in den Channel-Settings. Siehe PR [#14348](https://github.com/QwenLM/qwen-code/pull/14348)

**Managed Agent von Null auf laufend mit einem Helm-Befehl.** Helm-Chart konfigurieren, MySQL und Gateway sind an Bord. Siehe PR [#15492](https://github.com/QwenLM/qwen-code/pull/15492)

**Archivierte Gespräche stellst du direkt aus den Settings wieder her.** Unter Settings → Archive hat jeder Eintrag jetzt einen „Restore“- und einen „Export“-Button — du musst nicht mehr erst zum Gespräch navigieren. Siehe PR [#15872](https://github.com/QwenLM/qwen-code/pull/15872)

**Skill-Parameter siehst du beim Tippen.** Tippst du `/qwencode-weekly`, schwebt die Liste der noch fehlenden Parameter über der Eingabe. Ist einer gefüllt, rückt der nächste nach. Siehe PR [#15930](https://github.com/QwenLM/qwen-code/pull/15930)

**Update-Befehl mit Zielversion.** `qwen update --target-version <Versionsnummer>` installiert direkt die angegebene Version — ohne vorher die npm-Registry abzufragen. Downgrade oder Neuinstallation derselben Version geht auch. Siehe PR [#11486](https://github.com/QwenLM/qwen-code/pull/11486)

## 👏 Verbesserte Erfahrungen

**`/autofix-pr` hält deinen Branch aktuell und arbeitet direkt in deinem Checkout.** Hängt dein Branch hinter `main` und die CI schlägt fehl, merged er selbstständig `main` ein, bevor er die Checks erneut anstößt — kein manuelles Rebase. Mit `--in-place` läuft er in deinem aktuellen Checkout, du schaust zu und greifst ein. Im PR steuerst du mit `@qwen-code /takeover for N`, wie viele Runden er übernimmt; danach gibt er automatisch wieder ab. Siehe PR [#15922](https://github.com/QwenLM/qwen-code/pull/15922), [#15929](https://github.com/QwenLM/qwen-code/pull/15929), [#15388](https://github.com/QwenLM/qwen-code/pull/15388)

**Lange Antworten bekommst du in einem scrollbaren Fenster.** Wenn `/btw` ausführlich antwortet, erscheint der Text in einem Feld mit Scrollbalken — Mausrad, Pfeiltasten und PageUp/PageDown funktionieren. Siehe PR [#15982](https://github.com/QwenLM/qwen-code/pull/15982)

**Auch DeepSeek V4, qwen4 und die latest-series-Modelle lassen sich jetzt in der Denktiefe einstellen.** Diese Generationen hatten bisher keine wählbare Denktiefe, und DeepSeek V4.1 Flash über den Alibaba-Proxy hatte auch keinen Standardwert; jetzt ist jede Stufe pro Modell gesetzt, und zum Ausschalten des Denkens dient weiterhin der vorhandene Schalter. Siehe PR [#15987](https://github.com/QwenLM/qwen-code/pull/15987), [#15828](https://github.com/QwenLM/qwen-code/pull/15828)

**Web Shell: Ein-Klick-Update jetzt für pnpm, yarn und bun.** Bisher nur npm. Jetzt aktualisierst du mit jedem dieser Paketmanager per Knopfdruck. Erkennt er einen nicht unterstützten, zeigt er die manuellen Schritte an. Siehe PR [#15849](https://github.com/QwenLM/qwen-code/pull/15849)

**Die Statusleiste zeigt die Zahl der laufenden Hintergrund-Agents.** Im Desktop-Client und im Web Shell siehst du am Task-Symbol in der Fußzeile in Echtzeit, wie viele Agents gerade arbeiten. Siehe PR [#14002](https://github.com/QwenLM/qwen-code/pull/14002)

**Code-Navigation sagt, wenn kein Language-Server da ist.** Bisher kam bei fehlendem Language-Server einfach ein leeres Ergebnis. Jetzt meldet Qwen Code: Kein Language-Server verfügbar. Siehe PR [#15946](https://github.com/QwenLM/qwen-code/pull/15946)

**Kontextdateien im Panel anklicken und lesen.** Dateien wie AGENTS.md öffnest du direkt aus dem Panel — ein Klick, und der Inhalt erscheint. Siehe PR [#15932](https://github.com/QwenLM/qwen-code/pull/15932)

**Leere Session-Listen ohne Workspace verschwinden komplett.** Eine leere Spalte nahm bisher Platz weg, ohne etwas zu zeigen. Jetzt blendet sie sich aus, solange sie leer ist. Siehe PR [#15916](https://github.com/QwenLM/qwen-code/pull/15916)
