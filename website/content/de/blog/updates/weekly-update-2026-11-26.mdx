Qwen Code liefert diese Woche drei Stable-Releases aus — v0.28.3, v0.28.4 und v0.28.6.

**Aufgaben an eine andere Session übergeben.** Mit `/send` in der Web Shell gibst du Arbeit an eine andere Session weiter. Die Session erledigt die Aufgabe und berichtet dir das Ergebnis.

**Ergebnisse geplanter Aufgaben an eine Wunschadresse senden.** Lege in der Channel-Verwaltung einen Generic Webhook mit Empfängeradresse an — nach jeder geplanten Aufgabe geht das Ergebnis automatisch dorthin.

**Erzeugte Dateien gesammelt ansehen.** Berichte und Exporte aller Sessions landen auf der Artifacts-Seite. Du siehst sie dir direkt an oder lädst sie herunter, ohne jede Session einzeln zu öffnen.

## ✨ Neue Features

### Aufgaben mit /send an eine andere Session übergeben

Du übergibst Aufgaben jetzt selbst an eine andere Session. Tippst du in der Web Shell `/send prüfe den fehlgeschlagenen Test`, öffnet sich im selben Workspace eine neue Session und übernimmt die Aufgabe. Mit `--workspace` wählst du einen Workspace, mit `--session-id` eine bestehende Session. Ist die Aufgabe fertig, berichtet dir die aktuelle Session das Ergebnis.

Auch die KI übergibt Aufgaben über diesen Weg — sie gibt Arbeit jetzt auch an Sessions weiter, die du selbst geöffnet hast. Im YOLO-Modus übergibt sie Aufgaben in andere Projektordner ohne Bestätigungsdialog.

Was du damit machen kannst:

- In Session A recherchieren und Session B den Plan weiterschreiben lassen
- In der Haupt-Session Code schreiben und die Test-Fehlersuche an eine zweite Session abgeben
- Im rechten Panel den Fortschritt verfolgen und Freigabe-Anfragen und Fragen der anderen Session direkt beantworten

Siehe PR [#17539](https://github.com/QwenLM/qwen-code/pull/17539), [#17818](https://github.com/QwenLM/qwen-code/pull/17818)

### Channels: Ergebnisse geplanter Aufgaben an eine Wunschadresse senden, laufende Aufgaben korrigieren

**Ergebnisse geplanter Aufgaben gehen an eine Wunschadresse.** Neben Feishu-, WeCom- und DingTalk-Gruppen gibt es jetzt einen Generic Webhook für beliebige Plattformen: Du trägst in der Channel-Verwaltung eine HTTPS-Empfängeradresse ein, und Benachrichtigungen sowie Ergebnisse geplanter Aufgaben gehen automatisch dorthin. Siehe PR [#17405](https://github.com/QwenLM/qwen-code/pull/17405)

**Mitten in der Aufgabe die Richtung ändern.** Channels, die du eigenständig im Terminal startest, nutzen den Zustellmodus `inject`: Nachrichten, die während der Arbeit ankommen, gehen direkt in die laufende Runde. Die KI liest sie sofort und passt ihren Kurs an — ein Satz von dir genügt, wenn eine Aufgabe falsch läuft. Siehe PR [#15634](https://github.com/QwenLM/qwen-code/pull/15634)

**Der QQ-Bot schickt Dateien in den Chat.** Setzt du in den QQ-Channel-Settings `fileTools` auf `true` (standardmäßig aus) und startest den Channel neu, sendet die KI erzeugte Dateien, Bilder, Videos und Sprachnachrichten aus dem Workspace direkt in den Chat. Siehe PR [#15450](https://github.com/QwenLM/qwen-code/pull/15450)

Was du damit machen kannst:

- Geplante Aufgabe fertig — das Ergebnis landet automatisch in deinem eigenen System
- Läuft eine Aufgabe schief, korrigierst du sie mit einem Satz in der Gruppe — die KI ändert sofort die Richtung
- Aufgaben direkt in QQ stellen und erzeugte Dateien im selben Chat zurückerhalten

### Web Shell: Artifacts bündeln, Eingabe-Historie geräteübergreifend teilen

**Session-Ergebnisse bündelst du auf einer Seite.** Die lokale Web Shell bekommt eine Artifacts-Seite: Berichte, Exporte und Web-Vorschau-Snapshots aller Sessions im Workspace landen dort gesammelt. Du siehst sie dir direkt an oder lädst sie herunter. Siehe PR [#18071](https://github.com/QwenLM/qwen-code/pull/18071), [#17689](https://github.com/QwenLM/qwen-code/pull/17689)

**Eingabe-Historie auf allen Geräten.** Prompts und Befehle, die du am Computer tippst, findest du am Handy in der Eingabe-Historie desselben Workspaces — und umgekehrt. Siehe PR [#18120](https://github.com/QwenLM/qwen-code/pull/18120)

**Die Sidebar zeigt den Status jeder Session.** Sessions mit einem Goal tragen ein Goal-Zeichen in den Farben der Goals-Seite: blau, wenn sie laufen, bernsteinfarben, wenn sie auf dich warten. Sessions mit einer unterbrochenen letzten Runde zeigen ein Continue-Badge. Nach einem Neustart siehst du auf einen Blick, welche Sessions weiterlaufen müssen. Siehe PR [#17515](https://github.com/QwenLM/qwen-code/pull/17515), [#18044](https://github.com/QwenLM/qwen-code/pull/18044)

**Folgefragen-Vorschläge auf dem Handy antippen.** Die Vorschläge stehen als antippbare Buttons über dem Eingabefeld. Ein Tipp übernimmt den Text ins Eingabefeld — du passt ihn an und sendest ihn ab. Siehe PR [#17918](https://github.com/QwenLM/qwen-code/pull/17918)

**Weitere Verbesserungen.** Buttons in den Karten von Generated UI kopieren Text direkt oder laden kleine Dateien herunter ([#18158](https://github.com/QwenLM/qwen-code/pull/18158)); die Touch-Bearbeitungsleiste bleibt auf Handy und iPad einzeilig ([#18126](https://github.com/QwenLM/qwen-code/pull/18126)).

## 📊 Weitere neue Features

**Traditionelles Chinesisch als Oberfläche.** Web Shell und VS Code Companion unterstützen jetzt auch Traditionelles Chinesisch: Wähle in der Sprachauswahl `繁體中文 [zh-TW]`. Siehe PR [#17421](https://github.com/QwenLM/qwen-code/pull/17421)

**Englische Antworten auf Chinesisch anzeigen.** Aktivierst du in den Settings `general.displayLanguage` und wählst Vereinfachtes Chinesisch, zeigen Terminal und Web Shell englische Modellantworten und aufgeklapptes Denken auf Chinesisch. Archiv, Kopieren und weitere Gespräche behalten den Originaltext. Standardmäßig ist die Funktion aus; du schaltest sie im Terminal über `/settings` oder in den Settings der Web Shell ein. Siehe PR [#18175](https://github.com/QwenLM/qwen-code/pull/18175)

**Microsoft Teams als Channel-Erweiterung.** Installierst du die Erweiterung `@qwen-code/channel-msteams` und richtest einen Azure-Bot ein, gibst du dem Bot in Microsoft Teams per @ Aufgaben — in Privatchats und in Gruppen. Gespräche zu verschiedenen Themen stören einander nicht. Siehe PR [#15620](https://github.com/QwenLM/qwen-code/pull/15620)

**Screen-Reader-Modus für die CLI.** Das Terminal bekommt einen experimentellen Screen-Reader-Modus: Mit `--screen-reader` beim Start liest Qwen Code jede fertige Antwort einmal vor. Die Historie blätterst du per Tastatur durch; die aktuelle Auswahl und ausstehende Freigaben liest der Modus vor. Die grafische Standardoberfläche bleibt unverändert. Siehe PR [#17500](https://github.com/QwenLM/qwen-code/pull/17500)

## 👏 Verbesserte Erfahrungen

**Die Web Shell öffnet schneller.** Das Terminal lädt erst bei Bedarf, große Session-Aufzeichnungen überträgt Qwen Code komprimiert. Gemessen schrumpft die Zeit vom Klick auf eine alte Session bis zum sichtbaren Inhalt von rund 1,3 auf 0,8 Sekunden. Siehe PR [#17840](https://github.com/QwenLM/qwen-code/pull/17840), [#11220](https://github.com/QwenLM/qwen-code/pull/11220), [#18223](https://github.com/QwenLM/qwen-code/pull/18223)

**Hintergrund-Badges erklären sich auf Klick.** Jedes Badge über dem Eingabefeld trägt jetzt ein Fragezeichen. Klickst du es an, erklärt die KI in einfachen Worten, was die Aufgabe tut und warum sie läuft. Die Antwort erscheint im Frage-Panel daneben — Gespräch und Aufgabe laufen ungestört weiter. Siehe PR [#17398](https://github.com/QwenLM/qwen-code/pull/17398)

**Deine Nachricht bekommt sofort Antwort, der Befehl läuft weiter.** Führt die KI gerade einen Befehl aus und du schickst eine Nachricht, wandert der Befehl in den Hintergrund und läuft dort weiter. Deine Nachricht beantwortet die KI sofort. Siehe PR [#17926](https://github.com/QwenLM/qwen-code/pull/17926)

**MCP-Änderungen wirken sofort.** Fügt du in den Settings MCP-Server hinzu oder entfernst sie, gelten sie sofort in laufenden Sessions — ohne Neustart. Siehe PR [#17743](https://github.com/QwenLM/qwen-code/pull/17743)

**Folgefragen-Vorschläge kommen schneller.** Für die Vorschläge schaut sich die KI nur einen kurzen Abschnitt des Gesprächs an. Siehe PR [#17532](https://github.com/QwenLM/qwen-code/pull/17532)

**Mods schreiben auch in der Web Shell um.** Antworten und aufgeklappte Thinking-Blöcke zeigt die Web Shell so, wie das Mod-Plugin sie umgeschrieben hat. Historie, Kopieren, Suche und Branches nutzen weiter den Originaltext. Du schaltest dafür `experimental.mods` ein. Siehe PR [#17718](https://github.com/QwenLM/qwen-code/pull/17718), [#17920](https://github.com/QwenLM/qwen-code/pull/17920)

**Workflow-Phasen von Anfang an im Blick.** Der Workflow listet alle Phasen gleich beim Start: Noch nicht erreichte sind markiert, erreichte zeigen ihren tatsächlichen Fortschritt. Du siehst sofort, wo der ganze Workflow steht. Workflows aktivierst du zuerst mit der Umgebungsvariable `QWEN_CODE_ENABLE_WORKFLOWS=1`. Siehe PR [#17782](https://github.com/QwenLM/qwen-code/pull/17782)

**Denktiefe-Stufen für Gemini 4 und Kimi K3 automatisch.** Bindest du diese beiden Modelle an, stehen ihre Denktiefe-Stufen sofort bereit. Siehe PR [#18039](https://github.com/QwenLM/qwen-code/pull/18039), [#18095](https://github.com/QwenLM/qwen-code/pull/18095)

**Ersatzmodelle übernehmen ohne Wartezeit.** Ist `experimental.modelAvailabilityTracking` an, überspringt Qwen Code ein Modell, das in dieser Runde gerade an Kapazitätsmangel gescheitert ist, und nimmt direkt das nächste Ersatzmodell. Die nächste Runde probiert das übersprungene Modell erneut. Standardmäßig ist die Einstellung aus. Siehe PR [#17377](https://github.com/QwenLM/qwen-code/pull/17377)
