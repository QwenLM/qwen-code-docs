Qwen Code liefert diese Woche fünf Stable-Releases aus — v0.26.8 bis v0.27.2.

**Dein Qwen-Abo gilt jetzt auch in Qwen Code.** Logge dich mit deinem Plus/Pro-Abo in CLI, VS Code und Desktop ein und nutze die Modelle aus dem Abo direkt zum Chatten und für die Websuche.

**WeChat, QQ und E-Mail richtest du jetzt im Web Shell ein.** Bei WeChat und QQ scannst du den QR-Code direkt auf der Seite, bei E-Mail trägst du Serveradresse und Zugangsdaten ein.

**Der GitHub-Channel filtert Events pro Repository.** Die Whitelist nimmt nur die gelisteten Repositories, die Blacklist alle außer den gelisteten.

## ✨ Neue Features

### Login mit Qwen-Abo: die Modelle aus dem Abo direkt nutzen

Hast du ein Plus- oder Pro-Abo für dein Qwen-Konto, loggst du dich damit im Terminal, in VS Code oder im Desktop ein. Führe im Terminal `/auth` aus, wähle das Qwen-Mitgliedskonto und schließe die Autorisierung im Browser ab. Danach lädt der Client die Modelle aus deinem Abo, und die eingebaute Websuche steht bereit.

Was du damit machen kannst:

- Die Modelle aus deinem Abo arbeiten direkt für dich — die Nutzung läuft über das Abo
- Dasselbe Konto in Terminal, VS Code und Desktop: überall dieselben Modelle
- Kein API-Key nötig: Qwen abonnieren und direkt in Qwen Code loslegen

Siehe PR [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Konto und Modellliste nach dem Login mit dem Qwen-Abo](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### Web Shell: WeChat, QQ und E-Mail als Channel einrichten

Die Channel-Verwaltung im Web Shell kennt drei neue Plattformen: WeChat, QQ und E-Mail. Bei WeChat und QQ zeigt die Seite einen QR-Code — du scannst ihn mit dem Handy und bist eingeloggt. Bei E-Mail trägst du Serveradresse und Zugangsdaten ein. Damit richtest du alle großen Chat-Plattformen außer Telegram direkt im Web Shell ein.

Was du damit machen kannst:

- Scanne den QR-Code im Web Shell mit dem Handy und binde deinen privaten WeChat-Chat oder QQ an
- Lege in der Channel-Verwaltung einen Email Channel an oder bearbeite ihn und lege fest, welche Absender per Mail eine Session starten dürfen
- Channel-Pairings hebst du im Web Shell mit einem Klick wieder auf

Siehe PR [#16736](https://github.com/QwenLM/qwen-code/pull/16736), [#16724](https://github.com/QwenLM/qwen-code/pull/16724), [#16746](https://github.com/QwenLM/qwen-code/pull/16746)

![Die QR-Code-Login-Seite des WeChat-Channels im Web Shell](https://img.alicdn.com/imgextra/i1/O1CN01ldag0pIAw9J4s7XG_!!6000000004740-2-tps-2400-1626.png)

### GitHub-Channel: Events nach Repository filtern

Der GitHub-Channel schickt Repository-Events automatisch in die Session: Jemand öffnet einen PR, hinterlässt einen Kommentar, die CI ist durch — der Agent arbeitet alles ab. Du wählst den Umfang: Die Whitelist nimmt nur die gelisteten Repositories, die Blacklist alle außer den gelisteten. Ausgeschlossene Events überspringt Qwen Code komplett: Sie landen in keiner Session und verbrauchen keine Verarbeitung.

Was du damit machen kannst:

- Hunderte Repositories in der Organisation? Liste nur deine zwei auf und bekomme ausschließlich deren Events
- Repos, die du gerade nicht verfolgst, kommen auf die Blacklist — beim Übernehmen holst du sie zurück
- PRs fremder Repos bleiben außen vor, deine wichtigen Repos bekommen den Agent sofort

Siehe PR [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

![Repository-Filtereinstellungen im Channel-Editor](https://img.alicdn.com/imgextra/i4/O1CN01NAru06FwyBE7o1Mj_!!6000000003227-2-tps-3845-2160.png)

### Web Shell: Fragen-Heatmap, Nutzungsleiste und Sessions gesammelt aufräumen

**Heatmap für Fragen und Antworten.** Ein neuer Heatmap-Button zeigt die Fragen und Antworten mehrtägiger Läufe als Kalender. Die Farbintensität entspricht der Anzahl pro Tag, ein Klick auf einen Tag springt zur ersten Frage dieses Tages. Siehe PR [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**Nutzungsleiste unter dem Eingabefeld.** Unter dem Eingabefeld steht jetzt eine Zeile mit Zahlen: Runden, Ausgabegeschwindigkeit, Token gesamt, Cache-Trefferrate. Siehe PR [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**Sessions gesammelt anpinnen und archivieren.** Die Sidebar hat einen Mehrfachauswahl-Schalter: Sessions anhaken und mit einem Klick anpinnen oder archivieren. Siehe PR [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**Unklare Optionen erklärst du dir per Knopfdruck.** Stellt die KI eine Auswahlfrage, öffnet ein neuer Button im Frage-Panel eine Nebenaufgabe: Sie erklärt dir jede Option — Bedeutung, Unterschiede, Auswirkungen und Empfehlung. Siehe PR [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**Weitere Verbesserungen.** Workspaces klappst du mit einem Klick komplett ein oder aus und sortierst sie per Drag am Titel ([#16197](https://github.com/QwenLM/qwen-code/pull/16197)). Wartet eine Hintergrundaufgabe auf deine Freigabe, melden sich Desktop-Benachrichtigung oder ein akustisches Signal im Terminal — auch dann, wenn du gerade in einem anderen Fenster arbeitest ([#16800](https://github.com/QwenLM/qwen-code/pull/16800)). Tool-Cards wie MCP-Aufrufe zeigen beim Aufklappen direkt Parameter und vollständiges Ergebnis ([#15435](https://github.com/QwenLM/qwen-code/pull/15435)). Auf der Skill-Seite lädst du Skills direkt als ZIP-Archiv hoch ([#16424](https://github.com/QwenLM/qwen-code/pull/16424)).

![Mehrfachauswahl in der Sidebar der Web Shell und Nutzungsleiste unter dem Eingabefeld](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 Weitere neue Features

**Geplante Aufgaben wählen ihren Ziel-Channel.** Legst du im Web Shell eine geplante Aufgabe an, bestimmst du, in welchen Channel das Ergebnis geht. Siehe PR [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**QQ-Gruppen bekommen proaktive Nachrichten.** Ergebnisse aus geplanten Aufgaben, Webhooks und Hintergrundaufgaben gehen jetzt als aktive Gruppennachricht in die QQ-Gruppe. Der optionale Schalter `forwardBotMessages` leitet zusätzlich die Nachrichten anderer Bots aus der Gruppe an die Session weiter. Siehe PR [#15635](https://github.com/QwenLM/qwen-code/pull/15635), [#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**Hook für Dateiänderungen.** Lokale Sessions haben einen neuen `FileChanged`-Hook: Er feuert, wenn eine beobachtete Datei oder ein beobachtetes Verzeichnis angelegt, geändert oder gelöscht wird — auch Änderungen durch andere Programme meldet er. Siehe PR [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Drei neue Fähigkeiten für Mods.** `$.store` speichert Plugin-Daten über Sessions hinweg. `ui.render` schreibt den Antworttext um, den das Terminal anzeigt — gespeicherter und kopierter Text bleiben unverändert. `$.model.complete` führt eine einmalige Textvervollständigung aus. Siehe PR [#16791](https://github.com/QwenLM/qwen-code/pull/16791), [#16794](https://github.com/QwenLM/qwen-code/pull/16794), [#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**Neue PR-Kommentare landen automatisch in der gebundenen Session.** Ist eine Session an einen PR gebunden, kommen neue Kommentare direkt dort an — normale Kommentare und Inline-Review-Kommentare, ganz ohne @. Siehe PR [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 Verbesserte Erfahrungen

**`/btw`: Nachfragen und mehrere Nebenfragen parallel.** Eine neue Nebenfrage nimmt bereits beantwortete Nebenfragen mit, du knüpfst direkt an die letzte Antwort an. Mehrere Fragen laufen parallel, jede bekommt ihre eigene Antwort. Siehe PR [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**Die KI kennt deine Shell von Anfang an.** Am Session-Anfang steht, welche Shell die Befehle ausführt (bash, cmd.exe usw.). Die KI richtet die Syntax nach der Shell statt nach dem Betriebssystem — auf Windows schreibt sie passende Befehle. Siehe PR [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**Automatische Session-Titel sprechen die Sprache des Gesprächs.** Ein chinesischer Dialog bekommt einen chinesischen Titel, jede Sprache bleibt unter sich. Siehe PR [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Goal-Begründungen folgen der Session-Sprache.** Die Gründe für Annahme oder Ablehnung erscheinen in der Ausgabesprache der Session. Siehe PR [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**Thai, Laotisch, Khmer und Burmesisch: Folgefragen bleiben in der Sprache.** Chattest du in einer dieser Sprachen, generiert Qwen Code die Folgefragen-Vorschläge in derselben Sprache. Siehe PR [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**Experimentelle Code-Intelligenz (LSP) per Settings einschalten.** Setze `tools.lspEnabled` in den User-Settings auf true — ganz ohne CLI-Flag. Auch Clients ohne Parameter-Übergabe wie der Desktop nutzen damit Sprung zur Definition, Referenzsuche und Diagnosen. Standardmäßig bleibt LSP aus. Siehe PR [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**Subagents: Vordergrund oder Hintergrund global festlegen.** Setze `agents.defaultBackground` auf false, und Subagents liefern ihr Ergebnis direkt in der aktuellen Runde — ideal für Channels und Bots, die das Ergebnis in einem Zug brauchen. Wirksam nach einem Neustart. Siehe PR [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**Managed-Sessions halten mehrere Fragen gleichzeitig.** Mehrere Fragen einer Managed-Session bestehen nebeneinander, du beantwortest sie in beliebiger Reihenfolge. Siehe PR [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**Channel-Events führen per Klick in die Session.** Ein Klick auf einen Eintrag im Channel-Event-Zeitstrahl springt direkt in die zugehörige Session. Siehe PR [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
