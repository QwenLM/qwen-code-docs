Qwen Code hat diese Woche zwei Stable-Releases ausgeliefert — v0.25.3 und v0.26.0 — mit 436 gemergten PRs.

**Das Ergebnis liegt auf einer interaktiven Karte, die du selbst verstellst.** Willst du verschiedene Zahlen durchspielen und sehen, was sich ändert, stellst du die Werte direkt auf der Karte um — der Gesamtwert rechnet sofort mit.

**Workflows aus dem Repository funktionieren auch im Unterordner.** Zerlegt sich dein Projekt in Frontend, Backend und mehrere Komponentenordner, findest und startest du die gespeicherten Abläufe wie Code-Check und Testlauf auch dann, wenn du Qwen Code tief im Unterordner öffnest.

**Eine Befehlsgruppe `qwen daemon` für die Web Shell.** Starten, Status ansehen, Logs lesen, stoppen und neu laufen lassen steckt jetzt in dieser einen Gruppe.

## ✨ Neue Features

### Interaktive Karten: Werte verstellen, vergleichen, die passende Lösung finden

Manche Fragen beantwortest du nicht in einem Satz — du willst Zahlen ändern und schauen, was dann rauskommt. Dafür baut Qwen Code jetzt eine interaktive Karte: Stell Zahlen oder Verhältnisse um, das zugehörige Ergebnis erscheint sofort. Siehe PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

Zum Beispiel ein Team-Essen: Lass dir eine Kostenkarte bauen und trag Personenzahl, Preis pro Person und Raummiete ein. Kommen Leute dazu, änderst du die Zahl; wechselst du das Restaurant, änderst du den Preis. Die Gesamtkosten rechnen mit, ohne dass du jedes Mal eine Nachricht losschicken musst, damit neu gerechnet wird.

Das ist experimentell und standardmäßig aus: Stell in den experimentellen Einstellungen Generated UI an, dann wirkt es nach einem Neustart. In Managed-Agent-, Remote- und Sandbox-Sessions läuft die eingebaute Version noch nicht. Siehe PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

Was du damit machen kannst:

- Wohnungsangebote gegeneinander abwägen — Miete, Pendelzeit und Fahrtkosten zusammen
- Leute und Aufgaben im Projekt verschieben und sehen, was das an Zeit und Kosten macht
- Server-Konfigurationen vergleichen und Kapazität und Kosten für verschiedene Zugriffszahlen einschätzen

### Workflows: auch im Unterordner dieselben gespeicherten Abläufe

Ein Projekt zerlegt sich oft in Frontend, Backend und mehrere Komponentenordner. Hast du im Projekt-Root Abläufe wie Code-Check oder Testlauf gespeichert, findest und startest du sie jetzt auch, wenn du Qwen Code in einem Unterordner darunter öffnest.

Du arbeitest im Frontend-Ordner an einer Seite und willst den gespeicherten Check ablaufen lassen — in der Workflow-Liste deiner aktuellen Session steht er direkt bereit. Dafür sucht diese Version von der aktuellen Stelle aufwärts durch alle vertrauenswürdigen Ordner desselben Git-Repository. Das gilt für Sessions im lokalen Terminal genauso wie für normale Web-Shell-Sessions. Siehe PR [#14369](https://github.com/QwenLM/qwen-code/pull/14369), [#14646](https://github.com/QwenLM/qwen-code/pull/14646)

Was du damit machen kannst:

- In jedem Komponentenordner denselben einheitlichen Code-Check des Projekts benutzen
- Nach einer Änderung im Backend den gespeicherten Testlauf starten
- Für Projektdokumentation den Dokumenten-Check aus dem übergeordneten Ordner nehmen

### qwen daemon: die Web Shell mit einer Befehlsgruppe verwalten

Letzte Woche konnte die Web Shell mehrere Qwen Code auf einer Seite verbinden. Diese Woche kommt dazu, wie diese lokalen Dienste verwaltet werden.

Starten, Status ansehen, neu starten — alles steckt in `qwen daemon`. Etwa:

`qwen daemon start` bringt den Dienst im Hintergrund hoch und gibt dir die Adresse zurück. Mit `qwen daemon status` siehst du, was läuft, mit `qwen daemon logs` die Logs, mit `qwen daemon stop` hältst du einen bestimmten Dienst an. Siehe PR [#14739](https://github.com/QwenLM/qwen-code/pull/14739), [#14869](https://github.com/QwenLM/qwen-code/pull/14869)

Für die Fehlersuche zeigt `qwen daemon status --detail` zusätzlich Version, Laufzeit, Session-Zahl und Anzahl der Probleme. Startest du den Dienst in einem Skript und willst dich sofort verbinden, nimm `qwen daemon start --wait` — es wartet, bis die Laufzeitumgebung bereit ist. Siehe PR [#14902](https://github.com/QwenLM/qwen-code/pull/14902), [#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <Port>` startet den ausgewählten lokalen HTTP-Dienst neu und stellt dabei den Workspace und die Web-Shell-Einstellungen wieder her, die beim Start aufgezeichnet wurden. Siehe PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

Was du damit machen kannst:

- Den lokalen Dienst starten und im selben Terminal weiterarbeiten
- Den Status mehrerer lokaler Dienste vergleichen und den finden, der dich gerade braucht
- Einen bestimmten Dienst so neu starten, wie er das erste Mal gelaufen ist

![qwen daemon start stellt den Dienst im Terminal in den Hintergrund, in einem zweiten Terminal siehst du den Status](https://img.alicdn.com/imgextra/i4/O1CN015EshdwuaPaE7nW9B_!!6000000003381-2-tps-3841-2160.png)

### Web Shell: Dateien und Ausführungsschritte in der Oberfläche klarer sehen

**PDF und Word öffnest du direkt in der Oberfläche.** Ob über eine `@`-Referenz, das rechte `Files`-Panel oder eine Artefakt-Karte: PDFs öffnet der eingebaute Viewer des Browsers, Word-Dateien gehen an denselben drei Stellen. Siehe PR [#14825](https://github.com/QwenLM/qwen-code/pull/14825), [#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**Rechts im Panel legst du Dateien an und löschst sie.** Ein Klick auf den Ordnernamen neben dem Chat-Titel öffnet den Dateibaum des Workspace. Dort entstehen neue Dateien und neue Ordner. Für eine Datei kommt erst eine Bestätigung, für einen Ordner zwei — in ihm verschwindet alles mit. Siehe PR [#14344](https://github.com/QwenLM/qwen-code/pull/14344), [#14169](https://github.com/QwenLM/qwen-code/pull/14169), [#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**Der Trajectory-Tab hält an.** Blätterst du zu älteren Einträgen zurück, pausiert er von selbst, und das Bild bleibt bei den Zeilen stehen, die du gerade liest. Willst du wieder beim neuesten Stand sein, klickst du auf „Zum Neuesten springen“. Ein Klick auf eine beliebige Zeile der Liste zeigt deren Details. Siehe PR [#14723](https://github.com/QwenLM/qwen-code/pull/14723), [#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**Weitere Verbesserungen.** Im Gespräch wählst du eine Nachricht samt Antwort aus und löscht beides — oder nur einzelne Stellen ([#14297](https://github.com/QwenLM/qwen-code/pull/14297)); was gerade läuft und was fertig ist, samt Dauer jedes Schritts, sitzt jetzt in einem einklappbaren Bereich „Letzte Ausführungen“ ([#14071](https://github.com/QwenLM/qwen-code/pull/14071)); im Panel „Session-Token-Verbrauch“ bleiben oben Eingabe, Ausgabe und Cache stehen, darunter siehst du getrennt, was einzelne Modelle, der Haupt-Agent und die Sub-Agents verbrauchen; fährt die Maus über das Info-Icon neben einem Modellnamen, siehst du, wie lange das Modell bis zum ersten Token braucht und wie viele pro Sekunde herauskommen ([#14728](https://github.com/QwenLM/qwen-code/pull/14728), [#14648](https://github.com/QwenLM/qwen-code/pull/14648)).

![Projektdateien im rechten Panel der Web Shell öffnen und im Trajectory-Tab sehen, wie lange jeder Schritt gedauert hat](https://img.alicdn.com/imgextra/i4/O1CN011HVsNLd8EyF7nW9B_!!6000000005070-2-tps-3841-2160.png)

## 📊 Weitere neue Features

**Der Einstieg QwenCloud steht jetzt auf dem ersten Schirm von `/auth`.** Schlüssel für Nutzungsabrechnung und für den Token Plan wählt man getrennt, einen Schritt später kommt die Wahl zwischen China und International. Siehe PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**Wer seine Managed-Agent-Dienste selbst betreibt, verwaltet Projekte und Aufgaben bequemer.** Diese Sessions stehen jetzt auf der Web-Shell-Startseite neben den Sessions auf deinem eigenen Rechner — mit demselben Eingabefeld und denselben Freigabe-Karten. Dazu kommt: einen vorhandenen Projektordner direkt auswählen, beim Anlegen einer Session die aktivierten Skills mitnehmen, die Ausführungsrechte während des Laufs ändern und den Session-Namen von Hand setzen. Auch normale Managed-Agent-Sessions können denselben Projektordner gleichzeitig nutzen; die Dateien sind dann zwischen ihnen geteilt. Dafür muss das jeweilige Deployment diese Funktionen unterstützen. Siehe PR [#14316](https://github.com/QwenLM/qwen-code/pull/14316), [#14970](https://github.com/QwenLM/qwen-code/pull/14970), [#14930](https://github.com/QwenLM/qwen-code/pull/14930), [#14920](https://github.com/QwenLM/qwen-code/pull/14920), [#14987](https://github.com/QwenLM/qwen-code/pull/14987), [#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**Der QQ-Bot nimmt Dateien an.** Im Einzelchat oder per @ in einer Gruppe: Schickst du Word, PDF oder eine Tabelle, legt er sie ab, liest sie und antwortet darauf. Siehe PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**WeCom mit eigenen Apps funktioniert.** Ein Kollege schreibt in einer selbst gebauten App des Unternehmens einen Satz als Auftrag, Qwen Code übernimmt die Arbeit und antwortet im Namen genau dieser App. Siehe PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Commands aus Plugins im Claude-Format laufen jetzt auch im Terminal.** Letzte Woche galten sie nur im Einmal-Aufruf, jetzt rufst du sie direkt im Terminal auf — ohne Anfrage ans Modell. Auch die Ebene, die eingreift, bevor das Modell ein Werkzeug benutzt, ist in interaktiven Sessions offen: Sie darf diesen einen Aufruf umschreiben oder aufhalten. Das ist standardmäßig aus; in den Einstellungen gibt es den Mods-Schalter, nach einer Änderung brauchst du einen Neustart. Siehe PR [#14268](https://github.com/QwenLM/qwen-code/pull/14268), [#14565](https://github.com/QwenLM/qwen-code/pull/14565), [#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**Bei Befehlen im Hintergrund siehst du jetzt, wie weit ihre Ausgabe ist.** In den Task-Details stehen die letzten Zeilen, wie groß die Ausgabe ist und wann sie zuletzt geschrieben hat, dazu Speicherbedarf, Start und Ende — den Inhalt kopierst du mit einem Klick. Siehe PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 Verbesserte Erfahrungen

**Eingeklappte Inhalte auf der Startseite zeigen beim Überfahren eine Vorschau.** Siehe PR [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**Sortieren, Filtern und Kopieren in Tabellen sitzt besser.** Die erweiterten Bedienelemente für breite Tabellen und der Weg zum Kopieren sind in dieser Runde zusammen nachgeschärft. Siehe PR [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**Wiederholt Qwen Code dieselbe Sache, kommt zuerst ein Hinweis — die Runde läuft weiter.** Hat ein Befehl oder ein Datei-Lesen sich oft genug wiederholt, bekommt das Modell jetzt standardmäßig den Auftrag, es anders zu versuchen. Wer lieber automatisch abbrechen will, stellt das in den Einstellungen ein. Siehe PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**Auf dem Handy fallen zwei Pfeiltasten über dem Eingabefeld weg.** Die beiden Tasten für die Eingabe-Historie sind verschwunden; die Historien-Suche bleibt an ihrem Platz. Siehe PR [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**Das Favicon bleibt auch auf dunklen Tabs lesbar.** War es auf dunklem Tab-Hintergrund fast untergegangen, hebt es sich jetzt ab. Siehe PR [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**Die Modellliste aktualisiert der Modellauswahl-Button selbst.** Ein Klick darauf holt eine frische Liste; das Aktualisieren zeigt ein kleines Icon neben der Suche. Siehe PR [#14685](https://github.com/QwenLM/qwen-code/pull/14685), [#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**`Ctrl+V` fügt auf Linux Text ein.** Steht Text oder ein Link in der Zwischenablage, geht er direkt ins Eingabefeld; Bilder bleiben Anhänge. Siehe PR [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
