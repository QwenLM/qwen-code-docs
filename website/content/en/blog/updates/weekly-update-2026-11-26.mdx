Qwen Code shipped three stable releases this week — v0.28.3, v0.28.4, and v0.28.6.

**Hand a task to another session.** In Web Shell, `/send` passes the job to another session. It picks up the work and reports back when it finishes.

**Push scheduled-task results to an address you choose.** Add a Generic Webhook in channel management and fill in a receiving URL. When a scheduled task finishes, its result posts there automatically.

**See generated files in one place.** Reports and exports from every session gather on the Artifacts page. Preview or download them directly, without opening sessions one by one.

## ✨ New Features

### Hand a Task to Another Session with /send

You can hand a task to another session yourself. Type `/send check the test that just failed` in Web Shell, and a new session in the same workspace picks it up. Use `--workspace` to choose a workspace, or `--session-id` to target an existing session. When the task finishes, your current session relays the result.

The AI delegates the same way, including to sessions you opened by hand. With YOLO mode on, delegating to another project folder skips the confirmation prompt.

What you can do:

- Finish research in session A and send it to session B to draft the plan
- Keep coding in your main session while another session tracks down the test failure
- Watch progress in the right-side panel and handle the other session's confirmations and questions right there

See PR [#17539](https://github.com/QwenLM/qwen-code/pull/17539), [#17818](https://github.com/QwenLM/qwen-code/pull/17818)

### Channels: Push Scheduled-Task Results to an Address You Choose, Correct Course Mid-Task

**Scheduled-task results go to an address you choose.** Feishu, WeCom, and DingTalk groups already receive results. The new Generic Webhook works with any platform: enter an HTTPS receiving URL in channel management, and notifications and scheduled-task results post there. See PR [#17405](https://github.com/QwenLM/qwen-code/pull/17405)

**Channel messages can steer a task mid-run.** Channels started standalone from the terminal support the inject delivery mode. A message that arrives while the AI is working goes straight into the current turn. The AI reads it mid-task and adjusts course — one follow-up message fixes a task that has drifted. See PR [#15634](https://github.com/QwenLM/qwen-code/pull/15634)

**QQ bots send files into the chat.** Set `fileTools` to `true` in the QQ channel settings (off by default) and restart the channel. The AI then sends files, images, videos, and voice clips generated in the workspace straight into the chat. See PR [#15450](https://github.com/QwenLM/qwen-code/pull/15450)

What you can do:

- Scheduled tasks finish and post their results to your own systems automatically
- Drop one message in the group when a task drifts, and the AI changes course on the spot
- Assign work right in QQ and get the generated files back in the same chat

### Web Shell: Browse Session Artifacts on One Page, Share Input History Across Devices

**Browse and download session artifacts on one page.** The locally deployed Web Shell gains an Artifacts page. Reports, exports, and web-preview snapshots from every session in the workspace gather there for preview or download. See PR [#18071](https://github.com/QwenLM/qwen-code/pull/18071), [#17689](https://github.com/QwenLM/qwen-code/pull/17689)

**Input history follows you across devices.** Prompts and commands you typed on your computer show up in the input history when you open the same workspace on your phone — and the other way around. See PR [#18120](https://github.com/QwenLM/qwen-code/pull/18120)

**The sidebar shows each session's state.** Sessions with a goal carry a goal marker in the same colors as the Goals page: blue while running, amber when waiting on you. Sessions whose last turn was interrupted show a Continue badge, so after a restart you can see at a glance which ones to resume. See PR [#17515](https://github.com/QwenLM/qwen-code/pull/17515), [#18044](https://github.com/QwenLM/qwen-code/pull/18044)

**Follow-up suggestions are tappable on mobile.** Suggestions appear above the input box as tappable prompts. Tap one to fill the input box, edit it, and send. See PR [#17918](https://github.com/QwenLM/qwen-code/pull/17918)

**Other improvements.** Buttons in Generated UI cards copy text or download small files directly ([#18158](https://github.com/QwenLM/qwen-code/pull/18158)); the touch editing bar stays on one line on phones and iPad ([#18126](https://github.com/QwenLM/qwen-code/pull/18126)).

## 📊 More New Features

**Traditional Chinese interface.** Web Shell and the VS Code Companion interface add Traditional Chinese. Pick "繁體中文 [zh-TW]" in the language selector. See PR [#17421](https://github.com/QwenLM/qwen-code/pull/17421)

**Display translation.** Turn on `general.displayLanguage` in settings and pick Simplified Chinese. Replies the model writes in English and expanded thinking then display in Chinese in the terminal and Web Shell. Archives, copies, and follow-up conversation stay in the original language. Off by default; enable it in the terminal's `/settings` or the Web Shell settings page. See PR [#18175](https://github.com/QwenLM/qwen-code/pull/18175)

**Microsoft Teams channel extension.** Install the `@qwen-code/channel-msteams` extension separately and set up an Azure bot. Then @-mention the bot in Teams private chats and groups to assign work. Conversations in different topics stay independent. See PR [#15620](https://github.com/QwenLM/qwen-code/pull/15620)

**CLI screen-reader mode.** The terminal gains a screen-reader mode (experimental). Start with `--screen-reader`: each reply is read aloud once when it finishes, history is browsed with the keyboard, and the current selection and pending approvals are spoken. The default graphical interface stays unchanged. See PR [#17500](https://github.com/QwenLM/qwen-code/pull/17500)

## 👏 Experience Improvements

**Web Shell opens faster.** The terminal loads only when you use it, and large session transcripts are compressed before transfer. Opening a history session to seeing its content drops from about 1.3 seconds to 0.8 seconds in our measurements. See PR [#17840](https://github.com/QwenLM/qwen-code/pull/17840), [#11220](https://github.com/QwenLM/qwen-code/pull/11220), [#18223](https://github.com/QwenLM/qwen-code/pull/18223)

**Ask a background-task badge what it's doing.** Each badge above the input box gains a question mark. Click it and the AI explains in plain language what the task is doing and why it started. The answer shows in the Q&A panel beside it, while the conversation and the task keep running. See PR [#17398](https://github.com/QwenLM/qwen-code/pull/17398)

**Queued messages keep commands running.** Send a message while the AI runs a command. The command moves to the background and keeps running, and your message gets a response right away. See PR [#17926](https://github.com/QwenLM/qwen-code/pull/17926)

**MCP config changes apply instantly.** Add or remove MCP servers in settings, and running sessions pick up the change automatically, without a restart. See PR [#17743](https://github.com/QwenLM/qwen-code/pull/17743)

**Follow-up suggestions arrive faster.** Suggestion generation reads only a short slice of the conversation. See PR [#17532](https://github.com/QwenLM/qwen-code/pull/17532)

**Mods rewriting reaches Web Shell.** Web Shell shows replies and expanded thinking as Mods plugins rewrite them. History, copy, search, and branches keep the original text. Requires `experimental.mods`. See PR [#17718](https://github.com/QwenLM/qwen-code/pull/17718), [#17920](https://github.com/QwenLM/qwen-code/pull/17920)

**Workflows list every phase up front.** A workflow shows all the phases it will go through from the start. Phases not yet reached are marked; the active phase shows real progress, so you can see where the workflow stands at a glance. Enable workflows first with the environment variable `QWEN_CODE_ENABLE_WORKFLOWS=1`. See PR [#17782](https://github.com/QwenLM/qwen-code/pull/17782)

**Gemini 4 and Kimi K3 thinking tiers adapt automatically.** Connect either model and its thinking-depth tiers become available automatically. See PR [#18039](https://github.com/QwenLM/qwen-code/pull/18039), [#18095](https://github.com/QwenLM/qwen-code/pull/18095)

**Fallback models switch faster.** With `experimental.modelAvailabilityTracking` on, a model that just failed this turn from insufficient capacity is skipped. The next fallback model runs instead, and the failed one is retried next turn. The setting is off by default. See PR [#17377](https://github.com/QwenLM/qwen-code/pull/17377)
