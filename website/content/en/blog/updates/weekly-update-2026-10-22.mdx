Qwen Code shipped two stable releases this week — v0.25.3 and v0.26.0 — with 436 PRs merged.

**The answer comes back as a card you can keep editing.** Trying a few numbers to see what changes? Type new values straight into the card and the total recalculates.

**A workflow saved at the project root runs from any subdirectory.** A project split into front end, back end, and component directories still hands you the code checks and test runs you saved up top, even when you start Qwen Code deeper down.

**One `qwen daemon` command group runs Web Shell.** Start it, check status, read logs, stop it, restart it — all in one place.

## ✨ New Features

### Interactive Cards: Adjust the Numbers, Compare the Results Side by Side

Some questions only come out right after you try a few variations. Qwen Code now builds an interactive card for exactly that: adjust a number or a ratio, and the matching result shows up immediately. See PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

Planning a team dinner, for instance — ask for a cost card, then fill in headcount, price per person, and the venue fee. More people, change the headcount. Different restaurant, change the per-person price. The total recalculates every time, instead of you sending a message and waiting for a fresh answer.

This is off by default. To use it, turn on Generated UI in the experimental settings and restart. The built-in version doesn't cover managed, remote, or sandbox sessions yet. See PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

What you can do:

- Compare apartment options across rent, commute time, and transit cost
- Move people between tasks and get the schedule and cost back
- Weigh server configs and see the capacity and cost at different traffic levels

### Workflows: Saved at the Root, Usable from Any Subdirectory

A project is often split into a front end, a back end, and several component directories. Save code checks or test runs at the project root, and Qwen Code now finds and runs them when you start a session in a directory below.

Say you're changing a page in the front-end directory and want to run the project's saved check — it's already in the current session's workflow list. The update searches upward from the directory you're in, through trusted directories inside the same Git repository. That covers local terminal sessions and ordinary Web Shell sessions. See PRs [#14369](https://github.com/QwenLM/qwen-code/pull/14369), [#14646](https://github.com/QwenLM/qwen-code/pull/14646)

What you can do:

- Run the project's one code check from each component directory
- Change back-end code, then run the test workflow the repo already holds
- Use the doc check saved a level up while you write project docs

### qwen daemon: Web Shell Managed by One Command Group

Last week Web Shell learned to connect to several Qwen Code instances in one page. This week adds managing the local services behind them.

Starting Web Shell, checking status, and restarting all sit under `qwen daemon`.

Run `qwen daemon start` and the service comes up in the background with its address returned. `qwen daemon status` lists what's running, `qwen daemon logs` shows the logs, and `qwen daemon stop` shuts a named service down. See PRs [#14739](https://github.com/QwenLM/qwen-code/pull/14739), [#14869](https://github.com/QwenLM/qwen-code/pull/14869)

Troubleshooting? `qwen daemon status --detail` adds the version, uptime, session count, and issue count. Starting a service from a script and connecting right away? `qwen daemon start --wait` holds until the runtime is ready before your script moves on. See PRs [#14902](https://github.com/QwenLM/qwen-code/pull/14902), [#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <port>` restarts one local HTTP service and restores the workspace and Web Shell settings recorded when it started. See PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

What you can do:

- Start the local service, then keep working in the same terminal
- Check several local services at once and find the one that needs you
- Restart one service the way it was originally started

### Web Shell: Files and Run History, Easier to See

**PDF and Word files open inside the interface.** Reach them from an `@` reference, the Files panel on the right, or an artifact card. PDFs use the reader your browser already has; Word files preview from those same entry points. See PRs [#14825](https://github.com/QwenLM/qwen-code/pull/14825), [#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**The file tree creates and deletes.** Click the directory name beside the chat title and the workspace file tree opens on the right. Create files and folders there. Deleting a file asks once; deleting a folder asks again, because everything inside goes with it. See PRs [#14344](https://github.com/QwenLM/qwen-code/pull/14344), [#14169](https://github.com/QwenLM/qwen-code/pull/14169), [#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**The Trajectory tab pauses when you scroll back.** Reading earlier records stops the view on the lines you're looking at. Hit Jump to latest to catch up again. Click any row and that record's details open. See PRs [#14723](https://github.com/QwenLM/qwen-code/pull/14723), [#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**Other improvements.** Select one exchange — a message and its reply — and delete it, or pick several and delete those ([#14297](https://github.com/QwenLM/qwen-code/pull/14297)). What it's doing now and what it just finished, with the time each step took, sits in one collapsible Recent activity section ([#14071](https://github.com/QwenLM/qwen-code/pull/14071)). In the session token usage panel, the overview keeps input, output, and cache, and below it you can split out what each model, the main agent, and the sub-agents used; hover the Info icon beside a model name for its time to first token and how much it outputs per second ([#14728](https://github.com/QwenLM/qwen-code/pull/14728), [#14648](https://github.com/QwenLM/qwen-code/pull/14648)).

![Open a project file in the right panel of Web Shell, then switch to the Trajectory tab to see how long each step took](https://img.alicdn.com/imgextra/i4/O1CN011HVsNLd8EyF7nW9B_!!6000000005070-2-tps-3841-2160.png)

## 📊 More New Features

**A QwenCloud entry now sits on the first `/auth` screen.** Pay-as-you-go and Token Plan keys are chosen separately, and one step in you pick China or International. See PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**Run your own Managed Agent service? Projects and sessions are easier to manage.** Those sessions now sit on the Web Shell home page beside the ones on your own computer, using the same composer and the same approval cards. This release adds picking an existing project directory, carrying the enabled skills into a new session, adjusting execution permissions while a session runs, and renaming a session by hand. Ordinary managed sessions can share one project directory too, and the files in it are shared between them. Each of these needs support from the matching deployment. See PRs [#14316](https://github.com/QwenLM/qwen-code/pull/14316), [#14970](https://github.com/QwenLM/qwen-code/pull/14970), [#14930](https://github.com/QwenLM/qwen-code/pull/14930), [#14920](https://github.com/QwenLM/qwen-code/pull/14920), [#14987](https://github.com/QwenLM/qwen-code/pull/14987), [#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**The QQ bot takes files now.** In a direct message or an @ in a group, send it a Word file, a PDF, or a spreadsheet — it saves the file, reads it, and answers from it. See PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**Connect a self-built WeCom app.** A colleague drops a task into the app your company built itself; Qwen Code picks it up, does the work, and replies under that app's identity. See PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Commands that ship inside Claude-format plugins now run in the terminal.** Last week they only took effect in one-shot usage. Type one in the terminal and it runs, with no request to the model. The layer where a plugin steps in before the model uses a tool is open to interactive sessions too: it can rewrite that call or block it. This is off by default — there's a Mods switch in settings, and it takes effect after a restart. See PRs [#14268](https://github.com/QwenLM/qwen-code/pull/14268), [#14565](https://github.com/QwenLM/qwen-code/pull/14565), [#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**See how far a background command has gotten.** The task detail now shows the tail of its output, how much output there is, and when it last wrote, along with the memory it holds and its start and end times. The content copies with one click. See PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 Experience Improvements

**Hover a collapsed item on the home page to preview it.** See PR [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**Sorting, filtering, and copying on tables feel smoother.** The advanced controls on wide tables and the copy options all got attention this round. See PR [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**Repeating itself gets it a reminder, not a cut turn.** Once a command or a file read repeats past a certain count, the default is to remind it to try another way and keep going. Want an automatic stop? Choose that in settings. See PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**Two fewer keys above the composer on mobile.** The up and down arrows for paging through history are gone; history search still works where it always did. See PR [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**The browser tab icon shows up on dark tabs.** Against a dark tab background it was nearly invisible before. See PR [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**Refresh the model list from the picker itself.** Clicking the model picker pulls a fresh list, and the refresh shows as a small icon beside the search box. See PRs [#14685](https://github.com/QwenLM/qwen-code/pull/14685), [#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**`Ctrl+V` pastes text in the Linux terminal.** Text or a link off the clipboard goes straight into the composer; images are still handled as attachments. See PR [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
