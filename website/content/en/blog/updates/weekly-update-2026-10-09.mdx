Qwen Code shipped four stable releases over the past two weeks — v0.24.5 through v0.25.0 — with 467 PRs merged.

**Qwen Live is live.** Talk to it and it answers in voice. Mid-call you can share your screen, so it sees what's happening on it.

**Qwen Code can work the pages you're already logged into.** It goes into the Chrome you use every day — turning pages, filling forms, submitting — and does all of it in the background, so your computer stays yours.

**One email assigns the work.** Not at the machine? Say it from the mail app on your phone, and the Qwen Code on that computer handles it and replies with the result.

**A pile of repetitive work goes to the background at half price with `/batch-api`.** Describe the job, get a plan that costs nothing first, approve it, and hours later the results land as files.

**A turn felt slow or expensive? The Trajectory tab shows where it stuck.** Model requests, Tool calls, and Subagent requests each get a lane, so an unusually long stretch stands out.

## ✨ New Features

### Qwen Live Is Live

Qwen Live is available in both the Web Shell and the desktop version. Click the Live icon in the left sidebar and the Qwen Live card opens on the right: flip the switch, paste in your Bailian DashScope Realtime API key, click Save. See PR [#12529](https://github.com/QwenLM/qwen-code/pull/12529)

Once it's on, click Open Live Voice on the Live page, or the real-time voice button at the bottom right of the composer, and talk — it answers in voice. See PR [#12189](https://github.com/QwenLM/qwen-code/pull/12189)

During a call you can turn on screen sharing so it sees what's on your screen, then ask it about that error message right there in front of you. See PRs [#12378](https://github.com/QwenLM/qwen-code/pull/12378), [#12623](https://github.com/QwenLM/qwen-code/pull/12623)

What you can do:

- Your hands are on the keyboard — say the next step instead of typing it
- An error on screen you can't read — share the screen, let it look, get its take
- A round trip that takes a dozen messages — finish it by talking

### Qwen Code Works Inside the Chrome You Already Use

Qwen Code can go into the Chrome you use every day and get things done: the tabs you have open, the accounts you're signed in to — it keeps using them. It turns pages, fills forms, submits, and leaves the result page for you. Just say something like "read the report I have open and summarize today's orders". See PR [#11242](https://github.com/QwenLM/qwen-code/pull/11242)

Install the [Qwen Code extension](https://chromewebstore.google.com/detail/qwen-code/hdhmmjclhibojdddmancfgbkleahfaph) from the Chrome Web Store first. After that, say what you need in the conversation. Works on Mac and Linux; Windows isn't supported yet. See PR [#12510](https://github.com/QwenLM/qwen-code/pull/12510)

None of this comes to the foreground. Chrome isn't switched to, so your computer stays usable, and several sessions can use it at the same time — each gets its own tab group, without interfering with the others. See PR [#12229](https://github.com/QwenLM/qwen-code/pull/12229)

What you can do:

- Have it read the admin console you're logged in to and pull today's numbers against your own sheet
- Expense forms and tickets spread over several pages — one sentence, it fills and submits each
- Watch a process you can only see in the browser — an approval queue, a to-do list — and have it pick out what needs action

### One Email Assigns the Work

Sometimes a task comes to mind and the machine running Qwen Code isn't within reach. Email Channel is new: send it an email.

Say it in any mail app on your phone, and the Qwen Code on that computer picks it up, does the work, and replies with the result. Something looks off? Reply to that email and it knows how far it already got. Error reports people send you, alerts your systems fire — forward them into that mailbox and it takes over.

To set it up, give Qwen Code a mailbox account, then put your own address in its allowlist — it only acts on mail from you.

What you can do:

- Send one on your commute and reach your desk to a finished result
- Forward a user's bug report as-is; it reads the logs in the attachment and gives a first assessment
- The moment an alert mail goes out, Qwen Code is on it, and replies with the cause

See PR [#12939](https://github.com/QwenLM/qwen-code/pull/12939)

### /batch-api: Repetitive Work in the Background at Half Price

You have hundreds of small, independent jobs: a whole directory of docs to translate, dozens of tickets each needing a few fields, every post needing a summary. Sending them one by one fills the conversation with waiting, and the money goes fast.

Type `/batch-api` with the job in one sentence. It samples a few items and hands you a plan first — how many items, where the output goes, roughly how many tokens. That step is free. It submits only after you approve. The batch then runs in the background billed at half the real-time rate, and usually within tens of minutes to a few hours the results land as files where you said. Meanwhile this conversation keeps working.

```text
/batch-api translate the Markdown docs under docs/zh into English, writing each to docs/en with the same filename
```

It fits batches where one pass finishes each item and the items don't relate to each other. Anything that needs several rounds of discussion stays in a normal conversation.

What you can do:

- Translate an entire Chinese docs directory in one submission and collect the files hours later
- Extract fields from a batch of logs or tickets, folded into one run
- Sort and tag hundreds of pieces of user feedback in one submission

See PR [#12492](https://github.com/QwenLM/qwen-code/pull/12492)

### Trajectory Tab: See Where a Turn Spent Its Time

After a turn, all you know is that it took a while. You don't know whether the model was silent for half of it, talked too much, or one tool hung in the middle.

The Trajectory tab in the right panel spreads the time over three lanes: Model requests, Tool calls, Subagent requests. An unusually long stretch is easy to spot, and when the bars get dense you can widen one section to look. See PRs [#12524](https://github.com/QwenLM/qwen-code/pull/12524), [#12557](https://github.com/QwenLM/qwen-code/pull/12557)

Circle a suspect stretch on the axis and only what happened in that window stays below. Pick one entry and its input, its return, and its token cost open up for you to copy out. See PRs [#12543](https://github.com/QwenLM/qwen-code/pull/12543), [#12971](https://github.com/QwenLM/qwen-code/pull/12971)

The axis also has a Real time view that counts the time you spent waiting, and gives two numbers — elapsed and actually running. That's how much of your time a turn really took. See PR [#12607](https://github.com/QwenLM/qwen-code/pull/12607)

Finished turns collapse, so a long session doesn't have to be scrolled end to end. See PR [#13081](https://github.com/QwenLM/qwen-code/pull/13081)

What you can do:

- It feels slow — read the axis and you know the next move: switch models, or go look at that tool
- Back to one stretch of a long session — circle it, and collapse the turns that are done
- One call looks wrong — see its input, output, and token cost right there

### Channel: Sessions Split by Prefix, Private and Group Access Separated, Long Threads Roll Over

**One bot can take work on separate tracks.** Put a different prefix in front of the message and it goes to a different session, each with its own requirements for how work is handed over — one side reviews code while the other answers questions about the repo, and the two don't bleed into each other. No extra connection needed for that. In a group, @ the bot and then add the prefix. See PR [#12595](https://github.com/QwenLM/qwen-code/pull/12595)

**Who may message it privately and who may use it in a group are now two settings.** You can open the group completely while keeping DMs to a few people on a list. The two sides don't affect each other. See PRs [#12547](https://github.com/QwenLM/qwen-code/pull/12547), [#12475](https://github.com/QwenLM/qwen-code/pull/12475)

**Long group threads roll over on their own.** A thread just keeps growing until no message can be sent, and only that one session is broken — one DingTalk thread reached 8,577 messages. Set a limit and it rolls to a fresh session when the limit is hit, saying so in the group. See PR [#12616](https://github.com/QwenLM/qwen-code/pull/12616)

### Web Shell: Re-Laid-Out Sidebar, Search in Long Sessions, Multiple Worktrees per Repo

**The sidebar is laid out again.** A narrow navigation strip on the left gives Channel, voice, and the rest their own entries; the version number and infrequent actions move into More. See PR [#12943](https://github.com/QwenLM/qwen-code/pull/12943)

**You can search inside a long session.** Look for a line you said or a block of code you pasted — search the keyword and jump straight to that message. Older messages don't have to be scrolled up to first; searching reaches them. See PR [#12234](https://github.com/QwenLM/qwen-code/pull/12234)

**Ask a side question without stopping the main task.** A small question while the main task is still running is in the "+" menu of the composer; open it and the wording is written for you. The answer appears in the panel beside it, and the main task is untouched. See PR [#12775](https://github.com/QwenLM/qwen-code/pull/12775)

**One repo can have several working copies open at once.** Following last issue's branch graph, the Git dialog has a Worktree tab: each session uses its own copy, so edits don't collide. Which copy is running a session and which has uncommitted changes is visible at a glance, and one click switches. See PRs [#12154](https://github.com/QwenLM/qwen-code/pull/12154), [#11816](https://github.com/QwenLM/qwen-code/pull/11816)

## 📊 More New Features

**Committing is something you can hand over too.** Type `/commit`: it looks at which files you changed, drafts a commit message in the repo's own style, and stages only the files that belong in this commit. Files holding secrets, like `.env`, it refuses outright. It only creates the commit — the push stays yours. Narrow the scope by adding a sentence, like `/commit only stage the parser changes`. See PR [#10586](https://github.com/QwenLM/qwen-code/pull/10586)

**See what one message made it do.** In the Web Shell, hover over a message you sent and a wrench icon appears next to the copy button. Click it for the Tool calls tab: which files this turn read, which commands it ran, what it changed — item by item, and each expands to its result and diff. Earlier turns are there too. See PR [#12466](https://github.com/QwenLM/qwen-code/pull/12466)

**`/advisor` stops waiting to be called.** Once it's on, the working model checks in with an advisor before it starts changing things and again before it hands work over; the advice comes back into the conversation and it carries on. Subagents it dispatches can ask too. Each question costs extra tokens, and that conversation is shown to the advisor model — pick one you trust. See PRs [#9636](https://github.com/QwenLM/qwen-code/pull/9636), [#12688](https://github.com/QwenLM/qwen-code/pull/12688)

**Adding a new model asks you for less.** How large its context window is, how much it can output, whether it takes images — it works these out on its own now, from a built-in model catalog that updates in the background daily and still works offline. Values you set yourself still win. See PR [#11959](https://github.com/QwenLM/qwen-code/pull/11959)

**Hooking up external memory got simpler.** To make it remember things across sessions, an address and a secret are enough now — the extension install and service registration are gone. Search works out of the box. Writing to memory needs one more switch, and once it's on, everything stored goes past you first. See PR [#12891](https://github.com/QwenLM/qwen-code/pull/12891)

**A lot of memory no longer has to be laid out in full.** Once it's on, it puts only the entries relevant to your current question into context and pulls the rest on demand. When memory has grown to tens or hundreds of files, that saves a lot. See PR [#10183](https://github.com/QwenLM/qwen-code/pull/10183)

**QQ bots can receive images and videos.** Images and short videos sent in a group it can look at directly, instead of you turning them into text. See PR [#12850](https://github.com/QwenLM/qwen-code/pull/12850)

## 👏 Experience Improvements

**Typing is ready twice as fast when you open it.** On a clean machine, from `qwen` to a ready prompt used to take about 2.5 seconds, and the first 2 of those showed a blank terminal. That wait is halved now, and memory usage is down about 60% from 575 MB. See PRs [#12622](https://github.com/QwenLM/qwen-code/pull/12622), [#12602](https://github.com/QwenLM/qwen-code/pull/12602), [#12603](https://github.com/QwenLM/qwen-code/pull/12603)

**Chinese covers the whole settings panel.** With the interface language set to Chinese, the panel reads Chinese throughout. See PR [#12783](https://github.com/QwenLM/qwen-code/pull/12783)

**Channel group speakers and session admins are edited in a dialog.** No more opening the config file and typing it by hand. See PR [#12535](https://github.com/QwenLM/qwen-code/pull/12535)

**The interface got cleaner.** Empty parameters stop taking a line, the top of the stats page is laid out, and raw data moved into details. See PRs [#12601](https://github.com/QwenLM/qwen-code/pull/12601), [#13091](https://github.com/QwenLM/qwen-code/pull/13091)

**Edit a skill, refresh, and it takes effect.** See PR [#12182](https://github.com/QwenLM/qwen-code/pull/12182)
