## Installer Qwen Code

Qwen Code s'installe en une seule commande sur Windows, macOS et Linux.

**macOS / Linux :**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows (PowerShell) :**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

Une fois l'installation terminée, exécutez `qwen --version` pour confirmer. Vous pouvez aussi installer via npm :

```bash
npm i @qwen-code/qwen-code@latest -g
```

## Configurer le fournisseur de modèles

Une fois l'installation terminée, Qwen Code vous guide pour connecter un fournisseur de modèles. Nous recommandons la plateforme Alibaba Cloud Bailian.

1. Rendez-vous sur [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key) pour obtenir votre clé API
2. Lancez `qwen` dans le terminal, sélectionnez Alibaba ModelStudio
3. Collez votre clé API, choisissez le modèle

Si vous préférez configurer manuellement, éditez `~/.qwen/settings.json` :

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "votre-clé-API"
  }
}
```

Une fois configuré, utilisez la commande `/model` pour voir et changer de modèle :

## Lancer votre première conversation

Allez dans le répertoire de votre projet et lancez Qwen Code :

```bash
cd votre-projet && qwen
```

Décrivez simplement ce que vous voulez faire en langage naturel. Par exemple :

```
Écris une fonction Python qui calcule la suite de Fibonacci
```

Ou demandez à l'IA de trier vos fichiers :

```
Range les fichiers de ce dossier dans des sous-dossiers par type
```

Qwen Code décompose automatiquement la tâche, exécute les opérations et renvoie le résultat. Pas besoin de tout guider pas à pas — décrivez l'objectif, c'est tout.

## Installer des extensions Skills

Skills est le système d'extension de capacités de Qwen Code. Vous pouvez installer à la demande des Skills développés par la communauté pour donner à l'IA de nouvelles compétences spécialisées.

Installer un Skill est très simple, une seule phrase suffit :

```
Aide-moi à installer find-skills
```

Ou directement avec la commande :

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

Après l'installation, utilisez `/skills` pour voir les Skills installés.
