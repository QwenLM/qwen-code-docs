Qwen Code publie cette semaine deux versions stables, v0.25.3 et v0.26.0, avec 436 PR fusionnées.

**La réponse tient sur une carte interactive que vous modifiez.** Envie de changer quelques chiffres ou de tester plusieurs cas : modifiez les nombres sur la carte, le total se recalcule.

**Les workflows enregistrés dans le dépôt suivent dans les sous-dossiers.** Quand un projet se divise en front, back et plusieurs dossiers de composants, vous retrouvez et lancez toujours les contrôles de code et les tests enregistrés à la racine, même en démarrant Qwen Code plus bas.

**Une seule famille de commandes `qwen daemon` tient le Web Shell.** Démarrage, état, journaux, arrêt et redémarrage sont regroupés là.

## ✨ Nouvelles fonctionnalités

### Cartes interactives : réglez, comparez, tranchez

Sur certains sujets, vous voulez changer quelques chiffres et tester plusieurs cas pour voir ce que ça donne. Qwen Code fabrique maintenant une carte interactive pour ce besoin : ajustez un nombre ou une proportion, le résultat correspondant s'affiche aussitôt. Voir le PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

Pour un repas d'équipe, par exemple, demandez une carte de calcul des frais : nombre de convives, prix par personne, location de la salle. Le nombre change, vous changez le nombre ; vous changez de restaurant, vous changez le prix par personne. Le total se recalcule, sans renvoyer un message à l'IA à chaque fois.

Désactivée par défaut : activez Generated UI dans les paramètres expérimentaux, puis redémarrez pour l'obtenir. Les sessions gérées, à distance ou en bac à sable ne prennent pas encore la version intégrée. Voir le PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

Ce que vous pouvez en faire :

- Comparer des offres de location en croisant loyer, temps de trajet et frais de transport
- Ajuster l'équipe et la répartition des tâches d'un projet, et estimer délai et coût
- Comparer des configurations de serveur et estimer la capacité et le coût selon le trafic

### Workflows : enregistrés à la racine, utilisables depuis un sous-dossier

Un projet se divise souvent en front, back et plusieurs dossiers de composants. Si vous avez déjà enregistré des workflows de contrôle de code ou de tests à la racine, vous les retrouvez et les lancez désormais en démarrant Qwen Code dans un sous-dossier.

Vous modifiez une page dans le dossier front et voulez lancer le contrôle enregistré du projet : il est dans la liste des workflows de la session courante. Cette mise à jour ajoute la recherche vers le haut, dans les dossiers de confiance du même dépôt Git. Elle vaut pour les sessions de terminal local comme pour les sessions ordinaires du Web Shell. Voir les PR [#14369](https://github.com/QwenLM/qwen-code/pull/14369), [#14646](https://github.com/QwenLM/qwen-code/pull/14646)

Ce que vous pouvez en faire :

- Relancer le contrôle de code du projet depuis chaque dossier de composants
- Modifier le back, puis lancer le workflow de tests enregistré dans le dépôt
- Écrire la documentation du projet avec le contrôle des docs enregistré un niveau au-dessus

### qwen daemon : le Web Shell se gère en une famille de commandes

La semaine dernière, le Web Shell connectait plusieurs Qwen Code sur une seule page. Cette semaine ajoute la gestion de ces services locaux.

Démarrer le Web Shell, regarder l'état, redémarrer : tout est regroupé sous `qwen daemon`. Par exemple :

Lancez `qwen daemon start` : le service démarre en arrière-plan et renvoie son adresse d'accès. `qwen daemon status` liste les services lancés, `qwen daemon logs` affiche les journaux, `qwen daemon stop` arrête celui que vous nommez. Voir les PR [#14739](https://github.com/QwenLM/qwen-code/pull/14739), [#14869](https://github.com/QwenLM/qwen-code/pull/14869)

Pour diagnostiquer, `qwen daemon status --detail` ajoute la version, la durée de fonctionnement, le nombre de sessions et le nombre de problèmes. Dans un script, si vous devez vous connecter juste après le lancement, `qwen daemon start --wait` attend que l'environnement soit prêt avant de rendre la main. Voir les PR [#14902](https://github.com/QwenLM/qwen-code/pull/14902), [#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <port>` redémarre le service HTTP local indiqué et retrouve le workspace de départ et les réglages du Web Shell enregistrés. Voir le PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

Ce que vous pouvez en faire :

- Lancer le service local et continuer à travailler dans le même terminal
- Comparer l'état de plusieurs services locaux et repérer celui qui demande quelque chose
- Redémarrer un service précis avec sa configuration de départ enregistrée

![Dans un terminal, `qwen daemon start` place le service en arrière-plan ; un second terminal consulte son état avec `qwen daemon status`](https://img.alicdn.com/imgextra/i4/O1CN015EshdwuaPaE7nW9B_!!6000000003381-2-tps-3841-2160.png)

### Web Shell : fichiers et journal d'exécution, plus lisibles à l'écran

**PDF et Word s'ouvrent dans l'interface.** Depuis une référence `@`, depuis Files à droite ou depuis une carte de production : le PDF passe par la visionneuse du navigateur, et le Word se prévisualise par ces mêmes entrées. Voir les PR [#14825](https://github.com/QwenLM/qwen-code/pull/14825), [#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**À droite, vous créez et vous supprimez des fichiers.** Cliquez sur le nom du dossier à côté du titre de la conversation : l'arbre du workspace s'ouvre à droite. Vous y créez fichiers et dossiers. Supprimer un fichier demande une confirmation ; supprimer un dossier en demande deux, parce que son contenu part avec lui. Voir les PR [#14344](https://github.com/QwenLM/qwen-code/pull/14344), [#14169](https://github.com/QwenLM/qwen-code/pull/14169), [#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**L'onglet Trajectory se met en pause.** Remontez les entrées anciennes : la pause se prend toute seule et l'écran reste sur les lignes que vous lisez. Pour rejoindre le direct, cliquez sur « Jump to latest ». Cliquez sur n'importe quelle ligne pour ouvrir le détail de cette entrée. Voir les PR [#14723](https://github.com/QwenLM/qwen-code/pull/14723), [#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**Autres améliorations.** Dans une conversation, sélectionnez une question et sa réponse pour les supprimer ensemble, ou n'en retirez que quelques-unes ([#14297](https://github.com/QwenLM/qwen-code/pull/14297)) ; ce qu'il fait en cours et ce qu'il vient de finir, avec le temps de chaque étape, tiennent dans un bloc « Recent activity » repliable ([#14071](https://github.com/QwenLM/qwen-code/pull/14071)) ; dans le panneau « Session token usage », la vue d'ensemble garde entrée, sortie et cache, et dessous vous voyez séparément ce que chaque modèle, l'agent principal et les sous-agents ont utilisé ; survolez l'icône Info à côté d'un nom de modèle pour voir le délai avant le premier token et le nombre de tokens par seconde ([#14728](https://github.com/QwenLM/qwen-code/pull/14728), [#14648](https://github.com/QwenLM/qwen-code/pull/14648)).

![Les fichiers du projet ouverts dans le panneau de droite du Web Shell, puis l'onglet Trajectory montrant le temps pris par chaque étape](https://img.alicdn.com/imgextra/i4/O1CN011HVsNLd8EyF7nW9B_!!6000000005070-2-tps-3841-2160.png)

## 📊 Autres nouvelles fonctionnalités

**Premier écran de `/auth` : « 千问AI平台 / QwenCloud » s'ajoute.** Quand votre clé vient de l'une de ces deux plateformes — la première est l'entrée pour la Chine, la seconde l'entrée internationale —, le fournisseur officiel correspondant se choisit dès ce premier écran ; clé à l'usage et abonnement suivent chacun leur chemin. Voir le PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**Vous hébergez votre propre service Managed Agent ? Projets et tâches se gèrent plus simplement.** Ces sessions apparaissent désormais sur la page d'accueil du Web Shell, à côté de celles de votre ordinateur, avec le même champ de saisie et les mêmes cartes d'approbation. Cette version ajoute le choix d'un dossier de projet existant, la reprise des skills déjà activées dans une nouvelle session, l'ajustement des droits d'exécution en cours de session et le renommage manuel d'une session. Une session gérée ordinaire peut elle aussi partager un même dossier de projet, dont les fichiers sont communs entre ces sessions. Tout cela demande le déploiement correspondant. Voir les PR [#14316](https://github.com/QwenLM/qwen-code/pull/14316), [#14970](https://github.com/QwenLM/qwen-code/pull/14970), [#14930](https://github.com/QwenLM/qwen-code/pull/14930), [#14920](https://github.com/QwenLM/qwen-code/pull/14920), [#14987](https://github.com/QwenLM/qwen-code/pull/14987), [#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**Le bot QQ reçoit des fichiers.** En message privé, ou en le mentionnant dans un groupe : envoyez-lui un Word, un PDF ou un tableur, il le garde et répond à partir du fichier. Voir le PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**Une application interne WeCom se branche.** Un collègue confie une tâche en une phrase dans l'application que votre entreprise a elle-même intégrée ; Qwen Code la prend et répond sous l'identité de cette application. Voir le PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Les commandes embarquées d'un plugin au format Claude se tapent aussi dans le terminal.** La semaine dernière, elles ne valaient qu'en exécution unique ; désormais, tapez-les dans le terminal et elles tournent sans lancer de requête au modèle. La couche où le plugin intervient avant que le modèle appelle un outil s'ouvre elle aussi aux sessions interactives : elle peut réécrire cet appel ou le bloquer. Désactivée par défaut, avec un interrupteur Mods dans les paramètres ; un redémarrage est nécessaire. Voir les PR [#14268](https://github.com/QwenLM/qwen-code/pull/14268), [#14565](https://github.com/QwenLM/qwen-code/pull/14565), [#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**Une commande lancée en arrière-plan montre déjà sa sortie.** Le détail de la tâche donne la fin de la sortie, sa taille, l'heure de la dernière écriture, plus la mémoire occupée et les heures de début et de fin. Le contenu se copie en un clic. Voir le PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 Améliorations de l'expérience

**Une ligne repliée sur la page d'accueil s'aperçoit au survol.** Voir le PR [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**Tri, filtres et copie des tableaux deviennent plus simples.** Les contrôles avancés des tableaux larges et les options de copie ont été retravaillés ce tour-ci. Voir le PR [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**Qwen Code tourne en rond ? Il reçoit un rappel, et le tour continue.** Quand une commande ou une lecture de fichier se répète au-delà d'un certain nombre de fois, il part par défaut sur un rappel lui suggérant de changer de méthode ; pour un arrêt automatique, c'est dans les paramètres. Voir le PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**Sur mobile, deux touches de flèche en moins au-dessus du champ de saisie.** Les flèches de navigation dans l'historique sont parties ; la recherche dans l'historique reste où elle était. Voir le PR [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**Le favicon reste visible sur un onglet sombre.** Sur fond d'onglet sombre, il se fondait presque. Voir le PR [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**Le sélecteur de modèles rafraîchit sa propre liste.** Un clic sur le sélecteur va chercher une liste de modèles à jour ; le rafraîchissement apparaît comme une petite icône à côté de la recherche. Voir les PR [#14685](https://github.com/QwenLM/qwen-code/pull/14685), [#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**`Ctrl+V` colle du texte dans un terminal Linux.** Du texte ou un lien du presse-papiers entre directement dans le champ ; les images restent traitées comme des pièces jointes. Voir le PR [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
