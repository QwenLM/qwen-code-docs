Qwen Code publie cette semaine deux versions stables, v0.25.1 et v0.25.2, avec 371 PR fusionnées.

**Agent Collaboration : Claude Code et Codex entrent dans la conversation comme coéquipiers.** Leur réponse s'affiche directement dans la conversation où vous êtes, et vous pouvez aussi les envoyer travailler sur une autre machine.

**Plusieurs Qwen Code ouverts, tous connectés sur une seule page.** Dans la barre latérale, chaque Qwen Code forme son groupe ; dessous, ses conversations et ses workspaces du moment. Basculer de l'un à l'autre se fait dans la page.

**Un serveur MCP ne vous sert plus ? Excluez-le au démarrage.** `qwen --disable-mcp-server <nom>` ne vaut que pour cette exécution et ne touche à aucun fichier de configuration.

## ✨ Nouvelles fonctionnalités

### Agent Collaboration : Claude Code et Codex en coéquipiers dans la conversation

Une tâche se prête à deux bras en parallèle : l'un modifie le code, un autre programme le relit dans le même temps. Avant, quand vous mentionniez un Agent avec @, il ouvrait un sujet à part, recopiait vos dernières phrases et vous amenait sur cette nouvelle page ; la conversation principale ne recevait jamais sa réponse.

Aujourd'hui, mentionnez-le avec @ et il répond dans la conversation où vous êtes : avec son nom, son avancée, les outils employés, les tokens consommés ; une commande à lancer s'affiche toujours pour validation. Cet Agent n'a pas besoin d'être Qwen Code — si Claude Code ou Codex est installé chez vous, vous pouvez l'amener lui aussi dans la conversation. Voir le PR [#13467](https://github.com/QwenLM/qwen-code/pull/13467)

Il peut aussi travailler sur une autre machine : là-bas, Qwen Code tourne en service ; ajoutez-le comme assistant, envoyez-y les tâches lourdes, et il reprend le lien tout seul après un redémarrage de cette machine. Vous pouvez aussi mentionner une équipe avec @ : le leader découpe le travail et le distribue aux membres, qui lui rendent compte une fois leur part terminée. Voir le PR [#13583](https://github.com/QwenLM/qwen-code/pull/13583)

Différence avec l'envoi d'un sous-agent : le sous-agent traite une petite tâche pour lui seul et ne rend de compte qu'à lui ; celui que vous amenez avec @ parle devant vous, ce peut être un programme d'un autre fournisseur, et il peut tourner sur une autre machine.

La fonction reste expérimentale et est désactivée par défaut : activez « Enable Agent Collaboration » dans les paramètres, puis redémarrez. Il faut d'abord créer le coéquipier : ouvrez la page « Agents » à gauche et ajoutez-le. Ensuite, tapez @ suivi de son nom dans n'importe quelle conversation pour l'appeler.

Ce que vous pouvez en faire :

- Une main sur le code, l'autre sur la relecture : vous modifiez pendant qu'un autre Agent relit, et les deux se suivent clairement dans la même conversation
- Les tâches lourdes — compilation, exécution des tests — partent sur une autre machine, vous continuez ici
- Plusieurs fournisseurs différents forment une même équipe, chacun sur la partie où il est bon

### Plusieurs Qwen Code ouverts, tous connectés sur une seule page

Les uns ont un portable sous la main, une machine dédiée aux compilations et une autre qui garde les tâches longues. Les autres n'ont qu'un ordinateur et ouvrent un Web Shell par projet, pour ne pas mélanger les chantiers. Avant, une page de navigateur ne reconnaissait qu'un seul de ces Qwen Code : voir l'autre obligeait à recharger toute la page : un flash, et le texte à moitié écrit dans le champ était perdu.

Désormais, tous ceux que vous avez enregistrés restent connectés en même temps. Dans la barre latérale, chaque Qwen Code forme un groupe, avec ses conversations et ses workspaces du moment en dessous ; quand vous choisissez un workspace dans le champ de saisie, les répertoires sont eux aussi rangés par groupe ; basculer sur un autre groupe se fait dans la page. Voir les PR [#13739](https://github.com/QwenLM/qwen-code/pull/13739), [#13677](https://github.com/QwenLM/qwen-code/pull/13677)

Pour l'utiliser, la machine appelée doit d'abord autoriser votre page à se connecter : lancez `qwen serve` avec `--allow-origin`, en indiquant l'adresse que vous voyez dans la barre d'URL du navigateur.

Ce que vous pouvez en faire :

- Une compilation au long cours occupe la machine d'à côté : vous suivez son avancée depuis votre ordinateur
- Sur une seule machine, un Qwen Code par projet : rien ne se mélange et tout se voit sur une page
- Passer du portable à la machine fixe et reprendre la distribution des tâches

### Un serveur MCP ne vous sert plus, excluez-le au démarrage

Quiconque branche des serveurs MCP est déjà tombé là-dessus : l'un d'eux pose problème aujourd'hui, ses outils renvoient des erreurs ou le démarrage traîne, et vous voulez simplement « ne pas l'embarquer cette fois ». Avant, il n'y avait que la solution brutale : tout couper d'un coup, les serveurs venus des paramètres avec la configuration locale.

Vous pouvez maintenant le nommer au démarrage :

```text
qwen --disable-mcp-server github
```

Pour en exclure plusieurs d'un coup, répétez l'option ou écrivez `--disable-mcp-server github,postgres`. Cela ne vaut que pour ce démarrage, votre fichier de configuration reste intact. Voir le PR [#14003](https://github.com/QwenLM/qwen-code/pull/14003)

Ce que vous pouvez en faire :

- Un serveur vous semble coupable : excluez-le pour un essai et voyez si c'est bien lui
- Le démarrage traîne à cause d'un serveur : ne l'embarquez pas cette fois
- Le même code, un tour dédié à la base de données et un tour dédié au web, chacun avec ses serveurs

### Web Shell : les fichiers du projet s'ouvrent d'un clic, un ajout part sur-le-champ, et il prévient quand il attend votre feu vert

**Les fichiers du projet se parcourent à droite.** L'arbre complet du workspace s'affiche ici ; ouvrez un fichier, son contenu arrive à côté. Markdown, pages web, images et Excel se lisent directement, et vous pouvez copier le chemin, télécharger ou ajouter en référence. Voir les PR [#13878](https://github.com/QwenLM/qwen-code/pull/13878), [#13664](https://github.com/QwenLM/qwen-code/pull/13664)

**Un fichier local glissé dedans est téléversé.** Il part dans le dossier où vous le déposez, y compris dans la version desktop. Voir les PR [#14145](https://github.com/QwenLM/qwen-code/pull/14145), [#14053](https://github.com/QwenLM/qwen-code/pull/14053)

**Un message en file passe tout de suite, un message annulé revient dans le champ de saisie.** Ce que vous envoyez pendant une réponse attend d'abord en file ; cliquez sur « Send now » pour l'insérer immédiatement. Si vous appuyez sur stop alors que l'IA n'a encore rien produit, la phrase revient dans le champ de saisie : corrigez-la et renvoyez-la. Voir les PR [#13681](https://github.com/QwenLM/qwen-code/pull/13681), [#13488](https://github.com/QwenLM/qwen-code/pull/13488)

**Il envoie une notification quand il s'arrête pour vous attendre.** Soit il faut valider une opération, soit il a posé une question et attend votre réponse : avant, ces deux cas ne faisaient aucun bruit. Maintenant, dès que la page passe en arrière-plan, une notification apparaît ; un clic vous ramène dans cette conversation. Voir le PR [#13832](https://github.com/QwenLM/qwen-code/pull/13832)

**Un sous-agent ou une tâche d'arrière-plan en cours fait clignoter une pastille sur l'icône en liste, en haut de la zone de chat.** Visible sans ouvrir le panneau. Voir le PR [#14048](https://github.com/QwenLM/qwen-code/pull/14048)

## 📊 Autres nouvelles fonctionnalités

**À force de chercher sans rien rendre, on lui demande de conclure.** Après un certain nombre d'actions en lecture seule — lecture de fichiers, recherche de code —, un rappel lui arrive au tour suivant : exploiter ce qu'il a trouvé, faire avancer ce que vous demandez, ou dire clairement où il bloque. Quand le but est justement de faire le tour d'une situation, il énonce ses conclusions et les questions encore ouvertes. Voir le PR [#13601](https://github.com/QwenLM/qwen-code/pull/13601)

**Une interface apportée par un serveur MCP doit passer par vous avant d'écrire dans la conversation.** Certains serveurs MCP ne donnent pas que des outils : ils ajoutent une interface cliquable dans la conversation. Quand cette interface veut envoyer une phrase à votre place, Qwen Code pose devant vous le contenu complet, sa provenance et la conversation visée ; rien ne part sans votre clic de confirmation. Voir le PR [#13958](https://github.com/QwenLM/qwen-code/pull/13958)

**Ce que fait chaque agent d'un workflow se voit en cliquant sur son nœud.** Depuis la carte du workflow dans la conversation, la page « Tasks » ou la page du workflow, cliquez sur un agent : le panneau de droite ouvre son déroulé — la consigne reçue, les outils appelés, la sortie en cours, l'étape atteinte. Voir le PR [#14175](https://github.com/QwenLM/qwen-code/pull/14175)

**Le contrôle d'avant-exécution peut modifier les paramètres de cet appel.** C'est le rôle du hook que vous configurez dans les paramètres : il tourne avant chaque appel d'outil. Qwen Code revalide les nouveaux paramètres que le hook renvoie, puis repasse par les droits et la confirmation avant d'agir. Voir le PR [#13442](https://github.com/QwenLM/qwen-code/pull/13442)

**Une question à côté peut partir dans un autre workspace.** Pendant que la tâche principale répond, `/btw side` crée une conversation séparée dans un autre workspace de cette tâche, au lieu de la mélanger dans le même fil. Voir le PR [#13468](https://github.com/QwenLM/qwen-code/pull/13468)

**Les commandes embarquées d'un plugin au format Claude s'exécutent vraiment.** Ce type de commande est du code, pas un prompt pour le modèle. Avant, la taper revenait à adresser une phrase au modèle ; maintenant le plugin l'exécute en local et renvoie directement le résultat, sans consommer de token. Il faut activer `experimental.mods` dans les paramètres, un workspace de confiance, et le mode `qwen -p '…'` — une exécution, un résultat. L'interface interactive et le Web Shell ne le prennent pas encore en charge. Seule une partie de l'interface Mod est implémentée : aucune garantie que toutes les commandes existantes tournent. Voir les PR [#13843](https://github.com/QwenLM/qwen-code/pull/13843), [#13890](https://github.com/QwenLM/qwen-code/pull/13890), [#13915](https://github.com/QwenLM/qwen-code/pull/13915), [#13950](https://github.com/QwenLM/qwen-code/pull/13950)

## 👏 Améliorations de l'expérience

**Sur la page New task, les fichiers, le terminal et l'aperçu web sont déjà disponibles à droite avant toute phrase.** Le haut de page devient une barre d'outils allégée ; chaque workspace mémorise sa disposition, qui survit au rafraîchissement comme au changement de conversation. Quand vous envoyez votre première phrase, onglets, ordre, largeur des panneaux et plein écran sont transmis à la conversation qui vient de naître. Voir le PR [#14159](https://github.com/QwenLM/qwen-code/pull/14159)

**L'onglet Trajectory se cherche, se filtre et se feuillette.** Un nom d'outil, un nom de modèle ou un morceau de texte de journal mènent directement à l'entrée ; vous pouvez ne voir qu'un type d'entrée, ou seulement les échecs, ou seulement les succès. Les entrées plus anciennes se parcourent par tranches, puis ramènent à la plus récente — recherche et statistiques ne portent que sur la tranche affichée. Après une coupure et une reconnexion, votre position, votre sélection, vos filtres et votre défilement restent en place. Voir les PR [#13264](https://github.com/QwenLM/qwen-code/pull/13264), [#13716](https://github.com/QwenLM/qwen-code/pull/13716), [#13952](https://github.com/QwenLM/qwen-code/pull/13952)

**Une sélection dans une réponse se copie comme vous voulez.** Surlignez un passage : le menu propose deux choix, du texte brut, ou du Markdown fidèle à l'écriture d'origine — titres, listes, code et tableaux suivent. Voir le PR [#13833](https://github.com/QwenLM/qwen-code/pull/13833)

**La consommation de contexte s'ouvre à droite, au lieu d'empiler des cartes dans la conversation.** Avant, cliquer sur l'anneau du champ de saisie déposait une carte « Context Usage » dans la conversation, et le détail de cette carte en déposait une autre. Les deux s'ouvrent maintenant dans le panneau de droite, avec un exemplaire par conversation. Pour les garder dans la conversation, tapez `/context`. Voir le PR [#14086](https://github.com/QwenLM/qwen-code/pull/14086)

**Les tableaux larges et longs se regardent en plein écran.** Cliquez sur « Fullscreen » sur le tableau : il prend toute la fenêtre. Sortez avec Esc ou le bouton de sortie ; le tri appliqué, les filtres, les réglages de colonnes et la ligne atteinte sont tous conservés. Voir le PR [#13589](https://github.com/QwenLM/qwen-code/pull/13589)

**Un message en file se supprime sur place, avant d'être parti.** Y compris celui dont la pièce jointe n'est qu'à moitié envoyée : le fichier intérimaire est nettoyé avec lui. Voir le PR [#13594](https://github.com/QwenLM/qwen-code/pull/13594)

**Replier le tour masque aussi ce qui a fini en arrière-plan.** Les cartes de résultat des tâches d'arrière-plan et leurs notifications de fin partent dans le pli avec le reste. Voir le PR [#13825](https://github.com/QwenLM/qwen-code/pull/13825)

**Les messages de la saisie vocale existent en chinois, et un message d'erreur se ferme.** Les erreurs et le message « aucun son entendu » suivent la langue de l'interface ; cliquez sur la croix en haut à droite du message, le microphone revient en veille et vous pouvez réessayer tout de suite. Voir le PR [#13938](https://github.com/QwenLM/qwen-code/pull/13938)

**Pour une copie de travail séparée, choisir « Worktree » suffit.** Dans la boîte Git, cliquez dessus : le choix est pris et le menu se referme. Ce n'est qu'au premier message envoyé que la copie reçoit son nom et se crée, selon le déroulé de création de conversation — jusque-là, vous pouvez revenir en arrière à tout moment. Voir le PR [#13607](https://github.com/QwenLM/qwen-code/pull/13607)

**Les icônes sont alignées sur le logo actuel.** Y passent : le favicon de l'onglet du Web Shell, le signe de la barre latérale, l'icône des notifications web, puis l'image de démarrage et les icônes d'application de la version desktop. Voir le PR [#14052](https://github.com/QwenLM/qwen-code/pull/14052)
