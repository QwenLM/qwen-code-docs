Qwen Code publie cette semaine cinq versions stables, v0.26.8 à v0.27.2.

**Votre compte Qwen sous abonnement se connecte et sert directement.** Le CLI, VS Code et le bureau acceptent la connexion avec un abonnement Plus/Pro : les modèles de l'abonnement servent au chat et à la recherche web.

**WeChat, QQ et l'e-mail se configurent dans le Web Shell.** WeChat et QQ affichent un QR code à scanner depuis la page ; pour l'e-mail, l'adresse du serveur et les informations du compte suffisent.

**Le canal GitHub filtre les événements par dépôt.** La liste blanche ne reçoit que les dépôts listés ; la liste noire exclut ceux listés.

## ✨ Nouvelles fonctionnalités

### Qwen Code se connecte avec un compte Qwen sous abonnement

Un abonnement Plus ou Pro sur votre compte Qwen suffit pour vous connecter depuis le terminal, VS Code ou le bureau. Dans le terminal, lancez `/auth`, choisissez le compte membre Qwen, puis terminez l'autorisation dans le navigateur. Le client charge les modèles disponibles dans l'abonnement ; la recherche web intégrée est utilisable.

Ce que vous pouvez en faire :

- Les modèles de l'abonnement travaillent directement, la consommation est imputée à l'abonnement
- Le même compte sur le terminal, VS Code et le bureau : les mêmes modèles partout
- Un abonnement Qwen suffit pour utiliser Qwen Code, sans brancher d'API

Voir cette PR [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Compte et liste des modèles après connexion avec l'abonnement Qwen](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### WeChat, QQ et e-mail : trois canaux de plus dans le Web Shell

La gestion des canaux du Web Shell accueille WeChat, QQ et l'e-mail. WeChat personnel et QQ affichent leur QR code directement dans la page : scannez-le avec le téléphone pour vous connecter. Pour l'e-mail, renseignez l'adresse du serveur et les informations du compte. Toutes les principales plateformes de chat sauf Telegram se configurent désormais dans le Web Shell.

Ce que vous pouvez en faire :

- Scannez le QR code affiché dans le Web Shell avec votre téléphone pour brancher votre WeChat personnel en privé ou lier votre QQ
- Ajoutez ou modifiez un canal e-mail dans la gestion des canaux, et désignez les expéditeurs autorisés à ouvrir une session par e-mail
- Révoquez un appairage de canal en un clic, directement dans le Web Shell

Voir les PR [#16736](https://github.com/QwenLM/qwen-code/pull/16736), [#16724](https://github.com/QwenLM/qwen-code/pull/16724), [#16746](https://github.com/QwenLM/qwen-code/pull/16746)

![Page de connexion par QR code du canal WeChat dans le Web Shell](https://img.alicdn.com/imgextra/i1/O1CN01ldag0pIAw9J4s7XG_!!6000000004740-2-tps-2400-1626.png)

### Le canal GitHub filtre les événements par dépôt

Le canal GitHub pousse automatiquement les événements du dépôt dans la session : ouverture de PR, commentaire, fin de CI — l'agent enchaîne. Vous choisissez le périmètre : la liste blanche ne reçoit que les dépôts listés, la liste noire reçoit tous les dépôts sauf ceux listés. Les événements exclus sont ignorés : ils n'entrent pas dans la session et ne consomment aucun traitement.

Ce que vous pouvez en faire :

- Des centaines de dépôts dans l'organisation : listez seulement les deux dont vous vous occupez, et ne recevez que leurs événements
- Un dépôt que vous ne suivez plus passe en liste noire ; rajoutez-le quand vous le reprenez
- Les PR des dépôts sans rapport ne font plus la queue devant l'agent : vos dépôts sont traités plus vite

Voir cette PR [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

![Paramètres de filtrage des dépôts dans l'éditeur de canal](https://img.alicdn.com/imgextra/i4/O1CN01NAru06FwyBE7o1Mj_!!6000000003227-2-tps-3845-2160.png)

### Web Shell : questions-réponses et consommation plus lisibles, sessions rangées par lot

**Une heatmap des questions-réponses.** Une tâche longue tourne depuis plusieurs jours et vous voulez relire les échanges d'une journée : un bouton heatmap ouvre un calendrier classé par jour, l'intensité de la couleur correspond au nombre de questions-réponses du jour, et un clic sur une date saute à la première question-réponse de ce jour. Voir cette PR [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**Une barre de consommation sous le champ de saisie.** Une ligne de chiffres s'affiche sous le champ de saisie : nombre de tours, vitesse de sortie, total de tokens, taux de hit du cache. Voir cette PR [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**Les sessions s'épinglent et s'archivent par lot.** La barre latérale gagne un interrupteur de sélection multiple : cochez des sessions, puis épinglez-les ou archivez-les en un clic. Voir cette PR [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**Les options incomprises s'éclairent.** Quand l'IA propose un choix, le panneau de questions ajoute un bouton « Demander des détails » : il ouvre une tâche annexe qui explique le sens, les différences, les effets et la recommandation de chaque option. Voir cette PR [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**Autres améliorations.** Les workspaces se replient ou se déploient tous en un clic et se réordonnent en glissant leur titre ([#16197](https://github.com/QwenLM/qwen-code/pull/16197)) ; une tâche d'arrière-plan qui attend votre approbation déclenche une notification du bureau ou une sonnerie du terminal, même quand vous êtes dans une autre fenêtre ([#16800](https://github.com/QwenLM/qwen-code/pull/16800)) ; les cartes d'outils comme les appels MCP affichent leurs paramètres et le résultat complet dès qu'on les déplie ([#15435](https://github.com/QwenLM/qwen-code/pull/15435)) ; la page des skills accepte l'envoi direct d'un skill empaqueté en ZIP ([#16424](https://github.com/QwenLM/qwen-code/pull/16424)).

![Sélection multiple dans la barre latérale du Web Shell et barre de consommation sous le champ de saisie](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 Autres nouvelles fonctionnalités

**Les tâches planifiées choisissent leur canal de livraison.** À la création d'une tâche planifiée dans le Web Shell, vous désignez le canal qui recevra le résultat. Voir cette PR [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**Les groupes QQ reçoivent des messages proactifs.** Les résultats des tâches planifiées, des webhooks et des tâches d'arrière-plan partent en messages de groupe proactifs dans QQ. Un interrupteur optionnel `forwardBotMessages` transfère aussi à la session les messages des autres bots du groupe. Voir les PR [#15635](https://github.com/QwenLM/qwen-code/pull/15635), [#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**Un hook de changement de fichier.** Les sessions locales gagnent le hook `FileChanged` : il déclenche le hook configuré quand un fichier ou un dossier surveillé est créé, modifié ou supprimé — y compris par un autre programme. Voir cette PR [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Trois nouvelles capacités pour les plugins Mods.** `$.store` conserve les données du plugin d'une session à l'autre ; `ui.render` réécrit le texte de réponse affiché dans le terminal, le texte stocké et copié reste intact ; `$.model.complete` lance une complétion de texte ponctuelle. Voir les PR [#16791](https://github.com/QwenLM/qwen-code/pull/16791), [#16794](https://github.com/QwenLM/qwen-code/pull/16794), [#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**Les commentaires d'une PR liée arrivent dans la session.** Une session liée à une PR reçoit automatiquement les nouveaux commentaires de cette PR : commentaires ordinaires comme commentaires de revue inline, sans avoir besoin de @. Voir cette PR [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 Améliorations de l'expérience

**Les questions latérales `/btw` acceptent les relances et le parallèle.** Une nouvelle question latérale embarque les précédentes avec leurs réponses : vous relancez en continuant depuis ces réponses. Posez-en plusieurs à la suite : chacune reçoit sa réponse sans interrompre les autres. Voir cette PR [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**Le shell courant est annoncé à l'IA au démarrage.** Le début de session indique dans quel shell les commandes s'exécuteront (bash, cmd.exe, etc.). L'IA connaît la syntaxe à utiliser sans la deviner depuis le système ; sous Windows, les commandes sont plus souvent correctes. Voir cette PR [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**Le titre automatique des sessions suit la langue de la conversation.** Une conversation en chinois génère un titre en chinois ; chaque langue garde la sienne. Voir cette PR [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Les raisons du verdict de Goal suivent la langue de la session.** Le motif d'acceptation ou de rejet s'affiche dans la langue de sortie de la session. Voir cette PR [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**Les suggestions de suivi restent en thaï, lao, khmer et birman.** Quand vous discutez dans l'une de ces langues, les suggestions de suivi se génèrent dans la même langue. Voir cette PR [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**L'intelligence de code expérimentale (LSP) s'active dans les paramètres.** Réglez `tools.lspEnabled` sur true dans les paramètres au niveau utilisateur : la fonction s'active sans option en ligne de commande, et les clients qui ne peuvent pas passer d'arguments, comme le bureau, profitent eux aussi du saut à la définition, de la recherche de références et des diagnostics. Désactivée par défaut. Voir cette PR [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**Le mode par défaut des sous-agents, premier plan ou arrière-plan, se règle globalement.** Réglez `agents.defaultBackground` sur false : les sous-agents attendent la fin de leur exécution et rendent le résultat dans le tour courant — adapté aux canaux et aux bots qui doivent obtenir le résultat en un seul tour. Un redémarrage est nécessaire. Voir cette PR [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**Les sessions gérées tiennent plusieurs questions à la fois.** Plusieurs questions posées par une session gérée coexistent : vous y répondez dans l'ordre que vous voulez. Voir cette PR [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**Les événements de canal ouvrent leur session.** Dans la chronologie des événements d'un canal, un clic sur une entrée saute directement à la session correspondante. Voir cette PR [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
