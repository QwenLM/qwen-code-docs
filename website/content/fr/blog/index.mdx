Le blog Qwen Code est organisé en quatre sections par parcours d'apprentissage. Commencez par le Démarrage pour apprendre les concepts fondamentaux, explorez les Cas d'utilisation pour des scénarios réels, passez à Avancé pour les fonctionnalités avancées, et suivez enfin les itérations produit hebdomadaires dans Mises à jour.

## Sections

### [Démarrage](/fr/blog/quickstart)

Découvrez les concepts fondamentaux de Qwen Code et commencez rapidement la programmation IA.

### [Cas d'utilisation](/fr/blog/cases)

Scénarios réels et tutoriels, de l'automatisation bureautique au développement de code.

### [Avancé](/fr/blog/advanced)

Guides avancés pour Skills, Bailian CLI, génération de couvertures WeChat, etc.

### [Mises à jour](/fr/blog/updates)

Versions hebdomadaires, nouvelles fonctionnalités et actualités communautaires.
