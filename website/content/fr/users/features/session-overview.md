# Vue d'ensemble des sessions

Utilisez la Vue d'ensemble des sessions dans Web Shell pour parcourir les sessions, revenir à une conversation et gérer les titres et archives de sessions.

## Rechercher et ouvrir des sessions

Ouvrez **More → Session Overview**. Recherchez par titre de session, ID de session, branche Git ou numéro de pull request liée, comme `#123`. Utilisez les filtres de statut pour réduire la liste. Lorsque plusieurs workspaces sont disponibles, le filtre de workspace vous permet de choisir lesquels inclure. Choisissez **Refresh** pour recharger le catalogue.

Cliquez sur une ligne de session pour ouvrir cette conversation. Utilisez les cases à cocher de la ligne pour sélectionner des sessions pour les actions du pied de page ; les contrôles de pagination modifient la page visible et le nombre de lignes.

## Renommer une session

Choisissez l'action crayon de la ligne lorsqu'elle est disponible, puis modifiez le titre. Appuyez sur **Enter** pour enregistrer ou **Escape** pour annuler. Si l'éditeur perd le focus, le renommage inachevé est annulé plutôt qu'enregistré.

## Archiver des sessions

Sélectionnez des sessions avec leurs cases à cocher de ligne, puis choisissez **Archive** dans le pied de page. L'action est activée uniquement lorsque chaque session sélectionnée est inactive et prend en charge l'archivage. Confirmez dans la boîte de dialogue pour archiver, ou choisissez **Cancel** pour laisser les sessions actives.

Si un éditeur de renommage a encore le focus lorsque vous cliquez sur **Archive**, son brouillon inachevé est annulé et la confirmation d'archivage s'ouvre. Saisir ou annuler un renommage maintient les contrôles du pied de page en place, donc les clics près du bord d'un bouton atteignent toujours ce bouton.
