## Criando o Skill: Qwen Code + Bailian CLI

O esquema inteiro usa só duas coisas.

**Qwen Code faz a orquestração do fluxo.** Eu simplesmente mando screenshots do site para o Qwen Code e digo que quero criar um Skill para gerar esse tipo de capa. Embora o qwen3.8-max não tenha capacidade multimodal, **o Qwen Code chama automaticamente o modelo de visão que já configurei** — por exemplo, o qwen3.6-plus — para reconhecer o conteúdo e gerar uma descrição para o qwen 3.8-max. Aí o 3.8 analisa e implementa. Muito prático. O Qwen Code analisa o conteúdo do screenshot, classifica o tipo de conteúdo — claro, eu também fiz algum trabalho manual aqui — e o 3.8-max monta o prompt.

![](https://gw.alicdn.com/imgextra/i4/O1CN01eeOy4R1jz6BcBI7mI_!!6000000004618-2-tps-2808-1486.png)

**Bailian CLI usa o modelo qwen-image para gerar a imagem no estilo correspondente**, e no final junta a imagem de fundo com o título numa página HTML interativa. Você abre a página e faz ajustes finos — título, fonte, logo, nitidez — e exporta com um clique.

No final, juntei os dois processos num Skill de produção estável.

## Geração de Capas: Quatro Estilos

O estilo é a parte em que mais investi nesse esquema. As capas da OpenAI parecem simples, mas de perto têm várias direções diferentes. Dividi em quatro categorias:

**Objeto real.** Macro de texturas. Madeira, couro, nervuras de folha, metal escovado, dunas, olhos compostos. Preenchimento total, sem espaço em branco. Ideal para conteúdo sobre produtos, artesanato, qualidade material.

**Difusão.** Aquarela monocromática em gradiente. Do claro ao escuro, transição dentro do mesmo matiz. Sensação de seda, de fosco, de ondulação na água. Ideal para conteúdo criativo, artístico, emocional.

**Feixe de luz.** Um feixe de luz, ou um reflexo curvo. O fundo é um tom mais claro ou mais escuro da mesma família de cores. Contido, preciso. Conteúdo de tecnologia combina perfeitamente com esse.

**Onda.** Ondulações suaves em aquarela. Feito para podcasts e conteúdo de conversa. A amplitude converge no centro da imagem, deixando uma faixa tranquila para o título.

Quatro estilos, sete paletas de cores (azul, verde, vermelho, roxo, laranja, preto, dourado), mais quatro proporções de tela. As combinações são muitas. Mas todas seguem a mesma regra: poucas cores, visual limpo sem impacto agressivo. O design da OpenAI é bom justamente pela contenção. Não quero estragar isso.

## Como Usar?

No Qwen Code, basta dizer "gere uma capa com base em @artigo".

Ele lê seu artigo e recomenda de 1 a 3 estilos. Você escolhe — pode selecionar vários. Cada estilo gera uma imagem de fundo, e no final você compara tudo na página. A paleta de cores vem dos presets. Sem improviso livre. Claro, você também pode especificar diretamente.

O Bailian CLI gera duas opções. Não gostou? Ajuste o prompt e rode de novo. Imagem definida, um comando monta o HTML. Ao abrir, você tem um editor:

- Clique no título na tela e edite o texto diretamente
- Cinco fontes para escolher: PingFang, Song, Hei, Noto Serif, Zanku
- Máscara, tamanho da fonte — arraste o slider
- Cor do texto: branco, preto, creme
- Envie um logo (opcional, se precisar de imagem em alta resolução)
- Exporte em 1x, @2x, @3x, ou pressione ⌘Enter

O que você vê é o que você tem. Renderização em Canvas, download direto em PNG.

Tomei algumas decisões de design importantes:

**A imagem de fundo não tem texto.** IA gerando imagem com texto em chinês só produz caracteres corrompidos. Então a imagem é só imagem, e o texto vai por cima via HTML. Essa é a base de todo o esquema.

**O tamanho da imagem é travado na proporção da tela.** Capa de artigo no WeChat: 900×383, proporção 2.35:1, então a imagem é gerada em 1344×572. Se a proporção estiver errada, o recorte na exportação destrói a composição.

**Ondas podem ter várias cores, mas precisam ser suaves.** Os outros três estilos são estritamente monocromáticos. Ondas permitem 2-3 matizes adjacentes, baixa saturação, como aquarela se espalhando. Cores saturadas em contraste, não.

**Prompts todos em inglês.** Prompts em chinês geram qualidade instável. Os templates são todos escritos em inglês.

**Não é só para WeChat**: a tela padrão é a capa de artigo do WeChat. Mas há presets para quadrado 1080×1080, paisagem 16:9 e retrato 3:4. Personalizado também funciona. O mesmo artigo pode gerar capa para WeChat, Xiaohongshu e vídeo, tudo de uma vez.

Como instalar o Skill? Basta dizer ao seu AI Agent:

```
Clone o repositório de https://github.com/joeytoday/open1v-skills, copie o diretório open1v-openai-cover para ~/.agents/skills/, verifique se o SKILL.md existe e depois delete o repositório clonado.
```
