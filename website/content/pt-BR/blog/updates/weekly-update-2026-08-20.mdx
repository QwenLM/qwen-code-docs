Esta semana o Qwen Code lançou três versões oficiais, da v0.21.12 à v0.21.14, com 140+ PRs integrados.

**Segunda opinião independente.** O `/advisor` faz uma revisão independente da conversa atual e devolve quatro itens: conclusões, riscos, evidências faltando e recomendações. Tudo somente leitura, sem tocar na conversa principal.

**Um comando mostra as sessões em execução.** O novo comando `qwen sessions ps` lista as sessões que estão rodando no computador: em qual diretório, há quanto tempo e o PID.

**Review interrompido não recomeça do zero.** Uma revisão de PR interrompida retoma com `--resume`: se o estado conferir, continua do ponto em que parou.

## ✨ Novidades

### /advisor: um modelo independente revisa a conversa atual

Quando a conversa se alonga, é fácil ficar preso numa linha de raciocínio só — os pontos cegos do próprio contexto passam despercebidos. O `/advisor` chama uma segunda opinião independente para a conversa atual: uma sessão paralela, somente leitura, lê todo o contexto e devolve quatro itens: conclusões, riscos, evidências faltando e recomendações. A segunda opinião é estritamente somente leitura: não altera a conversa principal nem executa nenhuma ação; depois da revisão, a conversa segue sem interferência.

Dá para direcionar a pergunta com uma preocupação específica, por exemplo `/advisor essa abordagem é segura?`; a configuração `advisorModel` permite escolher um modelo dedicado para a revisão — sem configurar, usa o modelo atual.

Veja o PR [#7567](https://github.com/QwenLM/qwen-code/pull/7567)

![Os quatro itens da revisão do /advisor](https://img.alicdn.com/imgextra/i4/O1CN01x6UkJeTG4kD7nOLI_!!6000000004249-2-tps-3840-2160.png)

### qwen sessions ps: um comando mostra as sessões rodando no computador

Com várias sessões do Qwen Code abertas ao mesmo tempo, é fácil perder o controle de qual é qual. O novo comando `qwen sessions ps` lista todas as sessões interativas em execução no computador, uma por linha: nome da sessão, PID, tempo de execução e diretório. Para integrar com scripts, adicione `--json` para saída em JSON.

A lista só mostra o que está rodando de verdade: fechou uma sessão, ela some da lista na hora.

Veja o PR [#8969](https://github.com/QwenLM/qwen-code/pull/8969)

![qwen sessions ps lista as sessões em execução](https://img.alicdn.com/imgextra/i1/O1CN01edM2ef0oKxI7nOLI_!!6000000005536-2-tps-3840-2160.png)

### Review: revisão de PR interrompida retoma, comentários em linguagem clara

O `/review` recebeu várias melhorias práticas esta semana.

**Revisão interrompida continua do ponto em que parou.** Revisando um PR grande, se o processo caísse no meio, antes era preciso recomeçar do zero. Agora o `qwen review fetch-pr` ganhou o `--resume`: primeiro confere o estado no disco — o relatório da última revisão, a árvore de trabalho e o diff sem mudanças, e o PR sem atualizações —; se tudo conferir, segue de onde parou; se qualquer item não bater, recomeça automaticamente.

**Comentários de revisão em linguagem clara.** Ao revisar um PR com o `/review` e postar comentários, antes o texto vinha cheio de fórmula; agora os comentários são escritos em linguagem natural de revisão: onde está o problema, quando ele aparece e como corrigir. Para os comentários postados no PR, dá para configurar tudo: se levam marcador de severidade e assinatura, a profundidade da análise e se devem ser postados.

**Revisão de scripts olha o ambiente de execução.** Arquivos como scripts de shell e configurações de CI têm aquele problema difícil de pegar: "neste computador funciona, mas em outro ambiente quebra". Agora a revisão primeiro identifica em que ambientes esses arquivos realmente rodam e verifica de acordo com as características deles.

Veja os PRs [#9092](https://github.com/QwenLM/qwen-code/pull/9092), [#9027](https://github.com/QwenLM/qwen-code/pull/9027), [#8994](https://github.com/QwenLM/qwen-code/pull/8994), [#9263](https://github.com/QwenLM/qwen-code/pull/9263)

### Web Shell: arraste arquivos locais direto para a conversa

Depois de configurar o token da conexão remota (`QWEN_SERVER_TOKEN` ou `--token`), arraste um arquivo para a caixa de entrada da conversa no Web Shell — ou copie e cole — e ele é enviado para o Qwen Code: qualquer arquivo vai parar no workspace, a conversa ganha uma referência automaticamente e a IA já pode usar; no caso de arquivos de texto, o conteúdo pode ser anexado direto na conversa, e a IA lê na hora, sem precisar abrir o arquivo.

Também dá para escolher em qual pasta o upload vai cair; se a pasta não existir, ela é criada automaticamente. Sem token configurado, arrastar ou colar arquivos na conversa ainda não é suportado.

Veja os PRs [#8874](https://github.com/QwenLM/qwen-code/pull/8874), [#9180](https://github.com/QwenLM/qwen-code/pull/9180), [#9382](https://github.com/QwenLM/qwen-code/pull/9382)

## 📊 Mais funcionalidades

**Agents de workflow fixados em um diretório.** Nos workflows, dá para usar `agent({workingDir})` para fixar o agent em um diretório específico, fora da restrição do diretório padrão. Veja o PR [#8972](https://github.com/QwenLM/qwen-code/pull/8972)

**Release notes com resumo bilíngue.** As notas de release deixaram de ser uma lista pura de PRs: agora são agrupadas por tema de funcionalidade, com um resumo em linguagem clara por grupo e versão em chinês; os screenshots de antes/depois que vêm nos PRs também acompanham. Veja o PR [#9216](https://github.com/QwenLM/qwen-code/pull/9216)

**Especificação única para conectar bases de conhecimento externas.** Fornecedores de serviços de busca podem desenvolver plugins do Qwen Code seguindo a especificação; depois de conectados, a IA consulta o corpus deles. O que pode ser consultado é decidido pelos plugins que você instalou — a IA busca só dentro desse escopo. Veja o PR [#9068](https://github.com/QwenLM/qwen-code/pull/9068)

## 👏 Melhorias de experiência

**Gerenciamento de Channels em página completa.** O gerenciamento de Channels do Web Shell virou um layout de página inteira, igual ao de tarefas agendadas: quem pode usar cada canal, se exige aprovação ou whitelist, como as sessões são divididas e a qual workspace ele se vincula — tudo configurado numa única página. Veja o PR [#8848](https://github.com/QwenLM/qwen-code/pull/8848)

**"Digitando" do WeChat não some em tarefas longas.** O status "digitando" do WeChat expira; antes, numa tarefa longa, o indicador sumia no meio do caminho, como se a conexão tivesse caído. Agora ele é renovado a cada 4 segundos enquanto a tarefa roda e só desaparece quando termina. Veja o PR [#9358](https://github.com/QwenLM/qwen-code/pull/9358)

**Modo compacto mostra o raciocínio da IA.** O modo compacto do Web Shell (Ctrl+O) escondia todo o conteúdo de raciocínio. Agora, enquanto o modelo pensa, o resumo exibe "pensando"; quando termina, o raciocínio é recolhido dentro do resumo de ferramentas — clique para expandir e ver. Veja o PR [#9148](https://github.com/QwenLM/qwen-code/pull/9148)

**Troca de sessões com a barra lateral recolhida.** Com a barra lateral do Web Shell recolhida, passe o mouse sobre o ícone do projeto para abrir o navegador completo de sessões; estados pendentes — aprovação, perguntas ou conclusão — aparecem indicados por cores no ícone. Veja o PR [#9311](https://github.com/QwenLM/qwen-code/pull/9311)

**Pré-visualização de imagens sobrevive ao refresh.** Imagens enviadas no Web Shell — estejam na fila ou já injetadas no meio da tarefa — mantêm a pré-visualização depois do refresh da página; várias imagens não são mescladas nem perdidas. Veja o PR [#9310](https://github.com/QwenLM/qwen-code/pull/9310)

**Envio de perguntas mesmo sem conexão.** A caixa de entrada do Web Shell foi desacoplada do estado da conexão: mesmo com o stream desconectado, dá para enviar perguntas normalmente — a caixa não fica mais travada. Veja o PR [#9323](https://github.com/QwenLM/qwen-code/pull/9323)

**HTML exportado com expandir/recolher de um clique.** A página HTML exportada pelo `/export` ganhou dois botões no topo, "expandir tudo / recolher tudo": blocos de raciocínio e saídas de ferramentas mudam de uma vez só. Veja o PR [#9367](https://github.com/QwenLM/qwen-code/pull/9367)

**Recuperação de sessões grandes mais rápida.** A recuperação de sessões pelo daemon agora lê sob demanda: só os registros necessários para reconstruir o estado. Sessões grandes sentem bastante a diferença. Veja o PR [#9055](https://github.com/QwenLM/qwen-code/pull/9055)

**Shells em segundo plano não são limpos por engano.** Shells rodando em segundo plano agora contam como tarefas ativas; durante a atividade, eles não são removidos pela limpeza automática. Veja o PR [#9042](https://github.com/QwenLM/qwen-code/pull/9042)
