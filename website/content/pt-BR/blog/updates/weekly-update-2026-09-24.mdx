O Qwen Code lançou quatro versões oficiais esta semana, v0.24.1 a v0.24.4, com 200 PRs integrados.

**Dá para saber qual arquivo encheu o contexto.** Você vê qual fechar e libera espaço de novo.

**Uma linha de SSH muda o projeto de outro computador.** O código está no servidor, na máquina de build ou no computador de um colega: você fica no seu e manda ele editar os arquivos de lá e rodar o build de lá.

**Workflow interrompido no meio continua depois de reiniciar.** Você aproveita o que já rodou, e um fluxo de várias horas precisa refazer só os pontos que falharam.

## ✨ Novidades

### Descubra qual arquivo ou qual extensão está comendo o contexto

O `/context` abre o contexto por origem — prompt do sistema, ferramentas embutidas, ferramentas MCP, arquivos de memória, habilidades e arquivos trazidos por extensões — e esta semana ganhou mais duas linhas, uma para o contexto de inicialização e outra para o prefixo de cache. Descendo no `/context detail`, você chega aos arquivos específicos; o que vem de extensão aparece marcado como `Extension: nome da extensão · nome do arquivo`, com o quanto cada um ocupa. Terminal e Web Shell mostram o mesmo.

**Ele avisa quando isso pesa demais.** Somando o contexto fixo (`QWEN.md` e memória automática), se o total passar do menor entre dois números — 15% da janela ou 10 mil tokens — você recebe um aviso no carregamento.

**Regra de extensão pode entrar em ação só quando o arquivo dela aparece.** O contexto é injetado apenas quando você acessa o arquivo correspondente; no resto do tempo ele não ocupa nada.

Na prática:

- O contexto está no limite e você quer ver logo quais arquivos e quais extensões estão ocupando
- Instalou uma extensão e o contexto subiu um degrau: abra `/context detail` e veja qual foi
- Ao receber o aviso de excesso, você sabe se vale enxugar o `QWEN.md` ou desligar a memória automática

Veja os PRs [#12119](https://github.com/QwenLM/qwen-code/pull/12119), [#12318](https://github.com/QwenLM/qwen-code/pull/12318), [#12034](https://github.com/QwenLM/qwen-code/pull/12034)

### Uma linha de SSH e você edita o projeto de outro computador

O projeto mora num servidor, numa máquina de build ou no computador de um colega, e você quer que o Qwen Code mexa nele. Antes era preciso instalar o Qwen Code naquela máquina, subir o serviço por lá e só então preencher o endereço. Agora, ao adicionar um workspace no Web Shell, você escreve um endereço SSH direto no campo de caminho:

```text
ssh://user@host/absolute/project
```

Se o Qwen Code não está instalado lá, preencha esse endereço para registrar a máquina. Se por lá já roda um serviço do Qwen Code, salve endereço e token uma vez e, das próximas vezes, basta selecionar esse workspace ao adicionar. Depois de registrado, ler e escrever os arquivos de lá, rodar comandos de lá e ver o estado do Git acontecem na mesma conversa, na sua máquina. O workspace recém-adicionado abre somente para leitura: ele passa a editar arquivos depois que você autorizar "Confiar".

Na prática:

- Código e dependências estão na máquina de build, e você edita os arquivos de lá e roda o build de lá da conversa local
- Aproveite o ambiente pronto de outra máquina para validar uma vez
- Deixe o projeto local e o remoto abertos ao mesmo tempo e vá mexendo nos dois numa conversa só

Veja os PRs [#12255](https://github.com/QwenLM/qwen-code/pull/12255), [#12085](https://github.com/QwenLM/qwen-code/pull/12085), [#12412](https://github.com/QwenLM/qwen-code/pull/12412)

### Workflow interrompido no meio continua depois de reiniciar

Se um fluxo roda até a metade e você fecha o dia, ou se a máquina reinicia no meio do caminho, antes sobrava recomeçar tudo. Agora cada execução deixa registro, e a próxima continua de onde parou.

**Ele avisa assim que você reabre.** Ao abrir o Qwen Code, o aviso de inicialização lista qual execução foi interrompida, em qual passo ela parou e quantos subagentes já terminaram, e manda você olhar em `/workflows`. Todas essas execuções entram na lista de histórico.

**Os cartões de execução do histórico do Web Shell ganharam botões.** "Tentar novamente o trecho com falha" refaz só o que não terminou; "Rodar tudo novamente" recomeça do zero.

Na prática:

- Pare no meio do expediente e, amanhã, veja primeiro em que passo ele parou
- Num fluxo longo em que só dois subagentes falharam, refaz essas duas partes com "Tentar novamente o trecho com falha"
- Quer validar o mesmo fluxo outra vez desde o começo? Clique em "Rodar tudo novamente"

Veja os PRs [#12159](https://github.com/QwenLM/qwen-code/pull/12159), [#12291](https://github.com/QwenLM/qwen-code/pull/12291), [#12097](https://github.com/QwenLM/qwen-code/pull/12097)

### Web Shell: diff na aprovação, logs dobrados, aba Trajectory e histórico do Git

**Você vê a mudança antes de aprovar.** Toda alteração de arquivo que pede confirmação já lista no cartão de aprovação quais linhas entraram e quais saíram. Isso vale nos três casos: editar um arquivo, criar um arquivo e mexer num notebook. Veja o PR [#12443](https://github.com/QwenLM/qwen-code/pull/12443)

**Colar um log enorme vira um cartão dobrado.** Passou de 200 linhas ou 8 mil caracteres, o conteúdo é dobrado e o título vem do começo do texto; para abrir, use "Mostrar na caixa de entrada" e ele volta para a caixa. Ficam de fora: colagens que começam com `/` ou `!`, colagens curtas e conteúdo que substitui um texto selecionado. Veja o PR [#12084](https://github.com/QwenLM/qwen-code/pull/12084)

**Dá para adicionar a aba Trajectory no painel direito.** Depois de uma rodada que pareceu lenta ou cara, abra essa aba e veja onde o tempo foi: quanto cada rodada levou, quanto demorou o primeiro caractere, quantos tokens ela comeu e qual chamada de ferramenta pesou mais. Fica em "Adicionar aba", na área de extensões à direita, onde você escolhe Trajectory. Veja o PR [#12388](https://github.com/QwenLM/qwen-code/pull/12388)

**O histórico do Git ficou mais fácil de achar.** No Web Shell, o histórico de commits aparece num grafo de branches, dá para alternar entre todos os branches e buscar por mensagem de commit, autor ou hash. Endereços de repositório remoto também se adicionam e removem pela interface, sem abrir o terminal para digitar comando. Tudo fica na aba de branch, acima da caixa de entrada. Veja os PRs [#12152](https://github.com/QwenLM/qwen-code/pull/12152), [#11163](https://github.com/QwenLM/qwen-code/pull/11163)

**Outras melhorias.** O interruptor do modo de planejamento saiu da barra da caixa de entrada e foi para o menu "+", e com ele ligado fica uma etiqueta acima da caixa, que você pode fechar ([#12218](https://github.com/QwenLM/qwen-code/pull/12218)). Os arquivos gerados por `/export` viram um cartão na conversa, com prévia e download ([#12050](https://github.com/QwenLM/qwen-code/pull/12050)).

## 📊 Mais funcionalidades

**O Web Shell pode virar um app no seu computador.** Apareceu a opção de instalar à direita da barra de endereços: um clique e ele ganha ícone próprio e janela independente, igual a um app instalado da loja. Requer Chrome / Edge 111 ou mais novo, Firefox 128 ou mais novo, Safari 16.4 ou mais novo, e o endereço precisa ser local (`127.0.0.1` ou `localhost`) ou HTTPS — acessando por IP da rede local, não instala. Veja o PR [#11722](https://github.com/QwenLM/qwen-code/pull/11722)

**Dá para ajustar o tamanho do texto no desktop.** Aperte `Cmd` / `Ctrl` com `-`, `=` ou `0`, ou faça o gesto de pinça com dois dedos no trackpad. A escala vai de 50% a 300%, e na próxima abertura ela continua onde você deixou. Veja o PR [#12410](https://github.com/QwenLM/qwen-code/pull/12410)

**A cota do Goal aparece acima da caixa de entrada.** Aquela barra de status, que já mostrava o orçamento de tokens, agora também mostra os limites de rodadas e de tempo, em algo como `3 / 20 turns` e `12m 3s / 30m 0s`; Goal sem limite continua como estava. O histórico exportado por `/export` também passa a levar o percurso inteiro do Goal. Veja os PRs [#12201](https://github.com/QwenLM/qwen-code/pull/12201), [#12099](https://github.com/QwenLM/qwen-code/pull/12099)

**Para o Goal dizer que terminou, ele precisa provar na conversa.** Rodando com `/goal`, não basta ele afirmar que está pronto: a checagem relê o que de fato aconteceu nas últimas rodadas da conversa e, se não bater, considera não concluído. Veja o PR [#12105](https://github.com/QwenLM/qwen-code/pull/12105)

**Os subagentes podem trabalhar trancados num container.** Você manda varrer o repositório inteiro e rodar um monte de comando sem medo de ele achar sua chave SSH e suas credenciais na pasta pessoal: cada comando e cada leitura ou escrita acontecem dentro de um container Docker ou Podman, e o único lugar que ele consegue alterar é o workspace. Para rodar assim, defina `QWEN_AGENT_EXECUTION_BACKEND=docker` antes de iniciar. O preço é que workflows, Agent Team, MCP, LSP e habilidades ficam desligados junto, e o Windows ainda não é suportado. Veja o PR [#11711](https://github.com/QwenLM/qwen-code/pull/11711)

**Um provedor só pode misturar as duas interfaces.** Para mandar um modelo específico pela interface OpenAI Responses, acrescente `"wireApi": "responses"` na entrada daquele modelo e pronto; os demais continuam pelo Chat. Ao configurar um provedor personalizado pelo `/auth`, existe um passo opcional para escolher o formato da API. Veja o PR [#11538](https://github.com/QwenLM/qwen-code/pull/11538)

## 👏 Melhorias de experiência

**O Web Shell no celular melhorou.** Quando o serviço escuta num endereço externo, a página da sessão mostra um QR de pareamento no canto superior direito: o celular escaneia e entra direto na sessão atual, sem digitar token. Já na tela do celular, a caixa de entrada foi reorganizada, com mais de uma dúzia de ações guardadas na gaveta "Adicionar à mensagem". Veja os PRs [#12322](https://github.com/QwenLM/qwen-code/pull/12322), [#12252](https://github.com/QwenLM/qwen-code/pull/12252)

**Menos coisa na caixa de entrada.** Antes da sessão existir, a seleção de workspace e a etiqueta de branch do Git saíram da barra da caixa e ganharam uma linha própria embaixo. Com a sessão aberta, o workspace aparece só como um ícone de pasta no topo, e o caminho inteiro aparece ao passar o mouse. Os cartões de resultado que apontam para links agora abrem numa página nova. Veja os PRs [#12299](https://github.com/QwenLM/qwen-code/pull/12299), [#12317](https://github.com/QwenLM/qwen-code/pull/12317)

**O `/compress` diz o que aconteceu.** Depois de comprimir, aparece "Contexto comprimido: X → Y"; quando não há nada a comprimir, ele diz "Nada a comprimir."; e, depois de reabrir a sessão, o número no anel de contexto já vem atualizado. Veja o PR [#12141](https://github.com/QwenLM/qwen-code/pull/12141)

**A reconexão automática do Channel funciona em todos os workspaces.** Quando um único `qwen serve` atende vários workspaces, cada um com seu bot de Channel, ao subir o serviço ele agora religa o Channel de cada workspace confiável. Ou seja: depois de salvar, a opção "Conectar automaticamente ao iniciar o Qwen Code" vale de verdade. Veja o PR [#12385](https://github.com/QwenLM/qwen-code/pull/12385)

**No Linux, o sandbox agora só cerca a execução das ferramentas.** A configuração da semana passada, que trancava o Qwen Code inteiro no bwrap, nesta versão retorna erro e uma frase de migração: troque para `tools.executionSandbox` e ficam restritos só os comandos de shell e as leituras e escritas de arquivo. O Qwen Code em si, as chamadas de modelo e o seu login continuam na sua máquina. Veja o PR [#12267](https://github.com/QwenLM/qwen-code/pull/12267)

**Chamada única em script ficou mais rápida.** No uso de `qwen -p`, que roda uma frase e sai, o tempo caiu de 7,7 para 5,1 segundos no teste real e a memória, de 640 MiB para 421 MiB — um processo a menos. Veja o PR [#12340](https://github.com/QwenLM/qwen-code/pull/12340)

**Quando o QR não aparece no terminal, ele explica por quê.** Você apontou o serviço para um endereço externo e quer que o celular entre escaneando: se o QR não sair, aparece o motivo, junto de um QR só com o endereço — abra no celular e digite o token uma vez para conectar. Para forçar a saída do QR com o token dentro, use `qwen serve --token-qr`. Veja o PR [#12266](https://github.com/QwenLM/qwen-code/pull/12266)
