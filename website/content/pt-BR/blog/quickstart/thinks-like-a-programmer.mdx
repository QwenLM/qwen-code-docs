Se a IA vai mudar o mundo, o primeiro passo é transformar o mundo digital. O Qwen Code não é apenas uma ferramenta de linha de comando; é um companheiro programador que você pode invocar do seu terminal a qualquer momento.

No último ano, o paradigma da programação com IA mudou dramaticamente. Do modo Chat inicial ao modo de conclusão do Copilot, e agora ao modo Agente autônomo de hoje. Hoje, temos o prazer de apresentar o **Qwen Code**, uma ferramenta de programação com IA desenvolvida pelo Alibaba Tongyi Lab.

É de código aberto, gratuito e impulsionado pelo robusto modelo **Qwen3-Coder**. Ele não apenas pode escrever código por meio de interações conversacionais no terminal para dar vida instantânea às suas inspirações, mas também se integra profundamente ao seu fluxo de desenvolvimento para corrigir bugs, refatorar código e lidar com tarefas complexas com facilidade. Além disso, é um companheiro versátil que pode escrever artigos, desenhar gráficos e se misturar perfeitamente ao seu trabalho diário.

Concluímos o site de apresentação do produto Qwen Code simplesmente através de conversa. Ao longo de todo o processo, o Qwen Code pensa e age como um programador de verdade:

- **Decompor tarefas**: Cria uma lista de tarefas abrangente.
- **Escrever código**: Lê/escreve arquivos automaticamente e executa scripts.
- **Autocorreção**: Depura automaticamente quando encontra erros.
- **Entregar resultados**: Entrega não apenas código, mas aplicativos Web completos ou documentação.

Você não precisa mais guiá-lo passo a passo com instruções como "escreva esta função" ou "mude aquela variável". Ele não é mais uma ferramenta que requer manuais extensos; é um verdadeiro parceiro de codificação, autônomo e eficiente.

## Por que escolher o Qwen Code?

### 1. Núcleo poderoso: Impulsionado pelo Qwen3-Coder

O Qwen Code é construído sobre o poderoso modelo **Qwen3-Coder** e é profundamente otimizado para ele. Durante a fase de treinamento, permitimos que o modelo entendesse ferramentas, e o framework foi adaptado ao modelo. Ele demonstra capacidades excepcionais em geração de código, raciocínio e compreensão de contextos longos.

![](https://img.alicdn.com/imgextra/i3/O1CN01ypIjmp1jcekDsqfLl_!!6000000004569-2-tps-3184-1817.png)

### 2. Verdadeiro Agentic Workflow

O Qwen Code apresenta recursos avançados como **Skills**, **SubAgents** e **Plan Mode**, tornando o Agente mais autônomo e confiável. O Modo de Aprovação garante a segurança do trabalho permitindo confirmação passo a passo, ou você pode habilitar o **Modo YOLO** para permitir que a IA opere com total autonomia.

![](https://img.alicdn.com/imgextra/i1/O1CN01ZBzNFo1C9SAiM2mXk_!!6000000000038-2-tps-2020-1078.png)

### 3. Cobertura completa de cenários: Onde você precisar

Embora o Qwen Code tenha nascido no terminal, ele não é limitado por ele. É pequeno o suficiente, mas também poderoso o suficiente para existir em cinco ambientes distintos:

- **Ambiente Terminal**: A escolha dos geeks. Inicie-o no seu Terminal para codificação e criatividade em uma interface interativa elegante.
- **Ambiente IDE**: A escolha preferida da maioria dos desenvolvedores. Suporta editores populares como VS Code, Qoder, Zed e JetBrains, oferecendo tanto a conveniência da GUI quanto o poder do CodeAgent.
- **Ambiente CI/CD**: Use `qwen -p` para iniciar o **Modo Headless**. Você pode mencionar @QwenCode no GitHub Actions para fazê-lo responder automaticamente a issues, revisar código ou enviar PRs.
- **Ambiente do Navegador**: Um recurso experimental que integra o Qwen Code em uma extensão de navegador, permitindo que ele perceba o estado de páginas web e analise parâmetros – um ótimo auxiliar para depuração e coleta de dados.
- **Ambiente de Programação**: Use o SDK do Qwen Code para trazer capacidades de codificação inteligente para seu próprio ambiente, atualmente com suporte para Node.js e Java.

![](https://img.alicdn.com/imgextra/i2/O1CN01MC7wCV1nQz7FKy6Sz_!!6000000005085-2-tps-2880-1536.png)

### 4. Compromisso com código aberto e acesso gratuito

Estamos comprometidos com uma estratégia de código aberto e gratuita. Nesta era de rápida iteração de codificação com IA, acreditamos que o código aberto proporciona tranquilidade e o acesso gratuito incentiva os usuários a explorar mais possibilidades.

- **Uso gratuito**: Faça login via Qwen OAuth para desfrutar de uma cota diária de 2.000 solicitações gratuitas.
- **Compatibilidade de protocolos**: Como um projeto de código aberto, somos compatíveis com protocolos populares como Anthropic, Google Gemini e OpenAI.

## Comece agora

O Qwen Code agora é totalmente de código aberto no GitHub com 17,4k stars. Comece em três passos simples:

1. **Instalar** (requer Node.js 20+):
   ```bash
   npm install -g @qwen-code/qwen-code@latest
   ```
2. **Iniciar**:
   ```bash
   qwen
   ```
3. **Autenticar**:
   Digite `/auth` na sessão e selecione **Qwen OAuth** para começar sua jornada de programação com IA.
