## Instalar o Qwen Code

O Qwen Code suporta instalação por script com um clique, cobrindo Windows, macOS e Linux.

**macOS / Linux：**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows（PowerShell）：**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

Após a instalação, execute `qwen --version` para confirmar que foi bem-sucedida. Se preferir instalar via npm:

```bash
npm i @qwen-code/qwen-code@latest -g
```

## Configurar o Provedor de Modelo

Após a instalação, o Qwen Code guia você a conectar um provedor de modelo. Recomendamos a plataforma Alibaba Cloud Bailian.

1. Acesse [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key) para obter sua API Key
2. Execute `qwen` no terminal para iniciar, selecione Alibaba ModelStudio
3. Cole sua API Key e selecione o modelo

Se preferir configurar manualmente, edite `~/.qwen/settings.json`:

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "你的API-KEY"
  }
}
```

Após a configuração, use o comando `/model` para visualizar e alternar entre modelos:

## Iniciar a Primeira Conversa

Entre no diretório do seu projeto e inicie o Qwen Code:

```bash
cd your-project && qwen
```

Descreva o que você quer fazer em linguagem natural. Por exemplo:

```
Escreva uma função Python que calcule a sequência de Fibonacci
```

Ou peça à IA para organizar seus arquivos:

```
Organize os arquivos desta pasta em subpastas por tipo
```

O Qwen Code decompõe a tarefa automaticamente, executa as operações e retorna o resultado. Você não precisa ensinar passo a passo, basta descrever o objetivo.

## Instalar Extensões de Skills

Skills é o sistema de extensão de capacidades do Qwen Code. Você pode instalar Skills desenvolvidas pela comunidade conforme necessário, dando à IA mais capacidades profissionais.

Instalar uma Skill é simples, basta um comando:

```
Ajude-me a instalar find-skills
```

Ou use o comando diretamente:

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

Após a instalação, use `/skills` para ver as Skills instaladas.

## Integração com VS Code

Se você prefere trabalhar no editor, o Qwen Code oferece uma extensão para VS Code. Pesquise "Qwen Code" na loja de extensões e instale. Após a instalação, você pode conversar com a IA diretamente na barra lateral, com uma experiência de programação sem interrupções.
