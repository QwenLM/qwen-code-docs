# Visão geral da sessão

Use a Visão Geral da Sessão no Web Shell para navegar pelas sessões, retornar a uma conversa e gerenciar títulos e arquivos de sessões.

## Encontrar e abrir sessões

Abra **More → Session Overview**. Pesquise por título da sessão, ID da sessão, branch do Git ou número do pull request vinculado, como `#123`. Use os filtros de status para reduzir a lista. Quando múltiplos workspaces estiverem disponíveis, o filtro de workspace permite escolher quais incluir. Escolha **Refresh** para recarregar o catálogo.

Clique em uma linha de sessão para abrir aquela conversa. Use as caixas de seleção da linha para selecionar sessões para as ações do rodapé; os controles de paginação alteram a página visível e o número de linhas.

## Renomear uma sessão

Escolha a ação de lápis da linha quando estiver disponível e edite o título. Pressione **Enter** para salvar ou **Escape** para cancelar. Se o editor perder o foco, o renomeamento não concluído é cancelado em vez de salvo.

## Arquivar sessões

Selecione sessões com as caixas de seleção da linha e escolha **Archive** no rodapé. A ação é habilitada apenas quando todas as sessões selecionadas estão ociosas e suportam arquivamento. Confirme no diálogo para arquivar ou escolha **Cancel** para deixar as sessões ativas.

Se um editor de renomeação ainda tiver foco quando você clicar em **Archive**, seu rascunho não concluído é cancelado e a confirmação de arquivamento é aberta. Entrar ou cancelar uma renomeação mantém os controles do rodapé no lugar, então cliques perto da borda de um botão ainda atingem esse botão.
