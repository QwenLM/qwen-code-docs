# MCP 管理运行时模型

MCP 配置是持久的权威来源。每个 CLI 或 Web 会话继续拥有独立的 MCP 运行时，
因此 CLI 不依赖工作空间管理进程。

Web 管理页面可以创建一个可选的管理运行时，用于状态和管理操作。改变配置
的操作先持久化，然后在同一 ACP 进程内调和每个实时运行时。后续会话正常
加载已持久化的配置。

管理状态从管理运行时的客户端管理器读取，而不是从进程范围的兼容性状态
映射读取。兼容性映射对现有 CLI 消费者保持不变。共享池重连重启池条目；
非池化重连在每个实时运行时中重新发现服务器。

服务器 provenance 保持区分：用户 settings、工作空间 settings、项目
`.mcp.json` 和扩展。禁用项目或工作空间服务器会将排除项写入工作空间本地
settings，而不修改共享的项目文件。
