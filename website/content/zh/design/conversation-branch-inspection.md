# 会话分支检查

## 动机

Session JSONL 文件已经通过 `uuid` 和 `parentUuid` 构成一棵树，但 resume 目前只重建一条被物理选中的尾部。因此，当多个写入者向同一会话追加，或一次回退创建了第二个分支时，重启可能隐藏有效的兄弟历史。

本改动添加一个只读的拓扑检查器。它识别每一个语义叶子，描述其与显式回退记录的关系，并产生一个小巧、确定性的摘要。它不决定哪个分支是活动的。

## 边界

该检查器接受内存中的 `ChatRecord` 值，没有文件系统、会话服务、模型或写入者依赖。现有的 resume、fork、转录分页、守护进程、ACP 和 CLI 行为保持不变。

选定分支的重建继续使用带显式 `leafUuid` 的 `buildOrderedUuidChain`。后续的写入侧改动必须获取一个独占、稳定的转录快照，让用户或持久策略从报告出的叶子中选择一个，持久化该选择，并为恢复的写入者播种。这些归属操作都不属于检查器。

Claude Code 有一个全叶子转录读取器用于分析，而其常规 resume 路径仍选择最新的非 sidechain 叶子。Qwen 不能安全地使用该选择规则：一条显式回退证明了结构关系，但在多写入者转录中，它不能证明每个兄弟都是被有意放弃的。

## 语义叶子

一个 UUID 的第一条物理记录定义其父节点，与现有链遍历器一致。冲突的重复父节点会被诊断，而不是猜测。

原始终结记录使用一个刻意很小的中性尾部允许列表进行归一化：`custom_title`、`session_artifact_event` 和 `session_artifact_snapshot`。这些记录可以追加在会话尾部旁边或之后，而不创建一个独立的可恢复会话。它们的终结连续段坍缩到其最近的已知非中性祖先。如果不存在这样的祖先，仅元数据的连续段会被省略，因为它不是一个可重建的会话分支。坍缩的候选先去重，然后移除任何作为另一个候选严格祖先的候选。结果是语义叶子的一个反链。

所有其他系统记录保持有意义。特别是回退、压缩、归属和文件历史记录可能携带恢复状态，不能仅因为它们没有用户可见文本就被丢弃。

缺失的父节点让链停在可达的尾部岛屿。父节点成环会被报告并加以限制。读取侧绝不重新连接缺失的历史，也不给分支标上活动或已放弃。

## 摘要与回退关系

摘要是本地且确定性的。它们包括最近的分支点、消息数、时间戳、分支点之后的第一条真实用户文本，以及最新的真实用户和非思考助手文本。通知、cron 和轮中用户记录不被当作用户 prompt。文本做空白归一化并截断；工具参数和非文本部分被忽略。`updatedAt` 使用最后一条归一化进语义叶子的物理终结记录的时间戳，这样中性元数据活动不会丢失。

当一个分支的路径包含一条回退记录时，它是回退后代。当其路径与通往某条回退记录的路径分叉时，它是回退兄弟。这些只是结构标签，绝不意味着兄弟已过时。
