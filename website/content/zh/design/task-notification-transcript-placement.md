# 任务通知的转录放置位置

后台任务完成是模型输入，而不是用户撰写的 prompt。实时的 daemon 路径已经
用 `_meta.source = "background_notification"` 标识它们，但历史重放之前会
把持久化的通知记录投影为未标记的用户消息。

历史重放将保留持久化的模型输入角色，同时添加与实时通知相同的来源标记。
Web Shell 转录适配器会把该来源（无论来自 user 还是 assistant 块）映射为
一条信息性的系统消息。新记录还会持久化现有的结构化任务状态，使实时和重
放的消息使用相同的已完成、失败或已取消标签；较旧的记录回退到通用的通
知标签。通知内容在语义化状态图标旁原样渲染。这使实时和重放的通知都保
持显示在左侧，而不改变面向其他消费者的共享重放语义。
