# Web Shell AskUserQuestion 提交重试

## 问题

`AskUserQuestion` 在点击决策后立即锁定，但其回调不暴露异步权限结果。因此，
失败的请求会留下一个看似启用的面板，悄悄忽略重试。当权限载荷没有
`allow_once` 选项时，提交路径也会悄悄返回。

## 设计

- 给 `AskUserQuestion` 一个返回 promise 的确认回调，以及一个由其所属对话面
  提供的错误报告器。
- 在请求在途期间，禁用动作并显示提交中指示器。
- 成功接受的决策保持锁定，直到权限事件移除面板。这也覆盖了已记录但尚未最终
  确定的共识投票。
- 在被拒绝或结果为 `false` 时，报告错误并解锁动作，让用户可以重试。
- 缺失 `allow_once` 选项时立即报告，而不是悄悄返回。
