# Daemon 工作空间运行时移除

## 背景

运行时工作空间注册和持久化注册已经可用，但遗忘持久化注册并不会卸载存活的 bridge、ACP 挂载、会话准入状态或内存 lane。本设计为次级运行时添加同步热移除，同时保留现有的注册遗忘 API。

## 范围与不变量

- 只有动态注册的和从持久化恢复的次级运行时可以被移除。主运行时和所有 `--workspace` 运行时都是静态的。
- `DELETE /workspaces/:workspace` 会移除运行时及其所有已知的持久化别名。它绝不删除工作空间文件、设置、transcript、归档或其他项目数据。
- 非强制移除是观察性的：如果冻结的运行时存在活动，所有门控都会回滚，请求返回 `409 workspace_busy`。强制移除会终止该活动。
- 持久化在破坏性清理之前提交。存储失败会恢复活跃的运行时。存储提交之后的清理失败无法回滚该操作，并使用同步 bridge kill 作为兜底。
- 被移除的 cwd 在清理完成之前保持预留，之后可以用全新的 bridge、ACP dispatcher、连接注册表和内存 lane 重新注册。

## 协议

生产 daemon 在移除控制器已安装时宣告 `workspace_runtime_removal`。能力中的工作空间行新增可选的 `removable`；旧客户端和旧 daemon 保持兼容。

`DELETE /workspaces/:workspace` 使用现有的 workspace-id-or-canonical-cwd 选择器，并接受一个可选的 JSON body，其中包含布尔值 `force`。成功时返回被移除的身份、是否请求了强制、是否移除了任何持久化别名，以及排空后的最终活动快照。已经可观察到忙碌的非强制请求可以直接返回较早的排空前快照，而无需短暂地对运行时进行门控。现有的 `DELETE /workspace-registrations/:id` 仍然只做遗忘。

## 生命周期

注册表跟踪活跃、排空中和已移除的运行时。公共解析只能看到活跃的运行时；管理解析保留排空中的运行时以用于冲突报告和 cwd 预留。

移除首先获取一个快速活动快照。然后同步地将注册表标记为排空中、关闭每个工作空间的会话准入，并排空 ACP 挂载和内存 lane。最终快照在读取存活 bridge 计数之前先读取待处理的会话预留，这样预留到会话的转换不会表现为空闲。忙碌的非强制请求会反转门控。否则，所有已知的注册 ID 会被原子地删除，排队中的内存工作会被置为失败，子会话启动器和 bridge 会被停止，ACP 挂载会被销毁，所有权索引会被清除，注册表条目会被完结。

运行时清理按运行时身份而不是按 cwd 进行记忆化，因此之后注册在同一路径上的运行时不会复用旧的清理 promise。Daemon 关闭时会封存管理操作、等待它们收敛、停止启动器，然后对其余受管理的运行时使用相同的 bridge 拆除路径。

## 持久化身份

恢复会在规范化之前记录每个原始存储路径的 ID。解析到同一运行时的多个原始别名会作为一个 ID 集合保留，包括被显式启动工作空间遮蔽的别名。移除会在一个存储锁下删除该集合以及规范化的注册 ID，且不改变 schema。

## UI

Web Shell 仅在特性标签和 `removable: true` 同时存在时才暴露移除。该操作对不受信任的工作空间保持可用。第一次确认执行非强制请求；`workspace_busy` 会渲染活动计数并提供强制移除选项。当前会话属于目标工作空间时，强制选项被禁用。成功时会协调能力和会话列表，并在必要时回退到主工作空间。

## 失败与兼容性分析

客户端断开和 SDK 超时不会取消服务端的清理。并发的添加、持久化提升和移除操作按规范化 cwd 串行化。关闭时以 `daemon_shutting_down` 拒绝新的管理操作，并等待已开始的工作。旧客户端会忽略可选的能力字段和特性；旧 daemon 对缺失的路由继续产生普通的 `DaemonHttpError`。

工作空间作用域的 channel worker 组通过一个薄适配器提供活动和拆除。排空会阻止目标工作空间的 reload 和 webhook 路由；已提交的移除只停止并注销该 worker，使 daemon 状态和 pidfile 元数据收敛，而不影响其他工作空间。

## 验证

单元测试覆盖目标包括注册表状态转换和所有者清理、准入排空回滚、别名批量删除、busy/force/存储失败的路由行为、bridge 关闭原因幂等性、内存 lane 取消、SDK 请求编码，以及 Web Shell 特性与强制守卫。E2E 计划位于 `.qwen/e2e-tests/workspace-runtime-removal.md`。
