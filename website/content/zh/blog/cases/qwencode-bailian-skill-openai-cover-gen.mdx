## 创建技能：Qwen Code + 百炼 CLI

整个方案就两样东西。

**Qwen Code 做流程编排**。我直接给 Qwen Code 截图网站的内容，并告诉它我想要做个生成此类封面的技能，虽然 qwen3.8-max 并没有多模态能力，**Qwen Code 会自己调用我已经配置的视觉模型**，比如 qwen3.6-plus，识别内容并生成描述给 qwen 3.8-max，然后 3.8 会开始分析和实现，非常便捷。Qwen Code 会分析截图的内容，判断内容的分类，当然我自己也做了一些工作，然后 3.8-max 组装提示词。

![](https://gw.alicdn.com/imgextra/i4/O1CN01eeOy4R1jz6BcBI7mI_!!6000000004618-2-tps-2808-1486.png)

**百炼 CLI 使用 qwen-image 模型生成对应风格的图片**，最后把底图和标题拼成一个可交互的 HTML 页面。你可以打开页面进行微调，比如标题、字体、logo、清晰度自定义导出。

最后把两个过程组装成可稳定生产的 skills。

## 封面生成：四种风格

风格是这套方案里我最花心思的部分。OpenAI 的封面看着简单，细看其实有好几条路线。我拆成了四类：

**实物**。材质微距。木纹、皮革、叶脉、金属拉丝、沙丘、复眼。满铺，没有留白。适合讲产品、讲手艺、讲质感。

**晕染**。单色水彩渐变。从浅到深，同一个色相里过渡。丝绸感，磨砂感，水波纹。适合创意、艺术、情绪向的内容。

**光束弧影**。一道光束，或一个弧面反光。背景是同色系的深或浅。克制，精密。科技内容用这个最对味。

**波形**。柔和水彩波纹。给播客和对话类内容做的。波幅在画面中间收敛，留一条安静区域放标题。

四种风格，七种色系（蓝、绿、红、紫、橙、黑、金），再加上四种画布比例。排列组合下来，选择空间很大。但每一种都守着同一条线：颜色不过多，视觉干净不冲击。OpenAI 那套设计的好，好在克制。我不想破坏它。

## 如何使用？

在 Qwen Code 里说一句"根据 @文章 帮我生成封面" 。

它读你的文章，推荐 1-3 个风格。你选，可以多选。每个风格各出一张底图，最后在页面上切换对比。色系从预设里选。不自由发挥。当然你也可以直接指定。

百炼 CLI 跑两张备选。不满意，调提示词重跑。图定了，一条命令组装成 HTML。打开就是一个编辑器：

- 点画布上的标题，直接改字
- 五种字体点选：PingFang、宋体、黑体、Noto Serif、站酷
- 遮罩、字号，滑杆拖
- 文字颜色：白、黑、米
- 传 Logo（可选，如果你需要高清图的话）
- 导出选 1x、@2x、@3x，或按 ⌘Enter

所见即所得。Canvas 渲染，直接下载 PNG。

我做了几个关键设计决定：

**底图不带字。** AI 生图写中文，出来全是乱码。所以图片归图片，文字用 HTML 叠。这是整个方案的地基。

**生图尺寸跟画布比例锁死。** 公众号首图 900×383，比例 2.35:1，生图就用 1344×572。比例不对，导出裁切，构图全废。

**波形可以多色，但必须柔。** 其他三种严格单色。波形允许 2-3 个相邻色相，低饱和，像水彩晕开。高饱和撞色不行。

**提示词全英文。** 中文提示词出图质量不稳。模板都是英文写的。

**不限于公众号**：默认画布是公众号首图。但预设了正方形 1080×1080、横版 16:9、竖版 3:4。自定义也行。同一篇文章，公众号封面、小红书封面、视频封面，可以一起出。

怎么安装技能？你可以直接跟你的 AI Agent 说：

```
从 https://github.com/joeytoday/open1v-skills 克隆仓库，把 open1v-openai-cover 目录复制到 ~/.agents/skills/，验证 SKILL.md 存在后删除克隆的仓库。
```
