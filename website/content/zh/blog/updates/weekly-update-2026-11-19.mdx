Qwen Code 本周发布 v0.27.3～v0.28.0 三个正式版本。

**新旗舰 Qwen4-Max 可用。** 通义千问新一代旗舰模型，最新 Qwen Code 已接入。

**新会话默认在独立副本里干活。** 同一个项目开几个会话并行，各改各的工作树，你手上的分支和文件不受影响。

**任务结果直发飞书、企业微信、钉钉群。** 群里加一个自定义机器人，把 webhook 地址填进 Web Shell，通知和定时任务结果就发到群里。

## ✨ 新增特性

### 新旗舰 Qwen4-Max 可用

Qwen4-Max 是通义千问新一代旗舰模型：11 月 16 日正式版上架，文本、图像、视频都能处理，面向复杂推理、编程和智能体任务。

Qwen Code 在本周完成了接入。无论你是通过百炼、千问 AI 平台或Qwen 订阅等渠道接入，都可以使用 Qwen4-Max；思考深度分 low、high、xhigh 三档，默认 high，也可以关闭思考。

图片和视频可以直接发进对话让它理解。百炼和千问 AI 平台渠道下还有两个省 token 的设置：缓存保留时长可以从默认 5 分钟延长到 1 小时，图像精细度可以调低。

你能用它做什么：

- 附上设计稿截图，让它帮你搭页面
- 发一段录屏，让它梳理 Bug 的复现步骤
- 排查难定位的测试失败时，调高思考强度

详见 PR [#17513](https://github.com/QwenLM/qwen-code/pull/17513)

![模型列表里的 Qwen4-Max 与思考深度档位](https://img.alicdn.com/imgextra/i4/O1CN01cXhl153mN0L7o1Mj_!!6000000001943-2-tps-3845-2160.png)

### 新会话默认在独立工作树里运行，并行任务互不干扰

同一个项目里开多个 Web Shell 会话，以前共用一个目录，几个 AI 的改动互相覆盖，还会直接落进你正在编辑的文件。现在，受信任的 Git 工作区里新建会话默认在独立的工作树里干活——工作树是同一个仓库的另一份工作副本，提交历史相通，文件各改各的。

活干完了，成果有两种收法：在分支菜单里点「在此创建分支」，直接变成一个正式分支；或者点「移交到本地」，把改动带回你原来的目录。

不想要默认的工作树模式，把 `worktree.defaultForNewSessions` 设为 false，便直接在当前分支上干活。

你能用它做什么：

- 几个需求同时开几条会话一起改，互不覆盖
- 你在本地接着写代码，AI 在副本里改它的，两头不冲突
- 两个会话分别试两种重构方案，进行对比

详见 PR [#17228](https://github.com/QwenLM/qwen-code/pull/17228)

![Web Shell 新会话的工作树模式与分支菜单](https://img.alicdn.com/imgextra/i2/O1CN01Dzz4hbRKp6B7o1Mj_!!6000000003218-2-tps-3845-2160.png)

### 任务结果直发飞书、企业微信、钉钉群

上周微信、QQ、邮箱能在 Web Shell 里配置了，这周往下补群投递：飞书、企业微信、钉钉各多了一种「Webhook（仅发送）」连接方式。在群里添加自定义机器人，把它的 webhook 地址填进 Web Shell 的频道管理，通知、任务执行结果、定时任务结果就以 Markdown 消息发进群里。

这种方式只管发送，不接收群消息；要在群里和 AI 对话，用对应平台原有的机器人连接方式。

你能用它做什么：

- 设一个「每早 9 点汇总昨天合并的 PR」的定时任务，结果自动发进飞书项目群
- 让 AI 每晚跑一遍回归测试，跑完把结果发到企业微信群，上班直接看
- 给长任务设个完成通知，跑完自动发进钉钉群，同事同步看到进度

详见 PR [#16804](https://github.com/QwenLM/qwen-code/pull/16804)、[#17013](https://github.com/QwenLM/qwen-code/pull/17013)、[#17224](https://github.com/QwenLM/qwen-code/pull/17224)

![Web Shell 飞书 Webhook 配置页与群内消息效果](https://img.alicdn.com/imgextra/i1/O1CN01cs691H8c4KK3OTaQ_!!6000000002912-2-tps-1672-942.png)

### Web Shell：交付前看清改了多少，跑任务时盯住后台进度

**会话改了多少有变更总览了。** 会话干完活要交付，想知道一共改了多少文件、增删多少行，右侧面板多了「变更总览」：未提交的、每个绑定 PR 的、其余提交的，分开列出文件清单和行数。详见 PR [#17378](https://github.com/QwenLM/qwen-code/pull/17378)

**后台任务能点徽章查看。** 输入框上方多了几个小徽章，运行中的工作流、shell、监控、后台代理各占一个，点一下跳到对应的执行视图。详见 PR [#16813](https://github.com/QwenLM/qwen-code/pull/16813)

**侧栏会话能按工作区和日期筛了。** 工作区多了，侧栏能按工作区过滤；会话能按活动日期分组，先缩小范围再找会话。详见 PR [#17244](https://github.com/QwenLM/qwen-code/pull/17244)、[#17447](https://github.com/QwenLM/qwen-code/pull/17447)

**其他改进。** 每条回复能看钩子触发了几次、几次被拦、花了多久（[#17015](https://github.com/QwenLM/qwen-code/pull/17015)、[#17327](https://github.com/QwenLM/qwen-code/pull/17327)）；俄语界面翻译补齐（[#17414](https://github.com/QwenLM/qwen-code/pull/17414)）；会话搜索结果更清楚，能用键盘上下选择（[#16779](https://github.com/QwenLM/qwen-code/pull/16779)）。

![Web Shell 变更总览面板与后台任务徽章](https://img.alicdn.com/imgextra/i3/O1CN01uSlfCDtbSVG7o1Mj_!!6000000000575-2-tps-3845-2160.png)

## 📊 更多新功能

**会话能把活派给另一个工作区。** Web Shell 管着多个工作区时，一个会话能把活派给另一个工作区，用那边的指令和设置去干，干完结果送回来，还能接着追问。第一次派活要你确认一下。详见 PR [#17454](https://github.com/QwenLM/qwen-code/pull/17454)、[#17484](https://github.com/QwenLM/qwen-code/pull/17484)

**会话绑定 PR 能手动补，离线评论合并成摘要。** 上周绑定 PR 的会话能自动收到新评论，这周自动绑定漏掉时，输入 `/pr 编号或链接` 就能补绑，Web Shell 的会话总览和侧栏菜单里也有「绑定 PR」按钮；服务停过一段时间再启动，绑定 PR 上积压的评论合并成一条摘要送进会话。详见 PR [#16877](https://github.com/QwenLM/qwen-code/pull/16877)、[#17199](https://github.com/QwenLM/qwen-code/pull/17199)

**/memory 面板能改设置了。** 终端 `/memory` 面板里能直接开关自动保存和定期清理，用户级和项目级记忆文件也能打开编辑。详见 PR [#17213](https://github.com/QwenLM/qwen-code/pull/17213)

**Goals 页能看所有工作区的目标了。** 登记了多个工作区时，所有受信任工作区的目标汇总到一页，按时间排序，每张卡片标着属于哪个工作区；新建目标能选放进哪个工作区。详见 PR [#17230](https://github.com/QwenLM/qwen-code/pull/17230)

**Mods 插件能改写思考内容了。** 上周插件能改写终端里显示的回复文字，这周连展开的思考块也能改写——比如让插件把思考翻译成中文，两种终端界面都支持。详见 PR [#16873](https://github.com/QwenLM/qwen-code/pull/16873)、[#17443](https://github.com/QwenLM/qwen-code/pull/17443)

**Web Shell 在普通 HTTP 下正常可用。** 从另一台电脑用 http://电脑IP:端口 访问 Web Shell 时，终端标签、网页预览、本地命令这些功能都能用了。详见 PR [#17196](https://github.com/QwenLM/qwen-code/pull/17196)

**GitLab 频道能在 Web Shell 里配置。** 仓库白名单支持 group/subgroup/project 这类多级项目路径。详见 PR [#16845](https://github.com/QwenLM/qwen-code/pull/16845)

## 👏 体验优化

**上下文压缩后，最近一次完整操作原样保留。** 对话太长触发压缩时，最近一次操作和结果原样保留，只把更早的历史做摘要。详见 PR [#17141](https://github.com/QwenLM/qwen-code/pull/17141)

**切分支被未提交改动挡住，页面里就能处理。** 直接选暂存或丢弃改动再切换，不用回终端手动收拾。详见 PR [#17364](https://github.com/QwenLM/qwen-code/pull/17364)

**Goals 卡片状态一眼可辨。** 运行中是蓝色，等你处理是琥珀色；设了上限的目标显示回合、token、时长的进度条；会话里的目标长文本收成一行。详见 PR [#17349](https://github.com/QwenLM/qwen-code/pull/17349)、[#17133](https://github.com/QwenLM/qwen-code/pull/17133)

**用量看板打开更快。** Web Shell 状态页里的用量看板。详见 PR [#17239](https://github.com/QwenLM/qwen-code/pull/17239)

**选择弹窗里当前档位有高亮。** 思考深度弹窗里一眼能看出当前选中的是哪档，模型列表和执行模式选择也一样。详见 PR [#16622](https://github.com/QwenLM/qwen-code/pull/16622)

**会话改名立即生效。** 确认后新标题马上显示。详见 PR [#17006](https://github.com/QwenLM/qwen-code/pull/17006)
