Qwen Code 本周发布 v0.26.8～v0.27.2 五个正式版本。

**Qwen 订阅账号登录即用。** CLI、VS Code 和桌面端都能登录 Plus/Pro 订阅，直接用订阅里的模型聊天和联网搜索。

**微信、QQ、邮箱都能在 Web Shell 里配置了。** 微信和 QQ 在页面里扫二维码登录，邮箱填好服务器和账号就能接入。

**GitHub 频道支持仓库级动态过滤。** 白名单只收列出的仓库，黑名单排除列出的仓库。

## ✨ 新增特性

### Qwen Code 支持 Qwen 订阅账号登录

如果你的 Qwen 账号已有 Plus 或 Pro 订阅，可以在终端、VS Code 或桌面端用该账号登录。终端里运行 `/auth`，选择 Qwen 会员账号，再到浏览器完成授权。登录后，客户端会加载订阅可用的模型，也可以使用内置的网页搜索。

你能用它做什么：

- 订阅里的模型直接用来干活，用量走订阅
- 终端、VS Code、桌面端登录同一账号，模型一致
- 不用接 API，订阅 Qwen 后直接在 Qwen Code 中使用

详见 PR [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Qwen 订阅登录后的账号与模型列表](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### Web Shell 支持配置微信、QQ、邮箱频道

个人微信之前只能在终端里跑命令接入，QQ 和邮箱要手改设置文件。现在 Web Shell 的频道管理里多了这三个平台：微信和 QQ 可以直接在页面里显示二维码，手机扫码登录。邮箱填好服务器地址和账号信息即可。至此，除 Telegram 外的主流聊天平台都能在 Web Shell 里配置了。

你能用它做什么：

- 用手机扫 Web Shell 上的二维码，接入个人微信私聊或绑定 QQ
- 在频道管理里新增或编辑邮箱，指定哪些发件人可以通过邮件发起会话
- 撤销频道配对都可在 Web Shell 中一键管理

详见 PR [#16736](https://github.com/QwenLM/qwen-code/pull/16736)、[#16724](https://github.com/QwenLM/qwen-code/pull/16724)、[#16746](https://github.com/QwenLM/qwen-code/pull/16746)

![Web Shell 微信频道扫码登录页面](https://img.alicdn.com/imgextra/i1/O1CN01ldag0pIAw9J4s7XG_!!6000000004740-2-tps-2400-1626.png)

### GitHub 频道支持按仓库过滤动态

GitHub 频道会把仓库动态自动送进会话：有人开 PR、留评论、CI 跑完，agent 都能接着处理。以前接上就全收，组织里仓库一多，不相干的仓库也来打扰。现在能挑范围：白名单只收列出的仓库，黑名单收除列出之外的所有仓库，被排除的动态直接跳过，不进会话、不占处理。

你能用它做什么：

- 组织几百个仓库，只列自己负责的两个，动态只收它们的
- 最近不跟的仓库先拉黑，接手时再加回来
- 无关仓库的 PR 不再排队占 agent，你关心的仓库处理更快

详见 PR [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

### Web Shell：问答和用量看得更清楚，会话能批量整理

**问答热力图。** 长任务跑了好几天，想回看某天的问答，以前得一路往上翻对话。现在多了一个热力图按钮，点开是按天排成的日历，颜色深浅对应当天的问答次数，点某一天直接跳到那天的第一条问答。详见 PR [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**输入框下多了用量条。** 以前看用量得点开 Token 用量面板。现在输入框下面多了一行数字：回合数、输出速度、总 token、缓存命中率。详见 PR [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**会话能批量置顶和归档了。** 以前整理侧栏得一条条点，或者切到会话总览里操作。现在侧栏多了多选开关，勾选会话后一键置顶或归档。详见 PR [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**看不懂的选项能追问。** AI 弹出选择题时，看不懂选项以前没法问。现在问题面板多了「问详情」按钮，点开一个旁支任务，把每个选项的含义、差别、影响和建议讲清楚。详见 PR [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**其他改进。** 工作区能一键全部折叠或展开，按住标题拖动排序（[#16197](https://github.com/QwenLM/qwen-code/pull/16197)）；后台任务等你批准时，桌面弹通知或终端响铃，切去别的窗口也不会错过（[#16800](https://github.com/QwenLM/qwen-code/pull/16800)）；MCP 调用这类工具卡片，展开直接显示参数和完整结果（[#15435](https://github.com/QwenLM/qwen-code/pull/15435)）；技能页能直接上传 ZIP 压缩包装技能（[#16424](https://github.com/QwenLM/qwen-code/pull/16424)）。

![Web Shell 侧栏多选与输入框下的用量条](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 更多新功能

**定时任务能选频道投递目标。** 在 Web Shell 建定时任务时，可以指定结果发到哪个频道。详见 PR [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**QQ 群能主动发消息了。** 定时任务、webhook、后台任务的结果现在能作为主动群消息发进 QQ 群，之前 QQ 只能在回复窗口内被动应答。另加一个可选的 `forwardBotMessages` 开关，打开后群里其他机器人发的消息也会转给会话。详见 PR [#15635](https://github.com/QwenLM/qwen-code/pull/15635)、[#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**文件变更钩子。** 本地会话新增 `FileChanged` 钩子：监听的文件或目录发生新增、修改、删除时触发你配置的钩子，别的程序改动的文件也会通知。详见 PR [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Mods 插件新增三项能力。** `$.store` 让插件的数据跨会话保存；`ui.render` 可以改写终端里显示的回复文字，存储和复制的文本保持原样；`$.model.complete` 跑一次性的文本补全。详见 PR [#16791](https://github.com/QwenLM/qwen-code/pull/16791)、[#16794](https://github.com/QwenLM/qwen-code/pull/16794)、[#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**绑定 PR 的评论自动送进会话。** 会话绑定到 PR 后，PR 下的新评论自动送进这个会话，普通评论、行内 review 评论都算，不用 @ 也收得到。详见 PR [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 体验优化

**/btw 旁问能追问、能同时问几个。** 问新旁问时，之前答过的旁问会一起带上，追问可以接着之前的答案聊；连问几个各答各的，不打断彼此。详见 PR [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**启动时告诉 AI 当前用的 Shell。** 会话开头会注明命令将在哪种 Shell 下执行（bash、cmd.exe 等），AI 不用靠系统猜语法，Windows 上少写错命令。详见 PR [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**会话自动标题跟随对话语言。** 中文对话生成中文标题，各语言各归各。详见 PR [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Goal 检查结果的原因说明跟随会话语言。** 通过或驳回的理由用会话的输出语言显示。详见 PR [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**泰语、老挝语、高棉语、缅甸语的追问建议保持本语言。** 用这几种语言聊天时，追问建议也用同一种语言生成。详见 PR [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**实验性代码智能（LSP）能在设置里开了。** 在用户级设置里把 `tools.lspEnabled` 设为 true 即可启用，无需命令行参数，桌面端这类没法传参的客户端也能用上跳转定义、查找引用和诊断；默认关闭。详见 PR [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**子代理默认前台还是后台，可以全局配。** 把 `agents.defaultBackground` 设为 false，子代理会等跑完直接把结果交回当前回合，适合频道、机器人这类要在一轮里拿到结果的场景；重启后生效。详见 PR [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**托管会话能同时挂多个问题。** 托管会话提出的多个问题可以并存，按任意顺序回答。详见 PR [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**频道事件能点进会话了。** 频道事件时间线里的条目，点一下直接跳进它对应的会话。详见 PR [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
