Qwen Code 本周发布 v0.25.3、v0.26.0 两个正式版本，436 个 PR 合入。

**结果能做成一张能改的交互卡片。** 想换几个数字、试几种情况看看结果有什么不同，直接改卡片上的数字就行，总结果跟着重算。

**子目录里也能用仓库存好的工作流。** 一个项目分成前端、后端和多个组件目录时，你在项目根目录存过检查代码、运行测试这些流程，进到子目录启动 Qwen Code 照样能找到并运行。

**一组 qwen daemon 命令管住 Web Shell。** 启动、查状态、看日志、停止、重启都集中在这一组命令里。

## ✨ 新增特性

### 交互卡片：边调整边比较，找到合适的方案

有些问题，你可能想换几个数字、试几种情况看看结果会有什么不同。现在 Qwen Code 可以直接就这种需求做成交互卡片，随意调整数字或比例，就会立马呈现相应结果。详见 PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

比如安排一次团队聚餐，可以让它做一张费用计算卡片，填上人数、每人餐费和场地费。人数变了就改人数，换餐厅就改餐费，总费用会跟着重新计算，不需要每次都发消息让 AI 重算。

这项功能默认关闭，如需使用可在实验设置里开启 Generated UI，重新启动后生效。托管、远程和沙箱会话暂不支持内置版本。详见 PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

你能用它做什么：

- 比较租房方案，综合房租、通勤时间和交通费
- 调整项目人手与任务安排，估算工期和成本
- 对比服务器配置，估算不同访问量下的容量和费用

### 工作流：进入项目子目录，也能用同一套工作流程

一个项目可能分成前端、后端和多个组件目录。如果你已经在项目根目录保存了检查代码、运行测试等工作流，现在进入下面的子目录启动 Qwen Code，也能找到并运行这些流程。

比如你正在前端目录修改页面，想运行项目里保存的检查流程，可以直接在当前会话的工作流列表中找到它。这次更新支持从当前目录向上查找同一 Git 仓库内受信任目录中的工作流，适用于本地终端会话，也适用于普通 Web Shell 会话。详见 PR [#14369](https://github.com/QwenLM/qwen-code/pull/14369)、[#14646](https://github.com/QwenLM/qwen-code/pull/14646)

你能用它做什么：

- 在不同组件目录里，复用项目统一的代码检查流程
- 修改后端代码后，运行仓库保存的测试流程
- 编写项目文档时，使用上层目录保存的文档检查流程

### qwen daemon：Web Shell 管理，一组命令搞定

上周 Web Shell 支持在一个页面连接多个 Qwen Code，本周补齐这些本地服务的管理。

启动 Web Shell、查状态、重启等动作都集中在 `qwen daemon` 命令里，如：

运行 `qwen daemon start`，服务会在后台启动，并返回访问地址；用 `qwen daemon status` 查看已启动的服务，用 `qwen daemon logs` 查看日志，用 `qwen daemon stop` 停止指定服务。详见 PR [#14739](https://github.com/QwenLM/qwen-code/pull/14739)、[#14869](https://github.com/QwenLM/qwen-code/pull/14869)

排查问题时，`qwen daemon status --detail` 还能显示版本、运行时长、会话数量和问题数量。需要在脚本里启动服务后马上连接，可以使用 `qwen daemon start --wait`，等运行环境就绪后再继续。详见 PR [#14902](https://github.com/QwenLM/qwen-code/pull/14902)、[#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <端口>` 可以重启指定的本地 HTTP 服务，并恢复记录中的启动工作区与 Web Shell 设置。详见 PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

你能用它做什么：

- 启动本地服务后，继续在同一个终端处理其他工作
- 查看多个本地服务的状态，定位需要处理的那一个
- 按记录的启动配置重启指定服务

### Web Shell：文件和执行记录，在界面里看得更清楚

**PDF 和 Word 文件在界面里直接看。** 从 `@` 引用、右侧 Files 或者产物卡片里打开，PDF 走浏览器自带的阅读器，Word 文件在这几个入口里同样能预览。详见 PR [#14825](https://github.com/QwenLM/qwen-code/pull/14825)、[#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**右侧文件能建能删。** 点聊天标题旁边那个目录名，右侧就打开工作区的文件树。在这里能新建文件、新建文件夹；删一个文件要先确认，删文件夹要多确认一次，因为它里面的文件会跟着一起删掉。详见 PR [#14344](https://github.com/QwenLM/qwen-code/pull/14344)、[#14169](https://github.com/QwenLM/qwen-code/pull/14169)、[#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**轨迹面板能暂停。** 翻看之前的记录时会自动暂停，画面就停在你看的那几行；想接着看最新的，点「跳到最新」刷新。点列表里的任意一行，能看到这条记录的详情。详见 PR [#14723](https://github.com/QwenLM/qwen-code/pull/14723)、[#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**其他改进。** 对话里可以选中某一句和它的回复一起删掉，也能挑着删几处（[#14297](https://github.com/QwenLM/qwen-code/pull/14297)）；它正在做和刚做完的事，连同每一步耗时收进一个能收起的「最近执行」区（[#14071](https://github.com/QwenLM/qwen-code/pull/14071)）；「会话 Token 消耗」面板里，总览留着输入、输出和缓存这几项，下面能分开看各模型、主 Agent 和子 Agent 各用了多少；鼠标停在模型名旁的 Info 图标上，还能看到这个模型第一个字多久出来、每秒输出多少（[#14728](https://github.com/QwenLM/qwen-code/pull/14728)、[#14648](https://github.com/QwenLM/qwen-code/pull/14648)）。

## 📊 更多新功能

**`/auth` 第一屏多了「千问AI平台 / QwenCloud」。** 从这两个平台来的，现在在 `/auth` 第一屏就能选到对应的官方服务商，国内和国际分开选，按量付费和订阅两种 key 各走各的。详见 PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**它反复做同一件事时，默认先提醒而不是直接停下。** 一条命令、一次读文件连着重复到一定次数，以前这一轮会被掐断；现在默认改成提醒它换个办法、接着往下跑，想让它自动停可以在设置里选那种模式。提醒模式下它会继续花时间也继续花 token，任务上设的预算仍然管用。详见 PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**自建 Managed Agent 服务的用户，可以更方便地管理项目和任务。** 那些会话现在和你自己电脑上的会话并排摆在 Web Shell 首页，用同一个输入框和批准卡片。本期还能直接选已有的项目目录，新建会话时带上已启用的技能，运行中调整执行权限，手动改会话名称；普通托管会话也能同时用同一个项目目录，文件由这些会话共享。这些能力需要对应的部署支持。详见 PR [#14316](https://github.com/QwenLM/qwen-code/pull/14316)、[#14970](https://github.com/QwenLM/qwen-code/pull/14970)、[#14930](https://github.com/QwenLM/qwen-code/pull/14930)、[#14920](https://github.com/QwenLM/qwen-code/pull/14920)、[#14987](https://github.com/QwenLM/qwen-code/pull/14987)、[#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**Claude 格式插件自带的命令，终端里也能敲了。** 上周它只在跑一次出结果的用法里生效，现在终端里能直接敲，不发起模型请求。插件在模型要用某个工具之前插手的那一层也开到了交互会话里，可以改写这一次调用，也可以拦下来。这项默认关着，设置里有 Mods 开关，改完重启生效。详见 PR [#14268](https://github.com/QwenLM/qwen-code/pull/14268)、[#14565](https://github.com/QwenLM/qwen-code/pull/14565)、[#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**后台跑着的命令，能直接看到它输出到什么地步了。** 任务详情里有输出的最后一段、输出多大、最后一次写是什么时候，加上占了多少内存、开始和结束时间，内容也能一键复制。详见 PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

**QQ 机器人收得到文件了。** 单聊或者群里 @ 它，丢一份 Word、PDF 或者表格过去，它存下来照着读、照着答。详见 PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**企业微信的自建应用能接进来。** 同事在企业自建的应用里发一句话交代任务，Qwen Code 收到去办，办完用这个应用的身份回信。详见 PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)
