Qwen Code 本周发布 v0.21.2 到 v0.21.6 五个正式版本，300+ 个 PR 合入。另外还有一个大动作：Qwen Code Desktop v0.1.0 正式发布。

**桌面端来了。** 上周 Web Shell 刚做完一轮大更新，这周它直接变成了一个独立的桌面应用：Qwen Code Desktop v0.1.0 发布，macOS、Windows、Linux 三平台都有原生安装包，GitHub Releases 可直接下载。启动恢复、单实例窗口、自动更新这些桌面应用该有的基本功都齐了，界面还是你熟悉的 Web Shell。

**任务执行能"看见"了。** 新的 Session Workflow 视图把任务计划和执行进度画成一张流程图：计划有几步、哪步在跑、哪步在等、哪个子任务派给了哪个 AI，一目了然。AI 开工前还会先把这张图给你过目，你点头它才开工。默认关闭，settings 里打开即用。

**终端体验和权限管控也在补齐。** AI 画的图表现在能直接显示在终端里，不用自己开文件。子 Agent 现在能按活配权限：只读的活只给读权限，常用权限组合还能存成模板复用。长会话压缩可以单独指定便宜模型，成本更可控。

## ✨ 新增特性

### Qwen Code Desktop 正式发布：三大平台原生应用，打开就能用

之前 Qwen Code 的桌面体验分散在两处：Electron 桌面应用和浏览器里的 Web Shell。这周两者合流了：Qwen Code Desktop v0.1.0 正式发布，界面是上周大更新后的 Web Shell，启动、窗口管理、崩溃恢复、自动更新这些桌面的事归原生应用管。macOS、Windows、Linux 三大平台的安装包都已上线，GitHub Releases 直接下载。

已有 Electron 版的 macOS 用户不用手动迁移：新版本带一次性的迁移引导，切换后之后的更新也自动跟上。

你能用它做什么：

- 不用开终端，桌面端打开就能用 Qwen Code 的全部能力
- 三大平台体验一致
- 自动更新检查，后续版本不用手动重装

详见 PR [#8132](https://github.com/QwenLM/qwen-code/pull/8132)、[#8392](https://github.com/QwenLM/qwen-code/pull/8392)、[#8511](https://github.com/QwenLM/qwen-code/pull/8511)、[#8518](https://github.com/QwenLM/qwen-code/pull/8518)

### Session Workflow：计划、子任务、执行进度画成一张图

一个复杂任务跑起来之后，计划执行到哪一步、哪个子任务在干什么，之前只能靠翻对话记录自己拼。

新的 Session Workflow 视图把这一切画成一张流程图：计划的每一步是图上一个框，步骤之间的先后顺序用线连起来，哪步在跑、哪步被卡住实时显示；AI 派出去的子任务也挂在图上，点开能看它具体干了什么。AI 开工前会先把这张图给你过目，批准了才开工，不批准就回去重新计划。任务跑完之后，这张图还能打开回看，每一步是谁干的、干了什么都有记录。

功能默认关闭，settings 里把 `experimental.sessionWorkflow` 设为 true 即可开启。开启后还有两个配套便利：子任务遇到需要你确认的操作，比如跑命令、改文件，请求直接浮到主界面处理，不用钻进子任务里找；特别长的任务可以丢到后台跑，主对话继续干别的，跑完会通知你。

你能用它做什么：

- 复杂任务执行中一眼看清进度，哪步卡住看图就知道
- 先确认计划再开工，更放心
- 长任务丢后台，主对话继续干别的

详见 PR [#7580](https://github.com/QwenLM/qwen-code/pull/7580)、[#8391](https://github.com/QwenLM/qwen-code/pull/8391)、[#8240](https://github.com/QwenLM/qwen-code/pull/8240)、[#8303](https://github.com/QwenLM/qwen-code/pull/8303)

### 子 Agent 权限管控：按活发钥匙，并行任务互不干扰

你给 Qwen Code 一个大任务时，它有时会派几个"分身"（子 Agent）并行干活——一个去读代码、一个去跑测试。之前不管派哪个分身，它都和本尊一样全套能力：读文件、改文件、跑命令都会。你只想让它"看看代码写个总结"，它其实也能顺手改文件，不放心。

现在可以按任务配权限了：

- **按活发钥匙**：派分身时可以限定它能用哪些工具——一句话交代就行，比如"这活只读"，它派活时就带着这个限制，想改东西当场被拒
- **权限模板**：常用的权限组合存成模板，放在项目的 `.qwen/fork-profiles/` 目录里，下次一个参数复用，不用每次重新配
- **任务单保密**：修了一个漏洞——之前几个分身并行干活时，互相能看到别人的任务指令，现在各看各的，专心干自己的活

你能用它做什么：

- 只读的活只给读权限，杜绝顺手改文件
- 常用权限组合存成模板，一行复用
- 并行的分身各干各的，互不干扰

详见 PR [#8066](https://github.com/QwenLM/qwen-code/pull/8066)、[#8148](https://github.com/QwenLM/qwen-code/pull/8148)、[#8344](https://github.com/QwenLM/qwen-code/pull/8344)

### 对话压缩成本优化：压缩可以指定便宜模型

长会话触发自动压缩时，之前只能用主模型把完整上下文跑一遍——又贵又慢。

这周有三个改进。第一，`/model --compaction` 可以给压缩单独指定模型：让便宜模型去干"总结长对话"这一步，主对话照样用好模型，质量不受影响。第二，用主模型压缩时会复用之前缓存过的内容，响应更快，带图片的历史也支持。第三，用 Claude 系列模型的话，可以把 `generationConfig.cacheRetention` 设成 `"1h"`，缓存保留时间从默认 5 分钟拉长到 1 小时，间隔很长的会话不再每次都浪费缓存。

你能用它做什么：

- 压缩交给便宜模型，长会话账单更好看
- 主模型压缩复用缓存，响应更快
- 低频会话不再每次都吃缓存失效的亏

详见 PR [#7818](https://github.com/QwenLM/qwen-code/pull/7818)、[#8339](https://github.com/QwenLM/qwen-code/pull/8339)、[#8419](https://github.com/QwenLM/qwen-code/pull/8419)、[#8048](https://github.com/QwenLM/qwen-code/pull/8048)

### Channel 生态：GitLab 接入、钉钉互动卡片、配对审批管理

上周 GitHub Channel 上线，这周 Channel 生态继续扩。

**GitLab 来了。** GitLab 的 todos 和 @机器人 的评论会变成入站消息，哪些动作交给 AI 处理可以配置，处理过的不会重复处理。详见 PR [#7862](https://github.com/QwenLM/qwen-code/pull/7862)

**钉钉有互动卡片了。** 钉钉 Channel 支持互动卡片：AI 的运行状态实时更新在卡片上，需要你输入时弹出结构化提问，不用盯着一大段文字看。其他平台不受影响。详见 PR [#6930](https://github.com/QwenLM/qwen-code/pull/6930)

**配对审批能管了。** 之前 Channel 配对模式批准过的发送者没地方查看，更没法撤销。现在 Channel 编辑器里能看到谁被批准了、单独撤销某个审批，各个 workspace 的审批各管各的。详见 PR [#8045](https://github.com/QwenLM/qwen-code/pull/8045)、[#8081](https://github.com/QwenLM/qwen-code/pull/8081)

**GitHub/GitLab Channel 不用手编配置了。** Web Shell 里可以直接创建、编辑、配置 GitHub/GitLab Channel：token、访问范围、白名单等都在界面上操作，不用再打开 `settings.json`。详见 PR [#8310](https://github.com/QwenLM/qwen-code/pull/8310)

**GitHub Channel 细节打磨。** 本地已经登录 `gh` 的话，GitHub Channel 可以直接复用这份登录状态，不用再单独建一个 token。回复行为也收敛了：每个事件最多发一条最终评论，不刷屏；AI 处理期间原评论挂一个临时 👀 表情，结束自动移除。被中断的任务重启后可恢复，不用重跑。详见 PR [#8461](https://github.com/QwenLM/qwen-code/pull/8461)、[#8033](https://github.com/QwenLM/qwen-code/pull/8033)、[#8061](https://github.com/QwenLM/qwen-code/pull/8061)、[#8306](https://github.com/QwenLM/qwen-code/pull/8306)

## 📊 更多新功能

**Auto Recall 自动上下文检索。** 上周的外部语料检索是"AI 按需去查"，这周的 Auto Recall 是"每次提问自动查一遍"：检索结果附给 AI 当参考，常见敏感信息自动过滤。与按需检索模式互斥，由管理员部署。详见 PR [#7877](https://github.com/QwenLM/qwen-code/pull/7877)

**工具预载阈值。** 新增 `tools.toolSearch.threshold` 设置：工具不多的时候，会话启动时就全部声明好，不用中途再按需搜索，响应更快；设为 0 恢复原来的行为。详见 PR [#7922](https://github.com/QwenLM/qwen-code/pull/7922)

**/autofix 支持本地工作区。** 之前 `/autofix` 只能在 GitHub Actions 里跑，现在直接运行就能审查修复本地改动：发现问题、应用最小修复、跑检查、再复查，直到干净或确认修不了。跑之前会说明检查在沙箱里进行，需要你确认信任该仓库。详见 PR [#8121](https://github.com/QwenLM/qwen-code/pull/8121)

**Web Shell 审查结果结构化视图。** `/review` 跑完后，结果在 Web Shell 里有专门视图：多少问题、在哪、怎么修、证据是什么，一目了然，能按严重程度过滤，也能打开完整报告。详见 PR [#8402](https://github.com/QwenLM/qwen-code/pull/8402)

**Qwen 3.8 reasoning effort 生效。** 用 qwen3.8-max 系列模型时，`/effort` 的五档能真正控制模型思考的深度，不再只有一档生效。详见 PR [#8472](https://github.com/QwenLM/qwen-code/pull/8472)

**Goal v3 接入 CLI。** `/goal` 命令和交互模式现在用同一套运行时，状态卡片、生命周期命令两边对齐，体验一致。详见 PR [#8005](https://github.com/QwenLM/qwen-code/pull/8005)、[#8324](https://github.com/QwenLM/qwen-code/pull/8324)

**技能分级隐藏。** 新增 `skills.disabledLevels` 设置，可以按来源整层隐藏技能，技能太多太乱的时候有用。详见 PR [#8057](https://github.com/QwenLM/qwen-code/pull/8057)

**自动生成技能的生命周期管理。** `/learn` 等自动生成的技能现在有使用跟踪：30 天不用标记过期，90 天自动归档，不再越攒越多。详见 PR [#7846](https://github.com/QwenLM/qwen-code/pull/7846)

**memory.agentMaxTurns。** 统一配置记忆 Agent 的轮数上限，0 表示不限制。详见 PR [#8171](https://github.com/QwenLM/qwen-code/pull/8171)

**/summary 支持自定义路径。** `/summary` 现在可以带路径参数，把项目摘要保存到指定位置，父目录自动创建。详见 PR [#8116](https://github.com/QwenLM/qwen-code/pull/8116)

**daemon 容量与状态。** 每个 workspace 的会话上限从 20 提到 32，并行多开不容易撞上限；`/daemon/status` 能看到内存用量，离上限还有多远心里有数；子会话并发上限也可配置。详见 PR [#8235](https://github.com/QwenLM/qwen-code/pull/8235)、[#8245](https://github.com/QwenLM/qwen-code/pull/8245)、[#8341](https://github.com/QwenLM/qwen-code/pull/8341)

**Chrome 扩展 alpha。** Chrome 扩展 alpha 版补齐了引导流程、运行时诊断，以及真实 Chrome 环境下的自动化验收。详见 PR [#6739](https://github.com/QwenLM/qwen-code/pull/6739)

## 👏 体验优化

**流式输出时也能查状态了。** 模型还在输出时，`/status`、`/settings`、`/help` 这类只读命令现在立即执行，不用等回合结束；Web Shell 里 `/stats`、`/about`、`/context` 同样支持回合中立即运行，之前这些命令会被静默吞掉。详见 PR [#8130](https://github.com/QwenLM/qwen-code/pull/8130)、[#8496](https://github.com/QwenLM/qwen-code/pull/8496)

**长工具输出不再被截掉。** 命令输出和长思考内容之前超过 500 字符就硬截断，现在改成默认折叠、可展开的完整视图，导出的会话里也能看到全文。详见 PR [#8251](https://github.com/QwenLM/qwen-code/pull/8251)

**后台 Agent 在跑时回合保持展开。** 之前主 AI 一空闲，Web Shell 就把回合适为完成并折叠，哪怕后台子 Agent 还在跑，过一会儿又有更新冒出来，状态来回跳。现在只要还有活跃的子 Agent，回合保持展开。详见 PR [#8413](https://github.com/QwenLM/qwen-code/pull/8413)

**Thinking 块不再抖动，transcript 改内联。** 流式思考块的高度稳定了，不再跳来跳去；全屏记录覆盖层换成 Ctrl+O 内联开关。详见 PR [#8077](https://github.com/QwenLM/qwen-code/pull/8077)

**快捷键补充。** macOS 粘贴剪贴板图片新增 Option+V；@ 补全的分类切换新增 Ctrl+Tab / Ctrl+Shift+Tab，避开终端自带的快捷键冲突。详见 PR [#8120](https://github.com/QwenLM/qwen-code/pull/8120)、[#8074](https://github.com/QwenLM/qwen-code/pull/8074)

**搜索更快更稳。** 文件搜索更快；搜索失败时自动重试，不再把"没搜完"误报成"没有匹配"。详见 PR [#8253](https://github.com/QwenLM/qwen-code/pull/8253)、[#7888](https://github.com/QwenLM/qwen-code/pull/7888)

**表格与对话框细节。** Markdown 增强表格关闭单元格对话框时不再引起页面跳动；对话框打开瞬间的滚轮事件不再误滚背景。详见 PR [#8407](https://github.com/QwenLM/qwen-code/pull/8407)、[#8089](https://github.com/QwenLM/qwen-code/pull/8089)

**Ctrl+Shift+C 回归复制。** 之前 Ctrl+Shift+C 会触发退出或清屏动作，现在恢复终端复制的本职。详见 PR [#8011](https://github.com/QwenLM/qwen-code/pull/8011)

**会话详情菜单。** 窄布局下会话详情菜单不再溢出，还加了键盘可达的"复制完整会话 ID"操作。详见 PR [#8127](https://github.com/QwenLM/qwen-code/pull/8127)
