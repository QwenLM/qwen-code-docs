Qwen Code 本周发布 v0.26.4～v0.26.7 四个正式版本。

**远程连接加了独立开关，用起来更方便。** 现在在 **设置 → 连接** 里打开 **允许远程连接**，同一网络下就能连上另一台电脑。

**GitHub 事件自动推进你的会话。** 频道绑上仓库之后，新 commit、新 review、CI 挂了这些动态直接涌进绑定 PR 的会话。

**Web Shell 的状态也看得更清楚。** 频道的事件能集中查看，侧栏上哪个会话在跑、哪个在等你一眼就知道。

## ✨ 新增特性

### 远程连接：同网络下，用另一台设备接着工作

把几台 Qwen Code 连到一个页面里，之前被连那台启动时需要带上 `--hostname 0.0.0.0`，现在当电脑都处在同一网络环境下时，在 **设置 → 连接** 里填入地址和 Bearer token，就能连上另一台电脑了。

本周在 **设置** → **连接** 里加了一个 **允许远程连接** 开关，打开后会生成连接地址和一串 Bearer token，在另一台电脑输入后无需重启即可连上，也可随时关掉。详见 PR [#15887](https://github.com/QwenLM/qwen-code/pull/15887)、[#16199](https://github.com/QwenLM/qwen-code/pull/16199)

你能用它做什么：

- 换一台电脑，继续原来的对话
- 离开工位后，远程回复追问或处理审批
- 临时开放远程访问，结束后在设置里关闭

![远程连接](https://img.alicdn.com/imgextra/i4/O1CN01WL5kej9I8kI4s7XG_!!6000000004481-2-tps-2400-1626.png)

### GitHub 仓库的动态，自动推进你的会话里

频道绑了 GitHub 仓库之后，仓库那边新 commit、新 review、CI 挂了，都会自动推给频道里绑着这个 PR 的会话。Qwen Code 看到了就接着处理，比如构建挂了去读日志修。回复默认不公开，你确认了才发到 PR 下面。详见 PR [#16117](https://github.com/QwenLM/qwen-code/pull/16117)、[#16258](https://github.com/QwenLM/qwen-code/pull/16258)

频道编辑器里还可以直接配 GitHub 仓库的访问权限、@ 行为和通知频率，不用再去设置文件里手写。事件里提到的 PR 和 Issue 编号会自动变成可点击的链接。详见 PR [#16149](https://github.com/QwenLM/qwen-code/pull/16149)、[#16096](https://github.com/QwenLM/qwen-code/pull/16096)、[#16226](https://github.com/QwenLM/qwen-code/pull/16226)

你能用它做什么：

- PR 的 CI 挂了，失败日志直接推进会话，不用自己去翻
- 同事 review 了你的 PR，意见出现在聊天界面里
- 新仓库要跟踪，编辑器里填个地址就行

![GitHub 动态](https://img.alicdn.com/imgextra/i2/O1CN01HhyTIFzowNI2vGtw_!!6000000004881-2-tps-1440-900.png)

### Web Shell：频道动态和会话状态，在界面里看得更清楚

**频道事件能集中查看了。** 频道里每天有事在发生：GitHub 有 commit、定时任务跑完、会话回了消息。现在频道页面多了「事件」栏，所有活动按时间排成一条线，能按频道筛，时间线自己刷新。详见 PR [#16106](https://github.com/QwenLM/qwen-code/pull/16106)

**Token 用量面板能拆条看了。** 以前只列每类用了多少，现在每条请求单独拆开：输出速度多快、首次响应要等多久、成功还是失败，不同模型有不同颜色。点开某一条能看到失败的具体原因。详见 PR [#16108](https://github.com/QwenLM/qwen-code/pull/16108)、[#16111](https://github.com/QwenLM/qwen-code/pull/16111)

**侧栏会话多了状态标记。** 以前侧栏里的会话列表只是一个个名字，看不出里面在发生什么。现在每条会话旁边多了状态标记：正在跑的有个转圈，等着你批准的有个橙色提示，出错了有条红杠。把标记点开，能看到是谁在等、哪条提示刚答完。没读过的消息数也标出来了，还能一键全部标为已读或归档。详见 PR [#16022](https://github.com/QwenLM/qwen-code/pull/16022)

**会话并排显示。** 会话右键菜单多了「加到分屏」，直接把两条会话左右摆开对照着看。详见 PR [#15956](https://github.com/QwenLM/qwen-code/pull/15956)

**其他改进。** Workflow 模式的开关收进了输入框旁边的「+」菜单，打开时会有一个标签可以点关掉（[#16107](https://github.com/QwenLM/qwen-code/pull/16107)、[#15779](https://github.com/QwenLM/qwen-code/pull/15779)）。复制图片地址到输入框自动变成附件，截屏也能直接粘贴（[#16179](https://github.com/QwenLM/qwen-code/pull/16179)）。

## 📊 更多新功能

**交互卡片默认开启。** 之前交互卡片得去设置里开，现在装好就能用——让它算房贷、比方案，对话里直接拖滑块看结果。调好参数点「保留」还能交回对话接着聊。详见 PR [#15856](https://github.com/QwenLM/qwen-code/pull/15856)

**从网上下载的项目先让你信任了才跑 hooks。** 陌生项目里带的 hooks、权限规则和语言服务器，得先弹确认框、你点了「信任」之后才会生效。自己电脑上本地新建的项目不受影响。详见 PR [#16182](https://github.com/QwenLM/qwen-code/pull/16182)、[#16196](https://github.com/QwenLM/qwen-code/pull/16196)

**/verify-pr 能在 Docker 里跑不信任的代码。** 一条命令在本地起一个容器，把 PR 的代码放进去跑验证，模型密钥留在你机器上不过去。详见 PR [#16077](https://github.com/QwenLM/qwen-code/pull/16077)

**桌面端支持 Fedora 44 和 RHEL 10。** 用这两个系统的，从 GitHub Releases 直接下 rpm 包安装。详见 PR [#16060](https://github.com/QwenLM/qwen-code/pull/16060)

**QQ 群管理操作也能交给 AI 了。** 频道把自己的管理工具暴露给里面跑的会话，群里的撤回消息、踢人、审批加群这些操作，AI 都能替你执行。配哪些工具在频道设置里用 `moderationTools` 控制。详见 PR [#14348](https://github.com/QwenLM/qwen-code/pull/14348)

**托管 Agent 从头部署只要跑一条 Helm 命令。** 把 Helm chart 配好，MySQL 和网关都自己带好。详见 PR [#15492](https://github.com/QwenLM/qwen-code/pull/15492)

**归档的对话能从设置里直接恢复。** 点进设置 → 归档，每条旁边多了「恢复」和「导出」按钮，不用翻到那条会话再点恢复。详见 PR [#15872](https://github.com/QwenLM/qwen-code/pull/15872)

**技能打字时能看到剩下的参数提示。** 打完 `/qwencode-weekly` 之后，后面要填什么参数始终浮在那里；填完一个，提示缩成下一个。详见 PR [#15930](https://github.com/QwenLM/qwen-code/pull/15930)

**升级命令支持指定版本。** 运行 `qwen update --target-version <版本号>` 直接装到指定的版本，不用先连 npm registry 查有没有新版；想降级或重装同一个版本也可以。详见 PR [#11486](https://github.com/QwenLM/qwen-code/pull/11486)

## 👏 体验优化

**/autofix-pr 更稳了：落后主干自己合、能在检出里一起改、能说清管几轮。** 分支落后主干导致 CI 红时，它先把主干合进来再跑检查，省了手动 rebase。加 `--in-place` 就在你当前检出里干活，你在旁边看着一起改。在 PR 里写 `@qwen-code /takeover for N` 能说清管几轮，修完自动放手。详见 PR [#15922](https://github.com/QwenLM/qwen-code/pull/15922)、[#15929](https://github.com/QwenLM/qwen-code/pull/15929)、[#15388](https://github.com/QwenLM/qwen-code/pull/15388)

**长回答可以滚着看了。** `/btw` 答得特别长的时候，现在固定在一个有滚动条的框里，用鼠标滚轮、键盘上下键或 PageUp/PageDown 都能翻。详见 PR [#15982](https://github.com/QwenLM/qwen-code/pull/15982)

**DeepSeek V4、qwen4 和 latest-series 这几系模型也能设思考深度了。** 之前这几代模型没有可选的思考深度，走阿里代理的 DeepSeek V4.1 Flash 也没有默认值；现在各档位按模型给好，关思考走原来的开关。详见 PR [#15987](https://github.com/QwenLM/qwen-code/pull/15987)、[#15828](https://github.com/QwenLM/qwen-code/pull/15828)

**Web Shell 一键更新支持 pnpm、yarn、bun。** 以前只有 npm 能点更新，现在这几种包管理器都能一键升，检测到不支持时给出手动步骤。详见 PR [#15849](https://github.com/QwenLM/qwen-code/pull/15849)

**状态栏能看见有几个后台 agent 在跑。** 桌面端和 Web Shell 底部的任务标记上会实时显示正在运行的 agent 数量。详见 PR [#14002](https://github.com/QwenLM/qwen-code/pull/14002)

**代码跳转失败时给个明确的说法。** 没有可用的语言服务器时，以前默默返回空结果，现在会告诉你当前没有可用的语言服务器。详见 PR [#15946](https://github.com/QwenLM/qwen-code/pull/15946)

**上下文内存文件在面板里能点开预览。** AGENTS.md 这类文件，点了就能看内容。详见 PR [#15932](https://github.com/QwenLM/qwen-code/pull/15932)

**没有工作区的会话列表空着时那一栏整个藏起来。** 以前空栏占着地方，现在像已固定一样，空着就整栏不显示。详见 PR [#15916](https://github.com/QwenLM/qwen-code/pull/15916)
