Qwen Code 近两周发布 v0.24.5 ~ v0.25.0 共 4 个正式版本，467 个 PR 合入。

**Qwen Live 语音上线。** 直接跟它说话，它用语音回你；通话中还能共享屏幕，让它看你屏幕上正在发生什么。

**Qwen Code 能操作你已登录的网页了。** 它进你日常那个 Chrome 翻页、填表、提交，全程在后台完成，不影响你用电脑。

**发一封邮件，活就派出去了。** 人不在电脑前，用手机上的邮件 App 交代一句，那台电脑上的 Qwen Code 去办，办完回信告诉你结果。

**一批重复的活儿，用 /batch-api 半价挂到后台跑。** 说清要做什么，它先给一份不计费的计划，你点头才交出去，几小时后结果落成一个个文件。

**跑完一轮觉得慢或者贵，打开轨迹页签就知道卡在哪。** 模型请求、工具调用、子代理请求各摊成一条，哪一节长得反常看得出来。

## ✨ 新增特性

### Qwen Live 语音上线

Qwen Live 上线了，Web Shell 和桌面版里都能用。在左侧边栏点 Live 图标，右边就是 Qwen Live 卡片：拨开开关、把你的百炼 DashScope Realtime API key 粘进去，点 Save。详见 PR [#12529](https://github.com/QwenLM/qwen-code/pull/12529)

开启之后，在 Live 页点「Open Live Voice」，或者点对话输入框右下角的实时语音按钮，就能跟它说话，它用语音回你。详见 PR [#12189](https://github.com/QwenLM/qwen-code/pull/12189)

通话过程中你还可以点「共享屏幕」，让它看你屏幕上正在发生什么，你直接问画面上那段报错是什么意思。详见 PR [#12378](https://github.com/QwenLM/qwen-code/pull/12378)、[#12623](https://github.com/QwenLM/qwen-code/pull/12623)

你能用它做什么：

- 手在键盘上腾不出来，直接说下一步要它干什么
- 屏幕上出了看不懂的报错，共享屏幕让它自己看再给意见
- 一轮要来回说很多句的沟通，改成嘴上讲完

### Qwen Code 能操作你已登录的网页了

Qwen Code 能进你日常在用的那个 Chrome 办事：你开着的标签、你登着的账号，它接着用——翻页、填表、提交，再把结果页留给你看。你可以直接说一句「读我打开的那张报表，把今天的订单汇总一下」。详见 PR [#11242](https://github.com/QwenLM/qwen-code/pull/11242)

用之前先从 Chrome 应用商店装一个 [Qwen Code 扩展](https://chromewebstore.google.com/detail/qwen-code/hdhmmjclhibojdddmancfgbkleahfaph)，之后在对话里直接说要办什么就行。Mac 和 Linux 可用，Windows 还没支持。详见 PR [#12510](https://github.com/QwenLM/qwen-code/pull/12510)

它做这些都在后台完成，Chrome 不会被切到前台，不影响你用电脑；几个会话同时用它，各自一组标签，互不干扰。详见 PR [#12229](https://github.com/QwenLM/qwen-code/pull/12229)

你能用它做什么：

- 让它读你登着的那个后台，把今天的数据抄出来跟你的表对一遍
- 报销单、工单散在几个网页里，一句话让它逐条填完提交
- 盯一个只在网页上看得到的流程，比如审批队列、待办列表，让它把要处理的挑出来

### 发一封邮件，活就派出去了

有时事情想起来了，可那台跑着 Qwen Code 的电脑不在手边，你够不着——现在新增 Email Channel，直接发封邮件就行。

你在手机上随便哪个邮件 App 交代一句，那台电脑上的 Qwen Code 就去办，办完回你一封信说结果。觉得哪里不对，回那封邮件补一句，它知道前面已经做到哪儿。别人发来的报错邮件、系统发出来的告警，也能直接转进这个邮箱让它接手。

要用它，先给 Qwen Code 配一个邮箱账号，再把你自己的邮箱写进它的名单——只有你发的信它才动手。

你能用它做什么：

- 上班路上发一封信，让它提前把活儿干起来，到工位直接看结果
- 用户报障的邮件原样转进去，它读完附件里的日志先给一轮判断
- 告警邮件一发出来，Qwen Code 就先接手去查，查完回信告诉你原因

详见 PR [#12939](https://github.com/QwenLM/qwen-code/pull/12939)

### /batch-api：一批重复的活儿，半价挂到后台去跑

手上有几百个各自独立的小事：一整个目录的文档要翻译、几十份工单每条要抽几个字段、每篇都得写个摘要。一条条发过去，光是等就占满了对话，钱也花得快。

`/batch-api` 后面把要做的说一句，它先翻几个样本、列一份计划给你——一共多少条、写到哪个目录、大概花多少 token，这一步不计费。你点头，它才真的交出去。之后这批活儿在后台按实时价一半计费跑，通常几十分钟到几小时后，结果变成一个个文件落在你指定的地方；这期间你这条对话照常干活。

```text
/batch-api 把 docs/zh 下的 Markdown 文档翻译成英文，按同名写到 docs/en
```

它适合一轮就能办完、内容各不相关的那种批量活儿；需要来回讨论几轮的事，还是照原来的对话方式办。

你能用它做什么：

- 整个中文文档目录翻成英文，一次交上去，隔几小时去收
- 一批日志、工单按条提取字段，攒成一次跑完
- 几百条用户反馈逐条归类打标签，一次交上去

详见 PR [#12492](https://github.com/QwenLM/qwen-code/pull/12492)

### 轨迹页签：一轮跑得慢还是贵，能看清时间花在哪

跑完一轮，你觉得久了点，可你只知道「久了」——不知道是模型半天不开口，是它话说得太多，还是中间某个工具卡在那里。

右侧面板的轨迹页签把时间摊成三条：模型请求、工具调用、子代理请求各一条。哪一节长得反常，一眼看得出来；条太密的时候，可以把某一段拉宽了看。详见 PR [#12524](https://github.com/QwenLM/qwen-code/pull/12524)、[#12557](https://github.com/QwenLM/qwen-code/pull/12557)

哪一段看着可疑，就在轴上圈出那一段，下面只留下这段时间里发生的事；挑中某一条，它读了什么、返回了什么、花了多少 token，就在下面摊开，可以直接复制走。详见 PR [#12543](https://github.com/QwenLM/qwen-code/pull/12543)、[#12971](https://github.com/QwenLM/qwen-code/pull/12971)

轴上还有一个「真实时间」的画法，把你干等的时间也算进去，同时给出「历时多久、实际在跑多久」两个数——一轮下来到底占了你多少时间，看这里。详见 PR [#12607](https://github.com/QwenLM/qwen-code/pull/12607)

跑完的轮次能折起来，长会话不用从头翻到尾。详见 PR [#13081](https://github.com/QwenLM/qwen-code/pull/13081)

你能用它做什么：

- 觉得慢，看轴就知道下一步该动谁：换模型，还是去查那个工具
- 长会话里想回到某一段，圈出来只看那段，跑完的轮次折起来
- 怀疑某次操作做错了，当场看它的输入输出和花了多少 token

### Channel：一个机器人分头接活，私聊和群准入分开，长会话自动换新

**同一个机器人可以分头接活。** 在消息前面带上不同的前缀，走的就是不同的会话、各有各的交办要求——一边让它评审代码，一边让它答仓库里的问题，两条线互不串味，也不用为这个再开一个连接。群里 @ 完它再带前缀也行。详见 PR [#12595](https://github.com/QwenLM/qwen-code/pull/12595)

**谁能私聊它、谁能在群里使唤它，现在是两件事。** 你可以把群完全放开，同时只让名单里那几个人私聊它，两头互不影响。详见 PR [#12547](https://github.com/QwenLM/qwen-code/pull/12547)、[#12475](https://github.com/QwenLM/qwen-code/pull/12475)

**群里的长会话会自己开新的。** 一个线程越攒越长，长到最后每条消息都发不出去，坏的只有那一条会话——有个钉钉线程攒到 8,577 条消息。现在可以给它设个上限，到点自动换一条新会话，并在群里说一声。详见 PR [#12616](https://github.com/QwenLM/qwen-code/pull/12616)

### Web Shell：侧栏重排、长会话能搜历史记录、一个仓库多份文件副本等多重更新

**侧栏重新排过。** 左边多出一条窄导航，Channel、语音这些各有各的入口，版本号和不常用的动作收进「更多」里。详见 PR [#12943](https://github.com/QwenLM/qwen-code/pull/12943)

**长会话里能搜话。** 想找之前说过的一句、贴过的一段代码，搜关键词直接跳到那条消息，更早的消息不用先翻上去，搜了就能找到。详见 PR [#12234](https://github.com/QwenLM/qwen-code/pull/12234)

**「顺带一问」摆在明面上了。** 主任务还在跑的时候想插一句小问题，输入框的「+」菜单里有这一项，点开就帮你写好；答案出现在旁边的面板里，主任务不受影响。详见 PR [#12775](https://github.com/QwenLM/qwen-code/pull/12775)

**一个仓库可以同时开几份工作副本。** 接着上期的分支图，Git 对话框里多了一个 Worktree 页签：每条会话用自己那份，改东西互不影响；哪份在跑会话、哪份有没提交的改动，一眼看得到，点一下就切过去。详见 PR [#12154](https://github.com/QwenLM/qwen-code/pull/12154)、[#11816](https://github.com/QwenLM/qwen-code/pull/11816)

## 📊 更多新功能

**提交这件事也能交给它。** 敲 `/commit`，它看你改了哪些文件、照着仓库历史的写法拟一段提交说明，只把该进这次提交的文件放进去；像 `.env` 这种存着密钥的文件，它直接拒绝。它只创建提交，推送还是你自己来。想限定范围就在后面补一句，比如 `/commit only stage the parser changes`。详见 PR [#10586](https://github.com/QwenLM/qwen-code/pull/10586)

**看看一句话让它做了哪些事。** 在 Web Shell 里，鼠标停在你发的那条消息上，复制按钮旁边会出现一个扳手图标，点它就是「工具调用」页签：这一轮读了哪些文件、跑了哪些命令、改了哪里，一条条列出来，展开能看结果和改动。之前几轮也能查。详见 PR [#12466](https://github.com/QwenLM/qwen-code/pull/12466)

**`/advisor` 从手动评审变成自动上门。** 打开之后，干活的那个模型会在动手改之前和准备交活时自己去找顾问问一次，意见回到对话里再继续做；派出去的子代理也能问。每问一次额外花 token，这段对话会交给顾问模型看，挑一个你信得过的。详见 PR [#9636](https://github.com/QwenLM/qwen-code/pull/9636)、[#12688](https://github.com/QwenLM/qwen-code/pull/12688)

**接一个新模型，少填一堆东西。** 它的上下文窗口多大、一次能输出多少、能不能收图，这些现在它自己认——内置一份模型清单，每天在后台更新，断网时也能用。你自己填过的值仍然算数。详见 PR [#11959](https://github.com/QwenLM/qwen-code/pull/11959)

**外部记忆接进来得简单了。** 想让它记住跨会话的事，现在给它一个地址和密钥就行，装扩展、注册服务那些动作都省了。搜是默认就能用的；要让它往外记东西得再打开一个开关，打开之后存什么都会先给你过目。详见 PR [#12891](https://github.com/QwenLM/qwen-code/pull/12891)

**记忆多了不用整份摊开。** 打开之后，它按你当前问的问题只挑相关的几条放进上下文，要看全文再去取。记忆攒到几十上百个文件时省下不少。详见 PR [#10183](https://github.com/QwenLM/qwen-code/pull/10183)

**QQ 机器人能收图片和视频了。** 群里发给它的图片、短视频它都能直接看，不用你再转成文字描述。详见 PR [#12850](https://github.com/QwenLM/qwen-code/pull/12850)

## 👏 体验优化

**打开就能打字，快了一倍。** 在干净的电脑上，从敲下 `qwen` 到能打字原来要等约 2.5 秒，其中头 2 秒终端一片空白；现在这段等待减半，内存占用也从原来的 575 MB 降了约六成。详见 PR [#12622](https://github.com/QwenLM/qwen-code/pull/12622)、[#12602](https://github.com/QwenLM/qwen-code/pull/12602)、[#12603](https://github.com/QwenLM/qwen-code/pull/12603)

**设置面板的中文补齐了。** 界面语言选中文时，通篇都是中文。详见 PR [#12783](https://github.com/QwenLM/qwen-code/pull/12783)

**Channel 的群发言人、会话管理员能在弹窗里改了。** 不用再打开配置文件手敲。详见 PR [#12535](https://github.com/QwenLM/qwen-code/pull/12535)

**界面清爽了一些。** 空着的参数不占一行，统计页顶部排好，原始数据收进详情里。详见 PR [#12601](https://github.com/QwenLM/qwen-code/pull/12601)、[#13091](https://github.com/QwenLM/qwen-code/pull/13091)

**改完 skills 内容，刷新就生效。** 详见 PR [#12182](https://github.com/QwenLM/qwen-code/pull/12182)
