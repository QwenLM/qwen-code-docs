Qwen Code 本周发布 v0.21.15、v0.22.0、v0.22.2 三个正式版本，300+ 个 PR 合入。

**Goal 学会自己收尾。** Goal 自主运行默认带 token 预算，超了先写一段交接再停；目标确定够不着时，自己提前停下。

**Qwen 模型有了 Thinking 开关。** qwen3.5-plus 这类混合思考模型有了一个简单的 Thinking 开关：关掉当前会话不思考，打开恢复模型默认。

**AI 输出过程中也能用更多“/命令”了。** AI 正在输出时，`/theme`、`/tools` 等 10 个命令照样直接用，结果立刻出来。

## ✨ 新增特性

### Goal：自主运行有预算，停下前先交接

Goal 的自主运行这周补齐了几块"自知之明"：知道花了多少、该停就停、停之前把话说清楚。

**花的钱有账。** 每个 Goal 累计花了多少 token 现在单独记账，`get_goal` 里就能看到，和轮数并列显示。

**自主运行有预算。** 新建的 Goal 默认带一个 token 预算，自主运行把预算花完就停下来，Goal 进入等待状态。想让它继续，恢复或编辑这个 Goal，预算会自动再续一个窗口。

**停下前多给一轮交接。** 预算花完时，会多给一轮"交接轮"：不开新工作，只把做到了什么、还剩什么、下一步是什么讲清楚，然后停下。中途换人接手，看这段就能续上。

**卡住会自己停。** 检查点连续三次卡住，自动停下；有证据表明目标本身不可能达成时，当轮就停。

**`/goal-draft` 把模糊想法变成可执行的 Goal。** 它先问你几个问题，把模糊想法问清楚，再起草一份可验证的目标，并附一条可以直接执行的 `/goal set` 命令。它只负责起草，不会动手干活，用不用你自己定。

详见 PR [#9583](https://github.com/QwenLM/qwen-code/pull/9583)、[#9891](https://github.com/QwenLM/qwen-code/pull/9891)、[#10132](https://github.com/QwenLM/qwen-code/pull/10132)、[#9975](https://github.com/QwenLM/qwen-code/pull/9975)、[#10125](https://github.com/QwenLM/qwen-code/pull/10125)、[#10002](https://github.com/QwenLM/qwen-code/pull/10002)

### Qwen 模型有了 Thinking 开关

在 web shell 中，qwen3.5-plus、qwen3.6-plus、qwen3.6-flash、qwen3.7-plus、qwen3.7-max 这些模型，多了一个 Thinking 开关控制思考：关掉，当前模型回答不思考；打开，思考后再回答。

qwen3.8-max 的思考强度保留 low / medium / extra high 三档。

详见 PR [#9574](https://github.com/QwenLM/qwen-code/pull/9574)

![模型弹窗里的 Thinking 开关](https://img.alicdn.com/imgextra/i4/O1CN01BtvdvUAuKfH7nOLI_!!6000000007210-2-tps-3840-2160.png)

### 工作流有了正式开关和跑前审批

工作流是把一件大事拆开、分给多个 AI 助手同时干的功能。这周给它补齐了三道关卡：

- **正式开关**：设置里打开 `tools.workflowsEnabled` 就能用，而且只有你自己能开，项目配置动不了它
- **跑前审批**：跑之前，审批框把 AI 写好的工作流脚本完整摊开给你看——调研什么、分几步、怎么汇总，都写在里面，你看完点确认才跑
- **按需启动**：只在你明确要分工时才启动，比如直接说"用工作流"、点名跑某个工作流、让它接着上次跑；它觉得该用但你没提时，会先说打算怎么分工、派几个助手，等你拍板

详见 PR [#9098](https://github.com/QwenLM/qwen-code/pull/9098)、[#9837](https://github.com/QwenLM/qwen-code/pull/9837)、[#9806](https://github.com/QwenLM/qwen-code/pull/9806)

### GitHub PR 挂回创建它的会话

在 Web Shell 里提过 PR 的话，之后想找"这个 PR 是哪个会话提的"往往要翻记录。现在，从 Web Shell 的 Git 面板创建的 PR 会记在发起它的会话下面：侧边栏的会话名旁边出现 PR 角标，按 PR 号搜索也能找到对应会话。一个会话最多记 10 个 PR，同一个 PR 重新推送，记录会刷新到最新。

详见 PR [#9543](https://github.com/QwenLM/qwen-code/pull/9543)

![侧边栏的 PR 角标与搜索](https://img.alicdn.com/imgextra/i3/O1CN01J2dzfeTpIxI2b88O_!!6000000004996-2-tps-1280-800.png)

### AI 输出过程中也能用更多“/命令”了

AI 正在输出时想用斜杠命令，之前大多数得排队等这一轮结束。这周有 10 个命令加入"不用等"名单：`/theme`、`/editor`、`/vim`、`/voice`、`/terminal-setup` 这类界面设置命令，以及 `/tools`、`/tasks`、`/hooks`、`/docs`、`/bug` 这类只读命令——AI 说着话，你照样用，结果立刻出来。

详见 PR [#9495](https://github.com/QwenLM/qwen-code/pull/9495)

## 📊 更多新功能

**qwen3.8-max 转正式版。** qwen3.8-max 从预览版转正，Token Plan 用户在 `/model` 里可以直接选到稳定版。详见 PR [#9383](https://github.com/QwenLM/qwen-code/pull/9383)

**对话进行中也能补文件。** 上周文件能拖进 Web Shell 输入框，这周对话进行到一半也能补附件：输入框附件和 @ 引用工作区文件都支持，AI 当场就能收到。上传入口也统一了：引用工作区文件或直接上传二选一，传过的附件持久保存。详见 PR [#9570](https://github.com/QwenLM/qwen-code/pull/9570)、[#9477](https://github.com/QwenLM/qwen-code/pull/9477)

**对话模型也能兼任生图。** 同一个模型现在可以同时承担对话和内置图片生成，不用为出图单配一个生图模型；图片生成也支持了 MiniMax 的接口。详见 PR [#9650](https://github.com/QwenLM/qwen-code/pull/9650)、[#8322](https://github.com/QwenLM/qwen-code/pull/8322)

**Web Shell 里能直接管 Goal。** Goal 不再混在聊天消息里管理，Web Shell 页面给它单独留了一行紧凑的管理区。详见 PR [#9393](https://github.com/QwenLM/qwen-code/pull/9393)

**定时任务可以跑在现有会话里。** 创建定时任务时，可以选择让任务就在当前会话里执行。详见 PR [#9838](https://github.com/QwenLM/qwen-code/pull/9838)、[#9361](https://github.com/QwenLM/qwen-code/pull/9361)

**桌面端代码迁移到 OpenWork。** Electron 桌面端代码移到独立开源项目 [OpenWork](https://github.com/modelstudioai/openwork) 继续开发，Qwen Code 仓库保留升级到新版桌面的迁移桥。详见 PR [#9085](https://github.com/QwenLM/qwen-code/pull/9085)

**Computer Use 改成技能驱动。** AI 操作电脑换成自带技能，第一次用自动装好依赖、按提示重启一次照常使用；Node REPL 从内置工具改成独立 MCP 服务包 `@qwen-code/node-repl-mcp`，默认不启用，在 `mcpServers` 里配置后才生效。详见 PR [#9856](https://github.com/QwenLM/qwen-code/pull/9856)、[#9587](https://github.com/QwenLM/qwen-code/pull/9587)、[#9499](https://github.com/QwenLM/qwen-code/pull/9499)

**Kimi 成为内置服务商。** `/auth` 里选第三方服务商、选 Kimi，填 API key 就能接上，国际或国内端点可选；模型列表预置好旗舰 K3、K2.6 和两个代码专用模型，列表还能自己编辑。K3 常开思考，另外三个能自由开关思考。详见 PR [#9814](https://github.com/QwenLM/qwen-code/pull/9814)

## 👏 体验优化

**Web Shell 有了用量面板。** Web Shell 里可以打开会话级的 token 用量面板：总消耗、按模型拆分、子智能体调用、工具使用统计，一页看全。详见 PR [#9988](https://github.com/QwenLM/qwen-code/pull/9988)

**紧凑模式成为 Web Shell 唯一模式。** 思考块和工具活动默认收进摘要行，之前的 Ctrl+O 开关取消，主对话、分屏、子智能体详情面板统一用紧凑渲染。详见 PR [#9993](https://github.com/QwenLM/qwen-code/pull/9993)、[#9657](https://github.com/QwenLM/qwen-code/pull/9657)

**审批卡片进到消息流里。** 工具审批和提问不再盖住整个消息列表，改成贴着消息流显示的底部卡片，宽度和聊天区对齐。详见 PR [#9351](https://github.com/QwenLM/qwen-code/pull/9351)

**后台 shell 跑着，轮次保持展开。** 轮次里起了后台 shell，这个轮次就一直展开着，跑完才收起，方便盯进度。详见 PR [#9632](https://github.com/QwenLM/qwen-code/pull/9632)

**VS Code 插件用上统一渲染。** VS Code 插件的会话时间线换成和 Web Shell 同一套渲染器，两边的显示体验对齐了。详见 PR [#9719](https://github.com/QwenLM/qwen-code/pull/9719)

**终端大窗口滚动更顺。** 终端虚拟滚动的渲染从每秒 30 帧提到 60 帧，大窗口回看历史明显更流畅。详见 PR [#9681](https://github.com/QwenLM/qwen-code/pull/9681)

**加载了哪些上下文文件能看到了。** 通过设置附加了自定义上下文文件的话，会话第一条消息上方会列出加载了哪些文件，之前这一步是完全不可见的。详见 PR [#8855](https://github.com/QwenLM/qwen-code/pull/8855)

**会话记住上次选的模型。** daemon 会话重启或断开重连后，恢复到你上次为该会话选的模型；新会话仍用设置里的默认模型。详见 PR [#9687](https://github.com/QwenLM/qwen-code/pull/9687)

**钉钉频道能看懂引用了。** 之前在钉钉里引用一张图或一个文件，AI 只看到一个占位符；现在引用的图片、文件、音频、视频会真正下载下来交给 AI，转发的聊天记录也会解析出标题和摘要一并带入。详见 PR [#9347](https://github.com/QwenLM/qwen-code/pull/9347)、[#9339](https://github.com/QwenLM/qwen-code/pull/9339)

**私有仓库的扩展能装了。** 用 HTTPS Git 安装扩展支持了身份认证，从私有仓库克隆也行，凭据要不要持久化可以选。详见 PR [#9458](https://github.com/QwenLM/qwen-code/pull/9458)

**老版本 Git 也能装公开扩展。** Git 版本低于 2.37 的系统，安装公开 GitHub 扩展改走归档下载路径。详见 PR [#9680](https://github.com/QwenLM/qwen-code/pull/9680)、[#9690](https://github.com/QwenLM/qwen-code/pull/9690)

**一条命令开带锁的 Web Shell。** `qwen serve --open-with-auth` 打开一个带令牌认证的本地 Web Shell，没配令牌就自动生成一个并传给浏览器。详见 PR [#9738](https://github.com/QwenLM/qwen-code/pull/9738)

**Homebrew 不再误报更新。** 本地元数据确认没有新版本时，更新提示不再出现。详见 PR [#9502](https://github.com/QwenLM/qwen-code/pull/9502)
