Qwen Code 本周发布 v0.28.3、v0.28.4、v0.28.6 三个正式版本。

**给另一个会话派活。** 在 Web Shell 里用 `/send` 把活交给另一个会话，它接着干，干完回来向你汇报。

**定时任务结果推送到指定地址。** 在频道管理里加一个通用 Webhook、填一个接收地址，定时任务跑完，结果就自动推送过去。

**生成的文件集中看。** 所有会话生成的报告、导出文件都汇在「产物」页，直接预览、下载，不用挨个打开会话。

## ✨ 新增特性

### 用 /send 把任务交给另一个会话

上周可以让 AI 向另一个工作区派活，这周你可以自己发。在 Web Shell 输入 `/send 查一下刚才失败的测试`，同一工作区会开一条新会话接手。也可以用 `--workspace` 选工作区，或用 `--session-id` 指定已有会话。任务完成后，当前会话会转述结果。

AI 自己也能这么派活了：以前它只能把活交给它自己新开的会话，现在你手动开的会话它也能交过去；开了 YOLO 模式的话，往别的项目文件夹派活也不再弹窗问你。

你能用它做什么：

- 在 A 会话查完资料，发给 B 会话接着写方案
- 留在主会话写代码，把测试排查交给另一条会话
- 在右侧面板看进度，直接处理对方会话的确认请求和问题

详见 PR [#17539](https://github.com/QwenLM/qwen-code/pull/17539)、[#17818](https://github.com/QwenLM/qwen-code/pull/17818)

[📸 演示截图待补：/send 发送记录、跨会话徽章与右侧面板实时进度]

### 频道：任务结果发进你自己的系统，QQ 能发文件了

**任务结果能发进你自己的系统了。** 上周飞书、企业微信、钉钉群能收结果了，这周再加一种不挑平台的通用 Webhook（Generic Webhook）：在频道管理里填一个 HTTPS 接收地址，通知和定时任务结果就发过去。详见 PR [#17405](https://github.com/QwenLM/qwen-code/pull/17405)

**频道消息能中途纠偏了。** 终端独立启动的频道可用 inject 投递模式：AI 正在干活时收到的消息直接送进当前这轮，中途就能读到并调整方向——任务干到一半发现不对，补一句话就行。详见 PR [#15634](https://github.com/QwenLM/qwen-code/pull/15634)

**QQ 机器人能把文件发进聊天了。** QQ 频道配置里把 `fileTools` 设为 `true`（默认关闭）并重启频道后，AI 能把工作区里生成的文件、图片、视频、语音直接发进聊天。详见 PR [#15450](https://github.com/QwenLM/qwen-code/pull/15450)

你能用它做什么：

- 定时任务跑完，结果自动发进你自己的系统里
- 任务跑偏时在群里补一句话，AI 当场改方向
- 在 QQ 里直接派活，生成的文件原地发回聊天

[📸 演示截图待补：通用 Webhook 配置页与 QQ 收到的文件]

### Web Shell：会话产物一页收齐，输入历史跨设备共享

**会话产物能在一页里浏览下载了。** 本地部署的 Web Shell 新增「产物」页：整个工作区里所有会话产出的报告、导出、网页预览快照汇总到一页，直接预览或下载。详见 PR [#18071](https://github.com/QwenLM/qwen-code/pull/18071)、[#17689](https://github.com/QwenLM/qwen-code/pull/17689)

**输入历史能跨设备共享了。** 电脑上敲过的提示词和命令，手机上打开同一个工作区就能在输入历史里翻到，反过来也一样。详见 PR [#18120](https://github.com/QwenLM/qwen-code/pull/18120)

**侧栏能认出每个会话的状态了。** 带着目标的会话显示目标记号，颜色和 Goals 页一致：运行中蓝色、等你处理琥珀色；上次回合被中断的会话显示 Continue 徽章，重启后扫一眼就知道哪几个要接着跑。详见 PR [#17515](https://github.com/QwenLM/qwen-code/pull/17515)、[#18044](https://github.com/QwenLM/qwen-code/pull/18044)

**手机上的追问建议能点选了。** 建议变成输入框上方可点按的提示，点一下填进输入框，改完再发。详见 PR [#17918](https://github.com/QwenLM/qwen-code/pull/17918)

**其他改进。** Generated UI 卡片里的按钮能直接复制文本或下载小文件（[#18158](https://github.com/QwenLM/qwen-code/pull/18158)）；触屏编辑栏在手机和 iPad 上保持单行（[#18126](https://github.com/QwenLM/qwen-code/pull/18126)）。

## 📊 更多新功能

**繁体中文界面。** Web Shell 和 VS Code 伴侣界面新增繁體中文，语言选择里选「繁體中文 [zh-TW]」即可。详见 PR [#17421](https://github.com/QwenLM/qwen-code/pull/17421)

**显示翻译。** 设置里开启 `general.displayLanguage` 选简体中文后，模型用英文写的回复和展开的思考在终端和 Web Shell 里显示成中文；存档、复制、后续对话仍是原文。默认关闭，终端 `/settings` 或 Web Shell 设置页可开。详见 PR [#18175](https://github.com/QwenLM/qwen-code/pull/18175)

**Microsoft Teams 频道扩展。** 单独安装 `@qwen-code/channel-msteams` 扩展并配好 Azure 机器人后，可在 Teams 私聊和群里 @ 机器人派活，不同话题的对话互不干扰。详见 PR [#15620](https://github.com/QwenLM/qwen-code/pull/15620)

**CLI 读屏模式。** 终端新增读屏模式（实验性）：启动时加 `--screen-reader`，回复完成后播报一次，历史用键盘翻阅，当前选中的、待批准的操作都会读出来；默认图形界面不变。详见 PR [#17500](https://github.com/QwenLM/qwen-code/pull/17500)

## 👏 体验优化

**Web Shell 打开更快。** 终端用到时才加载，大会话记录压缩后再传；点开历史会话到看见内容，实测耗时从约 1.3 秒降到 0.8 秒。详见 PR [#17840](https://github.com/QwenLM/qwen-code/pull/17840)、[#11220](https://github.com/QwenLM/qwen-code/pull/11220)、[#18223](https://github.com/QwenLM/qwen-code/pull/18223)

**后台任务徽章能问「它在干嘛」。** 上周输入框上方能点徽章看后台任务，这周每个徽章多了个问号：点一下，AI 用大白话解释这个任务在干什么、为什么启动，答案显示在旁边的问答面板，当前对话和任务照常进行。详见 PR [#17398](https://github.com/QwenLM/qwen-code/pull/17398)

**排队消息不再打断正在跑的命令。** AI 正在跑一条命令时你补发一句话，命令转到后台继续跑，你的话当场得到回应。详见 PR [#17926](https://github.com/QwenLM/qwen-code/pull/17926)

**MCP 配置改动即时生效。** 在设置里增删 MCP 服务器后，运行中的会话自动生效，不用重启。详见 PR [#17743](https://github.com/QwenLM/qwen-code/pull/17743)

**追问建议出得更快。** 生成建议时只参考一小段对话。详见 PR [#17532](https://github.com/QwenLM/qwen-code/pull/17532)

**Mods 改写进 Web Shell。** 上周 Mods 插件能改写终端里的回复和思考，这周 Web Shell 也显示改写后的文字：回复和展开的思考都按插件改写后的样子显示，历史、复制、搜索、分支仍用原文。需开启 `experimental.mods`。详见 PR [#17718](https://github.com/QwenLM/qwen-code/pull/17718)、[#17920](https://github.com/QwenLM/qwen-code/pull/17920)

**工作流阶段预览。** 工作流要经过的阶段，一开始就全部列出来：没跑到的先标出来，跑到时显示实际进度，整体走到哪一眼可见。需先用环境变量 `QWEN_CODE_ENABLE_WORKFLOWS=1` 开启工作流。详见 PR [#17782](https://github.com/QwenLM/qwen-code/pull/17782)

**Gemini 4、Kimi K3 思考档位自动适配。** 接入这两个模型时，思考深度档位自动可用。详见 PR [#18039](https://github.com/QwenLM/qwen-code/pull/18039)、[#18095](https://github.com/QwenLM/qwen-code/pull/18095)

**备用模型切换更省时。** 开启 `experimental.modelAvailabilityTracking` 后，这轮里刚因容量不足失败的模型先跳过，直接用后面的备用模型，下一轮再试它。默认关闭。详见 PR [#17377](https://github.com/QwenLM/qwen-code/pull/17377)
