Qwen Code 本周发布 v0.22.3、v0.23.0 两个正式版本，320+ 个 PR 合入。

**AI 的说话方式随你挑了。** 简洁、主动、讲解、教学四种内置输出风格，能选，还能在对话中途随时切换。

**钉钉机器人能发文件了。** AI 写完的报告、文档作为附件直接发进会话，手机上就能点开。

**Web Shell 内置终端了。** 在对话旁边就能跑命令，每个页签独立，各干各的。

## ✨ 新增特性

### 输出风格：选 AI 的说话方式

不同的人对 AI 的回复有不同的期待：有人想要话少直接给结果，有人希望它边干边讲、带着学。这周输出风格可以选了，内置四种风格：

- **简洁**：先说结论，不带开场白和过程描述
- **主动**：直接开始干，拿不准时说出假设继续做，不反复问你
- **讲解**：改代码的同时，把相关代码讲给你听
- **教学**：边干边教，留一些小决定让你自己动手

选的方式有三种：在 `settings.json` 里设置 `general.outputStyle` 长期生效，启动时用 `--output-style` 指定单次生效，或者在对话中用 `/output-style` 随时切换，下一轮回复就用新风格。

你能用它做什么：

- 只想看结果时切到简洁，AI 直接说结论
- 学代码时切到讲解或教学，AI 边改边讲给你听
- 对话中途想换个输出风格，`/output-style` 随时切

详见 PR [#9565](https://github.com/QwenLM/qwen-code/pull/9565)、[#10283](https://github.com/QwenLM/qwen-code/pull/10283)、[#10683](https://github.com/QwenLM/qwen-code/pull/10683)

### Goal：AI 起草目标，你只管确认

上周 `/goal-draft` 让 AI 帮你把目标写好，这周起草完之后，AI 会把完整目标用确认框拿给你看，确认后就会立刻开始跑 Goal。

遇到要干好几轮、完成标准明确的任务，AI 还会主动判断这件事值得盯着做完，把目标起草好问你；如果不喜欢这个行为也可以在设置里整个关掉。目前这个能力在终端交互会话里可用，Web Shell 的支持还在路上。

上周 Goal 有了 token 预算，这周预算多少你说了算：在设置里改 `model.goalTokenBudget`，调大调小都行，设成 -1 就不设上限。

你能用它做什么：

- AI 把目标写好，点确认就开始干
- 完成标准明确的长任务，AI 会主动提议盯着做完
- 预算调大调小更可控

详见 PR [#10171](https://github.com/QwenLM/qwen-code/pull/10171)、[#10543](https://github.com/QwenLM/qwen-code/pull/10543)

### 代码审查：修复轮只审改动，审查深度记得住

**修复轮只审改动。** AI 帮你审完再改、改完再审的循环里，后续每轮只审有改动的文件，审过又没动过的沿用上一轮结论，省 token 也省时间。

**审查深度记得住。** 你明确用 `--effort` 指定过审查深度后，同一个项目里下次直接运行 `/review` 就沿用这个深度。

**长跑有反馈。** 自动修复轮跑得久时，PR 页面上的状态评论每 10 分钟左右更新一次，写上已运行时长和最近活动时间，干没干活一眼就知道。

**反复问题会提醒。** 同一个文件的严重问题如果修了又冒出来，审查结论里会明确标出这条问题链，提醒你换个思路。

你能用它做什么：

- 本地改一版审一版，每轮只重审改过的文件，连着跑几轮也花不了多少 token
- 同一个项目里 `/review --effort high` 跑过一次，之后直接敲 `/review` 就是同样的深度
- 挂在 PR 上的自动修复跑几小时，状态评论每 10 分钟更新一次，还在不在干活一目了然

详见 PR [#9659](https://github.com/QwenLM/qwen-code/pull/9659)、[#9883](https://github.com/QwenLM/qwen-code/pull/9883)、[#9771](https://github.com/QwenLM/qwen-code/pull/9771)、[#10010](https://github.com/QwenLM/qwen-code/pull/10010)

### 钉钉机器人能发文件了

钉钉里的 Channel 机器人以前只能发文字和图片，AI 写好的报告、整理好的文档，内容只能贴在消息里，想要文件本身得回电脑上找。现在机器人能把文件当附件发：AI 写完报告，直接把文件发到钉钉会话里，手机上就能点开下载。机器人主动给你发消息的时候，一样能带文件。

你能用它做什么：

- AI 写完的报告、文档，作为附件直接发到钉钉
- 手机上点开就能看、能下载
- 机器人主动汇报时也能带上文件

详见 PR [#10893](https://github.com/QwenLM/qwen-code/pull/10893)

![机器人把文件作为附件发进钉钉会话](https://img.alicdn.com/imgextra/i4/O1CN01SuHINQRUN9G3OTaQ_!!6000000004652-2-tps-1672-942.png)

### Web Shell：内置终端，会话与工作台管理更全

**对话旁边就能开终端。** 用 Web Shell 干活，经常想自己顺手跑几个命令：起个服务看看效果、确认一下构建结果。现在右侧面板就能开终端，在对话旁边直接跑。每个页签是一个独立终端，打开就是当前工作区的目录，一个页签里挂着长跑的服务，另一个页签照常敲命令，互不影响。

**不挑项目也能建任务。** 新建任务现在可以建一个不属于任何工作区的会话，随手问个问题、处理点跟具体项目无关的事都行。这类会话有自己的列表，重命名、导出、归档都支持。

**按聊过的内容找会话。** 忘了会话标题叫什么，直接搜当时聊过的话就能找到，匹配的会话下面还会带一句命中消息的摘录。

**定时任务有干净的上下文了。** 定时任务反复执行时，可以选择每次都新建一个会话，上下文各次独立；同一个任务产生的会话还会自动归到一组，列表不乱。

**工作区状态一眼看全。** 新增的工作区总览面板一页列出所有工作区：有几个会话在跑、MCP 连接情况、当前分支、有没有未提交的改动，每一行都能直接新建任务。

**会话总览更好用了。** 会话总览页换成支持排序、筛选、分页的表格，窗口窄的时候横向滚动，关键列固定不动。入口是侧边栏底部那排小图标里的网格图标，悬停显示"会话总览"。

**手机配对挪到了右上角。** 对话右上角有个二维码小图标，点开弹出配对码，用手机扫一下就能连上电脑里这个会话，在手机上给 AI 派活（这个功能叫 Local Control）。功能没开的话，点开它会直接带你去设置页打开。

**动手之前先看 Git 状态。** Update Project、Commit、Push 旁边现在带状态提示：落后或领先几个提交、有多少未提交的改动。有未提交改动时更新项目，可以选择先存起来再更新，或者放弃改动再更新。

你能用它做什么：

- 在对话旁边直接跑命令
- 搜聊过的话，找回过去的会话
- 所有工作区的状态一眼看全

详见 PR [#9984](https://github.com/QwenLM/qwen-code/pull/9984)、[#10514](https://github.com/QwenLM/qwen-code/pull/10514)、[#10612](https://github.com/QwenLM/qwen-code/pull/10612)、[#10233](https://github.com/QwenLM/qwen-code/pull/10233)、[#10611](https://github.com/QwenLM/qwen-code/pull/10611)、[#10589](https://github.com/QwenLM/qwen-code/pull/10589)、[#10115](https://github.com/QwenLM/qwen-code/pull/10115)、[#10432](https://github.com/QwenLM/qwen-code/pull/10432)、[#10397](https://github.com/QwenLM/qwen-code/pull/10397)、[#10390](https://github.com/QwenLM/qwen-code/pull/10390)

## 📊 更多新功能

**工作流可以中途管了。** 正在跑的工作流支持查看进度、暂停、恢复、取消、重跑；取消立即生效。详见 PR [#10411](https://github.com/QwenLM/qwen-code/pull/10411)、[#10468](https://github.com/QwenLM/qwen-code/pull/10468)

**记忆分项目和个人。** 让 AI 记事情时可以指定存到当前项目还是个人全局，两边有严格边界，互不相串。详见 PR [#9895](https://github.com/QwenLM/qwen-code/pull/9895)

**会话和 PR 的关联更全了。** 上周从 Web Shell Git 面板创建的 PR 能记回会话，这周又补齐了几块：PR 状态有了彩色图标，绿色进行中、紫色已合并、红色已关闭；按 issue 编号也能搜到对应会话；让 AI 在对话里跑 `gh pr create` 提的 PR 一样会记上。详见 PR [#9729](https://github.com/QwenLM/qwen-code/pull/9729)、[#10258](https://github.com/QwenLM/qwen-code/pull/10258)、[#10425](https://github.com/QwenLM/qwen-code/pull/10425)、[#9739](https://github.com/QwenLM/qwen-code/pull/9739)

**Mem0 外部记忆正式可用。** 想把 Qwen Code 接到 Mem0 记忆服务，现在安装官方扩展包、配置好就能用。详见 PR [#10653](https://github.com/QwenLM/qwen-code/pull/10653)、[#10634](https://github.com/QwenLM/qwen-code/pull/10634)

**同一台机器上的会话能按名字互发消息。** 多个会话分工干活时，一个会话可以按名字找到另一个会话，直接给它发消息。详见 PR [#10158](https://github.com/QwenLM/qwen-code/pull/10158)

**任务状态表情能自定义。** 钉钉 Channel 里，任务跑着时和跑完之后显示的表情，可以换成你喜欢的。详见 PR [#10610](https://github.com/QwenLM/qwen-code/pull/10610)

**服务商配置改完即生效。** 改了 `settings.json` 里的 `modelProviders`，当前会话就能用上新配置。详见 PR [#10582](https://github.com/QwenLM/qwen-code/pull/10582)、[#10269](https://github.com/QwenLM/qwen-code/pull/10269)
