Qwen Code 本周发布 v0.19.12、v0.20.0 和 v0.20.1 三个正式版本，220+ 个 PR 合入。

**Agent 跑偏了？打字就能修正。** 模型正在输出时按 Enter，消息会在下一个采样边界引导当前回合；按 Ctrl+Q 则延迟到下一轮。工具执行期间输入的消息同样生效。不用等 Agent 说完再纠正了。

**并行任务终于不打架了。** Web Shell 支持一键创建 Worktree 隔离会话，同一仓库里多个任务各自在独立 git worktree 中运行，文件编辑、`git add`、`git checkout` 互不干扰。紫色 ⑂ 标识贯穿 git chip、会话列表和 workspace 下拉菜单。

**联网搜索回来了。** 内置 `web_search` 工具基于百炼 Responses API，用你已有的百炼 API key 就能搜索。之前被移除后社区一直要求恢复，这次用服务端搜索 + 页面阅读重新实现，回答末尾自动附 Sources 引用链接。默认关闭，显式开启才生效。

**`web_fetch` 从头重建。** 之前抓网页会丢链接、PDF 变乱码、大页面截断后答案丢失。现在 HTML 先转 markdown 再截断、PDF 内联提取文本、二进制文件正确保存，还有 60 秒超时和 10MB 上限保护。

## ✨ 新增特性

### 实时转向：Agent 输出时打字就能修正方向

之前 Agent 正在输出时你打了一句话，得等它说完才能发出去，变成一个新的 prompt。Agent 跑偏了也只能看着它跑完再纠正。

现在 Enter 和 Ctrl+Q 有了明确的分工：

- **Enter**：消息排入转向队列，在下一个模型采样边界生效，仍然在当前回合内。Agent 正在写代码，你打一句 " 用 TypeScript 重写 "，它会在下一个采样点收到这个引导。
- **Ctrl+Q**：消息延迟到当前回合结束后，作为新一轮对话的开头。
- **工具执行期间**：输入的消息在工具结果返回后、同一回合内被消费。
- **反悔了？** 按 Up 或 Escape，排队的消息恢复到输入框。

@ 附件也会一起保留，不会被加上合成前缀。投递失败或取消时，消息不会丢失。

你能用它做什么：

- Agent 写代码方向不对，打字就能修正，不用等它写完
- 工具跑着的时候补充上下文信息
- 想好下一轮要问什么，Ctrl+Q 排队，当前回合结束自动发出

详见 PR [#7090](https://github.com/QwenLM/qwen-code/pull/7090)

### Worktree 隔离会话：并行任务各跑各的

在同一个仓库里同时处理两个任务，一个会话改了文件，另一个的 `git status` 就乱了。之前要手动 `git worktree add` + `cd`，现在 Web Shell 里一键搞定。

点击 workspace 分支 pill 下拉菜单的 "New Worktree Task"，daemon 自动在 `<repoRoot>/.qwen/worktrees/<slug>` 下创建 git worktree，会话的工作目录切到 worktree。整个界面用紫色 ⑂ 标识区分：git chip 变紫色、会话列表有 ⑂ 标记、workspace 下拉菜单有说明。非 git 仓库不显示这个选项。

Worktree 信息持久化到 sidecar 文件，daemon 重启后不丢失。恢复会话时自动重建 worktree 隔离，状态栏显示 worktree 分支名而不是主 workspace 分支。

你能用它做什么：

- 同时跑两个功能开发，互不干扰
- 一边修 bug 一边继续做 feature，不用 stash 来 stash 去
- 让 Agent 在隔离环境里做实验性修改，主工作区保持干净

### 内置 web_search：百炼 key 即可联网搜索

之前 Qwen Code 没有内置搜索，文档让你去配百炼 WebSearch MCP。但实测下来，那个 MCP 在复杂查询上质量不行——一个有标准答案的 Medicare 费率查询，MCP 跑多次返回 0/5 相关结果。

这周内置 `web_search` 工具回归了。基于百炼 Responses API 的服务端搜索，用你已经配好的百炼 API key 就行，不需要额外的 MCP 服务、额外的 provider、额外的 key。搜索代理会打开结果页面获取更有依据的回答，结果区分 " 实际读过的页面 " 和 " 未打开的候选链接 "，模型必须在回答末尾附上 Sources 引用小节。

**默认关闭**，需要两项配置才能启用：`tools.webSearch.enabled: true` 和搜索模型 `tools.webSearch.model`。如果配了但没配对，工具保持关闭，启动时会告诉你具体哪个条件没满足。也支持纯环境变量配置（`ENABLE_WEB_SEARCH`、`WEB_SEARCH_MODEL` 等），适合写不了 settings.json 的环境。每次搜索调用都需要确认（显示查询内容，可选 " 始终允许 "）。

你能用它做什么：

- 查时效性信息：库的最新版本变更、API 文档更新、安全公告
- 排查模型知识截止日期之后的问题：新版本 breaking change、最近的 bug report
- 替代手动离开终端去浏览器搜索的流程

详见 PR [#7215](https://github.com/QwenLM/qwen-code/pull/7215)

### web_fetch 全面重建：PDF 不再乱码、链接不再丢失

之前 `web_fetch` 有几个实际遇到的问题：大型列表页在转换前按原始 HTML 截断，答案被切掉，链接 URL 全部丢失，模型就自信地告诉你 " 目标不存在 "。PDF 被当文本解码，变成几万 token 的乱码。某些政府网站对匿名 User-Agent 返回 403。

这周从头重建了整个管线：

- **HTML 先转 markdown 再截断**，大页面深处的内容保留，所有超链接保留 URL。截断有显式标记，脚本和样式不占内容预算。
- **PDF 内联提取文本**，单次 `web_fetch` 调用就能回答 PDF 内容。二进制文件通过 magic bytes 识别（不只看 Content-Type），以正确扩展名保存。
- **60 秒超时 + 10MB 上限**，按 Esc 立即取消传输——之前 UI 可能冻住。15 分钟内重复抓取同一 URL 走缓存。
- **跨主机重定向不再静默跟随**，而是提示你重新发起，走正常权限流程。
- **权限模型**：每个主机首次访问需确认（GET 会暴露完整路径和查询，是数据外泄通道）。批准后持久化为按主机规则。GitHub blob URL 自动规范化为 raw 地址再评估权限。

你能用它做什么：

- 抓一个 PDF 链接，直接回答里面的内容
- 抓一个长列表页面，问页面深处的条目，链接不再丢失
- 跨主机重定向会提示你重新发起，不会静默跟随到陌生域名

详见 PR [#7146](https://github.com/QwenLM/qwen-code/pull/7146)

### Web Shell 本周大更新

Web Shell 这周改动量很大，从 git 集成到会话管理到 workspace 体验，集中说。

**Git 集成三件套。** `/log` 命令打开提交历史浏览器，图形化弹窗展示 commit 列表，点击展开看完整 message 和文件变更统计，一键复制 SHA，支持分页加载。`/diff` 弹窗也加了 History 标签页，不用切命令。git status chip 显示在 composer 工具栏，侧边栏展示工作区 git 状态，Changes 弹窗里能看可视化的 working-tree diff。详见 PR [#7204](https://github.com/QwenLM/qwen-code/pull/7204)、[#7054](https://github.com/QwenLM/qwen-code/pull/7054)

**Skill 管理页和 Goals 页。** Web Shell 有了独立的 skill 管理页面，查看和管理工作区 skill 不用回到终端。Goals 页让 `/goal` 的目标在 Web Shell 里可视化，daemon 重启后目标不再丢失。详见 PR [#7018](https://github.com/QwenLM/qwen-code/pull/7018)、[#6561](https://github.com/QwenLM/qwen-code/pull/6561)

**会话管理改进。** Cmd+B / Ctrl+B 切换侧边栏，split view 布局跨刷新保持（按标签页独立），恢复的会话历史支持分页加载不再一次全拉，归档会话支持导出。Add Workspace 弹窗加了目录自动补全。详见 PR [#7135](https://github.com/QwenLM/qwen-code/pull/7135)、[#7136](https://github.com/QwenLM/qwen-code/pull/7136)、[#7064](https://github.com/QwenLM/qwen-code/pull/7064)、[#6910](https://github.com/QwenLM/qwen-code/pull/6910)、[#7125](https://github.com/QwenLM/qwen-code/pull/7125)

**Workspace 体验。** 支持自定义 workspace 显示名称，多工作区场景下不再只能看路径。自定义斜杠命令动作，sidebar 自定义 API（品牌、导航、会话操作、footer）。新话题草稿会建议你开新会话，而不是在旧会话里继续。详见 PR [#7179](https://github.com/QwenLM/qwen-code/pull/7179)、[#7267](https://github.com/QwenLM/qwen-code/pull/7267)、[#7379](https://github.com/QwenLM/qwen-code/pull/7379)、[#7098](https://github.com/QwenLM/qwen-code/pull/7098)

## 👏 体验优化

**VP 模式鼠标选择回来了。** 之前 VP 模式的鼠标事件被 CLI 消费，没法选择复制。现在拖拽选择、双击选词、三击选行，松开自动复制到剪贴板。详见 PR [#6937](https://github.com/QwenLM/qwen-code/pull/6937)

**Ctrl+C 防误触。** 退出 TUI 需要 1 秒内按两次 Ctrl+C，单次不再直接退出。详见 PR [#7129](https://github.com/QwenLM/qwen-code/pull/7129)

**其他改进。** 每轮工具调用上限改为自适应、headless 模式支持上下文继承的子 agent、活跃 loop 中可以使用 goal 控制、流式输出时显示模式指示器、npm 更新改为后台安全执行。详见 PR [#7052](https://github.com/QwenLM/qwen-code/pull/7052)、[#7378](https://github.com/QwenLM/qwen-code/pull/7378)、[#7202](https://github.com/QwenLM/qwen-code/pull/7202)、[#7219](https://github.com/QwenLM/qwen-code/pull/7219)、[#7322](https://github.com/QwenLM/qwen-code/pull/7322)
