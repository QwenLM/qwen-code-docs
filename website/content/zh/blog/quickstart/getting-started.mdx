## 安装 Qwen Code

Qwen Code 支持通过脚本一键安装，Windows、macOS、Linux 都覆盖。

**macOS / Linux：**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows（PowerShell）：**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

安装完成后，运行 `qwen --version` 确认安装成功。如果你想用 npm 安装，也可以：

```bash
npm i @qwen-code/qwen-code@latest -g
```

## 配置模型服务商

安装完成后，Qwen Code 会引导你连接模型服务商。推荐使用阿里云百炼平台。

1. 前往[阿里云百炼](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key)获取 API Key
2. 在终端运行 `qwen` 启动，选择 Alibaba ModelStudio
3. 粘贴你的 API Key，选择模型

如果你更喜欢手动配置，编辑 `~/.qwen/settings.json`：

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "你的API-KEY"
  }
}
```

配置完成后用 `/model` 命令查看和切换模型：

## 开始第一次对话

进入你的项目目录，启动 Qwen Code：

```bash
cd your-project && qwen
```

直接用自然语言描述你想做的事情。比如：

```
帮我写一个 Python 函数，计算斐波那契数列
```

或者让 AI 帮你整理文件：

```
把这个文件夹里的文件按类型整理到不同文件夹中
```

Qwen Code 会自动拆解任务、执行操作、返回结果。你不需要一步步教它怎么做，描述目标就行。

## 安装 Skills 扩展

Skills 是 Qwen Code 的能力扩展系统。你可以按需安装社区开发的 Skill，让 AI 具备更多专业能力。

安装一个 Skill 很简单，一句话就行：

```
帮我安装 find-skills
```

或者直接用命令：

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

安装完成后用 `/skills` 查看已安装的 Skills。
