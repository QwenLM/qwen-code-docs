# 终端与日常交互

在项目目录运行 `qwen`，即可进入交互会话。输入任务，处理权限提示，完成后检查变更再提交。使用 `/help` 查看当前会话可用命令；已安装资源和功能配置会影响这个列表。

## 输入与快捷键

| 操作 | 默认输入 |
| --- | --- |
| 发送消息或确认对话框选项 | Enter |
| 输入换行 | Ctrl+J；终端支持时也可用 Shift+Enter |
| 移动到输入开头或结尾 | Ctrl+A / Ctrl+E |
| 删除光标到输入结尾或开头的内容 | Ctrl+K / Ctrl+U |
| 上一条 / 下一条输入历史 | Ctrl+P / Ctrl+N |
| 搜索输入历史 | Ctrl+R |
| 关闭对话框或取消其当前操作 | Esc |
| 展开或收起快捷键提示 | `/shortcuts` |

快捷键随界面上下文变化，请以界面提示为准。例如，在会话浏览器中，Ctrl+A 切换项目筛选范围，不用于编辑输入。

如果组合 Enter 键变成发送消息，请先使用 Ctrl+J，再运行 `/terminal-setup`。该命令根据终端检查原生支持、安装支持的快捷键，或给出手动设置说明；它可能修改终端配置。此功能用于交互式 CLI，不应作为批处理命令调用。

## 外观与编辑

使用 `/theme` 选择主题，`/settings` 查看偏好设置，`/editor` 选择编辑器，`/vim` 切换 Vim 输入模式。Vim 模式中，注意界面的 NORMAL/INSERT 状态，使用 Esc 和 `i` 切换。这些设置影响交互，不改变模型访问权限或工具权限。

## 输出样式

`/output-style` 打开样式浏览器。选择后，样式保存在项目本地设置中，**仅对下一段会话生效**。准备好后使用 `/clear` 或 `/new` 开始新会话，当前会话继续使用原样式。

用户级样式目录为 `~/.qwen/output-styles/`，项目级目录为 `.qwen/output-styles/`；自定义用户配置根目录会改变用户级位置。也可以启动时使用 `qwen --output-style <name>` 选择样式。请在浏览器中检查实际可用定义，不要假设其他环境也安装了某插件提供的样式。插件强制启用的样式不能通过此选择器替换。

## 自定义状态栏

例如：

```text
/statusline 显示当前项目和 Git 分支
```

Qwen Code 会将配置需求提交给模型，由状态栏配置 Agent 检查配置并创建脚本。这是一次 Agent 任务，可能读取 Shell 配置和编辑文件，并受正常权限约束；请检查生成的脚本和设置变更。配置完成后，状态栏随回复更新。

## 复制与导出

`/copy` 复制最近一次助手回复，`/copy 2` 选择倒数第二次回复。回复包含代码块时，根据复制偏好，界面可提供代码块或全文选项。`/export` 打开会话导出选项；`/export review.txt` 将文本导出到当前工作目录下。导出内容可能包含提示词、代码及工具输出，分享前请检查。

开始新会话、创建分支和恢复历史的方法见[会话管理](/zh/users/sessions/)。
