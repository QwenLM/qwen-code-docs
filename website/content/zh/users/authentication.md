# 登录与认证

使用 `/auth` 连接模型服务。`/connect` 和 `/login` 是同一命令的别名。实际可用性取决于账号、地区、服务商凭据及当前构建。

## 选择连接方式

| 入口 | 连接方法 |
| --- | --- |
| Qoder | 按提示完成 Qoder 账号登录。 |
| Qwen Account | 按提示完成 Qwen 账号订阅登录。当前对话框要求有效的 Plus 或 Pro 套餐。 |
| QwenCloud | 选择提供的 Token Plan 或标准 API Key 连接。 |
| Alibaba Cloud Model Studio | 选择提供的 Coding Plan、Token Plan 或标准 API Key 连接。 |
| Other Providers | 选择可用预设，并填写对应服务商的凭据。 |
| Custom Provider | 配置兼容端点、协议、凭据和模型。 |

账号登录和 API Key 是不同的连接方式。拥有账号订阅，不等于自动获得另一个 API 端点的调用权限。可用范围、价格、额度和活动权益由服务商决定，本文档不承诺这些权益。

## 连接并选择模型

1. 在项目中运行 `qwen`，输入 `/auth`。
2. 选择连接类型，并按界面提示操作。
3. 完成浏览器登录，或填写要求的服务商配置。
4. 打开 `/model`，选择当前连接可用的模型。
5. 先发送一个简短请求验证连接，再开始较长任务。

没有出现在列表中的 API 端点，可以通过 Custom Provider 接入，也可以按[模型与服务商](/zh/users/models/)修改 `providers` 配置。将密钥保存在环境变量中，不要提交到项目配置。

## 切换连接

重新打开 `/auth` 可以连接其他服务商。用 `/model` 在可用模型之间切换。模型选择与凭据是否有效是两回事：选择一个模型并不会自动获得访问权限。

修改服务商定义后，需要重新启动 CLI。编辑配置后服务商未出现时，先查看配置校验错误，重启后再试。

## 退出登录

```text
/logout
```

`/signout` 是同一命令的别名。此命令退出当前选中的 Qoder 或 Qwen Account 连接，并清除其选中的认证类型。对于当前 Qwen 订阅连接，还会移除保存的对应服务商条目。

退出登录后，当前模型选择可能仍然保留。如果该模型已不可用，请使用 `/model` 选择其他模型，或重新登录。

其他连接类型下，`/logout` 会提示使用 `/auth` 切换服务商。它不会在服务商侧吊销 API Key，也不会清除所有已配置连接。需要移除连接时，删除相应配置来源中的服务商定义；密钥泄露时，应通过服务商自身的管理入口吊销。

## 认证失败时

先检查当前连接和模型。账号登录成功不代表账号拥有所选模型的权限。API Key 连接需要检查端点、协议，以及启动 Qwen Code 的 shell 中是否已导出环境变量。

提交问题时不要附带令牌、包含凭据的浏览器回调地址或未脱敏配置。详见[故障排查](/zh/users/troubleshooting/)。
