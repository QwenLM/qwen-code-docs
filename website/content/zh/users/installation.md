# 安装与更新

> Qwen Code 1.0 Preview 的发行方式正在确认中。版本发布时，将补充公开安装命令、下载位置及实际提供的发行产物。

本页介绍安装后的验证方法，以及配置了发行源的构建中可用的更新命令。这不代表公开 Preview 安装包已经发布。

## 验证可执行程序

按照 Preview 版本的发行说明获取程序后，打开新终端并执行：

```sh
qwen --version
qwen --help
```

使用本文档前先核对版本。旧版本的配置、认证流程和命令可能不同。如果找不到命令，请检查可执行程序所在目录是否已加入当前 shell 的 PATH。如果机器上有多份安装，请先确认 shell 实际启动的是哪一份，再排查配置。

本文档使用 `qwen` 作为可执行程序名称，不以此指定包管理器或安装方式。

## 检查更新

对于配置了发行源的构建：

```sh
qwen update --check
```

此命令只检查更新，不安装。安装可用更新：

```sh
qwen update
```

更新后重新启动 Qwen Code。已经运行的进程继续使用启动时加载的代码。没有配置发行源的构建不会自行轮询某个默认下载服务。

## 自动更新

配置了发行源的交互式构建可以在启动后检查更新。在用户配置中加入以下内容，可以关闭自动安装、保留更新通知：

```json
{
  "general": {
    "enableAutoUpdate": false,
    "enableAutoUpdateNotification": true
  }
}
```

两个值均设为 `false` 时，关闭自动安装和更新通知。这些设置控制交互式自动更新流程，显式执行更新命令是单独的操作。

## 回退版本

配置的发行源中存在兼容目标版本时，可以执行：

```sh
qwen rollback --to '<version>'
```

将 `<version>` 替换为实际可用且早于当前生效版本的版本；当前版本或更新版本会被拒绝。回退成功后，自动更新暂停 24 小时。回退改变已安装的程序，不负责备份或恢复项目文件、配置或会话数据。

更新或回退失败时，保留错误信息和当前版本。重试前先检查发行源与网络连接，不要通过反复更换登录凭据解决下载失败。
