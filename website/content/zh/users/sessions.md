# 会话、分支与回退

会话保存一段对话及其状态。独立任务适合使用独立会话；需要在已有讨论基础上探索不同方案时，可以创建会话分支。

## 查找与恢复工作

| 命令 | 效果 |
| --- | --- |
| `/resume` | 打开会话浏览器 |
| `/resume <identifier>` | 按标识查找会话 |
| `/continue` | 继续当前项目最近的会话 |
| `/rename <name>` | 设置当前会话的显示名称 |
| `/new` 或 `/clear` | 开始新会话 |

也可以启动时选择：

```bash
qwen --continue
qwen --resume '<session-id>'
qwen --list-sessions
qwen --name "API migration"
```

找不到会话时，请在对应项目目录启动，并检查会话浏览器中的项目、分支和 worktree 筛选。自定义 `--config-dir` 也可能改变可用的用户数据。

`qwen --delete-session <index>` 按列表序号删除已保存会话。选择序号前请重新列出会话。删除会话记录不会撤销该会话产生的代码修改。

## 创建会话分支

已有可见对话消息后，运行：

```text
/branch 另一种实现方案
```

命令从当前对话创建新会话并切换过去，同时提示恢复原会话的方法。分支复制对话状态，包括可用的运行时偏好和工作区信息；它不会创建独立 Git 分支或文件副本。在已有 worktree 中，新的会话分支仍附着于该 worktree。

也可启动时使用 `qwen --resume <session-id> --fork-session`，从恢复的会话创建新会话。若两种方案还需要独立工作文件，请使用 [worktree](/zh/users/workspaces/)。

## 回退

`/rewind`（别名 `/checkpoint`）打开回退选择器。选择历史节点后，查看可用的对话、文件或两者同时恢复选项。确认界面会说明能够恢复的文件变更，以及缺少可用备份的文件。

回退受已记录文件历史限制。**手工编辑或通过 Shell 命令修改的文件可能无法恢复。** 仅恢复对话会保留当前文件；恢复文件可能覆盖后续编辑。请检查预览，并用 Git 提交或备份保存需要保留的变更。回退不会撤销部署、已发送请求等外部操作。

## 导出与持久化

`/export` 可保存便于阅读的会话内容。导出文件用于审阅和分享，不替代 `/resume` 所需的会话存储格式。

非交互任务中，`--no-session-persistence` 配合 `--print` 使用，使该会话不保存为可恢复记录：

```bash
qwen --print --no-session-persistence "总结项目结构"
```

此选项只控制会话持久化，不代表完全不写入诊断日志或其他应用数据。
