# Qwen Code 快捷键

本文档列出了 Qwen Code 中可用的快捷键。

## 通用

| 快捷键                           | 描述                                                                                                                                                                                                                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                            | 关闭对话框和建议。                                                                                                                                                                                                                                                                                 |
| `Ctrl+C`                         | 取消正在进行的请求并清空输入。按两次退出应用程序。                                                                                                                                                                                                                                                 |
| `Ctrl+D`                         | 如果输入为空，则退出应用程序。按两次确认。                                                                                                                                                                                                                                                         |
| `Ctrl+L`                         | 清屏。                                                                                                                                                                                                                                                                                             |
| `Ctrl+O`                         | 切换紧凑模式（隐藏/显示工具输出和思考过程）。                                                                                                                                                                                                                                                      |
| `Ctrl+S`                         | 允许完整打印长响应，禁用截断。使用终端的回滚功能查看完整输出。                                                                                                                                                                                                                                     |
| `Ctrl+T`                         | 切换工具描述的显示。                                                                                                                                                                                                                                                                               |
| `Ctrl+B`                         | 当前台 shell 命令运行时：将其提升为后台任务。子进程继续运行，agent 的回合解除阻塞，shell 会出现在 `/tasks` 和后台任务对话框中。如果没有 shell 在执行，则无操作——此时 Ctrl+B 会回退到其在提示区域的绑定（光标左移）。                                                                               |
| `Alt/Option+M`                   | 在富文本渲染预览和原始/源码模式之间切换 Markdown 输出。在 macOS 上，终端必须将 Option 键作为 Meta 键发送。                                                                                                                                                                                         |
| `Shift+Tab`（Windows 上为 `Tab`）| 循环切换审批模式（`plan` → `default` → `auto-edit` → `auto` → `yolo`）                                                                                                                                                                                                                             |

## 输入提示符

| 快捷键                                                | 描述                                                                                                                          |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `!`                                                   | 当输入为空时，切换 shell 模式。                                                                                               |
| `?`                                                   | 当输入为空时，切换快捷键显示。                                                                                                |
| `Ctrl+Enter` / `Cmd+Enter` / `Shift+Enter` / `Ctrl+J` | 插入换行符。                                                                                                                  |
| `Down Arrow`                                          | 向下移动一行，然后跳转至行尾，然后查看下一条历史记录。                                                                        |
| `Enter`                                               | 提交当前提示词。                                                                                                              |
| `Meta+Delete` / `Ctrl+Delete`                         | 删除光标右侧的单词。                                                                                                          |
| `Tab`                                                 | 如果存在当前建议，则自动补全。                                                                                                |
| `Up Arrow`                                            | 向上移动一行，然后跳转至行首，然后查看上一条历史记录。                                                                        |
| `Ctrl+A` / `Home`                                     | 将光标移动到行首。                                                                                                            |
| `Ctrl+B` / `Left Arrow`                               | 将光标向左移动一个字符。                                                                                                      |
| `Ctrl+C`                                              | 清空输入内容                                                                                                                  |
| `Esc`（按两次）                                       | 清空输入内容。                                                                                                                |
| `Ctrl+D` / `Delete`                                   | 删除光标右侧的字符。                                                                                                          |
| `Ctrl+E` / `End`                                      | 将光标移动到行尾。                                                                                                            |
| `Ctrl+F` / `Right Arrow`                              | 将光标向右移动一个字符。                                                                                                      |
| `Ctrl+H` / `Backspace`                                | 删除光标左侧的字符。                                                                                                          |
| `Ctrl+K`                                              | 删除从光标到行尾的内容。                                                                                                      |
| `Ctrl+Left Arrow` / `Meta+Left Arrow` / `Meta+B`      | 将光标向左移动一个单词。                                                                                                      |
| `Ctrl+N`                                              | 向下移动一行，然后跳转至行尾，然后查看下一条历史记录。                                                                        |
| `Ctrl+P`                                              | 向上移动一行，然后跳转至行首，然后查看上一条历史记录。                                                                        |
| `Ctrl+R`                                              | 反向搜索输入/shell 历史记录。                                                                                                 |
| `Ctrl+Y`                                              | 重试上一次失败的请求。                                                                                                        |
| `Ctrl+Right Arrow` / `Meta+Right Arrow` / `Meta+F`    | 将光标向右移动一个单词。                                                                                                      |
| `Ctrl+U`                                              | 删除从光标到行首的内容。                                                                                                      |
| `Ctrl+V`（Windows：`Alt+V`）                          | 粘贴剪贴板内容。如果剪贴板包含图片，图片将被保存，并在提示词中插入对它的引用。                                                |
| `Ctrl+W` / `Meta+Backspace` / `Ctrl+Backspace`        | 删除光标左侧的单词。                                                                                                          |
| `Ctrl+X`                                              | 在外部编辑器中打开当前输入内容。                                                                                              |

## 建议

| 快捷键                  | 描述                       |
| ----------------------- | -------------------------- |
| `Down Arrow` / `Ctrl+N` | 向下导航建议。             |
| `Tab` / `Enter`         | 接受选中的建议。           |
| `Up Arrow` / `Ctrl+P`   | 向上导航建议。             |

## 单选按钮选择

| 快捷键                        | 描述                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------ |
| `Down Arrow` / `j` / `Ctrl+N` | 向下移动选择。                                                                                         |
| `Enter`                       | 确认选择。                                                                                             |
| `Up Arrow` / `k` / `Ctrl+P`   | 向上移动选择。                                                                                         |
| `1-9`                         | 通过数字选择项目。                                                                                     |
| （多位数字）                  | 对于数字大于 9 的项目，快速连续按下数字键以选择相应的项目。                                            |

## 历史记录回滚

仅在启用 `ui.useTerminalBuffer`（设置 → UI → 虚拟化历史记录）时生效。在该模式下，对话历史记录在应用内的视口中渲染，而不是在宿主终端的回滚区中渲染，因此以下按键将替代终端的原生滚动。

| 快捷键            | 描述                                         |
| ----------------- | -------------------------------------------- |
| `Shift+Up`        | 向上滚动一行历史记录。                       |
| `Shift+Down`      | 向下滚动一行历史记录。                       |
| `PgUp`            | 向上滚动一页历史记录（视口高度）。           |
| `PgDn`            | 向下滚动一页历史记录（视口高度）。           |
| `Ctrl+Home`       | 跳转到对话顶部。                             |
| `Ctrl+End`        | 跳转到底部（并重新启用实时自动跟随）。       |
| **鼠标滚轮**      | 滚动历史记录（每次滚动 3 行）。              |
当开启 `ui.useTerminalBuffer` 时，终端会将鼠标事件转发给 qwen-code，从而允许通过鼠标滚轮控制应用内视口。作为副作用，**程序会拦截原生的点击拖拽文本选择操作** —— 在拖拽时按住 `Shift`（在 macOS 终端 / iTerm 中为 `Option`）可以绕过鼠标捕获，以常规方式选择文本。

### tmux 触控板滚动

在 tmux 内部，某些终端会在 qwen-code 接收到事件之前，将触控板或滚轮手势转换为普通的 `Up Arrow` 和 `Down Arrow` 序列。这些字节与真实的按键操作完全相同，因此 qwen-code 无法区分你是想滚动视口还是浏览历史命令。

如果在 tmux 中触控板滚动会切换历史命令，请启用 `ui.useTerminalBuffer`；然后使用 `Shift+Up` / `Shift+Down`，或者在 tmux 将滚轮事件转发给应用时使用鼠标滚轮。如果你更倾向于使用宿主机的回滚缓冲区，请调整 tmux 中针对滚轮事件的鼠标绑定。
