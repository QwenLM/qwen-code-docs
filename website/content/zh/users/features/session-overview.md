# 会话概览

在 Web Shell 中使用会话概览来浏览会话、返回对话，以及管理会话标题与归档。

## 查找并打开会话

打开 **More → Session Overview**。可按会话标题、会话 ID、Git 分支或关联的 pull request 编号（如 `#123`）进行搜索。使用状态筛选器缩小列表范围。当有多个工作区可用时，工作区筛选器可让你选择要包含哪些工作区。选择 **Refresh** 重新加载目录。

点击会话行即可打开该对话。使用行复选框选择会话以执行页脚操作；分页控件用于切换可见页面与行数。

## 重命名会话

当行上的铅笔操作可用时，选择它并编辑标题。按 **Enter** 保存，或按 **Escape** 取消。如果编辑器失去焦点，则未完成的重命名会被取消而非保存。

## 归档会话

使用行复选框选择会话，然后在页脚中选择 **Archive**。仅当所有选中的会话都处于空闲状态且支持归档时，该操作才会启用。在对话框中确认以执行归档，或选择 **Cancel** 使会话保持活动状态。

如果在点击 **Archive** 时重命名编辑器仍处于聚焦状态，其未完成的草稿会被取消，并打开归档确认对话框。进入或取消重命名时，页脚控件保持原位，因此靠近按钮边缘的点击仍能命中该按钮。
