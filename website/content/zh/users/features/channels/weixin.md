# 微信 (WeChat)

本指南介绍如何通过官方 iLink Bot API 在微信上配置 Qwen Code 频道。

## 前置条件

- 一个可扫描二维码的微信账号（移动端应用）
- 可访问 iLink Bot 平台（微信官方机器人 API）
- 该账号已启用微信 ClawBot 插件。下方的登录操作会授权机器人，而插件才会提供一个可以与之对话的会话。参见[在哪里发送消息](#在哪里发送消息)——这是首次配置时最容易遗漏的一步。

## 在 Web Shell 中配置

浏览器 UI 可以处理整个流程，包括二维码登录——无需终端，也无需手动编辑配置文件。

1. 打开 **Channel settings**，从可用平台中选择 **WeChat**。
2. 在编辑器的凭据区域，微信账号面板会显示当前是否已登录。点击 **Log in with QR code**。
3. 使用微信扫描生成的二维码，并在手机上确认。面板会依次显示"Scan the QR code"→"Scanned"→"WeChat connected"，守护进程会自动保存凭据。
4. 填写频道名称、工作空间和访问策略，然后点击 **Save**。建议将 allowlist 留空，改为在 **Pending requests** 中审批发送者——参见[谁可以与它对话](#谁可以与它对话)。
5. 从频道卡片启动频道。
6. 在微信 ClawBot 会话中发送消息——[在哪里发送消息](#在哪里发送消息)。

面板还提供 **Log in again** 和 **Log out**。如果二维码过期，点击 **Refresh QR code**。当编码器无法生成二维码时，面板会改为显示登录 URL 链接。

有两点需要注意：

- 该账号由**此守护进程上的所有微信频道共享**。重新登录会替换它。已在运行的频道会保留旧账号，直到你重启它们。
- 保存频道不需要已登录。你可以预先配置，但启动频道确实需要已登录的账号。

如果面板提示守护进程不支持微信登录，请更新守护进程或使用下方的终端方式。

## 通过终端配置

### 1. 通过二维码登录

微信使用二维码认证而非静态机器人 token。运行以下登录命令：

```bash
qwen channel configure-weixin
```

该命令会显示一个二维码 URL。使用微信移动端应用扫描二维码完成认证。认证凭据会保存到 `~/.qwen/channels/weixin/account.json`。

### 2. 配置频道

将频道配置添加到 `~/.qwen/settings.json`：

```json
{
  "channels": {
    "my-weixin": {
      "type": "weixin",
      "privatePolicy": "pairing",
      "allowedUsers": [],
      "sessionScope": "user",
      "cwd": "/path/to/your/project",
      "model": "qwen3.5-plus",
      "instructions": "You are a concise coding assistant responding via WeChat. Keep responses under 500 characters. Use plain text only."
    }
  }
}
```

注意：微信频道不使用 `token` 字段——认证凭据来自二维码登录步骤。

### 3. 启动频道

```bash
# 仅启动微信频道
qwen channel start my-weixin

# 或同时启动所有已配置的频道
qwen channel start
```

然后向机器人发送消息——参见下一节了解应使用哪个会话。

## 在哪里发送消息

**使用"微信ClawBot"会话，而不是向某个微信账号发送私聊消息。**

扫描二维码只是为你的账号授权了一个机器人，并不会把该账号变成机器人。插件激活后，在扫描二维码的账号的聊天列表中会出现一个名为 **微信ClawBot** 的独立会话。打开该会话并在那里发送消息。代理处理消息时，你应该会看到输入状态指示符（"..."），随后显示回复。

在测试之前，有两点值得了解：

- **向扫码账号发送的私聊消息永远不会到达频道。** 它只会作为普通聊天出现在你手机的微信中，频道完全看不到——没有错误、没有日志、没有配对请求。所有诊断都显示正常，但什么都不会发生。
- **机器人绑定到扫码的账号。** 其他人无法通过向该账号发消息来触达机器人，机器人也无法自行发起会话：总是由你先发送第一条消息。

如果微信ClawBot会话不存在，说明插件尚未激活。根据微信的 [ClawBot 文档](https://developers.weixin.qq.com/doc/aispeech/knowledge/openapi/Clawbotrelated.html)，插件在扫码账号的微信设置中管理，并且需要较新版本的微信以及设备上安装了 OpenClaw。请参阅该页面了解当前的版本要求和绑定步骤，而不是引用此处的版本号。

## 谁可以与它对话

在默认的 `privatePolicy: "pairing"` 策略下，来自未识别发送者的第一条消息**不会传递给代理**：频道会记录一个配对请求，回复一个 8 字符的配对码，然后丢弃消息本身。所以确实会收到回复——只是不是你所问问题的答案。审批该请求后，**再发送一条新消息**；审批不会重放被丢弃的那条消息。

在微信ClawBot会话中，你是唯一的发送者，因此你审批的请求就是你自己第一条消息产生的那个。完整流程参见[私聊配对](./overview#dm-pairing)，包括通过终端使用配对码审批。

`allowedUsers` 可以预先审批发送者，使其跳过配对。它匹配的是**平台用户 ID**，形如 `oAbCd… @im.wechat`——不是微信名称或账号。不匹配的条目会被静默忽略，因此在此处填写的账号看起来已配置但永远不会生效。

最简单的方式是**将 `allowedUsers` 留空**，然后在频道编辑器的 **Pending requests** 中审批用户。审批会被持久化，因此重启后仍然有效。如果你确实想预填该字段，请从配对请求中读取真实的 ID，而不是猜测。

## 图片与文件

您可以向机器人发送照片和文档，而不仅仅是文本。

**图片：** 发送图片（截图、照片等），代理将利用其视觉能力进行分析。这需要多模态模型——在频道配置中添加 `"model": "qwen3.5-plus"`（或其他支持视觉的模型）。当图片下载和处理时，会显示输入状态指示符。

**文件：** 发送 PDF、代码文件或任何文档。机器人会从微信 CDN 下载并解密文件，保存到本地，代理再使用文件工具读取。此功能适用于任何模型。

## 配置选项

微信频道支持所有标准频道选项（参见[频道概览](./overview#options)），此外还支持：

| 选项名     | 描述                                                              |
| ---------- | ----------------------------------------------------------------- |
| `baseUrl`  | 覆盖 iLink Bot API 的基础 URL（默认值：`https://ilinkai.weixin.qq.com`） |

## 与 Telegram 的关键区别

- **认证方式：** 二维码登录而非静态机器人 token。会话可能会过期——过期时频道会暂停并记录一条消息。
- **格式：** 微信仅支持纯文本。代理回复中的 Markdown 会被自动移除。
- **输入状态指示符：** 微信原生支持"..."输入状态指示符，而非"正在工作……"的文本消息。
- **群组：** 微信 iLink Bot 仅支持私聊——不支持群聊。
- **媒体加密：** 图片和文件在微信 CDN 上使用 AES-128-ECB 加密。频道会自动处理解密过程。

## 使用技巧

- **使用纯文本指令**——由于微信会移除所有 Markdown，请添加类似"仅使用纯文本"的指令，避免代理生成格式杂乱的回复。
- **保持回复简短**——微信消息气泡适合简洁的文本。在指令中添加字符限制会有帮助（例如"保持回复在 500 字符以内"）。
- **会话过期**——如果在日志中看到"Session expired (errcode -14)"，表明微信登录已过期。停止频道并重新运行 `qwen channel configure-weixin` 来重新登录。
- **限制访问**——使用 `privatePolicy: "pairing"` 或 `"allowlist"` 来控制可以与机器人对话的成员。详情请参阅[私聊配对](./overview#dm-pairing)。

## 故障排除

### "WeChat account not configured"

请先运行 `qwen channel configure-weixin` 通过二维码登录。

### "Session expired (errcode -14)"

您的微信登录会话已过期。停止频道并重新运行 `qwen channel configure-weixin`。

### 机器人无响应

按顺序排查——前两种情况在任何地方都不会产生错误，因此仅查看日志无法发现它们：

1. **你发送到了哪个会话？** 必须是微信ClawBot，而不是向某个微信账号发送私聊消息。参见[在哪里发送消息](#在哪里发送消息)。
2. **你是否审批了配对请求并发送了新消息？** 触发请求的那条消息已被丢弃，审批不会将其恢复。
3. 确认频道正在运行（`qwen channel status`，或 `qwen channel start my-weixin`）。
4. 检查终端输出中的错误。`[weixin] Poll error` 指向上游连接问题；`Session expired (errcode -14)` 表示需要重新登录。
5. 如果你预填了 `allowedUsers`，请确认条目是平台用户 ID（`oAbCd… @im.wechat`），而不是微信账号。不匹配的条目会被静默忽略，没有任何警告。

**区分"没有消息到达"和"消息到达但被拒绝"。** 频道会将入站决策记录到其状态目录（`~/.qwen/channels/<workspace-scope>/`）下的 `<channel>-<hash>-channel-events.jsonl`。如果该文件不存在，说明没有消息到达过频道——原因在上游，几乎总是你发送消息的会话。如果文件存在且包含 `"outcome":"skipped"` 和 `"reason":"sender_pairing_required"`，说明消息已到达并等待审批，记录中的 `actor` 字段就是要审批或加入 allowlist 的确切平台用户 ID。

### 图片无法正常使用

- 确保频道配置中使用了支持视觉的 `model`（例如 `qwen3.5-plus`）
- 检查终端中的 CDN 下载错误——可能表明存在网络问题
