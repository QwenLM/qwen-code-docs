# 快速开始

Qwen Code 是终端中的编程 Agent。进入项目、连接模型服务后，即可描述任务。它可以检查文件、提出并执行修改，并按照当前权限调用工具。

## 1. 打开项目

[获取 Preview 构建](/zh/users/installation/)后，进入项目目录：

```sh
cd /path/to/project
qwen
```

也可以显式指定工作目录：

```sh
qwen --cwd /path/to/project
```

出现工作区信任提示时，请检查项目来源。项目配置会影响 Agent 的运行方式，只应信任经过检查、准备开展工作的项目。详见[权限与工作区信任](/zh/users/permissions/)。

## 2. 连接模型服务

按照启动时的连接对话框完成设置。之后随时可以重新打开：

```text
/auth
```

选择账号登录、已有服务商预设或自定义端点。各入口及要求见[登录与认证](/zh/users/authentication/)。连接完成后，用 `/model` 查看并选择模型。

## 3. 从范围明确的任务开始

例如：

```text
解释这个项目如何启动，以及主要测试在哪里定义。
先阅读相关文件，并在说明中给出文件路径。
```

然后提出具体修改：

```text
为项目名称为空的情况增加校验。沿用现有的校验模式，
并运行覆盖此次行为变更的测试。
```

接受工具授权前，检查具体请求。在任务中写明要保留的文件、不要执行的命令以及预期测试。模型回答和代码修改仍需审阅。

## 4. 检查结果并继续会话

用 `/diff` 检查修改，用 `/context` 查看上下文使用情况。用 `/help` 查看可用命令，用 `/shortcuts` 查看当前快捷键。

退出后，可以继续最近的会话：

```sh
qwen --continue
```

用 `qwen --resume` 选择历史会话。可恢复的会话取决于工作目录及本地持久化数据。建议使用版本控制管理项目，会话历史不能替代仓库备份。

## 5. 执行单次请求

```sh
qwen -p "概括这个项目的用途。"
```

Print 模式不启动完整的交互式终端界面。应事先配置认证，并为无人值守执行选择合适权限，不要假定运行期间能够弹出交互式授权对话框。
