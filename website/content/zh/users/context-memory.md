# 上下文与记忆

Qwen Code 在准备模型请求时，会结合会话历史、项目指令、工具定义及任务相关内容。长期有效的项目约定适合保存在上下文文件中，当前任务通过会话说明。

## 项目指令

默认上下文文件名为 `AGENTS.md`。运行 `/init` 可分析项目并生成针对性的指令，交互模式会提供初始化选项。提交前请检查生成的内容。

例如，在项目根目录放置：

```markdown
# 项目约定

使用 package.json 声明的包管理器。
只运行与改动包相关的测试。
除非任务明确要求，否则保持公开 API 兼容。
说明实际运行的测试和仍未解决的失败。
```

子目录中的指令文件可以补充更具体的规则。文件发现受到工作区和信任范围约束；访问对应目录中的文件时，还可能加载嵌套指令。文件存在于磁盘上，不代表它已进入当前模型请求。使用 `/memory` 查看当前概览。

如需使用其他名称，可配置 `context.fileName`，支持单个名称或名称数组：

```json
{
  "context": {
    "fileName": ["AGENTS.md", "PROJECT.md"]
  }
}
```

已加载指令的变更会在轮次间检查；新出现的嵌套指令会在访问文件时发现。本版本没有 `/memory reload` 命令。

## 查看与压缩上下文

`/context` 展示上下文窗口使用情况，以及会话、系统指令、工具定义等分类。这是上下文诊断信息，不是费用账单。`/context-window` 用于管理支持此功能的模型的窗口偏好；设置更大数值不会扩大服务商的模型实际限制。

`/compact` 用摘要替代此前的会话上下文，也可以指定保留重点：

```text
/compact 保留 API 决策、失败测试名称和尚未完成的迁移步骤
```

摘要可能省略细节。准确要求应保存在项目文件中，继续重要变更前检查摘要是否保留了关键内容。下一项任务无关时，建议开始独立会话。

## 自动记忆

自动记忆按项目级或用户级保存可复用的信息。项目级记忆服务于当前项目；用户级记忆可能影响跨项目工作。它与人工维护的 `AGENTS.md`、保存的会话记录分别管理。

两个设置分别控制记忆范围：

```json
{
  "autoMemoryEnabled": true,
  "autoMemoryUserScopeEnabled": false
}
```

修改后需要重启。未配置时由运行时决定默认值，不能假设每个安装环境都已开启自动记忆。`/memory` 显示概览；启用后，`/memory manage` 可管理自动记忆文件。如果提示未启用，请检查设置并重启。

定期检查保存的信息，特别是在分享工作区之前。记忆提供上下文参考，不保证保存所有历史信息，也不保证信息始终正确。子 Agent 的专属持久记忆见[子 Agent](/zh/users/subagents/)。
