# Взаимодействия при установке расширений демона

## Контекст

Демон устанавливает расширения как асинхронные операции рабочего пространства.
Некоторые расширения требуют, чтобы пользователь выбрал плагин маркетплейса
Claude или предоставил значения конфигурации во время установки.

## Дизайн

Операция расширения может перейти в `waiting_for_input`. Её статус предоставляет
одно нечувствительное взаимодействие за раз:

- `marketplace_plugin` включает имя маркетплейса и плагины, доступные для
  выбора.
- `setting` включает имя настройки, описание, переменную окружения и признак
  чувствительности значения.

Клиент опрашивает существующий эндпоинт статуса операции, затем отправляет
ответ на `POST /workspace/extensions/operations/:operationId/interactions/:interactionId`.
In-memory колбэк операции возобновляется после валидации ответа.

Значения настроек никогда не включаются в статус операции, результаты или
логи. Существующий механизм настроек расширений остается ответственным за их
хранение.

## Время жизни

Операции установки и обновления имеют общее время жизни двадцать минут. Каждое
взаимодействие может использовать до десяти минут оставшегося времени жизни
операции. Другие мутации расширений сохраняют свой существующий таймаут.
Ожидающая операция остается в существующей сериализованной очереди мутаций,
поэтому никакая другая мутация расширения не может наблюдать частично
установленное состояние.
