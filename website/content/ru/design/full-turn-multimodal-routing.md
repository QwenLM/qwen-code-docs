# Полноходовая мультимодальная маршрутизация

## Область

Это реализует только Фазу 1 #6988: когда основная модель текстовая, явно
агентно-способная vision-модель может обработать полный ход, несущий
изображения.

Оно не добавляет персистентное состояние маршрутов, восстановление сессии,
долговечные визуальные сводки, стабильные ссылки на изображения, очистку
исторических медиа или повторную инспекцию изображений позже.

## Гейт возможностей

Полноходовая маршрутизация требует и возможностей изображения, и агента:

```json
{
  "id": "vision-agent",
  "capabilities": {
    "vision": true,
    "agent": true
  }
}
```

Отсутствующая или false-возможность `agent` сохраняет существующее поведение
транскрипции Vision Bridge.

## Маршрутизация

- Если основная принимает изображения, использовать существующий путь
  основной модели.
- Если выбранная vision-модель не агентно-способна, транскрибировать через
  Vision Bridge и отвечать на основной.
- Если выбранная vision-модель агентно-способна, сохранить исходные части
  изображений и установить точный селектор модели на уровне хода.
- Точные провайдер, модель и эндпоинт переиспользуются для повторов
  провайдера, исполнения инструментов, продолжений по результатам
  инструментов и блокирующих продолжений Stop Hook ACP.
- Headless-исполнение инструментов получает то же представление рантайма,
  что и выбранная модель изображений; дренирования уведомлений из очереди и
  cron остаются независимыми ходами и не наследуют его.
- Настроенные фолбэк-модели отключены для этого хода. Неудача разрешения
  точного маршрута завершается fail closed вместо отправки сырых данных
  изображений на основную модель.
- Следующий независимый ход пользователя очищает селектор и возвращается на
  основную. Каждый запрос модели, включая побочные запросы, получает только
  модальности медиа, поддерживаемые его точной целью.

Полноходовый селектор добавляет завершающий NUL-маркер к существующему
представлению `model\0baseUrl`. Слой чата удаляет этот маркер до разрешения
модели. Это сохраняет обычный выбор модели, квалифицированный эндпоинтом, на
его существующем поведении.

## Лимиты контекста

Автоматическое сжатие чата на базе LLM остается на пути основной модели.
Полноходовый маршрут пропускает это сжатие, потому что выполнение сжатия
основной модели, пока ход с изображениями принадлежит другому провайдеру,
нарушило бы гарантию точного маршрута. Существующие локальное микросжатие
истории и облегчение полезных нагрузок изображений все равно применяются, и
копии запроса/кэша сохраняют только модальности медиа, поддерживаемые их
целевой моделью. Поэтому слишком большой полноходовый запрос падает на
выбранной модели.

## Точки входа

Фаза 1 покрывает интерактивный TUI, ACP и неинтерактивный CLI.

Текстовые пути `@` разрешаются в их каноническую цель до обнаружения MIME,
проверок рабочего пространства, фильтрации игнорирования и чтения файлов. И
предоставленный пользователем алиас, и каноническая цель должны пройти
фильтрацию игнорирования, чтобы симлинк не мог замаскировать игнорируемый
файл или цель, не являющуюся изображением. Жесткие ссылки не разрешаются
`realpath` и не покрываются этой проверкой.
