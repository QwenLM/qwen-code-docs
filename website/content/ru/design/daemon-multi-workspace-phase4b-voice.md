# Voice с квалификацией по рабочему пространству

## Цель

Предоставить поверхности настроек Voice демона, пакетной транскрипции и
стриминговой транскрипции для каждого доверенного рантайма рабочего
пространства, не меняя legacy-маршруты только для primary.

## Дизайн

`GET`/`POST /workspaces/:workspace/voice`,
`POST /workspaces/:workspace/voice/transcribe` и
`WS /workspaces/:workspace/voice/stream` разрешают зарегистрированный
доверенный рантайм по id или кодированному cwd. Они используют cwd этого
рантайма, эффективное окружение, бридж и настройки рабочего пространства.
Запись настроек Voice через множественные REST всегда использует область
рабочего пространства; вторичные записи voice ACP используют ту же область,
чтобы они не могли мутировать общие пользовательские настройки.

Один `WorkspaceVoiceCoordinator` с областью процесса владеет существующим
лимитом в восемь активных операций Voice. Он учитывает и WebSocket, и пакетную
REST-работу через legacy-пути и пути с квалификацией по рабочему
пространству. Дренирование при удалении отклоняет новый допуск, но оставляет
существующую работу Voice видимой для снимка активности нефорсированного
удаления. Освобождение рантайма прерывает только аренды Voice выбранного
рантайма до выключения его бриджа.

## Совместимость

Legacy `/workspace/voice`, `/workspace/voice/transcribe` и `/voice/stream`
остаются привязанными к primary-рабочему пространству. Имена методов ACP и
схема настроек Voice без изменений. `workspace_qualified_voice` объявляет все
квалифицированные модальности Voice, когда включен общий слушатель
WebSocket ACP/Voice. Существующие теги возможностей (capabilities) модальностей
Voice остаются сигналами primary-рабочего пространства и не являются
предварительными условиями для вторичного рантайма, чья конфигурация
валидируется выбранным маршрутом.

Неизвестные селекторы рабочего пространства возвращают
`400 workspace_mismatch`; зарегистрированные, но недоверенные рантаймы
возвращают `403 untrusted_workspace` до чтения настроек Voice или аудио.
Общий лимит допуска в восемь операций покрывает пакетную и стриминговую
работу и для legacy-, и для множественных маршрутов. Ошибки пакетной емкости
возвращают `503 voice_capacity_exceeded` с `Retry-After: 5`; ошибки
стриминговой емкости отправляют кадр ошибки и закрываются с кодом `1013`.
