# Read-only каталог сессий недоверенного рабочего пространства

## Резюме

Многопространственные демоны выставляют узкий read-only каталог для
зарегистрированных, неосновных рабочих пространств, чье состояние доверия на
момент загрузки равно `false`. Каталог содержит персистентные сводки сессий и
sidecar организации сессий. Он не присоединяется к сессии, не запускает
ACP-потомка, не сливает живое runtime-состояние и не интерпретирует
определения возможностей (capability), управляемые рабочим пространством.

Это allowlist маршрутов, а не ACL рабочего пространства. Клиент, владеющий
bearer-токеном демона, может читать разрешенные данные для каждого
зарегистрированного рабочего пространства. Доверие продолжает гейтить
исполнение и мутации; оно не создает отдельную принципала аутентификации.

## Инварианты безопасности

Каждый вновь разрешенный путь чтения недоверенного рабочего пространства
должен удовлетворять всем этим условиям:

- Не вызывать `loadSettings()` или любой путь миграции/восстановления
  настроек.
- Не создавать, не восстанавливать, не переписывать и никак иначе не
  изменять хранилище.
- Подавлять file-backed debug-логирование, пока читатель каталога активен,
  чтобы некорректная запись не могла создать или дополнить debug-лог как
  побочный эффект чтения.
- Не вызывать `ensureChannel()` или любой другой путь запуска ACP-потомка.
- Не запрашивать и не сливать живое состояние бриджа недоверенного рантайма.
- Не исполнять внешние команды.
- Не обнаруживать и не парсить агентов, навыки, хуки, конфигурацию MCP или
  другие определения возможностей (capability) рабочего пространства,
  управляемые проектом.

Реализация обеспечивает границу живого состояния внутренней политикой чтения
`mergeLive: false` на всех формах списка сессий: по умолчанию, организованной
и отфильтрованной по `parentSessionId`. Та же асинхронная граница чтения
подавляет только file-backed debug-логирование для чтений недоверенного
каталога; доверенные запросы и логирование вне этой границы не изменяются.
Отсутствующее хранилище дает пустой каталог, а некорректные записи следуют
существующему поведению чтения по мере возможности (best-effort) без
восстановления файлов.

## Матрица маршрутов

Таблица описывает недоверенное вторичное рабочее пространство, если не
указано иное.

| Поверхность                                 | Результат         | Источник данных и ограничения                                                          |
| ------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------- |
| `GET /workspace/:id/sessions`               | 200               | Только персистентные файлы сессий; id или закодированный канонический cwd-селектор     |
| `GET /workspaces/:workspace/sessions`       | 200               | Тот же каталог только из персистентных данных                                          |
| `GET /workspace/:id/session-groups`         | 200               | Только sidecar организации; любой зарегистрированный id или закодированный cwd         |
| `GET /workspaces/:workspace/session-groups` | 200               | Только sidecar организации                                                             |
| Чтение файлов, bytes, stat, list, glob      | Существующее поведение | Существующая политика чтения файловой системы не изменяется                       |
| GET/запрос доверия рабочего пространства    | Существующее поведение | Существующая семантика конфигурации доверия не изменяется                         |
| `/capabilities`, `/daemon/status`           | Существующее поведение | Существующая диагностика демона не изменяется                                     |
| Множественные мутации сессий/групп          | 403               | Гейт доверия мутаций остается неизменным                                               |
| Единичные мутации групп                     | Существующее поведение | Остаются только для основного; селекторы вторичных завершаются fail closed        |
| Настройки, разрешения, провайдеры           | 403               | Загрузка настроек может мигрировать, создавать резервные копии или восстанавливать файлы |
| Память                                      | 403               | Текущий ответ включает пути глобальной памяти, а не проекцию только рабочего пространства |
| Окружение                                   | 403               | Выставляет наличие креденшалов и диагностику прокси/хоста                              |
| Preflight                                   | 403               | Может исполнять git, npm, ripgrep или другие пробы                                     |
| MCP, инструменты, хуки                      | 403               | Связаны с живым состоянием бриджа или конфигурацией проекта                            |
| Навыки, агенты                              | 403               | Обнаруживают и парсят определения, управляемые проектом                                |
| Транскрипт                                  | 403               | Текущий путь может запустить ACP, а инициализация курсора может записать HMAC-ключ     |
| Экспорт, статус/контекст/задачи сессии      | 403               | Нет реализации только из персистентных данных, квалифицированной по рабочему пространству |
| ACP HTTP/WebSocket, голос, каналы           | Отклоняется       | Возможности (capability) исполнения, процессов или долгоживущего рантайма              |

Неизвестные абсолютные, вложенные или незарегистрированные селекторы
рабочего пространства продолжают завершаться fail closed с существующим
ответом `400 workspace_mismatch`. Некорректный legacy-селектор единичной
формы сохраняет свое существующее сообщение валидации `400`. Ни один из
случаев не откатывается на основное рабочее пространство. Множественные
маршруты продолжают возвращать `403 untrusted_workspace` для недоверенного
основного рабочего пространства. Единичные маршруты основного сохраняют свое
существующее поведение совместимости.

## Семантика каталога сессий

Режим только из персистентных данных сохраняет существующее поведение
`archiveState`,
`view=organized`, `group`, `parentSessionId`, курсора и размера страницы. Он
никогда не заполняет ожидающие взаимодействия, ошибки ходов или состояние
клиента из живого рантайма; существующие дефолты персистентной сводки, такие
как `clientCount: 0` и `hasActivePrompt: false`, остаются wire-совместимыми.
Он никогда не вызывает `bridge.listWorkspaceSessions()`.

Доверенные вторичные и основное рабочие пространства сохраняют существующее
слияние персистентного/живого. Никакой маршрут, wire-поле, схема или тег
возможности (capability) не добавляется: старые клиенты продолжают
обрабатывать `403`, тогда как встроенный Web Shell потребляет новый ответ
`200`, когда поставляется вместе с демоном.

## Поведение Web Shell

Недоверенное вторичное рабочее пространство остается раскрываемым и
помечается и как `untrusted`, и как `read-only`. Раскрытие выполняет одно
чтение каталога.
Изменение `reloadToken` выполняет другое чтение, но обычный десятисекундный
опрос отключен, потому что этот демон не может создавать сессии в этом
рабочем пространстве.

Раскрытие не выбирает и не активирует рабочее пространство. Персистентные
сессии рендерятся как неинтерактивные строки с `role="note"` и доступным
именем, включающим имя сессии, дату и объяснение, что рабочее пространство
должно быть доверенным, прежде чем сессию можно будет открыть. Строка не
привязывает активацию мышью или клавиатурой и не получает стилизацию активной
сессии. Поведение доверенных рабочих пространств не изменяется. Недоверенное
основное остается отключенным в ожидании отдельного дизайна safe-mode
основного пространства.

## Поведение при отказах и совместимость

- Отсутствующее хранилище сессий или организации возвращает пустой каталог.
- Непарсируемые и не-объектные записи JSONL пропускаются существующим
  читателем сессий. Это изменение не добавляет валидацию схемы для
  структурно невалидных объектных записей.
- Нечитаемый sidecar организации возвращает существующее пустое
  представление чтения и предупреждение; чтения не восстанавливают его.
- Неудачи запросов Web Shell сохраняют существующее пустое состояние и
  предупреждение в консоли.
- GET доверия продолжает наблюдать текущую конфигурацию доверия на диске и
  сообщает вызывающим, что изменения рантайма требуют перезапуска. В этом
  изменении он не преобразуется в снимок загрузки.

## Отложенная работа

- Загрузчик снимка настроек и доверия без побочных эффектов.
- Проекция памяти только рабочего пространства.
- Редактируемый осмотр окружения и конфигурации.
- Инвентарь навыков и агентов, который не парсит определения проекта.
- Локальный для демона читатель транскриптов, который не запускает ACP и не
  инициализирует HMAC-ключ курсора, плюс по-настоящему read-only
  просматриватель сессий.
- Динамическое применение доверия, пересборка рантайма и удаление/дренирование
  рабочего пространства.
