# Кастомные Hex-цвета для именованных групп сессий

## Проблема

Именованные группы сессий сейчас разделяют шести-значный enum цветов,
используемый быстрыми цветовыми тегами сессий. Демон отклоняет любое другое
значение с `invalid_group_color`, TypeScript SDK выставляет то же закрытое
объединение, а редактор WebShell предлагает только предустановленный select.
Пользователи не могут выровнять именованные группы с существующей палитрой
проекта или визуально различить больший каталог групп.

Отслеживается в [#6744](https://github.com/QwenLM/qwen-code/issues/6744).

## Предлагаемые изменения

| Слой          | Изменение                                                                                                                                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Core           | Разделить предустановленные цвета тегов сессий и отображаемые цвета именованных групп. Именованные группы принимают предустановленные значения или шестизначный `#RRGGBB`; быстрые теги остаются только предустановленными. Нормализовать валидные Hex-значения в нижний регистр перед персистентностью. |
| REST и ACP   | Сохранить валидацию быстрых тегов только предустановленной и передавать цвета именованных групп в валидацию core.                                                                                                                           |
| TypeScript SDK | Экспортировать типы предустановленных и Hex-цветов. Ввод/вывод групп использует их объединение; организация сессий продолжает использовать предустановленные цвета.                                                                                    |
| WebShell       | Сохранить предустановленные варианты и добавить опцию Custom с нативным color picker и текстовым полем Hex. Рендерить точки кастомных групп с инлайновым фоновым цветом.                                                            |

## Решения

- Принимать только шестизначный `#RRGGBB`. Трех-, четырех- и восьмизначные
  формы отклоняются, чтобы каждая персистентная величина имела одну
  предсказуемую форму.
- Обрезать окружающие пробельные символы и канонизировать Hex-значения в
  нижний регистр в core. Клиенты могут нормализовать раньше для немедленной
  обратной связи, но core остается авторитетным.
- Не расширять быстрые цветовые теги сессий. Их каталог из шести значений
  остается компактным измерением упорядочения/фильтрации и сохраняет обратную
  совместимость.
- Сохранить версию схемы sidecar равной 1. Хранимое поле остается строкой, а
  старые предустановленные значения остаются валидными.
- Существующие клиенты, не распознающие Hex-класс, должны падать безопасно.
  WebShell рендерит Hex-точки групп через инлайновый `background-color`.

## Вне области

- Кастомные цвета для быстрых тегов сессий.
- Альфа-каналы, градиенты, именованные CSS-цвета или короткие Hex-формы.
- Изменение формата sidecar групп или миграция существующих значений.

## Открытые вопросы

Нет. Существующие пути структурированных ошибок и персистентности групп могут
быть расширены без поднятия версии протокола.
