# Доверенный контекст вызова демона

## Цель

Переносить удостоверенную демоном идентичность для одного принятого корневого
промпта на MCP-серверы, которые Qwen запускает через stdio. Контекст — это
метаданные корреляции, а не учётные данные авторизации.

Полный продакшен-путь:

```text
допуск промпта демоном
  -> приватный дочерний процесс ACP
  -> ход корневой сессии (Session)
  -> метаданные запроса tools/call MCP-инструментов stdio, запущенных Qwen
```

## Wire-контракт

Qwen добавляет следующее значение в
`tools/call.params._meta["qwen-code/invocation"]`:

```ts
interface InvocationContextV1 {
  version: 1;
  sessionId: string;
  promptId: string;
  originatorClientId?: string;
}
```

- `sessionId` — живая сессия демона, выбранная маршрутом запроса.
- `promptId` фиксируется, когда демон допускает промпт, до ожидания в
  поксессинной очереди. Неблокирующие вызывающие стороны могут предоставить
  id корреляции, используемый существующим сопоставлением терминальных
  событий; иначе демон генерирует UUID. В обоих случаях значение
  идентифицирует промпт, который демон фактически допустил, а не метаданные,
  скопированные из тела промпта.
- `originatorClientId`, когда присутствует, — это значение заголовка запроса
  после того, как демон проверил, что оно зарегистрировано на этой сессии.
- Неизвестные поля, неизвестные версии и пустые идентификаторы невалидны.

Демон удаляет предоставленные вызывающей стороной значения зарезервированных
ключей метаданных и реконструирует контекст из собственного состояния. Он
передаёт значение только тому дочернему процессу ACP, который сам запустил и
аутентифицировал capability на процесс. Автономные вызывающие стороны ACP не
могут внедрить зарезервированный контекст.

## Время жизни и раскрытие

ACP Session проверяет, что сессия контекста совпадает с его фактической
сессией, и привязывает его к корневому промпту через `AsyncLocalStorage`.
Параллельные промпты остаются изолированными, в том числе когда они разделяют
пулируемый транспорт MCP. Отложенные колбэки подтверждения явно
восстанавливают захваченный контекст.

Автоматические ходы cron, фоновые уведомления, возобновлённые фоновые агенты
и циклы рассуждений субагентов выполняются без контекста вызова. Контекст не
персистится после урегулирования корневого хода.

Только экземпляр транспорта, созданный Qwen как `StdioClientTransport` из MCP-конфигурации `command`, помечается как подходящий. Транспорты HTTP, SSE,
WebSocket, reverse, предоставленные SDK и размещённые клиентом метаданные не
получают. Маркер пригодности следует за обнаружением инструментов,
клонированием, пулированием, переподключением и повтором, не становясь
публичной опцией конфигурации MCP.

## Нецели

- Никакого поведения, специфичного для Browser Use, opencode,
  локального/удалённого бэкенда, страницы или навыка.
- Никакой энумерации входящих потоков или общего графа происхождения.
- Никакого нового API TypeScript SDK или поведения MCP-жизненного цикла
  qwen-serve.
- Никаких решений об авторизации на основе `originatorClientId`.
