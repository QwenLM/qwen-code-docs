# Общий обзор статуса жизненного цикла каналов

Дата: 2026-07-01

## Цель

Предоставить единую площадку для ревью, которая обобщает поведение статуса жизненного цикла для поддерживаемых адаптеров каналов и явно указывает, что намеренно остается вне скоупа.

## Скоуп

- Telegram
- Weixin
- DingTalk
- Feishu

## Явные задачи вне скоупа

- Slack остается вне скоупа.
- QQ Bot остается вне скоупа для UI статуса жизненного цикла.
- Пример плагина остается вне скоупа для UI статуса жизненного цикла.
- Терминальные эмодзи DingTalk остаются вне скоупа.

## Заметки для ревью

- `text_chunk` жизненного цикла Feishu остается no-op в хуке жизненного цикла. Он не добавляет и не обновляет контент ответа в этом месте.
- Slack намеренно исключен из этой матрицы, так как находится вне скоупа.
- Терминальные события DingTalk в рамках данного скоупа только отзывают существующую реакцию «глаз». Терминальные эмодзи не добавляются.
