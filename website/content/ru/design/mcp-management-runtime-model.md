# Модель рантайма управления MCP

Конфигурация MCP — долговечный источник истины. Каждая сессия CLI или Web
продолжает владеть независимым рантаймом MCP, поэтому CLI не зависит от
процесса управления рабочим пространством.

Страница управления Web может создавать опциональный рантайм управления для
операций статуса и управления. Операции, меняющие конфигурацию, сначала
персистят, затем согласовывают каждый живой рантайм в том же процессе ACP.
Более поздняя сессия загружает персистентную конфигурацию обычным образом.

Статус управления читается из клиентского менеджера рантайма управления, а не
из общепроцессной карты статуса совместимости. Карта совместимости остается
неизменной для существующих потребителей CLI. Переподключения общего пула
перезапускают запись пула; переподключения вне пула заново обнаруживают сервер
в каждом живом рантайме.

Происхождение серверов остается различимым: настройки пользователя, настройки
рабочего пространства, проектный `.mcp.json` и расширения. Отключение
проектных серверов или серверов рабочего пространства записывает исключение в
локальные для рабочего пространства настройки без изменения общего проектного
файла.
