
# Agent Plugins v1

Qwen Code нативно загружает переносимые пакеты [Agent Plugins v1](https://agent-plugins.org/).
Пакет сохраняет свои стандартные файлы `plugin.json`, `mcp.json` и
`SKILL.md`: при установке не генерируется `qwen-extension.json` и
не переписываются переносимые файлы.

Используйте существующие команды расширений с локальной директорией, ссылкой, архивом,
Git-репозиторием, URL архива или скоуп-пакетом npm:

```bash
qwen extensions install ./my-agent-plugin
qwen extensions link ./my-agent-plugin
qwen extensions install owner/my-agent-plugin
```

Корневой манифест должен соответствовать канонической схеме v1:

```json
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "my-agent-plugin",
  "version": "1.0.0"
}
```

## Поддерживаемые возможности

| Возможность                                  | Поддержка                                |
| -------------------------------------------- | ---------------------------------------- |
| `skills/*/SKILL.md` в дочерних директориях   | Да                                       |
| stdio MCP-серверы                            | Да                                       |
| Streamable HTTP MCP-серверы                  | Да                                       |
| Legacy HTTP+SSE MCP-серверы                  | Нет; запись пропускается                 |
| Команды, агенты и хуки                       | Нет; эти директории игнорируются         |
| Контекст Qwen, настройки, каналы и приложения | Нет                                      |
| Клиентские неймспейсы `extensions.*`         | Нет; нереализованные неймспейсы игнорируются |

Навыки следуют [спецификации Agent Skills](https://agentskills.io/specification).
Невалидный навык пропускается без отключения валидных соседних навыков.
Экспериментальное поле `allowed-tools` распознаётся как строка, но не предоставляет
предварительно одобренные инструменты Qwen.

Для stdio MCP-серверов Qwen Code раскрывает `${PLUGIN_ROOT}` и `${PLUGIN_DATA}`
однократно в `args`, значениях переменных окружения и `cwd`. `PLUGIN_DATA` — это
доступная для записи директория на установку, содержимое которой сохраняется
при обновлениях и переустановке. Удалённые MCP-эндпоинты должны использовать HTTPS,
за исключением loopback HTTP-эндпоинтов.

Agent Plugins v1 — это формат пакета, а не интеграция с маркетплейсом. Устанавливайте
пакеты через существующие источники расширений Qwen Code.
