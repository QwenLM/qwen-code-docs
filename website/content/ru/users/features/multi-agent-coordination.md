# Координация мульти-агентов

Qwen Code может координировать нескольких участников с помощью экспериментального runtime Agent Team. Участники получают отдельные задачи, используют общий список задач, обмениваются сообщениями и отображаются на существующих вкладках Agent View. `/coordinate` по умолчанию назначает воркерам-исследователям набор инструментов только для чтения и может разместить одного писателя в Git worktree, принадлежащем лидеру.

## Включение Agent Team

Установите `experimental.agentTeam` в `true` в настройках Qwen Code и перезапустите, или запустите Qwen Code с `QWEN_CODE_ENABLE_AGENT_TEAM=1`.

## Запуск координированной задачи

Используйте встроенный навык с целью:

```text
/coordinate investigate the authentication regression and propose the smallest fix
```

Лидер создаёт команду, назначает до трёх независимых рабочих потоков и использует существующие командные инструменты для сообщений и состояния задач. Разговоры и одобрения участников остаются видимыми через существующий UI Agent View. Участники только для чтения не могут выполнять команды оболочки или записывать файлы. Если необходима реализация, лидер может создать один Git worktree и закрепить в нём одного участника-писателя; лидер остаётся единственным авторитетом по слиянию для текущей ветки.

Если Agent Team отключён, `/coordinate` всё ещё может использовать обычные foreground-агенты для параллельного исследования только для чтения. Этот фолбэк — это делегирование, а не совместная команда: воркеры отчитываются только перед лидером.

## Выбор правильного режима мульти-агентов

| Режим                           | Для чего использовать                                       | Коммуникация                         | Поведение рабочего пространства                         |
| ------------------------------- | ----------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------- |
| `/coordinate` с Agent Team      | Разные рабочие потоки, вносящие вклад в один результат      | Общие задачи и сообщения участников  | Воркеры только для чтения; опциональный один писатель в worktree |
| Субагенты                       | Небольшие делегированные задачи                             | Воркер отчитывается перед родителем  | Зависит от выбранного агента                            |
| Arena                           | Несколько моделей, соревнующихся за одну задачу             | Агенты не сотрудничают               | Изолированные worktree; выбирается один победитель      |
| Herdr                           | Координация различных CLI-продуктов или удалённых терминальных сессий | Внешнее управление на уровне терминала | Управляется вне Qwen Code                      |

Текущий рабочий процесс намеренно повторно использует runtime Agent Team в процессе и UI Agent View. Участники обычно наследуют модель сессии, хотя определение агента может её переопределить. Постоянные независимые PTY-сессии, кросс-вендорные воркеры и удалённое подключение — это отдельные продуктовые задачи, которые не реализованы в `/coordinate`.
