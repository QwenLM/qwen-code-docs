# Обзор сессий

Используйте Session Overview в Web Shell для просмотра сессий, возврата к разговору
и управления заголовками и архивами сессий.

## Поиск и открытие сессий

Откройте **More → Session Overview**. Выполняйте поиск по заголовку сессии, ID сессии,
ветке Git или номеру связанного pull request, например `#123`. Используйте фильтры
по статусу для сужения списка. Когда доступно несколько рабочих пространств, фильтр
рабочих пространств позволяет выбрать, какие из них включить. Выберите **Refresh**
для перезагрузки каталога.

Щелкните строку сессии, чтобы открыть этот разговор. Используйте флажки строк для
выбора сессий, чтобы выполнить действия в нижней панели; элементы управления
пагинацией изменяют видимую страницу и количество строк.

## Переименование сессии

Выберите действие с карандашом в строке, когда оно доступно, затем отредактируйте
заголовок. Нажмите **Enter** для сохранения или **Escape** для отмены. Если редактор
теряет фокус, незавершенное переименование отменяется, а не сохраняется.

## Архивирование сессий

Выберите сессии с помощью флажков строк, затем выберите **Archive** в нижней панели.
Действие активно только тогда, когда каждая выбранная сессия находится в состоянии
простоя и поддерживает архивирование. Подтвердите архивирование в диалоговом окне
или выберите **Cancel**, чтобы оставить сессии активными.

Если редактор переименования все еще имеет фокус, когда вы нажимаете **Archive**,
его незавершенный черновик отменяется и открывается подтверждение архивирования.
Ввод или отмена переименования сохраняет элементы управления нижней панели на месте,
поэтому щелчки рядом с краем кнопки все равно достигают этой кнопки.
