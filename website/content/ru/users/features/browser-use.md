# Browser Use

Browser Use позволяет Qwen Code работать со страницами в вашем браузере Chrome,
используя ваши существующие вкладки и активные сессии.

## Использование

Используйте macOS или Linux с Chrome 125 или новее и Qwen Code 0.24.2 или новее
(проверьте командой `qwen --version`). **Установите
[расширение Qwen Code из Chrome Web Store](https://chromewebstore.google.com/detail/qwen-code/hdhmmjclhibojdddmancfgbkleahfaph)
в тот профиль Chrome, который хотите использовать.** Расширение обязательно и не
устанавливается вместе с пакетом Qwen Code. После установки Chrome обновляет его
автоматически.

**Используйте одну копию расширения на профиль.** Если ранее вы загружали его
в распакованном виде, удалите или отключите эту копию в `chrome://extensions`
перед установкой версии из магазина. Если включены обе копии, Qwen видит два
браузера для одного профиля и может подключиться к любому из них.

Если Chrome Web Store сообщает, что расширение недоступно в вашем регионе,
соберите его из исходного кода: следуйте инструкции в
[README](https://github.com/QwenLM/qwen-code/tree/main/packages/chrome-extension#readme)
директории `packages/chrome-extension` репозитория Qwen Code, затем откройте
`chrome://extensions`, включите режим разработчика, выберите **Загрузить распакованное расширение**
и укажите собранную директорию `dist/extension`.

Опишите задачу для браузера напрямую, например:

> Прочитай мою открытую панель и подведи итоги заказов за сегодня.

Qwen выбирает навык Browser Use, когда это уместно. При первом обращении
к браузеру автоматически регистрируется небольшая локальная программа
подключения в вашей пользовательской директории; последующие задачи
используют её повторно. Qwen подтверждает подключение к расширению
перед работой со страницами. Если подключение не удалось, откройте Chrome
и убедитесь, что версия Qwen Code — 0.24.2 или новее и что расширение включено в нужном профиле,
затем повторите попытку. Если зависимость времени
выполнения требует настройки при первом использовании, Qwen подскажет вам
и может попросить перезапустить сессию. Отдельное расширение Browser Use Qwen
или процесс `qwen serve` не нужны.

## Отключение

Используйте `/skills`, чтобы отключить **browser-use**. Это скрывает навык
от модели, но не разрывает существующую сессию браузера и не удаляет инструкции,
уже загруженные в разговор.
