# Горячие клавиши Qwen Code

В этом документе перечислены доступные горячие клавиши в Qwen Code.

## Общие

| Комбинация клавиш                  | Описание                                                                                                                                                                                                                                                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                              | Закрыть диалоги и подсказки. При пустом промпте — отменить текущий запрос; в режиме ожидания вне режима IDE, двойное нажатие открывает селектор отката.                                                                                                                                                        |
| `Ctrl+C`                           | Отменить текущий запрос и очистить ввод. Нажмите дважды для выхода из приложения.                                                                                                                                                                                                                             |
| `Ctrl+D`                           | Выйти из приложения, если поле ввода пусто. Нажмите дважды для подтверждения.                                                                                                                                                                                                                                 |
| `Ctrl+L`                           | Очистить экран.                                                                                                                                                                                                                                                                                               |
| `Ctrl+O` / `Alt/Option+T`          | Переключить расширенный режим детализации: развернуть или свернуть все блоки рассуждений и выводы инструментов встроенно. Нажмите ещё раз для сворачивания. Когда `ui.useTerminalBuffer` выключен, переключение перерисовывает весь диалог с необрезанным выводом в буфер прокрутки терминала.              |
| `Ctrl+S`                           | Сохраняет непустой ввод для текущего проекта и восстанавливает его при следующем запуске. При пустом вводе позволяет длинным ответам выводиться полностью, отключая усечение. Используйте буфер прокрутки терминала для просмотра всего вывода.                                                              |
| `Ctrl+T`                           | Переключить отображение описаний инструментов.                                                                                                                                                                                                                                                                |
| `Alt/Option+M`                     | Переключать вывод Markdown между полноценным отрендеренным предпросмотром и режимом исходного кода. В macOS терминал должен отправлять Option как Meta.                                                                                                                                                       |
| `Shift+Tab` (`Tab` на Windows)     | Переключать режимы подтверждения (`plan` → `default` → `auto-edit` → `auto` → `yolo`)                                                                                                                                                                                                                         |

## Оболочка переднего плана

Эти сочетания клавиш действуют, пока выполняется интерактивная команда оболочки переднего плана.

| Комбинация клавиш                   | Описание                                                                                                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl+F`                            | Переключать фокус клавиатуры между оболочкой и полем ввода. Когда оболочка не запущена, `Ctrl+F` перемещает курсор в поле ввода вправо.                   |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | Прокручивать активную оболочку вверх или вниз.                                                                                                            |
| `Ctrl+B`                            | Перевести оболочку в фоновую задачу. Дочерний процесс продолжает работать, ход агента разблокируется, а оболочка появляется в `/tasks` и диалоговом окне фоновых задач. |

| Комбинация клавиш                    | Описание                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------ |
| `Down Arrow` / `Ctrl+N`              | Перейти к следующей подсказке.                                           |
| `Tab` / `Enter`                      | Принять выбранную подсказку.                                             |
| `Up Arrow` / `Ctrl+P`                | Перейти к предыдущей подсказке.                                          |
| `Right Arrow`                        | Принять подсказку в виде призрачного текста, если поле ввода пусто.      |
| `Ctrl+Tab` / `Ctrl+Right Arrow`      | Переключиться на следующую категорию автодополнения, если вкладки категорий отображаются.    |
| `Ctrl+Shift+Tab` / `Ctrl+Left Arrow` | Переключиться на предыдущую категорию автодополнения, если вкладки категорий отображаются.   |

## Поиск по истории

Нажмите `Ctrl+R` для поиска по истории промптов или по истории оболочки, если активен режим оболочки.

| Комбинация клавиш            | Описание                                                     |
| ---------------------------- | ------------------------------------------------------------ |
| `Up Arrow` / `Down Arrow`    | Перемещение по найденным записям истории.                    |
| `Left Arrow` / `Right Arrow`| Свернуть или развернуть выбранную длинную запись.            |
| `Tab`                        | Принять выбранную запись в поле ввода без отправки.          |
| `Enter`                      | Отправить выбранную запись.                                  |
| `Esc`                        | Закрыть поиск по истории.                                    |

## Прокрутка истории

Активно, когда включена опция `ui.useTerminalBuffer` (Settings → UI → Virtualized History), режим экранного чтения выключен, и Qwen Code работает в совместимом интерактивном терминале (`stdout` — это TTY, CI неактивен, и `TERM` не равен `dumb`), что является стандартным поведением для обычных сеансов без экранного чтения. В этом режиме история диалога отображается во внутреннем окне приложения, а не в буфере прокрутки терминала, поэтому указанные ниже клавиши заменяют стандартную прокрутку терминала.

| Комбинация клавиш | Описание                                                                        |
| ----------------- | ------------------------------------------------------------------------------- |
| `Shift+Up`        | Прокрутить историю вверх на одну строку.                                        |
| `Shift+Down`      | Прокрутить историю вниз на одну строку.                                         |
| `PgUp`            | Прокрутить историю вверх на одну страницу (высоту окна).                        |
| `PgDn`            | Прокрутить историю вниз на одну страницу (высоту окна).                         |
| `Ctrl+Home`       | Перейти к началу диалога.                                                       |
| `Ctrl+End`        | Перейти к концу (и возобновить автоматическое следование в реальном времени).   |
| **Колесико мыши** | Прокрутить историю (3 строки за щелчок). Требуется `ui.mouseTracking` (включено по умолчанию). |

Когда `ui.useTerminalBuffer` включена и `ui.mouseTracking` активен (по умолчанию), терминал перенаправляет события мыши в qwen-code, чтобы колесо прокрутки могло управлять внутренним окном приложения. Как побочный эффект, стандартное выделение текста кликом и перетаскиванием перехватывается программой, поэтому qwen-code предоставляет собственное: **перетаскивание для выделения текста в окне истории, двойной щелчок для выделения слова, тройной щелчок для выделения строки.** Выделение подсвечивается и копируется в буфер обмена при отпускании кнопки мыши (работает локально, через SSH посредством OSC 52 и внутри tmux). Одиночный щелчок снимает выделение; прокрутка или новый вывод тоже его снимают. Выделение пока ограничено видимым окном. Можно вернуться к стандартному выделению терминала, удерживая `Shift` (или `Option` в macOS Terminal / iTerm) при перетаскивании. Установите `ui.mouseTracking` в `false`, чтобы полностью запретить qwen-code перехват мыши; это восстановит стандартное контекстное меню терминала, клики по гиперссылкам OSC 8 и выделение текста перетаскиванием, но внутреннее окно приложения больше не будет реагировать на мышь — используйте указанные выше сочетания клавиш для прокрутки.

### Прокрутка тачпадом в tmux

Внутри tmux некоторые терминалы преобразуют жесты тачпада или колеса прокрутки в обычные последовательности `Up Arrow` и `Down Arrow` еще до того, как их получит `qwen-code`. Эти байты идентичны реальным нажатиям клавиш со стрелками, поэтому `qwen-code` не может определить, хотите ли вы прокрутить окно или перейти по истории команд.

Если прокрутка тачпадом в tmux изменяет историю команд, убедитесь, что `ui.useTerminalBuffer` включена; затем используйте `Shift+Up` / `Shift+Down` или колесо мыши, когда tmux перенаправляет события колеса в приложение (требуется `ui.mouseTracking`). Если вы предпочитаете использовать буфер прокрутки хоста, настройте привязки мыши в tmux для событий колеса.
