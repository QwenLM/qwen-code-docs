# Горячие клавиши Qwen Code

В этом документе перечислены доступные горячие клавиши в Qwen Code.

## Общие

| Комбинация клавиш                | Описание                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc`                            | Закрыть диалоги и подсказки.                                                                                                                                                                                                                                                                                      |
| `Ctrl+C`                         | Отменить текущий запрос и очистить ввод. Нажмите дважды для выхода из приложения.                                                                                                                                                                                                                                 |
| `Ctrl+D`                         | Выйти из приложения, если поле ввода пусто. Нажмите дважды для подтверждения.                                                                                                                                                                                                                                     |
| `Ctrl+L`                         | Очистить экран.                                                                                                                                                                                                                                                                                                   |
| `Ctrl+O`                         | Переключить компактный режим (скрыть/показать вывод инструментов и рассуждения).                                                                                                                                                                                                                                  |
| `Ctrl+S`                         | Позволяет выводить длинные ответы полностью, отключая усечение. Используйте буфер прокрутки терминала для просмотра всего вывода.                                                                                                                                                                                 |
| `Ctrl+T`                         | Переключить отображение описаний инструментов.                                                                                                                                                                                                                                                                    |
| `Ctrl+B`                         | Пока выполняется команда оболочки в активном режиме: перевести её в фоновую задачу. Дочерний процесс продолжает работать, ход агента разблокируется, а оболочка появляется в `/tasks` и диалоговом окне фоновых задач. Не действует, если оболочка не выполняется — в этом случае Ctrl+B срабатывает как привязка для области ввода (курсор влево). |
| `Alt/Option+M`                   | Переключать вывод Markdown между полноценным отрендеренным предпросмотром и режимом исходного кода. В macOS терминал должен отправлять Option как Meta.                                                                                                                                                           |
| `Shift+Tab` (`Tab` на Windows)   | Переключать режимы подтверждения (`plan` → `default` → `auto-edit` → `auto` → `yolo`)                                                                                                                                                                                                                             |

| `Ctrl+B` / `Left Arrow`                             | Переместить курсор на один символ влево.                                                                                          |
| `Ctrl+C`                                            | Очистить поле ввода                                                                                                               |
| `Esc` (двойное нажатие)                             | Очистить поле ввода.                                                                                                              |
| `Ctrl+D` / `Delete`                                 | Удалить символ справа от курсора.                                                                                                 |
| `Ctrl+E` / `End`                                    | Переместить курсор в конец строки.                                                                                                |
| `Ctrl+F` / `Right Arrow`                            | Переместить курсор на один символ вправо.                                                                                         |
| `Ctrl+H` / `Backspace`                              | Удалить символ слева от курсора.                                                                                                  |
| `Ctrl+K`                                            | Удалить текст от курсора до конца строки.                                                                                         |
| `Ctrl+Left Arrow` / `Meta+Left Arrow` / `Meta+B`    | Переместить курсор на одно слово влево.                                                                                           |
| `Ctrl+N`                                            | Перейти на строку вниз, затем к концу строки, затем к следующей записи в истории.                                                 |
| `Ctrl+P`                                            | Перейти на строку вверх, затем к началу строки, затем к предыдущей записи в истории.                                              |
| `Ctrl+R`                                            | Обратный поиск по истории ввода и оболочки.                                                                                       |
| `Ctrl+Y`                                            | Повторить последний неудачный запрос.                                                                                             |
| `Ctrl+Right Arrow` / `Meta+Right Arrow` / `Meta+F`  | Переместить курсор на одно слово вправо.                                                                                          |
| `Ctrl+U`                                            | Удалить текст от курсора до начала строки.                                                                                        |
| `Ctrl+V` (Windows: `Alt+V`)                         | Вставить содержимое буфера обмена. Если в буфере обмена есть изображение, оно будет сохранено, а ссылка на него будет вставлена в запрос. |
| `Ctrl+W` / `Meta+Backspace` / `Ctrl+Backspace`      | Удалить слово слева от курсора.                                                                                                   |
| `Ctrl+X`                                            | Открыть текущий ввод во внешнем редакторе.                                                                                        |

## Подсказки

| Комбинация клавиш       | Описание                             |
| ----------------------- | ------------------------------------ |
| `Down Arrow` / `Ctrl+N` | Перейти к следующей подсказке.       |
| `Tab` / `Enter`         | Принять выбранную подсказку.         |
| `Up Arrow` / `Ctrl+P`   | Перейти к предыдущей подсказке.      |

| ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Down Arrow` / `j` / `Ctrl+N` | Переместить выделение вниз.                                                                                |
| `Enter`                       | Подтвердить выбор.                                                                                         |
| `Up Arrow` / `k` / `Ctrl+P`   | Переместить выделение вверх.                                                                               |

## Прокрутка истории

Активно только при включенной опции `ui.useTerminalBuffer` (Settings → UI → Virtualized History). В этом режиме история диалога отображается во внутреннем окне приложения, а не в буфере прокрутки терминала, поэтому указанные ниже клавиши заменяют стандартную прокрутку терминала.

| Комбинация клавиш | Описание                                           |
| ----------------- | -------------------------------------------------- |
| `Shift+Up`        | Прокрутить историю вверх на одну строку.           |
| `Shift+Down`      | Прокрутить историю вниз на одну строку.            |
| `PgUp`            | Прокрутить историю вверх на одну страницу (высоту окна). |
| `PgDn`            | Прокрутить историю вниз на одну страницу (высоту окна). |
| `Ctrl+Home`       | Перейти к началу диалога.                          |
| `Ctrl+End`        | Перейти к концу (и возобновить автоматическое следование в реальном времени). |
| **Колесико мыши** | Прокрутить историю (3 строки за щелчок).           |
Когда включена опция `ui.useTerminalBuffer`, терминал перенаправляет события мыши в `qwen-code`, чтобы колесо прокрутки могло управлять viewport приложения. Как побочный эффект, **стандартное выделение текста кликом и перетаскиванием перехватывается программой** — удерживайте `Shift` (или `Option` в macOS Terminal / iTerm) при перетаскивании, чтобы обойти захват мыши и выделить текст обычным способом.

### Прокрутка тачпадом в tmux

Внутри tmux некоторые терминалы преобразуют жесты тачпада или колеса прокрутки в обычные последовательности `Up Arrow` и `Down Arrow` еще до того, как их получит `qwen-code`. Эти байты идентичны реальным нажатиям клавиш со стрелками, поэтому `qwen-code` не может определить, хотите ли вы прокрутить viewport или перейти по истории команд.

Если прокрутка тачпадом в tmux изменяет историю команд, включите `ui.useTerminalBuffer`; затем используйте `Shift+Up` / `Shift+Down` или колесо мыши, когда tmux перенаправляет события колеса в приложение. Если вы предпочитаете использовать буфер прокрутки хоста, настройте привязки мыши в tmux для событий колеса.
