# Запрос workflow на один ход


Для сохранения предпочтения между обычными отправками см.
[session Workflow mode](./workflow-mode.md).

При включённой опции `tools.workflowsEnabled` добавьте `ultracode` или существующее
ключевое слово `workflow` в сообщение пользователя, чтобы предложить использование
Workflow tool для этого хода. Например: `ultracode: audit these three modules`.
Модель решает, подходит ли workflow для данного запроса. Ключевое слово не
запускает workflow, не изменяет разрешения, не выбирает модель и не меняет
уровень усилий.

Ввод в терминале Ink и OpenTUI, ввод в композере IDE и ввод в композере Web Shell
поддерживают это напоминание. Оно добавляется к запросу модели отдельно от
отображаемого сообщения. Следующее обычное сообщение его не наследует.
Продолжения инструментов и автоматические повторные попытки не добавляют его
снова. Текст, вставленный в композер, считается вводом пользователя; расширения
вложений и контекст, добавленный хуком, — нет.

Восстановленная история и вставки из регистра Ink Vim остаются неизвестным
вводом, в том числе после очистки буфера или отключения Vim. Новый ввод в
режиме вставки Vim всё ещё может активировать напоминание.

`ultracode` игнорирует полные цитаты/кодовые спаны и токены, похожие на пути,
такие как `ultracode.js`, `x-ultracode` или `ultracode/file`. Существующее
правило совместимости `workflow` принимает отдельные слова, разделённые
пробелами, с граничными символами, например `(workflow)`, но не `workflows`
или `my-workflow-runner`. Когда встречаются оба ключевых слова, добавляется
только одно напоминание.

Обычный `qwen -p`, обычный stdin, запланированный ввод и строковые промпты SDK
не включаются автоматически. Потоковый ввод TypeScript SDK может явно
идентифицировать каждое исходное сообщение пользователя:

```ts
import { query, type SDKUserMessage } from ' @qwen-code/sdk';

async function* messages(): AsyncIterable<SDKUserMessage> {
  yield {
    type: 'user',
    session_id: crypto.randomUUID(),
    parent_tool_use_id: null,
    origin: { kind: 'human' },
    message: { role: 'user', content: 'ultracode: inspect the modules' },
  };
}

for await (const event of query({ prompt: messages() })) {
  console.log(event);
}
```

Опустите `origin` для контекста, сгенерированного приложением, автоматизации,
результатов инструментов и воспроизведения истории. Отсутствующий или
невалидный origin оставляет обычный чат работающим без напоминания о ключевом
слове. Декларация не предоставляет никаких разрешений инструментов. Клиенты ACP
могут использовать существующую декларацию `_meta['qwen.submittedPrompt']` для
каждого запроса для исходного текста пользователя; метаданные, приватные для
демона, остаются зарезервированными.

Установите `ui.disableWorkflowKeywordTrigger` в `true`, чтобы отключить оба
ключевых слова во всех этих точках входа. В диалоге настроек терминала это
**Disable Workflow Keyword Trigger**, и оно вступает в силу для новых
сообщений. Напоминание также опускается, когда workflows или необходимая
поверхность инструментов недоступны. Сессия workflow только по имени предлагает
только сохранённые workflows с `{ name, args }`; она не предлагает написание
скрипта.
