# Оценка Qwen Code


В данной оценке сравниваются семь версий Qwen Code на бенчмарке SWE-bench Verified с использованием одной и той же модели Qwen 3.7 Max и одинаковой конфигурации. Средние результаты находятся в диапазоне от **76,40% до 77,80%**, разброс составляет **1,40 процентных пункта**.

## Конфигурация оценки

| Параметр                  | Значение                                                                                              |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| Набор данных            | `princeton-nlp/SWE-bench_Verified`, 500 случаев                                                       |
| Запуски                 | 3 прогона на версию, 1 500 задач на версию; 7 версий Qwen Code                                       |
| Модель                  | `Qwen 3.7 Max`                                                                                      |
| Сэмплинг                | `temperature=1`, `top_p=0.95`                                                                       |
| Мышление / Рассуждение  | `interleaved_thinking=true`, `thinking_type=adaptive`, `reasoning_effort=high`                      |
| Лимиты контекста / вывода | `context_1m=true`, `model_context_length=1,000,000`, `max_tokens=64,000`, `model_max_tokens=65,535` |
| Лимиты стенда           | `max_iterations=500`, `runtime_timeout_sec=7,200`, `agent_timeout_multiplier=3.0`                   |
