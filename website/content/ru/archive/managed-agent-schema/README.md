# Архивные миграции базы данных Managed Agent


Эти файлы описывают устаревшую базу данных из 63 таблиц на момент коммита `18f80f56666a347a2b67b2ef98099cc58356b253`. Они являются историческими справочными материалами и находятся вне classpath runtime и тестов. Архивные Java-миграции и свидетели обновлений не выполняются новой средой.

Единственная активная baseline — это [`V1__managed_schema.sql`](../../../packages/managed-agent-server/src/main/resources/db/managed-schema/V1__managed_schema.sql). Managed Server и Runtime Broker используют тот же версионированный ресурс и требуют пустую базу данных или структурно проверенную полную baseline из 32 таблиц. Устаревший, частичный, сторонний или содержащий только историю каталог отклоняется до начала записей инициализации. Реинициализация проверяет каталог; она не заполняет и не восстанавливает его.

Миграции старых данных и обновлений на месте не существует. Сохраните старую среду и базу данных для исторического чтения, остановите новые допуски и урегулируйте незавершённую работу перед переключением, и создавайте новые сессии только в новой среде. Откат после появления новых данных должен сохранять и обслуживать эти записи из новой базы данных.

Архивные тесты сохраняют свидетельства устаревшего алгоритма миграции. Активные замены проверяют свежую инициализацию, неизменяемость существующих строк, типизированные вариантные столбцы, уникальность хуков и индексированный допуск, а также отклонение устаревших каталогов. Продублированный `schema.sql` брокера был удалён, а не сохранён как ещё один авторитет схемы.

SQL V69 для retention из PR #13642 и `RuntimeBrokerRetentionLegacyUpgradeTest.java` сохраняют бывшие свидетельства обновления retention-индексов и квитанций из head `db4c37064b9f34d2aa879b23b0e894fbed0281e1`. Они являются только архивными: активная baseline V1 из 32 таблиц предоставляет retention-индексы, а заменяющий тест проверяет паритет свежего каталога и неизменяемость квитанций при повторной инициализации. V69 не является активной миграцией или резервированием версии.
