На этой неделе Qwen Code выпустил три стабильные версии: v0.28.3, v0.28.4 и v0.28.6.

**Задачу можно отдать другой сессии.** В Web Shell `/send` передаёт задачу другой сессии: она продолжает работу и по готовности докладывает вам.

**Результаты задач по расписанию уходят на заданный адрес.** Добавьте Generic Webhook в управлении каналами и укажите адрес получателя — готовый результат задачи по расписанию приходит туда автоматически.

**Созданные файлы собраны в одном месте.** Отчёты и экспортированные файлы всех сессий собираются на странице Artifacts: предпросмотр и скачивание сразу, без обхода сессий по одной.

## ✨ Новые возможности

### /send передаёт задачу другой сессии

Отдайте задачу другой сессии прямо из Web Shell: введите `/send проверь тест, который только что упал` — в том же workspace откроется новая сессия и возьмёт задачу. Флаг `--workspace` выбирает workspace, `--session-id` указывает существующую сессию. Когда задача готова, текущая сессия пересказывает результат.

AI тоже умеет отдавать задачи: и в сессии, которые открыл сам, и в сессии, которые открыли вы вручную. В режиме YOLO передача задачи в другую папку проекта идёт без окна подтверждения.

Что это даёт:

- собрали материалы в сессии A — передайте в сессию B, она продолжит писать план
- пишите код в основной сессии, а разбор тестов отдайте другой
- смотрите прогресс в правой панели и сразу обрабатывайте запросы подтверждения и вопросы другой сессии

Подробнее: PR [#17539](https://github.com/QwenLM/qwen-code/pull/17539), [#17818](https://github.com/QwenLM/qwen-code/pull/17818)

[📸 Скриншот демонстрации будет добавлен: журнал отправок /send, межсессионные бейджи и прогресс в реальном времени в правой панели]

### Каналы: результаты задач по расписанию — на заданный адрес, задачу можно поправить на ходу

**Результаты задач по расписанию уходят на заданный адрес.** Группы Feishu, WeCom и DingTalk уже получают результаты задач. Добавился Generic Webhook — подключение без привязки к платформе: укажите HTTPS-адрес получателя в управлении каналами, и уведомления и результаты задач по расписанию уходят туда. Подробнее: PR [#17405](https://github.com/QwenLM/qwen-code/pull/17405)

**Сообщение канала правит задачу на ходу.** Каналы, запущенные отдельно в терминале, поддерживают режим доставки inject: сообщение, пришедшее во время работы AI, попадает прямо в текущий раунд — AI читает его по ходу и меняет направление. Заметили на середине задачи, что что-то не так, — достаточно одной фразы. Подробнее: PR [#15634](https://github.com/QwenLM/qwen-code/pull/15634)

**Бот QQ отправляет файлы прямо в чат.** Выставьте `fileTools` в `true` в настройках канала QQ (по умолчанию выключено) и перезапустите канал — AI отправляет в чат созданные в workspace файлы, изображения, видео и голосовые сообщения. Подробнее: PR [#15450](https://github.com/QwenLM/qwen-code/pull/15450)

Что это даёт:

- задача по расписанию завершилась — результат автоматически уходит в вашу систему
- задача идёт не туда — одна фраза в группе, и AI меняет направление на месте
- отдайте задачу прямо в QQ — созданные файлы вернутся в тот же чат

[📸 Скриншот демонстрации будет добавлен: страница настройки Generic Webhook и файлы, полученные в QQ]

### Web Shell: файлы сессий на одной странице, история ввода общая для устройств

**Файлы сессий просматриваются и скачиваются на одной странице.** В локально развёрнутом Web Shell появилась страница Artifacts: отчёты, экспорты и снимки веб-превью всех сессий workspace собраны на одной странице — сразу предпросмотр или скачивание. Подробнее: PR [#18071](https://github.com/QwenLM/qwen-code/pull/18071), [#17689](https://github.com/QwenLM/qwen-code/pull/17689)

**История ввода общая для устройств.** Промпты и команды, набранные на компьютере, видны в истории ввода того же workspace на телефоне — и наоборот. Подробнее: PR [#18120](https://github.com/QwenLM/qwen-code/pull/18120)

**Боковая панель показывает статус каждой сессии.** Сессии с целью несут значок цели в цветах страницы Goals: выполняется — синий, ждёт вашего решения — янтарный. У сессий с прерванным последним раундом — бейдж Continue: после перезапуска одним взглядом видно, какие сессии продолжить. Подробнее: PR [#17515](https://github.com/QwenLM/qwen-code/pull/17515), [#18044](https://github.com/QwenLM/qwen-code/pull/18044)

**Подсказки на телефоне выбираются касанием.** Подсказки для продолжения диалога стали нажимаемыми над полем ввода: касание подставляет текст в поле — поправьте и отправьте. Подробнее: PR [#17918](https://github.com/QwenLM/qwen-code/pull/17918)

**Прочие улучшения.** Кнопки в карточках Generated UI копируют текст и скачивают небольшие файлы ([#18158](https://github.com/QwenLM/qwen-code/pull/18158)); сенсорная панель редактирования на телефоне и iPad остаётся в одну строку ([#18126](https://github.com/QwenLM/qwen-code/pull/18126)).

[📸 Скриншот демонстрации будет добавлен: страница Artifacts и значки статусов в боковой панели]

## 📊 Прочие новинки

**Интерфейс на традиционном китайском.** Web Shell и VS Code Companion получили традиционный китайский: выберите «繁體中文 [zh-TW]» в списке языков. Подробнее: PR [#17421](https://github.com/QwenLM/qwen-code/pull/17421)

**Перевод отображения.** Включите `general.displayLanguage` в настройках и выберите упрощённый китайский: ответы модели на английском и раскрытые размышления отображаются по-китайски в терминале и Web Shell. Архив, копирование и дальнейший диалог сохраняют оригинал. По умолчанию выключено; включается через `/settings` в терминале или на странице настроек Web Shell. Подробнее: PR [#18175](https://github.com/QwenLM/qwen-code/pull/18175)

**Расширение канала Microsoft Teams.** Установите расширение `@qwen-code/channel-msteams` отдельно и настройте бота Azure — в личных чатах и группах Teams упоминайте бота через @ и отдавайте ему задачи; разговоры на разные темы не мешают друг другу. Подробнее: PR [#15620](https://github.com/QwenLM/qwen-code/pull/15620)

**Режим экранного чтеца в CLI.** В терминале появился режим экранного чтеца (экспериментальный): запускайте с `--screen-reader` — готовый ответ озвучивается один раз, история листается с клавиатуры, выбранный элемент и операции, ждущие одобрения, читаются вслух. Графический интерфейс по умолчанию остаётся прежним. Подробнее: PR [#17500](https://github.com/QwenLM/qwen-code/pull/17500)

## 👏 Улучшения UX

**Web Shell открывается быстрее.** Терминал загружается только при использовании, записи больших сессий передаются в сжатом виде. От клика по исторической сессии до появления содержимого по замерам уходит около 0,8 секунды вместо примерно 1,3 секунды. Подробнее: PR [#17840](https://github.com/QwenLM/qwen-code/pull/17840), [#11220](https://github.com/QwenLM/qwen-code/pull/11220), [#18223](https://github.com/QwenLM/qwen-code/pull/18223)

**Бейдж фоновой задачи отвечает на вопрос «что она делает».** У каждого бейджа над полем ввода появился знак вопроса: клик — и AI простым языком объясняет, что делает задача и зачем она запущена. Ответ появляется в соседней панели вопросов и ответов; текущий диалог и задача продолжаются как обычно. Подробнее: PR [#17398](https://github.com/QwenLM/qwen-code/pull/17398)

**Сообщение в очереди не прерывает выполняющуюся команду.** AI выполняет команду, а вы отправляете ещё одну фразу — команда уходит в фон и продолжает работу, ваша фраза получает ответ сразу. Подробнее: PR [#17926](https://github.com/QwenLM/qwen-code/pull/17926)

**Изменения конфигурации MCP применяются сразу.** Добавили или убрали MCP-сервер в настройках — работающие сессии подхватывают изменение автоматически, перезапуск не нужен. Подробнее: PR [#17743](https://github.com/QwenLM/qwen-code/pull/17743)

**Подсказки для продолжения диалога появляются быстрее.** При генерации подсказок используется только небольшой фрагмент диалога. Подробнее: PR [#17532](https://github.com/QwenLM/qwen-code/pull/17532)

**Mods переписывают текст и в Web Shell.** Плагины Mods переписывают ответы и раскрытые размышления в Web Shell: текст отображается в переписанном виде. История, копирование, поиск и ветвление сохраняют оригинал. Требуется включённый `experimental.mods`. Подробнее: PR [#17718](https://github.com/QwenLM/qwen-code/pull/17718), [#17920](https://github.com/QwenLM/qwen-code/pull/17920)

**Предпросмотр этапов рабочего процесса.** Все этапы рабочего процесса перечислены с самого начала: ещё не запущенные помечены заранее, на текущем этапе виден фактический прогресс — общий ход работы читается с первого взгляда. Сначала включите рабочие процессы переменной окружения `QWEN_CODE_ENABLE_WORKFLOWS=1`. Подробнее: PR [#17782](https://github.com/QwenLM/qwen-code/pull/17782)

**Ступени размышлений Gemini 4 и Kimi K3 подключаются автоматически.** Подключите одну из этих моделей — ступени глубины размышлений доступны сразу. Подробнее: PR [#18039](https://github.com/QwenLM/qwen-code/pull/18039), [#18095](https://github.com/QwenLM/qwen-code/pull/18095)

**Переключение на резервную модель экономит время.** С включённым `experimental.modelAvailabilityTracking` модель, только что упавшая в этом раунде из-за нехватки мощности, пропускается: сразу работает следующая резервная модель, а в следующем раунде упавшую пробуют снова. По умолчанию выключено. Подробнее: PR [#17377](https://github.com/QwenLM/qwen-code/pull/17377)
