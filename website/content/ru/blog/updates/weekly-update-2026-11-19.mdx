На этой неделе Qwen Code выпустил три стабильные версии — с v0.27.3 по v0.28.0.

**Доступен новый флагман Qwen4-Max.** Новое поколение флагманских моделей Qwen уже подключено в свежем Qwen Code.

**Новые сессии по умолчанию работают в отдельной копии.** Откройте несколько сессий одного проекта параллельно: каждая правит свой worktree, ваша ветка и файлы остаются нетронутыми.

**Результаты задач уходят прямо в группы Feishu, WeCom и DingTalk.** Добавьте в группу собственного бота, укажите его webhook-адрес в Web Shell — уведомления и результаты задач по расписанию приходят в группу.

## ✨ Новые возможности

### Доступен новый флагман Qwen4-Max

Qwen4-Max — новый флагман семейства Qwen: стабильная версия вышла 16 ноября, модель работает с текстом, изображениями и видео и рассчитана на сложные рассуждения, программирование и агентные задачи.

Qwen Code подключил её на этой неделе. Модель доступна через Bailian, платформу Qwen AI, подписку Qwen и другие каналы. Глубина размышлений — три ступени: low, high и xhigh; по умолчанию high, размышление можно отключить.

Изображения и видео отправляйте прямо в диалог — модель их понимает. На каналах Bailian и платформы Qwen AI есть две настройки для экономии токенов: время хранения кэша продлевается с 5 минут по умолчанию до 1 часа, детализацию изображений можно снизить.

Что это даёт:

- приложите скриншот дизайн-макета — модель соберёт по нему страницу
- отправьте запись экрана — модель разберёт шаги воспроизведения бага
- трудноуловимый сбой теста — поднимите ступень размышлений

Подробнее: PR [#17513](https://github.com/QwenLM/qwen-code/pull/17513)

![Qwen4-Max в списке моделей и ступени глубины размышлений](https://img.alicdn.com/imgextra/i4/O1CN01cXhl153mN0L7o1Mj_!!6000000001943-2-tps-3845-2160.png)

### Новые сессии — в отдельных worktree, параллельные задачи не пересекаются

Несколько сессий Web Shell в одном проекте работают параллельно и правят файлы независимо: в доверенном Git workspace новая сессия по умолчанию получает отдельный worktree. Worktree — вторая рабочая копия того же репозитория: история коммитов общая, файлы каждая сессия правит свои.

Работа готова — забирайте результат двумя способами: «Создать ветку здесь» в меню веток превращает его в обычную ветку, «Передать локально» переносит правки в ваш исходный каталог.

Режим worktree по умолчанию не нужен — выставьте `worktree.defaultForNewSessions` в false, и сессии работают прямо в текущей ветке.

Что это даёт:

- несколько задач идут в параллельных сессиях, каждая в своей копии
- вы пишете код локально, AI работает в своей копии — оба процесса идут независимо
- две сессии пробуют два варианта рефакторинга — сравнивайте результат

Подробнее: PR [#17228](https://github.com/QwenLM/qwen-code/pull/17228)

### Результаты задач — прямо в группы Feishu, WeCom и DingTalk

Вслед за WeChat, QQ и почтой очередь дошла до групп: Feishu, WeCom и DingTalk получили способ подключения «Webhook (только отправка)». Добавьте в группу собственного бота и укажите его webhook-адрес в управлении каналами Web Shell — уведомления, результаты выполнения задач и результаты задач по расписанию приходят в группу сообщениями Markdown.

Это подключение одностороннее: оно только отправляет сообщения в группу, входящие сообщения группы не принимает. Для диалога с AI в группе используйте штатное подключение бота соответствующей платформы.

Что это даёт:

- задача по расписанию «каждое утро в 9 — сводка PR, слитых вчера»: результат сам приходит в проектную группу Feishu
- AI прогоняет регрессионные тесты каждый вечер и отправляет результат в группу WeCom — утром открываете готовую сводку
- уведомление о завершении длинной задачи само уходит в группу DingTalk — коллеги видят прогресс вместе с вами

Подробнее: PR [#16804](https://github.com/QwenLM/qwen-code/pull/16804), [#17013](https://github.com/QwenLM/qwen-code/pull/17013), [#17224](https://github.com/QwenLM/qwen-code/pull/17224)

### Web Shell: обзор изменений перед сдачей и прогресс фоновых задач

**Масштаб правок сессии виден в обзоре изменений.** Работа готова к сдаче, и нужно понять, сколько файлов затронуто и сколько строк добавлено или удалено, — откройте «Обзор изменений» в правой панели: списки файлов и число строк отдельно по незакоммиченным правкам, по каждому привязанному PR и по остальным коммитам. Подробнее: PR [#17378](https://github.com/QwenLM/qwen-code/pull/17378)

**Фоновые задачи открываются по бейджу.** Над полем ввода появились бейджи: запущенные рабочие процессы, shell, мониторинг и фоновые агенты — у каждого свой. Клик переносит в соответствующее представление выполнения. Подробнее: PR [#16813](https://github.com/QwenLM/qwen-code/pull/16813)

**Сессии в боковой панели фильтруются по workspace и дате.** Workspace стало больше — фильтруйте боковую панель по workspace; сессии группируются по дате активности: сначала сузьте выборку, потом ищите сессию. Подробнее: PR [#17244](https://github.com/QwenLM/qwen-code/pull/17244), [#17447](https://github.com/QwenLM/qwen-code/pull/17447)

**Прочие улучшения.** У каждого ответа видно, сколько раз сработали хуки, сколько вызовов заблокировано и сколько времени заняло ([#17015](https://github.com/QwenLM/qwen-code/pull/17015), [#17327](https://github.com/QwenLM/qwen-code/pull/17327)); русский перевод интерфейса дополнен ([#17414](https://github.com/QwenLM/qwen-code/pull/17414)); результаты поиска по сессиям стали понятнее, выбирать можно стрелками вверх и вниз ([#16779](https://github.com/QwenLM/qwen-code/pull/16779)).

## 📊 Прочие новинки

**Сессия передаёт задачу в другой workspace.** Web Shell держит несколько workspace — сессия может отдать задачу другому workspace: та выполняется по его инструкциям и настройкам, результат возвращается в исходную сессию, и можно задавать уточняющие вопросы. Первая передача задачи требует вашего подтверждения. Подробнее: PR [#17454](https://github.com/QwenLM/qwen-code/pull/17454), [#17484](https://github.com/QwenLM/qwen-code/pull/17484)

**Привязка PR дополняется вручную, накопленные комментарии приходят сводкой.** Автоматическая привязка пропустила PR — введите `/pr <номер или ссылка PR>`, и привязка дополнится; кнопка «Привязать PR» есть в обзоре сессии и в меню боковой панели Web Shell. Если сервис некоторое время был остановлен, после запуска накопленные комментарии привязанного PR объединяются в одну сводку и доставляются в сессию. Подробнее: PR [#16877](https://github.com/QwenLM/qwen-code/pull/16877), [#17199](https://github.com/QwenLM/qwen-code/pull/17199)

**Панель `/memory` управляет настройками.** В терминальной панели `/memory` включайте и выключайте автосохранение и периодическую очистку, открывайте и правьте файлы памяти уровня пользователя и уровня проекта. Подробнее: PR [#17213](https://github.com/QwenLM/qwen-code/pull/17213)

**Страница Goals собирает цели всех workspace.** Зарегистрировано несколько workspace — цели всех доверенных workspace собраны на одной странице и отсортированы по времени, каждая карточка помечена своим workspace. При создании цели выбирайте, в какой workspace её положить. Подробнее: PR [#17230](https://github.com/QwenLM/qwen-code/pull/17230)

**Плагины Mods переписывают блоки размышлений.** Плагины Mods меняют не только текст ответа в терминале, но и раскрытые блоки размышлений — например, переводят размышления на китайский. Работает в обоих терминальных интерфейсах. Подробнее: PR [#16873](https://github.com/QwenLM/qwen-code/pull/16873), [#17443](https://github.com/QwenLM/qwen-code/pull/17443)

**Web Shell полноценно работает по обычному HTTP.** Откройте Web Shell с другого компьютера по адресу `http://<IP компьютера>:<порт>` — терминальные вкладки, веб-превью и локальные команды работают. Подробнее: PR [#17196](https://github.com/QwenLM/qwen-code/pull/17196)

**Канал GitLab настраивается в Web Shell.** Белый список репозиториев поддерживает многоуровневые пути проектов вида group/subgroup/project. Подробнее: PR [#16845](https://github.com/QwenLM/qwen-code/pull/16845)

## 👏 Улучшения UX

**Сжатие контекста сохраняет последнюю операцию целиком.** Длинный диалог запускает сжатие: последняя операция и её результат остаются как есть, в сводку уходит только более ранняя история. Подробнее: PR [#17141](https://github.com/QwenLM/qwen-code/pull/17141)

**Незакоммиченные правки при смене ветки решаются на странице.** Отправьте правки в stash или отбросьте их прямо на странице и переключайте ветку — весь шаг проходит в одном окне. Подробнее: PR [#17364](https://github.com/QwenLM/qwen-code/pull/17364)

**Статус карточек Goals читается с первого взгляда.** Выполняется — синий, ждёт вашего решения — янтарный; цели с лимитами показывают прогресс-бары раундов, токенов и времени; длинный текст цели в сессии свёрнут в одну строку. Подробнее: PR [#17349](https://github.com/QwenLM/qwen-code/pull/17349), [#17133](https://github.com/QwenLM/qwen-code/pull/17133)

**Панель расхода открывается быстрее.** Речь о панели расхода на странице статуса Web Shell. Подробнее: PR [#17239](https://github.com/QwenLM/qwen-code/pull/17239)

**Текущая ступень подсвечена в окне выбора.** В окне глубины размышлений сразу видно выбранную ступень; то же в списке моделей и выборе режима выполнения. Подробнее: PR [#16622](https://github.com/QwenLM/qwen-code/pull/16622)

**Переименование сессии применяется сразу.** Подтвердили — новый заголовок отображается сразу. Подробнее: PR [#17006](https://github.com/QwenLM/qwen-code/pull/17006)
