На этой неделе Qwen Code выпустил две стабильные версии — v0.25.1 и v0.25.2 — и принял 371 pull-реквест.

**Agent Collaboration: Claude Code и Codex через @ становятся вашими напарниками.** Ответ напарника появляется прямо в текущем диалоге, а работать он может на другом компьютере.

**Несколько ваших Qwen Code подключены одновременно на одной странице.** В боковой панели каждый Qwen Code занимает свою группу; под группой перечислены его актуальные сессии и рабочие области, переключаться между ними можно прямо на странице.

**Не нужен конкретный MCP-сервис — отключите его при запуске.** `qwen --disable-mcp-server <имя>` действует только на этот запуск и не трогает файл настроек.

## ✨ Новые возможности

### Agent Collaboration: Claude Code и Codex через @ становятся вашими напарниками

Одну задачу можно разложить на несколько и решать параллельно: например, он правит код, а другая программа в это же время его проверяет. Раньше, когда вы вызывали агента через @, он заводил отдельную ветку, переносил туда ваши последние реплики и уводил вас на новую страницу — в основном диалоге его ответ так и не появлялся.

Теперь вы вызываете его через @ — и он отвечает прямо в этом диалоге: видно имя, до какого шага он дошёл, какие инструменты использовал и сколько токенов потратил; перед запуском команды по-прежнему показывает её вам на одобрение. Это необязательно Qwen Code: если у вас установлены Claude Code или Codex, их можно позвать так же. Подробнее: PR [#13467](https://github.com/QwenLM/qwen-code/pull/13467)

Он может работать и на другом компьютере: там поднят сервис Qwen Code, добавляете его как помощника — и тяжёлую работу отправляете на ту машину; если та перезагрузится, соединение восстановится само. Можно вызвать через @ и целую группу: ведущий разбивает задачу и раздаёт её участникам, а выполненные возвращаются ему. Подробнее: PR [#13583](https://github.com/QwenLM/qwen-code/pull/13583)

Чем это отличается от субагента: субагента модель выпускает сама, по небольшому делу, и отчитывается только ей; вызванный через @ говорит у вас на глазах — это может быть программа другого вендора и другая машина.

Функция пока экспериментальная и по умолчанию выключена: включите «Enable Agent Collaboration» в настройках и перезапустите. Напарника нужно создать заранее — на странице «Agents» слева. После этого в любом диалоге достаточно вызвать его по имени через @.

Что это даёт:

- он правит код, а второй агент через @ параллельно проверяет — обе линии видно в одном диалоге
- тяжёлую работу — сборку, прогон тестов — отправляете на другую машину и продолжаете работать у себя
- в одну группу собираются программы разных вендоров, каждая берёт свой участок

### Несколько Qwen Code подключены одновременно на одной странице

У кого-то под рукой ноутбук, отдельная машина под сборку и ещё одна с длинной задачей; у кого-то один компьютер, но на каждый проект заведён свой Qwen Code Web Shell, и смешивать дела не хочется. Раньше браузерная страница знала только один из них: чтобы посмотреть другой, страницу нужно было перезагрузить целиком — с миганием посередине и с потерей того, что вы уже написали.

Теперь все сохранённые подключены одновременно. В боковой панели каждый Qwen Code — отдельная группа, под ней перечислены его текущие сессии и рабочие области; когда выбираете рабочую область в поле ввода, каталоги тоже разложены по группам. Переключение на другую группу происходит прямо на странице. Подробнее: PR [#13739](https://github.com/QwenLM/qwen-code/pull/13739), [#13677](https://github.com/QwenLM/qwen-code/pull/13677)

Чтобы это заработало, тот компьютер должен пустить вашу страницу: запускайте `qwen serve` с `--allow-origin`, вписав адрес, который вы видите в строке браузера.

Что это даёт:

- на машине сборки идёт длинная задача — вы со своего компьютера видите, до чего она дошла
- на одном компьютере отдельный Qwen Code на каждый проект: дела не смешиваются, а всё видно на одной странице
- пересесть с ноутбука на десктоп и продолжать раздавать задачи оттуда же

### Не нужен MCP-сервис — отключите его при запуске

Знакомо всем, кто подключает MCP-сервисы: сегодня один из них сбоит — инструменты выдают ошибку или запуск тормозит, а хочется только одного: «в этот раз без него». Раньше годилось лишь решение одним махом — отключить сервис из настроек вместе с локальной конфигурацией.

Теперь его можно указать по имени прямо при запуске:

```text
qwen --disable-mcp-server github
```

Если нужно убрать сразу несколько, параметр можно повторить или записать как `--disable-mcp-server github,postgres`. Он действует только на этот запуск, ваш файл настроек остаётся нетронутым. Подробнее: PR [#14003](https://github.com/QwenLM/qwen-code/pull/14003)

Что это даёт:

- подозреваете сервис — отключите его на один запуск и проверьте, он ли
- запуск тормозит из-за сервиса — на этот раз идите без него
- на одном и том же коде: один прогон — только база данных, другой — только веб-страницы, каждый со своим сервисом

### Web Shell: файлы проекта открываются кликом, добавленное сообщение уходит сразу, а когда вас ждут — уведомление

**Файлы проекта листаются прямо справа.** Дерево каталогов всей рабочей области здесь; открыли файл — содержимое рядом. Markdown, веб-страницы, картинки и Excel смотрятся сразу; путь можно скопировать, файл скачать или сослаться на него. Подробнее: PR [#13878](https://github.com/QwenLM/qwen-code/pull/13878), [#13664](https://github.com/QwenLM/qwen-code/pull/13664)

**Локальный файл загружается перетаскиванием.** В какую папку дерева перетащили — туда и легло; в десктопной версии то же самое. Подробнее: PR [#14145](https://github.com/QwenLM/qwen-code/pull/14145), [#14053](https://github.com/QwenLM/qwen-code/pull/14053)

**Сообщение из очереди вставляется немедленно, отменённое возвращается в поле ввода.** То, что вы отправили, пока он ещё отвечает, встаёт в очередь. Нужно, чтобы он получил это как можно скорее, — нажмите «Send now», и сообщение вставится сразу. Если остановить до того, как в ответе появился первый символ, та реплика вернётся в поле ввода: поправьте и отправьте снова. Подробнее: PR [#13681](https://github.com/QwenLM/qwen-code/pull/13681), [#13488](https://github.com/QwenLM/qwen-code/pull/13488)

**Когда он останавливается и ждёт вас — приходит уведомление.** Нужно одобрить операцию или ответить на его встречный вопрос — раньше в обоих случаях было полное молчание. Теперь, если страница ушла в фон, появляется уведомление; одно нажатие возвращает вас в ту сессию. Подробнее: PR [#13832](https://github.com/QwenLM/qwen-code/pull/13832)

**Пока идут субагенты или фоновые задачи, на значке-списке вверху области чата горит мигающая точка.** Это видно, не открывая панель. Подробнее: PR [#14048](https://github.com/QwenLM/qwen-code/pull/14048)

## 📊 Прочие новинки

**Если он долго только ищет и не даёт результат, его подталкивают к выводу.** После определённого числа только-читающих действий — чтения файлов, поиска по коду — следующим ходом он получает напоминание: использовать уже найденное, сделать шаг к тому, что вы просили, или объяснить, на чём встал. Если задача и состояла в том, чтобы разобраться в ситуации, — выдать вывод и открытые вопросы. Подробнее: PR [#13601](https://github.com/QwenLM/qwen-code/pull/13601)

**Интерфейс от MCP-сервиса не отправит сообщение в диалог без вашего подтверждения.** Некоторые сервисы дают не только инструменты, но и кликабельную панель прямо в переписке. Когда эта панель хочет отправить текст за вас, Qwen Code сперва показывает всё содержимое, его источник и то, в какой диалог оно пойдёт, — и только после вашего подтверждения сообщение уходит. Подробнее: PR [#13958](https://github.com/QwenLM/qwen-code/pull/13958)

**Что сделал каждый агент в рабочем процессе, видно по его узлу.** Нажмите агента на карточке рабочего процесса в диалоге, на странице Tasks или на странице рабочего процесса — и в правой панели откроется его текущий прогон: заданный ему промпт, какие инструменты он вызвал, что выводится сейчас, до какого шага дошёл. Подробнее: PR [#14175](https://github.com/QwenLM/qwen-code/pull/14175)

**Проверка перед действием может подменить параметры этого запуска.** Хуки, которые вы задали в настройках, — это как раз такая проверка: она отрабатывает перед использованием инструмента. Если хук вернул новые параметры, их сначала проверяют заново, затем снова проходят права и подтверждение — и только потом действие выполняется по-настоящему. Подробнее: PR [#13442](https://github.com/QwenLM/qwen-code/pull/13442)

**Вопрос между делом можно адресовать другой рабочей области.** Пока основная задача отвечает, `/btw side` заводит отдельный диалог в другой рабочей области — и не смешивается с основной. Подробнее: PR [#13468](https://github.com/QwenLM/qwen-code/pull/13468)

**Команды из плагинов в формате Claude теперь по-настоящему исполняются.** Такая команда — это код, а не промпт для модели: раньше её ввод означал «сказать что-то модели», теперь плагин выполняет команду локально и сразу возвращает результат, не расходуя токены. Нужно включить `experimental.mods` в настройках, рабочая область должна быть доверенной, и работает только в однократном прогоне вида `qwen -p '…'` — в интерактивном интерфейсе и Web Shell пока нет. Реализована лишь часть интерфейса Mod, так что готовая команда не обязана завестись. Подробнее: PR [#13843](https://github.com/QwenLM/qwen-code/pull/13843), [#13890](https://github.com/QwenLM/qwen-code/pull/13890), [#13915](https://github.com/QwenLM/qwen-code/pull/13915), [#13950](https://github.com/QwenLM/qwen-code/pull/13950)

## 👏 Улучшения UX

**На странице новой задачи правые панели — файлы, терминал и предпросмотр веб-страниц — работают, ещё до того как вы что-то написали.** Верх заменили компактной панелью инструментов; каждая рабочая область запоминает этот расклад, он переживает перезагрузку и переключение сессий. Когда вы отправляете первую реплику, в новую сессию переходят и вкладки, и их порядок, и ширина панелей, и полноэкранный режим. Подробнее: PR [#14159](https://github.com/QwenLM/qwen-code/pull/14159)

**Вкладка Trajectory умеет искать, фильтровать и листать историю.** Поиск по имени инструмента, имени модели или тексту записи допрыгивает до нужного; можно оставить только один тип записей или только неудачные либо только успешные. Более старые записи подгружаются порциями, а после прокрутки вы возвращаетесь к самой свежей — поиск и статистика считают только тот диапазон, который вы сейчас пролистали. Обрыв связи и переподключение ничего не сбрасывают: где вы остановились, что выбрали, какой фильтр стоит и до куда прокрутили — всё остаётся. Подробнее: PR [#13264](https://github.com/QwenLM/qwen-code/pull/13264), [#13716](https://github.com/QwenLM/qwen-code/pull/13716), [#13952](https://github.com/QwenLM/qwen-code/pull/13952)

**Выделив кусок ответа, выберите, как его копировать.** Выделите мышью — в меню два варианта: простым текстом или Markdown с исходным оформлением, где заголовки, списки, код и таблицы переносятся как есть. Подробнее: PR [#13833](https://github.com/QwenLM/qwen-code/pull/13833)

**Сколько занято в контексте — открывается справа, а не карточками в диалоге.** Раньше клик по кольцу у поля ввода ронял в переписку карточку Context Usage, а детали из неё роняли ещё одну. Теперь оба вида живут в правой панели, у каждой сессии своя копия. Хотите оставить карточку в диалоге — наберите `/context`. Подробнее: PR [#14086](https://github.com/QwenLM/qwen-code/pull/14086)

**Широкую и длинную таблицу можно развернуть на весь экран.** Нажмите Fullscreen на таблице — она займёт всё окно; выход по Esc или кнопкой выхода. Ваша сортировка, фильтры, настройки столбцов и строка, до которой вы дочитали, остаются. Подробнее: PR [#13589](https://github.com/QwenLM/qwen-code/pull/13589)

**Сообщение из очереди можно удалить прямо там, не отправляя.** Это верно и для того, что ещё загружается с вложением: временный файл тоже подчищается. Подробнее: PR [#13594](https://github.com/QwenLM/qwen-code/pull/13594)

**Свернули раунд — результаты фоновых задач убираются вместе с ним.** Карточки вывода фоновых задач и уведомления о завершении попадают в тот же свод. Подробнее: PR [#13825](https://github.com/QwenLM/qwen-code/pull/13825)

**У подсказок голосового ввода появился китайский, а ошибку можно закрыть.** Сообщения об ошибке и «Звук не услышан» показываются на языке интерфейса; кнопка закрытия в правом верхнем углу подсказки возвращает микрофон в готовность — можно пробовать сразу снова. Подробнее: PR [#13938](https://github.com/QwenLM/qwen-code/pull/13938)

**Нужна отдельная рабочая копия — достаточно выбрать Worktree.** Нажатие в диалоге Git сразу фиксирует выбор и закрывает меню; имя подбирается и копия создаётся по тому же порядку, что и при создании сессии, — и только когда вы отправляете первую реплику. До этого выбор можно вернуть. Подробнее: PR [#13607](https://github.com/QwenLM/qwen-code/pull/13607)

**Иконки привели к текущему фирменному знаку.** Заменили значок во вкладке браузера Web Shell, логотип в боковой панели, иконку браузерных уведомлений, а также заставку и иконку приложения в десктопной версии. Подробнее: PR [#14052](https://github.com/QwenLM/qwen-code/pull/14052)
