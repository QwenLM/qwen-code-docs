На этой неделе Qwen Code выпустил четыре стабильные версии — с v0.26.4 по v0.26.7.

**У удалённого подключения появился отдельный переключатель — пользоваться стало удобнее.** Зайдите в **Настройки → Подключение** и включите **«Разрешить удалённое подключение»**: теперь в той же сети можно подключиться к другому компьютеру.

**События GitHub сами продвигают вашу сессию.** Привязали репозиторий к каналу — новые коммиты, ревью и падения CI сами приходят в сессию, привязанную к этому PR.

**Состояние Web Shell тоже видно яснее.** События канала собраны в одном месте, а в боковой панели сразу видно: какая сессия работает, какая ждёт вас.

## ✨ Новые возможности

### Удалённое подключение: работаете с другого компьютера в той же сети

Раньше, чтобы связать несколько экземпляров Qwen Code в одну страницу, на принимающей стороне нужно было запускаться с `--hostname 0.0.0.0`. Теперь, когда компьютеры в одной сети, достаточно в **Настройки → Подключение** ввести адрес и Bearer-токен — и вы на другом компьютере.

На этой неделе в **Настройки** → **Подключение** добавили переключатель **«Разрешить удалённое подключение»**: включаете — генерируется адрес и Bearer-токен, вводите их на другом компьютере, подключаетесь без перезапуска. Закончили — выключаете. Подробнее: PR [#15887](https://github.com/QwenLM/qwen-code/pull/15887), [#16199](https://github.com/QwenLM/qwen-code/pull/16199)

Что это даёт:

- пересесть за другой компьютер и продолжить тот же диалог
- отойти от рабочего места и удалённо ответить на вопрос или согласовать правку
- временно открыть удалённый доступ и закрыть, когда всё сделано




![Удалённые подключения](https://img.alicdn.com/imgextra/i4/O1CN01WL5kej9I8kI4s7XG_!!6000000004481-2-tps-2400-1626.png)

### События из репозитория GitHub сами приходят в вашу сессию

Привязали репозиторий GitHub к каналу — новый коммит, ревью или упавшая CI сами уходят в сессию, которая ведёт этот PR. Qwen Code видит событие и действует дальше: например, читает лог упавшей сборки и правит. Ответ по умолчанию не публичный — его сначала видите вы, и только после вашего подтверждения он уходит в PR. Подробнее: PR [#16117](https://github.com/QwenLM/qwen-code/pull/16117), [#16258](https://github.com/QwenLM/qwen-code/pull/16258)

В редакторе канала теперь прямо настраиваются права доступа к репозиторию, поведение при @-упоминаниях и частота уведомлений — без ручной правки файлов настроек. Номера PR и issue в событиях становятся кликабельными ссылками. Подробнее: PR [#16149](https://github.com/QwenLM/qwen-code/pull/16149), [#16096](https://github.com/QwenLM/qwen-code/pull/16096), [#16226](https://github.com/QwenLM/qwen-code/pull/16226)

Что это даёт:

- CI упала — лог уже в сессии, не надо искать самому
- коллега отревьюил PR — замечания видны прямо в интерфейсе чата
- нужно следить за новым репозиторием — вставили адрес в редакторе, и готово

### Web Shell: события канала и состояние сессий видны прямо в интерфейсе

**События канала теперь собраны в одном месте.** В канале каждый день что-то происходит: коммиты GitHub, отработавшие задачи по расписанию, ответы сессий. Теперь на странице канала есть столбец «События»: все активности выстроены по времени, можно фильтровать по каналу, лента обновляется сама. Подробнее: PR [#16106](https://github.com/QwenLM/qwen-code/pull/16106)

**Панель расхода токенов раскладывается по запросам.** Раньше показывалась сумма по каждой категории, теперь каждый запрос отдельно: скорость вывода, время до первого ответа, успех или ошибка, разные модели — разным цветом. Раскрыли запрос — видна конкретная причина сбоя. Подробнее: PR [#16108](https://github.com/QwenLM/qwen-code/pull/16108), [#16111](https://github.com/QwenLM/qwen-code/pull/16111)

**У сессий в боковой панели появились метки состояния.** Раньше в боковой панели были только имена сессий — непонятно, что внутри происходит. Теперь у каждой сессии метка: работает — крутится индикатор, ждёт одобрения — оранжевая подсказка, ошибка — красная полоса. Раскрыли метку — видно, кто ждёт и на какую реплику только что ответили. Непрочитанные сообщения тоже подсвечены, можно разом отметить всё прочитанным или отправить в архив. Подробнее: PR [#16022](https://github.com/QwenLM/qwen-code/pull/16022)

**Сессии можно расставить рядом.** В контекстном меню сессии появилось «Добавить в разделённый вид» — две сессии раскладываются слева и справа, удобно сравнивать. Подробнее: PR [#15956](https://github.com/QwenLM/qwen-code/pull/15956)

**Прочие улучшения.** Переключатель режима Workflow переехал в меню «+» рядом с полем ввода; когда включён, появляется ярлык, по которому его можно выключить ([#16107](https://github.com/QwenLM/qwen-code/pull/16107), [#15779](https://github.com/QwenLM/qwen-code/pull/15779)). Скопировали адрес картинки в поле ввода — она сама становится вложением; скриншот тоже вставляется напрямую ([#16179](https://github.com/QwenLM/qwen-code/pull/16179)).

## 📊 Прочие новинки

**Интерактивные карточки включены по умолчанию.** Раньше их надо было включать в настро

йках, теперь работают сразу после установки: попросили посчитать ипотеку или сравнить варианты — двигаете ползунки и видите результат прямо в диалоге. Настроили параметры, нажали «Сохранить» — и они возвращаются в сессию, можно продолжать разговор. Подробнее: PR [#15856](https://github.com/QwenLM/qwen-code/pull/15856)

**Скачанный проект сначала просит доверия — и только потом запускает хуки.** Чужие проекты с хуками, правилами доступа и языковыми серверами: перед запуском появляется окно подтверждения, нажали «Доверять» — тогда применяется. Локальные проекты, созданные на вашем компьютере, это не затрагивает. Подробнее: PR [#16182](https://github.com/QwenLM/qwen-code/pull/16182), [#16196](https://github.com/QwenLM/qwen-code/pull/16196)

**`/verify-pr` запускает недоверенный код в Docker.** Одна команда поднимает локальный контейнер, код из PR заходит внутрь и проверяется; ключи моделей остаются на вашем компьютере и в контейнер не передаются. Подробнее: PR [#16077](https://github.com/QwenLM/qwen-code/pull/16077)

**Десктопная версия — для Fedora 44 и RHEL 10.** Пользователи этих систем скачивают rpm-пакет прямо из GitHub Releases и устанавливают. Подробнее: PR [#16060](https://github.com/QwenLM/qwen-code/pull/16060)

**Управление группой QQ тоже можно отдать AI.** Канал отдаёт свои инструменты модерации сессиям, которые в нём работают: отзыв сообщений, исключение участников, одобрение заявок — AI выполняет эти действия за вас. Какие инструменты доступны, настраивается через `moderationTools` в настройках канала. Подробнее: PR [#14348](https://github.com/QwenLM/qwen-code/pull/14348)

**Managed Agent разворачивается с нуля одной командой Helm.** Настроили Helm-чарт — MySQL и шлюз идут в комплекте. Подробнее: PR [#15492](https://github.com/QwenLM/qwen-code/pull/15492)

**Архивные диалоги восстанавливаются прямо из настроек.** Зашли в Настройки → Архив: у каждой записи кнопки «Восстановить» и «Экспорт» — не нужно открывать саму сессию. Подробнее: PR [#15872](https://github.com/QwenLM/qwen-code/pull/15872)

**При вводе скилла видна подсказка с оставшимися параметрами.** Набрали `/qwencode-weekly` — подсказка с параметрами висит над полем ввода; заполнили один — она сворачивается до следующего. Подробнее: PR [#15930](https://github.com/QwenLM/qwen-code/pull/15930)

**Команда обновления принимает конкретную версию.** `qwen update --target-version <номер версии>` ставит указанную версию напрямую, не нужно сначала проверять npm registry на наличие новой; подходит и для отката, и для переустановки той же версии. Подробнее: PR [#11486](https://github.com/QwenLM/qwen-code/pull/11486)

## 👏 Улучшения UX

**`/autofix-pr` стал надёжнее: сам подтягивает основную ветку, работает в вашем каталоге и принимает число раундов.** Ветка отстала от основной, и CI красный — он сначала вливает основную ветку и потом прогоняет проверки, без ручного rebase. С флагом `--in-place` работает прямо в вашем checkout — вы смотрите и правите рядом. В PR пишете `@qwen-code /takeover for N` — он отрабатывает N раундов и после сам отпускает. Подробнее: PR [#15922](https://github.com/QwenLM/qwen-code/pull/15922), [#15929](https://github.com/QwenLM/qwen-code/pull/15929), [#15388](https://github.com/QwenLM/qwen-code/pull/15388)

**Длинный ответ теперь с прокруткой.** `/btw` выдал очень длинный ответ — он закреплён в рамке с полосой прокрутки; листается колёсиком, стрелками и PageUp/PageDown. Подробнее: PR [#15982](https://github.com/QwenLM/qwen-code/pull/15982)

**У моделей DeepSeek V4, qwen4 и семейства latest-series тоже можно задать глубину размышлений.** У этих поколений не было выбираемой глубины, а у DeepSeek V4.1 Flash через прокси Alibaba не было и значения по умолчанию; теперь уровни заданы для каждой модели, а отключение размышлений по-прежнему идёт через существующий переключатель. Подробнее в PR [#15987](https://github.com/QwenLM/qwen-code/pull/15987), [#15828](https://github.com/QwenLM/qwen-code/pull/15828)

**Обновление в Web Shell в один клик — для pnpm, yarn и bun.** Раньше кнопка обновления работала только с npm, теперь все три пакетных менеджера обновляются в один клик; если менеджер не поддерживается, показываются шаги для ручного обновления. Подробнее: PR [#15849](https://github.com/QwenLM/qwen-code/pull/15849)

**В строке состояния видно, сколько фоновых агентов работает.** В десктопе и Web Shell внизу, на метке задач, в реальном времени показывается число запущенных агентов. Подробнее: PR [#14002](https://github.com/QwenLM/qwen-code/pull/14002)

**Навигация по коду говорит, почему не сработала.** Нет доступного языкового сервера — раньше молча возвращался пустой результат, теперь явно сказано: языковой сервер сейчас недоступен. Подробнее: PR [#15946](https://github.com/QwenLM/qwen-code/pull/15946)

**Контекстные файлы памяти открываются для просмотра в панели.** Файлы вроде AGENTS.md — нажали, и содержание видно. Подробнее: PR [#15932](https://github.com/QwenLM/qwen-code/pull/15932)

**Пустой список сессий без workspace больше не занимает место.** Раньше пустая колонка висела и отъедала пространство, теперь, как с закреплёнными — нет сессий, нет и колонки. Подробнее: PR [#15916](https://github.com/QwenLM/qwen-code/pull/15916)
