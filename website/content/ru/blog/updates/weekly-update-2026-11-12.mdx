На этой неделе Qwen Code выпустил пять стабильных версий — с v0.26.8 по v0.27.2.

**Вход по подписке Qwen — и сразу за работу.** CLI, VS Code и десктопная версия принимают вход с подпиской Plus/Pro: модели подписки доступны для чата и веб-поиска, расход списывается с подписки.

**WeChat, QQ и почта подключаются в Web Shell.** WeChat и QQ входят по QR-коду прямо на странице, для почты достаточно адреса сервера и данных аккаунта.

**Канал GitHub фильтрует события по репозиториям.** Белый список пропускает только перечисленные репозитории, чёрный список исключает перечисленные.

## ✨ Новые возможности

### Вход в Qwen Code по аккаунту с подпиской Qwen

Если у вашего аккаунта Qwen уже есть подписка Plus или Pro, войдите с этим аккаунтом в терминале, VS Code или десктопной версии. В терминале выполните `/auth`, выберите аккаунт Qwen с подпиской и завершите авторизацию в браузере. После входа клиент загружает модели, доступные по подписке; встроенный веб-поиск тоже работает.

Что это даёт:

- модели подписки сразу идут в работу, расход списывается с подписки
- один аккаунт в терминале, VS Code и десктопной версии — модели одинаковые
- API подключать не нужно: оформили подписку Qwen — и пользуетесь ею в Qwen Code

Подробнее: PR [#16378](https://github.com/QwenLM/qwen-code/pull/16378)

![Аккаунт и список моделей после входа по подписке Qwen](https://img.alicdn.com/imgextra/i2/O1CN01yN4UdkxBF2G7nW9B_!!6000000007738-2-tps-3841-2160.png)

### Настройка каналов WeChat, QQ и почты в Web Shell

Личный WeChat, QQ и почта теперь подключаются в управлении каналами Web Shell. WeChat и QQ показывают QR-код прямо на странице — отсканируйте его телефоном и войдите. Для почты укажите адрес сервера и данные аккаунта. Теперь в Web Shell настраиваются все основные чат-платформы, кроме Telegram.

Что это даёт:

- отсканировали QR-код в Web Shell телефоном — подключили личный чат WeChat или привязали QQ
- добавили или изменили почтовый канал в управлении каналами и указали, каким отправителям можно начинать сессию письмом
- отменить сопряжение канала можно в Web Shell одним нажатием

Подробнее: PR [#16736](https://github.com/QwenLM/qwen-code/pull/16736), [#16724](https://github.com/QwenLM/qwen-code/pull/16724), [#16746](https://github.com/QwenLM/qwen-code/pull/16746)

![Страница входа по QR-коду канала WeChat в Web Shell](https://img.alicdn.com/imgextra/i1/O1CN01ldag0pIAw9J4s7XG_!!6000000004740-2-tps-2400-1626.png)

### Канал GitHub фильтрует события по репозиториям

Канал GitHub сам доставляет события репозиториев в сессию: кто-то открыл PR, оставил комментарий, CI отработала — агент подхватывает и продолжает. Теперь вы выбираете диапазон: белый список пропускает только перечисленные репозитории, чёрный список — все, кроме перечисленных. Исключённые события агент пропускает: они не попадают в сессию и не обрабатываются.

Что это даёт:

- в организации сотни репозиториев — перечислите свои два, и события приходят только по ним
- репозиторий, за которым сейчас не следите, добавьте в чёрный список; вернётесь к нему — уберите
- PR посторонних репозиториев не занимают очередь агента, нужные репозитории обрабатываются быстрее

Подробнее: PR [#16493](https://github.com/QwenLM/qwen-code/pull/16493)

![Настройки фильтра репозиториев в редакторе канала](https://img.alicdn.com/imgextra/i4/O1CN01NAru06FwyBE7o1Mj_!!6000000003227-2-tps-3845-2160.png)

### Web Shell: вопросы и расход на виду, сессии разбираются пачками

**Тепловая карта вопросов и ответов.** Длинная задача идёт несколько дней, и нужно вернуться к вопросам и ответам конкретного дня — откройте тепловую карту: это календарь по дням, глубина цвета показывает число вопросов и ответов за день, клик по дню переносит к первому вопросу этого дня. Подробнее: PR [#16037](https://github.com/QwenLM/qwen-code/pull/16037)

**Под полем ввода появилась строка расхода.** Число раундов, скорость вывода, всего токенов и доля попаданий в кэш — сразу под полем ввода, без открытия панели расхода токенов. Подробнее: PR [#16815](https://github.com/QwenLM/qwen-code/pull/16815)

**Сессии закрепляются и архивируются пачками.** В боковой панели появился переключатель множественного выбора: отметьте сессии и закрепите или архивируйте их одним нажатием. Подробнее: PR [#16702](https://github.com/QwenLM/qwen-code/pull/16702)

**У вариантов выбора появились подробности.** AI задал вопрос с вариантами, а смысл непонятен — нажмите «Спросить подробнее» в панели вопроса: откроется отдельная задача и разберёт, что значит каждый вариант, чем они отличаются, на что влияют и что рекомендуется. Подробнее: PR [#16458](https://github.com/QwenLM/qwen-code/pull/16458)

**Прочие улучшения.** Все workspace сворачиваются или разворачиваются одним нажатием, порядок меняется перетаскиванием за заголовок ([#16197](https://github.com/QwenLM/qwen-code/pull/16197)); фоновая задача ждёт одобрения — десктоп шлёт уведомление, терминал звонит, не пропустите и в другом окне ([#16800](https://github.com/QwenLM/qwen-code/pull/16800)); карточки инструментов вроде вызовов MCP раскрываются сразу с параметрами и полным результатом ([#15435](https://github.com/QwenLM/qwen-code/pull/15435)); на страницу навыков можно загрузить ZIP-архив и установить навык ([#16424](https://github.com/QwenLM/qwen-code/pull/16424)).

![Множественный выбор в боковой панели Web Shell и строка расхода под полем ввода](https://img.alicdn.com/imgextra/i2/O1CN01kYhxxjdH7KK7o1Mj_!!6000000001014-2-tps-3845-2160.png)

## 📊 Прочие новинки

**Задачи по расписанию выбирают канал доставки.** При создании задачи по расписанию в Web Shell укажите, в какой канал отправлять результат. Подробнее: PR [#16524](https://github.com/QwenLM/qwen-code/pull/16524)

**QQ-бот сам отправляет сообщения в группу.** Результаты задач по расписанию, webhook и фоновых задач теперь уходят в QQ-группу по инициативе бота. Необязательный переключатель `forwardBotMessages` добавляет пересылку сообщений других ботов группы в сессию. Подробнее: PR [#15635](https://github.com/QwenLM/qwen-code/pull/15635), [#15904](https://github.com/QwenLM/qwen-code/pull/15904)

**Хук FileChanged следит за файлами.** В локальных сессиях появился хук `FileChanged`: создание, изменение или удаление отслеживаемого файла или каталога запускает настроенный хук. Изменения от других программ тоже приходят. Подробнее: PR [#13969](https://github.com/QwenLM/qwen-code/pull/13969)

**Плагины Mods получили три новые возможности.** `$.store` хранит данные плагина между сессиями; `ui.render` меняет текст ответа в терминале — сохранённый и скопированный текст остаётся прежним; `$.model.complete` делает разовое текстовое дополнение. Подробнее: PR [#16791](https://github.com/QwenLM/qwen-code/pull/16791), [#16794](https://github.com/QwenLM/qwen-code/pull/16794), [#16737](https://github.com/QwenLM/qwen-code/pull/16737)

**Комментарии привязанного PR сами приходят в сессию.** Сессия привязана к PR — новые комментарии под этим PR автоматически доставляются в неё: и обычные, и замечания ревью к конкретным строкам. Упоминание через @ не нужно. Подробнее: PR [#16602](https://github.com/QwenLM/qwen-code/pull/16602)

## 👏 Улучшения UX

**`/btw` продолжает прошлые ответы и держит несколько вопросов сразу.** Новый вопрос между делом получает предыдущие ответы — уточняйте, отталкиваясь от них. Несколько вопросов идут параллельно, каждый со своим ответом, и не перебивают друг друга. Подробнее: PR [#16408](https://github.com/QwenLM/qwen-code/pull/16408)

**AI знает, в каком Shell пойдут команды.** В начале сессии указывается Shell для команд (bash, cmd.exe и другие) — AI пишет синтаксис под него, а не угадывает по системе. На Windows ошибок в командах меньше. Подробнее: PR [#16491](https://github.com/QwenLM/qwen-code/pull/16491)

**Автозаголовки сессий говорят на языке диалога.** Диалог на китайском языке получает заголовок на китайском — каждый язык со своим заголовком. Подробнее: PR [#16806](https://github.com/QwenLM/qwen-code/pull/16806)

**Причины проверки Goal показываются на языке сессии.** Почему проверка пройдена или отклонена — объясняется на языке вывода сессии. Подробнее: PR [#15806](https://github.com/QwenLM/qwen-code/pull/15806)

**Подсказки уточнений на тайском, лаосском, кхмерском и бирманском остаются на своём языке.** Общаетесь на одном из этих языков — подсказки для уточняющих вопросов генерируются на нём же. Подробнее: PR [#16341](https://github.com/QwenLM/qwen-code/pull/16341)

**Экспериментальный LSP включается в настройках.** Выставьте `tools.lspEnabled` в true на уровне пользователя — переход к определению, поиск использований и диагностика работают без флагов командной строки, даже в десктопной версии, куда флаг не передать. По умолчанию функция выключена. Подробнее: PR [#14613](https://github.com/QwenLM/qwen-code/pull/14613)

**Передний план для дочерних агентов задаётся глобально.** Выставьте `agents.defaultBackground` в false: дочерние агенты отрабатывают на переднем плане и возвращают результат в текущем раунде. Это подходит каналам и ботам, которым результат нужен за один раунд. Изменение вступает в силу после перезапуска. Подробнее: PR [#15178](https://github.com/QwenLM/qwen-code/pull/15178)

**Управляемая сессия держит несколько вопросов сразу.** Вопросы, которые задала управляемая сессия, могут висеть одновременно — отвечайте в любом порядке. Подробнее: PR [#16484](https://github.com/QwenLM/qwen-code/pull/16484)

**События канала ведут в свою сессию.** Клик по записи в ленте событий канала открывает соответствующую сессию. Подробнее: PR [#16375](https://github.com/QwenLM/qwen-code/pull/16375)
