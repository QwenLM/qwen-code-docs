За последние две недели Qwen Code выпустил 4 стабильных релиза — с v0.24.5 по v0.25.0 — и принял 467 pull-реквестов.

**Заработал Qwen Live.** Говорите с ним напрямую — он отвечает голосом; во время вызова можно показать экран, чтобы он видел то, что происходит у вас на экране.

**Qwen Code умеет работать в ваших авторизованных страницах.** Он действует в том самом Chrome, которым вы пользуетесь каждый день: переключает страницы, заполняет формы, отправляет — и всё это в фоне, компьютер остаётся в вашем распоряжении.

**Отправили письмо — и задача поставлена.** Вас нет за компьютером? Наберите пару строк в почтовом приложении телефона: Qwen Code на том компьютере возьмётся за дело и ответит письмом, когда закончит.

**Пакет однотипных задач уходит в фон вдвое дешевле через /batch-api.** Опишите, что нужно сделать; сначала он даст план без списания с баланса — работа отправится только после вашего одобрения, а через несколько часов результаты лягут в отдельные файлы.

**Раунд оказался долгим или дорогим — вкладка Trajectory покажет, где узел.** Дорожки Model requests, Tool calls и Subagent requests разложены отдельно; аномально длинный участок заметен сразу.

## ✨ Новые возможности

### Заработал Qwen Live

Qwen Live доступен и в Web Shell, и в десктопной версии. Нажмите значок Live в боковой панели слева — справа откроется карточка Qwen Live: включите тумблер, вставьте туда свой API-ключ DashScope Realtime от Bailian и нажмите Save. Подробнее: PR [#12529](https://github.com/QwenLM/qwen-code/pull/12529)

После включения нажмите «Open Live Voice» на странице Live или кнопку голосового вызова в правом нижнем углу поля ввода — и говорите, он ответит голосом. Подробнее: PR [#12189](https://github.com/QwenLM/qwen-code/pull/12189)

Во время разговора можно нажать «Демонстрация экрана» — и он увидит то, что происходит у вас на экране: например, сразу спросите, что значит ошибка, открытая перед вами. Подробнее: PR [#12378](https://github.com/QwenLM/qwen-code/pull/12378), [#12623](https://github.com/QwenLM/qwen-code/pull/12623)

Что это даёт:

- Руки заняты клавиатурой — просто скажите голосом, что делать дальше
- На экране непонятная ошибка: покажите экран, и он сам посмотрит и посоветует
- Длинную переписку из многих реплик можно проговорить вслух за один заход

### Qwen Code умеет работать в ваших авторизованных страницах

Qwen Code берётся за дело в том самом Chrome, которым вы пользуетесь ежедневно: открытые вами вкладки, аккаунты, в которые вы вошли, — всё в его распоряжении. Он переключает страницы, заполняет формы, отправляет — и оставляет итоговую страницу вам. Скажите прямо: «Прочитай отчёт, который у меня открыт, и сведи заказы за сегодня». Подробнее: PR [#11242](https://github.com/QwenLM/qwen-code/pull/11242)

Перед использованием установите [расширение Qwen Code](https://chromewebstore.google.com/detail/qwen-code/hdhmmjclhibojdddmancfgbkleahfaph) из Chrome Web Store — дальше просто опишите задачу в диалоге. Доступно на Mac и Linux; на Windows пока нет. Подробнее: PR [#12510](https://github.com/QwenLM/qwen-code/pull/12510)

Всё это выполняется в фоне: Chrome не выходит на передний план, компьютер остаётся у вас; несколько сессий могут работать с ним одновременно — у каждой своя группа вкладок, они не мешают друг другу. Подробнее: PR [#12229](https://github.com/QwenLM/qwen-code/pull/12229)

Что это даёт:

- Пусть прочитает авторизованную админ-панель и выпишет данные за сегодня для сверки с вашей таблицей
- Заявки на компенсацию и тикеты разбросаны по нескольким страницам: одна фраза — и он заполнит и отправит каждую
- Процесс виден только в браузере (очередь согласований, список задач) — поставьте его на мониторинг, и он отберёт то, что требует обработки

### Письмо ушло — и задача поставлена

Идея приходит, а компьютер с Qwen Code вне досягаемости — дотянуться нечем. Теперь появился Email Channel: достаточно отправить письмо.

Наберите пару строк в любом почтовом приложении телефона — Qwen Code на том компьютере возьмётся за дело и ответит письмом с результатом. Заметили, что что-то не так, — ответьте на то же письмо и добавьте уточнение: он помнит, до чего уже дошёл. Письмо с ошибкой от пользователя или системное оповещение тоже можно переслать прямо в этот ящик — он подхватит.

Для работы сначала настройте для Qwen Code почтовый аккаунт, а затем добавьте ваш собственный адрес в список разрешённых — он реагирует только на ваши письма.

Что это даёт:

- Письмо по дороге на работу — задача выполняется заранее, а к приходу на рабочее место вы видите результат
- Жалоба пользователя пересылается как есть: он прочитает логи из вложения и даст первичную оценку
- Оповещательное письмо ушло — Qwen Code подхватит его раньше вас, разберётся и ответит, в чём причина

Подробнее: PR [#12939](https://github.com/QwenLM/qwen-code/pull/12939)

### /batch-api: пакет однотипных задач — в фон за полцены

Сотни независимых мелких дел: перевести всю директорию документации, из десятков тикетов вытащить по несколько полей, к каждой статье написать аннотацию. Отправлять по одной задаче — ожидание займёт весь диалог, да и деньги уходят быстро.

Напишите, что нужно сделать, после `/batch-api` — сначала он просмотрит несколько примеров и составит план: сколько всего элементов, в какой каталог писать, примерно сколько токенов уйдёт. Сам этот шаг не тарифицируется. Только если вы согласитесь, работа действительно отправится. Дальше пакет выполняется в фоне по цене вдвое ниже тарифа реального времени, обычно за десятки минут или несколько часов результаты ложатся файлами в указанное место — а ваш диалог тем временем работает как обычно.

```text
/batch-api переведи Markdown-документы из docs/zh на английский и запиши в docs/en под теми же именами
```

Он подходит для пакетных задач, которые каждая делается за один заход и не связана с другими; то, что требует нескольких кругов обсуждения, оставляйте в обычном диалоге.

Что это даёт:

- Перевести весь китайский каталог документации на английский: отправить за один раз, собрать через несколько часов
- Из пачки логов и тикетов вытащить нужные поля поштучно — всё одним заходом
- Сотни отзывов пользователей разметить по категориям и меткам — отправить за один раз

Подробнее: PR [#12492](https://github.com/QwenLM/qwen-code/pull/12492)

### Вкладка Trajectory: видно, куда раунд потратил время

Раунд закончился, и он показался долгим — но вы знаете только «долгим»: молчала ли модель половину времени, говорила слишком много или где-то посередине завис вызов инструмента — непонятно.

Вкладка Trajectory в правой панели раскладывает время на три дорожки: Model requests, Tool calls и Subagent requests — по одной на каждую. Аномально длинный участок видно сразу; когда дорожек слишком плотно, отдельный интервал можно растянуть. Подробнее: PR [#12524](https://github.com/QwenLM/qwen-code/pull/12524), [#12557](https://github.com/QwenLM/qwen-code/pull/12557)

Отметьте на оси подозрительный интервал — ниже останутся только события этого времени. Выберите конкретную запись: что она прочитала, что вернула и сколько токенов потрачено, — всё раскроется под ней, и это можно забрать копированием. Подробнее: PR [#12543](https://github.com/QwenLM/qwen-code/pull/12543), [#12971](https://github.com/QwenLM/qwen-code/pull/12971)

На оси есть и режим Real time: он засчитывает и время, пока вы просто ждёте, и даёт две цифры — «сколько прошло» и «сколько реально выполнялось». Сколько времени один раунд забрал у вас — смотреть сюда. Подробнее: PR [#12607](https://github.com/QwenLM/qwen-code/pull/12607)

Завершённые раунды сворачиваются: не нужно листать длинную сессию от начала до конца. Подробнее: PR [#13081](https://github.com/QwenLM/qwen-code/pull/13081)

Что это даёт:

- Кажется, что медленно, — посмотрите на ось и решайте, за что браться: менять модель или разбираться с тем инструментом
- В длинной сессии надо вернуться к отдельному участку: отметьте его и смотрите только его, завершённые раунды сверните
- Подозреваете ошибку в конкретной операции — посмотрите её ввод, вывод и расход токенов на месте

### Channel: один бот различает задачи по префиксам, допуск в личку и в группу настраиваются отдельно, длинные беседы сами обновляются

**Один и тот же бот может принимать задачи по-разному.** Разные префиксы перед сообщением — это разные сессии, каждая со своими требованиями к постановке: с одной стороны просите рецензировать код, с другой — отвечать на вопросы по репозиторию; два потока не смешиваются, и заводить ещё одно соединение не нужно. В группе тоже работает: сначала @боту, потом префикс. Подробнее: PR [#12595](https://github.com/QwenLM/qwen-code/pull/12595)

**Кто может писать боту в личку, а кто командовать им в группе — теперь два независимых условия.** Группу можно открыть полностью, оставив личные сообщения доступными только людям из списка: две стороны не затрагивают друг друга. Подробнее: PR [#12547](https://github.com/QwenLM/qwen-code/pull/12547), [#12475](https://github.com/QwenLM/qwen-code/pull/12475)

**Длинные ветки в группах сами открывают новые.** Если ветка разрастается, наступает момент, когда не проходит уже ни одно сообщение, — и сломана оказывается только эта беседа: одна ветка в DingTalk накопила 8,577 сообщений. Теперь для неё можно задать предел: по достижении открывается новая сессия, и в группу приходит уведомление. Подробнее: PR [#12616](https://github.com/QwenLM/qwen-code/pull/12616)

### Web Shell: перестроенный сайдбар, поиск по истории в длинных сессиях, несколько рабочих копий одного репозитория и другие обновления

**Сайдбар перестроен.** Слева появилась узкая полоса навигации: у Channel, Live и остального теперь собственные вход; номер версии и редко нужные действия убраны в «Ещё». Подробнее: PR [#12943](https://github.com/QwenLM/qwen-code/pull/12943)

**В длинной сессии можно искать по сказанному.** Нужна фраза, которую вы говорили раньше, или вставленный кусок кода: поиск по ключевому слову прыгает прямо к тому сообщению, старые сообщения не надо предварительно прокручивать — что искалось, то находится. Подробнее: PR [#12234](https://github.com/QwenLM/qwen-code/pull/12234)

**«Вопрос между делом» вынесен на виду.** Пока главная задача выполняется, можно вставить мелкий вопрос: пункт есть в меню «+» у поля ввода, откройте — и он подготовлен за вас. Ответ появляется в соседней панели, главная задача не трогается. Подробнее: PR [#12775](https://github.com/QwenLM/qwen-code/pull/12775)

**У одного репозитория может быть несколько рабочих копий одновременно.** Продолжение графа веток из прошлого выпуска: в диалоге Git появилась вкладка Worktree — каждая беседа работает со своей копией, изменения друг друга не касаются; какая копия ведёт беседу и где есть незакоммиченные изменения — видно сразу, переключение одним кликом. Подробнее: PR [#12154](https://github.com/QwenLM/qwen-code/pull/12154), [#11816](https://github.com/QwenLM/qwen-code/pull/11816)

## 📊 Прочие новинки

**Коммит тоже можно отдать ему.** Наберите `/commit`: он посмотрит, какие файлы изменены, составит сообщение коммита в стиле истории репозитория и добавит только те файлы, которые действительно относятся к этому коммиту; файлы с секретами вроде `.env` он отклоняет наотрез. Создаётся только коммит — push остаётся вашим делом. Нужен ограниченный охват — допишите условие: `/commit only stage the parser changes`. Подробнее: PR [#10586](https://github.com/QwenLM/qwen-code/pull/10586)

**Можно посмотреть, что сделала одна реплика.** В Web Shell наведите курсор на отправленное вами сообщение: рядом с кнопкой копирования появляется значок гаечного ключа — это вкладка «Tool calls». Там построчно: какие файлы прочитаны за раунд, какие команды выполнены, что изменено; разворачивается — виден результат и изменения. Прежние раунды тоже доступны. Подробнее: PR [#12466](https://github.com/QwenLM/qwen-code/pull/12466)

**`/advisor` приходит сам, а не по вызову.** После включения рабочая модель сама заглядывает к советнику перед тем как править и перед сдачей результата; мнение возвращается в диалог, и работа продолжается. Поставленные дочерние агенты тоже могут спрашивать. Каждый вопрос стоит дополнительных токенов, и этот диалог уходит на обзор советнику — выбирайте того, кому доверяете. Подробнее: PR [#9636](https://github.com/QwenLM/qwen-code/pull/9636), [#12688](https://github.com/QwenLM/qwen-code/pull/12688)

**Новую модель подключать стало короче.** Размер контекстного окна, лимит вывода, поддержка картинок — теперь всё это определяется автоматически: встроенный каталог моделей обновляется каждый день в фоне и работает даже без сети. Значения, которые вы вписали руками, по-прежнему имеют приоритет. Подробнее: PR [#11959](https://github.com/QwenLM/qwen-code/pull/11959)

**Внешнюю память подключать стало проще.** Пусть помнит через сессии: теперь достаточно дать адрес и ключ — ставить расширение и регистрировать сервис не нужно. Поиск включён по умолчанию; чтобы ещё и записывать во внешнюю память, нужен отдельный переключатель — с ним каждая запись сначала показывается вам. Подробнее: PR [#12891](https://github.com/QwenLM/qwen-code/pull/12891)

**Большую память не обязательно раскрывать целиком.** После включения в контекст подбираются только несколько релевантных файлов под текущий вопрос; полный текст берётся по отдельному запросу. Когда памяти на десятки и сотни файлов, экономия выходит ощутимая. Подробнее: PR [#10183](https://github.com/QwenLM/qwen-code/pull/10183)

**QQ-бот теперь принимает изображения и видео.** Картинки и короткие ролики, посланные ему в группе, он смотрит напрямую — пересказывать их текстом больше не нужно. Подробнее: PR [#12850](https://github.com/QwenLM/qwen-code/pull/12850)

## 👏 Улучшения UX

**Печатать можно сразу, вдвое быстрее.** На чистой машине от набора `qwen` до готовности принимать ввод проходило около 2,5 секунды, из них первые 2 секунды терминал был пуст; теперь ожидание сократилось вдвое, а потребление памяти упало с 575 МБ примерно на 60%. Подробнее: PR [#12622](https://github.com/QwenLM/qwen-code/pull/12622), [#12602](https://github.com/QwenLM/qwen-code/pull/12602), [#12603](https://github.com/QwenLM/qwen-code/pull/12603)

**Панель настроек полностью на китайском.** Если язык интерфейса — китайский, по-китайски теперь пишется всё. Подробнее: PR [#12783](https://github.com/QwenLM/qwen-code/pull/12783)
