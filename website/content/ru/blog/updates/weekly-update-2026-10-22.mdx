На этой неделе Qwen Code выпустил две стабильные версии — v0.25.3 и v0.26.0 — и принял 436 pull-реквестов.

**Результат живёт в интерактивной карточке, где всё правится на месте.** Нужно перебрать несколько чисел и посмотреть, как изменится итог, — меняйте значения прямо в карточке, общий результат пересчитается следом.

**Сохранённые в проекте рабочие процессы работают и из подпапки.** Когда проект разбит на фронтенд, бэкенд и несколько каталогов компонентов, вы сохраняете проверку кода и прогон тестов в корне; зайдите в подпапку и запустите там Qwen Code — эти процессы найдутся и запустятся.

**Одна группа команд `qwen daemon` — и Web Shell под управлением.** Запуск, статус, логи, остановка и перезапуск собраны в этих командах.

## ✨ Новые возможности

### Интерактивные карточки: меняйте значения и сравнивайте варианты на ходу

Иногда нужно поменять несколько чисел и посмотреть, как изменится результат. Теперь Qwen Code делает под такую задачу интерактивную карточку: правите числа или доли — и сразу видите новый итог. Подробнее: PR [#14338](https://github.com/QwenLM/qwen-code/pull/14338)

Допустим, планируете обед с командой — попросите собрать карточку расчёта затрат и впишите число гостей, цену обеда на человека и аренду зала. Сменилось число гостей — правьте его; перешли в другой ресторан — поменяйте цену обеда. Итоговая сумма пересчитывается сама, не нужно каждый раз писать запрос заново.

Функция по умолчанию выключена: включите Generated UI в экспериментальных настройках и перезапустите. Во встроенном виде она пока недоступна в управляемых сессиях, удалённых сессиях и в песочнице. Подробнее: PR [#14888](https://github.com/QwenLM/qwen-code/pull/14888)

Что это даёт:

- сравниваете варианты аренды жилья: плата, время в дороге и стоимость проезда вместе
- подбираете состав команды и разбивку задач, прикидываете срок и стоимость проекта
- сравниваете конфигурации серверов и прикидываете ёмкость и цену при разном трафике

### Рабочие процессы: зашли в подпапку проекта — тот же набор

Проект обычно разделён на фронтенд, бэкенд и несколько каталогов компонентов. Если проверка кода, прогон тестов и другие процессы уже сохранены в корне проекта, теперь Qwen Code найдёт и запустит их, даже когда вы запустили его в подпапке.

Допустим, вы правите страницу в каталоге фронтенда и хотите запустить сохранённую в проекте проверку — процесс лежит в списке рабочих процессов текущей сессии. Поиск идёт вверх по каталогам в пределах одного доверенного Git-репозитория; работает и в локальном терминале, и в обычном Web Shell. Подробнее: PR [#14369](https://github.com/QwenLM/qwen-code/pull/14369), [#14646](https://github.com/QwenLM/qwen-code/pull/14646)

Что это даёт:

- единая проверка кода во всех каталогах компонентов — одна и та же
- поправили бэкенд — прогоните сохранённый в репозитории тестовый процесс
- пишете документацию — берите процесс проверки документов из каталога выше

### qwen daemon: управление Web Shell одной группой команд

На прошлой неделе Web Shell научился подключать несколько Qwen Code на одной странице. На этой неделе добавили управление этими локальными сервисами.

Запуск Web Shell, проверка статуса, перезапуск и прочие действия собраны в командах `qwen daemon`:

Команда `qwen daemon start` поднимает сервис в фоне и возвращает адрес; `qwen daemon status` показывает запущенные сервисы, `qwen daemon logs` — логи, `qwen daemon stop` останавливает нужный. Подробнее: PR [#14739](https://github.com/QwenLM/qwen-code/pull/14739), [#14869](https://github.com/QwenLM/qwen-code/pull/14869)

При разборе неполадок `qwen daemon status --detail` дополнительно показывает версию, время работы, число сессий и число проблем. Если в скрипте нужно поднять сервис и сразу подключиться, берите `qwen daemon start --wait` — команда ждёт готовности окружения. Подробнее: PR [#14902](https://github.com/QwenLM/qwen-code/pull/14902), [#14914](https://github.com/QwenLM/qwen-code/pull/14914)

`qwen daemon restart --port <порт>` перезапускает указанный локальный HTTP-сервис и восстанавливает записанные стартовую рабочую область и настройки Web Shell. Подробнее: PR [#14929](https://github.com/QwenLM/qwen-code/pull/14929)

Что это даёт:

- подняли локальный сервис — и продолжаете работать в том же терминале
- видите статус нескольких локальных сервисов и находите тот, что нужно править
- перезапускаете сервис ровно с той конфигурацией, с которой он стартовал

### Web Shell: файлы и история исполнения стали разборчивее

**PDF и Word открываются прямо в интерфейсе.** Заходите в файл через ссылку `@`, через панель Files справа или через карточку артефакта: PDF открывается штатным просмотрщиком браузера, Word предпросматривается во всех этих же входах. Подробнее: PR [#14825](https://github.com/QwenLM/qwen-code/pull/14825), [#14868](https://github.com/QwenLM/qwen-code/pull/14868)

**Файлы справа можно создавать и удалять.** Нажмите имя каталога рядом с заголовком чата — справа раскроется дерево файлов рабочей области. Там создаются файлы и папки. Удаление файла требует подтверждения, удаление папки — двух: её содержимое уйдёт вместе с ней. Подробнее: PR [#14344](https://github.com/QwenLM/qwen-code/pull/14344), [#14169](https://github.com/QwenLM/qwen-code/pull/14169), [#14158](https://github.com/QwenLM/qwen-code/pull/14158)

**Вкладка Trajectory умеет вставать на паузу.** Листаете прежние записи — она остановилась на тех строках, что вы читаете. Хотите снова видеть актуальное — нажмите «К последним». Клик по любой строке открывает детали этой записи. Подробнее: PR [#14723](https://github.com/QwenLM/qwen-code/pull/14723), [#14984](https://github.com/QwenLM/qwen-code/pull/14984)

**Прочие улучшения.** В диалоге можно удалить реплику вместе с ответом на неё, а можно выбрать несколько реплик ([#14297](https://github.com/QwenLM/qwen-code/pull/14297)); то, что он делает сейчас и сделал только что, вместе с длительностью каждого шага собрано в сворачиваемый блок «Последние выполнения» ([#14071](https://github.com/QwenLM/qwen-code/pull/14071)); на панели «Расход токенов сессии» в обзоре остались вход, вывод и кэш, ниже видно отдельно по моделям, основному агенту и субагентам; наведите курсор на значок Info у имени модели — увидите, сколько ждался первый символ и сколько токенов в секунду выдаёт модель ([#14728](https://github.com/QwenLM/qwen-code/pull/14728), [#14648](https://github.com/QwenLM/qwen-code/pull/14648)).

## 📊 Прочие новинки

**На первом экране `/auth` появились «千问AI平台 / QwenCloud».** «千问AI平台» — вход для Китая, QwenCloud — для остального мира. Провайдеры с этих платформ теперь выбираются прямо на первом экране `/auth`; ключ оплаты по факту и подписочный ключ идут отдельными дорожками. Подробнее: PR [#14073](https://github.com/QwenLM/qwen-code/pull/14073)

**Кто поднял собственный сервис Managed Agent, удобнее управляет проектами и задачами.** Такие сессии стоят рядом с вашими локальными прямо на главной странице Web Shell — то же поле ввода, те же карточки одобрения. В этом выпуске можно выбрать уже существующий каталог проекта, при создании сессии подхватить включённые навыки, менять права исполнения на ходу и переименовывать сессию вручную; обычная управляемая сессия тоже может работать в том же каталоге проекта, файлы у них общие. Нужно, чтобы деплой это поддерживал. Подробнее: PR [#14316](https://github.com/QwenLM/qwen-code/pull/14316), [#14970](https://github.com/QwenLM/qwen-code/pull/14970), [#14930](https://github.com/QwenLM/qwen-code/pull/14930), [#14920](https://github.com/QwenLM/qwen-code/pull/14920), [#14987](https://github.com/QwenLM/qwen-code/pull/14987), [#15026](https://github.com/QwenLM/qwen-code/pull/15026)

**QQ-бот принимает файлы.** В личной переписке или через @ в группе отправьте ему Word, PDF или таблицу — он сохранит файл и разберётся с ним. Подробнее: PR [#14343](https://github.com/QwenLM/qwen-code/pull/14343)

**Собственные приложения WeCom подключаются.** Коллега пишет задачу во внутреннем приложении вашей организации, Qwen Code получает её и выполняет, а ответ отправляет от имени этого же приложения. Подробнее: PR [#13976](https://github.com/QwenLM/qwen-code/pull/13976)

**Команды из плагинов в формате Claude работают и в терминале.** На прошлой неделе они действовали только в однократном прогоне, теперь их можно набирать прямо в терминале — без обращения к модели. Слой, в котором плагин вмешивается до вызова инструмента, открыт и в интерактивной сессии: он переписывает этот вызов или отменяет его. По умолчанию выключено; переключатель Mods в настройках, после изменения нужен перезапуск. Подробнее: PR [#14268](https://github.com/QwenLM/qwen-code/pull/14268), [#14565](https://github.com/QwenLM/qwen-code/pull/14565), [#14889](https://github.com/QwenLM/qwen-code/pull/14889)

**У фоновой команды видно, до чего она уже вывела.** В деталях задачи есть хвост вывода, его объём и время последней записи, плюс занятая память, время начала и окончания; содержимое копируется одним нажатием. Подробнее: PR [#14831](https://github.com/QwenLM/qwen-code/pull/14831)

## 👏 Улучшения UX

**Свёрнутое на главной странице показывается по наведению курсора.** Подробнее: PR [#14826](https://github.com/QwenLM/qwen-code/pull/14826)

**Сортировка, фильтры и копирование в таблицах стали удобнее.** Расширенные элементы для широких таблиц и копирование отполировали в этом же заходе. Подробнее: PR [#14707](https://github.com/QwenLM/qwen-code/pull/14707)

**Когда Qwen Code зацикливается, его подталкивают, а не обрывают раунд.** После определённого числа одинаковых действий — одного и того же запуска команды или чтения файла — по умолчанию ему приходит напоминание сменить подход и продолжать. Автоматическую остановку можно выбрать в настройках. Подробнее: PR [#15016](https://github.com/QwenLM/qwen-code/pull/15016)

**В поле ввода на телефоне убрали две стрелки.** Стрелки над полем, листавшие историю ввода, убраны; поиск по истории остался на прежнем месте. Подробнее: PR [#14220](https://github.com/QwenLM/qwen-code/pull/14220)

**Значок во вкладке браузера виден на тёмной вкладке.** Раньше на тёмном фоне он почти сливался. Подробнее: PR [#14417](https://github.com/QwenLM/qwen-code/pull/14417)

**Список моделей обновляется прямо в селекторе.** Нажатие на селектор модели подтягивает свежий список; кнопка обновления — маленький значок рядом с поиском. Подробнее: PR [#14685](https://github.com/QwenLM/qwen-code/pull/14685), [#14983](https://github.com/QwenLM/qwen-code/pull/14983)

**`Ctrl+V` в Linux-терминале вставляет текст.** Если в буфере текст или ссылка, он попадает прямо в поле ввода; картинки по-прежнему проходят как вложение. Подробнее: PR [#14172](https://github.com/QwenLM/qwen-code/pull/14172)
