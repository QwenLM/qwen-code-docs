На этой неделе Qwen Code выпустил три стабильные версии — с v0.21.12 по v0.21.14, принято более 140 PR.

**Независимое второе мнение.** `/advisor` проводит независимое ревью текущего диалога и возвращает четыре пункта: выводы, риски, недостающие доказательства и рекомендации. Только чтение — основной диалог не затрагивается.

**Одна команда — и видно все работающие сессии.** Новая команда `qwen sessions ps` показывает, какие сессии выполняются на машине: в каком каталоге, сколько времени работает, номер процесса.

**Прерванное Review не начинается заново.** Прерванное ревью PR возобновляется с `--resume`: если состояние совпадает, работа продолжается с места остановки.

## ✨ Новые возможности

### /advisor: независимая модель проверяет текущий диалог

В длинном диалоге легко застрять в одной линии рассуждений и не заметить слепых зон собственного контекста. `/advisor` даёт независимое второе мнение: отдельная сессия только для чтения проходит по всему контексту и возвращает четыре пункта — выводы, риски, недостающие доказательства, рекомендации. Второе мнение строго только чтение: оно не меняет основной диалог и ничего не выполняет — после ревью диалог продолжается как раньше.

Можно задать конкретный фокус, например `/advisor безопасно ли это решение?`; настройка `advisorModel` указывает отдельную модель для ревью — если не задана, используется текущая.

Подробнее в PR [#7567](https://github.com/QwenLM/qwen-code/pull/7567)

![Четыре пункта ревью от /advisor](https://img.alicdn.com/imgextra/i4/O1CN01x6UkJeTG4kD7nOLI_!!6000000004249-2-tps-3840-2160.png)

### qwen sessions ps: одна команда показывает все сессии на машине

Когда открыто несколько сессий Qwen Code, легко перепутать, где какая. Новая команда `qwen sessions ps` выводит все интерактивные сессии, работающие на машине, по одной на строку: имя сессии, номер процесса, время работы, каталог. Для скриптов добавьте `--json` — вывод в JSON.

В списке только то, что действительно работает: закрыли сессию — она сразу исчезает из списка.

Подробнее в PR [#8969](https://github.com/QwenLM/qwen-code/pull/8969)

![qwen sessions ps выводит работающие сессии](https://img.alicdn.com/imgextra/i1/O1CN01edM2ef0oKxI7nOLI_!!6000000005536-2-tps-3840-2160.png)

### Review: прерванное ревью PR можно продолжить, комментарии — простым языком

У `/review` на этой неделе несколько практичных улучшений.

**Прерванное ревью продолжается с места остановки.** Раньше, если ревью большого PR обрывалось на середине, приходилось начинать заново. Теперь у `qwen review fetch-pr` появился `--resume`: команда сверяет состояние на диске — прежний отчёт ревью, worktree и содержимое diff не изменились, PR не обновлялся — и если всё совпадает, продолжает работу; любое несовпадение — автоматически начинает заново.

**Комментарии ревью переписаны простым языком.** Когда `/review` проверяет PR и публикует комментарии, раньше они были шаблонными. Теперь это естественный язык ревью: где проблема, когда она проявится и как её исправить. Для комментариев, публикуемых в PR, в настройках меняется: ставить ли метки серьёзности и подпись, насколько глубоко проверять и публиковать ли вообще.

**Ревью скриптов учитывает окружение исполнения.** Для shell-скриптов и конфигов CI типична проблема «на этой машине работает, в другом окружении падает» — и её трудно заметить. Теперь ревью сначала определяет, в каких окружениях эти файлы реально выполняются, и проверяет с учётом их особенностей.

Подробнее в PR [#9092](https://github.com/QwenLM/qwen-code/pull/9092), [#9027](https://github.com/QwenLM/qwen-code/pull/9027), [#8994](https://github.com/QwenLM/qwen-code/pull/8994), [#9263](https://github.com/QwenLM/qwen-code/pull/9263)

### Передача файлов в Web Shell: перетащите локальный файл прямо в диалог

Настройте Token удалённого подключения (`QWEN_SERVER_TOKEN` или `--token`) — и файлы можно перетаскивать в поле ввода Web Shell или вставлять из буфера: файл уходит в Qwen Code. Любой файл попадает в workspace, а в диалоге автоматически появляется ссылка — AI сразу может его использовать. Для текстовых файлов содержимое можно приложить прямо к диалогу — AI читает его, не открывая файл.

Можно указать папку, куда попадают загрузки; если папки нет, она создаётся автоматически. Без настроенного Token перетаскивание и вставка файлов в диалог пока не работают.

Подробнее в PR [#8874](https://github.com/QwenLM/qwen-code/pull/8874), [#9180](https://github.com/QwenLM/qwen-code/pull/9180), [#9382](https://github.com/QwenLM/qwen-code/pull/9382)

## 📊 Больше новых возможностей

**Agent в workflow привязывается к нужному каталогу.** В workflow вызов `agent({workingDir})` закрепляет agent за указанным каталогом — без ограничений диапазоном каталогов по умолчанию. Подробнее в PR [#8972](https://github.com/QwenLM/qwen-code/pull/8972)

**У Release notes появились двуязычные аннотации.** Release notes больше не выглядят как простой список PR: записи сгруппированы по темам функций, у каждой группы — короткая аннотация простым языком, добавлена версия на китайском; скриншоты «до/после» из PR тоже переносятся. Подробнее в PR [#9216](https://github.com/QwenLM/qwen-code/pull/9216)

**Единый стандарт подключения внешних баз знаний.** Разработчики поисковых сервисов могут по стандарту написать плагин для Qwen Code — после установки AI сможет искать по их данным. Что доступно для поиска, определяют установленные вами плагины; AI ищет только в этих пределах. Подробнее в PR [#9068](https://github.com/QwenLM/qwen-code/pull/9068)

## 👏 Улучшения опыта

**Управление Channel — теперь полноценная страница.** Управление Channel в Web Shell переделано в целую страницу, как у задач по расписанию: кому доступен каждый канал, одобрение или белый список, как разделяются сессии, к какому workspace привязан — всё настраивается на одной странице. Подробнее в PR [#8848](https://github.com/QwenLM/qwen-code/pull/8848)

**Индикатор «печатает…» в WeChat не гаснет на длинных задачах.** Статус «печатает…» в WeChat со временем истекает — раньше во время длинной задачи индикатор исчезал, и казалось, что связь оборвалась. Теперь он обновляется каждые 4 секунды до самого завершения. Подробнее в PR [#9358](https://github.com/QwenLM/qwen-code/pull/9358)

**В компактном режиме видно, как AI думает.** Компактный режим Web Shell (Ctrl+O) раньше полностью скрывал размышления. Теперь, пока модель думает, в сводке показывается «Размышление…», а после завершения размышления сворачиваются в сводку инструментов — их можно раскрыть и прочитать. Подробнее в PR [#9148](https://github.com/QwenLM/qwen-code/pull/9148)

**Переключение сессий даже со свёрнутой боковой панелью.** Когда боковая панель Web Shell свёрнута, наведение на иконку проекта открывает полный браузер сессий; состояния — ожидает одобрения, вопрос, ожидает завершения — отмечаются цветом на иконке. Подробнее в PR [#9311](https://github.com/QwenLM/qwen-code/pull/9311)

**Предпросмотр изображений не теряется после обновления страницы.** Изображения, отправленные в Web Shell, — в очереди они или уже добавлены в задачу — сохраняют предпросмотр после обновления страницы; несколько изображений не склеиваются и не теряются. Подробнее в PR [#9310](https://github.com/QwenLM/qwen-code/pull/9310)

**Вопросы отправляются даже при обрыве связи.** Поле ввода Web Shell отвязано от состояния подключения: даже если поток оборвался, вопрос можно отправить — поле больше не блокируется. Подробнее в PR [#9323](https://github.com/QwenLM/qwen-code/pull/9323)

**Экспортированный HTML разворачивается и сворачивается одной кнопкой.** Вверху HTML-страницы, экспортированной через `/export`, появились две кнопки — «Развернуть всё / Свернуть всё»: блоки размышлений и вывод инструментов переключаются одним нажатием. Подробнее в PR [#9367](https://github.com/QwenLM/qwen-code/pull/9367)

**Большие сессии восстанавливаются быстрее.** daemon восстанавливает сессии по требованию: читаются только записи, нужные для восстановления состояния; на больших сессиях прирост заметен. Подробнее в PR [#9055](https://github.com/QwenLM/qwen-code/pull/9055)

**Фоновые shell больше не удаляются по ошибке.** shell, работающие в фоне, теперь считаются активными задачами — во время активности они не очищаются автоматически. Подробнее в PR [#9042](https://github.com/QwenLM/qwen-code/pull/9042)
