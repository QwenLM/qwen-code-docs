В статье [Быстрый старт](/ru/blog/quickstart/getting-started) Qwen Code работал прямо в терминале. Здесь — два других интерфейса: **десктопное приложение** и **Web Shell в браузере**.

## Разница между двумя способами

| Что нужно | Что выбрать |
| --- | --- |
| Запускать одним кликом по иконке приложения | Десктоп |
| Установить CLI, ввести команду запуска и работать в браузере | Web Shell |

Возможности у них одинаковые, интерфейс — тоже. Web Shell легче; для десктопа нужен установщик.

## Десктопное приложение

Скачайте установщик для своей платформы на странице [последней версии Qwen Code Desktop](https://github.com/QwenLM/qwen-code/releases/tag/desktop-latest) — есть macOS, Windows и Linux. Установили, открыли — и можно сразу вести диалог. Новые версии скачиваются и ставятся сами.

![Десктопное приложение Qwen Code](https://img.alicdn.com/imgextra/i3/O1CN01qgbh0E6t5mD7o1Mj_!!6000000007102-2-tps-3845-2160.png)

## Сервис Web Shell

Перейдите в каталог проекта, где должен работать Qwen Code:

```bash
cd your-project
qwen serve --open
```

Браузер сам откроет `http://127.0.0.1:4170/`.

Слева — список сессий и добавленные проекты, в центре — диалог, справа — файлы проекта и внесённые в них изменения.

Хотите добавить ещё проекты — новый сервис не поднимайте: нажмите **«Add workspace»** в боковой панели. Каждый проект остаётся в своём каталоге — переключаетесь на нужный и сразу с ним работаете.

Если привычнее команды, при запуске можно указать сразу несколько каталогов:

```bash
qwen serve --workspace ~/code/site --workspace ~/code/api
```

Web Shell можно установить и как приложение на компьютере: справа у адресной строки браузера появится значок установки. Нажмите его — у Web Shell будут своя иконка и отдельное окно, а подключаться он станет к тому же запущенному сервису.

Один интерфейс подключается сразу к нескольким Qwen Code на разных машинах.

![Web Shell Qwen Code](https://img.alicdn.com/imgextra/i1/O1CN01Pv6PASJbbDD7o1Mj_!!6000000003585-2-tps-3845-2160.png)

## Команды управления сервисом

`qwen serve` занимает окно терминала: закрыли окно — сервис остановился. Чтобы он работал в фоне, есть своя группа команд:

```bash
qwen daemon start      # поднять сервис в фоне и получить адрес доступа
qwen daemon status     # посмотреть, сколько сервисов работает на этой машине
qwen daemon logs       # посмотреть логи
qwen daemon stop       # остановить нужный сервис
```

Логика как с сервисом печати: на компьютере он запущен постоянно, и печать отзывается в любой момент. Закроете вкладку — задача продолжит работать.

![qwen daemon start поднимает сервис в фоне, а status во втором терминале показывает его состояние](https://img.alicdn.com/imgextra/i4/O1CN015EshdwuaPaE7nW9B_!!6000000003381-2-tps-3841-2160.png)
