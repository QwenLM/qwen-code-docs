## Установка Qwen Code

Qwen Code поддерживает установку одним скриптом — Windows, macOS и Linux.

**macOS / Linux:**

```bash
bash -c "$(curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh)" -s --source website
```

**Windows (PowerShell):**

```powershell
curl -fsSL -o %TEMP%\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\install-qwen.bat --source website
```

После установки выполните `qwen --version`, чтобы убедиться, что установка прошла успешно. Если предпочитаете установить через npm:

```bash
npm i @qwen-code/qwen-code@latest -g
```

## Настройка провайдера моделей

После установки Qwen Code поможет вам подключить провайдера моделей. Рекомендуется использовать платформу Alibaba Cloud Bailian.

1. Перейдите в [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api-key) для получения API Key
2. Запустите `qwen` в терминале, выберите Alibaba ModelStudio
3. Вставьте ваш API Key, выберите модель

Если предпочитаете ручную настройку, отредактируйте `~/.qwen/settings.json`:

```json
{
  "modelProviders": {
    "openai": [
      {
        "id": "qwen3.5-plus",
        "name": "[Bailian] qwen3.5-plus",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "envKey": "BAILIAN_API_KEY"
      }
    ]
  },
  "env": {
    "BAILIAN_API_KEY": "ваш-API-KEY"
  }
}
```

После настройки используйте команду `/model` для просмотра и переключения моделей:

## Начало первого диалога

Перейдите в директорию вашего проекта и запустите Qwen Code:

```bash
cd your-project && qwen
```

Просто опишите на естественном языке, что вы хотите сделать. Например:

```
Напиши функцию на Python для вычисления последовательности Фибоначчи
```

Или попросите AI организовать файлы:

```
Разложи файлы в этой папке по типам в разные директории
```

Qwen Code автоматически разобьёт задачу, выполнит операции и вернёт результат. Не нужно обучать его шаг за шагом — просто опишите цель.

## Установка расширений Skills

Skills — это система расширения возможностей Qwen Code. Вы можете устанавливать Skills, разработанные сообществом, чтобы дать AI больше профессиональных навыков.

Установить Skill просто — одной командой:

```
Установи find-skills
```

Или напрямую командой:

```bash
/skills find-skills install web-component-design -y -a qwen-code
```

После установки используйте `/skills` для просмотра установленных Skills.
