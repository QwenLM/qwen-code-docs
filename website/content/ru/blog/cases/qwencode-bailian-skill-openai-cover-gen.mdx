Сдержанно и стильно — идеально для технического блога.

## Создание Skill: Qwen Code + Bailian CLI

Вся схема держится на двух вещах.

**Qwen Code оркестрирует процесс.** Я просто даю Qwen Code скриншот сайта и говорю, что хочу сделать Skill для генерации таких обложек. Хотя qwen3.8-max не обладает мультимодальными способностями, **Qwen Code сам вызывает настроенную мной визуальную модель** — например, qwen3.6-plus — которая распознаёт содержимое и передаёт описание qwen 3.8-max. Дальше 3.8 анализирует и реализует — очень удобно. Qwen Code разбирает содержимое скриншота, определяет категорию контента (я тоже кое-что подготовила вручную), а 3.8-max собирает prompt.

![](https://gw.alicdn.com/imgextra/i4/O1CN01eeOy4R1jz6BcBI7mI_!!6000000004618-2-tps-2808-1486.png)

**Bailian CLI генерирует изображение в нужном стиле на модели qwen-image**, а затем фоновая картинка и заголовок собираются в интерактивную HTML-страницу. Можно открыть страницу и подкрутить: заголовок, шрифт, логотип, резкость — и экспортировать.

В итоге оба процесса собраны в стабильно работающий Skill.

## Генерация обложек: четыре стиля

Стили — та часть, над которой я больше всего думала. Обложки OpenAI выглядят просто, но при ближайшем рассмотрении там несколько направлений. Я разделила их на четыре типа:

**Предметный**. Макросъёмка текстур. Дерево, кожа, прожилки листьев, шлифованный металл, дюны, фасеточные глаза. Заполнение на весь кадр, без пустого пространства. Подходит для статей о продуктах, ремёслах, качестве.

**Акварель**. Однотонный градиент. От светлого к тёмному, переходы в пределах одного оттенка. Ощущение шёлка, матовости, ряби на воде. Для креатива, искусства, эмоционального контента.

**Луч света**. Один луч света или изогнутый блик. Фон — тот же цвет, темнее или светлее. Сдержанно, точно. Для технологического контента — самое то.

**Волна**. Мягкие акварельные волны. Сделано для подкастов и диалогов. Амплитуда сходится к центру кадра, оставляя тихую зону для заголовка.

Четыре стиля, семь цветовых схем (синий, зелёный, красный, фиолетовый, оранжевый, чёрный, золотой) и четыре формата холста. Комбинаций много. Но каждый стиль держится одного принципа: цветов немного, визуально чисто, без агрессии. Дизайн OpenAI хорош именно сдержанностью. Я не хотела это ломать.

## Как пользоваться?

Скажите Qwen Code: «Сгенерируй обложку для @статьи».

Он читает вашу статью и рекомендует 1–3 стиля. Выбираете — можно несколько. Для каждого стиля генерируется фоновая картинка, потом на странице переключаете и сравниваете. Цветовая схема — из пресетов, без самодеятельности. Хотя можно и указать напрямую.

Bailian CLI прогоняет два варианта. Не нравится — подкручиваете prompt и перезапускаете. Картинка готова — одна команда собирает HTML. Открываете — и перед вами редактор:

- Кликните по заголовку на холсте — правьте текст
- Пять шрифтов на выбор: PingFang, Songti, Heiti, Noto Serif, Zanku
- Маска, размер шрифта — ползунками
- Цвет текста: белый, чёрный, кремовый
- Загрузите логотип (по желанию, если нужна картинка в высоком разрешении)
- Экспорт: 1x, @2x, @3x, или ⌘Enter

Несколько ключевых решений, которые я приняла:

**Фон без текста.** AI при генерации изображений пишет китайские иероглифы кракозябрами. Поэтому картинка — отдельно, текст накладывается через HTML. Это фундамент всей схемы.

**Размер генерации жёстко привязан к формату холста.** Обложка для WeChat — 900×383, соотношение 2.35:1, значит генерируем 1344×572. Если пропорции не совпадают, при экспорте кадрирование ломает композицию.

**Волна может быть многоцветной, но только мягкой.** Остальные три стиля — строго однотонные. Волна допускает 2–3 соседних оттенка, низкая насыщенность, как растёкшаяся акварель. Насыщенные контрастные цвета — нет.

**Prompt только на английском.** Китайские prompt дают нестабильное качество. Все шаблоны написаны на английском.

**Не только для WeChat.** Холст по умолчанию — обложка WeChat. Но есть пресеты: квадрат 1080×1080, горизонтальный 16:9, вертикальный 3:4. Можно и свой размер. Одна статья — обложка для WeChat, для Xiaohongshu, для видео — всё за один прогон.

Как установить Skill? Просто скажите вашему AI Agent:

```
Склонируй репозиторий https://github.com/joeytoday/open1v-skills, скопируй директорию open1v-openai-cover в ~/.agents/skills/, убедись, что SKILL.md на месте, и удали клонированный репозиторий.
```

Обложка теперь — не двадцать минут листания картинок, а одна фраза и две минуты ожидания, плюс выбор из нескольких стилей. Если пишете технические блоги — попробуйте.
