Блог Qwen Code организован в четыре раздела по пути обучения. Начните с раздела «Начало работы», чтобы изучить основные концепции и быструю настройку, затем изучите «Примеры использования» для реальных сценариев, перейдите к «Продвинутый» для расширенных функций и, наконец, отслеживайте еженедельные итерации продукта в разделе «Обновления».

## Разделы

### [Начало работы](/ru/blog/quickstart)

Изучите основные концепции Qwen Code и быстро начните программировать с ИИ.

### [Примеры использования](/ru/blog/cases)

Реальные сценарии и руководства: от автоматизации офиса до разработки кода.

### [Продвинутый](/ru/blog/advanced)

Расширенные руководства по Skills, Bailian CLI, генерации обложек WeChat и другому.

### [Обновления](/ru/blog/updates)

Еженедельные релизы, новые функции и новости сообщества.
