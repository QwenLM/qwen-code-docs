UsersConfigurationIgnoring Files

파일 무시

이 문서는 Qwen Code의 Qwen Ignore(.qwenignore) 기능에 대한 개요를 제공합니다. Qwen Code는 context.fileFiltering.customIgnoreFiles로 구성된 사용자 정의 무시 파일도 인식하며, 기본값은 호환 파일인 .agentignore 및 .aiignore입니다.

Qwen Code는 .gitignore(Git에서 사용)와 유사하게 파일을 자동으로 무시하는 기능을 포함합니다. .qwenignore 또는 구성된 사용자 정의 무시 파일에 경로를 추가하면 이 기능을 지원하는 도구에서 제외되지만, Git과 같은 다른 서비스에는 여전히 표시됩니다.

작동 방식

이러한 무시 파일 중 하나에 경로를 추가하면 Qwen 무시 규칙을 존중하는 도구는 일치하는 파일과 디렉토리를 작업에서 제외합니다. 예를 들어, read_many_files 명령을 사용할 때 .qwenignore 또는 구성된 사용자 정의 무시 파일의 경로는 자동으로 제외됩니다.

대부분의 경우 이러한 무시 파일은 .gitignore 파일의 규칙을 따릅니다:

  • 빈 줄과 #으로 시작하는 줄은 무시됩니다.
  • 표준 glob 패턴이 지원됩니다(*, ? 및 [] 등).
  • 끝에 /를 넣으면 디렉토리만 일치합니다.
  • 처음에 /를 넣으면 무시 파일을 기준으로 경로가 고정됩니다.
  • !는 패턴을 반전합니다.

이러한 무시 파일은 언제든지 업데이트할 수 있습니다. 변경 사항을 적용하려면 Qwen Code 세션을 다시 시작해야 합니다.

무시 파일 사용 방법

단계설명
무시 규칙 활성화프로젝트 루트 디렉토리에 .qwenignore, 기본 사용자 정의 파일(.agentignore / .aiignore) 또는 구성된 사용자 정의 무시 파일을 생성
무시 규칙 추가무시 파일을 열고 무시할 경로를 추가합니다. 예: /archive/ 또는 apikeys.txt

기본적으로 Qwen Code는 .qwenignore, .agentignore 및 .aiignore를 읽습니다. 다른 사용자 정의 무시 파일을 사용하려면 다음을 구성하세요:

{
  "context": {
    "fileFiltering": {
      "customIgnoreFiles": [".cursorignore"]
    }
  }
}

.qwenignore는 context.fileFiltering.respectQwenIgnore가 활성화된 경우 항상 포함됩니다. 사용자 정의 무시 파일 경로는 프로젝트 루트를 기준으로 합니다.

무시 파일 예시

지원되는 무시 파일을 사용하여 디렉토리와 파일을 무시할 수 있습니다:

# /packages/ 디렉토리와 모든 하위 디렉토리 제외
/packages/

# apikeys.txt 파일 제외
apikeys.txt

무시 파일에서 *와 함께 와일드카드를 사용할 수 있습니다:

# 모든 .md 파일 제외
*.md

마지막으로 !를 사용하여 제외에서 파일과 디렉토리를 제외할 수 있습니다:

# README.md를 제외한 모든 .md 파일 제외
*.md
!README.md

무시 파일에서 경로를 제거하려면 해당 줄을 삭제하세요.
