설정 참조

개요

이 페이지는 qwen serve daemon과 adapter에 영향을 미치는 모든 설정을 수집합니다: 환경 변수, CLI 플래그, settings.json 키, 프로그래밍 옵션. 기능별 페이지는 교차 설정 정보가 필요할 때 여기로 링크합니다.

CLI 플래그 (qwen serve)

플래그타입기본값효과
--hostname <host>string127.0.0.1바인드 주소. 루프백 값: 127.0.0.1, localhost, ::1, [::1]. 루프백이 아닌 값은 부팅 시 bearer 토큰 필요. host:port 입력은 --port 사용을 안내하며 거부.
--port <n>number4170수신 포트. 0은 임시 포트를 의미.
--token <s>stringenvBearer 토큰. QWEN_SERVER_TOKEN을 오버라이드하며 부팅 시 트리밍됩니다. 프로세스 명령줄에 표시되므로, 배포에서는 env를 권장.
--openbooleanfalse런타임 준비 후 마운트된 Web Shell을 엽니다. 설정된 토큰은 URL 프래그먼트로 전달됩니다. 브라우저 실행 대상이 아닌 경우 순수 --open은 조용한 no-op입니다.
--open-with-authbooleanfalse루프백에서 베어러 인증과 함께 Web Shell을 엽니다. 활성화된 Web Shell과 빌드된 애셋이 필요합니다. 선택된 --token / QWEN_SERVER_TOKEN을 재사용하거나, listen 전에 프로세스 수명의 256비트 베어러를 생성합니다. 브라우저 대상이 아닌 환경에서는 시작하고 비밀 포함 프래그먼트 URL을 출력합니다. ServeOptions 또는 SDK 설정이 아닙니다.
--require-authbooleanfalseBearer 인증을 루프백과 /health로 확장. 토큰 없이는 부팅 거부.
--workspace <dir>절대 경로 / 반복 가능process.cwd()시작 워크스페이스 런타임. 반복하면 추가 격리 런타임 등록. 첫 번째가 primary. 모든 값은 절대 경로이고 디렉토리여야 하며, 부팅 시 표준화.
--memory-project-scope <mode>git-root / workspaceworkspace프로젝트 메모리 분할. workspace는 정확한 워크스페이스 디렉토리별로 격리. git-root는 동일한 Git 루트의 워크스페이스가 공유하는 레거시 호환 스코프. QWEN_CODE_MEMORY_PROJECT_SCOPE 오버라이드.
--max-sessions <n>number32워크스페이스당 활성 세션 상한. 0 / Infinity는 무제한. NaN / 음수 값은 예외 발생.
--max-total-sessions <n>number여러 시작/복원 워크스페이스에 대해 파생Daemon 전체 활성 세션 상한. 생략 시 워크스페이스당 상한과 시작/복원 워크스페이스 수에서 유한 기본값이 한 번 파생. 0 / Infinity는 무제한.
--max-pending-prompts-per-session <n>number5세션당 수락되었지만 대기 중/실행 중인 프롬프트 상한. 초과 시 503 반환. 0 / Infinity는 무제한. 음수 또는 비정수 값은 예외 발생.
--max-connections <n>number256HTTP 리스너 server.maxConnections. 0 / Infinity는 무제한.
--enable-session-shellbooleanfalse직접 POST /session/:id/shell 실행 활성화. Bearer 토큰 필요하며, 모든 호출은 세션 바인딩된 X-Qwen-Client-Id를 포함해야.
--event-ring-size <n>number8000세션당 SSE 리플레이 링. 소프트 상한은 1_000_000.
--compacted-replay-max-bytes <n>양의 정수4194304POST /session/:id/load가 반환하는 경계된 인메모리 리플레이 스냅샷의 바이트 상한. 하드 상한은 268435456.
--max-journal-events <n>양의 안전 정수10000미완료 턴에 대한 인플라이트 liveJournal 리플레이 엔트리의 세션당 기본 상한. 적응적 성장으로 상승 가능(--max-journal-bytes 참조). 어느 쪽의 journal 플래그라도 고정하면 성장 비활성화.
--max-journal-bytes <n>양의 안전 정수8388608(8 MiB)인플라이트 liveJournal의 세션당 기본 바이트 상한. 턴이 이를 초과하면 적응적 성장이 세션의 상한을 필요에 따라 상승시키며, 2배까지 가능하지만 남은 풀 헤드룸으로 제한되며 세션당 256 MiB 하드 상한을 초과하지 않음 — 유효 --memory-budget-mb의 5%인 daemon 전체 풀 내(최대 1024 MB로 제한; 유효 예산이 1024 MB 최소값 미만이면 0 — 성장 비활성화), 모든 workspace bridge가 공유; 헤드룸이 없으면 가장 오래된 엔트리가 history_truncated 마커와 함께 삭제. 어느 쪽의 journal 플래그라도 고정하면 성장 비활성화.
--memory-budget-mb <n>[1024, 1048576] 범위의 정수cgroup 제약 또는 호스트 메모리의 50%, 플래그 최대값(1048576 MB)으로 제한Daemon 프로세스 트리의 총 메모리 예산. 해석된 사용 가능 메모리로 제한. Daemon 상태의 limits.memory에서 보고되며, 자식 프로세스 크기를 결정하지 않음 — 현재 유일한 소비자는 적응적 live-journal 성장(--max-journal-bytes 참조). 부팅은 범위를 벗어난 값을 거부.
--memory-pressure-mode <mode>off | observeobserveDaemon이 자체 RSS와 V8 힙에서 메모리 압박 수준을 도출하는지 여부. 두 모드 모두 runtime.memory.pressure를 보고하며, observe만 daemon_memory_pressure를 발생. 루트 프로세스 전용. 조치 없음.
--child-heap-mode <mode>off | observeobserveDaemon이 예산의 자식별 힙 분할을 모델링하는지 여부. observe는 이를 보고하고 이를 초과하는 spawn을 카운트. 적용되는 것 없음. off는 분할을 전혀 공개하지 않음 — maxConcurrentChildren과 perChildCeilingMb 모두 null.
--http-bridgebooleantrueStage 1 브리지 모드. --no-http-bridge도 http-bridge로 폴백하며 stderr에 출력.
--mcp-client-budget <n>양의 정수미설정WorkspaceMcpBudget.clientBudget을 설정하고 childEnvOverrides를 통해 ACP 자식으로 전달.
--mcp-budget-mode <m>off / warn / enforce예산이 설정되면 warn, 그렇지 않으면 offWorkspaceMcpBudget.mode 설정. enforce는 --mcp-client-budget 필요.
--external-tool-guard-mode <m>off / requiredoff관리되는 ACP 외부 사전 실행 Guard 활성화. required는 루프백 프로바이더가 v1 핸드셰이크를 완료하지 않으면 시작 거부.
--external-tool-guard-endpoint <url>루프백 HTTP(S) origin미설정required 모드에서만 사용되는 프로바이더 origin. origin 전용이어야 하며 127.0.0.1, localhost, 또는 ::1 사용. 경로, 자격 증명, 리다이렉트, 프록시 라우팅은 거부.
--external-tool-guard-timeout-ms <n>100..30000 범위의 정수3000핸드셰이크 및 prepare당 데드라인. 타임아웃은 핸드셰이크 중 시작을 실패시키거나, 턴 중에 호출을 차단하고 실패.
--allow-origin <pattern>반복 가능 string미설정기본 CORS 거부를 대체하는 교차 origin 허용 목록. *는 모든 origin을 허용하지만 토큰 필요.
--allow-private-auth-base-urlbooleanfalse/workspace/auth/provider가 localhost / 사설 네트워크 인증 프로바이더 baseUrl을 설치하도록 허용. 신뢰할 수 있는 로컬 개발에서만 사용.
--web / --no-webbooleantrue데몬 루트에서 빌드된 Web Shell SPA를 제공(GET /, /assets/*, /session/:id 문서 내비게이션). 이 진입점은 bearerAuth 이전에 마운트됩니다. 모든 API 라우트는 토큰 게이트 상태입니다. --no-web은 데몬을 API 전용으로 남깁니다.
--prompt-deadline-ms <n>양의 정수미설정서버 측 프롬프트 월클럭 제한(ms). 타임아웃 시 abort 후 에러 반환.
--writer-idle-timeout-ms <n>양의 정수미설정SSE 연결당 유휴 타임아웃(ms). 이 시간 동안 이벤트가 전송되지 않으면 daemon이 SSE 연결을 닫음.
--channel-idle-timeout-ms <n>음이 아닌 정수0마지막 세션이 닫힌 후 ACP 자식을 유지하는 시간. 0은 즉시 회수.
--initialize-timeout-ms <n>양의 정수10000initialize 핸드셰이크를 포함한 ACP 자식 요청 타임아웃(ms).
--session-restore-timeout-ms <n>양의 정수60000ACP 세션 로드/재개 타임아웃(ms). 이 플래그를 생략하면 명시적으로 제공된 initialize 타임아웃이 기본값을 높이되 낮추지는 않습니다.
--session-reap-interval-ms <n>음이 아닌 정수60000세션 리퍼 스캔 간격. 0은 비활성화.
--session-idle-timeout-ms <n>음이 아닌 정수1800000연결 해제된 세션의 유휴 회수 시간. 0은 비활성화.
--rate-limit / --no-rate-limitbooleanenv / off프롬프트, 변경, 읽기 라우트에 대한 티어별 HTTP 속도 제한 활성화.
--rate-limit-prompt <n>양의 정수10윈도우당 프롬프트 요청 제한. 속도 제한 활성화 필요.
