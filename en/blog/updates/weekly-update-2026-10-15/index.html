Qwen Code Weekly: @ Claude Code or Codex as Teammates, One Page Connects Several Qwen Code Projects, Name an MCP Server to Drop at Startup

Qwen Team
2026-10-15

Qwen Code shipped two stable releases this week — v0.25.1 and v0.25.2 — with 371 PRs merged.

Agent Collaboration: @ Claude Code or Codex into the conversation as a teammate. Its answer lands in the conversation you’re in. You can also send the work to another machine.

Every Qwen Code you have open stays connected in one page. Each one gets its own group in the sidebar, listing the sessions and workspaces it actually has right now. Switching between them happens inside the page.

Don’t want an MCP server this time? Name it at startup. qwen --disable-mcp-server <name> affects that run only and leaves your settings file untouched.

✨ New Features

Agent Collaboration: @ Claude Code or Codex into the Conversation as a Teammate

Sometimes you want one job split and run in parallel — it edits the code while another program checks the work. Before, @ an Agent and it opened a separate thread, copied over your last few messages, and threw you to that new page. The main conversation never got its answer.

Now when you @ it, it answers in the conversation you’re in: with a name, the step it’s on, the tools it used, and the token cost. Commands still pop up for your approval. The Agent doesn’t have to be Qwen Code — if you have Claude Code or Codex installed, @ it in and put it to work. See PR #13467 

It can also work on another machine. Run the Qwen Code server there, add it as a teammate, and hand the heavy jobs to that box; after that machine reboots, it reconnects on its own. You can @ a whole team too: the leader splits the work and assigns it, and the members report back to the leader. See PR #13583 

Here’s how it divides work with sub-agents. A sub-agent runs one small job for it and reports only to it. An @ teammate talks in front of you, can be another vendor’s program, and can sit on another machine.

This is experimental and off by default: turn on Enable Agent Collaboration in settings, then restart. Build the teammate first — create one on the Agents page in the left sidebar. After that, @ its name in any conversation to call it in.

What you can do:

  • Have it edit code while you @ another Agent to review it — both lines stay legible in one conversation
  • Hand builds and test runs to another machine and keep working here
  • Put programs from different vendors on one team, each taking the part it’s good at

Every Qwen Code You’ve Open, Connected in One Page

Some people have a laptop, a box dedicated to builds, and another one holding a long job. Some run a single machine with a separate Qwen Code Web Shell per project, because they don’t want jobs tangling together. Before, a browser page knew about only one of them. Looking at another meant reloading the whole page — a flash, and whatever you’d half-typed was gone.

Now all the ones you’ve saved stay connected at once. Each Qwen Code gets its own group in the sidebar, listing the sessions and workspaces it has right now; when you pick a workspace in the composer, the directories stay sorted by group too. Switching to another group happens inside the page. See PRs #13739 , #13677 

The machine being connected to has to let your page in first: start qwen serve with --allow-origin and the address you see in the browser bar.

What you can do:

  • A long build runs on that other box while you watch how far it’s got from your own machine
  • Open one per project on a single machine — the jobs stay separate and one page shows them all
  • Move from the laptop to the desktop and keep assigning work

Drop an MCP Server by Naming It at Startup

Anyone using MCP servers has hit this: one service misbehaves today, tools throw errors or startup gets slow, and all you want is to leave it out this once. Before, the only option was the all-or-nothing switch — turning off the servers from settings along with your local config.

Now you can name it at startup:

qwen --disable-mcp-server github

To drop several, repeat the flag or write --disable-mcp-server github,postgres. It applies to this startup only; your config file stays untouched. See PR #14003 

What you can do:

  • Suspect a service — leave it out for one run and see whether the problem goes with it
  • Startup dragged down by one service — skip it this time
  • Same codebase, one run on the database and one on the web, each carrying only its own servers

Web Shell: Click a Project File to Read It, Land a Follow-up Right Away, Get Pinged When It Needs You

Browse your project’s files in the right panel. The whole workspace directory tree sits there. Click a file and its contents open beside it: Markdown, web pages, images, and Excel all read directly. You can also copy the path, download, or reference it. See PRs #13878 , #13664 

Drag a local file in and it uploads. It goes to whichever folder you drop it on. Same in the desktop version. See PRs #14145 , #14053 

A queued message can jump the line, and a cancelled one goes back to the composer. Anything you send while it’s answering waits in a queue. Hit Send now to insert it immediately. Press stop before it has output anything, and your message returns to the composer so you can fix it and resend. See PRs #13681 , #13488 

It sends a notification when it stops and waits for you. Two cases: it needs you to approve an action, or it asked you something and needs an answer. Both went silent before. Now, as long as the page is in the background, you get a notification, and one click takes you back to that session. See PR #13832 

A sub-agent or background task running lights a pulsing dot on the list-style icon at the top of the chat. You see it without opening the panel. See PR #14048 

📊 More New Features

Keep looking without giving you a result? It gets reminded to conclude. Once read-only actions — reading files, searching code — pass a certain count, the next round hands it a reminder: use what it already found, push what you asked for one step further, or say where it’s stuck. If the job was to scope things out, state the conclusion and what’s still open. See PR #13601 

An interface that comes with an MCP server needs your go-ahead before it posts into the conversation. Some MCP servers give you more than tools — they put a clickable panel in the conversation. When that panel wants to send a message for you, Qwen Code lays out the full content, where it came from, and which conversation it’s headed to. Nothing goes out until you confirm. See PR #13958 

Click an agent’s node to see what it did in a workflow. Click an agent on the workflow card in the conversation, on the Tasks page, or on the workflow page, and the right panel opens its run: the prompt it was given, the tools it called, what it’s outputting, and the step it’s on. See PR #14175 

The check that runs before it acts can change the arguments for that run. A hook you configure in settings is exactly this check: it fires before a tool gets used. New arguments handed back by that check are re-validated, then go through permissions and confirmation again, before anything actually runs. See PR #13442 

A side question can open in another workspace. While the main task is answering, /btw side creates its own conversation in a secondary workspace, so it doesn’t mix into the main thread. See PR #13468 

Commands shipped inside Claude-format plugins actually run now. These commands are code, not a prompt for the model. Typing one used to amount to saying something to the model; now the plugin runs it locally and returns the result, spending no tokens. Turn on experimental.mods in settings and trust the workspace — and it only takes effect in one-shot usage like qwen -p '…', not the interactive UI or Web Shell yet. Only part of the Mod interface is implemented, so a ready-made command isn’t guaranteed to run. See PRs #13843 , #13890 , #13915 , #13950 

👏 Experience Improvements

On the new-task page, the files panel, terminal, and web preview work before you say a word. The top is a slim toolbar now. Each workspace remembers this layout on its own, so a refresh or a session switch doesn’t lose it. When you send your first message, the tabs, their order, the panel widths, and Fullscreen all carry over to the session that gets created. See PR #14159 

The Trajectory tab searches, filters, and pages back through history. Search a tool name, a model name, or any text in the records and it jumps there. Show only one kind of record, or only failures or only successes. Load older records a stretch at a time, and you come back to the newest one — search and stats cover only the stretch you’ve loaded. A mid-run disconnect and reconnect keeps where you stood, what you selected, your filters, and your scroll position. See PRs #13264 , #13716 , #13952 

Select part of an answer and choose how it copies. Drag over some text and the menu offers two: plain text, or Markdown with the formatting it was written in — headings, lists, code, and tables come along. See PR #13833 

Context usage opens in the right panel on one click, instead of stacking cards in the conversation. Clicking the ring on the composer used to drop a Context Usage card into the conversation, and the details on that card dropped another. Both open in the right panel now, one per session. Want it in the conversation? Type /context. See PR #14086 

A wide, long table can go fullscreen. Click Fullscreen on the table and it fills the window. Esc or the exit button brings you back; your sort, filters, column settings, and the row you’d read to are all still there. See PR #13589 

Delete a queued message right there, before it goes out. That works for a message whose attachment is still uploading, and the temporary file gets cleaned up with it. See PR #13594 

Collapse a turn and the finished background results go into the fold with it. Background task output cards and their completion notifications fold away together. See PR #13825 

Voice-input prompts come in Chinese, and an error can be dismissed. Errors and messages like “no audio detected” follow the interface language. Click close in the top-right of the prompt and the mic returns to ready — try again straight away. See PR #13938 

Want an independent copy? Selecting Worktree settles it. Click it in the Git dialog and it’s chosen, the menu closes. Only when you send your first message does it name and create that copy, following the session-creation flow; change your mind any time before that. See PR #13607 

Icons now match the current brand mark. Changed: the Web Shell’s browser tab icon, the sidebar logo, browser notification icons, and the desktop version’s splash image and app icons. See PR #14052
